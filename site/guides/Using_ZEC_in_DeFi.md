# Using Zcash in DeFi


## Near Intents 

Zcash and NEAR Intents have been integrated, allowing users to swap Zcash (ZEC) with other top altcoins, including Bitcoin, Solana, NEAR, and XRP, without paying any fees. This integration is part of NEAR Protocol's efforts to create an infrastructure of autonomous and verifiable AI bots, which also brings benefits to Zcash by enabling AI-powered payment rails. Zcash users are now capable of accessing smart contracts and wider [DeFi applications](https://nym.com/blog/what-is-defi) while preserving their privacy via [Near Intents](https://app.near-intents.org).

## Kamino

[Kamino](https://kamino.com/earn/lend) is one of the leading DeFi protocols in the Solana ecosystem, providing services such as lending, borrowing, liquidity vaults, and automated liquidity management. Through integration with the Solana ecosystem, Zcash (ZEC) users can utilize Solana-based Wrapped ZEC assets to interact with various DeFi applications.

By using Solana Wrapped ZEC, users can access Kamino’s Earn and Lending features, allowing ZEC to be used as a productive asset through decentralized liquidity provision and lending mechanisms. This expands Zcash’s functionality from a private payment asset to one that can participate in decentralized financial activities.

The integration with Kamino opens up opportunities for Zcash to enter the Solana DeFi ecosystem, which features fast transactions, low fees, and a wide range of smart contract-based financial applications.

## ZenRock Bridge

[ZenRock Bridge](https://zenrocklabs.io/) provides a blockchain interoperability solution that enables the secure and efficient transfer of assets across networks.

In the context of Zcash, bridge technologies like ZenRock allow ZEC assets to connect with other blockchain ecosystems that support smart contracts and DeFi applications. This enables users to bring the value of Zcash to various networks without losing flexibility in how they use their assets.

Interoperability is a critical component in the development of DeFi because it allows assets from a specific blockchain to participate in a cross-network digital economy.

## Solana Wrapped ZEC Ecosystem (Meteora, Orca, and Raydium)

Solana Wrapped ZEC enables Zcash to be used within the Solana ecosystem through an asset representation compatible with the Solana network standard.

With Wrapped ZEC, users can interact with various DeFi protocols such as:

- Liquidity pools
- Decentralized exchanges (DEX)
- Yield farming
- Automated market making

Protocols such as [Meteora](https://www.meteora.ag/), [Orca](https://www.orca.so/), and [Raydium](https://raydium.io/swap/?inputMint=sol&outputMint=4k3Dyjzvzp8eMZWUXbBCjEvwSkkk59S5iCNLY3QrkX6R) provide liquidity infrastructure that enables ZEC to participate in trading and liquidity provision activities.

This integration combines Zcash’s privacy advantages with the speed and efficiency of the Solana network, creating new use cases for private assets within the modern DeFi ecosystem.

## THORChain / THORSwap

[THORChain](https://thorchain.org/) is a cross-chain liquidity protocol that allows users to exchange native assets from various blockchains without relying on traditional wrapped tokens.

Through [THORChain](https://thorchain.org/) and [THORSwap](https://thorswap.finance/), users can exchange assets across blockchains, including Zcash (ZEC). This integration gives Zcash direct access to decentralized liquidity via the THORChain network, allowing users to retain the characteristics of native assets without having to use centralized intermediaries.

With the introduction of the ZEC pool on [THORChain](https://thorchain.org/), the [THORChain](https://thorchain.org/) network now supports permissionless Zcash liquidity activities. [THORChain](https://thorchain.org/) nodes can monitor the Zcash blockchain and provide the infrastructure for cross-chain trading between ZEC and other blockchain assets.

This integration offers several benefits for the Zcash ecosystem:

- Access to cross-blockchain liquidity;
- ZEC trading without reliance on centralized exchanges;
- Enhanced interoperability with other blockchain assets;
- Expanded use of ZEC within the multichain DeFi ecosystem.

Learn More on: </br> 1. [THORChain Vision](https://thorchain.org/vision) </br>
               2. [THORSwap Learn](https://docs.thorswap.finance/thorswap)

## Innovation around Zcash DeFi 

**Layer 1 Solution**

Options are currently being explored to enable DeFi applications within the Zcash ecosystem using the current Layer 1. This could be possible by perofrming most of the contract operations off-chain with a sequencer & have the validation of those actions done on chain. A version of this was created in partnership with JP Morgan on their enterprise blockchain. As of NU5 a mechanism exists (TZE) to add this type of extension to Zcash. 

**zkEVM**

This would bring native programmability to Zcash with an EVM-compatible virtual machine that supports zero-knowledge proof computation. This would allow Zcash to find growth through a more diverse developer community and foster an ecosystem of privacy preserving applications and tokens. This would make it comparable to other existing L2 privacy solutions. 

Continuing research into Proof-of-Stake & the Cosmos Interblockchain Communication Protocol is led by the ECC. Next steps are being assessed along with the success of the Ethereum Merge to PoS with any issues that may arise. 

**ZSA/UDA's**

Zcash Shielded Assets / User Defined Assets have been in development with the assistance of a dedicated team. Following the NU5 protocol upgrade they are significantly closer to fruition. Mechanisms for trustless & private cross-chain bridging of these assets enabling interoperability are currently in the works. A link to the Zcon3 presentation on this below.
