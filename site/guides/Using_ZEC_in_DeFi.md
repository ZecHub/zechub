## THORChain / THORSwap

[THORChain](https://thorchain.org/) is a cross-chain liquidity protocol that allows users to exchange native assets from various blockchains without relying on traditional wrapped tokens.

Through [THORChain](https://thorchain.org/) and [THORSwap](https://thorswap.finance/), users can exchange assets across blockchains, including Zcash (ZEC). This integration gives Zcash direct access to decentralized liquidity via the THORChain network, allowing users to retain the characteristics of native assets without having to use centralized intermediaries.

With the introduction of the ZEC pool on [THORChain](https://thorchain.org/), the [THORChain](https://thorchain.org/) network now supports permissionless Zcash liquidity activities. [THORChain](https://thorchain.org/) nodes can monitor the Zcash blockchain and provide the infrastructure for cross-chain trading between ZEC and other blockchain assets.

This integration offers several benefits for the Zcash ecosystem:

- Access to cross-blockchain liquidity;
- ZEC trading without reliance on centralized exchanges;
- Enhanced interoperability with other blockchain assets;
- Expanded use of ZEC within the multichain DeFi ecosystem.

## Using cbZEC on DeFi Base

cbZEC brings Zcash liquidity into the Base ecosystem by allowing ZEC users to interact with various decentralized finance (DeFi) applications without having to give up their exposure to the Zcash ecosystem.

Through the [Base network](https://www.base.org/), cbZEC serves as a representation of ZEC that can be used within the Ethereum Layer-2 environment. This allows users to exchange assets, provide liquidity, access lending markets, and utilize various DeFi services with lower transaction fees and faster confirmations compared to the main Ethereum network.

[The integration](https://x.com/base/status/2094848959986409953?s=20) of cbZEC into various Base DeFi platforms expands Zcash’s utility from merely a payment asset to one that can be used in a wide range of decentralized financial activities.

## Innovation around Zcash DeFi 

**Layer 1 Solution**

Options are currently being explored to enable DeFi applications within the Zcash ecosystem using the current Layer 1. This could be possible by perofrming most of the contract operations off-chain with a sequencer & have the validation of those actions done on chain. A version of this was created in partnership with JP Morgan on their enterprise blockchain. As of NU5 a mechanism exists (TZE) to add this type of extension to Zcash. 

**zkEVM**

This would bring native programmability to Zcash with an EVM-compatible virtual machine that supports zero-knowledge proof computation. This would allow Zcash to find growth through a more diverse developer community and foster an ecosystem of privacy preserving applications and tokens. This would make it comparable to other existing L2 privacy solutions. 

Continuing research into Proof-of-Stake & the Cosmos Interblockchain Communication Protocol is led by the ECC. Next steps are being assessed along with the success of the Ethereum Merge to PoS with any issues that may arise. 

**ZSA/UDA's**

Zcash Shielded Assets / User Defined Assets have been in development with the assistance of a dedicated team. Following the NU5 protocol upgrade they are significantly closer to fruition. Mechanisms for trustless & private cross-chain bridging of these assets enabling interoperability are currently in the works. A link to the Zcon3 presentation on this below.
