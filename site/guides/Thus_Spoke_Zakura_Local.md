# Thus Spoke Zakura (THS) — Local Regtest Development

Thus Spoke Zakura (`ths`) is a disposable Zcash **Regtest** environment that runs Zakura, lightwalletd, and a wallet-backed dashboard. It is the fastest way to test wallets, applications, and protocol behaviour (including NU7) on your own machine.

**v0.5.0** (25 November 2026) makes the native runtime the default and adds flexible mining controls, a configurable NU7 activation height, new CLI tools, and Node.js test integration.

> **Warning**: Regtest only. Test coins have no value and development keys are public. Never send real funds to an address generated by this environment.

---

## Quick start

On macOS 12+ or Linux with glibc 2.35+ (Intel or ARM):

```bash
curl --proto '=https' --tlsv1.2 -fsSL https://raw.githubusercontent.com/zcashlabs/thus-spoke-zakura/main/install.sh | sh
ths start
```

Startup may take a few minutes. When `ths` prints that the instance is ready, it opens the dashboard. Keep the terminal open while you use it.

Account 1 starts with 5 Ironwood ZEC. Use the dashboard or CLI to fund other accounts and send payments.

---

## Mining controls

v0.5.0 adds several ways to control block production:

| Mode | Command | Use case |
|------|---------|----------|
| Manual | Default or `--no-auto-mine` | Precise control over when blocks are produced |
| Fixed interval | `ths start --block-time <SECONDS>` | Simulate steady block times |
| Mempool-triggered | `ths start --mine-on-mempool` | Mine as soon as a transaction appears |
| Disable auto-mine | `--no-auto-mine` | Full manual control |

Example for a 10-second block interval:

```bash
ths start --block-time 10
```

---

## Configurable NU7 activation

You can choose the block height at which NU7 activates:

```bash
ths start --nu7-height 100
```

The chosen height is shown on the Network page of the dashboard. This is useful for testing wallet and protocol behaviour both before and after NU7 activation on a private chain.

---

## RPC querying

Query the Zakura node directly:

```bash
ths rpc getblockchaininfo
ths rpc getinfo
```

`ths endpoints --json` (or `--env`) prints the local API, Zakura RPC, and lightwalletd addresses for the running instance.

---

## Other useful CLI commands

- `ths completions` — generate shell completions
- `ths wallet send --to-address <ADDRESS>` — send to an external address
- `ths wallet quote` — obtain a payment quote
- `ths reorg --depth 3` / `ths rollback --depth 3` — test chain reorganisations

---

## Node.js testing

The `@zcashlabs/thsjs` package (available from source) lets you start and stop isolated THS networks from Node.js tests. This is useful for automated integration tests that need a clean Regtest chain.

See the repository for usage details: [github.com/zcashlabs/thus-spoke-zakura](https://github.com/zcashlabs/thus-spoke-zakura).

---

## Docker alternative

Native runtime is the default in v0.5.0. To use Docker instead:

```bash
ths start --docker
```
