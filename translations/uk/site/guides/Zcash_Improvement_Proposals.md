# Що таке ZIP
Пропозиція щодо вдосконалення Zcash (ZIP) — це документ із проєктним описом, який надає інформацію спільноті Zcash або описує нову функцію для Zcash, його процесів чи середовища. ZIP має містити стислу технічну специфікацію цієї функції та обґрунтування її потреби.

ZIP-и задумані як основний механізм для пропонування нових функцій, збору відгуків спільноти щодо певного питання та документування проєктних рішень, які були прийняті в Zcash. Власник(и) ZIP (зазвичай автор(и)) відповідає(ють) за досягнення консенсусу в спільноті та документування окремих думок, що не збігаються із загальною позицією.

Оскільки ZIP-и підтримуються як текстові файли у версійному репозиторії, історія їхніх змін є історичним записом пропозиції щодо функції.

-> [zips.z.cash](https://zips.z.cash)


## Редактори ZIP

Кожен ZIP, що надходить, має пройти процес перевірки. Завдання редакторів ZIP — забезпечити, щоб формат і зміст будь-якого ZIP належним чином описували терміни, обґрунтування та внесені технічні зміни. 

```markdown
* Jack Grigg, Kris Nuttycombe and Daira-Emma Hopwood associated with the ECC.
* Conrado, and Arya, associated with the ZF.
* Sam and Mark, associated with SL.
```
