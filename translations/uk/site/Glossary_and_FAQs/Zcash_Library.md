## P

| Term | Definition |
|------|-----------|
| Payments | Використовувати Zcash для повсякденних покупок можливо через низку різних платіжних провайдерів. [Платіжні застосунки](https://z.cash/pay-with-zcash/) |

Project Tachyon перебудовує захищений протокол навколо PCD, дозволяючи кожному гаманцю мати рекурсивний доказ того, що його власний баланс є правильним, замість повторного сканування ланцюга. | PIR (Private Information Retrieval) | Методи, які дають змогу отримати запис із сервера так, щоб сервер не дізнався, який саме запис ви запитали. Активно досліджуються для Zcash як спосіб для легких гаманців отримувати потрібні їм дані, не розкриваючи, що саме вони шукають. |

## Q

| Term | Definition |
|------|-----------|
| QR Code | Машинозчитуваний код, що використовується для кодування адрес Zcash для зручного сканування. Unified Addresses (UA) зазвичай поширюються через QR-коди в сучасних гаманцях Zcash. |
| Quantum Recoverability | Властивість нот Ironwood, визначена в [ZIP 2005](https://zips.z.cash/zip-2005), яка дає змогу зберегти відновлюваність ончейн-запису монети, якщо майбутній квантовий комп’ютер зламає криптографію, що захищає її сьогодні. |------|-----------|
| Tachyon | Програма масштабування Zcash, орієнтована на NU7. Вона відводить гаманці від сканування кожного блоку в бік стану гаманця з доказами, неявної синхронізації та стану вузла, який можна скорочувати, з метою досягти пропускної здатності екранованих транзакцій на рівні тисяч транзакцій за секунду. [Сайт проєкту](https://tachyon.z.cash/overview/) |
| TAZ | Testnet Zcash (тестова валюта без вартості). |
| Testnet | Окремий блокчейн для тестування оновлень і функцій перед mainnet. |
| Trailing Finality Layer (TFL) | Дослідження щодо додавання шару фінальності поверх ланцюга Zcash з доказом виконаної роботи, щоб нещодавні блоки можна було фіналізувати без заміни майнінгу. Crosslink — це дизайн, що виник у результаті цього. |
| Transaction | Платіж між користувачами, надісланий у мережу та зрештою підтверджений у блоці. |
| Transaction Expiry | Транзакції завершують дію приблизно через 25 хвилин (20 блоків), якщо не підтверджені; кошти повертаються автоматично. |
| Transaction Fee | Стандартна комісія становить 0.0001 ZEC. Вищі комісії отримують пріоритет; дуже низькі комісії можуть спричинити затримки або завершення дії. |
| Transparent Address | Також називається taddr. Починається з t. Повністю публічна (як Bitcoin). |
| Transparent Transaction | Транзакція виключно між прозорими адресами — усе є публічно видимим. |
| Turnstile | Правило обліку, яке відстежує, скільки цінності входить до кожного екранованого пулу та виходить із нього, щоб жоден пул не міг вивести більше, ніж у нього надійшло. Використовується на кожному переході між пулами в історії Zcash і наразі захищає міграцію з Orchard до Ironwood. [Докладніше](/zcash-tech/the-turnstile) |

## U

| Term | Definition |
|------|-----------|
| Unified Address | Сучасний формат адреси (запроваджений у NU5), який працює як для прозорих, так і для shielded-платежів в одному рядку. |
| Upgrade Activation | Конкретна висота блока, на якій мережеве оновлення (наприклад, NU5, NU6) автоматично активується. |

## V

| Term | Definition |
|------|-----------|
| Viewing Key | Приватний ключ, який дозволяє переглядати баланс і історію транзакцій shielded-адреси без можливості витрачати кошти. |

## W

| Term | Definition |
|------|-----------|
| Wallet | Програмне або апаратне забезпечення, яке зберігає приватні ключі та дозволяє надсилати/отримувати ZEC. До активних гаманців належать ZODL (iOS/Android), Zingo! (мобільний/десктопний), Nighthawk (Android), YWallet, Zallet (незабаром) і Keystone (апаратний). Повний список дивіться у [Гаманці екосистеми Zcash](https://z.cash/ecosystem/?wallets=#tag-wallets) |
| WebZjs | Перший JavaScript SDK для Zcash, створений ChainSafe для браузерних середовищ. Він лежить в основі снапу Zcash Shielded Wallet, який приніс shielded ZEC до MetaMask. |

## X

| Term | Definition |
|------|-----------|
| XZC | Старіший тікерний символ для Zcash, який використовується на деяких застарілих біржах. Офіційний тікер — ZEC. |

## Y

| Term | Definition |
|------|-----------|
| YWallet | Гаманець Zcash, орієнтований на приватність, з підтримкою Orchard, Sapling і прозорих адрес, відомий швидкою синхронізацією. Більше не підтримується: його розробник підтвердив, що він не буде оновлений для Ironwood, тому більше не може слідувати за мережею. Zkool, від того ж розробника, є підтримуваним наступником. |

## Z

| Term | Definition |
|------|-----------|
| Zcash | Криптовалюта, орієнтована на приватність, яка використовує zk-SNARKs. Поєднує прозорі платежі (у стилі Bitcoin) і повністю shielded-платежі. |
| Zcash Foundation | Незалежна неприбуткова організація, яка підтримує екосистему Zcash, фінансує розробку та просуває приватність. |
| Zcash Network | Однорангова мережа вузлів, яка перевіряє транзакції та підтримує блокчейн. |
| ZEC | Офіційний код валюти для Zcash (деякі біржі досі показують XZC). |
| Zerocash | Академічний протокол (2014), на якому базується Zcash. |
| Zaino | Індексатор Zcash нового покоління, який замінює lightwalletd і розробляється Zcash Foundation. Дає змогу light-клієнтам синхронізуватися швидше й приватніше. Частина інфраструктурного оновлення Zcash Z3. |
| Zakura | Реалізація повного вузла Zcash, випущена у липні 2026 року, створена як форк Zebra компаніями Valar Group і Project Tachyon. Орієнтована на пропускну здатність і швидкість синхронізації, із завантаженням через snapshot і заявленою метою досягти масштабу карткових мереж — близько 50 000 транзакцій за секунду. [zakura.com](https://zakura.com) |
| Zallet | Компонент гаманця, який перебрав на себе функції гаманця zcashd після його виведення з експлуатації, побудований на Zaino як частина інфраструктурної роботи Zcash Z3. |
| Zebra | Реалізація повного вузла Zcash від Zcash Foundation на Rust (альтернатива zcashd). Готова до використання в production і активно підтримується. [GitHub](https://github.com/ZcashFoundation/zebra) |
| zcashd | Оригінальний повний вузол Zcash, відгалужений від Bitcoin Core. Виведений з експлуатації в липні 2026 року після тривалого етапу deprecation, а його ролі були розподілені між Zebra для консенсусу та Zallet для функцій гаманця. |
| ZIP | Zcash Improvement Proposal — процес врядування спільноти, який використовується для пропонування та ратифікації змін протоколу. [Репозиторій ZIP](https://github.com/zcash/zips) |
| ZODL | Zcash Open Development Lab. Незалежна організація, заснована на початку 2026 року Josh Swihart і колишньою інженерною командою Electric Coin Company після їхньої відставки через суперечку щодо врядування з Bootstrap. У березні 2026 року вона залучила понад 25 мільйонів доларів seed-фінансування та підтримує гаманець Zodl, який у лютому 2026 року був перейменований із Zashi. [zodl.com](https://zodl.com) |
| zk-SNARKs | Zero-Knowledge Succinct Non-Interactive Arguments of Knowledge — криптографія, що лежить в основі shielded-транзакцій Zcash. Дозволяє довести твердження (наприклад, коректне витрачання), не розкриваючи жодної секретної інформації. |
| ZSA (Zcash Shielded Assets) | Токени, випущені користувачами, які успадковують shielded-приватність Zcash, даючи змогу активам, відмінним від ZEC, приватно переміщуватися мережею. Описані в [ZIP 226](https://zips.z.cash/zip-0226) і є кандидатною функцією для NU7. |
