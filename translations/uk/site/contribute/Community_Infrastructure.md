# Структура інфраструктури спільноти ZecHub


### Інфраструктура спільноти

Програма винагород ZecHub пропонує розробникам вільнішу й спрощенішу альтернативу окремим завданням: [Винагороди ZEC](https://bounties.zechub.wiki/).


## Корисні посібники

- [Посібник для розробників ZecHub](https://zechub.wiki/developers)

- [Документація Zcash](https://zcash.readthedocs.io/en/latest/)

- [Книга Zebra](https://zebra.zfnd.org)

- [Документація Akash Network](https://akash.network/docs/)

- [Налаштування Zebrad в Akash Network](https://zechub.wiki/guides/akash-network-zebra#content)

- [Пояснення запитів на платежі Zcash (відео)](https://www.youtube.com/watch?v=l5auYQIzYsQ)

- [Специфікація ZIP-321](https://zips.z.cash/zip-0321)

Якщо вам потрібна ґрунтовна порада від розробників Zcash, ви можете створити допис на [Форумі спільноти](https://forum.zcashcommunity.com).
