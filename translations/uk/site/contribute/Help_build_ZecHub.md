# Допоможіть розбудовувати ZecHub 

Якщо ви є учасником спільноти Zcash і хочете долучитися до розбудови ZecHub, є кілька надзвичайно корисних способів це зробити.

Добирайте посилання для розсилки та додавайте їх на сторінку розсилки в GitHub: -> [Натисніть тут, щоб переглянути інструкції](https://github.com/ZecHub/zechub/blob/main/site/contribute/ZecWeekly_Newsletter.md)

Перевіряйте факти у вікідокументах, пропонуйте зміни та нові сторінки в Github

Створюйте відеоконтент у таких категоріях:
```
* Zcash explainer videos
* Zcash wallet guide/tutorials
* Third-party application demos
```

Створюйте дизайни, як-от постери/графіку/анімації, для екосистеми Zcash і Privacy 

Перекладайте будь-які наявні сторінки вікі.

Повідомляйте про помилки

#### Щоб дізнатися про розміри винагород, будь ласка, прочитайте нашу сторінку для учасників -> [тут](https://zechub.wiki/contribute/contributing-guide#content).

Щопонеділка ми публікуємо завдання, за які наразі відкрито винагороди. Ви також можете пропонувати винагороди! Переважно їх можна знайти в ZEC Bounties.

![zecbounties](/content-images/0e4f5109-c0c9-4a0a-8d71-8172e36b9726-1a94469edf.webp)



[ZEC Bounties](https://bounties.zechub.wiki/)

[ZecHub Завдання Github](https://github.com/ZecHub/zechub/issues)

[ZecHub-Вікі: завдання Github](https://github.com/ZecHub/zechub-wiki/issues)



Якщо ви хочете долучитися в інший спосіб, напишіть ZecHub ([@ZecHub](https://twitter.com/zechub)) у Twitter або приєднуйтеся до нашого [Discord](https://discord.gg/zcash).

**( Zcash | Namada | Penumbra | Ycash ) адресою**
