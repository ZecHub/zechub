# Крани

<img width="2138" height="878" alt="Screenshot_2025-10-30_10-36-45" src="/content-images/bba0da3b-7064-4680-9535-a0dfcf50cc00-1827fccf4b.webp" />


Крани — це сервіси, які безкоштовно видають невеликі суми криптовалюти. Їх часто використовують розробники для експериментів із криптовалютою, а також користувачі, щоб отримати невеликі суми криптовалюти без необхідності її купувати. Зазвичай вони обмежують кількість криптовалюти, яку користувач може отримати протягом певного проміжку часу.
