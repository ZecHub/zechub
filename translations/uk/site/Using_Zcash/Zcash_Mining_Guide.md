# Посібник із майнінгу Zcash: приєднання до майнінг-пулу з особистим обладнанням

## Вступ

Zcash (ZEC) — це криптовалюта, орієнтована на приватність, яка використовує для майнінгу алгоритм доказу виконаної роботи Equihash. Майнінг Zcash передбачає використання обчислювальної потужності для розв’язання складних математичних задач, підтвердження транзакцій і захисту мережі в обмін на винагороди в ZEC. Через високу складність мережі соло-майнінг не рекомендується більшості користувачів. Приєднання до майнінг-пулу — найкращий спосіб отримувати стабільні винагороди, об’єднуючи свою хеш-потужність з іншими.

Цей посібник зосереджений на майнінгу Zcash за допомогою особистого обладнання (наприклад, домашнього ПК з GPU або початкових ASIC). Зверніть увагу, що хоча GPU все ще можуть майнити Zcash, у 2026 році ASIC набагато ефективніші та прибутковіші через складність мережі. Завжди перевіряйте поточну прибутковість за допомогою таких інструментів, як WhatToMine.com, оскільки на доцільність впливають вартість електроенергії, ціни на обладнання та вартість ZEC. Майнінг може бути не прибутковим для всіх; вивчіть місцеві правила та тарифи на електроенергію (орієнтуйтеся на < $0.08/kWh).


## Вимоги

### Обладнання
- **GPU-майнінг (особисте налаштування, рекомендоване для початківців):**
  - GPU NVIDIA або AMD щонайменше з 4 ГБ VRAM (наприклад, NVIDIA GTX 1070, RTX 3060; AMD RX 580 або кращі).
  - Сумісна материнська плата, достатньо потужний блок живлення (щонайменше 750W для кількох GPU) і хороше охолодження для запобігання перегріву.
  - Установки з кількома GPU поширені для досягнення вищого хешрейту (наприклад, 6x GPU можуть забезпечити 1-2 kSol/s).
- **ASIC-майнінг (ефективніший, але дорожчий):**
  - Сумісні з Equihash ASIC, такі як Bitmain Antminer Z15 (420 kSol/s) або Innosilicon A9 (50 kSol/s).
  - Вони гучніші, гарячіші та споживають більше енергії (наприклад, 1500W+); підходять для спеціально відведених приміщень. Купуйте в надійних джерелах, таких як Bitmain.com або реселери (Blockware Mining).
- **Загальне:** Стабільний інтернет, комп’ютер для налаштування/моніторингу. ASIC домінують у мережі (~13 GSol/s загального хешрейту у 2026 році), через що GPU-майнінг менш конкурентний, але все ще можливий для ентузіастів.

### Програмне забезпечення
- **Операційна система:** Windows 10/11, Linux (для стабільності рекомендується Ubuntu).
- **Програмне забезпечення для майнінгу:**
  - Для GPU: lolMiner (підтримує AMD/NVIDIA), GMiner або miniZ (орієнтований на NVIDIA). Завантажуйте з офіційних GitHub-репозиторіїв (наприклад, github.com/Lolliedieb/lolMiner-releases).
  - Для ASIC: використовуйте вбудовану прошивку/панель керування виробника (наприклад, вебінтерфейс Bitmain).
- **Гаманець:** Гаманець Zcash для отримання виплат. Рекомендовано:
  - Екранований (приватний): Zashi Wallet, Zingo (мобільний/десктопний) YWallet (мобільний/десктопний).
  - Прозорий (простіший, але менш приватний): Edge Wallet, Zecwallet Lite.
  - Завантажуйте з [гаманців](https://zechub.wiki/wallets). Для приватності згенеруйте екрановану адресу (починається з 'zs'), якщо пул її підтримує.

### Інше
- Електроенергія: розрахуйте витрати. GPU споживають 150-300W на карту; ASIC 1000W+.
- Антивірус: вимкніть під час налаштування, оскільки він може позначати майнери як загрози.

## Покроковий посібник із приєднання до майнінг-пулу

### Крок 1: Налаштуйте свій гаманець Zcash
1. Завантажте та встановіть гаманець з офіційного сайту Zcash у розділі [гаманці](https://zechub.wiki/wallets).
2. Створіть новий гаманець і надійно збережіть свою seed-фразу.
3. Згенеруйте адресу для отримання коштів (бажано екрановану для приватності). Запишіть її, наприклад: `zs1exampleaddress...`.
4. Якщо ви використовуєте прозору адресу (починається з 't'), це простіше, але забезпечує меншу приватність.

### Крок 2: Підготуйте своє обладнання
- Для GPU:
  1. Встановіть GPU у свій ПК і оновіть драйвери (NVIDIA: GeForce Experience; AMD: Radeon Software).
  2. Виконайте розгін, якщо маєте досвід (використовуйте MSI Afterburner для стабільності; орієнтуйтеся на +100-200 core clock, -500 memory для ефективності).
- Для ASIC:
  1. Підключіть ASIC до живлення та Ethernet.
  2. Знайдіть його IP-адресу за допомогою такого інструмента, як Advanced IP Scanner, або застосунку виробника.
  3. Увійдіть у вебпанель керування (наприклад, введіть IP у браузері, стандартний логін: root/root для Bitmain).

**Попередження:** Забезпечте належну вентиляцію; майнінг генерує тепло. Починайте з малого, щоб протестувати налаштування.

### Крок 3: Оберіть майнінг-пул і приєднайтеся до нього
Майнінг-пули розподіляють роботу та ділять винагороди залежно від внесеного вами хешрейту. Обирайте за комісіями (0-2%), мінімумом виплати (0.01-0.1 ZEC), розташуванням (низький ping) і надійністю.

**Рекомендовані пули (на основі хешрейту, комісій і відгуків):**
- **2Miners (zec.2miners.com)**: комісія 1%, виплати PPLNS, підтримує GPU/ASIC/NiceHash. Високий хешрейт (~1.17 GSol/s), надійні сервери.
- **F2Pool (zec.f2pool.com)**: комісія 2%, виплати PPS+, підтримка кількох монет. Великий пул (~2.57 GSol/s).
- **ViaBTC (zec.viabtc.com)**: комісія 2% (PPS+), зручна панель керування, глобальні сервери.
- **AntPool (zec.antpool.com)**: комісія 1%, від Bitmain, добре підходить для ASIC (~494 MSol/s).
- **Sovright (mining.sovright.com)**: пул Zcash, побудований на Stratum V2, який наразі працює як публічний testnet. Поки що немає реальних виплат у ZEC, тож розглядайте його як спосіб протестувати своє налаштування, а не як джерело доходу. Докладніше дивіться в окремому розділі нижче.
- Інші: Kryptex Pool, Luxor (перевіряйте poolwatch.io/coin/zcash для статистики в реальному часі).

1. Відвідайте сайт пулу та створіть обліковий запис (email або без реєстрації для деяких, як-от 2Miners).
2. Додайте адресу свого гаманця Zcash у налаштуваннях для виплат.
3. Запишіть stratum-сервер пулу (наприклад, zec.2miners.com:1010) і порт.

### Крок 4: Встановіть і налаштуйте програмне забезпечення для майнінгу
- Для GPU (приклад: lolMiner на Windows/Linux):
  1. Завантажте lolMiner з GitHub (остання версія, наприклад, 1.88).
  2. Розпакуйте в папку.
  3. Створіть batch-файл (start.bat) з конфігурацією:
     ```
     lolMiner.exe --coin ZEC --pool zec.2miners.com:1010 --user YOUR_WALLET_ADDRESS.WORKER_NAME --pass x
     ```
     - Замініть `YOUR_WALLET_ADDRESS` на свою адресу ZEC.
     - `WORKER_NAME`: назва для вашої установки (наприклад, Rig1).
     - Для серверів у ЄС: eu.zec.2miners.com:1010.
  4. Запустіть batch-файл. Він підключиться до пулу та почне майнінг.
- Для ASIC (приклад: Bitmain Antminer):
  1. Увійдіть у вебпанель керування.
  2. Перейдіть до Miner Configuration.
  3. Додайте дані пулу:
     - URL: stratum+tcp://zec.2miners.com:1010
     - Username: YOUR_WALLET_ADDRESS.WORKER_NAME
     - Password: x (або порожньо).
  4. Збережіть і перезавантажте майнер.
- Для іншого програмного забезпечення (наприклад, GMiner):
  ```
  miner.exe --algo 125_4 --server zec.2miners.com:1010 --user YOUR_WALLET_ADDRESS.WORKER_NAME --pass x
  ```

**Тест:** Запустіть на 10-15 хвилин; перевірте консоль на наявність прийнятих шар і хешрейту.

### Крок 5: Почніть майнінг і здійснюйте моніторинг
1. Запустіть майнер: він підключиться до пулу й почне надсилати шари.
2. Здійснюйте моніторинг через:
   - Панель пулу: введіть адресу свого гаманця, щоб побачити хешрейт, невиплачений баланс і статистику.
   - Консоль програми: стежте за помилками, температурою (тримайте < 80 градусів C).
   - Інструменти: використовуйте HiveOS або SimpleMining OS для віддаленого керування установкою.
3. Виплати: більшість пулів виплачують автоматично, коли ви досягаєте мінімуму (наприклад, 0.05 ZEC). Перевіряйте правила пулу.

## Sovright: testnet-пул і мережа ретрансляції

Sovright (sovright.com) запускає майнінг-пул Stratum V2 і окрему мережу ретрансляції блоків. Вони виконують різні завдання, тому нижче розглядаються окремо.

### Майнінг-пул (mining.sovright.com)

Пул Sovright працює в публічному testnet Zcash (NU6, Stratum V2), а не в mainnet. Testnet не виплачує реальні ZEC. Використовуйте його для тестування конфігурації свого майнера, а не для заробітку.

- Для початку обліковий запис не потрібен. Спрямуйте CPU- або ASIC-майнер Equihash на пул, і ваші шари з’являться на живій панелі керування.
- Sovright також публікує open source проксі Stratum V2 для майнерів, які хочуть самі обирати шаблони блоків замість того, щоб просто брати завдання пулу:
  ```
  git clone https://github.com/sovright/mining-infra
  cd mining-infra
  cargo build --release -p sovright-v1-stratum-proxy
  ./target/release/sovright-v1-stratum-proxy --listen 0.0.0.0:3334 --upstream 34.28.134.13:3333
  ```
  Спрямуйте свій майнер на проксі замість прямого підключення до пулу:
  ```
  stratum+tcp://<your-proxy-ip>:3334
  ```
  використовуючи ім’я воркера на кшталт `yourname.rig1`.
- На сторінці прозорості Sovright вказано політику "include all" для екранованих транзакцій, на відміну від деяких пулів, які їх фільтрують. Кожен блок отримує підписану атестацію, щоб цю політику можна було перевірити незалежно.
- Створіть обліковий запис на mining.sovright.com (вхід через Google або email), щоб відстежувати власних воркерів замість зразкових даних на панелі керування.

### Мережа ретрансляції (relay.sovright.com)

Окремо Sovright запускає публічну мережу ретрансляції блоків у mainnet Zcash. Коли пул знаходить блок, швидкість, з якою цей блок досягає решти мережі, визначає, як часто він стає orphaned, тобто програє гонку розповсюдження, і винагорода за нього втрачається. Ретранслятор пересилає блоки між чотирма регіонами, використовуючи compact block relay з forward error correction.

Публічна панель керування показує ефект у реальному часі: регіони, підключені до relay, отримують нові блоки значно менш ніж за половину часу, потрібного звичайному peer to peer gossip, а панель відстежує поточний рівень orphan-блоків у мережі.

Це інфраструктура для операторів пулів, а не для окремих майнерів. Open source репозиторій `mining-infra` від Sovright документує шлюз ретрансляції `submitblock` для швидшого поширення знайдених блоків у mesh, ніж це робить нативний P2P. Щоб підключитися, зверніться безпосередньо до Sovright (support@sovright.com), щоб отримати адреси relay-вузлів і auth key.


## Поради та найкращі практики
- **Прибутковість:** Використовуйте калькулятори на кшталт whattomine.com/coins/166-zec-equihash. Приклад: RTX 3060 (~300 Sol/s) приносить ~0.001 ZEC/день при $50/ZEC, мінус ~$0.50 за електроенергію.
- **Приватність:** Використовуйте екрановані пули, якщо вони доступні; уникайте повторного використання адрес.
- **Безпека:** Використовуйте надійні паролі; увімкніть 2FA у пулах/гаманцях. Ніколи не діліться приватними ключами.
- **Усунення проблем:** Якщо немає шар, перевірте firewall, антивірус або неправильну конфігурацію. Долучайтеся до форумів, таких як forum.zcashcommunity.com або Reddit r/zec.
- **Альтернативи:** Якщо це неприбутково, розгляньте хмарний майнінг або стейкінг інших монет.
- **Екологічна примітка:** Майнінг споживає енергію; за можливості використовуйте відновлювані джерела.
- **Оновлення:** Zcash може змінюватися (наприклад, можливий перехід на PoS); перевіряйте новини на z.cash.
