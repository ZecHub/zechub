# Zcash Посібник із майнінгу: приєднання до майнінг-пулу з власним обладнанням

## Вступ

Zcash (ZEC) — це криптовалюта, орієнтована на приватність, яка використовує алгоритм доказу роботи Equihash для майнінгу. Майнінг Zcash передбачає використання обчислювальної потужності для розв’язання складних математичних задач, підтвердження транзакцій і захисту мережі в обмін на винагороди в ZEC. Через високу складність мережі соло-майнінг не рекомендується більшості користувачів. Приєднання до майнінг-пулу — найкращий спосіб отримувати стабільні винагороди, поєднуючи свою хеш-потужність з іншими.

Цей посібник зосереджений на майнінгу Zcash за допомогою власного обладнання (наприклад, домашнього ПК із GPU або ASIC початкового рівня). Зверніть увагу: хоча GPU все ще можуть майнити Zcash, у 2026 році ASIC є значно ефективнішими й прибутковішими через складність мережі. Завжди перевіряйте поточну прибутковість за допомогою таких інструментів, як WhatToMine.com, оскільки на доцільність впливають такі чинники, як вартість електроенергії, ціни на обладнання та вартість ZEC. Майнінг може бути прибутковим не для всіх; дослідіть місцеві правила та тарифи на електроенергію (орієнтуйтеся на < $0.08/kWh).


## Вимоги

### Обладнання
- **Майнінг на GPU (власна конфігурація рекомендована для початківців):**
  - GPU NVIDIA або AMD із щонайменше 4 ГБ VRAM (наприклад, NVIDIA GTX 1070, RTX 3060; AMD RX 580 або кращі).
  - Сумісна материнська плата, достатньо потужний БЖ (щонайменше 750 Вт для кількох GPU) і хороше охолодження для запобігання перегріванню.
  - Установки з кількома GPU поширені для вищих хешрейтів (наприклад, 6 GPU можуть досягати 1–2 kSol/s).
- **Майнінг на ASIC (ефективніший, але дорожчий):**
  - ASIC, сумісні з Equihash, як-от Bitmain Antminer Z15 (420 kSol/s) або Innosilicon A9 (50 kSol/s).
  - Вони гучніші, гарячіші та споживають більше енергії (наприклад, 1500 Вт+); підходять для спеціально відведених приміщень. Купуйте в надійних джерелах, таких як Bitmain.com або реселери (Blockware Mining).
- **Загальне:** стабільний інтернет, комп’ютер для налаштування та моніторингу. ASIC домінують у мережі (~13 GSol/s загального хешрейту у 2026 році), що робить майнінг на GPU менш конкурентоспроможним, але все ще можливим для ентузіастів.

### Програмне забезпечення
- **Операційна система:** Windows 10/11, Linux (для стабільності рекомендовано Ubuntu).
- **Програмне забезпечення для майнінгу:**
  - Для GPU: lolMiner (підтримує AMD/NVIDIA), GMiner або miniZ (орієнтований на NVIDIA). Завантажуйте з офіційних репозиторіїв GitHub (наприклад, github.com/Lolliedieb/lolMiner-releases).
  - Для ASIC: використовуйте вбудовану прошивку/панель керування виробника (наприклад, вебінтерфейс Bitmain).
- **Гаманець:** гаманець Zcash для отримання виплат. Рекомендовано:
  - Захищені (приватні): ZODL Wallet, Zingo (мобільний/настільний), Zkool (мобільний/настільний).
  - Прозорі (простіші, але менш приватні): Edge Wallet, Zecwallet Lite.
  - Завантажуйте з [wallets](https://zechub.wiki/wallets). Створіть захищену адресу (починається з «zs») для приватності, якщо пул її підтримує.

### Інше
- Електроенергія: розрахуйте витрати. GPU використовують 150–300 Вт на карту; ASIC — 1000 Вт+.
- Антивірус: вимкніть його під час налаштування, оскільки він може позначати майнери як загрози.

## Покроковий посібник із приєднання до майнінг-пулу

### Крок 1: Налаштуйте свій гаманець Zcash
1. Завантажте та встановіть гаманець з офіційного вебсайту Zcash [wallets](https://zechub.wiki/wallets).
2. Створіть новий гаманець і безпечно створіть резервну копію своєї seed-фрази.
3. Створіть адресу для отримання коштів (бажано захищену для приватності). Запишіть її, наприклад: `zs1exampleaddress...`.
4. Якщо використовуєте прозору адресу (починається з «t»), це простіше, але забезпечує менше приватності.

### Крок 2: Підготуйте обладнання
- Для GPU:
  1. Встановіть GPU у свій ПК та оновіть драйвери (NVIDIA: GeForce Experience; AMD: Radeon Software).
  2. Виконайте розгін, якщо маєте досвід (використовуйте MSI Afterburner для стабільності; орієнтуйтеся на +100–200 до частоти ядра, -500 до пам’яті для ефективності).
- Для ASIC:
  1. Підключіть ASIC до живлення та Ethernet.
  2. Знайдіть його IP-адресу за допомогою такого інструмента, як Advanced IP Scanner, або застосунку виробника.
  3. Відкрийте вебпанель керування (наприклад, введіть IP у браузері; стандартний логін для Bitmain: root/root).

**Попередження:** забезпечте належну вентиляцію; майнінг генерує тепло. Почніть з малого, щоб протестувати.

### Крок 3: Виберіть майнінг-пул і приєднайтеся
Майнінг-пули розподіляють роботу та ділять винагороди відповідно до внесеного вами хешрейту. Вибирайте за комісіями (0–2%), мінімумом виплати (0.01–0.1 ZEC), розташуванням (низький пінг) і надійністю.

**Рекомендовані пули (на основі хешрейту, комісій і відгуків):**
- **2Miners (zec.2miners.com)**: комісія 1%, виплати PPLNS, підтримує GPU/ASIC/NiceHash. Високий хешрейт (~1.17 GSol/s), надійні сервери.
- **F2Pool (zec.f2pool.com)**: комісія 2%, виплати PPS+, підтримка багатьох монет. Великий пул (~2.57 GSol/s).
- **ViaBTC (zec.viabtc.com)**: комісія 2% (PPS+), зручна панель керування, глобальні сервери.
- **AntPool (zec.antpool.com)**: комісія 1%, від Bitmain, добре підходить для ASIC (~494 MSol/s).
- **Foundry Zcash Pool (foundrydigital.com/foundry-zcash-pool/)**: професійний пул для майнінгу Zcash від Foundry Digital. Використовує виплати PPLNS, пропонує прозоре відстеження винагород і підтримку корпоративного рівня. Найкраще підходить для інституційних та великих майнерів на ASIC; потребує перевірки облікового запису.
- **Sovright (mining.sovright.com)**: пул Zcash, побудований на Stratum V2, який наразі працює як публічна тестова мережа. Живих виплат у ZEC ще немає, тому розглядайте його як спосіб протестувати своє налаштування, а не як джерело заробітку. Докладніше дивіться у спеціальному розділі нижче.
- Інші: Kryptex Pool, Luxor (перевіряйте poolwatch.io/coin/zcash для статистики в реальному часі).

1. Відвідайте вебсайт пулу та створіть обліковий запис (електронна пошта або без реєстрації для деяких, як-от 2Miners).
2. Додайте адресу свого гаманця Zcash у налаштуваннях для виплат.
3. Запишіть stratum-сервер пулу (наприклад, zec.2miners.com:1010) і порт.

### Крок 4: Встановіть і налаштуйте програмне забезпечення для майнінгу
- Для GPU (приклад: lolMiner на Windows/Linux):
  1. Завантажте lolMiner з GitHub (остання версія, наприклад 1.88).
  2. Розпакуйте у папку.
  3. Створіть пакетний файл (start.bat) із конфігурацією:
     ```
     lolMiner.exe --coin ZEC --pool zec.2miners.com:1010 --user YOUR_WALLET_ADDRESS.WORKER_NAME --pass x
     ```
     - Замініть `YOUR_WALLET_ADDRESS` на свою адресу ZEC.
     - `WORKER_NAME`: назва вашої установки (наприклад, Rig1).
     - Для серверів ЄС: eu.zec.2miners.com:1010.
  4. Запустіть пакетний файл. Він підключиться до пулу та почне майнінг.
- Для ASIC (приклад: Bitmain Antminer):
  1. Увійдіть у вебпанель керування.
  2. Перейдіть до Miner Configuration.
  3. Додайте дані пулу:
     - URL: stratum+tcp://zec.2miners.com:1010
     - Ім’я користувача: YOUR_WALLET_ADDRESS.WORKER_NAME
     - Пароль: x (або порожньо).
  4. Збережіть налаштування та перезавантажте майнер.
- Для іншого програмного забезпечення (наприклад, GMiner):
  ```
  miner.exe --algo 125_4 --server zec.2miners.com:1010 --user YOUR_WALLET_ADDRESS.WORKER_NAME --pass x
  ```

**Тест:** запустіть на 10–15 хвилин; перевірте консоль на прийняті шери та хешрейт.

### Крок 5: Почніть майнінг і моніторинг
1. Запустіть майнер: він підключиться до пулу та почне надсилати шери.
2. Моніторинг через:
   - Панель пулу: введіть адресу свого гаманця, щоб побачити хешрейт, невиплачений баланс і статистику.
   - Консоль програмного забезпечення: стежте за помилками, температурою (підтримуйте < 80 градусів C).
   - Інструменти: використовуйте HiveOS або SimpleMining OS для віддаленого керування установкою.
3. Виплати: більшість пулів платять автоматично, коли ви досягнете мінімуму (наприклад, 0.05 ZEC). Перевірте правила пулу.

## Sovright: пул тестової мережі та ретрансляційна мережа

Sovright (sovright.com) керує майнінг-пулом Stratum V2 та окремою мережею ретрансляції блоків. Вони виконують різні завдання, тому нижче розглядаються окремо.

### Майнінг-пул (mining.sovright.com)

Пул Sovright працює у публічній тестовій мережі Zcash (NU6, Stratum V2), а не в mainnet. Тестова мережа не виплачує реальні ZEC. Використовуйте її для перевірки конфігурації майнера, а не для заробітку.

- Для початку обліковий запис не потрібен. Спрямуйте CPU або ASIC-майнер Equihash на пул, і ваші шери відображатимуться на інтерактивній панелі.
- Sovright також публікує відкритий проксі Stratum V2 для майнерів, які хочуть вибирати власні шаблони блоків, а не просто брати завдання пулу:

### Моніторинг пулу Foundry Zcash

Для користувачів пулу Foundry Zcash:

- Відстежуйте продуктивність майнера через панель пулу Foundry.
- Перевіряйте:
  - Активних воркерів
  - Заявлений хешрейт
  - Прийняті шери
  - Орієнтовні винагороди
  - Статус виплат

Оскільки Foundry використовує модель винагород PPLNS, винагороди за майнінг залежать від внесених шерів протягом вікна винагород пулу, а не лише від миттєвого хешрейту.

Рекомендовані практики моніторингу:
- Порівнюйте хешрейт на панелі ASIC із заявленим хешрейтом Foundry.
- Досліджуйте відхилені шери, застарілі шери або нестабільність з’єднання.
- Підтримуйте стабільне мережеве з’єднання, оскільки простої зменшують кількість надісланих шерів і потенційні винагороди.
  ```
  git clone https://github.com/sovright/mining-infra
  cd mining-infra
  cargo build --release -p sovright-v1-stratum-proxy
  ./target/release/sovright-v1-stratum-proxy --listen 0.0.0.0:3334 --upstream 34.28.134.13:3333
  ```
  Спрямуйте свій майнер на проксі замість пулу безпосередньо:
  ```
  stratum+tcp://<your-proxy-ip>:3334
  ```
  використовуючи ім’я воркера на кшталт `yourname.rig1`.
- Сторінка прозорості Sovright заявляє про політику «включати всі» для захищених транзакцій, на відміну від деяких пулів, які їх відфільтровують. Кожен блок отримує підписану атестацію, тож політику можна перевірити незалежно.
- Створіть обліковий запис на mining.sovright.com (вхід через Google або електронну пошту), щоб відстежувати власних воркерів замість зразкових даних панелі.

### Ретрансляційна мережа (relay.sovright.com)

Sovright окремо керує публічною мережею ретрансляції блоків у mainnet Zcash. Коли пул знаходить блок, швидкість, із якою цей блок досягає решти мережі, визначає, як часто він стає осиротілим, тобто програє гонку поширення, а винагорода за нього втрачається. Ретранслятор пересилає блоки між чотирма регіонами за допомогою компактної ретрансляції блоків із прямим виправленням помилок.

Публічна панель показує ефект наживо: регіони, підключені до ретранслятора, отримують нові блоки значно менше ніж за половину часу, потрібного звичайному одноранговому поширенню, а панель відстежує поточний рівень осиротілих блоків у мережі.

Це інфраструктура для операторів пулів, а не окремих майнерів. Відкритий репозиторій Sovright `mining-infra` документує шлюз ретрансляції `submitblock` для швидшого розповсюдження знайдених блоків у сітці, ніж через нативний P2P. Щоб підключитися, зверніться безпосередньо до Sovright (support@sovright.com) щодо адрес однорангових вузлів ретранслятора та ключа автентифікації.


## Майнінг проти власного вузла Zebra

Усе вище спрямовує ваш майнер до чужого пулу. Інший шлях — самостійно запустити вузол і налаштувати програмне забезпечення для майнінгу запитувати в нього роботу. Оскільки zcashd зупинився 18 липня 2026 року, це означає [Zebra](/zcash-tech/zebra-full-node) — вузол, який охоплює цей розділ.

Роль Zebra невелика й конкретна: він створює шаблони блоків і приймає розв’язані блоки через свій інтерфейс RPC. Хешування виконується програмним забезпеченням для майнінгу, а розподіл винагород між кількома майнерами — завдання програмного забезпечення пулу. Чи знайде соло-майнінг коли-небудь блок, залежить від вашої частки хешрейту мережі, яку цей розділ не намагається оцінити. Саме тому вступ до цієї сторінки не рекомендує соло-майнінг більшості користувачів.

Кроки ґрунтуються на двох сторінках Zebra Book, [Майнінг Zcash за допомогою Zebra](https://zebra.zfnd.org/user/mining.html) та [Майнінг з Zebra у Docker](https://zebra.zfnd.org/user/mining-docker.html), станом на 8 жовтня 2026 року. Назви ключів і значення за замовчуванням змінюються між випусками, тому перевіряйте Book, перш ніж покладатися на них.

### Встановіть адресу, яка отримуватиме винагороду

Створіть конфігураційний файл із налаштуваннями за замовчуванням, а потім відредагуйте його:

```bash
mkdir -p ~/.config
zebrad generate -o ~/.config/zebrad.toml
```

Потрібна адреса майнера ([Book: Адреса майнера](https://zebra.zfnd.org/user/mining.html#miner-address)):

```toml
[mining]
miner_address = "YOUR_ADDRESS"
```

Zebra приймає прозору адресу P2PKH або P2SH, адресу Sapling або Unified Address. Для Unified Address із кількома отримувачами Book зазначає, що Zebra виплачує одному отримувачу, «віддаючи перевагу Orchard, потім Sapling, а потім прозорому».

Два необов’язкові ключі розміщуються в тому самому розділі `[mining]`:

| Ключ | Що він робить | Обмеження |
|---|---|---|
| `extra_coinbase_data` | Додає публічний тег, наприклад назву пулу, до входу coinbase кожного видобутого вами блоку після власного маркера Zebra ([Book](https://zebra.zfnd.org/user/mining.html#extra-coinbase-data)) | 86 байтів. Понад це «Zebra відмовляється запускатися» |
| `miner_memo` | Додає захищену пам’ятку до виходу винагороди. На відміну від `extra_coinbase_data`, вона не є публічною: її може прочитати лише той, хто має ключ перегляду для адреси отримання ([Book](https://zebra.zfnd.org/user/mining.html#miner-memo)) | 512 байтів. Працює лише тоді, коли винагорода надходить захищеному отримувачу. З прозорою адресою вона «мовчки не має ефекту» |

### Відкрийте порт RPC

Програмне забезпечення для майнінгу взаємодіє з Zebra через JSON-RPC, який залишається вимкненим, доки ви не вкажете адресу для прослуховування ([Book: Розділ RPC](https://zebra.zfnd.org/user/mining.html#rpc-section)):

```toml
[rpc]
listen_addr = "127.0.0.1:8232"
```

8232 — стандартний порт RPC у Mainnet. `127.0.0.1` залишає порт доступним лише з тієї самої машини.

Починаючи з Zebra 2.0.0, порт RPC захищає cookie — метод, подібний до того, який використовував zcashd. Zebra записує cookie під час запуску кінцевої точки RPC і видаляє його під час завершення роботи. За замовчуванням файл розміщується в каталозі кешу Zebra, наприклад `/home/user/.cache/zebra/.cookie` на Linux, і містить один рядок:

```text
__cookie__:PASSWORD
```

`rpc.cookie_dir` переміщує файл. `rpc.enable_cookie_auth = false` вимикає перевірку, а разом із нею — єдину автентифікацію, яку має порт RPC: тоді будь-що, що може досягти порту, може викликати його.

### Запустіть Zebra і дочекайтеся синхронізації

```bash
zebrad
```

Zebra читає конфігурацію з розташування за замовчуванням. Передайте `-c /path/to/zebrad.toml`, щоб використати інший файл. Дочекайтеся завершення синхронізації. У журналі відображається `sync_percent=100.000%`, коли її завершено ([Book: Запуск zebra](https://zebra.zfnd.org/user/mining.html#running-zebra)). [Zebra Повний вузол](/zcash-tech/zebra-full-node) охоплює вимоги до обладнання та дискового простору.

### Перевірте за допомогою getblocktemplate

`getblocktemplate` — це виклик, який програмне забезпечення для майнінгу здійснює, щоб отримати роботу, тому це також найшвидший тест ([Book: Тестування налаштування](https://zebra.zfnd.org/user/mining.html#testing-the-setup)). Вставте вміст свого cookie-файлу замість `__cookie__:PASSWORD`:

```bash
curl --silent --data-binary '{"jsonrpc": "1.0", "id":"curltest", "method": "getblocktemplate", "params": [] }' -H 'Content-type: application/json' http://__cookie__:PASSWORD@127.0.0.1:8232/ | jq
```

Робоче налаштування повертає об’єкт `result` із полями, потрібними майнеру, зокрема `previousblockhash`, `coinbasetxn`, `target` та `height`. Якщо ви встановили `extra_coinbase_data`, Book пояснює, як знайти свій тег у `coinbasetxn.data`.

### Спрямуйте на нього своє програмне забезпечення для майнінгу

Укажіть програмному забезпеченню для майнінгу або пулу кінцеву точку RPC, `127.0.0.1:8232`, а також ім’я користувача й пароль із cookie. Book зазначає, що Zebra «підтримує методи RPC, потрібні для запуску більшості програм для майнінг-пулів» ([Book: Запуск майнінг-пулу](https://zebra.zfnd.org/user/mining.html#run-a-mining-pool)).

Дві примітки з Book перед вибором програмного забезпечення:

- **s-nomp призначений лише для тестування.** Book називає його налаштування s-nomp «експериментальним» і зазначає, що s-nomp «не сумісний з NU5, тому деякі функції майнінгу вимкнено». Його посібник [Testnet](https://zebra.zfnd.org/user/mining-testnet-s-nomp.html) додає, що s-nomp «офіційно не оновлювався для NU5 або пізніших оновлень мережі», і спрямовує виробничих майнерів до програмного забезпечення пулів, яке підтримує поточні оновлення.
- **Zebra постачається з готовим стеком.** Репозиторій Zebra містить налаштування Docker Compose у [`docker/mining/`](https://github.com/ZcashFoundation/zebra/tree/main/docker/mining), яке запускає Zebra разом із майнінг-пулом і, за бажанням, CPU-майнером. Пул у ньому — s-nomp, і він запускається в Testnet, якщо ви це не зміните, тож розглядайте його як спосіб вивчити складові системи.

### Шлях Docker

Найкоротший шлях із Book — образ `zfnd/zebra` Docker, де адреса та порт RPC передаються як змінні середовища ([Book: Майнінг з Zebra у Docker](https://zebra.zfnd.org/user/mining-docker.html)). Команда нижче взята з Book з однією зміною: вона публікує порт RPC лише на loopback-адресі хоста, тож інші машини не можуть його досягти.

```bash
docker run -d --name zebra_local \
  -e ZEBRA_MINING__MINER_ADDRESS="YOUR_ADDRESS" \
  -e ZEBRA_RPC__LISTEN_ADDR=0.0.0.0:8232 \
  -p 8233:8233 \
  -p 127.0.0.1:8232:8232 \
  -v zebrad-cache:/home/zebra/.cache/zebra \
  zfnd/zebra:latest
```

Це запускає вузол Mainnet, публікує порт P2P (8233) на хості Docker і робить порт RPC (8232) доступним лише з самого хоста. Виведіть cookie за допомогою:

```bash
docker exec -it zebra_local cat /home/zebra/.cache/zebra/.cookie
```

- **Зберігайте `0.0.0.0` у `ZEBRA_RPC__LISTEN_ADDR`.** Це адреса, яку Zebra прослуховує всередині контейнера. Docker пересилає опублікований порт до власного мережевого інтерфейсу контейнера, тому Zebra, який прослуховує `127.0.0.1` всередині контейнера, не отримає з’єднання навіть із хоста. `127.0.0.1:` перед `-p` — це те, що не дає порту бути доступним у мережі.
- **Команда з Book** публікує порт RPC за допомогою `-p 8232:8232`, що відкриває його на кожному мережевому інтерфейсі хоста.
- **Щоб попрактикуватися в Testnet**, додайте `-e ZEBRA_NETWORK__NETWORK="Testnet"`, встановіть `ZEBRA_RPC__LISTEN_ADDR=0.0.0.0:18232`, опублікуйте `-p 18233:18233` і `-p 127.0.0.1:18232:18232` та вкажіть адресу Testnet. Адреса Mainnet не дасть Zebra запуститися в Testnet, і навпаки.

Виплати майнерам і робота з гаманцем не входять до цього розділу. Щодо частини з гаманцем дивіться [Zallet](/zcash-tech/zallet).

## Поради та найкращі практики
- **Прибутковість:** використовуйте калькулятори, такі як whattomine.com/coins/166-zec-equihash. Приклад: RTX 3060 (~300 Sol/s) заробляє ~0.001 ZEC/день за $50/ZEC, за вирахуванням ~$0.50 за електроенергію.
- **Приватність:** використовуйте захищені пули, якщо вони доступні; не використовуйте адреси повторно.
- **Безпека:** використовуйте надійні паролі; увімкніть 2FA у пулах/гаманцях. Ніколи не діліться приватними ключами.
- **Усунення несправностей:** якщо немає шерів, перевірте брандмауер, антивірус або неправильну конфігурацію. Приєднуйтеся до форумів, таких як forum.zcashcommunity.com або Reddit r/zec.
- **Альтернативи:** якщо майнінг неприбутковий, розгляньте хмарний майнінг або стейкінг інших монет.
- **Екологічна примітка:** майнінг споживає енергію; за можливості використовуйте відновлювані джерела.
- **Оновлення:** Zcash може розвиватися (наприклад, можливий перехід на PoS); перевіряйте z.cash для новин.
