# Посібник із майнінгу Zcash: приєднання до майнінг-пулу з особистим обладнанням

## Вступ

Zcash (ZEC) — це криптовалюта, орієнтована на приватність, яка використовує алгоритм доказу виконаної роботи Equihash для майнінгу. Майнінг Zcash передбачає використання обчислювальної потужності для розв’язання складних математичних задач, підтвердження транзакцій і захисту мережі в обмін на винагороди в ZEC. Через високу складність мережі сольний майнінг не рекомендується більшості користувачів. Приєднання до майнінг-пулу — найкращий спосіб отримувати стабільні винагороди, об’єднуючи свій хешрейт з іншими.

Цей посібник зосереджений на майнінгу Zcash за допомогою особистого обладнання (наприклад, домашнього ПК з GPU або початкових ASIC). Зауважте, що хоча GPU все ще можуть майнити Zcash, у 2026 році ASIC є значно ефективнішими та прибутковішими через складність мережі. Завжди перевіряйте поточну прибутковість за допомогою таких інструментів, як WhatToMine.com, оскільки на доцільність впливають витрати на електроенергію, ціни на обладнання та вартість ZEC. Майнінг може бути неприбутковим не для всіх; дослідіть місцеві норми та тарифи на електроенергію (орієнтир: < $0.08/kWh).


## Вимоги

### Обладнання
- **Майнінг на GPU (особиста конфігурація рекомендована для початківців):**
  - GPU NVIDIA або AMD щонайменше з 4 ГБ VRAM (наприклад, NVIDIA GTX 1070, RTX 3060; AMD RX 580 або кращі).
  - Сумісна материнська плата, достатньо потужний блок живлення (щонайменше 750 Вт для кількох GPU) і хороше охолодження, щоб запобігти перегріванню.
  - Ферми з кількома GPU поширені для досягнення вищого хешрейту (наприклад, 6x GPU можуть забезпечувати 1-2 kSol/s).
- **Майнінг на ASIC (ефективніший, але дорожчий):**
  - ASIC, сумісні з Equihash, такі як Bitmain Antminer Z15 (420 kSol/s) або Innosilicon A9 (50 kSol/s).
  - Вони гучніші, сильніше нагріваються та споживають більше енергії (наприклад, 1500W+); підходять для окремих приміщень. Купуйте в надійних джерелах, таких як Bitmain.com або реселери (Blockware Mining).
- **Загальне:** Стабільний інтернет, комп’ютер для налаштування/моніторингу. ASIC домінують у мережі (~13 GSol/s загального хешрейту у 2026 році), що робить майнінг на GPU менш конкурентним, але все ще можливим для ентузіастів.

### Програмне забезпечення
- **Операційна система:** Windows 10/11, Linux (Ubuntu рекомендується для стабільності).
- **Програмне забезпечення для майнінгу:**
  - Для GPU: lolMiner (підтримує AMD/NVIDIA), GMiner або miniZ (орієнтований на NVIDIA). Завантажуйте з офіційних репозиторіїв GitHub (наприклад, github.com/Lolliedieb/lolMiner-releases).
  - Для ASIC: використовуйте вбудовану прошивку/панель керування від виробника (наприклад, вебінтерфейс Bitmain).
- **Гаманець:** Гаманець Zcash для отримання виплат. Рекомендовано:
  - Екранований (приватний): Zodl Wallet, Zingo (Mobile/Desktop) YWallet (mobile/desktop).
  - Прозорий (простіший, але менш приватний): Edge Wallet, Zecwallet Lite.
  - Завантажуйте з [гаманців](https://zechub.wiki/wallets). Для приватності згенеруйте екрановану адресу (починається з `zs`), якщо пул її підтримує.

### Інше
- Електроенергія: розрахуйте витрати. GPU споживають 150-300W на карту; ASIC 1000W+.
- Антивірус: вимкніть під час налаштування, оскільки він може позначати майнери як загрози.

## Покроковий посібник із приєднання до майнінг-пулу

### Крок 1: Налаштуйте свій гаманець Zcash
1. Завантажте та встановіть гаманець з офіційного сайту Zcash [гаманці](https://zechub.wiki/wallets).
2. Створіть новий гаманець і надійно збережіть резервну копію своєї сід-фрази.
3. Згенеруйте адресу для отримання (бажано екрановану для приватності). Запишіть її, наприклад `zs1exampleaddress...`.
4. Якщо ви використовуєте прозору адресу (починається з `t`), це простіше, але забезпечує меншу приватність.

### Крок 2: Підготуйте своє обладнання
- Для GPU:
  1. Встановіть GPU у свій ПК та оновіть драйвери (NVIDIA: GeForce Experience; AMD: Radeon Software).
  2. Виконайте розгін, якщо маєте досвід (використовуйте MSI Afterburner для стабільності; орієнтир для ефективності: +100-200 до core clock, -500 до пам’яті).
- Для ASIC:
  1. Підключіть ASIC до живлення та Ethernet.
  2. Знайдіть його IP-адресу за допомогою такого інструмента, як Advanced IP Scanner, або застосунку виробника.
  3. Відкрийте вебпанель керування (наприклад, введіть IP в браузері, стандартний логін: root/root для Bitmain).

**Попередження:** Забезпечте належну вентиляцію; майнінг генерує тепло. Починайте з малого, щоб протестувати.

### Крок 3: Оберіть майнінг-пул і приєднайтеся до нього
Майнінг-пули розподіляють роботу та ділять винагороди залежно від наданого вами хешрейту. Обирайте за комісіями (0-2%), мінімумом виплат (0.01-0.1 ZEC), розташуванням (низький ping) і надійністю.

**Рекомендовані пули (на основі хешрейту, комісій і відгуків):**
- **2Miners (zec.2miners.com)**: 1% комісія, виплати PPLNS, підтримує GPU/ASIC/NiceHash. Високий хешрейт (~1.17 GSol/s), надійні сервери.
- **F2Pool (zec.f2pool.com)**: 2% комісія, виплати PPS+, підтримка кількох монет. Великий пул (~2.57 GSol/s).
- **ViaBTC (zec.viabtc.com)**: 2% комісія (PPS+), зручна панель керування, глобальні сервери.
- **AntPool (zec.antpool.com)**: 1% комісія, від Bitmain, добре підходить для ASIC (~494 MSol/s).
- **Foundry Zcash Pool (foundrydigital.com/foundry-zcash-pool/)**: Професійний пул для майнінгу Zcash від Foundry Digital. Використовує виплати PPLNS, пропонує прозоре відстеження винагород і підтримку корпоративного рівня. Найкраще підходить для інституційних і великомасштабних майнерів на ASIC; потребує верифікації акаунта.
- **Sovright (mining.sovright.com)**: Пул Zcash, побудований на Stratum V2, який наразі працює як публічний testnet. Реальних виплат ZEC поки немає, тому сприймайте його як спосіб протестувати своє налаштування, а не як джерело заробітку. Деталі дивіться в окремому розділі нижче.
- Інші: Kryptex Pool, Luxor (перевіряйте poolwatch.io/coin/zcash для статистики в реальному часі).

1. Відвідайте сайт пулу та створіть акаунт (email або без реєстрації для деяких, як-от 2Miners).
2. Додайте адресу свого гаманця Zcash у налаштуваннях для виплат.
3. Занотуйте stratum-сервер пулу (наприклад, zec.2miners.com:1010) і порт.

### Крок 4: Встановіть і налаштуйте програмне забезпечення для майнінгу
- Для GPU (приклад: lolMiner на Windows/Linux):
  1. Завантажте lolMiner з GitHub (остання версія, наприклад 1.88).
  2. Розпакуйте в папку.
  3. Створіть batch-файл (start.bat) з конфігурацією:
     ```
     lolMiner.exe --coin ZEC --pool zec.2miners.com:1010 --user YOUR_WALLET_ADDRESS.WORKER_NAME --pass x
     ```
     - Замініть `YOUR_WALLET_ADDRESS` на свою адресу ZEC.
     - `WORKER_NAME`: назва вашої ферми (наприклад, Rig1).
     - Для серверів ЄС: eu.zec.2miners.com:1010.
  4. Запустіть batch-файл. Він підключиться до пулу та почне майнінг.
- Для ASIC (приклад: Bitmain Antminer):
  1. Увійдіть у вебпанель керування.
  2. Перейдіть до Miner Configuration.
  3. Додайте дані пулу:
     - URL: stratum+tcp://zec.2miners.com:1010
     - Username: YOUR_WALLET_ADDRESS.WORKER_NAME
     - Password: x (або порожньо).
  4. Збережіть і перезавантажте майнер.
- Для іншого програмного забезпечення (наприклад, GMiner):
  ```
  miner.exe --algo 125_4 --server zec.2miners.com:1010 --user YOUR_WALLET_ADDRESS.WORKER_NAME --pass x
  ```

**Тест:** Запустіть на 10-15 хвилин; перевірте консоль на наявність прийнятих шар і хешрейту.

### Крок 5: Почніть майнінг і моніторинг
1. Запустіть майнер: він підключиться до пулу та почне надсилати шари.
2. Виконуйте моніторинг через:
   - Панель керування пулу: введіть адресу свого гаманця, щоб побачити хешрейт, невиплачений баланс і статистику.
   - Консоль програмного забезпечення: стежте за помилками, температурою (тримайте < 80 градусів C).
   - Інструменти: використовуйте HiveOS або SimpleMining OS для віддаленого керування фермою.
3. Виплати: більшість пулів виплачують автоматично, коли ви досягаєте мінімуму (наприклад, 0.05 ZEC). Перевіряйте правила пулу.

## Sovright: Testnet-пул і релейна мережа

Sovright (sovright.com) запускає майнінг-пул Stratum V2 і окрему мережу ретрансляції блоків. Вони виконують різні завдання, тому розглядаються окремо нижче.

### Майнінг-пул (mining.sovright.com)

Пул Sovright працює в публічному testnet Zcash (NU6, Stratum V2), а не в mainnet. Testnet не виплачує реальні ZEC. Використовуйте його для перевірки конфігурації свого майнера, а не для заробітку.

- Для початку не потрібен акаунт. Спрямуйте CPU або ASIC Equihash-майнер на пул, і ваші шари з’являться на панелі в реальному часі.
- Sovright також публікує проксі Stratum V2 з відкритим кодом для майнерів, які хочуть самі обирати шаблони блоків, а не просто брати завдання пулу:

### Моніторинг Foundry Zcash Pool

Для користувачів Foundry Zcash Pool:

- Контролюйте продуктивність майнера через панель керування пулу Foundry.
- Перевіряйте:
  - Активних воркерів
  - Повідомлений хешрейт
  - Прийняті шари
  - Орієнтовні винагороди
  - Статус виплат

Оскільки Foundry використовує модель винагород PPLNS, винагороди за майнінг залежать від наданих шар протягом вікна винагород пулу, а не лише від миттєвого хешрейту.

Рекомендовані практики моніторингу:
- Порівнюйте хешрейт на панелі ASIC із хешрейтом, який показує Foundry.
- Досліджуйте відхилені шари, прострочені шари або нестабільність з’єднання.
- Підтримуйте стабільне мережеве з’єднання, оскільки простої зменшують кількість надісланих шар і потенційні винагороди.
  ```
  git clone https://github.com/sovright/mining-infra
  cd mining-infra
  cargo build --release -p sovright-v1-stratum-proxy
  ./target/release/sovright-v1-stratum-proxy --listen 0.0.0.0:3334 --upstream 34.28.134.13:3333
  ```
  Спрямуйте свій майнер на проксі замість прямого підключення до пулу:
  ```
  stratum+tcp://<your-proxy-ip>:3334
  ```
  використовуючи ім’я воркера на кшталт `yourname.rig1`.
- На сторінці прозорості Sovright вказано політику "include all" для екранованих транзакцій, на відміну від деяких пулів, які їх відфільтровують. Кожен блок отримує підписану атестацію, тож політику можна перевірити незалежно.
- Створіть акаунт на mining.sovright.com (вхід через Google або email), щоб відстежувати власних воркерів замість зразкових даних панелі.

### Релейна мережа (relay.sovright.com)

Sovright окремо запускає публічну мережу ретрансляції блоків у mainnet Zcash. Коли пул знаходить блок, швидкість, з якою цей блок досягає решти мережі, визначає, як часто він стає orphaned, тобто програє гонку поширення, і винагорода за нього втрачається. Релейна мережа пересилає блоки через чотири регіони, використовуючи компактну ретрансляцію блоків із прямою корекцією помилок.

Публічна панель показує ефект у реальному часі: регіони, підключені до релея, бачать нові блоки значно менш ніж за половину часу, потрібного звичайному peer to peer gossip, а панель відстежує поточний рівень orphan-блоків у мережі.

Це інфраструктура для операторів пулів, а не для окремих майнерів. У репозиторії `mining-infra` з відкритим кодом Sovright задокументовано шлюз ретрансляції `submitblock` для швидшого розповсюдження знайдених блоків у сітці, ніж через нативний P2P. Щоб підключитися, зв’яжіться безпосередньо з Sovright (support@sovright.com), щоб отримати адреси релейних вузлів і ключ автентифікації.


## Поради та найкращі практики
- **Прибутковість:** Використовуйте калькулятори на кшталт whattomine.com/coins/166-zec-equihash. Приклад: RTX 3060 (~300 Sol/s) приносить ~0.001 ZEC/день при $50/ZEC, мінус ~$0.50 за електроенергію.
- **Приватність:** Використовуйте екрановані пули, якщо доступні; уникайте повторного використання адрес.
- **Безпека:** Використовуйте надійні паролі; увімкніть 2FA у пулах/гаманцях. Ніколи не діліться приватними ключами.
- **Усунення проблем:** Якщо немає шар, перевірте брандмауер, антивірус або неправильну конфігурацію. Приєднуйтеся до форумів на кшталт forum.zcashcommunity.com або Reddit r/zec.
- **Альтернативи:** Якщо це неприбутково, розгляньте хмарний майнінг або стейкінг інших монет.
- **Екологічна примітка:** Майнінг споживає енергію; за можливості використовуйте відновлювані джерела.
- **Оновлення:** Zcash може розвиватися далі (наприклад, можливий перехід на PoS); стежте за новинами на z.cash.
