# <img src="/content-images/image-2024-02-03-173258092-a5440e5ee2.webp" alt="Alt Text" width="50"/>   Кастодіальні біржі

Ironwood — це екранований пул, що з’явився з оновленням мережі в липні 2026 року. Біржі, які працюють лише з прозорими t-адресами, ніколи з ним не взаємодіють, тому для них зазначено «не застосовується». Якщо біржа працює з екранованими адресами, але не повідомила, який пул використовує, це вказано замість припущень.
