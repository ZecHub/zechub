# Ресурси Zcash

Існує низка ресурсів, які допомагають користувачам зрозуміти Zcash.

**[Zcash Media](https://www.youtube.com/c/ZcashMedia)**

Zcash Media — незалежна організація, що створює освітні документальні фільми про Zcash. Їхнє перше відео «Built to Fix Bitcoin's Fatal Flaw, What is Zcash (ZEC)?» є чудовим вступом до Zcash.

**[X (раніше Twitter)](https://x.com)**

Twitter є фактичним центром комунікації для спільноти Zcash, а також ширшого криптовалютного простору. Це чудове місце, щоб бути в курсі всього, що стосується Zcash, а також стежити за помітними членами спільноти. Ось [документ](https://www.notion.so/zechub/Social-Media-Links-05b9df645af54de7a1989d9c4ccc4d05) зі списком найважливіших облікових записів, за якими варто стежити.

**[Спільнота Zcash](https://www.zcashcommunity.com/)**

Zcash Community — сайт, яким керує спільнота та який висвітлює проєкти, створені спільнотою на підтримку екосистеми Zcash. Це чудовий спосіб познайомитися зі спільнотою Zcash та її різноманітними застосуваннями як валюти.

**[Форум Zcash](https://forum.zcashcommunity.com/)**

Як згадано в посібнику для нових користувачів, форум Zcash — чудове місце для розгорнутих обговорень тем, пов’язаних із Zcash, а також запропонованих ідей. Пропозиції завжди потрапляють на форум, щоб спільнота мала змогу обговорити та подискутувати щодо них.

**[Z.cash](https://z.cash/)**

Z.cash — головний вебсайт Zcash. Він надає матеріали й документацію про Zcash для широкого кола користувачів і дозволяє новим користувачам глибше зануритися в технічні пояснення щодо Zcash.

**[GitHub Zcash](https://github.com/zcash/zcash)**

Маєте навички програмування й хочете глибше зануритися в технічний бік Zcash? Репозиторій Zcash на GitHub є репозиторієм zcashd, першої реалізації вузла Zcash. zcashd досяг автоматичного припинення підтримки 18 липня 2026 року й більше не підтримується, а сторінка завантаження, на яку раніше посилався цей запис, більше не доступна. Підтримуваний стек — це [Zebra](https://github.com/ZcashFoundation/zebra) для вузла та [Zallet](https://github.com/zcash/zallet) для гаманця — дивіться [посібник із міграції з zcashd на Zebra та Zallet](https://zechub.wiki/guides/migration-guide-zcashd-to-zebrad-zallet).

**[GitHub Zcash Foundation](https://github.com/ZcashFoundation)**

Ще один репозиторій GitHub, що містить проєкти Zcash Foundation, зокрема [zebra](https://github.com/ZcashFoundation/zebra), реалізацію вузла Zcash мовою Rust.

**[Halo2](https://zcash.github.io/halo2/index.html)**

Концепції, що лежать в основі систем доказів із нульовим розголошенням.

**[Документація Zcash RPC](https://zcash.github.io/rpc/)**

Список команд RPC, які надавав zcashd. Щодо підтримуваного набору RPC гаманця дивіться [Zallet Book](https://zcash.github.io/zallet/).
