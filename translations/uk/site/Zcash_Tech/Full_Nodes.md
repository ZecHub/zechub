# Повні вузли

## Коротко

- Повний вузол зберігає повну копію блокчейну Zcash і перевіряє кожен новий блок та транзакцію відповідно до правил консенсусу.
- Zebra (`zebrad`) — це вузол, який слід встановити сьогодні. Zakura — друга реалізація, відгалужена від Zebra.
- zcashd припинено. Його автоматична зупинка після завершення підтримки відбулася 18 липня 2026 року на висоті блоку 3417100, і ці вузли більше не запускаються.
- Вузол і гаманець тепер є окремими програмами. [Zallet](https://github.com/zcash/zallet) працює з вузлом і зберігає ключі.
- Запуск власного вузла надає вам незалежну перевірку та усуває потребу довіряти чужому серверу.

## Основне пояснення

Повний вузол — це програмне забезпечення, яке запускає повну копію блокчейну криптовалюти, надаючи вам доступ до функцій протоколу.

Він зберігає повний запис кожної транзакції, що відбулася від генезису, тому може перевіряти дійсність нових транзакцій і блоків, доданих до блокчейну.

## Реалізації вузлів

### Zebra

Zebra — це незалежна, готова до промислового використання реалізація повного вузла протоколу Zcash, створена Zcash Foundation і написана мовою Rust. Оскільки zcashd припинено, Zebra (`zebrad`) є рекомендованим повним вузлом для нових розгортань.

Zebra перевіряє блоки й транзакції, бере участь у одноранговій мережі та надає RPC-інтерфейс для застосунків. Гаманець тепер є окремим компонентом: [Zallet](https://github.com/zcash/zallet) працює з вузлом Zebra та обробляє ключі й баланси. Це замінює zcashd, який об’єднував вузол і гаманець в одному процесі.

Для обслуговування екранованих легких гаманців вузол працює разом з індексатором: або усталеним [lightwalletd](https://github.com/zcash/lightwalletd), або новішим [Zaino](https://zechub.wiki/zaino).

Обов’язково прочитайте книгу Zebra для отримання інструкцій із налаштування та приєднуйтеся до сервера R&D Discord для підтримки.

[Github](https://github.com/ZcashFoundation/zebra/)

[Книга Zebra](https://zebra.zfnd.org)

Дивіться [Zebra Повний вузол](/zcash-tech/zebra-full-node), щоб дізнатися про встановлення, конфігурацію та вимоги до обладнання.

### Zakura

Zakura — це другий сумісний із консенсусом повний вузол, відгалужений від Zebra і розроблений Valar Group спільно з Project Tachyon. Він дотримується тих самих правил протоколу та додає швидшу синхронізацію, обрізання блоків і рівень сумісності RPC zcashd. Дивіться [Zakura Вузол](/zcash-tech/zakura-node).

### zcashd (припинено)

> **Примітка:** zcashd припинено. Electric Coin Company [оголосила про припинення підтримки](https://z.cash/support/zcashd-deprecation/), а автоматична зупинка після завершення підтримки відбулася 18 липня 2026 року на висоті блоку 3417100. Кожен немодифікований вузол zcashd 6.20.0 зупинився на цій висоті та відмовляється перезапускатися, а програмне забезпечення не підтримує NU6.3. Використовуйте Zebra. Якщо у вас є zcashd `wallet.dat`, дотримуйтеся [Посібника з міграції: zcashd до Zebrad/Zallet](https://zechub.wiki/migration-guide-zcashd-to-zebrad-zallet).

zcashd була оригінальною реалізацією повного вузла для Zcash, розробленою та підтримуваною Electric Coin Company. Наведені нижче інструкції зі збирання збережено для довідки та для операторів, які мігрують з zcashd.

Zcashd надає набір API через свій RPC-інтерфейс. Ці API надають функції, які дозволяють зовнішнім застосункам взаємодіяти з вузлом.

[Lightwalletd](https://github.com/zcash/lightwalletd) — це приклад застосунку, який використовує повний вузол, щоб дати розробникам змогу створювати й підтримувати зручні для мобільних пристроїв екрановані легкі гаманці без потреби безпосередньо взаємодіяти з Zcashd.

[Повний список підтримуваних RPC-команд](https://zcash.github.io/rpc/)

[Книга Zcashd](https://zcash.github.io/zcash/)

#### Запуск вузла (Linux)

- Встановіть залежності

      sudo apt update

      sudo apt-get install \
      build-essential pkg-config libc6-dev m4 g++-multilib \
      autoconf libtool ncurses-dev unzip git python3 python3-zmq \
      zlib1g-dev curl bsdmainutils automake libtinfo5

- Клонуйте останній випуск, перейдіть на нього, налаштуйте та зберіть:

      git clone https://github.com/zcash/zcash.git

      cd zcash/

      git checkout v5.4.1
      ./zcutil/fetch-params.sh
      ./zcutil/clean.sh
      ./zcutil/build.sh -j$(nproc)

- Синхронізуйте блокчейн (це може зайняти кілька годин)

    Щоб запустити вузол, виконайте:

      ./src/zcashd

- Приватні ключі зберігаються у ~/.zcash/wallet.dat

[Посібник із Zcashd на Raspberry Pi](https://zechub.notion.site/Raspberry-Pi-4-a-zcashd-full-node-guide-6db67f686e8d4b0db6047e169eed51d1)

## Практичні наслідки

### Мережа

Запускаючи повний вузол, ви допомагаєте зміцнювати мережу Zcash, підтримуючи її децентралізацію.

Це допомагає запобігати ворожому контролю та зберігати стійкість мережі до деяких форм порушень роботи.

DNS-сідери надають список інших надійних вузлів через вбудований сервер. Це дозволяє транзакціям поширюватися мережею.

### Статистика мережі

Ось приклади платформ, що надають доступ до мережевих даних Zcash:

[Zcash Оглядач блоків](https://zcashblockexplorer.com)

[Coinmetrics](https://docs.coinmetrics.io/info/assets/zec)

[Blockchair](https://blockchair.com/zcash)

Ви також можете сприяти розвитку мережі, запускаючи тести, пропонуючи нові покращення та надаючи метрики.

### Майнінг

Майнерам потрібні повні вузли для доступу до всіх RPC, пов’язаних із майнінгом, таких як getblocktemplate і getmininginfo.

Zcashd також уможливлює майнінг до екранованої coinbase-винагороди. Майнеры та майнінгові пули можуть за замовчуванням майнити безпосередньо, накопичуючи екрановані ZEC на z-адресі.

Прочитайте [Посібник із майнінгу](https://zcash.readthedocs.io/en/latest/rtd_pages/zcash_mining_guide.html) або приєднуйтеся до сторінки форуму спільноти для [Zcash Майнерів](https://forum.zcashcommunity.com/c/mining/13).

### Конфіденційність

Запуск повного вузла дозволяє вам незалежно перевіряти всі транзакції та блоки в мережі Zcash.

Запуск повного вузла усуває деякі ризики для конфіденційності, пов’язані з використанням сторонніх сервісів для перевірки транзакцій від вашого імені.

Використання власного вузла також дозволяє підключатися до мережі через [Tor](https://zcash.github.io/zcash/user/tor.html).
Це має додаткову перевагу, оскільки дозволяє іншим користувачам приватно підключатися до .onion-адреси вашого вузла.

## Поширені помилки

- Збирання zcashd за наведеними вище інструкціями з очікуванням робочого вузла. Ці бінарні файли зупиняються на висоті припинення підтримки.
- Запуск вузла з припущенням, що ваш мобільний гаманець тепер його використовує. Легкий гаманець продовжує звертатися до сервера, на який його налаштовано, доки ви не вкажете йому власний. Дивіться [Вузли легких гаманців](/zcash-tech/lightwallet-nodes).
- Запуск лише `zebrad` з очікуванням, що легкі гаманці підключаться. Вузлу потрібен індексатор поруч: або lightwalletd, або [Zaino](/zcash-tech/zaino).
- Пошук RPC гаманця на вузлі. Ключі та баланси перенесено до Zallet.
