## Ahoboa
[Kra & Gye Wo Keystone 3 Pro anaa Keystone 3](https://keyst.one) 

Battery Level: Hwɛ sɛ wo keystone device no wɔ battery level a ɛboro 20%.

USB Nhama anaa SD Kaad:

- USB cable ma firmware Update (a ɛka ho).
- Micro SD card (a ɛwɔ 1 TB ase) ma nkɔso (tɔ no soronko).

Keystones official website a wobɛkɔ so akɔ Verification ne Firmware Update.

Zashi app nhyehyɛe wɔ wo mobile device so.

## [Anamɔn biara Akwankyerɛ(Keystone Device)](https://keyst.one/get-started) 


**Paw Wo Kasa**
-Device Verification(via QR): Device Verification ho hia kɛse sɛ wobehu efĩ a ebetumi aba bere a wɔde rekɔ, siw supply chain ntua ano, na wɔhwɛ hu sɛ ahobammɔ wɔ firmware a wɔde ahyɛ mu no mu.
  - Kɔ Device Verification krataafa a ɛwɔ Keystone wɛbsaet no so.
  - Klik Scan QR Code so wɔ aban wɛbsaet no so.
  - Fa wo Keystone mfoninitwa afiri no scan QR code a wɔakyerɛ wɔ wɛbsaet no so no.
  - Verification code bi bɛpue wɔ wo Keystone screen no so.
  - Hyehyɛ saa koodu yi wɔ wɛbsaet no so na wie nokwaredi nhyehyɛe no.

- **Firmware Nsakraeɛ:**
  - Fa MicroSD kaad so yɛ foforo
    - Hwɛ sɛ anyɛ yiye koraa no, wo Keystone sika kotoku no wɔ battery charge 20%.
    - Fa SD card no hyɛ wo kɔmputa no mu na fa format no sɛ FAT32.
    - Twe Cypherpunk firmware a aba foforo no fi [Keystone Firmware Update krataafa no so](https://keyst.one/firmware) na fa keystone3.bin fael no sie wo MicroSD kaad no ntini mu.
    - Fa SD card a firmware no wom no gu wo Keystone sika kotoku mu.
    - Kɔ "Upgrade" option a ɛwɔ wo Keystone sika kotoku no so, afei di akwankyerɛ a ɛwɔ screen no so akyi na fi ase yɛ update nhyehyɛe no.
  - **Fa USB Cable so yɛ foforo**
    - Sɛ wo firmware version no nnu 1.0.4 a, ɛho behia sɛ wode MicroSD card yɛ update a edi kan no ansa na woatumi akɔ so ayɛ USB updates.
    - Hwɛ sɛ anyɛ yiye koraa no, wo Keystone sika kotoku no wɔ battery charge 20%.
    - Fa USB so to so na fa USB nhama no di dwuma de fa wo Keystone sika kotoku no bata wo kɔmputa no ho. Klik [Approve] na ma wo Keystone sika kotoku USB kwan, efisɛ ebia ɛbɛma kwan ma woabɔ charge nkutoo.
    - Bue wo kɔmputa ahorow wɛb brawsa na kɔ [Keystone Firmware Update krataafa no so](https://keyst.one/firmware)
    - Wɔ update krataafa no so no, klik Install Update button no so na di akwankyerɛ a wɔde ama no akyi na fa firmware a aba foforo no hyɛ mu.
- **Yɛ Wallet:**
    - Secure Password: Paw PIN anaa password a emu yɛ den a wode bɛbɔ wo sika kotoku ho ban.
    - To Wo Sikakorabea Din (Wɔpɛ): Sɛ wopɛ a, ma wo sika kotoku no din na ama ɛnyɛ den sɛ wubehu anaasɛ twa anammɔn yi so.
    - Paw Create New Wallet sɛ woresiesie sika kotoku nea edi kan a.
    - Wo mfiri no bɛma woanya nsɛmfua 24 aba kasasin.
    - Kyerɛw aba kasasin yi to hɔ na fa sie yiye.
    - Si aba kasasin no so dua denam nsɛmfua a wobɛhwɛ so nnidiso nnidiso sɛnea ɛte wɔ screen no so no so.
- **Fa Zashi + Keystone Sikakorabea no di nkitaho:**
    - Wɔ Keystone afiri no so: Klik ... wɔ kratafa titiriw no so
    - Kɔ Connect Software Wallet so na paw Zashi. QR code a ɛbɛma woanya Zashi nkitahodi no bɛda adi.
    - Wɔ Zashi App mu no: Klik zashi dropdown (screen no atifi benkum so) .
    - Kɔ Connect Hardware Wallet so
    - Kɔ Ready to Scan so
    - Scan QR a wɔada no adi wɔ Keystone Device so no
    - Wɔ Zashi App mu no: Si Keystone Wallet Akontaabu no so dua denam akontaabu a wɔada no adi a wobɛbɔ so
    - Klik Connect so wɔ screen no ase
