# Zcash Network Nkɔsoɔ a Wɔayɛ

Zcash tu mpɔn denam network upgrades so: nsakrae a wɔayɛ no biako wɔ mmara a node biara pene so, emu biara yɛ adwuma wɔ set block height. Upgrade biara a ɛwɔ aseɛ ha no wɔ n’ankasa krataafa a ɛkyerɛkyerɛ mu, wɔ kasa a ɛnyɛ den mu, deɛ ɛsesaeɛ ne deɛ enti a ɛsesaeɛ. Ɛyɛ foforo wɔ Zcash mu? Kenkan wɔn nnidiso nnidiso, efi Sprout kosi Ironwood.

Sɛ wopɛ asɛm a wɔde aniwa hu a ɛfa sɛnea Zcash kokoamsɛm akɔ so wɔ saa nkɔsoɔ yi nyinaa mu a, hwɛ [Nkɔso a Ɛba wɔ Kokoam Nsɛm Ho](https://zechub.wiki/zcash-evolution). Kratafa yi ne index no. Ɛno ne bere nhyehyɛe.

Wɔakyerɛ nna no wɔ UTC mu. Dashboard ahorow bi kyerɛ wɔn wɔ mpɔtam hɔ bere mu, a ɛyɛ block koro no ara ne bere koro no ara. Ironwood date no yɛ akontaabu a efi ne activation block sorokɔ, a ɛyɛ fixed trigger, enti da pɔtee no betumi asesa kakra. Daakye nkɔsoɔ, NU7, da so ara wɔ nhyehyɛeɛ mu na ɛnte sɛ Ironwood.
