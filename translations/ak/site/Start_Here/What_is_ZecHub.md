# Dɛn ne ZecHub?
---

ZecHub yɛ nwomasua beaeɛ a wɔde ama Zcash. Botae a ɛwɔ [ZecHub na ɔkyerɛwee](http://zechub.xyz) ne sɛ ɛbɛma nkyerɛkyerɛ atenaeɛ a mpɔtam hɔfoɔ bɛtumi abom ayɛ adwuma de abɔ, ahyɛ mu den, na wɔahyɛ nneɛma a ɛboa Zcash abɔdeɛ a nkwa wom nhyehyɛeɛ no ho nkuran. Yɛfa akwan kakraa bi so na ɛyɛ eyi.

1. [Nkyerɛkyerɛ a wɔde ma](https://www.youtube.com/playlist?list=PL6_epn0lASLFF28ePj7P5TvtMG_WE7p3O)
2. [Wiki-docs a wɔde kyerɛw nsɛm](https://zechub.wiki/)
3. [Podcast a ɛbisabisa mpɔtam hɔfoɔ nsɛm](https://www.youtube.com/playlist?list=PL6_epn0lASLHlNCMtUErX8UfaJK6N9K5O).
4. [Nnawɔtwe biara Zcash amanneɛbɔ krataa.](https://zechub.substack.com/)

Nkyerɛkyerɛ, blog tiawa, ne nsɛmma nhoma no yɛ nea wɔabue ano na wɔde ahyɛ GitHub so, a ɛkyerɛ sɛ obiara a ofi mpɔtam hɔ betumi aboa. Eyi yɛ nea wɔde hwɛ hu sɛ emu nsɛm no yɛ nokware na ɔkwan no ankasa renhu amane wɔ huammɔdi biako pɛ ho.

Sɛ woyɛ foforo wɔ Zcash mu a, fa di dwuma [akwankyerɛ yi](/start-here/new-user-guide).****

2. Yɛ Github akonta foforo anaa fa w’ankasa wo deɛ kɔ mu
