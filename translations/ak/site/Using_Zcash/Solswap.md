# **Sɛnea wobɛsesa ZEC wɔ Phantom Wallet mu**

![img1](/content-images/SJOlnt-ceg-34468cfecd.webp)

Wokura ZEC dedaw wɔ Solana (sɛ nhwɛso no efi token a wotua holders wɔ ZEC)? Mma nnsesa no. Fa saa token no kɔ Zcash sika kotoku a wɔabɔ ho ban a [Woanya ZEC wɔ Solana so? Fa kɔ Zcash a wɔabɔ ho ban no so](/using-zcash/solana-zec-to-shielded).

---

## **Native ZEC anaasɛ ZEC token bi?**

"ZEC" wɔ Phantom betumi akyerɛ agyapade ahorow abien, enti hu nea woretua ho ka.

- **Phantom's built-in Swap button** ma wo token gyinabea a ɛkyerɛ ZEC wɔ Solana (anaasɛ network foforo a Phantom boa). Ɛnyɛ ZEC. Ɛte wo Phantom address so, enni Zcash shielded dwumadie biara, na Zcash sika kotokuo ntumi nhunu anaasɛ ɛbɔ ho ban.
- **Native ZEC** wɔ Zcash blockchain no so nko ara na wɔde kɔ Zcash address bi so. Sɛ wobɛnya no a, ɛhia service a ɛbisa wo Zcash address, te sɛ swap a ɛwɔ mu [ZODL](https://zodl.com), akwan horow a ɛwɔ so no mu biako [DEX kratafa no](/dex), anaa solswap.org a ɛno akyi no, wobɛtwe sika akɔ wo Zcash sika kotoku mu (Anamɔn 8).

### Hwɛ ansa na woatua

- **Network:** ɛsɛ sɛ ZEC a wo nsa bɛka no wɔ **Zcash** network no so. Sɛ ɛka sɛ Solana, Ethereum anaa Base a, ɛyɛ token.
- **Agyapadeɛ:** native ZEC nni token contract anaa mint address biara. Sɛ wo de no kyerɛ biako a, ɛyɛ token. Afei nso, "ZEC" tokens a ɛte sɛ nea ɛdɔɔso wɔ Solana so, enti nkɔ edin no nkutoo so. OmniBridge token a ɛwɔ Solana so no yɛ `A7bdiYdS5GjqGFtxf17ppRHtDKPkkRqbKtR27dxvQXaS`; ɛno da so ara yɛ token, ɛnyɛ native ZEC.
- **Address:** native ZEC kɔ Zcash address bi so, a ɛfiri aseɛ `t1`, `u1` or `zs`. Sɛ wɔde ZEC no rekɔ wo Phantom address so a, na worenya token.

---

##  **Anamɔn 1: Bue Swap Interface no**
Fi ase **Phantom app** no na kɔ **[solswap.org so na ɛwɔ hɔ](https://solswap.org/)** fi Phantom browser no so. W’ankasa kyerɛw address no. Sait no yɛ adwuma wɔ NEAR Intents so na ebetumi de ZEC akɔ Zcash address bi so.

Phantom's ankasa **Swap** button nso kyerɛw ZEC, nanso ɛno ma wunya token a yɛaka ho asɛm wɔ atifi hɔ no, ɛnyɛ native ZEC.

![img2](/content-images/S1Cp-KWqxe-ab70e844b9.webp)

##  **Anamɔn 2: Paw Networks ne Tokens a wode bɛto hɔ**
- Paw wo **source network** (sɛ nhwɛso no, *Ethereum* anaa *Solana*) afei fa to hɔ ma sesa.

![img3](/content-images/S1SaGYZ9xx-2a27ccdd47.webp)

- Paw base token te sɛ **SOL, USDT, anaa USDC**.
- Paw **ZEC** sɛ wo **destination token**.
- Hwɛ sɛ Zcash nam swap interface no so wɔ hɔ.

![img4](/content-images/ry4QQF-5gx-f3805528ea.webp)

---

##  **Anamɔn 3: Hyehyɛ Sika dodow & Nhwehwɛmu Quote**
- Hyehyɛ sika dodow a wopɛ sɛ wosesa.
- Fa sika a wogye a wɔakyerɛ wɔ **solswap.org** no di dwuma. Saa asɛm a wɔafa aka no ne nea ɛfa ɔkwan yi so.

![img5](/content-images/B1U1NYW5xe-58cf150668.webp)

---

##  **Anamɔn 4: Hwɛ Gas & Fees**
- Fa source-chain gas token no sie a ɛdɔɔso wɔ Phantom mu na ama woapene deposit no so (*SOL* wɔ Solana so, *ETH* wɔ Ethereum so).
- Kenkan fee line a ɛwɔ solswap quote no so ansa na woasi so dua. Phantom's built-in Swap de n'ankasa fee nhyehyɛe di dwuma (abakɔsɛm mu no ɛyɛ 0.85% Phantom fee a wɔde network gas ne bridging fee ka ho). Saa nɔma ahorow no mfa solswap.org sika a wɔde asie ho.

---

##  **Anamɔn 5: Sesa Nsiesiei (Wɔpɛ)**
Wɔ solswap.org no, hwɛ slippage ne quoted minimum receive wɔ saa screen no so ansa na wode sika ahyɛ mu.

Sɛ worehwɛ Phantom's ankasa **Swap** krataa no mmom a, wowɔ token kwan no so fi krataafa yi atifi. To mu na bue `solswap.org` wɔ Phantom browser no mu.

---

##  **Anamɔn 6: Si Swap so dua**
- Hwɛ swap ho nsɛm nyinaa wɔ solswap.org.
- Si so dua sɛ wode sika asie wɔ Phantom.

![img6](/content-images/HkU1UKZ5gx-e068ea8d5a.webp)

---

## **Anamɔn 7: Monitor Gyinabea**
- Di sika a wode asie no akyi wɔ solswap.org dwumadi mu kosi sɛ ɛbɛkyerɛ sɛ **Wɔawie**.
- Solana anaa source-chain transaction ID no wɔ saa dwumadie row no so ne chain explorer no so ma saa network no.

![img7](/content-images/S1NBwKbcxe-5b7d11f5c1.webp)

## **Anamɔn 8: Twe Native ZEC kɔ Wo Zcash Wallet mu**
Swap no akyi no, wo ZEC bɛda adi wɔ wo solswap.org **Account** balance no mu. Ɛnnya mmaa Zcash network no so, na ɛnni Phantom nso mu.

1. Bue Zcash sika kotoku bi a [directory a wɔde kyerɛw nsɛm](/wallets) agyiraehyɛde **Ironwood: Wɔasiesie**. Copy a `u1` wo sika kotoku no nkyerɛwde sɛ wɔabɔ ho ban. BI `t1` nso yɛ adwuma, nanso saa sika a wode asie no yɛ ɔmanfo de kosi sɛ wobɛbɔ ho ban.
2. Wɔ solswap.org so no, kɔ **Account** na pia **Withdraw**. Paw **ZEC**, hyehyɛ network no to **Zcash**, fa address no hyɛ mu na hwɛ nkyerɛwde a edi kan ne nea etwa to ansa na woasi so dua.
3. Sɛ **Received amount** ne **Fee** tra "–" na button no nyɛ hwee a, sika a aka no nnyera. Ɛte NEAR Intents mu wɔ wo Phantom key ase. Wie wɔ so [bɛn.com](https://near.com): fa Phantom sika kotoku koro no ara hyɛ mu, bue **Move legacy assets**, pia **Withdraw** wɔ ZEC row no so (ɛnyɛ **Move**), hyehyɛ network no to **Zcash**, na fa saa ara `u1`. Phantom bɛka akyerɛ wo sɛ **Sign Message**. Sɛ abisade no fi hɔ nkutoo a, si so dua `near.com` ne nkrasɛm no din ahorow `"verifying_contract": "intents.near"`. Screens a edi mũ a wɔde bɛyɛ saa adwuma no wɔ mu [Woanya ZEC wɔ Solana so? Fa kɔ Zcash a wɔabɔ ho ban no so](/using-zcash/solana-zec-to-shielded).

---

## **Anamɔn a Edi Hɔ**
Sɛ native ZEC wɔ wo Zcash sika kotoku mu pɛ a, fa sie shielded ne [ZEC a wode bedi dwuma wɔ kokoam](/guides/using-zec-privately).

ZEC token a wɔde Phantom's Swap button atɔ no, wontumi mmɔ ho ban mfi Phantom. Saa token no ne OmniBridge agyapadeɛ a ɛwɔ Solana so. Fa no kɔ baabi foforo [Woanya ZEC wɔ Solana so? Fa kɔ Zcash a wɔabɔ ho ban no so](/using-zcash/solana-zec-to-shielded).
