# Nea Enti a Kokoam Nsɛm Ho Hia

Wɔ dijitaal bere yi mu no, ahobammɔ a wobɛbɔ wo [kokoamusɛm](https://www.privacyguides.org/en/) abɛyɛ nea ɛho hia kɛse. Bere a ebia ebinom bebu kokoam nsɛm sɛ ade a ayera de, nanso ɛnte saa. Wo kokoam nsɛm da asiane mu na ɛsɛ sɛ ɛyɛ ade a ɛhaw wo. Kokoam nsɛm som bo kɛse efisɛ ɛfa tumi ho, na hwɛ a wɔbɛhwɛ sɛ wɔde tumi bedi dwuma wɔ asɛyɛde mu no ho hia yiye.

## Tor & I2P Mfiridwuma Ho Nneɛma

## Tor

[Tor](https://www.privacyguides.org/en/tor/?h=tor) yɛ proxy adwinnade a ɛde Tor network no di dwuma de hyehyɛ nkitahodi ma application ahorow. Torbot nya eyi denam wɔn kar a wɔde fa Tor so, na ɛnam so ma ɛyɛ kɛse [kokoam nsɛm ne din a wɔmmɔ](https://www.torproject.org/) ma saa akwammisa ahorow yi.

## I2P Ntrɛwmu

I2P network a wɔsan frɛ no... [Intanɛt Dwumadi a Aniwa Nhu](https://geti2p.net/en/about/intro), yɛ peer-to-peer overlay network a wɔabɔ no kokoam koraa. Ɛhwɛ hu sɛ wɔde nkrasɛm no mu nsɛm, fibea, ne baabi a ɛkɔ no asie wɔn a wɔhwɛ no. Ɔkwan foforo so no, obiara ntumi nhu baabi a kar no fi anaa baabi a ɛrekɔ anaa nkrasɛm a wɔde rekɔ no mu nsɛm ankasa. Encryption a wɔde di dwuma wɔ I2P mu no hwɛ hu sɛ wɔn a wɔde di dwuma no nya kokoam nsɛm a ɛkorɔn na wɔmmɔ din.

### I2P a wɔde bɛhyɛ mu

Nneɛma abien na wɔde di dwuma. Mfitiase no [Java I2P na ɛwɔ hɔ](https://geti2p.net/en/download) ɛyɛ adwuma wɔ Windows, macOS, Linux ne Android so. [i2pd](https://i2pd.website/), a wɔde C++ akyerɛw no, yɛ hare na ɛyɛ nea wɔtaa paw wɔ server anaa afiri a ahoɔden sua so.

Sɛ ɛyɛ adwuma wie a, I2P da mpɔtam hɔ console bi adi wɔ so `127.0.0.1:7657` ne proxy ahorow a ɛwɔ so `127.0.0.1:4444` (HTTP) ne `127.0.0.1:4447` (SƆKOSO). Hwɛ kwan sɛ ebegye simma pii wɔ mfiase a edi kan no mu: Ɛsɛ sɛ I2P yɛ tunnels fa network no so ansa na biribiara ayɛ adwuma, na ɛyɛ ntɛmntɛm bere tenten a ɛtra intanɛt so no.

### I2P a wode bedi dwuma ne Zcash

Hu sɛ **mprempren Zcash node biara nka I2P natively.** Zebra nni I2P mmoa, na zcashd nso annyɛ saa. Sɛ wohu akwankyerɛ bi a ɛkyerɛ sɛ ɛde Zcash node di dwuma wɔ I2P so a, ɛrekyerɛkyerɛ biribi a softwea no nyɛ mu.

Nea I2P ho wɔ mfaso ankasa ma ha ne biribiara a atwa sika kotoku no ho ahyia: sɛ wobɛkɔ sait bi, forum anaa ɔsom bi so a worenda wo address adi. Sɛ wopɛ sɛ wobɔ sika kotoku nkitahodi no ankasa din a, Tor ne ɔkwan a mfaso wɔ so nnɛ, na afã horow a ɛwɔ ase hɔ no kata so.

## Tor ne I2P kyɛ nneɛma a ɛyɛ pɛ nanso ɛwɔ nsonsonoe kɛse nso. 

Tor ne I2P nyinaa yɛ decentralized ne anonymous peer-to-peer networks, nanso I2P ma ahobanbɔ a ɛkorɔn sɛ wɔde toto Tor ho a. Nanso, wɔayɛ I2P titire sɛ wɔde bɛkɔ nnwuma te sɛ email, chat, ne torrent wɔ ne network mu na wontumi mfa nni dwuma mfa nkɔ intanɛt a wɔde di dwuma daa no so. Ɔkwan foforɔ so no, Tor ma wɔn a wɔde di dwuma no kwan ma wɔkɔ wɛbsaet a emu dɔ no so, te sɛ I2P, nanso ɛsan nso yɛ adwuma sɛ browser a ɛyɛ daa a wɔde kɔ wɛbsaet a ɛwɔ wɛb a ɛwɔ soro no so.

*Hyɛ no nsow: Sɛ wopɛ nsɛm pii fa nsɛdi ne nsonsonoe a ɛwɔ Tor & I2P mu ho a, kɔ hɔ [ha](https://geti2p.net/en/comparison/tor)*

## Mobile sika kotoku a wɔde Orbot refa Tor so

Orbot yɛ virtual private network (VPN) a ɛho ka sua a wɔayɛ ama smartphones a ɛkyerɛ traffic fi applications nyinaa a ɛwɔ wo device so denam Tor network so.

Di akwankyerɛ yi akyi na fa Zcash sika kotoku bi fa Tor so. Hyɛ no nsow sɛ Ywallet, a akwankyerɛ yi nkyerɛase ahorow a atwam no de dii dwuma no, wɔnhwɛ so bio na ɛrenni network no akyi wɔ Ironwood akyi, enti paw sika kotoku a wɔahwɛ so yiye fi [Sika kotoku](/using-zcash/wallets) kratafa.

1.  Twe na fa *Orbot* fi app store no so.

2.  Sɛ insatllation wie a, nkyia nkrasɛm bɛda adi. Kɔ so kɔ *Orbot* home page no so na klik *'Tor Enabled Apps' so.* 

3. Wei bɛma woanya kratafa bi wɔ screen no so a ɛkyerɛ application ahorow a ɛne Tor hyia. Hwehwɛ wo Zcash sika kotoku no wɔ list no mu na hwɛ hu sɛ woapaw.

4. Nkitahodi abisade a wɔde besiesie VPN bɛda adi, a ɛbɛma *Orbot* atumi ahwɛ ntwamutam akwantuo no so. *Orbot* bɛ Initialise bere a wɔapene saa kwan yi so pɛn. 

5. Hwɛ taskbar anaa Orbot homepage no mu na hwɛ sɛ Tor reyɛ adwuma, eyi si so dua bere a wuhu 'Connected to the Tor network'.

*Hyɛ no nsow: Sɛ wo mobile network no siw Tor kwan a, wubetumi de Bridge Server adi dwuma sɛ ɔkwan foforo a wobɛfa so abɔ.*


## Tor a wode bɛhyɛ PC anaa desktop so

* Tor browser betumi atwe afi official website no so, wubetumi akɔ link no so [ha](https://www.torproject.org/download/).

 Ɔkwan a ɛyɛ mmerɛw sen biara a wobɛfa so ahyɛ Tor ne Tor Browser Bundle. Sɛ wopɛ instɔlehyɛn a enni ti a, wobɛtumi apaw sɛ wobɛhyehyɛ Tor daemon no wɔ ɔkwan soronko so. 

*Hyɛ no nsow: Sɛnea wɔahyɛ no, Tor Browser bundle no da SOCKS atiefo bi adi wɔ tcp/9150 so na Tor daemon no da SOCKS atiefo adi wɔ tcp/9050 so.*

* Hwɛ instɔlehyɛn no [akwankyerɛ](https://support.torproject.org/apt/) pɔtee ma wo dwumadie nhyehyɛeɛ no sɛdeɛ Tor Project no de ama no.

## Node a wɔde tu mmirika wɔ Tor so

Eyi ne ɔfã a asesa kɛse, na mmuae a ɛyɛ nokware ne sɛ mprempren ɛyɛ den sen sɛnea na ɛte.

**zcashd ayera.** Ɛduruu mmoa awieeɛ na ɛgyinaa wɔ 18 July 2026 wɔ block 3,417,100. Ɛrensan mfi ase bio, ne download krataafa no san de 404 ba, na apt repository no nsom bio. Akwankyerɛ biara a ɛka kyerɛ wo sɛ tu mmirika `zcashd -proxy=127.0.0.1:9050` mfa biribiara ho bio.

**Zebra nso ntumi nyɛ no de besi nnɛ.** Zebra ne node a wɔhwɛ so, na ne network crate no kura isolated-connection code ma Tor, nanso wɔaka feature no ho asɛm wɔ mu `zebra-network/Cargo.toml`:

```
# tor = ["arti-client", "tor-rtcompat"]
```

Crate documentation no ka adeɛ korɔ no ara pefee: *"Mprempren wɔagyae tor connections kɔsi." `arti-client`'s a ɔde ne ho to so `x25519-dalek v1.2.0` no yɛ foforo."* The `connect_isolated_tor` function no yɛ commented out ka ho. Enti ɔkwan biara nni hɔ a wɔboa a wobɛfa so ayɛ Zcash node wɔ Tor so nnɛ.

Sɛ wo hia node-level anonymity seesei a, ɔkwan a ɛyɛ adwuma ne sɛ wode afiri no nyinaa bɛto Tor anaa VPN akyi wɔ operating-system level sen sɛ wobɛhyehyɛ node no ankasa. Ɛno bɔ wo network beae ho ban a womfa wo ho nto node features a wɔankyekye so.

### Nea woda so ara betumi ayɛ nnɛ

- **Fa wo sika kotoku no fa Tor** a Orbot wɔ mobile so, sɛnea yɛaka ho asɛm wɔ atifi hɔ no. Eyi ne ɔkwan a mfaso wɔ so ma nnipa dodow no ara, na ɛde wo IP sie fi lightwalletd server a wo sika kotoku ne no kasa no
- **Fa Tor Browser** di dwuma ma block explorers, forums ne biribi foforo biara a wobɛpɛ sɛ womfa address nhyɛ wo nkyɛn
- **Kae nea Tor mfa nsie.** Ɛma wo network beae no yɛ anonymize, ɛnyɛ wo on-chain dwumadi. Sɛ wode fi address a ɛda adi pefee so mena a, ɛda so ara yɛ baguam, na bo a ɛsom a ɛda atare a wɔabɔ ho ban ntam no da so ara tintim sika dodow no. Hwɛ [Atare a Wɔabɔ ho Ban](/using-zcash/shielded-pools) esiane nea ɛda so ara yɛ nea wotumi hu nti
