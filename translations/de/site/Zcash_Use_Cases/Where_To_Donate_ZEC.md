> Zuletzt geprüft: 27. Oktober 2026, auf den jeweiligen Spendenseiten der Organisationen. Adressen ändern sich, daher verlinkt diese Seite auf die Spendenseiten, statt Adressen zu kopieren. Kopieren Sie die Adresse immer von der Website der jeweiligen Organisation. Hinweise zur Steuer sind Angaben der jeweiligen Organisation und keine Steuerberatung.

## TL;DR

- Neun gemeinnützige Organisationen veröffentlichen eine ZEC-Adresse. Fünf von ihnen verwenden eine abgeschirmte Adresse, sodass Ihre Spende on-chain privat bleibt
- Vier bekannte gemeinnützige Organisationen akzeptieren ZEC nur an einer transparenten Adresse: EFF, Freedom of the Press Foundation, das Tor Project und das Internet Archive
- Spendenplattformen wie The Giving Block und Every.org akzeptieren ZEC für Tausende Wohltätigkeitsorganisationen, aber keine von ihnen gibt an, abgeschirmtes ZEC zu unterstützen
- Wenn Sie eine Spendenquittung benötigen, prüfen Sie vor der Spende den Hinweis der jeweiligen Organisation unten

## <img src="/content-images/user-svgrepo-com-21adf62b7c.svg" width="24" height="24" className="inline-block align-middle mr-1 p-[2px]" alt="user icon"/> Für wen ist das?

- ZEC-Inhaber, die für einen Zweck spenden möchten, der ihnen wichtig ist
- Spender, die möchten, dass ihre Spende privat bleibt
- Alle, die eine Liste von Organisationen suchen, die sie mit ZEC unterstützen können

Wenn Sie eine gemeinnützige Organisation betreiben und ZEC akzeptieren möchten, siehe [Private Spenden als US-Nonprofit akzeptieren](/zcash-use-cases/accept-private-donations-as-a-us-nonprofit).

<br/>

## <img src="/content-images/icons8-lock-2f8e221321.svg" width="24" height="24" className="inline-block align-middle mr-1 p-[2px]" alt="lock icon"/> Abgeschirmt oder transparent: Warum es wichtig ist

Wenn Sie ZEC von einer abgeschirmten Wallet an eine **abgeschirmte** Adresse senden, bleiben der Betrag, der Absender und der Empfänger alle privat.

Wenn Sie an eine **transparente** Adresse senden, ist die Spende auf der blockchain sichtbar: Jeder kann den Betrag, den Zeitpunkt ihres Eingangs und den Kontostand der Organisation sehen. Die übrigen Aktivitäten Ihrer abgeschirmten Wallet bleiben privat, aber die Spende selbst ist öffentlich. Siehe [The Turnstile](/zcash-tech/the-turnstile), um zu erfahren, was öffentlich wird, wenn ZEC einen abgeschirmten Pool verlässt.

Beide unterstützen weiterhin die Organisation. Abgeschirmt hält lediglich die Spende privat.

## <img src="/content-images/chain-for-links-svgrepo-com-117ee0dec1.svg" width="24" height="24" className="inline-block align-middle mr-1 p-[2px]" alt="chain-links icon"/> Spendenplattformen

Plattformen akzeptieren ZEC im Namen vieler Wohltätigkeitsorganisationen, wandeln es normalerweise in Dollar um und senden Ihnen die Quittung. Sie sind eine einfache Möglichkeit, einer Wohltätigkeitsorganisation ZEC zu spenden, die selbst keine Kryptowährungen hält. Keine von ihnen gibt an, abgeschirmtes ZEC zu akzeptieren, erwarten Sie also, von oder an eine transparente Adresse zu senden.

| Plattform | Was sie ist | ZEC |
|---|---|---|
| [The Giving Block](https://thegivingblock.com/resources/cryptocurrency-we-accept/) | Kryptospenden-Service, der von vielen US-Nonprofits genutzt wird | Gelistet |
| [Every.org](https://support.every.org/hc/en-us/articles/1500007829861-What-cryptocurrencies-coins-and-exchanges-does-Every-org-support) | Spendenplattform für US-Wohltätigkeitsorganisationen | Gelistet |
| [The Signatry](https://thesignatry.com/asset-giving/cryptocurrency/) | Christlicher donor-advised fund | Auf seiner Kryptoseite erwähnt; fragen Sie zuerst nach |

## <img src="/content-images/ladder-svgrepo-com-7232bf46ed.svg" width="24" height="24" className="inline-block align-middle mr-1 p-[2px]" alt="step icon"/> So spenden Sie

1. Wählen Sie oben eine Organisation aus und öffnen Sie ihre Spendenseite
2. Kopieren Sie die ZEC-Adresse von dieser Seite, nicht aus diesem Wiki oder einem Screenshot
3. Prüfen Sie nach dem Einfügen die ersten und letzten Zeichen
4. Wenn Sie eine Quittung wünschen, fügen Sie Ihre E-Mail-Adresse im Memo hinzu (nur abgeschirmt) oder folgen Sie dem obigen Hinweis der Organisation
5. Senden Sie aus einer [abgeschirmten Wallet](/wallets)

<br/>

## <img src="/content-images/icons8-cancel-7f786be3c1.svg" width="24" height="24" className="inline-block align-middle mr-1 p-[2px]" alt="cancel icon"/> Häufige Fehler, die Sie vermeiden sollten

- Eine Adresse aus einem Forumsbeitrag, sozialen Medien oder einem alten Screenshot kopieren, statt von der eigenen Seite der Organisation
- Von einer Börse senden, wodurch die Spende mit Ihrem Konto verknüpft werden kann
- Eine Steuerquittung erwarten, ohne vorher den Hinweis der Organisation zu prüfen
- An eine Sapling-Adresse aus einer Wallet senden, die nicht an Sapling senden kann

<br/>

## <img src="/content-images/checked-checkbox-svgrepo-com-7ea19022da.svg" width="28" height="28" className="inline-block align-middle mr-1 p-[2px]" alt="done icon"/> Ergebnis

Sie können:
- Einen Zweck finden, der ZEC akzeptiert
- Eine abgeschirmte Option wählen, wenn Ihre Spende privat bleiben soll
- Vor der Spende wissen, ob Sie eine Quittung erhalten

Kennen Sie eine gemeinnützige Organisation, die ZEC akzeptiert und nicht aufgeführt ist? Schlagen Sie sie mit einem Pull Request vor und verlinken Sie dabei auf ihre eigene Spendenseite.
