> **Ein umfassender Leitfaden zu datenschutzfreundlichen Trinkgeld- und Profil-Tools auf Basis von Zcash für Content-Ersteller, Cypherpunks und die datenschutzbewusste Community.**

## TL;DR

* Zwei Zcash-Tools helfen Kreativen, privat bezahlt zu werden. Zcash.me bietet dir eine Profilseite mit deiner Shielded Address, und mit TIPZ können Fans dir Trinkgelder senden.
* Mit Zcash.me teilst du einen Link, `zcash.me/[username]`, der deine Unified Address und deine Social-Media-Konten zeigt.
* Mit TIPZ können Fans Trinkgelder in anderen Kryptowährungen geben, und jedes Trinkgeld erreicht dich als geschütztes ZEC.
* Beide Tools fragen nach deiner Unified Address (`u1...`).
* Trinkgelder an eine Shielded Address halten dein Einkommen und Guthaben aus der Öffentlichkeit heraus.

## Kernerklärung

### Zcash.me

![Zcash.me Logo](/content-images/_unavailable.svg)

#### Überblick

**Zcash.me** ist ein Profilverzeichnis und eine Discovery-Plattform, mit der jeder leicht ZEC für Zcash-Nutzer finden und senden kann. Es dient als „Linktree für Zcash“ – eine einfache Möglichkeit, deine Shielded Address und deine Social-Media-Präsenz mit einem einzigen Link zu teilen.

| Element              | Details |
|-------------------|---------|
| **Website**       | [https://zcash.me/](https://zcash.me/) |
| **Twitter**       | [@zcashme](https://x.com/zcashme) |
| **Profilformat**| `zcash.me/[username]` |
| **Status**        | Live (mit Funktionen in Entwicklung) |

#### Hauptfunktionen

##### Derzeit verfügbar
- **Individuelle Profilseiten** - Personalisierte Seite mit Benutzername, Biografie, Avatar und Standort
- **Anzeige der Shielded Address** - Kopierbutton mit einem Klick für deine Unified Address
- **Social-Link-Integration** - X, LinkedIn, Telegram und eigene Websites
- **Verifizierungssystem** - Verifiziertes Abzeichen für Vertrauen in der Community
- **Empfehlungsrangliste** - Verfolge die besten Empfehlenden und Community-Leader
- **Aktivitätsstatus** - Zeigt die letzte aktive Zeit an.

##### Demnächst verfügbar
| Funktion            | Beschreibung |
|--------------------|-------------|
| Standortkarte       | Finde Zcash-Nutzer in deiner Nähe |
| Plattformstatistiken| Wachstumsmetriken anzeigen |
| Community-Umfragen    | Über Themen des Ökosystems abstimmen |
| Neuigkeiten & Ankündigungen | Offizielle Updates |
| Forum              | Community-Diskussion |
| Mobile App         | Vollständige mobile Erfahrung |

#### Erste Schritte
1. Besuche [https://zcash.me/](https://zcash.me/) und klicke auf **Join**.
2. Wähle einen einzigartigen Benutzernamen, füge eine Biografie und ein Profilbild hinzu.
3. Füge deine Zcash Unified Address ein (`u1...`)
4. Verbinde deine Social-Media-Konten.
5. Teile deinen Link: `zcash.me/[yourusername]`

### TIPZ

![TIPZ Logo](/content-images/BbXM8cDV_400x400-e6071ba983.webp)

#### Überblick

**TIPZ** ist ein **privates Trinkgeldprotokoll**, das speziell für Kreative und Cypherpunks entwickelt wurde. Fans geben Trinkgelder in jeder wichtigen Kryptowährung; diese werden automatisch umgewandelt und als **geschütztes ZEC** zugestellt.

| Element              | Details |
|-------------------|---------|
| **Website**       | [https://tipz.cash/](https://tipz.cash/) |
| **Twitter**       | [@tipz_cash](https://x.com/tipz_cash) |
| **Profilformat**| `tipz.cash/@[username]` |
| **Status**        | Live |

> *„tipz.cash ist ein privates Trinkgeldprotokoll für Kreative und Cypherpunks.“*

#### Warum Datenschutz für Kreative wichtig ist

##### Finanzielle Freiheit
- 0 % Plattformgebühren
- Non-custodial & Selbstverwahrung
- Keine Mittelsmänner

##### Datenschutzorientiertes Design
- Jedes Trinkgeld kommt als geschütztes ZEC an.
- Privates Wallet-Guthaben
- Verschlüsselte Nachrichten mit Trinkgeldern
- Option auf vollständige Anonymität für Kreative

##### Cross-Chain-Zahlungen
| Währung | Netzwerk |
|----------|---------|
| ETH      | Ethereum |
| USDC     | Mehrere Chains |
| SOL      | Solana |
| ZEC      | Direktes Zcash |

##### Schutz für Kreative
- Kein Risiko einer Deplatforming
- Zensurresistent
- Kein KYC erforderlich

## Visualisierung / Analogie

Ein Trinkgeldglas auf einer Cafétheke ist aus Glas. Jeder im Raum sieht, wer eine Münze hineinwirft und wie voll das Glas ist.

Eine Shielded Address funktioniert wie ein verschlossener Briefkasten mit einem Schlitz. Fans werfen einen Umschlag mit einer Münze und einer Notiz hinein, und nur der Kreative öffnet den Kasten. TIPZ fügt an der Tür einen Währungsumtausch hinzu: Ein Fan kann mit ETH oder SOL ankommen, und was im Briefkasten landet, ist ZEC.

```
TIPZ Payment Flow

Fan -> tipz.cash Protocol -> Creator's Wallet (Shielded ZEC)

Fan selects amount + message -> Protocol auto-converts -> Creator receives private shielded ZEC.
```
