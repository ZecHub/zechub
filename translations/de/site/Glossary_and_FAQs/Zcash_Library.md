## A

| Begriff | Definition |
|------|-----------|
| Actions | Anstatt für jeden Spend und Output mehrere einzelne Beweise zu erstellen, führt das Orchard-Protokoll diese in einer einzigen Action zusammen. |
| Adressen | Zcash hat Shielded- (Z/zaddr) und transparente (T/taddr) Adressen. Unified Addresses (UA) werden schrittweise eingeführt, um Z und T nach dem NU5-Upgrade zu ersetzen. |
| Arborist Call | Ein zweiwöchentlicher Call zu Updates bei der Zcash-Protokoll- und Forschungsentwicklung. Wird im Zcash Community Forum und auf Discord veranstaltet. [Sitzungsnotizen](https://github.com/ZcashCommunityGrants/arboretum-notes) / [Forum-Ankündigungen](https://forum.zcashcommunity.com) |
| Auto-Shielding | Ermöglicht es Nutzern (genauer gesagt ihren Wallets), Gelder automatisch von einer transparenten Adresse in den neuesten shielded ZEC-Pool zu verschieben. |

## B

| Begriff | Definition |
|------|-----------|
| Benchmarking | Miner können Kennzahlen zur Effizienz verschiedener Hardware einreichen, die für das Mining von Zcash verwendet wird. [Hier ansehen](https://zcashbenchmarks.info) |
| Block | Ein Block ist ein Eintrag in der Zcash-blockchain, der eine Reihe von Transaktionen enthält, die über das Netzwerk gesendet wurden. Im Durchschnitt wird ungefähr alle 75 Sekunden ein neuer Block an die blockchain angehängt. |
| Block Explorer | Ein Online-Tool, um alle vergangenen und aktuellen Transaktionen auf der blockchain anzuzeigen. [Zcash Block Explorer](https://zcashexplorer.app/) |
| Blogs | [ZODL Blog (ehemals Electric Coin Co)](https://zodl.com/blog/) / [Zcash Foundation Blog](https://zfnd.org/blog/) / [ZecHub Blog](https://zechub.wiki/zechub-dao) |
| Blossom | Das 3. große Netzwerk-Upgrade für Zcash. [Mehr Infos](https://zcash.readthedocs.io/en/latest/rtd_pages/nu_dev_guide.html?highlight=orchard#blossom) |

## C

| Begriff | Definition |
|------|-----------|
| Canopy | Das 5. große Netzwerk-Upgrade für Zcash. [Mehr Infos](https://zcash.readthedocs.io/en/latest/rtd_pages/nu_dev_guide.html?highlight=orchard#canopy) |
| Commitment Scheme | Ermöglicht es einem Committer, sich mit einer kurzen Zeichenfolge auf ein Polynom festzulegen, die von einem Verifier genutzt werden kann, um behauptete Auswertungen des festgelegten Polynoms zu bestätigen. Nützlich zur Reduzierung der Kommunikationskosten im Zcash-Protokoll. |
| Community | [Das offizielle Zcash Community Forum](https://forum.zcashcommunity.com) / [Zcash Community Discord](https://discord.com/channels/669694001464737815/669694001921654794) / [Zcash R&D Discord](https://discord.com/invite/6AK7keWFaK) / [Reddit](https://www.reddit.com/r/zec/) / [Telegram](https://t.me/Zcash_Community) / [Twitter](https://x.com/zcash) |
| Cypherpunk Zero | Ein Creative Universe und gemeinschaftliches Projekt zwischen ECC, dem Illustrator Stranger Wolf, Mighty Jaxx und ausgewählten Ökosystem-Partnern. [Cypherpunk Zero Website](https://halo.electriccoin.co/?utm_source=ECC&utm_medium=Website&utm_campaign=None) / [Opensea-Sammlung](https://opensea.io/collection/cypherpunk-zero) |

## D

| Begriff | Definition |
|------|-----------|
| DeFi | Projekte, die ZEC mit DeFi integrieren: [Maya Protocol](https://www.mayaprotocol.com/ecosystem#user-interfaces/) / [Near Intents](https://near-intents.org/) / [ZenRock](https://app.zenrocklabs.io/) / [ShapeShift](https://app.shapeshift.com/) / [LeoDex](https://leodex.io/) / [ThorSwap](https://app.thorswap.finance/) |
| Deshielding | Bezieht sich auf eine Transaktion, die von einer zaddr (shielded Adresse) an eine taddr (transparente Adresse) gesendet wird. Der Ursprung der Transaktion ist nicht sichtbar, jedoch gelangen die Gelder in einen öffentlich sichtbaren Wertpool. |
| Entwickler-Ressourcen | [Entwickler-Ressourcen](https://www.zcashcommunity.com/developers/) |
| Dokumentation | [Offizielle Dokumentation](https://zcash.readthedocs.io/en/latest/) |

## E

| Begriff | Definition |
|------|-----------|
| ECC | Die Electric Coin Company, das Team hinter dem Zcash-Protokoll, früher bekannt als die Zcash Company. |
| ECDSA | Elliptic Curve Digital Signature Algorithm ist ein kryptografisch sicheres digitales Signaturschema. Der ECDSA-Signier-/Verifizierungsalgorithmus basiert auf elliptischer Kurvenpunkt-Multiplikation. |
| Bildung | Lernorientierte Videos, die Zcash erklären, gibt es [hier](https://www.zcashcommunity.com/zcash-education/) |
| Verschlüsselte Memos | Ein zusätzliches Feld für Transaktionen an shielded Adressen, das für den Empfänger einer Zahlung sichtbar ist. Das verschlüsselte Memo ist nur für Sender und Empfänger sichtbar. |
| Equihash | Der speicherorientierte Proof-of-Work-Mining-Algorithmus, der bei Zcash verwendet wird. |
| Veranstaltungen | Der Kalender mit Zcash-bezogenen Veranstaltungen kann auf [Luma](https://luma.com/zcash) und [Zcash Foundation](https://zfnd.org/zf-events/) eingesehen werden |
| Börsen | [Liste der Börsen, die Zcash unterstützen](https://z.cash/exchanges/) |

## F

| Begriff | Definition |
|------|-----------|
| Fiat-Shamir | Eine Technik, um aus einem interaktiven Wissensbeweis eine digitale Signatur zu erzeugen. Auf diese Weise kann eine Tatsache (z. B. das Wissen um ein Geheimnis) öffentlich bewiesen werden, ohne die zugrunde liegenden Informationen offenzulegen. |
| Founders Reward | Die Gründerbelohnung entspricht 20 Prozent der gesamten Blockbelohnung; sie wird vom Wert jedes Blocks abgezogen und transparent verteilt, um Protokollentwicklung und Wachstum voranzutreiben. |
| Free2z | Ein Tool für anonyme Inhalte und private Spenden auf Basis von Zcash. [Free2z](https://free2z.com) |
| FROST | Flexibles, rundenoptimiertes Schnorr-Threshold-Signaturschema. [Forschungspapier](https://eprint.iacr.org/2020/852) |

## G

| Begriff | Definition |
|------|-----------|
| Governance | Entscheidungen aus dem ZIP-Prozess werden in die Zcash-Spezifikation sowie in die Software geschrieben, die das Netzwerk betreibt. Die Änderungen werden on-chain ratifiziert, wenn die Mehrheit des Netzwerks das Upgrade übernimmt und den Konsens nicht bricht. [Vollständige Protokollhistorie](https://zfnd.org/protocol-governance/) |

## H

| Begriff | Definition |
|------|-----------|
| Halo | Ermöglicht Circuit-Upgrades ohne Trusted Setup und macht das shielded Protokoll von Zcash agiler für künftige Verbesserungen und Erweiterungen. [Technische Erklärung](https://z.cash/learn/what-is-halo-for-zcash/) |
| HD Wallet | Hierarchisch-deterministische Wallets erzeugen aus einem einzigen Seed eine Reihe von Schlüsselpaaren und bieten so Komfort, einfache Verwaltung sowie ein hohes Sicherheitsniveau. |
| Heartwood | Das 4. große Netzwerk-Upgrade von Zcash. [Mehr Infos](https://z.cash/upgrade/heartwood/) |

## I

| Begriff | Definition |
|------|-----------|
| Index | Der ZCX-Index von CoinDesk repräsentiert einen Echtzeit-Spotkurs für Zcash in USD-Äquivalent. [Preisindex](https://www.coindesk.com/indices/zcx/) |
| Integrationen | Du kannst Zcash-Zahlungen über eine Reihe von Drittanbietern akzeptieren. [Zahlungsabwickler](https://z.cash/zcash-for-business/) |
| Interaktives Beweissystem | Eine abstrakte Maschine, die Berechnung als Austausch von Nachrichten zwischen zwei Parteien modelliert: einem Prover und einem Verifier. |
| Investment | Für institutionelle Investoren oder Family Offices, die sich bei Zcash engagieren möchten, stehen verschiedene Finanzoptionen zur Verfügung. [Vollständige Liste](https://z.cash/investors/) |

## J

| Begriff | Definition |
|------|-----------|
| JubJub | Eine elliptische Kurve, die für eine effiziente Implementierung in zk-SNARK-Circuits entwickelt wurde. |

## K

| Begriff | Definition |
|------|-----------|
| Keystone Wallet | Eine Air-Gapped-Hardware-Wallet mit nativer Zcash-Unterstützung (Orchard shielded), kompatibel mit ZODL für Cold Signing. [Keystone](https://keyst.one) |

## L

| Begriff | Definition |
|------|-----------|
| Layer-1 | Bezieht sich auf ein Basisnetzwerk und seine zugrunde liegende Infrastruktur. Layer-1-blockchains können Transaktionen validieren und finalisieren, ohne dass ein anderes Netzwerk benötigt wird. Zcash ist eine L1-blockchain. |
| librustzcash | Ein Rust-Workspace, der alle Crates und Abhängigkeiten für die Arbeit mit Zcash enthält. [repo](https://github.com/zcash/librustzcash) |
| Lightwalletd | Ein zustandsloser Server, der Light Clients mit blockchain-Informationen versorgt. [Lightwalletd](https://zcash.readthedocs.io/en/latest/rtd_pages/lightclient_support.html) |

## M

| Begriff | Definition |
|------|-----------|
| Metriken | Netzwerk-Metriken sind [hier](https://tokenterminal.com/explorer/projects/zcash/metrics/all) verfügbar |
| Metadaten | Daten, die zusammen mit einer Zcash-Transaktion eines Nutzers erzeugt werden. Dazu können Blockhöhe, Transaktionsversion oder Expiry Height usw. gehören. |
| Mobile SDK | Ein leichtgewichtiges SDK, das Android mit Zcash verbindet und es Android-Apps von Drittanbietern ermöglicht, shielded Transaktionen zu senden und zu empfangen. [Github](https://github.com/zcash/zcash-android-wallet-sdk) |
| Mining | Der Prozess, bei dem für jeden Block Knoten im Zcash-Netzwerk durch komplexe mathematische Berechnungen auf Basis einer selbstanpassenden Schwierigkeit um eine Lösung konkurrieren. [Leitfaden](https://z.cash/mining-zcash/) |
| Multisignatur | Eine Adresse, für deren Ausgabe mehrere Signaturen privater Schlüssel erforderlich sind. Derzeit wird Multisig-Funktionalität nur von transparenten Adressen unterstützt. |

## N

| Begriff | Definition |
|------|-----------|
| Nighthawk | Eine Mobile-Wallet für Zcash. [Website](https://nighthawkwallet.com) |
| NU5 | Das 6. große Netzwerk-Upgrade für Zcash, das den Orchard shielded Pool und Unified Addresses einführt. [Mehr Infos](https://zcash.readthedocs.io/en/latest/rtd_pages/nu_dev_guide.html#nu5) |
| NU6 | Das 7. große Netzwerk-Upgrade für Zcash, das die Blocksubvention anpasst, um das Programm Zcash Community Grants und Shielded Labs zu finanzieren. Aktiviert Ende 2024. [Mehr Infos](https://zcash.readthedocs.io/en/latest/rtd_pages/nu_dev_guide.html#nu6) |
| NU7 | Das kommende 8. große Netzwerk-Upgrade für Zcash. Eine Abfrage der Community-Stimmung ist 2026 über ZODL geöffnet. Erwartet werden weitere Verbesserungen des shielded Pools und Governance-Updates. [Forum-Diskussion](https://forum.zcashcommunity.com/t/nu7-sentiment-polling-questions-for-community-review-coinholder-voting-via-zodl/55713) |

| Overwinter | Das 1. Netzwerk-Upgrade für Zcash. [Mehr Infos](https://zcash.readthedocs.io/en/latest/rtd_pages/nu_dev_guide.html#overwinter) |

## Q

| Begriff | Definition |
|------|-----------|
| QR-Code | Ein maschinenlesbarer Code, der zur Kodierung von Zcash-Adressen für einfaches Scannen verwendet wird. Unified Addresses (UAs) werden in modernen Zcash-Wallets typischerweise über QR-Codes geteilt. |

## R

| Begriff | Definition |
|------|-----------|
| Wiederherstellungsphrase | Eine Folge aus 12 oder 24 Buchstaben und Zahlen, die zum Sichern und Wiederherstellen einer Wallet verwendet wird. In Zcash erzeugt diese Phrase Spending Keys und Viewing Keys erneut und ist daher entscheidend für die Wiederherstellung von Geldern und die Sicherheit. |

## S

| Begriff | Definition |
|------|-----------|
| Sapling | Ein großes Netzwerk-Upgrade, das erhebliche Effizienzverbesserungen für shielded Transaktionen einführte und den Weg für die mobile Nutzung ebnete. Aktiviert bei Block 419200. |
| Selektive Offenlegung | Ermöglicht dem Besitzer einer shielded Adresse, Viewing Keys oder Zahlungsnachweise selektiv mit Dritten zu teilen, während die Daten für alle anderen privat bleiben. |
| Shielded Address | Auch zaddr genannt. Beginnt mit z. Verbirgt Sender, Empfänger, Betrag und Memo mithilfe von zk-SNARKs. |
| Shielded Transaction | Eine Transaktion ausschließlich zwischen shielded Adressen. Vollständig privat auf der blockchain. |
| Sol/s | Lösungen pro Sekunde – misst die Equihash-Mining-Leistung. |
| Spending Key | Der private Schlüssel, der das Ausgeben von einer shielded Adresse ermöglicht (erlaubt auch die Einsicht in Guthaben und Verlauf). |
| Sprout | Die ursprüngliche shielded Protokollversion von Zcash (Start 2016). |

## T

| Begriff | Definition |
|------|-----------|
| TAZ | Testnet Zcash (wertlose Testwährung). |
| Testnet | Eine separate blockchain zum Testen von Upgrades und Funktionen vor dem Mainnet. |
| Transaktion | Eine Zahlung zwischen Nutzern, die an das Netzwerk übermittelt und schließlich in einem Block bestätigt wird. |
| Ablauf von Transaktionen | Transaktionen laufen nach ungefähr 25 Minuten (20 Blöcken) ab, wenn sie unbestätigt bleiben; die Gelder kehren automatisch zurück. |
| Transaktionsgebühr | Die Standardgebühr beträgt 0.0001 ZEC. Höhere Gebühren werden bevorzugt; sehr niedrige Gebühren können zu Verzögerungen oder zum Ablauf führen. |
| Transparente Adresse | Auch taddr genannt. Beginnt mit t. Vollständig öffentlich (wie Bitcoin). |
| Transparente Transaktion | Eine Transaktion ausschließlich zwischen transparenten Adressen – alles ist öffentlich sichtbar. |

## U

| Begriff | Definition |
|------|-----------|
| Unified Address | Modernes Adressformat (eingeführt in NU5), das sowohl für transparente als auch für shielded Zahlungen in einer einzigen Zeichenfolge funktioniert. |
| Upgrade-Aktivierung | Die spezifische Blockhöhe, bei der ein Netzwerk-Upgrade (z. B. NU5, NU6) automatisch aktiviert wird. |

## V

| Begriff | Definition |
|------|-----------|
| Viewing Key | Ein privater Schlüssel, mit dem du das Guthaben und den Transaktionsverlauf einer shielded Adresse einsehen kannst, ohne die Gelder ausgeben zu können. |

## W

| Begriff | Definition |
|------|-----------|
| Wallet | Software oder Hardware, die private Schlüssel speichert und es dir ermöglicht, ZEC zu senden/empfangen. Zu den aktiven Wallets gehören ZODL (iOS/Android), Zingo! (Mobil/Desktop), Nighthawk (Android), YWallet, Zallet (kommend) und Keystone (Hardware). Eine vollständige Liste findest du unter [Zcash-Ökosystem-Wallets](https://z.cash/ecosystem/?wallets=#tag-wallets) |

## X

| Begriff | Definition |
|------|-----------|
| XZC | Ein älteres Ticker-Symbol für Zcash, das auf einigen Legacy-Börsen verwendet wurde. Der offizielle Ticker ist ZEC. |

## Y

| Begriff | Definition |
|------|-----------|
| YWallet | Eine leistungsstarke, auf Privatsphäre ausgerichtete Zcash-Wallet mit Unterstützung für Orchard, Sapling und transparente Adressen. Bekannt für schnelle Synchronisationsgeschwindigkeiten. Verfügbar für iOS und Android. [YWallet](https://ywallet.app) |

## Z

| Begriff | Definition |
|------|-----------|
| Zcash | Auf Privatsphäre fokussierte Kryptowährung mit zk-SNARKs. Verbindet transparente Zahlungen (im Bitcoin-Stil) und vollständig shielded Zahlungen. |
| Zcash Foundation | Unabhängige gemeinnützige Organisation, die das Zcash-Ökosystem unterstützt, Entwicklung finanziert und Privatsphäre fördert. |
| Zcash Network | Peer-to-Peer-Netzwerk aus Knoten, das Transaktionen validiert und die blockchain pflegt. |
| ZEC | Der offizielle Währungscode für Zcash (einige Börsen zeigen noch XZC an). |
| Zerocash | Das akademische Protokoll (2014), auf dem Zcash basiert. |
| Zaino | Der Indexer der nächsten Generation für Zcash, der lightwalletd ersetzt und von der Zcash Foundation entwickelt wird. Ermöglicht Light Clients eine schnellere und privatere Synchronisierung. Teil des Infrastruktur-Upgrades Zcash Z3. |
| Zallet | Die kommende offizielle Zcash-Wallet des Teams von Electric Coin Co / ZODL, basierend auf Zaino. Zallet Alpha befindet sich Stand 2026 in aktiver Entwicklung. [Forum](https://forum.zcashcommunity.com/t/zcash-z3-updates-formerly-zcashd-deprecation/48965) |
| Zebra | Die Rust-basierte Full-Knoten-Implementierung der Zcash Foundation (Alternative zu zcashd). Produktionsreif und aktiv gepflegt. [GitHub](https://github.com/ZcashFoundation/zebra) |
| ZIP | Zcash Improvement Proposal – der Community-Governance-Prozess, mit dem Protokolländerungen vorgeschlagen und ratifiziert werden. [ZIP-Repository](https://github.com/zcash/zips) |
| ZODL | Der neue Markenname für die Verbraucherprodukte der Electric Coin Company, einschließlich der ZODL-Wallet-App (früher ECC Wallet genannt) und der ZODL-Governance-Plattform für Coinholder-Abstimmungen. [zodl.com](https://zodl.com) |
| zk-SNARKs | Zero-Knowledge Succinct Non-Interactive Arguments of Knowledge — die Kryptografie hinter den shielded Transaktionen von Zcash. Ermöglicht es, eine Aussage (z. B. eine gültige Ausgabe) zu beweisen, ohne geheime Informationen offenzulegen. |
