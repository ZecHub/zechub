## En resumen

- Acepta pagos usando una dirección blindada [shielded]
- Evita exponer los datos de transacciones de los clientes
- Usa memos o sistemas off-chain para el seguimiento de pedidos
- Mantén privados los ingresos de la empresa

## <img src="/content-images/warning-error-svgrepo-com-b7ea8a50da.svg" width="24" height="24" className="inline-block align-middle mr-1 p-[2px]" alt="warning icon"/> El problema

Los pagos tradicionales con criptomonedas exponen:
- El comportamiento de compra de los clientes
- Los ingresos del comerciante
- El historial de transacciones

Esto conduce a:
- Pérdida de privacidad de los clientes
- Filtraciones de inteligencia competitiva
- Transparencia financiera que quizá no deseas

<br/>

## <img src="/content-images/icons8-lock-2f8e221321.svg" width="24" height="24" className="inline-block align-middle mr-1 p-[2px]" alt="toolbox icon"/> ¿Por qué Zcash?

Zcash permite:
- Pagos privados de clientes
- Seguimiento confidencial de ingresos
- Protección de la actividad empresarial


<br/>

## <img src="/content-images/icons8-toolbox-9bebbb1619.svg" width="24" height="24" className="inline-block align-middle mr-1 p-[2px]" alt="toolbox icon"/> Lo que necesitas

- Una billetera [wallet] Zcash compatible con transacciones blindadas
- Un flujo de pago sencillo (manual o integrado)
- Opcional: sistema de seguimiento de pedidos


<br/>

## <img src="/content-images/ladder-svgrepo-com-7232bf46ed.svg" width="24" height="24" className="inline-block align-middle mr-1 p-[2px]" alt="step icon"/> Guía paso a paso

### Paso 1: Configura una dirección de pago

- Genera una dirección blindada (z)
- Úsala para recibir pagos


### Paso 2: Muestra las instrucciones de pago

Para cada transacción:
- Muestra tu dirección z
- Indica el importe del pago
- Incluye opcionalmente una referencia en el memo

### Paso 3: Realiza el seguimiento de los pedidos

Usa:
- Memos (p. ej., ID de pedido)
- O seguimiento off-chain (base de datos, hoja de cálculo)


Ejemplo:
- Pedido n.º 4821


### Paso 4: Confirma el pago

- Supervisa las transacciones blindadas entrantes
- Vincula el memo o el importe con el pedido


### Paso 5: Mantén buenas prácticas de privacidad

- Evita reutilizar direcciones públicamente si es posible
- No expongas el historial de transacciones
- Separa las billeteras para distintas unidades de negocio si es necesario


<br/>

## <img src="/content-images/icons8-cancel-7f786be3c1.svg" width="24" height="24" className="inline-block align-middle mr-1 p-[2px]" alt="cancel icon"/> Errores comunes que debes evitar

- Usar direcciones transparentes [transparent] para pagos  
- Publicar pruebas [proofs] de transacciones públicamente  
- Vincular la identidad del cliente con datos de la blockchain  
- No realizar un seguimiento adecuado de los pagos
