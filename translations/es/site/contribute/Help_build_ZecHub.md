# Ayuda a construir ZecHub 

Si eres miembro de la comunidad de Zcash y quieres contribuir a construir ZecHub, hay algunas cosas que son de gran ayuda.

Selecciona enlaces para el boletín y agrégalos a la página de GitHub del boletín: -> [Haz clic aquí para ver las instrucciones](https://github.com/ZecHub/zechub/blob/main/site/contribute/ZecWeekly_Newsletter.md)

Verifica los datos de los documentos de la wiki, sugiere ediciones y propone nuevas páginas en GitHub

Crea contenido de video en las siguientes categorías:
```
* Zcash explainer videos
* Zcash wallet guide/tutorials
* Third-party application demos
```

Produce diseños como carteles/gráficos/animaciones para el ecosistema de Zcash y la privacidad 

Traduce cualquiera de las páginas existentes de la wiki.

Reporta errores

#### Para obtener detalles sobre los montos de las recompensas, lee nuestra página de contribuciones -> [aquí](https://zechub.wiki/contribute/contributing-guide#content).

Publicamos incidencias para las tareas que actualmente tienen recompensas abiertas todos los lunes. ¡También puedes sugerir recompensas! Principalmente se encuentran en ZEC Bounties.

![zecbounties](/content-images/0e4f5109-c0c9-4a0a-8d71-8172e36b9726-1a94469edf.webp)



[ZEC Bounties](https://bounties.zechub.wiki/)

[ZecHub Incidencias de GitHub](https://github.com/ZecHub/zechub/issues)

[ZecHub-Incidencias de GitHub de la wiki](https://github.com/ZecHub/zechub-wiki/issues)



Si hay otras formas en las que te gustaría contribuir, envía un mensaje a ZecHub ([@ZecHub](https://twitter.com/zechub)) en Twitter o únete a nuestro [Discord](https://discord.gg/zcash).
