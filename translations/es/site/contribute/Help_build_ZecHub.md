# Ayuda a construir ZecHub 

Si eres miembro de la comunidad de Zcash y quieres contribuir a construir ZecHub, hay algunas cosas que resultan muy útiles.

Selecciona enlaces para el boletín [newsletter] y añádelos a la página GitHub del boletín: -> [Haz clic aquí para ver las instrucciones](https://github.com/ZecHub/zechub/blob/main/site/contribute/ZecWeekly_Newsletter.md)

Verifica los datos de los documentos de la wiki, sugiere ediciones y propone nuevas páginas en GitHub

Crea contenido de vídeo en las siguientes categorías:
```
* Zcash explainer videos
* Zcash wallet guide/tutorials
* Third-party application demos
```

Produce diseños como carteles/gráficos/animaciones para Zcash y el ecosistema de privacidad [privacy] 

Traduce cualquiera de las páginas existentes de la wiki.

Reportar errores

### Recompensas

Las cantidades no son fijas en ZEC. Utiliza la [política de cantidades de recompensas](https://bounties.zechub.wiki/docs/bounty-amounts): elige un intervalo en USD para la clase de trabajo, conviértelo al precio al contado e introduce ZEC en el tablero. Esa política es la fuente de referencia.

Flujo de trabajo de los colaboradores y tipos de trabajo: [Contribuir a ZecHub](https://zechub.wiki/contribute/contributing-guide).
