# <img src="/content-images/image-2024-02-03-173258092-a5440e5ee2.webp" alt="Alt Text" width="50"/>   Exchanges con custodia

Ironwood es el pool blindado que llegó con la actualización de red de julio de 2026. Los exchanges que solo manejan direcciones t transparentes nunca lo utilizan, por lo que se marcan como no aplicable. Cuando un exchange sí maneja direcciones blindadas pero no ha indicado qué pool utiliza, la línea lo señala en lugar de especular.
