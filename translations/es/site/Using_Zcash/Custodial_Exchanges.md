# <img src="/content-images/image-2024-02-03-173258092-a5440e5ee2.webp" alt="Alt Text" width="50"/>   Exchanges custodios [Custodial Exchanges]

Ironwood es el pool blindado [shielded pool] que llegó con la actualización de red [network upgrade] de julio de 2026. Los exchanges que solo manejan direcciones t transparentes [transparent t-addresses] nunca interactúan con él, por lo que se marcan como no aplicable. Cuando un exchange sí maneja direcciones blindadas pero no ha indicado qué pool utiliza, la línea lo indica en lugar de hacer suposiciones.
