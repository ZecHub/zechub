# Navegadores web [Web Browsers]

1. **Brave:** Uno de los navegadores más destacados y seguros del mercado actual. Bloquea anuncios y rastreadores invasivos para la privacidad. Bloquea el almacenamiento de datos por terceros. 

2. **Mulvad:** Un navegador web centrado en la privacidad desarrollado en colaboración entre Mullvad VPN y el Proyecto Tor. Se ha creado para minimizar el rastreo y la toma de huellas digitales.

3. **Tor:** Este navegador bloquea plugins como Flash, RealPlayer, QuickTime y otros: pueden manipularse para revelar tu dirección IP. No recomendamos instalar complementos o plugins adicionales en el navegador Tor.


## ¿Cuáles son las consideraciones de seguridad al seleccionar un navegador web?

Al seleccionar un navegador web, hay algunas cosas que debes tener en cuenta: Las vulnerabilidades y los exploits de seguridad suelen descubrirse con regularidad. Algunos navegadores son rastreables de alguna manera, pero hay navegadores que permiten a los usuarios navegar de forma anónima; el navegador [Tor](https://download.torproject.org/), por ejemplo. 

**Toma de huellas digitales [Fingerprinting]**: Si quieres mantener privados aspectos como los programas instalados en tu equipo, la configuración de hardware y más, considera buscar un navegador web que admita la función de resistencia a la toma de huellas digitales. 

**Prueba HTTPS [HTTPS Test]**: Otra consideración de seguridad que debes tener en cuenta al seleccionar un navegador web es el protocolo de prueba HTTPS, que ayuda a cifrar la conexión al sitio web y oculta las cookies, las URL y otros tipos de metadatos confidenciales. Con HTTPS, la conexión está cifrada y ningún tercero en la red puede leer el contenido transferido entre el servidor y tu navegador. 

**Protección contra cookies de rastreo [Tracking Cookie Protection]**: Además, una gran parte de las páginas web de la World Wide Web tiene rastreadores ocultos de terceros; estos rastreadores leen y escriben cookies en tu navegador. Estas cookies pueden representar amenazas maliciosas porque pueden utilizarse para rastrear tu navegación entre sitios web; para evitar este rastreo, selecciona un navegador web que bloquee las cookies de navegación desconocidas.

**Prueba de navegación [Navigation Test]**: A medida que navegas de una página web a otra, encontrarás muchos enlaces (algunos son enlaces internos, mientras que otros enlazan a otro sitio web). Al hacer clic en estos enlaces, determinadas API del navegador permiten que el primer sitio se comunique con el segundo. Para resolverlo, selecciona un navegador web que impida que los sitios web compartan datos de rastreo cuando hagas clic en un enlace. Al seleccionar el navegador que creas que podría ajustarse a tus necesidades, asegúrate de que proporcione funciones sólidas de privacidad y funciones esenciales, como bloqueadores de anuncios integrados y demás. Además, muchos de estos navegadores web admiten extensiones y complementos, y a veces estas extensiones pueden plantear riesgos de seguridad; asegúrate de instalar siempre estas extensiones desde un ecosistema seguro o fuentes de confianza.
 
## Integración de la billetera [Wallet] del navegador Brave Zcash

El navegador Brave está allanando el camino para el ecosistema web3. ¿Cómo? Ahora se pueden aprovechar más de 2 millones de dominios imparables para mostrar sitios web descentralizados. Con las sólidas funciones de seguridad de los navegadores Brave, las personas pueden explorar Internet sin ser rastreadas. Brave y Zcash están uniendo fuerzas para incorporar nuevas herramientas de privacidad al ecosistema Web3. Para obtener mayores beneficios, Brave se integraría rápidamente con el protocolo Zcash mediante la billetera de criptomonedas integrada de Brave para revolucionar las transacciones de criptomonedas. Esta integración permitiría a los usuarios almacenar, enviar y recibir ZEC de forma muy sencilla, además de otras criptomonedas. La colaboración entre el navegador web Brave y Zcash realmente cambiaría las reglas del juego, ya que los usuarios tendrían un mayor control sobre su actividad en Web3. 

Otro hecho intrigante sobre la integración del navegador Brave y Zcash es la función de mensajería privada y descentralizada; Brave, ECC y el equipo de la Fundación Filecoin están allanando el camino para una función basada en la privacidad en el navegador Brave. Esta colaboración tiene como objetivo ofrecer mensajes privados y transmisión de medios mediante el protocolo Zcash. Aquí, el Sistema de Archivos Interplanetario (IPFS) desempeñará un papel esencial al ofrecer capacidad de almacenamiento seguro para el contenido cifrado.
