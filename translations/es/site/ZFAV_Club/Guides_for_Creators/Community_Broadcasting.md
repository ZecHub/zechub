# Transmisión comunitaria [Community Broadcasting] con VDO.Ninja y OBS Studio

Este breve tutorial fue creado durante el [DWeb Camp 2023](https://dwebcamp.org/) por un grupo de becarios y voluntarios. El objetivo de este ejercicio es aprovechar el uso de dispositivos de teléfonos inteligentes conectados a una red MESH sin conexión para la grabación y transmisión de vídeo colaborativas.

Utilizamos dos programas de código abierto [open source] [OBS Studio (Open Broadcaster software)](https://obsproject.com/) y [VDO.Ninja](https://vdo.ninja/). Estos programas pueden descargarse y ejecutarse localmente en tu ordenador.

## OBS Studio (software Open Boardcaster)

OBS Studio es un programa libre y de código abierto para la grabación y transmisión en directo que está disponible para múltiples sistemas operativos. El programa se lanzó por primera vez en 2012 y cuenta con bastantes seguidores entre la comunidad de transmisión de videojuegos y los creadores independientes de contenido de vídeo.

Las interfaces de usuario de OBS Studio pueden parecer bastante intimidantes para quienes lo usan por primera vez. OBS Studio se divide en dos ventanas: «Vista previa» y «Transmisión». La ventana de vista previa muestra los vídeos disponibles (varias cámaras, como webcam, Iriun Webcam, OBS Virtual Camera, fuente de vídeo y de navegador) llamados «Escenas», y «Transmisión» muestra la emisión en directo.

Para transmitir a OBS Studio la señal de una cámara remota desde VDO.ninja, empieza añadiendo una nueva «Fuente de navegador» mediante «Fuentes > Añadir > Navegador». En la nueva ventana, puedes proporcionar la URL de la fuente de VDO.Ninja y seleccionar «Hacer visible la fuente».

Ahora puedes empezar a transmitir las señales remotas.

## VDO.Ninja

[VDO.Ninja](https://vdo.ninja/) es una aplicación web libre y de código abierto que te permite convertir tus dispositivos móviles en una cámara para transmisión en directo. El programa puede descargarse e implementarse en tu ordenador local o puedes utilizar directamente la [versión en línea en https://vdo.ninja](https://vdo.ninja/).

La interfaz de VOD.Ninja es sencilla: solo abre VDO.Ninja en el navegador web de tus dispositivos móviles y selecciona «Añade tu cámara a OBS». A continuación, selecciona tu cámara y dispositivo de audio de la lista de dispositivos y haz clic en «Iniciar». Luego recibirás un enlace de «visualización» que puedes añadir a OBS Studio.

## Preguntas frecuentes [FAQ]

- ¿Qué tipos de tarjetas gráficas de vídeo se requieren para OBS Studio?

Puedes utilizar un ordenador personal con una buena tarjeta gráfica y mucha memoria o, como alternativa, puedes usar codificadores de hardware [Teradek VidiU](https://www.bhphotovideo.com/c/product/1609186-REG/teradek_10_0235_vidiu_x_modem.html?gclid=EAIaIQobChMIl4aIo7zX_wIVDhqtBh0PgwhxEAAYAiAAEgInufD_BwE)
- ¿OBS te permite realizar traducción y subtitulado en directo?

Hay algunos complementos aportados por la comunidad que parecen proporcionar dicha función. [https://github.com/eddieoz/OBS-live-translation](https://github.com/eddieoz/OBS-live-translation)

- ¿Podrías desarrollar tus propios complementos para OBS Studio?

Sí, OBS admite scripts de lua y python. También JavaScript para superposiciones y vistas web.

- ¿Usamos fundido a negro en directo o transiciones?

¡Eso depende de ti, el productor!

- ¿Hay latencia cuando transmites?

Esto depende principalmente del destino al que estés transmitiendo. Por ejemplo, YouTube podría tener un retraso de un minuto o más debido al procesamiento de vídeo que se realiza en sus servidores antes de la emisión.

- El audio se interrumpe al usar OBS en una máquina lenta y durante el uso de pantalla verde

Utiliza un codificador de hardware o usa stream yard
[https://support.streamyard.com/hc/en-us/articles/360056350852-How-to-Use-OBS-Virtual-Camera-with-StreamYard](https://support.streamyard.com/hc/en-us/articles/360056350852-How-to-Use-OBS-Virtual-Camera-with-StreamYard) o [RiverSide.FM](http://riverside.fm/)
