# Compartición de archivos P2P con IPFS y el navegador Brave

Podemos usar IPFS para compartir archivos multimedia grandes entre nosotros de forma entre pares [Peer-to-Peer].

Entonces, ¿cuál es el problema?: Las pasarelas de IPFS no funcionan con archivos grandes; agotarán el tiempo de espera.

**Requisitos**: [IPFS Desktop](https://docs.ipfs.tech/install/ipfs-desktop/) + [Brave Navegador](https://brave.com/)

En resumen, el video está al final.

Podemos usar esto entre nosotros en el ZF AV Club para transferir archivos multimedia grandes y documentarlo para todos ustedes porque es divertido y genial.

*ADEMÁS*, colaboraremos directamente con el equipo de IPFS en Protocol Labs para desarrollar este caso de uso [use case].
¡Otro beneficio que surgió de las conexiones establecidas en dWeb Camp!

Sin IPFS instalado en la máquina receptora Y usando un navegador que no sea Brave: Tendrán que esperar a que la pasarela cargue el archivo. *Esto devolverá un error 504 con archivos grandes.*

A continuación: Cómo fijar los archivos de otras personas en su máquina para que no tengamos el problema de un único punto de fallo cuando el nodo original se desconecte.
