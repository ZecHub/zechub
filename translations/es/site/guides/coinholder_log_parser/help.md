# Filtro de registro electoral

`./filterForElection.sh <logname> <election #>`    

muestra los sighashs y las alturas de ballet para las entradas que involucran el número de elección indicado

`./numberOfBallets.sh <logname> <election #>`      

muestra el conteo de la última entrada (la más actual) para la altura de ballet dado un número de elección
