# Zingo 2.0 - Pepper Sync

## TL;DR

* Pepper Sync 是在 Zingo! 2.0 中推出的同步引擎 [synchronization engine]，后者是由 Zingo Labs 构建的开源 Zcash 钱包 [wallet]。
* 它采用非线性同步，而非按大型连续区块扫描链 [chain]，因此您的余额和交易 [transaction] 会更早显示。
* 进度会持续保存。如果连接中断或应用关闭，同步会从停止处恢复，而不是重新开始。
* 您可以在同步完成前进行消费。
* 屏蔽 [shielded] 交易在整个过程中始终保持私密。

## 核心说明

Zingo 2.0 是 Zingo! 钱包的最新版本，这是一款为 Zcash 社区打造的轻量级开源钱包。本次发布的亮点是 Pepper Sync，这是一项重大升级，彻底重新思考了钱包与 blockchain 的连接方式。

过去，同步可能感觉极其缓慢、容易出错且消耗大量资源，有时会迫使用户从头开始。Pepper Sync 改变了这一切。它让同步更快速、更顺畅、更可靠，并且对您的设备要求更低，同时完全保留屏蔽交易的隐私 [privacy]。

无论您是首次尝试 Zcash 的全新用户，还是管理多个屏蔽钱包的长期社区成员，Pepper Sync 都让体验更加实用和愉快。

### Pepper Sync 的核心功能

Pepper Sync 引入了多项改进：

- 更快的同步 - 您的钱包可在几分钟内准备就绪，而非数小时。
- 智能更新 - 数据以更小的区块处理，避免完整重新扫描。
- 抗中断能力 - 如果连接中断，同步会从上次停止的位置恢复。
- 轻量且高效 - 针对手机、笔记本电脑及其他低性能设备进行了优化。
- 更清晰的反馈 - 实时进度更新可减少困惑。
- 保护隐私 - 屏蔽交易在整个过程中始终保持私密。

### 相较以往的改进

旧版本的 Zingo 经常因漫长的同步时间、不清晰的错误处理和高资源占用而令用户感到沮丧。Pepper Sync 解决了这些常见问题：

| 功能               | 旧版 Zingo                         | 搭载 Pepper Sync 的 Zingo 2.0              |
| ------------------ | -------------------------------------- | -------------------------------------------- |
| 同步速度           | 较慢，尤其是在首次设置时               | 初始同步和后续同步都快得多                   |
| 错误处理           | 偶尔停滞且故障原因不明确               | 稳定性提升，并具备自动恢复功能               |
| 用户体验           | 对新用户而言同步感觉“不透明”           | 更透明，状态和更新更清晰                     |
| 设备性能           | CPU/内存使用率高                       | 针对流畅的资源使用进行了优化                 |

简而言之：同步现在更快、更可靠，也更易于理解。

## 视觉化 / 类比

可以把旧式钱包同步想象成：在您获准对此发表任何看法之前，必须从第一页开始大声读完一本很长的书。若中途停下，您就得从第一页重新开始。Pepper Sync 读的是同一本书，但它会保留书签，先阅读与您相关的章节，并允许您在读完最后一页之前谈论这个故事。

书签是关键。每个旧版本都将中断的同步视为白费的工作；Pepper Sync 则将其视为暂停。

## 深入了解

### Pepper Sync 的工作方式（简要视图）

Pepper Sync 不会以庞大、笨重的区块重新扫描 blockchain，而是以小而易于管理的步骤运行，并始终在过程中保存您的位置。

1. 连接 - 钱包与网络建立连接。
2. 获取区块 - 数据会逐步下载。
3. 验证 - 交易会得到验证。
4. 处理屏蔽 note [note] - 始终保护隐私。
5. 更新余额 - 钱包会安全地刷新。
6. 保存进度 - 无缝停止和恢复。
7. 完成 - 钱包已准备好进行交易。

## 实际影响

### 谁能从 Pepper Sync 中受益？

- 新用户 - 可以快速设置钱包，不会因延迟而气馁。
- 日常用户 - 可靠的同步让屏蔽支付 [payment] 可用于日常使用。
- 开发者 [developer] 与测试人员 - 更短的同步时间意味着更快的测试周期。
- 移动设备与轻量设备 - Zingo 现在即使在资源受限的硬件上也能高效运行。

### 为什么这对 Zcash 很重要

Zcash 围绕屏蔽交易构建，这是加密货币中最强大的隐私工具之一。但只有易于获取时，隐私才有用。

Pepper Sync 的帮助方式包括：

- 降低入门门槛 - 新用户可以快速开始。
- 支持日常可用性 - 屏蔽地址 [address] 更容易获得信任。
- 推动生态系统发展 - 更好的钱包体验会带来更多采用、应用和服务。

通过改善钱包体验，Pepper Sync 强化了整个 Zcash 生态系统。

## 常见错误

**将 Pepper Sync 视为独立的钱包**。Pepper Sync 是 Zingo! 钱包内部的同步引擎，而不是独立应用。您安装的是 Zingo；Pepper Sync 是在其底层运行的组件。

**认为更快的同步意味着更弱的隐私**。速度来自区块数据的获取、排序和缓存方式，而非暴露更多信息。屏蔽交易始终保持私密。

**认为必须完全同步后才能消费**。在同步完成前进行消费是 Pepper Sync 的核心功能之一，因此您无需等待钱包到达链的尖端。

## FAQ - 常见问题

**问：每次打开钱包时都必须重新扫描吗？**

答：不必。Pepper Sync 会保存进度，因此您只需从上次的位置更新。

**问：如果我的互联网连接断开，会发生什么？**

答：同步会暂停，之后会继续，无需重新开始。

**问：同步期间我的隐私安全吗？**

答：是的。屏蔽交易会保持完全私密。

**问：首次同步需要多长时间？**

答：通常是几分钟而不是几小时，具体取决于您的设备和互联网连接。

**问：同步完成前可以使用钱包吗？**

答：可以。Pepper Sync 支持在同步完成前消费，因此您无需等待钱包到达链的尖端。

## 结论

借助 Zingo 2.0 Pepper Sync，同步不再是屏蔽钱包最大的痛点。它现在快速、稳定且易于使用，降低了新用户的门槛，也让日常使用更加实用。

对用户而言，这意味着更少等待和更多隐私。对开发者而言，这意味着更坚实的构建基础。对 Zcash 生态系统而言，这是让屏蔽交易人人可用的又一步。

搭载 Pepper Sync 的 Zingo 2.0 不仅是一次升级；它更是迈向私密、实用加密货币的一大步。
