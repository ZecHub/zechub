# Zcash 的后量子安全性

## TL;DR

- 量子计算机是一种未来风险，因为它们可能破解当今 blockchain 所使用的一些公钥密码学。
- "后量子"是指在普通计算机上运行、但旨在抵御未来量子计算机攻击的密码学。
- Zcash 如今尚未完全具备后量子能力。
- 屏蔽 [shielded] Zcash 减少了未来攻击者能够研究的公开交易数据量，但使用屏蔽功能并不等同于完全抵抗量子攻击。
- Zcash 正通过研究、ZIP 以及诸如 ZIP 2005 和 Project Tachyon 等升级提案进行准备。
- 安全的后量子迁移必须同时保护资金、隐私、钱包、交易所和共识规则。

如需了解 Ironwood 已经改变了什么，以及各部分按日期更新的状态，请参阅 [Zcash 是否具备后量子能力？](/zcash-tech/is-zcash-post-quantum)。

## 什么是量子计算？

普通计算机将信息存储为比特。每个比特不是 `0`，就是 `1`。

量子计算机使用称为量子比特的 quantum bits。量子比特可以被特殊算法用于比普通计算机快得多地解决某些数学问题。

这并不意味着量子计算机在所有事情上都更快。风险是特定的。一些密码学依赖于对普通计算机极其困难、但对足够强大的量子计算机容易得多的数学问题。

对于 blockchain，最重要的例子是公钥密码学。公钥和签名 [signature] 用于证明用户被允许花费币。

## 为什么 Blockchain 重视此事

Blockchain 使用密码学完成几项不同的工作：

| 密码学工具 | 它的作用 | 量子影响 |
| --- | --- | --- |
| 数字签名 | 证明所有者授权了花费 | 常见椭圆曲线系统面临高风险 |
| 哈希函数 | 构建地址、commitment、Merkle 树和挑战 | 风险较低，但安全余量很重要 |
| 零知识证明 | 在不泄露细节的情况下证明屏蔽交易有效 | 取决于证明系统和假设 |
| 密钥协商 | 帮助钱包为接收者加密 note 数据 | 在量子威胁模型下需要仔细审查 |

足够强大的量子计算机可能威胁当今使用的许多签名方案，包括椭圆曲线签名。这很重要，因为签名让网络知道一笔交易已由正确的密钥授权。

哈希函数不同。Grover 算法可以加速暴力搜索，但不会以同样直接的方式破解哈希函数。更大的安全余量会有所帮助。

## 什么是后量子密码学？

后量子密码学是旨在同时抵御普通计算机和未来量子计算机的密码学。

这并不意味着该密码学使用量子计算机。它意味着系统基于不同的困难数学问题。

2024 年，NIST 发布了首批最终确定的后量子标准：

- 用于密钥建立的 **ML-KEM**
- 用于数字签名的 **ML-DSA**
- 用于基于哈希的数字签名的 **SLH-DSA**

这些标准是一个重要里程碑，但 blockchain 不能在一夜之间简单地将一种算法替换为另一种。必须考虑共识规则、钱包、硬件钱包、交易大小、手续费和隐私。

## 量子风险如何在链上出现

理解这种风险的一种简单方式是：

1. 用户创建一个密钥对。
2. 公钥或签名数据可能出现在链上。
3. 未来的量子攻击者可能能够利用这些公开材料获知私钥。
4. 如果资金仍由该密钥控制，它们可能面临风险。

透明 blockchain 从设计上就暴露大量信息。地址、金额和交易关联均为公开信息。花费币时，公钥材料也可能变得可见。

这也是地址重复使用有害的一个原因。重复使用会给观察者更多可在今天关联的数据，也会给未来攻击者更多可分析的历史材料。

## Zcash 有何不同？

Zcash 同时支持透明和屏蔽交易。

透明 Zcash 的运作方式更类似 Bitcoin 风格的公开 blockchain 使用方式。地址、金额和交易关系均可见。

屏蔽 Zcash 则不同。屏蔽交易使用零知识证明，使网络能够验证交易遵循规则，而无需泄露发送者、接收者或金额。

这赋予 Zcash 重要的隐私优势：

- 为所有人发布的交易数据更少。
- 用户在保持屏蔽状态时避免创建公开的支付图谱。
- 未来的观察者拥有更少可供分析的公开财务历史。
- 可以通过 viewing key 实现选择性披露，而不是采用默认公开的记录。

但屏蔽 Zcash 并不会自动具备后量子能力。屏蔽池仍依赖于密码学假设。花费授权、note commitment、nullifier、证明系统、加密和钱包密钥都需要仔细审查。

简而言之：

> 屏蔽使用可减少公开暴露，但 Zcash 仍需要有意识地进行后量子升级。

## Zcash 风险图谱

| 领域 | 面向初学者的解释 | 后量子关注点 |
| --- | --- | --- |
| 透明地址 | 公开地址和公开交易图谱 | 与其他透明 blockchain 类似的风险 |
| 花费授权 | 用户被允许花费的证明 | 签名方案可能需要替换或迁移 |
| 屏蔽 note | 屏蔽池内的私有价值记录 | 某些组件可能需要新的假设或恢复工具 |
| zk-SNARKs | 证明屏蔽交易有效的证明 | 需要审查证明系统假设 |
| 钱包扫描 | 钱包如何找到并解密收到的 note | 密钥协商和 note 加密需要审查 |
| 迁移 | 将资金转移至更安全的密码学 | 必须避免资金损失和隐私泄露 |

## Zcash 如何进行准备

### Zcash 拥有网络升级流程

Zcash 以前曾改变过其密码学。Sapling 使屏蔽交易更容易使用。NU5 引入了 Orchard、Unified Addresses 和 Halo 2。

这很重要，因为后量子准备不是一行软件补丁。它需要协调一致的网络升级、钱包变更、审计，以及留给用户迁移的时间。

过去的 Zcash 升级表明，该生态系统拥有从旧密码学转向新设计的经验。

### Halo 和 Orchard 减少了旧有假设

Halo 2 被 Orchard 使用，后者是 Zcash 的现代屏蔽池。一个重要改进是，Halo 移除了 Orchard 证明系统对可信设置的需求。

这与后量子安全性并不相同。它仍然相关，因为它表明，当有更好的设计可用时，Zcash 可以替换重要的密码学构建模块。

### ZIP 2005 聚焦于量子可恢复性

ZIP 2005 的标题是"Orchard Quantum Recoverability"。它提出了一些变更，旨在帮助 Orchard 用户在针对旧有假设的量子攻击变得可行时恢复或迁移资金。

可恢复性不等同于完整的后量子安全性。它的范围更窄，但仍然有用：

- 完整的后量子安全性旨在阻止量子攻击奏效。
- 可恢复性为诚实用户提供了在旧密码学变得不安全时更好的路径。

对于初学者，可以把它想象成紧急出口方案。它不会替换整栋建筑，但如果旧锁变得脆弱，它能帮助人们安全地离开旧房间。

### Project Tachyon 着眼于更大规模的协议改进

Project Tachyon 是一项拟议的 Zcash 升级，重点关注规模、同步和状态增长。其公开网站称，该提案旨在缩小交易、减少验证者状态增长，并将完整的后量子隐私作为附带效果获得。

由于 Tachyon 是一项提案，它在激活前仍取决于工程工作、审查和社区批准。最好将其理解为 Zcash 正在进行的研究和升级方向的一部分，而不是用户今天已经拥有的功能。

### 研究和标准正在推进

更广泛的密码学世界也在推进。NIST 的后量子标准为实现者提供了更强的签名和密钥建立构建模块。零知识研究人员继续研究能够在量子假设下保持稳健的证明系统。

Zcash 可以受益于这项工作，但仍必须将其适配为保护隐私的 blockchain。

## 未来可能的升级方法

### 后量子花费授权

Zcash 最终可能需要不依赖易受量子攻击签名方案的花费授权。

这可能使用后量子签名、混合签名或其他设计。混合设计会在过渡期间同时使用经典检查和后量子检查，因此系统不会只依赖一种假设。

挑战在于大小和成本。后量子签名可能比当今签名更大，这会影响交易大小、带宽、手续费、移动钱包和硬件钱包。

### 新的地址和密钥格式

新的密码学通常需要新的密钥和地址。用户需要一条从旧格式迁移到更安全格式的清晰路径。

钱包中的迁移应当简单。大多数用户不应为了保持安全而必须理解每一个密码学细节。

### 保护隐私的迁移

迁移对于 Zcash 尤其敏感。如果许多用户以明显模式将资金从旧 pool 转移至新 pool，迁移本身可能泄露信息。

良好的迁移计划需要保护：

- 用户资金
- 用户隐私
- 钱包兼容性
- 交易所支持
- 硬件钱包支持
- 网络共识安全性

### 后量子证明系统审查

仅替换签名还不够。Zcash 的屏蔽设计也依赖于零知识证明和 commitment。

未来的工作可能需要审查或替换：

- zk-SNARK 假设
- 多项式 commitment
- Fiat-Shamir 挑战哈希
- Note commitment
- Nullifier 构造
- Merkle 树假设
- Note 加密和 viewing key 行为

某些组件可能可通过调整参数而接受。其他组件可能需要新的设计。

## 初学者示例

### 示例 1：旧锁

想象一个今天很坚固的保险箱锁。未来发明的新工具可能会迅速打开那把旧锁。

后量子密码学就像用预计不会被新工具破解的设计替换这把锁。

对于 blockchain，更换锁很困难，因为每个钱包、节点、交易所和硬件设备都必须理解新设计。

### 示例 2：公开收据箱

透明 blockchain 数据就像将每张收据永远放进一个公开箱子里。即使今天没有人能够读懂每种模式，未来的工具可能会在以后发现更多信息。

屏蔽 Zcash 试图从一开始就避免发布这些收据。这有助于长期隐私，但保护屏蔽系统的锁仍必须针对量子未来进行审查。

### 示例 3：退出计划

可恢复性就像在火灾发生前规划逃生路线。你希望永远不需要它，但尽早设计它要比在紧急情况下设计安全得多。

ZIP 2005 将这一理念应用于 Orchard note。

## 用户今天可以做什么

用户无需恐慌。能够破解已部署 blockchain 密码学的大型公共量子计算机如今尚不可用。

良好的习惯仍然有帮助：

- 在可能时优先使用屏蔽 Zcash。
- 避免重复使用地址。
- 保持钱包更新。
- 关注 Zcash 网络升级公告。
- 留意有关可恢复性或迁移的 ZIP 和钱包指引。
- 不要假设透明活动是私密的。
- 不要根据传言转移资金；请等待来自受信任的 Zcash 开发者和钱包团队的明确指引。

## 挑战

后量子升级对于每条 blockchain 都很困难。

常见挑战包括：

- 更大的密钥和签名
- 更大的交易
- 更高的验证成本
- 更多带宽使用
- 新的安全审计
- 硬件钱包支持
- 移动钱包性能
- 交易所和托管整合
- 迁移期间的隐私泄露
- 社区对共识变更的共识

对于 Zcash，最困难的部分不仅是保持币可花费。困难之处在于，在保持币可花费的同时，保留使 Zcash 与众不同的隐私。

## 总结

量子计算机最终可能威胁 blockchain 使用的一些密码学。后量子密码学是长期答案，但必须谨慎部署。

Zcash 如今尚未完全具备后量子能力。然而，Zcash 拥有有用的优势：屏蔽交易减少公开暴露，网络具有密码学升级的历史，而且诸如 ZIP 2005 和 Project Tachyon 等当前研究已经瞄准未来量子风险。

对于初学者，核心理念很简单：今天的隐私可减少未来的数据暴露，谨慎的升级可以帮助 Zcash 在不牺牲可用性的情况下迈向更强的量子时代安全性。
