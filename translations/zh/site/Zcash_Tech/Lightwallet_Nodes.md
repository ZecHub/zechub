# Zcash 轻钱包节点

## 介绍

大多数人通过轻钱包使用 Zcash，而轻钱包不会下载整个 blockchain。相反，它会与一个已经完成这项工作的服务器通信。本页解释这些服务器是什么、它们能看到和不能看到你的哪些信息、如何通过 Tor 路由你的连接，以及如何更改你的钱包所使用的服务器。

如今有两款软件为轻钱包提供服务。**lightwalletd** 是最初的服务，用 Go 编写。**Zaino** 是一个较新的用 Rust 编写的索引器，作为 zcashd 弃用工作的一部分而构建。

## 轻钱包服务器的作用

轻钱包服务器位于你的钱包与 Zcash blockchain 之间，为钱包提供一种带宽高效的链视图。它会为你做三件事。

它提供 compact block。它发送的不是完整区块，而是一种紧凑形式，只携带钱包检测对其屏蔽地址的付款、检测其 notes 的花费以及更新其 witnesses 所需的信息。

它中继你的交易。当你发送交易时，你的钱包会将完成的交易交给服务器，由服务器将其广播到网络。

它回答链查询，例如当前高度以及你的钱包所需的手续费信息。

你的钱包仍然会在本地完成私密工作。它保存你的密钥，对区块进行试探性解密以查找你的 notes，并在你的设备上构建和签名交易。

## 服务器能看到和不能看到什么

这是最容易被误解的部分。你的密钥永远不会离开你的设备，但这并不等于服务器对你一无所知。

这里参考的是 [Zcash 钱包应用威胁模型](https://zcash.readthedocs.io/en/latest/rtd_pages/wallet_threat_model.html)，如果你在意这个问题，值得完整阅读。它列出了几类对手。与本页最相关的是这样一种对手：它能够监视你的钱包与互联网之间的流量，以及服务器与互联网之间的流量。无论谁运行这个服务器，天然都处于这一位置的一部分，因为你的钱包会直接连接到他们。

先看哪些内容是受保护的。根据该模型，对所有对手都成立，哪怕服务器已被攻破，它“无法获知用户的任何加密密钥材料（spending keys、viewing keys、seed phrase 等）”，无法窃取你的资金，也无法让你发送你无意发送的资金。完全屏蔽交易中的金额和 memo 会保持加密状态。

然后是哪些内容不受保护。威胁模型将以下内容列为面对可观测流量的对手时已知的弱点：

| 弱点 | 方式 |
|:--|:--|
| 判断你是谁 | “对手知道用户的 IP 地址，这可能使其推断出用户的真实身份” |
| 判断你大致在哪里 | 在“地理位置数据库中查询你的 IP，以近似确定其位置” |
| 判断你是否发送或接收了屏蔽交易，以及发生时间 | 发送交易“会使用更多带宽，即使连接是加密的，这一点仍然可见”。该模型指出，发送和接收这一行为本身对服务器也是可见的 |
| 统计你随着时间推移发起了多少笔交易 | 相同的带宽模式，只是放到更长时间段内观察 |
| 发现重复出现的支付模式 | 观察活动发生的时间 |
| 推断某个地址是否属于你 | 一个已经知道某个地址的对手“可以向该地址发送资金，并观察你的钱包在获取该交易时是否出现带宽峰值” |

该模型还指出，通常情况假设“用户与 lightwalletd 服务器运营者之间存在信任关系”。

因此，诚实的总结是这样的。轻钱包服务器无法花掉你的钱，也无法读取你的屏蔽交易中的金额或 memo。它最容易获知的是你的 IP 地址以及你的活动时间，而这两者结合起来，足以透露很多关于一个人的信息。屏蔽交易保护的是上链内容本身。它们并不会自动隐藏你与服务器之间的连接。

## 通过 Tor 路由

Tor 会切断你的 IP 地址与钱包流量之间的联系，从而消除上表中最强的标识信息。

许多 Zcash 钱包所依赖的 Rust 库已经支持这一点。zcash_client_backend 包含一个基于 [Arti](https://tpo.pages.torproject.net/core/arti/) 的 Tor 模块，Arti 是 Tor 的 Rust 实现，因此钱包无需附带单独的 Tor 客户端，就可以通过 Tor 路由同步、交易广播和价格查询。

Zaino 开发者也提出了同样的观点，并直接引用了该威胁模型：存在“使用匿名传输协议（例如 Nym 或 Tor）来混淆客户端身份，使 Zcash 的索引服务器无法识别客户端”的需求。

在 **ZODL** 中，Tor 是“高级设置”里的一个选项。该钱包的发行说明建议用户，如果他们“希望减少元数据暴露”，可以使用手动连接模式“并在高级设置中启用 Tor”；应用还会在你恢复钱包之前提示你开启 Tor，因为如果不这么做，一个全新的 IP 就可能在那一刻与整个钱包历史关联起来。

有两个注意点。Tor 会向服务器隐藏你的 IP，但不会改变服务器从你的请求中获知的信息。而且 onion routing 会增加延迟，因此同步会更慢。运行你自己的服务器则以另一种方式避开了信任问题，因为那样运营者就是你自己。

## Zaino，Rust 索引器

[Zaino](/site/Zcash_Tech/Zaino) 是由 Zingo 团队用 Rust 编写的索引器，旨在作为 zcashd 弃用工作的一部分取代 lightwalletd。它服务于轻客户端、全客户端和区块浏览器，读取“Zebra 或 Zcashd 全验证节点”持有的链数据。

它仍在积极开发中，0.7.0 版本于 2026 年 8 月发布。它的目标是在可能的情况下保持与 lightwalletd 的向后兼容性，这样钱包无需重写就可以指向它。

Zaino 有它自己的页面并附有架构图，因此本页只介绍它作为轻钱包服务器的角色。

## 在你的钱包中更改服务器

如果你想选择自己信任的运营者、把活动分散到不同运营者之间，或者指向你自己的服务器，这样做就很值得。

下方菜单路径在本页更新时是正确的，但钱包界面会变化，因此请把它们视为提示，而不是精确路线。请寻找“高级设置”或服务器选项。

#### ZODL

前称 Zashi。点击右上角的齿轮，然后进入“高级设置”。Tor 也在同一个界面里。如果同步失败是由服务器未及时更新导致的，ZODL 还会提供“切换服务器”的快捷选项。

#### Ywallet

点击右上角的齿轮，然后进入 Zcash 标签页。

![Ywallet 服务器设置](/content-images/b0a2910b-dbdf-4292-8e69-af5a386aa183-f51f098d19.webp)

#### Zingo

点击左上角的汉堡菜单，然后进入“设置”，接着向下滚动。

![Zingo 服务器设置](/content-images/ea8f7672-e644-41a5-a422-db131740404a-2626f5fa79.webp)

#### eZcash

点击左上角的汉堡菜单，然后进入“设置”，再进入“高级”。

![eZcash 服务器设置](/content-images/655c0172-61a0-4322-b8cf-4eee4bb53b51-0b93df2e71.webp)

这些截图拍摄于 2025 年 3 月，而这些应用此后已经发布了新版本，因此按钮位置可能已经发生变化。

## 运行你自己的服务器

最强的选择是自己充当运营者，这样就能彻底消除信任问题。这两种服务器都是开源的：[lightwalletd](https://github.com/zcash/lightwalletd) 使用 Go 编写，[Zaino](https://github.com/zingolabs/zaino) 使用 Rust 编写。两者都从全验证节点读取数据，因此你还会需要 [Zebra](/site/Zcash_Tech/Zebra_Full_Node)。

## 总结

轻钱包让你无需占用磁盘空间就能使用 shielded pool，这是一个不错的权衡。只是要清楚你交换掉了什么。服务器无法拿走你的资金，也无法读取你的屏蔽金额，但它非常适合看到你的 IP 地址以及你交易的时间。通过 Tor 路由，谨慎选择你的运营者，或者自己运行一个。
