# Zcash 新用户指南

## 简而言之

- 在受支持的交易所 [exchange]（Gemini、BitcoinVN 等）购买 **ZEC**
- **设置屏蔽钱包 [shielded wallet]**（推荐使用 Zodl、Zingo 或 Zkool）
- 将你的 ZEC 从交易所**提取**到你的屏蔽钱包
- **发送一笔屏蔽交易 [shielded transaction]** — 你在 Zcash 上的第一笔私密支付 [payment]
- 在论坛或 Discord **加入社区**

---

刚接触 Zcash 吗？本指南将带你了解如何成为 Zcash 用户和 *ZEC* 持有者。

---

**购买 ZEC**

要使用 Zcash 网络，你需要购买其货币 *ZEC*。

获取 ZEC 最简单的方法是 [在 Gemini](https://www.gemini.com/prices/zcash) 或 [这些交易所中的任意一家购买](https://zechub.wiki/using-zcash/custodial-exchanges)。

需要注意的一点是，你不必购买完整的 1 个 *ZEC*。

*ZEC* 可以分割，你可以从仅购买一小部分该币开始。

---

**设置钱包**

购买一些 *ZEC* 后，你可能想将其转移到 Zcash 钱包中。 

这篇 [文章解释了](https://www.ledger.com/academy/not-your-keys-not-your-coins-why-it-matters) 为什么将 *ZEC* 存放在钱包中很重要。 

我们建议使用 [屏蔽钱包](https://zechub.wiki/wallets)，因为这些钱包提供了使 *ZEC* 与众不同的隐私 [privacy] 功能。
