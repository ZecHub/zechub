# 什么是 ZecHub？
---

ZecHub 是一个关于 Zcash 的去中心化学习中心。[ZecHub](http://zechub.xyz) 的目标是搭建一个教育平台，让社区成员一起创作、审核和推广有助于 Zcash 生态的内容。具体来说，我们主要通过以下几种方式来做到这一点。

1. [教程](https://www.youtube.com/playlist?list=PL6_epn0lASLFF28ePj7P5TvtMG_WE7p3O)
2. [Wiki 文档](https://zechub.wiki/)
3. [采访社区成员的播客](https://www.youtube.com/playlist?list=PL6_epn0lASLHlNCMtUErX8UfaJK6N9K5O)
4. [Zcash 每周通讯](https://zechub.substack.com/)

教程、短文博客和每周通讯都是开源的，托管在 GitHub 上，社区里的任何人都可以参与贡献。这样既能保证内容准确，也能让这个渠道本身不存在单点故障。

如果你是 Zcash 新手，请参阅[这份指南](/start-here/new-user-guide)。****
