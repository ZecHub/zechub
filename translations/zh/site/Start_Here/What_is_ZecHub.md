# 什么是 ZecHub？
---

ZecHub 是面向 Zcash 的去中心化[decentralized]教育枢纽[education hub]。[ZecHub](http://zechub.xyz) 的目标是提供一个教育平台[educational platform]，让社区成员能够共同创建、验证和推广支持 Zcash 生态系统的内容。我们通过几种机制实现这一目标。

1. [教程Tutorials](https://www.youtube.com/playlist?list=PL6_epn0lASLFF28ePj7P5TvtMG_WE7p3O)
2. [Wiki 文档Wiki-docs](https://zechub.wiki/)
3. [采访社区成员的播客Podcast](https://www.youtube.com/playlist?list=PL6_epn0lASLHlNCMtUErX8UfaJK6N9K5O)。
4. [每周 Zcash 新闻简报[newsletter]。](https://zechub.substack.com/)

教程、短篇博客和新闻简报均为开源内容，并托管在 GitHub 上，这意味着社区中的任何人都可以贡献内容。这是为了确保内容准确，并确保该渠道本身不存在单点故障。

如果您是 Zcash 的新用户，请使用 [本指南](/start-here/new-user-guide)。****
