# Zcash 资源

有许多资源可以帮助用户了解 Zcash。

**[Zcash Media](https://www.youtube.com/c/ZcashMedia)**

Zcash Media 是一个独立机构，制作关于 Zcash 的教育纪录片。他们的第一部视频《为修复 Bitcoin 的致命缺陷而生，什么是 Zcash（ZEC）？》是了解 Zcash 的绝佳入门介绍。

**[X（原 Twitter）](https://x.com)**

Twitter 是 Zcash 社区以及更广泛加密货币领域事实上的交流中心。这里是了解所有 Zcash 相关动态、关注知名社区成员的绝佳场所。以下是一份 [文档](https://www.notion.so/zechub/Social-Media-Links-05b9df645af54de7a1989d9c4ccc4d05)，列出了值得关注的顶级账号。

**[Zcash 社区](https://www.zcashcommunity.com/)**

Zcash Community 是一个由社区运营的网站，重点介绍支持 Zcash 生态系统的社区运营项目。这是了解 Zcash 社区及其作为货币的各种应用的绝佳方式。

**[Zcash 论坛](https://forum.zcashcommunity.com/)**

如新用户指南中所述，Zcash 论坛是就 Zcash 主题和提议的想法进行长篇讨论的绝佳场所。提案总会发布到论坛，以便社区有机会讨论和辩论这些提议的想法。

**[Z.cash](https://z.cash/)**

Z.cash 是 Zcash 的主网站。它为广泛的用户群体提供 Zcash 的内容和文档，并让新用户能够深入了解 Zcash 背后的技术说明。

**[Zcash GitHub](https://github.com/zcash/zcash)**

具备编程能力，并想深入了解 Zcash 的技术层面吗？Zcash GitHub Repo 是 zcashd 的代码仓库，后者是首个 Zcash 节点实现。zcashd 于 2026 年 7 月 18 日达到自动终止支持的时间点，现已不再维护；本条目此前链接的下载页面也已不再提供服务。目前维护中的技术栈是用于节点的 [Zebra](https://github.com/ZcashFoundation/zebra)，以及用于钱包的 [Zallet](https://github.com/zcash/zallet)——请参阅从 [zcashd 迁移到 Zebra 和 Zallet 的迁移指南](https://zechub.wiki/guides/migration-guide-zcashd-to-zebrad-zallet)。

**[Zcash Foundation GitHub](https://github.com/ZcashFoundation)**

另一个 GitHub 代码仓库，托管 Zcash Foundation 的项目，包括 [zebra](https://github.com/ZcashFoundation/zebra)——一个使用 Rust 编写的 Zcash 节点实现。

**[Halo2](https://zcash.github.io/halo2/index.html)**

零知识证明系统背后的概念。

**[Zcash RPC 文档](https://zcash.github.io/rpc/)**

zcashd 公开的 RPC 命令列表。有关目前维护的钱包 RPC 接口，请参阅 [Zallet Book](https://zcash.github.io/zallet/)。
