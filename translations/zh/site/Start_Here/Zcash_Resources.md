# Zcash 资源

有许多资源可帮助用户了解 Zcash。

**[Zcash Media](https://www.youtube.com/c/ZcashMedia)**

Zcash Media 是一个制作 Zcash 教育纪录片的独立组织。他们的第一部视频“Built to Fix Bitcoin's Fatal Flaw, What is Zcash (ZEC)?”是了解 Zcash 的绝佳入门。

**[X（原 Twitter）](https://x.com)**

Twitter 是 Zcash 社区以及更广泛加密货币领域事实上的沟通中心。这里是了解 Zcash 各方面动态、关注知名社区成员的好地方。以下这份[文档](https://www.notion.so/zechub/Social-Media-Links-05b9df645af54de7a1989d9c4ccc4d05)列出了值得关注的主要账户。

**[Zcash 社区](https://www.zcashcommunity.com/)**

Zcash Community 是一个由社区运营的网站，重点介绍支持 Zcash 生态系统的社区运营项目。它是了解 Zcash 社区及其作为货币的各种应用的好方式。

**[Zcash 论坛](https://forum.zcashcommunity.com/)**

正如新用户指南中提到的，Zcash 论坛是就 Zcash 主题和提案进行深入讨论的好地方。提案总会发布到论坛，以便社区有机会讨论和辩论这些提议。

**[Z.cash](https://z.cash/)**

Z.cash 是 Zcash 的主网站。它为广泛用户提供有关 Zcash 的内容和文档，并让新用户能够深入了解 Zcash 背后的技术说明。

**[Zcash Github](https://github.com/zcash/zcash)**

具备编程能力，并想深入了解 Zcash 的技术层面吗？Zcash Github Repo 是 zcashd 的代码仓库，zcashd 是第一个 Zcash 节点实现。zcashd 已于 2026 年 7 月 18 日达到自动停止支持的期限，不再维护；本条目此前链接的下载页面也不再提供服务。目前维护的技术栈为：用于节点的 [Zebra](https://github.com/ZcashFoundation/zebra)，以及用于钱包的 [Zallet](https://github.com/zcash/zallet)——请参阅 [从 zcashd 迁移至 Zebra 和 Zallet 的指南](https://zechub.wiki/guides/migration-guide-zcashd-to-zebrad-zallet)。

**[Zcash Foundation Github](https://github.com/ZcashFoundation)**

另一个托管 Zcash Foundation 项目的 GitHub 代码库，其中包括以 Rust 编写的 Zcash 节点实现 [zebra](https://github.com/ZcashFoundation/zebra)。

**[Halo2](https://zcash.github.io/halo2/index.html)**

零知识证明系统背后的概念。

**[Zcash RPC 文档](https://zcash.github.io/rpc/)**

zcashd 曾公开的 RPC 命令列表。有关当前维护的钱包 RPC 接口，请参阅 [Zallet Book](https://zcash.github.io/zallet/)。
