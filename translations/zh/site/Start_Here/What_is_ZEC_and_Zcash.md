# Zcash 基础

## TL;DR

- **ZEC** 是运行在 Zcash 区块链上、以隐私为第一优先的数字货币
- 与 Bitcoin 不同，ZEC 借助零知识证明，支持完全**屏蔽（私密）的交易**
- 你的财务隐私由你掌控：公开什么、向谁公开，都由你决定
- Zcash 是开源、无需许可且去中心化的

## 什么是 ZEC？

ZEC 是基于 Zcash 区块链的数字货币，也是互联网上最接近现金的东西。它和 Bitcoin 有很多相似之处，但它让用户可以进行完全私密的转账，从而解决了 Bitcoin 最大的缺陷。

#### 为什么需要私密的货币？

ZEC 让人们无需任何许可就能传输数据。有了点对点、无需许可的货币系统，人们就可以不依赖中心化机构，自己储存价值、与他人交易。借助 ZEC，什么时候向别人披露自己的财务信息，由自己决定。

## 什么是 Zcash？

Zcash 是 “Zerocash” 协议的一种实现：一个开源的区块链账本，内置一套精密的零知识证明系统。它以 Bitcoin 的代码为基础，专注于借助这套证明系统保护[交易元数据](https://nym.com/blog/what-is-metadata)的机密性，提供更高标准的隐私。说到底，Zcash 就是让数据的所有权保持私密，并且在交易时无需许可即可转移。

#### 为什么这很重要？

Zcash 解决了 Bitcoin 最大的缺陷：无法私密地拥有和转移数据。随着区块链应用和加密货币越来越普及，仅靠“假名”交易已经保护不了用户隐私，专门分析链上交易的监控工具也越来越常见。
