# Zcash 开发基金

Zcash 是一种独特的区块链协议，因为它是自筹资金的。这意味着从事 Zcash 开发的团队不需要从外部投资者那里拿钱，因此既能专注于推动采用，也能始终与 Zcash 更广泛的理念和使命保持一致。
