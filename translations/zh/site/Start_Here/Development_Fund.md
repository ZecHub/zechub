# Zcash 开发基金 [Development Fund]

Zcash 是一个独特的 blockchain 协议，因为它实现了自筹资金。这意味着，致力于 Zcash 的团队无需从外部投资者那里筹集资金，并且能够专注于推动采用，同时始终与 Zcash 更广泛的精神理念和使命保持一致。
