# 使用本维基

其中一些内容可能让人不知所措。我们理解！这里的信息很多。以下是一份简单的分步指南，重点说明你应如何浏览本维基。

## 初识 Zcash

如果你刚接触 Zcash，这里是快速了解相关内容的绝佳起点。你首先应该查看以下页面：

[Zcash 新用户指南](https://zechub.wiki/start-here/new-user-guide#content)

[Zcash 资源](https://zechub.wiki/start-here/zcash-resources#content)

[Zcash 基础知识](https://zechub.wiki/start-here/what-is-zec-and-zcash#content)

## 准备使用 Zcash

阅读完介绍文档及其相关资源后，请查看 [使用 ZEC](https://zechub.wiki/guides/using-zec-privately#content) 和 [教程](https://youtube.com/playlist?list=PL6_epn0lASLFF28ePj7P5TvtMG_WE7p3O&si=4vleWUbCGbNJu1-M) 视频，以了解如何使用 ZEC。

## 我是 Zcash 社区成员

如果你是社区成员，太棒了！要保持最新资讯，最好的方法是关注每周新闻简报 [Zcash 生态系统摘要](https://zechub.substack.com/s/zcash-ecosystem-digest)，并关注 [Zcash 社区页面列表](https://zechub.wiki/zcash-community/community-links#content) 中的所有账号。

## 我想为 ZecHub 做贡献

太好了！请阅读 [什么是 ZecHub](https://zechub.wiki/start-here/what-is-zechub#content)，然后查看 [帮助构建 ZecHub](https://zechub.wiki/contribute/help-build-zechub)，了解如何贡献。
