# 使用本 Wiki

内容太多，可能会让人有点无从下手。我们懂！这里的信息确实很多。所以我们准备了一份简单的分步指南，告诉你该怎么浏览这个 Wiki。

## 刚接触 Zcash

如果你刚接触 Zcash，从这里开始就对了。建议先看看下面这几页：

[Zcash 新用户指南](https://zechub.wiki/start-here/new-user-guide#content)

[Zcash 资源](https://zechub.wiki/start-here/zcash-resources#content)

[Zcash 基础知识](https://zechub.wiki/start-here/what-is-zec-and-zcash#content)

## 准备好使用 Zcash 了

读完入门文档和相关资源后，可以看看 [使用 ZEC](https://zechub.wiki/guides/using-zec-privately#content) 和 [教程](https://youtube.com/playlist?list=PL6_epn0lASLFF28ePj7P5TvtMG_WE7p3O&si=4vleWUbCGbNJu1-M) 视频，学习怎么使用 ZEC。

## 我是 Zcash 社区成员

如果你已经是社区成员，太棒了！想第一时间掌握最新动态，最好的办法是订阅每周通讯 [Zcash 生态摘要](https://zechub.substack.com/s/zcash-ecosystem-digest)，并关注 [Zcash 社区页面列表](https://zechub.wiki/zcash-community/community-links#content) 里的所有账号。

## 我想为 ZecHub 做贡献

欢迎！请先阅读 [什么是 ZecHub](https://zechub.wiki/start-here/what-is-zechub#content)，再到 [帮助建设 ZecHub](https://zechub.wiki/contribute/help-build-zechub) 看看怎样参与贡献。
