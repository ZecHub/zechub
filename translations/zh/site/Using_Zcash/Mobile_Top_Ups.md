# 使用 Zcash 进行手机充值

在本指南中，你将学习如何使用 ZEC 购买话费。

## 请按照以下步骤操作：

### 1. 创建账户
访问 [Coinsbee.com](https://www.coinsbee.com/en/shop/mobile-top-ups/) 并创建账户。

### 2. 选择你的国家和运营商
滚动到左上角并选择你的国家；然后选择手机话费，并选择你想要充值的运营商（例如：MTN）。

![步骤 2 - 选择国家和运营商](/content-images/0-qvB7ZCWaVWa-C2d8-db0d4ea372.webp)

### 3. 填写信息并购买
填写正确的信息，然后点击“立即购买”按钮。打开购物车查看你的订单，点击继续，并使用 $ZEC 确认购买。

![步骤 3 - 购买页面](/content-images/0-ikF-ooBc9W7olfNt-7a4584edda.webp)

### 4. 付款详情
系统将提供等值的 $ZEC 金额，以及应将资金发送至的透明地址。

![步骤 4 - ZEC 付款详情](/content-images/0-6_YhAhQnsLbrMvHN-c9646f3604.webp)

### 5. 发送付款
仔细复制并粘贴金额和地址。在备注字段中，添加你自己的屏蔽地址，以便在需要退款时使用。

![步骤 5 - 发送 ZEC](/content-images/0-DNnpyemsKcW-k-u-bcaaa51d3a.webp)

### 6. 处理中
资金发送后，你的请求将在几分钟内得到处理。

![步骤 6 - 处理页面](/content-images/0-LgXuUVLVecqrUW5G-a894c7b2dd.webp)

### 7. 确认
嘿……我的号码已经充值成功！你还可以在付款过程中确认你的电子邮箱，这样交易完成后就会通过电子邮件收到通知。

![步骤 7 - 充值成功](/content-images/0-TJKIcqznQ4Y8_jgo-e725aed571.webp)

## 无需账户购买充值

上述方法需要创建 Coinsbee 账户。如果你不愿意这样做，CardsRelay 提供无需注册即可使用 ZEC 购买手机充值的服务。

### 1. 选择你的国家和运营商
访问 [CardsRelay](https://cardsrelay.com)，然后打开手机充值部分。该服务在全球支持超过 750 家运营商。

### 2. 输入号码和金额
填写要充值的手机号码，并选择充值金额。显示的价格是单一的全包总价，之后不会额外收取汇率加价。

### 3. 输入你的电子邮箱
需要提供电子邮箱地址以发送确认信息，并且会在下单前进行验证。不会创建账户，也不会要求提供身份证明文件。

### 4. 使用 ZEC 付款
在结账时选择 Zcash。ZEC 将被直接接受，而非由第三方兑换。系统会显示付款地址和确切金额。

### 5. 确认
充值将被处理，确认邮件通常会在数秒内送达。

CardsRelay 还销售约 2,500 个品牌的礼品卡，并且除 Zcash 外还接受 Monero 和 Zano。该服务由 Payzy ME FZ Ltd. 运营。
