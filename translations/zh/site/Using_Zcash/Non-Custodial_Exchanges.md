# <img src="/content-images/ZEC-USD-a2189a84b9.webp" alt="替代文本" width="50"/>   非托管交易所

[Zcash 非托管交易所](/dex)

在不断发展的加密货币交易世界中，非托管交易所（也称为去中心化交易所或 DEX）让用户无需将资金交给交易所账户即可交易。你自行保管密钥，但这并不意味着没有其他方参与。根据所选路径，一笔兑换可能会经过网站或钱包应用、路由服务、智能合约、求解器和桥。

上述交易所让你可以从自己的钱包获取和交易 Zcash。一笔兑换的隐私程度取决于服务、你付款所使用的网络，以及你的 ZEC 最终是否进入屏蔽地址。以下章节将解释其中的差异。

### **了解非托管交易所**

非托管交易所，也称为去中心化交易所（DEX），是无需用户将资金存入交易所本身即可进行加密货币交易的平台。用户可以保留对私钥的控制权，并从自己的钱包进行交易。跨链兑换仍依赖其他方进行报价、路由和结算交易（见下文）。

这可以提高安全性，因为用户无需依赖交易所保管其资产，从而降低遭受黑客攻击或管理不善的风险。但这并不会让一笔兑换天然具备隐私性。非托管交易所上的交易通常使用智能合约，而智能合约是公开的；你所使用的服务仍可能看到你的地址和连接详情。

非托管加密货币交易所的一项关键优势在于，用户对其资产拥有更强的控制权。由于这些交易所不保管资产，用户可对其数字货币享有完整的所有权和支配权。

### **非托管交易所与托管交易所**

**#1 安全性**：非托管交易所无需将资金存放在中心化交易所账户中。用户保留对私钥的控制权，降低了托管交易所可能遭遇的黑客攻击、内部攻击和平台故障风险。跨链兑换在交易结算期间，资金仍可能暂时存放在充值地址或桥中。

**#2 隐私**：非托管兑换通常不需要交易所账户，因此你往往无需使用电子邮件或身份证件注册。这并不等同于匿名。你在源网络（例如 Solana 或 Ethereum）上发送的充值在该链上是公开的，服务仍可看到你的钱包地址、IP 地址和兑换详情。Zcash 一侧的隐私取决于你的 ZEC 最终落在何处（见下文）。

**#3 去中心化**：非托管交易所更符合加密货币的去中心化理念。用户对交易活动拥有更大的自主权和控制权，这与 blockchain 技术的更广泛原则一致。

对于托管交易所而言，大多数中心化交易所的去中心化程度通常相当低，因为交易所团队或管理人员会管理交易所中的用户数据或信息。

**#4 对监管变化的适应性**：非托管交易所通常更能适应不断变化的监管环境。由于它们不持有用户资金，与托管交易所相比，可能面临更少的合规挑战。

**#5 创新与实验**：非托管交易所经常推动加密货币领域的创新。它们鼓励开发去中心化技术，例如自动做市商（AMM）和去中心化金融（DeFi）应用。

**#6 全球可访问性**：非托管交易所通常为世界各地的用户提供加密货币访问渠道，包括监管障碍可能限制托管交易所服务可用性的地区。

**#7 无 KYC 要求**：许多非托管交易所不会预先要求提供身份证明文件。大多数仍会根据合规数据库筛查钱包地址；若某些内容被标记，一笔兑换可能被延迟、阻止或拒绝。在依赖某项服务前，请查看其条款。

### **Zcash 保护什么，以及不保护什么**

Zcash 的隐私来自屏蔽地址。当 ZEC 在屏蔽地址之间转移时，发送方、接收方、金额和备注都会在 Zcash 链上加密。有关其运作方式，请参阅 [屏蔽资金池](/using-zcash/shielded-pools)。

一笔兑换包含 Zcash 无法隐藏的部分：

- **源网络。** 你从 Solana、Ethereum 或其他公开链发送的资金在该链上可见，包括你的地址和金额。
- **接收地址。** 某些兑换路径会将 ZEC 发送至透明地址。例如，Near Intents 将 ZEC 列为仅支持 [透明地址](https://docs.near-intents.org/resources/chain-support)。发送到透明（t1 或 t3）地址的 ZEC 是公开的，与 Bitcoin 类似。之后将其屏蔽可保护你接下来进行的操作，但入账转账和屏蔽交易仍然可见。
- **服务。** 应用及任何路由服务都能看到你提供的地址和金额，以及 IP 地址等连接数据。

将 ZEC 发送到由你控制的钱包，并在使用前将其屏蔽。[私密地使用 ZEC](/guides/using-zec-privately) 介绍了后续步骤。

### **一笔兑换涉及哪些角色**

以通过 Near Intents 1Click 服务路由的一笔兑换为例。其 [API 条款](https://docs.near-intents.org/security-compliance/terms-of-service) 将以下内容视为彼此独立的组成部分：

- **界面**：你使用的网站或钱包。它可由 Intents Technology 运营，也可由拥有自身条款的第三方运营。
- **1Click**：由 Intents Technology Limited 运营的路由和结算服务。你会将资金发送至为你的报价创建的充值地址。文档称 1Click 不会托管资金，但条款指出，转账进行期间，资产可能会被持有或锁定在桥基础设施中。
- **协议**：Near Intents 智能合约。
- **求解器**：完成报价的独立第三方。
- **桥**：原生 ZEC 通过由 Intents Technology 运营的 PoA Bridge 转移。

Near Intents 还会针对多个 AML 数据库 [筛查集成报价流程](https://docs.near-intents.org/security-compliance/risk-and-compliance)，并表示覆盖范围因流程和集成而异。根据其条款，被标记的兑换可能被延迟、阻止、冻结或拒绝。

### **兑换期间你会共享什么**

- 接收兑换资金的 ZEC 地址，以及源网络上的退款地址。
- 资产和金额，以及你发送的充值交易；该交易在源链上是公开的。
- 连接数据。1Click 条款称 Intents Technology 可能收集请求元数据、IP 地址和钱包地址；near.com 的隐私政策列出了 IP 地址、位置、浏览器和设备信息。
- 应用额外添加的任何信息，例如其他已连接的钱包地址。应用也可能通过自身的合规检查筛查你的钱包。

### **在哪里查看条款和获得支持**

条款会发生变化，因此在进行大额兑换前请阅读最新版本。

- **从你使用的应用开始。** 它是你的主要联系点。1Click API 条款称，Intents Technology 与基于其构建的应用用户不存在直接关系。
- **Near Intents：** near.com/terms 和 near.com/privacy 上的条款及隐私政策，以及 [1Click API 条款](https://docs.near-intents.org/security-compliance/terms-of-service)和 [风险与合规](https://docs.near-intents.org/security-compliance/risk-and-compliance)。
- **追踪和支持：** 可在 [Near Intents Explorer](https://explorer.near-intents.org) 查询一笔兑换，或在 [Near Intents Telegram](https://t.me/near_intents) 中提问。
- **退款：** 失败的兑换可能会退回到你提供的退款地址，但 near.com 的条款称不保证退款。1Click 条款还称，不会考虑处理低于 300 美元的用户错误恢复请求。

现在，让我们探索几个可便捷使用、可促进 Zcash 交易的非托管交易所。使用这些平台可为你提供获取更多 Zcash 币的便利方式。

### **总结**

非托管交易所或 DEX 让你从自己的钱包交易，同时保留对私钥的控制权。这有助于提高安全性，但隐私取决于路径：源链是公开的，服务可以看到你的地址和连接数据，而你的 ZEC 只有在位于屏蔽地址中时才具有隐私性。

尽管非托管交易所提供了令人信服的优势，但也应认识到它们可能存在缺点，例如潜在的流动性问题，以及对经验较少的用户而言更陡峭的学习曲线。

与任何金融决策一样，交易者在非托管与托管交易所选项之间做出选择前，应仔细评估自身的优先事项、风险承受能力以及对该技术的熟悉程度。
