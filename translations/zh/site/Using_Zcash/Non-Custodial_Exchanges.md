# <img src="/content-images/ZEC-USD-a2189a84b9.webp" alt="Alt Text" width="50"/>   非托管交易所

[Zcash 非托管交易所](/dex)

在不断发展的加密货币交易世界中，非托管交易所，也称为去中心化交易所或 DEX，让用户无需将资金交给交易所账户即可进行交易。你保管自己的密钥，但这并不意味着没有其他方参与。根据所选路径，一次兑换可能会经过网站或钱包应用、路由服务、智能合约、求解器和跨链桥。

上述交易所让你可以从自己的钱包获取和交易 Zcash。一次兑换的私密程度取决于服务、你付款所使用的网络，以及你的 ZEC 是否最终进入屏蔽地址。以下部分将说明其中的区别。

### **了解非托管交易所**

非托管交易所，也称为去中心化交易所（DEX），是无需用户将资金存入交易所本身即可促进加密货币交易的平台。相反，用户保有对自己私钥的控制权，并从自己的钱包进行交易。跨链兑换仍依赖其他方来报价、路由和结算交易（见下文）。

这可以提高安全性，因为用户无需依赖交易所保管其资产，从而降低遭受黑客攻击或管理不善的风险。但这并不会自动使一次兑换变得私密。非托管交易所上的交易通常使用智能合约，而智能合约是公开的；你所使用的服务仍可能看到你的地址和连接详情。

非托管加密货币交易所的一项关键优势在于，它们让用户对资产拥有更强的控制权。由于这些交易所不保管资产，用户对其数字货币享有完全的所有权和支配权。

### **非托管交易所与托管交易所**

**#1 安全性**：非托管交易所无需将资金存放在中心化交易所账户中。用户保有对私钥的控制权，从而降低托管交易所可能遭遇的黑客攻击、内部攻击和平台故障风险。跨链兑换在交易结算期间，资金仍可能短暂存放在充值地址或跨链桥中。

**#2 隐私**：非托管兑换通常不需要交易所账户，因此你往往无需使用电子邮件或身份证件注册。这不等同于匿名。你在源网络上发送的充值（例如 Solana 或 Ethereum）会在该链上公开，服务仍可看到你的钱包地址、IP 地址和兑换详情。Zcash 侧的隐私取决于你的 ZEC 最终落在何处（见下文）。

**#3 去中心化**：非托管交易所更符合加密货币的去中心化理念。用户对自己的交易活动拥有更大的自主权和控制权，这与区块链技术的更广泛原则一致。

对于托管交易所而言，大多数中心化交易所的去中心化程度通常相当低，因为交易所团队或管理人员会管理交易所内的用户数据或信息。

**#4 对监管变化的适应性**：非托管交易所通常更能适应不断变化的监管环境。由于它们不持有用户资金，与托管交易所相比，可能面临更少的合规挑战。

**#5 创新与实验**：非托管交易所经常推动加密领域的创新。它们促进去中心化技术的发展，例如自动做市商（AMM）和去中心化金融（DeFi）应用。

**#6 全球可及性**：非托管交易所通常为世界各地的用户提供加密货币访问渠道，包括那些监管障碍可能限制托管交易所服务可用性的地区。

**#7 无 KYC 要求**：许多非托管交易所不会预先要求身份证明文件。大多数仍会根据合规数据库筛查钱包地址；如果某些事项被标记，兑换可能被延迟、阻止或拒绝。在依赖某项服务前，请查阅其条款。

### **Zcash 能保护什么，以及不能保护什么**

Zcash 的隐私来自屏蔽地址。当 ZEC 在屏蔽地址之间转移时，发送方、接收方、金额和备注都会在 Zcash 链上加密。有关其运作方式，请参阅 [屏蔽资金池](/using-zcash/shielded-pools)。

一次兑换有一些部分是 Zcash 无法隐藏的：

- **源网络。** 你从 Solana、Ethereum 或其他公开链发送的资金会在该链上可见，包括你的地址和金额。
- **接收地址。** 某些兑换路径会将 ZEC 发送到透明地址。例如，Near Intents 将 ZEC 列为仅支持 [透明地址](https://docs.near-intents.org/resources/chain-support)。发送到透明（t1 或 t3）地址的 ZEC 是公开的，与 Bitcoin 很相似。之后将其屏蔽可以保护你接下来的操作，但转入交易和屏蔽交易仍然可见。
- **服务。** 应用和任何路由服务都能看到你提供给它们的地址和金额，以及 IP 地址等连接数据。

将 ZEC 发送到你控制的钱包，并在使用前将其屏蔽。[私密地使用 ZEC](/guides/using-zec-privately) 介绍了后续步骤。

### **一次兑换中涉及哪些参与方**

以通过 Near Intents 1Click 服务路由的一次兑换为例。其 [API 条款](https://docs.near-intents.org/security-compliance/terms-of-service) 将其视为彼此独立的部分：

- **界面**：你使用的网站或钱包。它可以由 Intents Technology 运营，也可以由拥有自身条款的第三方运营。
- **1Click**：由 Intents Technology Limited 运营的路由和结算服务。你将资金发送至为你的报价创建的充值地址。文档称 1Click 不会托管资金，但条款指出，在转账进行期间，资产可能被保留或锁定在跨链桥基础设施中。
- **协议**：Near Intents 智能合约。
- **求解器**：完成报价的独立第三方。
- **跨链桥**：原生 ZEC 通过由 Intents Technology 运营的 PoA Bridge 转移。

Near Intents 还会针对多个 AML 数据库 [筛查集成报价流程](https://docs.near-intents.org/security-compliance/risk-and-compliance)，并表示覆盖范围因流程和集成而异。根据其条款，被标记的兑换可能被延迟、阻止、冻结或拒绝。

### **兑换期间你会共享什么**

- 接收兑换的 ZEC 地址，以及源网络上的退款地址。
- 资产和金额，以及你发送的充值交易；该交易在源链上是公开的。
- 连接数据。1Click 条款称 Intents Technology 可能收集请求元数据、IP 地址和钱包地址；near.com 的隐私政策列出了 IP 地址、位置、浏览器和设备信息。
- 应用额外添加的任何信息，例如其他已连接的钱包地址。应用也可能通过其自身的合规检查筛查你的钱包。

### **在哪里查看条款和获取支持**

条款会变化，因此在进行大额兑换前请阅读当前版本。

- **从你使用的应用开始。** 它是你的主要联系点。1Click API 条款称，Intents Technology 与基于其构建的应用用户不存在直接关系。
- **Near Intents：** near.com/terms 和 near.com/privacy 上的条款和隐私政策，以及 [1Click API 条款](https://docs.near-intents.org/security-compliance/terms-of-service)和 [风险与合规](https://docs.near-intents.org/security-compliance/risk-and-compliance)。
- **追踪与支持：** 可在 [Near Intents 浏览器](https://explorer.near-intents.org)中查询兑换，或在 [Near Intents Telegram](https://t.me/near_intents) 中提问。
- **退款：** 失败的兑换可能会退回至你提供的退款地址，但 near.com 的条款称退款并不保证。1Click 条款还称，不会考虑处理因用户错误导致的低于 USD 300 的追回请求。

现在，让我们探索几个可使用的非托管交易所，它们支持 Zcash 交易。使用这些平台将为你提供一种便捷的方式，以获取更多 Zcash 币。

### **总结**

非托管交易所或 DEX 让你可以从自己的钱包进行交易，同时保有对私钥的控制权。这有助于提高安全性，但隐私取决于路径：源链是公开的，服务可以看到你的地址和连接数据，而你的 ZEC 只有位于屏蔽地址中时才是私密的。

尽管非托管交易所提供了引人注目的优势，但也必须认识到，它们可能存在缺点，例如潜在的流动性问题，以及对经验较少用户而言更陡峭的学习曲线。

与任何金融决策一样，交易者在非托管和托管交易所选项之间作出选择前，应仔细评估自己的优先事项、风险承受能力以及对相关技术的熟悉程度。
