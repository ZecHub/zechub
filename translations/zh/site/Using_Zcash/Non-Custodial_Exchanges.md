# <img src="/content-images/ZEC-USD-a2189a84b9.webp" alt="Alt Text" width="50"/>   非托管交易所 [Non-Custodial Exchanges]

## 摘要

* 非托管交易所让你能够从自己的钱包 [wallet] 兑换 [swap] 币种。你保留私钥，且没有交易所 [exchange] 账户持有你的资金。
* 保管好你的私钥可保护你免受交易所黑客攻击和故障的影响。隐私 [privacy] 则是另一个问题。
* 你从另一条链 [chain]（如 Solana 或 Ethereum）发送的存款在该链上是公开的。兑换服务还会看到你的地址 [address] 和连接数据。
* 某些兑换路径会将 ZEC 发送至透明 [transparent] 地址，该地址是公开的。
* 当你的 ZEC 存放在屏蔽 [shielded] 地址中时，它就会变为私密。在使用前，请先在自己的钱包中将其屏蔽。

## 核心说明

[Zcash 非托管交易所](/dex)

在不断发展的加密货币交易世界中，非托管交易所，也称为去中心化 [decentralized] 交易所（Decentralized Exchanges 或 DEXs），让用户无需将资金交给交易所账户即可交易。你保留自己的私钥，但这并不意味着没有其他方参与。根据路径不同，一次兑换可能会经过网站或钱包应用、路由服务、智能合约 [smart contracts]、求解器和桥 [bridge]。

上面列出的交易所让你能够从自己的钱包获取和交易 Zcash。一次兑换的隐私程度取决于服务、你付款所使用的网络，以及你的 ZEC 最终是否进入屏蔽地址。以下部分将说明其中的区别。

### **了解非托管交易所**

非托管交易所，也称为去中心化交易所（DEXs），是无需用户将资金存入交易所本身即可促进加密货币交易的平台。用户保留对私钥的控制权，并从自己的钱包进行交易。跨链 [cross-chain] 兑换仍然依赖其他方来报价、路由和结算交易（见下文）。

这可以提升安全性，因为用户不依赖交易所持有资产，从而降低黑客攻击或管理不善的风险。它本身并不能使兑换变得私密。非托管交易所上的交易通常使用公开的智能合约，你所使用的服务仍可看到你的地址和连接详情。

非托管加密货币交易所的一项关键优势在于，它们让用户能够更好地控制自己的资产。由于这些交易所不保留资产，用户对其数字货币享有完全的所有权和控制权。

### **非托管交易所与托管交易所**

**#1 安全性**：非托管交易所无需将资金存放在中心化交易所账户中。用户保留对私钥的控制权，降低了托管交易所可能面临的黑客攻击、内部攻击和平台故障风险。跨链兑换在交易结算期间，资金仍可能会短暂存放在存款地址或桥中。

**#2 隐私**：非托管兑换通常不需要交易所账户，因此你往往无需使用电子邮件或身份证件注册。这并不等同于匿名。你在源网络（例如 Solana 或 Ethereum）上发送的存款在该链上是公开的，服务仍可看到你的钱包地址、IP 地址和兑换详情。Zcash 一侧的隐私取决于你的 ZEC 最终进入何处（见下文）。

**#3 去中心化**：非托管交易所更符合加密货币的去中心化理念。用户对自己的交易活动拥有更大的自主权和控制权，这与区块链技术的更广泛原则一致。

对于托管交易所而言，大多数中心化交易所的去中心化程度通常相当低，这使得交易所团队或管理人员能够管理交易所上的用户数据或信息。

**#4 对不断变化法规的适应性**：非托管交易所通常更能适应不断变化的监管环境。由于它们不持有用户资金，与托管交易所相比，可能面临更少的合规挑战。

**#5 创新与实验**：非托管交易所经常推动加密领域的创新。它们鼓励去中心化技术的发展，例如自动做市商（AMMs）和去中心化金融（DeFi）应用。

**#6 全球可访问性**：非托管交易所通常让全球用户都能访问加密货币，包括监管障碍可能限制托管交易所服务可用性的地区。

**#7 无 KYC 要求**：许多非托管交易所不会预先要求提供身份证件。大多数服务仍会根据合规数据库筛查钱包地址，如果发现问题，兑换可能被延迟、阻止或拒绝。在依赖某项服务前，请先查看其条款。

### **Zcash 能保护什么，以及不能保护什么**

Zcash 的隐私来自屏蔽地址。当 ZEC 在屏蔽地址之间转移时，发送方、接收方、金额和备忘录 [memo] 都会在 Zcash 链上加密 [encryption]。有关其运作方式，请参阅 [屏蔽池](/using-zcash/shielded-pools)。

一次兑换中有些部分是 Zcash 无法隐藏的：

- **源网络。** 你从 Solana、Ethereum 或另一条公共链发送的资金在该链上可见，包括你的地址和金额。
- **接收地址。** 某些兑换路径会将 ZEC 发送至透明地址。例如，NEAR Intents 将 ZEC 列为仅支持 [透明地址](https://docs.near-intents.org/resources/chain-support)。发送至透明（t1 或 t3）地址的 ZEC 是公开的，与 Bitcoin 十分类似。之后将其屏蔽可以保护你接下来的操作，但入账转账和屏蔽交易仍然可见。
- **服务。** 应用和任何路由服务都会看到你提供的地址和金额，以及 IP 地址等连接数据。

将 ZEC 发送至你控制的钱包，并在使用前将其屏蔽。[私密使用 ZEC](/guides/using-zec-privately) 介绍了后续步骤。

### **一次兑换中涉及哪些方**

以通过 NEAR Intents 1Click 服务路由的兑换为例。其 [API 条款](https://docs.near-intents.org/security-compliance/terms-of-service) 将其视为以下独立部分：

- **界面**：你使用的网站或钱包。它可以由 Intents Technology 运行，也可以由拥有自身条款的第三方运行。
- **1Click**：由 Intents Technology Limited 运行的路由和结算服务。你将资金发送至为你的报价创建的存款地址。文档称 1Click 不会接管托管权，但条款指出，在转账进行期间，资产可能被持有或锁定在桥基础设施中。
- **协议**：NEAR Intents 智能合约。
- **求解器**：完成报价的独立第三方。
- **桥**：原生 ZEC 通过由 Intents Technology 运营的 PoA Bridge 转移。

NEAR Intents 还会根据多个 AML 数据库 [筛查集成报价流程](https://docs.near-intents.org/security-compliance/risk-and-compliance)，并称覆盖范围因流程和集成而异。根据其条款，被标记的兑换可能被延迟、阻止、冻结或拒绝。

### **兑换期间你会共享什么**

- 接收兑换的 ZEC 地址，以及源网络上的退款地址。
- 资产和金额，以及你发送的存款交易，该交易在源链上是公开的。
- 连接数据。1Click 条款称 Intents Technology 可能收集请求元数据、IP 地址和钱包地址，而 near.com 上的隐私政策列出了 IP 地址、位置、浏览器和设备信息。
- 应用额外添加的任何内容，例如其他已连接的钱包地址。应用还可能通过自身的合规检查筛查你的钱包。

## 视觉化说明 / 类比

托管交易所的运作方式像银行。你开设账户，将资金留在它的金库中，并请银行为你交易。

非托管兑换的运作方式像繁忙街道上的货币兑换窗口。你将现金递过窗口，取回另一种货币，且从不把钱留给柜员。街上的人可以看到你走上前并交出现金，就像任何人都能看到你在源链上的存款。柜员会看到你的脸和金额。

窗口之后发生什么取决于你。将新币放入密封信封，也就是使用屏蔽地址，之后就没有人能追踪它们。

## 实际影响

### **在哪里查看条款和支持**

条款会发生变化，因此在进行大额兑换前，请阅读当前版本。

- **从你使用的应用开始。** 它是你的主要联系点。1Click API 条款称，Intents Technology 与基于其构建的应用用户没有直接关系。
- **NEAR Intents：** near.com/terms 和 near.com/privacy 上的条款与隐私政策，以及 [1Click API 条款](https://docs.near-intents.org/security-compliance/terms-of-service) 和 [风险与合规](https://docs.near-intents.org/security-compliance/risk-and-compliance)。
- **追踪与支持：** 在 [NEAR Intents 浏览器](https://explorer.near-intents.org) 上查询兑换，或在 [NEAR Intents Telegram](https://t.me/near_intents) 中咨询。
- **退款：** 失败的兑换可能会退回至你提供的退款地址，但 near.com 的条款称退款不受保证。1Click 条款还称，不会考虑低于 USD 300 的用户错误恢复请求。

现在，让我们探索一些可用的、支持 Zcash 交易的非托管交易所。使用这些平台将为你提供一种便捷的方式来获取更多 Zcash 币。

### **总结**

非托管交易所或 DEXs 让你能够从自己的钱包交易，同时保留对私钥的控制权。这有助于提升安全性，但隐私取决于路径：源链是公开的，服务会看到你的地址和连接数据，而你的 ZEC 只有进入屏蔽地址后才会变得私密。

尽管非托管交易所提供了令人信服的优势，但也应认识到它们可能存在缺点，例如潜在的流动性问题，以及经验较少的用户面临更陡峭的学习曲线。

与任何财务决策一样，交易者在选择非托管或托管交易所方案前，应仔细评估自己的优先事项、风险承受能力以及对该技术的熟悉程度。

## 常见错误

- **将“非托管”视为“私密”。** 保留私钥可以保护你的资金免受交易所故障影响。源链上的存款是公开的，服务也会看到你的地址和 IP 地址。
- **将兑换后的 ZEC 留在透明地址中。** 如果路径将资金发送至 t1 或 t3 地址，请在使用前将 ZEC 转入自己钱包中的屏蔽地址。
- **跳过退款地址检查。** 失败的兑换可能退回至你提供的退款地址，且退款不受保证。发送前请检查该地址。
- **将“无需 KYC”理解为“无需检查”。** 大多数服务都会根据合规数据库筛查钱包地址，因此被标记的兑换可能被延迟或阻止。
