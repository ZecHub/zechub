# Zcash 面向创作者的工具 [Tools]：打赏与个人资料平台

> **面向内容创作者、密码朋克和注重隐私 [privacy] 的社区，基于 Zcash 构建的保护隐私的打赏与个人资料工具综合指南。**

## TL;DR

* 两款 Zcash 工具可帮助创作者私密地获得支付 [payment]。Zcash.me 提供一个包含你的屏蔽 [shielded] 地址 [address] 的个人资料页面，而 TIPZ 则让粉丝可以向你发送打赏。
* 使用 Zcash.me 时，你可分享一个链接 `zcash.me/[username]`，其中会显示你的统一地址和社交媒体账户。
* 使用 TIPZ 时，粉丝可以用其他加密货币打赏，而每笔打赏都会以屏蔽 ZEC 的形式到达你手中。
* 这两款工具都会要求提供你的统一地址（`u1...`）。
* 发送至屏蔽地址的打赏可让你的收入和余额不公开显示。

## 核心说明

### Zcash.me

![Zcash.me Logo](/content-images/_unavailable.svg)

#### 概述

**Zcash.me** 是一个个人资料目录和发现平台，让任何人都能轻松找到并向 Zcash 用户发送 ZEC。它是"面向 Zcash 的 Linktree"——一种通过单一链接分享你的屏蔽地址和社交媒体形象的简单方式。

| 项目              | 详情 |
|-------------------|---------|
| **网站**       | [https://zcash.me/](https://zcash.me/) |
| **Twitter**       | [@zcashme](https://x.com/zcashme) |
| **个人资料格式**| `zcash.me/[username]` |
| **状态**        | 已上线（部分功能仍在开发中） |

#### 主要功能

##### 当前可用
- **自定义个人资料页面** - 包含用户名、简介、头像和位置的个性化页面
- **屏蔽地址展示** - 可一键复制你的统一地址
- **社交链接集成** - X、LinkedIn、Telegram 和自定义网站
- **验证系统** - 用于建立社区信任的已验证徽章
- **推荐排行榜** - 追踪顶级推荐人和社区领袖
- **活跃状态** - 显示最后活跃时间。

##### 即将推出
| 功能            | 描述 |
|--------------------|-------------|
| 位置地图       | 查找附近的 Zcash 用户 |
| 平台统计数据| 查看增长指标 |
| 社区投票    | 就生态系统主题进行投票 |
| 新闻与公告 | 官方更新 |
| 论坛              | 社区讨论 |
| 移动应用         | 完整的移动端体验 |

#### 入门指南
1. 访问 [https://zcash.me/](https://zcash.me/) 并点击 **加入**。
2. 选择一个唯一的用户名，添加简介和个人资料图片。
3. 粘贴你的 Zcash 统一地址（`u1...`）
4. 关联你的社交媒体账户。
5. 分享你的链接：`zcash.me/[yourusername]`

### TIPZ

![TIPZ Logo](/content-images/BbXM8cDV_400x400-e6071ba983.webp)

#### 概述

**TIPZ** 是一项专为创作者和密码朋克打造的**私密打赏协议**。粉丝可使用任何主流加密货币打赏；它会自动转换并以**屏蔽 ZEC** 的形式交付。

| 项目              | 详情 |
|-------------------|---------|
| **网站**       | [https://tipz.cash/](https://tipz.cash/) |
| **Twitter**       | [@tipz_cash](https://x.com/tipz_cash) |
| **个人资料格式**| `tipz.cash/@[username]` |
| **状态**        | 已上线 |

> *"tipz.cash 是一项面向创作者和密码朋克的私密打赏协议。"*

#### 为何隐私对创作者至关重要

##### 财务自由
- 0% 平台手续费 [fee]
- 非托管 [custodial] 与自托管
- 没有中间人

##### 隐私优先设计
- 每笔打赏都会以屏蔽 ZEC 的形式到达。
- 私密钱包 [wallet] 余额
- 随打赏附带加密 [encryption] 消息
- 提供完全匿名的创作者选项

##### 跨链 [cross-chain] 支付
| 货币 | 网络 |
|----------|---------|
| ETH      | Ethereum |
| USDC     | 多条链 [chain] |
| SOL      | Solana |
| ZEC      | 直接 Zcash |

##### 创作者保护
- 无平台封禁风险
- 抗审查
- 无需 KYC

## 视觉化 / 类比

咖啡馆柜台上的打赏罐是玻璃制成的。房间里的每个人都能看到是谁投进了一枚硬币，以及罐子有多满。

屏蔽地址就像一个带投递口的上锁邮箱。粉丝将装有硬币和 note 的信封投入其中，只有创作者能够打开这个邮箱。TIPZ 在门口增加了一处货币交易所 [exchange]：粉丝可以带着 ETH 或 SOL 前来，而最终落入邮箱的是 ZEC。

```
TIPZ Payment Flow

Fan -> tipz.cash Protocol -> Creator's Wallet (Shielded ZEC)

Fan selects amount + message -> Protocol auto-converts -> Creator receives private shielded ZEC.
```
