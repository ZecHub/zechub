## TL;DR

* 两款 Zcash 工具可帮助创作者私密地获得报酬。Zcash.me 为你提供一个包含屏蔽地址的个人资料页面，而 TIPZ 让粉丝能够向你打赏。
* 使用 Zcash.me，你可以分享一个链接 `zcash.me/[username]`，展示你的统一地址和社交账号。
* 使用 TIPZ，粉丝可使用其他加密货币打赏，而每笔打赏都会以屏蔽的 ZEC 形式送达你。
* 两款工具都会要求提供你的统一地址（`u1...`）。
* 向屏蔽地址发送打赏可使你的收入和余额不公开显示。

## 核心说明

### Zcash.me

![Zcash.me Logo](/content-images/_unavailable.svg)

#### 概述

**Zcash.me** 是一个个人资料目录和发现平台，使任何人都能轻松找到并向 Zcash 用户发送 ZEC。它相当于“面向 Zcash 的 Linktree”——通过一个链接即可分享你的屏蔽地址和社交资料。

| 项目              | 详情 |
|-------------------|---------|
| **网站**       | [https://zcash.me/](https://zcash.me/) |
| **Twitter**       | [@zcashme](https://x.com/zcashme) |
| **个人资料格式**| `zcash.me/[username]` |
| **状态**        | 已上线（部分功能仍在开发中） |

#### 主要功能

##### 当前可用
- **自定义个人资料页面** - 包含用户名、简介、头像和所在地的个性化页面
- **屏蔽地址展示** - 一键复制你的统一地址
- **社交链接集成** - X、LinkedIn、Telegram 和自定义网站
- **验证系统** - 用于建立社区信任的已验证徽章
- **推荐排行榜** - 追踪顶级推荐人和社区领袖
- **活跃状态** - 显示最后活跃时间。

##### 即将推出
| 功能            | 描述 |
|--------------------|-------------|
| 地图定位       | 查找附近的 Zcash 用户 |
| 平台统计数据| 查看增长指标 |
| 社区投票    | 对生态系统议题投票 |
| 新闻与公告 | 官方更新 |
| 论坛              | 社区讨论 |
| 移动应用         | 完整的移动端体验 |

#### 开始使用
1. 访问 [https://zcash.me/](https://zcash.me/)，然后点击 **加入**。
2. 选择一个唯一的用户名，添加简介和个人资料图片。
3. 粘贴你的 Zcash 统一地址（`u1...`）
4. 连接你的社交账号。
5. 分享你的链接：`zcash.me/[yourusername]`

### TIPZ

![TIPZ Logo](/content-images/BbXM8cDV_400x400-e6071ba983.webp)

#### 概述

**TIPZ** 是一项专为创作者和密码朋克打造的 **私密打赏协议**。粉丝可使用任何主流加密货币打赏；款项会自动兑换并以 **屏蔽的 ZEC** 形式送达。

| 项目              | 详情 |
|-------------------|---------|
| **网站**       | [https://tipz.cash/](https://tipz.cash/) |
| **Twitter**       | [@tipz_cash](https://x.com/tipz_cash) |
| **个人资料格式**| `tipz.cash/@[username]` |
| **状态**        | 已上线 |

> *“tipz.cash 是一项面向创作者和密码朋克的私密打赏协议。”*

#### 为何隐私对创作者至关重要

##### 财务自由
- 0% 平台费用
- 非托管与自托管
- 无中间商

##### 隐私优先设计
- 每笔打赏都会以屏蔽的 ZEC 形式送达。
- 私密钱包余额
- 随打赏附带加密消息
- 可完全匿名创作

##### 跨链支付
| 货币 | 网络 |
|----------|---------|
| ETH      | Ethereum |
| USDC     | 多条链 |
| SOL      | Solana |
| ZEC      | 直接 Zcash |

##### 创作者保护
- 无平台封禁风险
- 抗审查
- 无需 KYC

## 可视化 / 类比

咖啡馆柜台上的小费罐是玻璃制的。房间里的每个人都能看到谁投进了一枚硬币，以及罐子有多满。

屏蔽地址就像一个带投递口的上锁邮箱。粉丝将装有硬币和留言的信封投入其中，只有创作者能打开邮箱。TIPZ 会在门口增加一个货币兑换处：粉丝可以带着 ETH 或 SOL 前来，而落入邮箱的则是 ZEC。

```
TIPZ Payment Flow

Fan -> tipz.cash Protocol -> Creator's Wallet (Shielded ZEC)

Fan selects amount + message -> Protocol auto-converts -> Creator receives private shielded ZEC.
```
