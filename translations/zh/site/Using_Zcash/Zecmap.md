# ZecMap

ZecMap 是一个面向全球、由社区驱动的目录，用于发现接受 Zcash (ZEC) 的商家和服务。它围绕交互式地图界面构建，帮助 ZEC 持有者回答一个实际问题：**“我可以在哪里花掉我的 ZEC？”**

网站：[zecmap.com](https://zecmap.com/)

---

## TL;DR

- ZecMap 是一个**免费、公开的目录**，收录接受 ZEC 的商家——包括本地商户和线上商店。
- 浏览**交互式地图**，查找你附近或世界任何地方支持 ZEC 的商家。
- **任何人都可以提交**商家信息；列表会先经过社区审核，才会公开显示。
- **贡献者奖励计划**会激励用户添加并核实商家数据。
- ZecMap 最近与 [CipherPay](https://x.com/ZecMap/status/2059622324958093616) 达成合作，以扩展商家集成。

---

## ZecMap 的作用

ZecMap 在全球地图上整理接受 Zcash 的商家。每条列表都会显示商家名称、类别、位置或网站，以及接受 ZEC 的方式。这让 ZEC 持有者可以轻松：

- 在出行前找到附近接受 ZEC 的咖啡馆、餐厅、酒店、商店或服务。
- 发现支持 Zcash 支付的线上商店、VPN 提供商、自由职业者或数字服务。
- 按城市、国家或旅行路线浏览不同地区对 Zcash 的采用情况。
- 帮助目录保持最新，让新开始接受 ZEC 的商家及时被收录。

## 使用场景

### 查找本地商家

打开 [zecmap.com](https://zecmap.com/) 并在地图上搜索你附近的商家。前往之前，请先与商家确认他们目前是否接受 ZEC，并询问他们偏好的 wallet 或支付流程。

### 发现线上商店与服务

ZecMap 也收录线上商家。你可以按类别浏览，查找接受 ZEC 支付的电商商店、主机服务、VPN 提供商及其他数字商家。

### 围绕 ZEC 规划旅行

要去一个新的城市或国家旅行？ZecMap 让你在到达前就能查看当地商家覆盖情况，因此你可以提前规划前往支持 ZEC 的餐厅、商店和服务点。

### 支持新的 Zcash 用户

新用户通常会先了解如何购买和存储 ZEC，之后才会发现在哪里可以使用它。ZecMap 提供了下一步——一份可浏览、具有现实用途的 ZEC 商家清单。

## 添加商家

如果某家商家接受 ZEC，但尚未出现在 ZecMap 上，任何社区成员都可以提交。一次优质提交通常包括：

| 字段 | 需提供的内容 |
|-------|----------------|
| 商家名称 | 对外公开使用的官方名称 |
| 网站或联系方式 | URL 或社交媒体主页 |
| 位置 | 线下商家提供地址；线上商家提供所在地区 |
| 类别 | 咖啡馆、餐厅、商店、服务、线上商店等 |
| 证据 | 公开支付页面、商家公告或直接确认 |
| 支付说明 | 线下、线上或两者皆可；透明地址 ZEC 或 shielded ZEC |

提交内容应避免包含私人客户数据。如果使用交易证明，请在分享前移除个人信息、订单编号和家庭住址。

## 验证与批准

列表在公开显示之前会经过审核流程：

1. 贡献者提交一家拥有足够公开信息、可供验证的商家。
2. 审核该条目是否重复以及基本信息是否准确。
3. 通过公开来源或联系商家确认其接受 ZEC。
4. 审核通过的条目会显示在地图上。
5. 社区成员可以标记过时或错误的条目，以便目录保持最新。

由于商家的支付选项可能发生变化，请将这些列表视为社区维护的信息，而不是保证。在出行或进行大额购买前，请先与商家确认。

## 贡献者奖励计划

ZecMap 会奖励那些帮助扩展和维护目录的贡献者。奖励机制旨在鼓励：

- **新条目**——添加接受 ZEC 且尚未出现在地图上的商家。
- **验证**——确认现有条目仍然有效且准确。
- **维护**——更新过时信息或标记已关闭的商家。
- **覆盖扩展**——在代表性不足的城市、地区或线上类别中添加商家。

如需了解当前奖励规则及领取方式，请访问 [zecmap.com](https://zecmap.com/) 或查看 Zcash 社区频道中的 ZecMap 公告。

## 主要功能

- **全球交互式地图**——按位置浏览或搜索商家。
- **商家列表**——包含本地和线上商家及其支付详情。
- **用户账户**——提交条目、追踪贡献并建立贡献者资料。
- **社区审核**——条目上线前会经过检查。
- **举报工具**——标记过时或错误条目，保持地图准确。

## 生态系统集成

ZecMap 接受那些通过 **Flexa** 接收 Zcash 支付的商家。Flexa 是一个被越来越多零售地点使用的支付网络。这使地图上收录的现实世界商家数量超出了原生接受 Zcash 的范围。

ZecMap 还宣布与 [CipherPay](https://cipherpay.app) 达成合作，以深化目录中商家的支付基础设施集成。

## 使用 ZecMap 的提示

- **出发前先确认。** 一定要与商家核实他们当前是否接受 ZEC。
- **检查支付类型。** 有些商家接受透明地址 ZEC，另一些则偏好 shielded。付款前请先询问。
- **帮助社区。** 如果你发现某个条目已经过时或有误，请报告它，避免误导他人。
- **补充你知道的信息。** 如果本地商家接受 ZEC 但未被列出，请提交它——你的本地知识很有价值。
