# 可使用 ZEC 的场所

如今，监控（被 *透明度* 一词掩盖）主要已成为政府和金融界的常态，作为一项人权的隐私似乎被低估了。

不过，在新的金融方式方面，有像 Zcash 这样的人致力于保护你的安全和隐私，因为它们确实很重要。

Zcash 通过 ZEC 同时提供增强的隐私和安全功能。但，采用和使用的第一步始于更多（实体）企业、商店和服务提供者接受 **ZEC** 作为支付选项这一事实。

# 为什么一家公司 / 服务可能希望接受 $ZEC？

如果你拥有一家公司，或者销售任何产品或服务，你可能希望接收 Zcash。为什么？以下是其中一些你可以将其作为支付方式的诸多原因和好处。

- **增强隐私。|** 与知名的传统支付方式不同，Zcash 得益于 zk-SNARKs，通过在 blockchain 上保持交易屏蔽状态（不公开可见），确保你的交易安全且私密；交易中涉及的数据只与发送方和接收方相关（且对二者可见）。
- **更快速、更具成本效益的支付方式。|** ZEC 交易直接进行，无需银行等第三方，因此处理时间更短、费用低于传统支付方式，所以你可以忘掉 Paypal。现在你知道那不是一个 *合适的* 选项。
- **扩大客户群。** | 通过接受 ZEC，你的公司 / 产品或服务可以吸引更广泛的、偏好使用加密货币的人群。
- **促进并提升客户忠诚度。|** 进入这一细分市场并让人们知道你的场所接受 ZEC，能让你在普通和潜在客户中获得优势和偏好；每当他们需要使用 ZEC 时，都会来找你。
- **以 *创新* 之姿脱颖而出。|** 当决定在你的商店、企业中接受 ZEC，甚至作为出租车司机提供服务时，你便可跻身于支持不同金融、支付和消费方式的人群之中。
