# 使用 IPFS 和 Brave 浏览器进行 P2P 文件共享

我们可以使用 IPFS 以点对点（Peer-to-Peer）的方式在彼此之间共享大型媒体文件。

那么问题是什么：IPFS 网关（gateways）无法处理大型文件，它们会超时。

**要求**：[IPFS Desktop](https://docs.ipfs.tech/install/ipfs-desktop/) + [Brave 浏览器](https://brave.com/)

简而言之，视频在最后。

我们可以在 ZF AV Club 成员之间使用它来传输大型媒体文件，并将其记录下来分享给大家，因为它既有趣又非常酷！！

*此外*，我们将直接与 Protocol Labs 的 IPFS 团队合作，以开发这一用例（use case）。
这是在 dWeb Camp 建立联系后带来的另一项好处！

如果接收设备未安装 IPFS，并且使用的浏览器不是 Brave：您将需要等待网关加载文件。*对于大型文件，这将返回 504 错误。*

接下来：如何在您的设备上固定（pin）其他人的文件，以便在原始节点（node）离线时避免单点故障问题。
