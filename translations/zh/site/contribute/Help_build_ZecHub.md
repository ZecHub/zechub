# 帮助构建 ZecHub 

如果您是 Zcash 社区的一员，并且希望为构建 ZecHub 做出贡献，以下几项工作会非常有帮助。

为新闻简报 [newsletter] 策划链接，并将其添加到新闻简报的 GitHub 页面：-> [点击此处查看说明](https://github.com/ZecHub/zechub/blob/main/site/contribute/ZecWeekly_Newsletter.md)

核查 wiki 文档的事实，提出编辑建议，并在 GitHub 中提议新页面

创建以下类别的视频内容：
```
* Zcash explainer videos
* Zcash wallet guide/tutorials
* Third-party application demos
```

为 Zcash & 隐私 [privacy] 生态系统制作海报、图形和动画等设计作品

翻译任意现有的 wiki 页面。

报告问题

### 奖励

ZEC 中的金额并不固定。请使用 [悬赏金额政策](https://bounties.zechub.wiki/docs/bounty-amounts)：为该类工作选择一个美元区间，按现货价格转换，并在面板中填写 ZEC。该政策是唯一的权威依据。

贡献者工作流程和工作类型：[为 ZecHub 做贡献](https://zechub.wiki/contribute/contributing-guide)。
