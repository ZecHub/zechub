# 帮助建设 ZecHub

如果你是 Zcash 社区的一员，并且想为建设 ZecHub 做出贡献，以下这些事情都会非常有帮助。

为新闻简报筛选链接，并将其添加到新闻简报的 GitHub 页面：-> [点击这里查看说明](https://github.com/ZecHub/zechub/blob/main/site/contribute/ZecWeekly_Newsletter.md)

核查 wiki 文档中的事实、提出编辑建议，并在 Github 上提议新页面

创作以下类别的视频内容：
```
* Zcash 讲解视频
* Zcash wallet 指南/教程
* 第三方应用演示
```

为 Zcash 和隐私生态制作海报/图形/动画等设计内容

翻译任何现有的 wiki 页面。

报告 bug

### 奖励

ZEC中的金额并非固定。请遵循[赏金金额政策](https://bounties.zechub.wiki/docs/bounty-amounts)：为相应类别的工作选定一个美元区间，按现货价格换算，然后在看板上填写ZEC。该政策是唯一权威依据。

贡献者工作流程和工作类型：[为 ZecHub](https://zechub.wiki/contribute/contributing-guide) 做贡献。
