# ZecHub 风格指南

ZecHub 风格简洁且亲切。我们欢迎每个人，并专注于 Zcash 社区。

## 原则

1. **随时提供协助** - 向 Zcash 用户表明我们与他们站在一起。

2. **简短且切中要点：** 传达尽可能简单的信息。先说明最重要的内容。

3. **以用户为中心：** 我们首先为用户写作，其次是开发者，最后是其他所有人。

## 基础规则

- **直奔主题**。先说明最重要的内容。将关键词前置，方便快速浏览。清楚说明用户有哪些选择以及下一步该做什么。

- **像说话一样写作**。我们的用户是真实的人。用书面文字与他们交谈。

- **保持简短**。向用户提供足够的信息，以便他们解决问题或作出选择。

- **标题中省略句号**。删除标题、主标题、副标题、UI 标题以及不超过 3 个词的列表项末尾的标点。段落和正文中使用句号。

  - 示例：按下发送按钮->按下发送按钮

- **如有疑问，避免使用大写**。仅将专有名词或像 Zcash 这样的名称大写，以及标题或短语的第一个词大写。

  - 示例：如何使用统一地址发送 ZEC。 → 如何使用统一地址发送 ZEC

- **改写薄弱的表达**。大多数时候，每个陈述都以动词开头。应改写 You can 和 there were。

  - 示例：您可以通过手机发送和接收 ZEC->使用手机发送和接收 ZEC

- **不要留过多空格**。句号和冒号后只使用一个空格。

- **避免使用非英语词汇**，例如 de facto 或 ad hoc。避免使用常见英语短语的拉丁语缩写。

    | 使用此表达    | 不要使用此表达 |
    |-------------|-----------------|
    | 例如 | e.g.            |
    | 即     | i.e.            |

## 推文

> 本通用风格指南适用于为 ZecHub 撰写文章或用户指南。它也适用于推文和其他简短陈述：保持简短，将要点前置，并省略短行末尾的标点。
