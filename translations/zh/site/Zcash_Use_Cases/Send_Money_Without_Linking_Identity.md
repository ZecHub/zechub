# <img src="/content-images/send-svgrepo-com-b62f643de0.svg" width="24" height="24" alt="Journalist icon"/> 在不关联身份的情况下发送资金

<span className="inline-flex items-center gap-[6px]"><span className="inline-block w-[12px] h-[12px] bg-green-500 rounded-full"></span>中级 - 7 分钟</span>

## TL;DR

- 始终从**屏蔽地址 (shielded address)**发送
- 避免直接进行透明到透明的交易
- 打破身份之间的可关联性
- 留意时间和行为模式

<br/>

## <img src="/content-images/user-svgrepo-com-21adf62b7c.svg" width="24" height="24" className="inline-block align-middle mr-1 p-[2px]" alt="user icon"/> 这适合谁？

- 发送敏感支付的任何人
- 重视隐私的用户
- 面临监控风险的人群

## <img src="/content-images/warning-error-svgrepo-com-b7ea8a50da.svg" width="24" height="24" className="inline-block align-middle mr-1 p-[2px]" alt="warning icon"/> 问题所在

发送加密货币通常会暴露：

- 你的钱包身份
- 你的交易历史
- 你与谁互动

这会形成一个**可追踪的金融关系图**。

<br/>

## <img src="/content-images/icons8-lock-2f8e221321.svg" width="24" height="24" className="inline-block align-middle mr-1 p-[2px]" alt="toolbox icon"/> 为什么选择 Zcash？


Zcash 通过屏蔽交易实现**完全私密的转账**。

这能打破：

- 地址可关联性
- 公开交易追踪

<br/>

## <img src="/content-images/icons8-toolbox-9bebbb1619.svg" width="24" height="24" className="inline-block align-middle mr-1 p-[2px]" alt="toolbox icon"/> 你需要准备什么

- 一个支持屏蔽交易的钱包
- 对 z 地址的基本了解

<br/>

## <img src="/content-images/ladder-svgrepo-com-7232bf46ed.svg" width="24" height="24" className="inline-block align-middle mr-1 p-[2px]" alt="step icon"/> 分步指南

### 步骤 1：确保资金已屏蔽

如果你的资金位于透明地址中：

- 请先将其转入屏蔽地址


### 步骤 2：从屏蔽地址发送至屏蔽地址

始终优先选择 `z to z` 交易

这能确保最高级别的隐私。


### 步骤 3：避免身份关联

请勿：

- 公开宣布交易
- 在不同情境中重复使用同一地址
- 将地址与已知身份关联

### 步骤 4：考虑时间模式

高级提示：

- 避免在收到大额资金后立即发送
- 尽可能打破可预测的模式

<br/>

## <img src="/content-images/icons8-cancel-7f786be3c1.svg" width="24" height="24" className="inline-block align-middle mr-1 p-[2px]" alt="cancel icon"/> 应避免的常见错误

- 直接从透明地址发送  
- 在多人之间重复使用地址  
- 公开确认交易  
- 忽视元数据（时间、频率）
