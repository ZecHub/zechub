# 使用屏蔽 [shielded] ZEC 保存记录

## TL;DR

- 屏蔽资金具有隐私 [privacy] 性，但您仍然可以保留清晰、完整的财务记录
- 备忘录 [memo] 可作为账簿中的明细项，例如发票编号或支付 [payment] 用途
- viewing key 让您或您选择的人员（如会计师）能够查看您的历史记录，而不会将其公开
- 您可以汇总任意期间的收入和支出，这正是申报或报税所需的信息
- 这些做法都不会削弱您的隐私，因为由您决定谁能看到哪些信息

<br/>

## 这适合谁？

- 以 ZEC 收款的自由职业者和小型企业
- 需要在保持隐私的同时记账的任何人
- 正在为会计师或报税准备记录的人

<br/>

## 挑战

隐私和记录保存可能看似相互矛盾。如果您的交易 [transaction] 是屏蔽的，金额和地址 [address] 就会对公众隐藏，那么您如何妥善记账，或向会计师展示您的收入？

对于 Zcash 而言，这是一种错误的取舍。屏蔽交易默认会向所有人隐藏您的活动，但 Zcash 也为您提供了工具 [tools]，让您能够按自己的条件向需要这些记录的人披露自己的记录。您可以同时对全世界保持隐私，并向会计师开放。

<br/>

## 备忘录是您的账簿

每笔屏蔽的（z 到 z）交易都可以附带一条加密 [encryption] 的 [备忘录](/using-zcash/memos)。对于记录保存而言，备忘录是您写明支付用途的地方：发票编号、客户名称、项目代码，或诸如"3 月房租"之类的简短说明。

由于备忘录随交易一同传递，且仅相关方可读取，它便成为您账簿中的私密明细项。当您或您的客户在每笔支付中附上清晰的备忘录时，您的交易历史就会变成可用的账簿，而不再是一串缺乏背景的金额列表。

一个简单习惯：与客户约定，始终在备忘录中填写发票编号。之后，将支付与发票进行匹配就会变得简单直接。

<br/>

## 查看您自己的历史记录

要记账，您需要查看自己的活动。您的钱包 [wallet] 持有用于解密屏蔽交易的密钥，因此您的钱包可以向您展示完整情况：日期、金额、哪些是收到的、哪些是发出的，以及附带的备忘录。

这部分内容公众无法看到，但您可以看到，因为这些数据属于您。定期查看历史记录，而不是等到年末才查看，能让您的记录保持准确，也更容易发现错误。

<br/>

## 与会计师共享记录

当您需要让他人查看您的屏蔽活动时，例如会计师或审计师，您不必交出花费密钥，也不必公开任何内容。您只需共享一个 [viewing key](/zcash-tech/viewing-keys)。

完整 viewing key 为只读。它允许持有人查看某个地址的转入和转出交易，包括金额和备忘录，但绝不能让他们转移您的资金。因此，它是可以安全交给会计师的内容。他们能获得恰好所需的可见性，您的资金仍由您控制，而世界其他人依然什么也看不到。

这称为选择性披露 [selective disclosure]，也是屏蔽 Zcash 能够支持诚实记账而非阻碍记账的实用原因之一。

<br/>

## 汇总某一期间

对于大多数申报，您需要一段时间内的总额：本季度收到多少、发出多少、您的净头寸是多少。由于您可以查看自己完整的历史记录，因此可以汇总您选择的任何期间，例如一个月、一个季度或一年。

保持备忘录的一致性会让这更容易，因为您可以按支付用途分组，而不只是按日期和金额分组。

<br/>

## 关于税务的说明

税务规则因国家而异，并且会随时间变化，因此这些是一般信息，并非税务建议。在许多地方，接收或处置加密货币可能会产生税务后果，您可能需要保留关于您收到什么、何时收到以及当时价值的记录。

好消息是，屏蔽 Zcash 不会阻止您履行这些义务。您可以保留完整的私密记录，按照税务机关要求的期间进行汇总，并通过 viewing key 向会计师或税务机关披露这些记录，而无需公开您的活动。如果您不确定自己有哪些义务，请咨询您所在国家的合格专业人士。

<br/>

## 应避免的常见错误

- 跳过备忘录，导致年末只剩金额而没有背景信息
- 对所有事情重复使用同一个地址，这会使区分客户或用途变得更困难
- 等到报税季才查看一整年的历史记录，而不是随时保留记录
- 在会计师只需要只读 viewing key 时共享花费密钥
