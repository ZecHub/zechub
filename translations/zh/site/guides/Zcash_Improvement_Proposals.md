# 什么是 ZIP
Zcash 改进提案（ZIP）是一种设计文档，用于向 Zcash 社区提供信息，或描述 Zcash 及其流程或环境中的新功能。ZIP 应当为该功能提供简明的技术规范以及功能设计依据。

我们希望 ZIP 成为提议新功能、收集社区对某个问题反馈，以及记录融入 Zcash 的设计决策的主要机制。ZIP 的所有者（通常是作者）负责在社区内建立共识，并记录不同意见。

由于 ZIP 以文本文件形式维护在版本化仓库中，因此其修订历史就是该功能提案的历史记录。

-> [zips.z.cash](https://zips.z.cash)


## ZIP 编辑者

每个提交的 ZIP 都必须经过审查流程。ZIP 编辑者的职责是确保任何 ZIP 的格式和内容都能充分说明相关术语、设计依据以及所作出的技术变更。 

```markdown
* Jack Grigg, Kris Nuttycombe and Daira-Emma Hopwood associated with the ECC.
* Conrado, and Arya, associated with the ZF.
* Sam and Mark, associated with SL.
```
