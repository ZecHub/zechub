# 什么是 ZIP
Zcash 改进提案 (ZIP) 是一份设计文档，为 Zcash 社区提供信息，或描述 Zcash 及其流程或环境的新功能 (feature)。ZIP 应提供该功能的简明技术规范和设计理由。

我们希望 ZIP 成为提出新功能、收集社区对某一议题意见，以及记录促成 Zcash 的设计决策的主要机制。ZIP 的负责人（通常是作者）负责在社区内建立共识 (consensus)，并记录不同意见。

由于 ZIP 以文本文件形式维护在版本控制仓库中，其修订历史即为该功能提案的历史记录。

-> [zips.z.cash](https://zips.z.cash)


## ZIP 编辑者

每份提交的 ZIP 都必须经过审查流程。ZIP 编辑者负责确保任何 ZIP 的格式和内容充分说明所涉及的术语、理由和技术变更。

```markdown
* Jack Grigg, Kris Nuttycombe and Daira-Emma Hopwood associated with the ECC.
* Conrado, and Arya, associated with the ZF.
* Sam and Mark, associated with SL.
```
