# Free2Z：账户设置 + 直播教程

## 简介

Free2Z 是一个让创作者和支持者建立联系并实现目标的平台。Free2Z 为创作者提供工具，让他们能够展示才华并为项目筹集资金，同时不牺牲隐私 [privacy]。支持者可以找到并支持他们认同的事业。

## 创建你的账户

目前，有两种方式可以在 Free2Z 上创建账户：  
1. 选择用户名和密码。  
2. 连接你的 Twitter 账户。  

要创建账户或登录，请访问 https://free2z.cash/ 并点击“CREATE”按钮。

![Login/signup form](/content-images/image-2023-11-19-133101013-3ee51e3b6f.webp)

登录/注册表单将显示在你的浏览器中。选择你的用户名和一个强密码——这将是你的登录信息。完成验证码并点击“Enter”按钮以创建账户。

![Username and password entry form](/content-images/image-2023-11-19-133141052-0387984be1.webp)

或者，你可以通过连接你的 Twitter 账户来创建 Free2Z 账户。为此，请点击“Login With”旁边的 Twitter 徽标，随后系统会要求你连接 Twitter 账户。

![Twitter login option](/content-images/image-2023-11-19-133210103-f65246bbee.webp)

点击 **Authorize app**，将你的 Twitter 账户连接到 Free2Z。

## 个性化你的个人资料

账户创建后，你将被重定向至你的 Free2Z 个人资料页面。如果你是通过连接 Twitter 创建账户，大部分字段将自动填写。如果你是通过输入用户名和密码创建账户，则应在此填写你的信息。你可以使用化名而不是真实姓名。

![Default empty profile header](/content-images/default-header-a11eb8328f.webp)

现在的页面相当单调，因此让我们通过设置头像和横幅让它变得更有趣。Free2Z 界面通过上传按钮（右侧的向上箭头）让这一步变得非常简单。

![Avatar and banner upload buttons](/content-images/avatar-and-banner-bd20d0bbfb.webp)

你可以在页面顶部看到结果。

![Profile page after customization](/content-images/resultatpage-f4ddacb8b8.webp)

啊，好多了！如果你具备一些艺术才能，可以让你的 Free2Z 个人资料页面看起来非常出色！为你的页面写一段精彩的描述。你可以介绍自己，或描述他人可以期待从你这里获得的内容类型。（提示：使用 markdown 语法来个性化你的描述！）

![Editing the description field](/content-images/edit-description-b52afabec1.webp)

不要忘记提供你的 Zcash 屏蔽 [shielded] 地址 [address]，这样支持者就可以直接向你捐款！

![Zcash shielded address field](/content-images/p2p-address-b89f035bd9.webp)

完成页面设置的最后一步是设置“Member Price”。这是其他用户订阅你的页面需要支付的 2Zs（Tuzies）价格！（稍后会进一步介绍 2Zs。）

![Member price setting](/content-images/member-price-2dafd7e399.webp)

最后，点击“Update Profile”按钮以完成个人资料设置！

## 订阅和 2Zs

Free2Z 允许用户订阅他们喜爱的创作者，并获得独家功能和仅限会员的内容。创作者应为订阅配置最低 2Zs 金额。  

2Zs 或 Tuzies 是在 Free2Z 中用于多种用途的应用内数字积分，包括：  
1. 订阅创作者  
2. 提升 Free2Z 页面的可见度  
3. 向创作者捐款  

你可以在个人资料页面的页眉中查看你的 2Zs 积分。

![2Zs / Tuzies balance in header](/content-images/tuzis-balance-9d6a9eff7f.webp)

点击你的 2Zs 余额，即可使用 Zcash 购买更多 2Zs。最低购买金额为 0.05 ZEC，当前兑换率为 0.05 ZEC = 10 2Zs。

![Buying 2Zs interface](/content-images/buy-tuzies-e82c626047.webp)

## 捐款和订阅

找到你喜欢的创作者后，你可以通过捐款和订阅来表达欣赏。所有捐款都会直接进入创作者的钱包 [wallet]。例如，让我们订阅 [Free2Z 自己的页面](https://free2z.cash/free2z)。

![Free2Z official page](/content-images/free2z-page-94c5fd5f4f.webp)

要订阅页面，只需点击页面页眉中的订阅图标。

![Subscribe button on creator page](/content-images/subscribe-to-creator-76c306d924.webp)

你将看到订阅所需的最低金额。确认你是否拥有足够的 tuzis，然后点击订阅。

![Confirm subscription popup](/content-images/confirm-subscribe-7381923e36.webp)

### 使用 2Zs 或 Zcash 捐款

你可以通过点击 Fund creator 图标，直接在其页面上捐款。

![Fund creator button](/content-images/fund-creator-ac59aee7bf.webp)

或者，在帖子内部查找浮动加号按钮。你可以在这里向创作者捐款，或在 Free2Z 上推广该帖子。

![Floating action buttons inside a post](/content-images/post-floating-buttons-a1e2ef1102.webp)

## 直播

Free2Z 平台提供了一项很棒的功能，称为 Free2Z Live。借助此工具，创作者可以为已订阅的会员开始直播。一些 Free2Z Live 的主要功能包括：  
- 音频和视频  
- 屏幕共享  
- 协作代码编辑  
- 聊天  
- 白板  
- 以及更多功能！

### 你可以使用 Free2Z Live 做什么

Free2Z Live 是一项强大的工具，允许创作者直播任何类型的内容。以下是你可以使用 Free2Z Live 直播的几类内容示例：  
- 教程和演示  
- 表演和活动  
- 协作项目  
- 现场报道和新闻工作  
- 你的创造力就是唯一的限制！

### 如何开始直播

使用 Free2Z Live 开始直播非常容易。但在开始直播前，有一些要求。  
1. 创作者**必须**设置至少 **10 2Zs** 的**会员价格**。  
2. 创作者账户中**必须**至少拥有 150 2Zs 余额。  

如果创作者满足上述**两个**条件，其个人资料页面上将显示名为 **Go Live** 的图标。

![Go Live button](/content-images/go-live-4c8ac67505.webp)

要开始直播，只需点击 **Go Live** 按钮，Free2Z 应用将请求使用你的麦克风和网络摄像头的权限（如果你有网络摄像头）。授予必要权限后，Free2Z 将要求你输入希望在直播期间使用的昵称。选择昵称后，点击 **Join** 以开始直播。

![Select nickname for live stream](/content-images/select-nickname-414444b992.webp)

完成！当你开始直播时，你的个人资料将显示一个表示你正在直播的图标，因此你的订阅者可以加入直播。

![Joining a livestream](/content-images/join-livestream-679334ba53.webp)

当人们加入直播时，他们可以聊天、申请加入舞台、通过投票互动等。

![Example of a Free2Z Live session](/content-images/free2z-live-example-eecb2ae553.webp)

_（Free2Z Live 会话示例）_

Free2Z Live 功能丰富且强大。在下一节中，我将概述其功能和工具 [tools]。

### 探索 Free2Z Live

本文档并非旨在成为 Free2Z 或 Free2Z Live 的深入指南。但以下是其工具的总体概述。

在屏幕左下角，我们可以看到几个按钮。

![Bottom left controls](/content-images/free2z-live-left-60b450b01c.webp)

这里有一项很好的功能，即共享你的屏幕，让其他用户可以看到你正在做什么。

在底部，我们可以找到直播选项。

![Bottom toolbar](/content-images/free2z-live-bottom-ae64a6960c.webp)

这里的一些主要选项包括：  
- 静音 / 取消麦克风静音  
- 启用 / 禁用网络摄像头  
- 离开舞台  
- 将所有发言者静音  
- 离开  

要结束直播，你应点击“Leave”按钮，然后点击“End meeting for all”，以为所有参与者停止会议。

![Bottom right interaction panel](/content-images/free2z-live-right-c83cb6d209.webp)

右下角的按钮包含与直播互动相关的功能，例如：  
- **Chat**：允许参与者在直播期间彼此聊天，并与主持人聊天。  
- **Polls**：允许主持人创建投票并收集参与者反馈。  
- **List of participants**：显示直播参与者列表。  
- **Plugins**：允许主持人添加插件和扩展，以增强直播体验。

![Plugins panel](/content-images/free2z-live-plugins-e9a30ee355.webp)

本文档的目的并不是解释所有插件，但我确实鼓励你尝试每一个，因为它们都为创作者和观众之间提供了很好的互动价值。要启动插件，只需点击右侧的“rocket”按钮。

## 结论

总之，Free2Z 是一个多功能平台，创作者可以在此展示能力、分享知识、为项目筹集资金，并通过强大的 Free2Z Live 工具与支持者互动。
