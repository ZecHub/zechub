# Nym VPN 

Nym 是一种不断演进的混合网络 (mixnet)，这是一类用于隐私 (privacy) 的计算机网络基础设施，可隐藏用户元数据，将源 IP 地址与目标 IP 地址分离。它可匿名化多种类型的通信，包括消息、文件传输、支付 (payment) 交易 (transaction) 以及在基础网站上的网页浏览。该项目基于免费开源软件构建，并且是去中心化 (decentralized) 的，由全球分布的一组独立节点 (nodes) 维护。Nym VPN & Mixnet 接受以屏蔽 (shielded) ZEC 支付！

### 访问受地域限制的内容

绕过地域限制，访问您所在地区不可用的流媒体服务、网站或内容。

### 增强您在公共 WiFi 上的安全性

在咖啡馆、机场或酒店使用公共 Wi-Fi 时，保护您的数据免受黑客侵害。

### 一体化高级隐私

保护您的隐私  
加密 (encryption) 您的互联网连接，以隐藏您的在线活动，不让互联网服务提供商、广告商和数据追踪者发现。

### 在线保持匿名

隐藏您的 IP 地址，以便在浏览时保持匿名，避免被画像或接收定向广告。

### 避免带宽限速

防止互联网服务提供商在您进行流媒体播放或游戏时降低您的互联网连接速度。

### 防止监控和审查

绕过审查，并在限制严格的国家访问被封锁的网站或社交媒体。

### 保护网上银行

在访问网上银行或进行支付时，保护敏感的财务信息。

### 避免动态定价

隐藏您的位置，避免因航班、酒店或产品所在地而遭受价格歧视。

### 保护您的加密货币交易

通过 NymVPN 的不可关联 (unlinkable) 支付和高级元数据保护，保护您的加密货币活动。
