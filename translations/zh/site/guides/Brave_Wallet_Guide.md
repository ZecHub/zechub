# 如何使用 Brave Wallet 发送和接收屏蔽[shielded] Zcash (ZEC)：分步隐私[privacy]指南

Brave Wallet 是直接内置于 Brave 浏览器中的安全原生加密货币钱包 [wallet]，无需扩展程序。


## 为什么支持屏蔽 ZEC 很重要


Zcash 是少数默认提供屏蔽交易 [transaction] 隐私的加密货币之一。

Brave Wallet 现已支持 Orchard 屏蔽 ZEC，无需第三方软件即可进行私密交易。

用户现在可以发送/接收 ZEC，而无需透露余额或元数据，全部操作均在 Brave 浏览器内完成。

## 第 1 部分：设置 Brave Wallet

**涵盖步骤：**

1. 打开 Brave 浏览器（目前仅支持桌面版）

2. 点击钱包图标，或前往 brave://wallet

3. 设置您的钱包（创建或导入）

4. 访问加密货币仪表板


![img1](/content-images/f54cd1a1-8569-4925-ba1c-7597d030593e-8d83734cd5.webp)


## 第 2 部分：将 Zcash（ZEC）添加到 Brave Wallet

**涵盖步骤：**

1. 在钱包仪表板中，点击 "管理资产"

2. 搜索 ZEC 并启用它

3. ZEC 现在会显示在您的钱包中


![img2](/content-images/6f2b2190-cf55-4394-9d5f-29ff9b5bb525-13d37cb455.webp)


## 第 3 部分：接收屏蔽 ZEC（统一地址）

**涵盖步骤：**

1. 在您的资产中点击 ZEC

2. 选择 "接收"

3. Brave 会生成一个统一地址（UA），该地址同时支持屏蔽和透明交易

4. 复制或扫描二维码

5. 将您的 UA 分享给发送方



![img3](/content-images/53c940b6-1a03-4fa7-aefa-d3478f678a88-23f68a3855.webp)



## 第 4 部分：私密发送屏蔽 ZEC

**涵盖步骤：**

1. 选择 ZEC -> 发送

2. 粘贴收款人的统一地址或屏蔽地址

3. 输入金额

4. 确认交易详情

5. 点击发送，资金现已通过 Orchard pool 私密转移


![img4](/content-images/Internet_20250808_172118_4-e6df0f7fe2.webp)




## 地址类型

以下是每种 Zcash 地址类型的说明：

**t-addr（t1...）** - 透明地址的工作方式与 Bitcoin 地址类似，这意味着交易在 blockchain 上公开可见。它们更易于与非 Zcash 钱包配合使用，但不提供隐私。

**z-addr（zs...）** - 屏蔽地址使用 Zcash 的隐私技术（Sprout/Sapling）隐藏发送方、接收方和金额。只有 viewing key 或所有者可以披露详情。

**UA（u... 或二维码）** - 统一地址将多种地址类型（透明、屏蔽、Orchard）合并为一个地址。这在尽可能优先保障隐私的同时，实现最大兼容性。
