# 网络浏览器 [Web Browsers]

1. **Brave：**当今市场上最知名且最安全的浏览器之一。它会拦截侵犯隐私 [privacy] 的广告和追踪器。它会阻止第三方数据存储。

2. **Mulvad：**一款注重隐私的网络浏览器，由 Mullvad VPN 与 Tor Project 合作开发。其设计旨在尽量减少追踪和指纹识别。

3. **Tor：**该浏览器会拦截 Flash、RealPlayer、QuickTime 等插件：这些插件可能被操纵以泄露你的 IP 地址。我们不建议在 Tor Browser 中安装额外的附加组件或插件。


## 选择网络浏览器时有哪些安全注意事项？

选择网络浏览器时，有几件事需要牢记：安全漏洞和攻击手段通常会被定期发现。某些浏览器在某种程度上可被追踪，但也有允许用户匿名浏览的浏览器——例如 [Tor 浏览器](https://download.torproject.org/)。

**指纹识别 [Fingerprinting]：**如果你希望对机器上安装的软件、硬件配置等信息保持私密，请考虑选择支持抗指纹识别功能的网络浏览器。

**HTTPS 测试 [HTTPS Test]：**选择网络浏览器时，另一项需要注意的安全考量是 HTTPS 测试协议。它有助于加密网站连接，并隐藏 Cookie、URL 及其他类型的敏感元数据。使用 HTTPS 后，连接会被加密，网络中的第三方无法读取服务器与你的浏览器之间传输的内容。

**追踪 Cookie 防护 [Tracking Cookie Protection]：**此外，万维网上的大部分网页都隐藏有第三方追踪器；这些追踪器会读取并写入浏览器中的 Cookie。这些 Cookie 可能构成恶意威胁，因为它们可用于追踪你在不同网站上的浏览活动；为防止这种追踪，请选择会拦截未知浏览 Cookie 的网络浏览器。

**导航测试 [Navigation Test]：**当你从一个网页导航到另一个网页时，会遇到许多链接（有些是内部链接，另一些则链接到其他网站）。当你点击这些链接时，某些浏览器 API 允许第一个网站与第二个网站通信。为解决此问题，请选择在你点击链接时阻止网站共享追踪数据的网络浏览器。当你选择认为可能适合自己需求的浏览器时，请确保它提供强大的隐私功能及内置广告拦截器等必要功能。此外，许多此类网络浏览器支持扩展程序和附加组件，而这些扩展程序有时可能带来安全风险；请务必始终从安全的生态系统或可信来源安装这些扩展程序。
 
## Brave Browser Zcash 钱包 [wallet] 集成

Brave 浏览器正在为 Web3 生态系统铺平道路。如何做到？现在可以利用超过 200 万个不可阻挡域名来展示去中心化 [decentralized] 网站。借助 Brave Browser 强大的安全功能，人们可以在不被追踪的情况下探索互联网。Brave 和 Zcash 正携手为 Web3 生态系统带来新的隐私工具 [tools]。为获得更大益处，Brave 将通过 Brave 的内置加密货币钱包，迅速与 Zcash 协议集成，从而革新加密货币交易 [transaction]——此集成将使用户能够非常轻松地安全存储、发送和接收 ZEC，以及其他加密货币。Brave 网络浏览器与 Zcash 之间的合作将真正改变局面，因为用户将能更好地掌控自己的 Web3 活动。

关于 Brave 浏览器与 Zcash 集成的另一个有趣事实是其私密且去中心化的消息功能；Brave、ECC 和 Filecoin Foundation 团队正在为 Brave 浏览器开辟基于隐私的功能——此次合作旨在通过 Zcash 协议提供私密消息和媒体传输。在此，星际文件系统（IPFS）将在为加密 [encryption] 内容提供安全存储能力方面发挥关键作用。
