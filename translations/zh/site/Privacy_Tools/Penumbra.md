# Penumbra 

Penumbra 致力于成为在 Cosmos 生态系统中竞争的尖端、完全屏蔽的 Layer 1 网络。它使用户能够安全地进行交易、质押和兑换代币，并进行做市，而无需在链上披露其元数据。作为一个完全屏蔽的 blockchain，它还提供不牺牲隐私或去中心化的网页屏蔽交易 — Penumbra 默认提供隐私，没有透明交易或透明价值 pool。

## Penumbra IBC 所使用的技术

IBC 集成：位居首位的是区块链间通信（Inter-Blockchain Communication，IBC）协议，这是一项突破性且创新的技术，可促进 Penumbra 的运作。它对于增强网络内的互操作性至关重要。IBC 还可让不同的 blockchain 网络进行通信和交换数据。此外，IBC 在促进 Penumbra 之间的无缝资产转移、数据共享和交互方面发挥关键作用。这种互操作性和技术可帮助用户轻松地在各种 blockchain 之间转移代币和资产。另一方面，IBC 还有助于扩容，通过加快交易、优化性能并减少 Penumbra 网络中的延迟。

零知识证明（Zero-Knowledge Proofs，ZKPs）：Penumbra 利用零知识证明密码学技术，确保所有交易均得到验证和确认，同时不披露发送方、接收方或转移金额等任何细节。

![image.png](/content-images/_unavailable.svg)

具有隐私的去中心化交易所：Panumbra 网络的核心是隐私。该网络可利用去中心化交易所机制，在保护交易和加密货币交易隐私的同时，保护财务数据，并赋予用户控制其交易策略披露的权利。

## 用例

安全交易：Penumbra 允许用户使用任何加密资产体验屏蔽交易。由于 Penumbra 是一个完全屏蔽的 blockchain，它允许用户私密地进行交易，在资产跨链转移时保护发送方、接收方、金额和资产类型；它确保交易保持私密，未经用户许可不得被追踪或解密。值得一提的是，每个 Penumbra 地址都支持查看功能 — 此构建允许用户选择向其授权的第三方披露活动，以满足合规或其他需求。有趣的是，Penumbra 交易以极快速度运行，且交易手续费低廉。这得益于权益证明共识。 

质押：从宏观角度来看，Penumbra 希望始终位居食物链顶端。作为世界上首个屏蔽权益证明网络，其唯一目的就是确保委托人的隐私和验证者的问责性。Penumbra 提供的另一项引人注目的功能是 PEN 质押代币，它在保障网络安全的同时，赋予代币持有人通过链上投票流程参与项目治理的权利。网络中的每位委托人都会获得一种名为 dPEN 的原生代币。顺便一提，dPEN 会记录在屏蔽池中，并且可以像任何其他资产一样交易。从链上治理的角度来看，网络的未来掌握在利益相关者手中：他们对提案进行投票并参与决策，同时确保项目不受中心化实体控制。 

代币兑换：代币兑换是 Penumbra 的另一个用例。该网络支持任何类型加密资产之间的屏蔽兑换 — 一经提交，所有兑换都会被封存！通过利用 ZSwap，用户可以兑换任何加密资产对，而不会披露交易历史或时间戳等敏感细节，这可能有助于打击金融欺诈。虽然最大可提取价值（Maximal Extractable Value，MEV）常见于透明链，但像 Penumbra 这样的完全屏蔽链不存在 MEV，因为网络交易不会泄露用户活动数据。

做市：完全屏蔽链 — Penumbra，让做市商能够控制其交易策略和特征的信息披露，而不是向全世界公开其全部活动。
