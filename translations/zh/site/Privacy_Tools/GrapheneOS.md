# Graphene OS

## TL;DR

- **GrapheneOS** 是一个专注于隐私 [privacy] 和安全的非营利开源移动操作系统，完全兼容日常 Android 应用
- 核心优势：强化的应用沙盒、内存安全代码与漏洞利用缓解措施、硬件支持的验证启动、精细化权限，以及设备锁定时的 USB-C 端口保护
- 可通过官方 **WebUSB 安装程序**进行安装（推荐大多数用户使用），技术用户也可使用**命令行流程**
- 对于 Zcash 用户而言，它是移动端自托管的坚实基础：将其与持续维护的屏蔽 [shielded] 钱包 [wallet] 及标准 OPSEC 安全习惯结合使用

GrapheneOS 是一个致力于提升移动设备隐私和安全，同时保持与 Android 应用兼容性的非营利开源项目。该操作系统高度重视推进隐私和安全技术，尤其专注于加强沙盒机制、漏洞利用缓解措施和改进权限模型。它于 2014 年以 **CopperheadOS** 之名诞生，此后已发展成为守护您数字隐私和安全的强大卫士。

GrapheneOS 的主要目标是在不损害用户体验的前提下，加强安全边界，例如应用沙盒。

GrapheneOS 可为特定功能引入各种开关，例如网络权限、传感器权限，或设备锁定时的限制（涵盖 USB 外设、相机访问和快捷设置磁贴等方面）。此外，更复杂的面向用户的隐私和安全功能经过周密设计，以维持易用的体验，并各自配有用户界面增强功能。

## **GrapheneOS 的功能**

**安全强化** GrapheneOS 包含广泛的安全增强功能，例如内存安全编程语言和基于编译器的安全功能，以减少常见漏洞。

**沙盒机制** 它强化了应用沙盒机制，以隔离各个应用，从而限制潜在攻击途径。

**验证启动** GrapheneOS 使用硬件支持的密钥和可验证的启动流程，以确保操作系统的完整性。

**增强权限** 它为应用权限提供了更完善的控制，使用户能够精细调整和管理应用可访问的数据。

**隐私仪表板 [dashboard]** 用户可通过隐私仪表板监控和控制应用行为，从而了解数据使用情况。

**内置安全更新** GrapheneOS 提供及时的安全更新，确保用户获得针对漏洞的最新保护。

**强加密 [encryption]** 它默认采用全磁盘加密，保护存储在设备上的数据。

**改进的浏览器安全性** 默认浏览器经过配置以增强安全性，包括防跟踪保护。

**预装应用极少** GrapheneOS 仅预装极少量应用，降低潜在的安全和隐私风险。

**USB 恶意端口保护** 设备锁定时，它可防止他人通过 USB 端口未经授权访问设备。

**反恶意软件保护** GrapheneOS 包含用于检测和阻止已知恶意软件的功能。

**专注于隐私** 该操作系统的设计高度重视用户隐私，尽可能减少数据收集和暴露。

**开源** 这是一个开源项目，能够实现透明度，并允许社区贡献以提升安全性。

**可自定义的安全策略** 用户能够根据自身偏好自定义各种安全策略。

**兼容性** GrapheneOS 致力于保持与 Android 应用的兼容性，使用户能够继续使用自己喜爱的应用，同时受益于增强的安全和隐私功能。

## **安装 GrapheneOS**

如最佳实践部分所述，建议使用推荐的官方安装指南。安装 GrapheneOS 有两种方法：使用基于 [WebUSB 的安装程序](https://grapheneos.org/install/web)，或使用 [命令行安装指南](https://grapheneos.org/install/cli)

**基于 Web USB 的安装** 要使用 Web 安装程序方法安装 GrapheneOS，您通常需要以下材料和资源：

- 2GB 可用内存和 32GB 可用存储空间。
- USB 线缆（A 或 C）
- 使用受支持的主机操作系统 [host operating system] 和具备可用 WebUSB 支持的浏览器。请查看当前 [官方 WebUSB先决条件](https://grapheneos.org/install/web#prerequisites)，以了解受支持的版本和浏览器打包限制；较旧、已结束生命周期的系统不受官方支持。
- Web 安装程序也可从受支持的 Android 设备、ChromeOS 或 GrapheneOS 运行。请遵循官方指南中针对浏览器的说明，而不要假定每个 Chromium 软件包都支持 WebUSB。

请通过下方链接查看安装指南，并按照安装流程操作

[GrapheneOS Web 安装程序指南](https://grapheneos.org/install/web#prerequisites)

**命令行安装** 不建议不具备技术背景的用户使用命令行安装，且命令行安装需要以下工具和资源；

- 您应至少拥有 2GB 可用内存和 32GB 可用存储空间
- USB 线缆（A 或 C）
- 使用 [当前命令行先决条件](https://grapheneos.org/install/cli#prerequisites) 所支持的主机操作系统，并按照该指南准备所需工具。
- Android、ChromeOS 和 GrapheneOS 主机应使用 Web 安装程序；它们未被列为支持命令行安装的主机。

请通过下方链接查看安装指南，并按照安装流程操作 

[命令行安装](https://grapheneos.org/install/cli#prerequisites)

## **最佳实践**

**保持操作系统最新** 定期更新 GrapheneOS，确保您拥有最新的安全补丁和增强功能。

**使用强密码** 为设备加密和应用登录设置强度高且唯一的密码，以防止未经授权的访问。

**应用权限** 仔细审查和管理应用权限，仅授予每个应用正常运行所必需的权限。

**定期备份** 定期备份您的数据，以防设备丢失或数据损坏。

**加密存储空间** 如果默认未启用，请加密设备存储空间，以便在设备丢失或被盗时保护您的数据。

**安全锁定屏幕** 使用安全锁定屏幕，例如 PIN、密码或生物识别认证，以防止未经授权的访问。

**安装后重新锁定引导加载程序** 官方安装流程要求 [暂时解锁引导加载程序](https://grapheneos.org/install/web#unlocking-the-bootloader) 以刷写 GrapheneOS，随后在使用前 [再次将其锁定](https://grapheneos.org/install/web#locking-the-bootloader)，以启用完整的验证启动。解锁和重新锁定均会清除所有用户数据，因此请先备份，并按顺序遵循官方步骤。请勿 root 已安装的操作系统。

**验证应用来源** 验证应用及其来源的真实性，避免安装恶意软件。

**安装注重隐私的浏览器** 为实现安全浏览，可考虑使用注重隐私的浏览器，例如 Brave 浏览器、Firefox 或 Bromite。

**定期审计应用** 定期审查并卸载您不再使用或不再信任的应用，以减少攻击面。

**启用双因素认证（2FA）** 为您的在线账户启用 2FA，以增加一层额外安全保障。

**避免公共 Wi-Fi** 连接公共 Wi-Fi 网络时应保持谨慎，因为其安全性可能较低。必要时请使用 VPN。

**谨慎处理位置数据** 限制应用的位置追踪；若您重视隐私，可考虑使用位置欺骗工具。

**避免未知链接和附件** 警惕未经请求的链接和电子邮件附件，因为它们可能是网络钓鱼攻击或恶意软件。

**审查默认设置** 仔细审查并调整默认设置，使其符合您的隐私偏好。

**社区支持** 参与 GrapheneOS 社区和论坛，获取提示、更新和安全建议。您可以点击 [这里](https://grapheneos.org/contact) 联系团队并保持更新，以了解更多联系方式。

**使用官方安装方式** GrapheneOS 提供两种官方支持的安装方法。用户可选择推荐大多数人使用的基于 WebUSB 的安装程序，或遵循为更具技术倾向的用户量身定制的命令行安装指南。

## **结论**

本质上，GrapheneOS 旨在提供一种优先保护用户隐私和安全的替代移动操作系统，使用户能够更好地掌控自己的数字生活，同时保持与其依赖应用的兼容性。这是一个致力于在隐私和安全至关重要的时代，为移动设备安全和隐私树立高标准的项目。
