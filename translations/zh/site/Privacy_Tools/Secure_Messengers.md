# 安全即时通讯工具 (Secure Messengers)

## 端到端加密 (End-to-end encryption)

对于安全即时通讯工具而言，端到端加密是一种保障对话安全的方法。当消息从一台设备传送到另一台设备时，任何人都无法读取相关消息，包括你用于发送消息的通讯应用以及第三方。此外，许多具有开创性且知名的消息服务提供商，如 Facebook、WhatsApp 和 Zoom，已经在使用端到端加密技术。

## 为什么需要 E2EE？

为了获得更大的益处，端到端加密技术在需要数据安全的场景中发挥着关键作用，包括但不限于金融、通信和医疗保健行业。它使组织能够轻松遵守数据隐私 (privacy)、安全法规及法律。

**数据隐私**：借助端到端加密，只有消息或数据的预期接收者能够访问并解密它。这意味着即使是 Facebook 和 WhatsApp 等消息服务提供商也无法读取内容。对于不希望敏感信息被泄露的用户和组织而言，这种高度的数据隐私至关重要；这些信息可能包括金融交易 (transaction)、商务通信，或需要防止未经授权访问的私人聊天内容。

**数据安全**：这种强大的技术能够保护传输中或静态存储的数据免受潜在泄露的影响。
当数据通过服务器或互联网传输时，会暴露于许多使其容易遭受未经授权访问者（如黑客）拦截的因素。借助端到端加密技术，传输的数据可能被拦截，但只要发送者或接收者不持有加密 (encryption) 密钥，其内容便仍然无法读取。这有望降低数据泄露的程度，同时确保个人和组织的通信安全。

**信任与用户控制**：借助端到端加密，个人和组织能够自由通信，因为他们知道自己的消息、文件和其他敏感信息不会遭到未经授权的访问。同样，这项技术有助于保护个人和组织免受政府干预和监控。

### 一些热门的安全即时通讯工具

**Zcash 加密备忘录 (Encrypted Memos)**

Zcash 支持屏蔽备忘录的钱包允许用户在屏蔽支付中附加加密消息。每个屏蔽输出都有各自的 512 字节备忘录字段；这并不是整笔交易共用的单一 512 字节额度。有关文本格式和钱包支持情况，请参阅[备注](/using-zcash/memos)。交易手续费以 ZEC 支付，[ZIP 317](https://zips.z.cash/zip-0317) 定义了一种取决于交易复杂度的常规手续费。以美元计的费用也会随 ZEC 汇率变化，因此无法保证手续费低于 1 美分。发送前请查看钱包给出的手续费报价。消息送达取决于交易传播、确认策略以及接收方钱包的同步情况；它并不是即时聊天。

试试看：https://z.cash/wallets

**Signal 应用**

![Signal App](/content-images/signal-app-logo-scaled-454032876-81b24a0421.webp)

Signal 私密即时通讯工具是一款将数据隐私提升至极致的安全通讯应用。Signal 私密即时通讯应用免费且易于使用，用户无需具备任何经验。Signal 应用采用端到端加密技术，确保你的通信完全私密。任何希望安全发送私密消息的人都应考虑使用 Signal 私密即时通讯应用，因为它能显著降低你的网络安全漏洞和数据足迹。

试试看：[https://signal.org/download/](https://signal.org/download/)

**BisonRelay**

![Bison Relay](/content-images/ogimg-v1-1000556235-9390372d1e.webp)

Bison Relay 应用于 2022 年首次推出。Bison Relay 不依赖用户拥有账户——令人难以置信！在这里，每条发送和接收的消息都会通过 Decred Lightning Network 单独付费。该应用的唯一目的是完全消除对账户的需求，同时尽量减少元数据。另一方面，Bison Relay 终结了通常实施审查的方式。

试试看：[https://bisonrelay.org/download](https://bisonrelay.org/download)

**Session 应用**

![Session App](/content-images/logo-black-9e799f2b06.webp)

如果你还不了解 Session 应用，不必担心！以下是简要介绍：Session 是颇具竞争力的端到端加密即时通讯工具之一。该应用旨在尽量减少敏感元数据。Session 应用面向希望获得绝对隐私并摆脱任何形式监控的个人而设计。在 Session 应用中，用户无需电话号码或电子邮件地址即可创建账户，这意味着它完全匿名。用户可以通过其网络安全地发送消息而不留下任何痕迹，因此没有任何内容会泄露。

试试看：[https://getsession.org](https://getsession.org)

## 总结

端到端加密非常重要，因为它能促进强大的隐私保护、从根本上强化数据安全，并让用户在信息跨网络和设备传输时仍能完全掌控自己的信息，从而解决数字时代的关键问题。
