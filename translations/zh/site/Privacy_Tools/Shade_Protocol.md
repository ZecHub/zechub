# Shade Protocol

![Shade Protocol Logo](/content-images/Af8EzlNiwGr4FTFX7oqdBuE-71316827d0.webp)

## 什么是Shade Protocol？

Shade Protocol是一个注重隐私（privacy）保护的 DeFi（去中心化金融）生态系统，旨在提供一系列金融产品，同时确保用户隐私和安全。Shade Protocol构建于 Secret Network 之上，专注于打造以隐私为中心的金融环境，为用户提供稳定币、合成资产、借贷平台等工具。Shade Protocol的旗舰产品是 Silk Stablecoin，它将隐私功能与价格稳定性相结合。

## 所用技术

**Secret Network**

Shade Protocol构建于 Secret Network 之上，这是一个提供隐私保护智能合约的第 1 层 blockchain。Secret Network 使用加密的输入、输出和状态来确保交易隐私，保护用户数据不在公共账本上暴露。

![Secret Network Diagram](/content-images/1-yyZ5hFOw6z8zXX_rgJn5iw-9091067aa1.webp)

Secret Network 使开发者能够构建具有加密数据的去中心化应用，既可原生部署在 Secret 上，也可通过跨链通信部署在其他 blockchain 上，为Web3解锁强大的新用例。

**Cosmos SDK 和 Tendermint Core**

Cosmos通过定义更好、更现代的构建方式，并使用 Tendermint 和Cosmos SDK 等新工具创建这些 blockchain，从而实现异构 blockchain 的互连。  
该协议使用Cosmos SDK，这是一个用于构建可扩展且可互操作的 blockchain 应用的模块化框架。这使Shade Protocol能够受益于Cosmos生态系统的稳健性和互操作性。

![Cosmos SDK and Tendermint Core Diagram](/content-images/83dfbb311bfd6ce22d1c9468160d8e33b4c5ce8e-ed16bb7658.webp)

在共识和网络安全方面，Shade Protocol采用 Tendermint Core，其提供拜占庭容错（BFT）共识，确保高安全性和快速终局性。

**隐私保护去中心化金融**

隐私保护 DeFi 利用加密交易、零知识证明和私有智能合约等先进密码学技术，在 blockchain 网络上维护用户隐私和数据机密性。通过使用 Secret Network 的 secret contracts 及Cosmos SDK 等技术实现互操作性，这些解决方案支持机密交易、私有资产管理和选择性披露，确保金融活动保持安全并符合隐私法规。这种方法保护用户免受追踪和欺诈，在遵守隐私标准的同时提供去中心化金融自由。

## 应用

**Shade 和 Silk 代币**

Shade Protocol为其两种主要代币使用 viewing key：Shade ($SHD) 和 Silk ($SILK)。Shade ($SHD) 在生态系统中承担多种角色，充当金库、治理和收益分配代币。它用于质押、治理提案、流动性提供、交易和 bond。另一方面，Silk ($SILK) 是该协议专注于隐私的稳定币，与由黄金、Bitcoin、USD、欧元和日元等全球多种货币及商品构成的篮子挂钩。

### 隐私

用户可能偏好Shade Protocol的主要原因之一是其提供的隐私。Shade 上的交易对公众屏蔽，确保金融数据保持机密。与交易详情对所有人可见的传统公共 blockchain 不同，Shade Protocol代币使用加密的输入、输出和状态，这意味着敏感信息不会被窥探者发现。这增强了用户隐私和安全性，使个人能够在不暴露个人信息或交易历史的情况下参与金融活动，从而防范潜在威胁并维护金融机密性。

### 稳定价值

Silk Stablecoin 提供价格稳定性，这对于希望避免通常与加密货币相关的波动性的用户至关重要。Silk 与一篮子资产挂钩，有助于长期维持其价值。每种稳定币都从特定来源获得价值，通常与美元挂钩。然而，这种方法带来了重大且往往未被察觉的风险。Silk 通过在全球波动中保持稳定，而不依赖美元等单一价值锚定来缓解这些风险。相反，Silk 的价值基于一个称为 Silk Currency Basket 的加权指数。该篮子包括全球货币（USD、CAD、EUR、JPY）以及 Bitcoin 和黄金等商品。通过纳入多种货币和资产，Silk 相较于单一货币实现了更高的锚定稳定性。广泛的研究和测试表明，黄金和 Bitcoin 作为可靠的价值储存手段，表现优于传统货币，这证明了将它们纳入该篮子的合理性。

### 去中心化

作为 DeFi 平台，Shade Protocol在没有中央控制的情况下运行，为用户提供金融自主权。Shade Protocol的去中心化治理使其代币持有者社区能够直接参与决策过程。代币持有者可以提出变更建议、对倡议进行投票，并为协议的发展和方向作出贡献。这确保控制权分散于多元化的利益相关者群体，而非由中央机构持有。通过利用 blockchain 技术，治理过程透明、安全且不可篡改，从而培育出更具包容性和韧性的生态系统。

### 互操作性

作为Cosmos生态系统的一部分，Shade Protocol可以轻松与其他 blockchain 交互，增强流动性，并为用户提供更多机会在不同网络中利用其资产。通过利用 Secret Network 的隐私保护技术，Shade Protocol确保这些跨链活动保持机密性和完整性。这种互操作性不仅增强了去中心化应用的灵活性和功能性，也促进了一个更加互联且稳健的 blockchain 生态系统，减少对孤立网络的依赖，并推动去中心化金融解决方案的更广泛采用。

## 结论

Shade Protocol是 DeFi 领域的开创性项目，提供构建于稳健技术之上的隐私导向金融解决方案。通过提供具备隐私功能的稳定币并开发全面的金融工具套件，Shade Protocol旨在服务重视安全性、稳定性和去中心化的用户。

Shade Protocol的凝聚力和价值捕获原则为稳定性及无缝用户体验提供了坚实基础，使其有望成为未来 DeFi 协议的领导者。凭借自适应、可扩展的治理，以及引入新Shade Protocol原语的明确路线图，其快速增长的潜力无疑极为巨大。
