### 由曲线上的点构成的单向通道 [one-way street]

> **系列：** *Zcash 从第一性原理出发*。**文章 2：椭圆曲线**
> **读者：** 新手。我们只假设你了解 [文章 1（有限域）](article-1-finite-fields.md)：围绕一个质数取模循环的算术。不需要其他背景知识。
> **你将收获：** 对椭圆曲线、使其有用的"陷门"，以及 Zcash 如何将它们转化为密钥和 commitments 的直观且正确的理解。

[文章 1](article-1-finite-fields.md) 为我们提供了完美的算术游乐场：有限域 [finite field]。但域本身只是数字。为了构建 [文章 0](article-0-shielded-transaction.md) 中的密钥和"密封信封"，Zcash 需要一种具有特殊单向难度的对象：正向计算容易，逆向几乎不可能。这个对象就是**椭圆曲线 [elliptic curve]**。本文将从头开始构建它，先讲直觉，再讲代数。

---

## 1. 为什么你应该关心？

每个隐私 [privacy] 系统都需要一条**单向通道**：正向操作轻而易举，反向操作实际上不可能完成。

原因如下。你的**秘密密钥 [secret key]**是一个你必须保密的数字。你的**公钥 [public key]**（以及你的地址 [address]）由它派生，并向全世界展示。整个系统的安全性取决于一个事实：*给定公钥，任何人都无法逆向推导出你的秘密密钥。* 如果可以，他们就能花费你的资金。

因此，我们需要一种数学运算，其中：

- **正向**进行（秘密 -> 公开）快速且容易，但
- **反向**进行（公开 -> 秘密）极其困难，即使地球上的所有计算机工作到宇宙寿命终结也无法完成。

普通的有限域乘法并不够好；除法可以立即撤销它（这正是文章 1 的重点）。我们需要没有简单"撤销"按钮的东西。椭圆曲线恰好提供了这一点，而且额外的好处是，它们的点可以通过非常适合构建 commitments 的方式组合。让我们看看它是如何做到的。

---

## 2. 直觉：其点可以"相加"的曲线

暂时忘掉密码学。**椭圆曲线**只是满足某种形式方程的一组点 [points] `(x, y)`：

```
y^2 = x^3 + ax + b
```

在普通数字上，它看起来像一条平滑、起伏的曲线，通常带有一个圆润的环和两条尾部：

![alt text](/content-images/image-14-1d2e8c25d2.webp)

真正令人惊讶的是：**你可以将这条曲线上的两个点"相加"，得到同一条曲线上的第三个点。** 这不是普通的坐标相加。它是一条几何规则，*看见*它比说出来更容易。

### 弦规则（相加两个不同的点）

要计算 `P + Q`：

1. 画一条穿过 `P` 和 `Q` 的直线。
2. 这条直线会在恰好另一个位置与曲线相交。将其称为 `R*`。
3. **将 `R*` 关于水平轴反射。** 这个反射点就是答案，即 `P + Q`。

![alt text](/content-images/image-11-61f3df1989.webp)

### 切线规则（将一个点加到自身）

要计算 `P + P`（写作 `2P`），没有第二个点可供画线，因此改用 `P` 处的**切线 [tangent]**，然后遵循同样的"第三个交点，再反射"步骤。

这就是完整的运算。两条几何规则。有了它们，椭圆曲线的点构成了数学家所说的一个**群 [group]**：一个具有良好性质的"加法"的集合。它甚至还有一个"零"。

### 无穷远点（曲线的零）

每个数系都需要一个 `0`，即与它相加时不会改变任何东西的元素。在椭圆曲线上，这一角色由一个特殊的额外点承担，称为**无穷远点 [point at infinity]**，写作 `O`。你可以将它想象成"无限远的上方"，即垂直线相交的地方。将 `O` 加到任何点上都不会改变该点，就像加上 `0` 一样。

## 3. 从图像到有限域

上面的平滑曲线只是*直觉*。但 Zcash 不使用实数（根据文章 1，它们会舍入并泄露大小）。它使用**有限域上的椭圆曲线**：同一个方程 `y^2 = x^3 + ax + b`，但所有算术都对一个质数取模进行。

这样做时，这条漂亮的曲线会碎裂成一片**彼此断开的散点**，每个满足模 `p` 方程的 `(x, y)` 对对应一个点。它看起来根本不再像一条曲线。但关键在于：

> **弦与切线规则的代数仍然完美成立。** 曾经通过几何方式求出 `P + Q` 的相同公式，现在可以用有限域算术计算它。这些点仍然构成一个群，具有相同的 `0`（无穷远点）。

让我们用一个微小、经过完整验证的例子来具体说明。

### 一条完整曲线，精确计算

取有限域 `F_17` 上的 `y^2 = x^3 + 2x + 2`。计算所有有效点后，恰好得到**18 个点，加上无穷远点 = 共 19 个。** 其中几个如下：

```
(0,6) (0,11) (3,1) (3,16) (5,1) (5,16) (6,3) (6,14) (7,6) (7,11) ...
```

现在选择点 `G = (5, 1)`，并不断将它加到自身。看看会发生什么（下面每一行都是计算得出，而非猜测）：

| 步骤 | 点 | 步骤 | 点 |
|---|---|---|---|
| `1G` | (5, 1) | `11G` | (13, 10) |
| `2G` | (6, 3) | `12G` | (0, 11) |
| `3G` | (10, 6) | `13G` | (16, 4) |
| `4G` | (3, 1) | `14G` | (9, 1) |
| `5G` | (9, 16) | `15G` | (3, 16) |
| `6G` | (16, 13) | `16G` | (10, 11) |
| `7G` | (0, 6) | `17G` | (6, 14) |
| `8G` | (13, 7) | `18G` | (5, 16) |
| `9G` | (7, 6) | `19G` | **O（无穷远）** |
| `10G` | (7, 11) | | |

有两件事值得注意：

- 它**遍历了全部 18 个有限点，然后在第 19 步落在 `O`**，之后将永远重复。起始点 `G`"生成"整个群，因此我们称其为**生成元 [generator]**。
- 这是一个经过验证的群：例如 `1G + 2G = (5,1) + (6,3) = (10,6)`，这恰好等于 `3G`。加法在内部是一致的，正如群所要求的那样。

## 4. 陷门：标量乘法 [scalar multiplication]

这张 `1G, 2G, 3G, ...` 表是所有内容的核心。反复将一个点加到自身称为**标量乘法**：点 `kG` 表示"将 `G` 自加 `k` 次"。

现在魔法来了。考虑两个方向：

| 方向 | 问题 | 难度 |
|---|---|---|
| **正向** | 给定 `k` 和 `G`，计算 `kG` | **容易。** 即使 `k` 大到天文数字，名为*倍增加法 [double-and-add]*的技巧也能在几百步内完成 |
| **反向** | 给定 `G` 和 `kG`，恢复 `k` | 在真实的密码学曲线上**实际上不可能** |

这种不对称性就是我们在第 1 节需要的**单向通道**。反向问题（"哪个 `k` 产生了这个点？"）称为**椭圆曲线离散对数问题 [Elliptic Curve Discrete Logarithm Problem, ECDLP]**，而在 Zcash 使用的曲线上，没有已知方法能在宇宙热寂之前解决它。

![alt text](/content-images/image-12-86b9ace6cb.webp)

> 在我们的玩具 `F_17` 曲线上，你*可以*直接从表中读出 `k`，因为它只有 19 个点。真实曲线大约有 `2^(255)` 个点。这张表的行数会比宇宙中的原子数还多，因此"直接读出"不是一个选项。规模小使玩具曲线易于教学，也正是它不安全的原因。

## 5. 密钥如何诞生（回报）

我们现在拥有解释真正密码学密钥所需的一切，而且它简单得令人惊讶：

> **选择一个秘密数字 `k`。公开点 `kG`。就这么简单。**
> `k` 是你的**私钥 [private key]**。`kG` 是你的**公钥**。单向通道（ECDLP）确保没有人能将 `kG` 逆向推回 `k`。

这个单一理念，即*公钥是秘密标量乘以固定生成元*，是 Zcash 的花费密钥、viewing key 和地址的种子。完整的密钥树在其上叠加了更多结构，但每一条分支都从这条根生长而来。

### 补充：为什么曲线点能构成完美的 commitments

回想一下文章 0 中的"密封信封"（commitment），它必须**隐藏**其内容，同时又**不可能被伪造**。椭圆曲线为我们提供了一种清晰的构建方式。取两个固定的公开生成元点 `G` 和 `H`、一个秘密值 `v`，以及一个随机盲化数字 `r`，并构造：

```
Commitment  =  v.G  +  r.H
```

这是一个**Pedersen commitment**，它具备我们想要的两种性质：

- **隐藏性 [Hiding]：** 随机的 `r` 将结果扩散到整条曲线上，因此该点不会透露任何关于 `v` 的信息。
- **绑定性 [Binding]：** ECDLP 使得找到产生同一点的*不同* `(v, r)` 不可行，因此你无法改变自己所 commitment 的内容。

一个额外性质后来变得无比宝贵：这些 commitments 可以**相加**。对 `v_1` 的 commitment 加上对 `v_2` 的 commitment，仍然是对 `v_1 + v_2` 的有效 commitment。这种"同态 [homomorphic]"行为使得 Zcash 能在以后证明流入交易的资金等于流出交易的资金，同时不透露任何金额。我们将在大约文章 6 中运用它。

## 6. 它在 Zcash 中的位置

这些痕迹是具体且可验证的。

| Zcash 设计 | 使用的曲线 | 角色 |
|---|---|---|
| **Sapling**（较旧） | **BLS12-381** 加上一条称为 **Jubjub** 的嵌入曲线 | BLS12-381 承载证明系统；Jubjub 构建在 BLS12-381 的标量域上，因此密钥和 commitment 操作可以在零知识证明内部廉价执行 |
| **Orchard**（当前） | **Pallas** 和 **Vesta**（"Pasta" 循环） | Pallas 承载 Orchard 的密钥和 commitments；Pallas/Vesta 配对经过特别安排，使高级证明高效 |

为什么一条曲线会被"嵌入"另一条曲线的域中，以及为什么两条曲线的*循环*很有用，都是实际且重要的问题，但它们属于证明系统文章。现在的结论已经很明确：**每个 Zcash 密钥都是一个标量乘以生成元，每个 Zcash commitment 都是曲线点之和**，它们位于这些具名曲线之一上。

## 7. 坦诚的说明

为保持易读性，我们做了一些简化。我们使用了**短 Weierstrass**形式（`y^2 = x^3 + ax + b`）；Zcash 的曲线通常以其他等价形式表示（Jubjub 是一条*twisted Edwards* 曲线），这些形式出于效率和安全性而选择，但群的理念是相同的。我们没有定义精确的点加法公式（它们是"第三个交点，再反射"的代数版本），也搁置了曲线阶、余因子和"配对 [pairings]"等细节，它们会在证明系统文章中变得重要。这些都不会改变直觉；它们会使其更加精确。

## 8. 总结

- 隐私系统需要一条**单向通道**：正向容易，反向不可行。椭圆曲线提供了这种通道。
- **椭圆曲线**是满足 `y^2 = x^3 + ax + b` 的点集，其点可以通过几何**弦与切线 [chord-and-tangent]**规则进行**相加**，其中特殊的**无穷远点**充当零。
- 在**有限域**上，曲线变成一片散点，但相同的加法仍然有效，点构成一个**群**。（已验证示例：`y^2 = x^3 + 2x + 2` 上的 `F_17` 有 19 个点，而 `G = (5,1)` 生成全部点。）
- **标量乘法** `kG` 易于计算，但难以逆转：即 **ECDLP**。这就是陷门。
- **密钥：**私钥 `k`，公钥 `kG`。**Commitments：**Pedersen 形式 `v.G + r.H`，它隐藏、绑定，并可方便地**相加**。
- 在 **Zcash** 中，Sapling 使用 **BLS12-381 + Jubjub**，而 Orchard 使用 **Pallas/Vesta（Pasta）**曲线；每个密钥和 commitment 都位于这些曲线上。

## 术语表

| 术语 | 通俗含义 |
|---|---|
| **Elliptic curve** | 满足 `y^2 = x^3 + ax + b` 的点，具有特殊的点"加法" |
| **Point addition** | 弦与切线规则：穿过两个点的直线，取第三个交点，再反射 |
| **Point at infinity (`O`)** | 曲线的"零"；将它加上不会改变任何东西 |
| **Generator (`G`)** | 其倍数最终覆盖整个群的基点 |
| **Scalar multiplication (`kG`)** | 将 `G` 自加 `k` 次；正向容易，逆向困难 |
| **ECDLP** | 从 `kG` 恢复 `k` 的困难问题；安全性的基础 |
| **Pedersen commitment** | `v.G + r.H`；一种可以隐藏、绑定和相加的密封信封 |

## 常见问题

**为什么不只使用模质数的大数字，而要使用曲线？**  
两者都可以提供单向通道，但椭圆曲线能以小得多的密钥和更快的操作达到相同安全性，而且其点算术非常适合 commitments。

**ECDLP 被证明是困难的吗？**  
它并没有被*证明*不可能，但数十年的密集努力并未在精心选择的曲线上发现高效攻击。安全性建立在这个经过充分检验的假设之上。

**量子计算机能破解它吗？**  
足够大的量子计算机可以破解 ECDLP。这是整个行业已知的长期担忧，也是一个活跃的研究领域；如今的曲线仍可抵抗经典计算机。

**为什么 Zcash 使用不止一条曲线？**  
不同工作，不同曲线。一条曲线承载零知识证明系统；另一条曲线（嵌入第一条的域中）使证明内的密钥和 commitment 操作高效。接下来的文章会解释为什么这种配对很重要。

### 测试你的直觉

使用第 3 节经过验证的表，我们的玩具曲线上的 `9G + 10G` 是什么？答案又告诉你关于 `G` 的什么信息？*（答案如下。）*

<details><summary>答案</summary>

`9 + 10 = 19`，而我们看到 `19G = O`，即无穷远点。因此 `9G + 10G = O`。这意味着 `10G` 是 `9G` 的**负元 [negative]**（加法逆元）：两个相加得到"零"点的点。在曲线上，一个点的负元只是它关于 x 轴的镜像，而实际上 `9G = (7,6)` 和 `10G = (7,11)` 具有相同的 `x`，其 `y` 值之和为 `17 = 0 (mod 17)`。这种结构完全一致，这正是"它是一个群"所保证的。
</details>
