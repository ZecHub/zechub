## 1. 你为什么应该关心？

想象一下，你的银行对账单被钉在城镇广场的一面墙上。永久如此。任何人（你的房东、雇主、陌生人、未来的雇主、政府）都可以查看每一笔房租支付、医疗账单、捐款、咖啡消费，并准确追踪你把钱转给了谁，以及谁把钱转给了你。

这不是反乌托邦式的假设。**Bitcoin 大致就是这样运作的。**

Bitcoin 常被称为"匿名"，但它并不是。它是*假名制*的：你的名字不在账本上，但每一笔交易、金额以及地址之间的关联都是公开且永久的。整个"链分析"领域的存在，就是为了揭开这层薄薄的假名，将地址与真实的人关联起来。一旦你的某个地址被关联到你，你的财务历史就会随之展开。

Zcash 的建立是为了回答一个看似简单却极其困难的问题：

> **我们能否拥有完全私密的货币，隐藏发送者、接收者和金额，同时仍让任何人验证规则是否得到遵守？**

这两个目标彼此冲突。公开账本之所以可验证，*正是因为*每个人都能看见它。隐私 [Privacy] 意味着没有人能看见它。那么，公众如何验证不被允许查看的东西？

解决这一悖论，就是本系列的完整故事。让我们开始吧。

## 2. Zcash 内部存在两个世界

首先，澄清一个常见误解：**Zcash 不是"隐私币"。它是一种将隐私作为选项提供的币。** 它最初实际上是 Bitcoin 的一个分叉，并在同一条 blockchain 上承载两个并行系统。

| | **透明 [Transparent] 世界** | **屏蔽世界** |
|---|---|---|
| 隐私 | 公开，与 Bitcoin 一样 | 私密 |
| 地址以什么开头 | `t...` | `z...` 或 `u...` |
| 发送者 / 接收者 / 金额 | 对所有人**可见** | 对所有人**隐藏** |
| 底层技术 | Bitcoin 风格的公开账本 | 密码学 commitment [commitment] + 零知识证明 [zero-knowledge proof] |

资金甚至可以跨越两者之间的边界：将资金转入屏蔽世界称为*屏蔽化*，将其转回称为*去屏蔽化*。

透明世界就是"你大致已经了解的 Bitcoin"。而**屏蔽世界**包含所有优美的密码学，这也是本系列唯一关心的世界。

## 3. 直觉：公共公告板上的密封信封

以下是贯穿本文其余部分的核心心智图景。我们会不断回到它。

想象一块巨大的**公共公告板**，地球上的每个人都能随时看到它。

* **接收资金**意味着有人将一个**密封、不透明的信封**钉到公告板上。信封内是*它包含多少资金*以及*只有接收者能读取的秘密*，因为信封被锁定给该接收者的个人密钥。全世界都能看到*一个信封出现了*。除了所有者，没有人能看到里面有什么。

* **公告板只会不断增长。** 信封永远不会被撕下或删除。新的信封会永远钉在上面。

* **花费资金**意味着走到帘幕后面，证明*"我拥有公告板上一个尚未花费的信封，并且我有权打开它"*，然后将一个唯一的**作废代币 [token]**放入公开的"已花费"箱，并为你要支付的人钉上**新信封**。

这个小仪式（放入作废代币，钉上新信封，全都在帘幕后进行）*就是*一笔 Zcash 支付 [payment]。其他一切都是细节。

现在，让我们给这些道具赋予真实名称。

## 4. 五个名词

这五个术语构成屏蔽 Zcash 的完整词汇。将它们当作一个*故事*来学习，而不是术语表，它们就会留在你脑海中。

| 故事中的事物 | 真实的 Zcash 术语 | 它实际是什么 |
|---|---|---|
| 信封的内容（金额 + 所有者 + 一个秘密） | **Note [Note]** | 私密的"硬币"：属于某人的一部分价值 |
| 公告板上密封、不透明的信封 | **Note commitment** | 一种密码学封印，证明信封存在，同时隐藏其中内容 |
| 公告板本身 | **Note commitment tree** | 一份仅可追加的记录，保存*所有曾被创建的 note* |
| "已花费"箱中的作废代币 | **Nullifier [nullifier]** | 一个独特标记，表示"这个 note 现已被花费" |
| "帘幕后"的魔法 | **零知识证明** | 证明整笔花费有效，同时不透露任何内容的证明 |

如果你从本文中只记住一件事，就记住这张表。接下来的所有内容，只是在解释为什么每个部分都必须以这样的形式存在。

## 5. 为什么每个部分都必须这样设计

这是大多数解释文章跳过的部分，但它恰恰将"我记住了一些词"与"我理解这个设计"区分开来。这五个部分中的每一个，都是为解决**一个具体问题**而存在的。

### Note commitment：隐藏内容，但使伪造不可能

普通信封可以被蒸汽打开。密码学的 **note commitment** 不可以。将它想象成一个*神奇地*密封、完全不透明的信封，具有两种超能力：

- **隐藏性**：查看密封信封，无法得知其中的金额或所有者。
- **绑定性**：一旦密封，内容就不能被替换。你不能随后声称信封中装的是不同金额。

一个封印如何能同时做到这两件事？这是一个真实且可以回答的问题。它是**文章 3（commitment）**的主题。现在，先接受这个魔法信封，然后继续前进。

### Nullifier：真正巧妙的部分

当你花费一个 note 时，你会公布它的 **nullifier**，即"作废代币"。这个代币由*note 本身* **以及** *你的秘密密钥*计算得出。这个配方同时带来三个属性，而每一个都很重要：

1. **只有所有者可以创建它。** 你需要秘密密钥来计算它，因此没有人可以替你花费你的 note。
2. **对于给定的 note，它始终是*同一个*代币。** 尝试两次花费同一个 note，你每次都会生成*完全相同的*作废代币，而公开的"已花费"箱中已经包含它。重复花费被拒绝。
3. **没有人可以将它追溯到它所属的信封。** 作废代币看起来与它来源的信封完全无关。

第三个属性是 Zcash 隐私的**核心**，值得在下方单独用一节讲解。

### 零知识证明：帘幕本身

一切都发生在帘幕后，而你随后交给全世界的是一份**零知识证明**，一种不可伪造的证书。它同时默默证明以下所有内容：

- *我正在花费的信封确实钉在公告板上*（它是一个真实、存在的 note），
- *我确实有权打开它*（我持有正确的密钥），
- *我的作废代币计算正确*（不能在重复花费检查中作弊），
- *我的新信封包含的资金恰好与旧信封一样多*：**没有凭空创造资金。**

奇迹在于，这份证明**完全不透露**其中任何事实。它不透露金额、地址，也不透露是哪一个信封。它只会让你确信*以上每项陈述都是真的*。这究竟如何可能，是**文章 5（零知识证明）**的主题，也是本系列的高潮。

## 7. 一笔支付，从头到尾

让我们观察 Alice 向 Bob 支付，并标示每一个公开和私密步骤。

![alt text](/content-images/image-4-7af0dfe795.webp)

请注意使隐私得以实现的不对称性：

- **Alice 的旧 note**通过已花费箱中的一个 *nullifier* 消亡。
- **Bob 的新 note**通过公告板上的一个全新 *commitment* 诞生。
- 对所有观察者而言，这两件事之间**没有可见关联。** 资金轨迹至此中断。

> **Bob 如何知道自己收到了支付？** 他的 note 被加密 [encryption] 给了他的密钥。他会持续扫描公告板，只有*他的*信封会为他打开，就像拥有唯一能打开一组特定锁具的一把钥匙。其背后的机制是 **viewing key**，这是后续主题。

## 8. 世界看到了什么，什么仍然隐藏

| 关于支付的事实 | 公众可见吗？ |
|---|---|
| 发生了一笔屏蔽交易 | 是 |
| 它遵守了所有规则（无伪造、无重复花费） | 是（通过证明） |
| **谁**发送了资金 | 隐藏 |
| **谁**接收了资金 | 隐藏 |
| 发送了**多少** | 隐藏 |
| 花费了此前的**哪个** note | 隐藏 |

这就是第 1 节中悖论的解决方案。公众验证的是*规则*，而不是*内容*。验证与隐私不再相互冲突，因为零知识证明让你可以检查前者，而无需接触后者。

## 9. 核心所在：为什么信封与作废代币无法关联

如果你理解了这一个概念，你就理解了为什么 Zcash 是私密的。请慢慢阅读。

- 当一个 note **诞生**时，一个**信封（commitment）**被钉到公告板上。
- 当同一个 note 被**花费**时，一个**作废代币（nullifier）**会被放入箱中，这可能发生在数月之后。
- 它们由**不同的秘密配方**生成，并且没有任何**公开数学方法**可以将一个转换为另一个。

因此，外部观察者会看到不断出现的信封流和不断出现的作废代币流，但**无法将它们配对**。他们无法说"今天放入的作废代币对应去年 3 月钉上的信封"。这种关联*只*存在于 note 所有者的秘密知识中，而零知识证明会确认关联有效，*却不透露它。*

这种被切断的关联，正是链分析公司在 Bitcoin 中赖以获利的东西，也是 Zcash 刻意切断的东西。

> **检验你的直觉：** 如果 nullifier 改为*只*由 note 计算得出（不涉及秘密密钥），第 5 节中的三个属性会有哪一个失效？为什么这会悄然摧毁隐私？*（答案见文末。）*

## 12. 总结

- Bitcoin 是**透明**的；Zcash 提供一个**屏蔽**世界，其中发送者、接收者和金额均被隐藏。
- 表面上的悖论（*私密却可公开验证*）正是关键所在，而且它可以被解决。
- 一笔屏蔽支付由五个相互咬合的部分构成：一个 **note**（硬币）、一个 **note commitment**（密封信封）、**note commitment tree**（公共公告板）、一个 **nullifier**（防止重复花费的作废代币）以及一份 **零知识证明**（在不透露任何内容的情况下证明有效性的帘幕）。
- 隐私最终建立在**一条被切断的关联**之上：外部任何人都无法将 note 的诞生（commitment）与其消亡（nullifier）连接起来。
- 公众验证的是**规则**，而绝不是**内容**。

## 术语表

| 术语 | 通俗英语含义 |
|---|---|
| **Note** | 一个私密的价值单位，相当于 Zcash 中的硬币或钞票 |

| **Shielding / deshielding** | 将资金转入 / 转出私密的屏蔽世界 |
| **Viewing Key** | 让所有者发现并读取发送给自己的 note 的密钥 |

## 常见问题

**Zcash 总是私密的吗？**
不是。隐私适用于*屏蔽*世界（`z...`/`u...` 地址）。透明（`t...`）交易是公开的，与 Bitcoin 一样。

**如果一切都被隐藏，什么能阻止有人凭空印钱？**
零知识证明。它通过数学方式强制每笔交易的输出都必须由真实、未花费的输入支持，*同时*保持金额秘密。

**同一个 note 可以被花费两次吗？**
不可以。花费一个 note 会公布其 nullifier；第二次尝试会公布完全相同的 nullifier，它已经存在于"已花费"箱中，因此网络会拒绝它。

**外部人士可以将发送者与接收者关联起来吗？**
不可以。commitment（note 的诞生）和 nullifier（note 的消亡）无法被任何不拥有所有者秘密知识的人匹配。

---

### 直觉测试的答案（第 9 节）

如果 nullifier *只*由 note 计算得出，没有秘密密钥，那么**任何人**都可以计算它，从而破坏属性 #1（只有所有者可以花费）。更糟的是，nullifier 现在可以直接从 note 的公开信息中推导出来，这可能让观察者**将 nullifier 关联回其 commitment**，从而破坏属性 #3，并悄然瓦解整个系统的隐私。秘密密钥使作废代币既*专属于你*，又*不可关联 [unlinkable]*。
