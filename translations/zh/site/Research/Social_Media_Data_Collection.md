# 社交媒体数据收集

目前，很难找到一个没有受到社交网络影响的人。它们因易用性，以及传播信息时的速度和效率而广受欢迎。

不幸的是，这种便利性也让我们作为用户忽视了社交媒体平台收集了多少关于我们的信息、它们能如何处理这些信息，以及恶意第三方一旦获得这些信息后可能会做什么。

接下来，我们将概述其中一些平台收集的有关我们的数据、它们如何使用这些数据，以及为什么这可能会对我们的隐私 [privacy]，乃至个人或家庭安全构成威胁。

Discord
-------

我们需要从 Discord 开始，因为它是我们在"家里"使用的通信应用。

Discord 对于管理围绕广泛主题的大型社区非常有用，但和许多其他平台一样，它也会从我们的个人信息中获益。

### Discord 存储的数据

根据其隐私政策，Discord 会收集以下有关我们的信息：

-   文本消息（包括草稿）、语音消息、直播封面图、你添加的好友或互动过的用户、你玩的游戏、你注册的服务器或社区、你通过该应用进行的购买或销售，以及你在审核内容时作出的决定。

它们不会存储你的视频或直播视频，不过它们也为未来改变这一决定留下了空间。

它们还会自动收集某些信息，例如你连接时使用的 IP 地址、所用浏览器和操作系统。

### 它们如何使用这些数据

它们对我们数据所做的大多数事情都可以被视为合理，例如改善用户体验、提供更个性化的体验，以及维护社区标准。然而，它们也可以使用你的数据来推广其服务，甚至可能与第三方共享其中一部分，以推广其服务或分析公司的增长情况。

它们还声称，可以根据法院命令向提出请求的任何机构提供这些信息。

Twitter
-------

与 Discord 一样，Twitter 也会在其服务器上存储大量信息。它还会保存私信、你关注的人以及你互动过的人（保存的帖子、收藏），事实上，它们的政策十分相似，包括与第三方和主管机构共享你的数据。

Meta
----

Meta 应用程序集团，包括 Facebook、Instagram，以及现在的 Threads，做得更进一步。仅你提供的信息清单就长到无法逐一详述。其中包括你的所有帖子，包括语音 note、使用设备"相机"功能或图库拍摄的照片、你看到的广告、你花费时间查看的广告，甚至包括你选择忽略的广告。还包括你的消息元数据，例如位置、日期、时间和设备。还包括你在各种不同应用功能上花费的时间，以及在法律未保护你的情况下，你的宗教信仰、哲学信念、性取向，甚至工会成员身份。

但它们通过著名的 Pixel 更进一步，Meta 能够知道你在 **Facebook 之外** 所做的事情：你访问的网站、你在这些网站上花费的时间、你玩的游戏、你购买的商品，甚至包括你的教育水平等数据。当然，还包括有关你设备的技术信息，例如 IP 地址、操作系统、浏览器等，无论你是否登录 Facebook。

为什么我应该在意？
------------------

"我没有什么可隐瞒的"是淡化这些平台收集的所有数据重要性的最常见论点。然而，即使你所做的事情并不违法，也有充分理由担心这些公司了解你的哪些信息。

如果一名政治活动人士所反对的任何强大组织认定其所作所为是"错误的"，并向这些公司中的任何一家索取此人的信息，这名活动人士可能会受到严重影响，[它们会毫不犹豫地提供这些信息](https://gizmodo.com/twitter-saudi-arabia-x-jack-dorsey-areej-al-sadhan-abdu-1850805085)。

还有明显的例子表明，你的个人信息可能落入陌生人、公司或黑客手中，他们可能将其用于恶意目的，例如身份盗窃、获得你的账户访问权限、发送不需要的广告、勒索你，或 [操纵你](https://en.wikipedia.org/wiki/Facebook%E2%80%93Cambridge_Analytica_data_scandal)。

同样地，你可能会失去对自己数据的控制。你可能不知道数据如何被存储、处理或与第三方共享；或者如果你改变主意，可能无法删除或修改这些数据。如果你信任的服务提供商 [未能妥善保护你的数据](https://www.iotworldtoday.com/security/duolingo-data-breach-exposes-3-million-user-emails) [正确地](https://edition.cnn.com/2023/01/05/tech/twitter-data-email-addresses/index.html)，这也可能使你面临风险。

有替代方案吗？
-----------------------

尽管没有那么流行，但至少大多数最受欢迎的社交网络都有替代方案。让我们来看看其中一些：

### Matrix，类似 Discord，但更注重隐私

Matrix 是 Discord 和 Telegram 最接近的替代方案，拥有许多相同功能，但增加了隐私增强功能，例如端到端加密 [encryption]、不将数据作为商业模式，以及保持其代码开源。如果你决定运行自己的服务器，它完全免费，不过你可能希望为互联网上的专业服务器付费，或向该项目捐款。它支持跨平台，甚至允许与 Discord、Telegram 及其他热门应用程序集成。

### Mastodon

Mastodon 是 Twitter 最受欢迎的替代方案之一，但并非唯一。Mastodon 的突出之处在于它是去中心化 [decentralized] 的，这意味着任何希望这样做的个人或组织都可以为具有共同兴趣或特征的人启动自己的实例或"服务器"，但他们可以与其他独立实例互动。

在 Mastodon 中，每位管理员都制定自己的规则，而且由于它们不从事数据业务，因此不会收集太多有关用户、人口统计特征或偏好的信息，也不会与第三方共享这些信息。

遗憾的是，它们并未在消息中实施端到端加密，这一点需要牢记。

### Signal

我们的消息客户端 wiki 中详细介绍过，Signal 是 Telegram 和 WhatsApp 的更具隐私性和安全性的替代方案，拥有非常吸引人且有趣的功能
