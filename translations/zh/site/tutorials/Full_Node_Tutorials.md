# Full Node 教程

Zcash 全节点会验证网络上的透明交易和屏蔽交易。运行全节点有助于提升网络的韧性与稳定性。此外，运行全节点还能为用户提供更强的安全性与保障。以下是设置/升级 zcashd 或 zebrad 全节点的视频指南。

> **注意：** zcashd 正在被[弃用](https://z.cash/support/zcashd-deprecation/)，转而使用 [Zebra](https://github.com/ZcashFoundation/zebra)（`zebrad`）作为节点，以及 [Zallet](https://github.com/zcash/zallet) 作为钱包。下面的 zcashd 视频保留作参考；对于新的部署，请遵循[迁移指南：从 zcashd 到 Zebrad/Zallet](https://zechub.wiki/migration-guide-zcashd-to-zebrad-zallet)。

如需更多信息，请阅读我们的[全节点指南](https://zechub.wiki/full-nodes)。
