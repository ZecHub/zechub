# <img src="/content-images/ZCG-Circle-Logo-10-f41b8229ca.webp" alt="Alt Text" width="50"/>  Zcash Community Grants

## 使命宣言

Zcash Community Grants 计划为进入 Zcash 生态系统的独立团队提供资金，以便为 Zcash 生态系统的公共利益开展重要的持续开发（或其他工作）。

## 人员和团队

Zcash Community Grants 由一个委员会管理，目前由 5 人组成。该社区负责审查并批准希望基于 Zcash 协议进行构建的第三方团队提交的拨款（grant）申请。有关 [Team](https://zcashcommunitygrants.org/committee/) 的更多信息

近期获 ZCG 批准的项目包括由 QEDIT 团队主导的 Zcash 屏蔽（shielded）资产（ZSA）。通过 Zcash 将 DeFi 引入 ZEC，并通过一项新的支付（payment）协议为 Zcash 主网增加额外功能。

Zcash Media 的短纪录片以 Edward Snowden、Zooko 和 Deirdre Connolly 等知名 Zcash 用户为主角，旨在制作可被广泛分享的相关、有趣且具有教育意义的视频。

Ledger 的硬件钱包集成可全面支持 Sapling 屏蔽交易（transaction），使 Zcash 能够被私密且安全地存储。此项工作由 Zondax 团队完成。

由 ZGo 开展的一套面向实体商店的简易一键式屏蔽支付及销售点系统 SDK。

全球大使计划帮助 Zcash 在国际范围内及世界各地的线下社区活动中获得更广泛的代表性。

还有更多项目已由 Zcash 拨款委员会审查，请查看已提交项目的 [完整更新列表](https://docs.google.com/spreadsheets/d/1FQ28rDCyRW0TiNxrm3rgD8ai2KGUsXAjPieQmI1kKKg/edit?gid=135980745#gid=135980745)。

## 组织结构

Zcash Community Grants 是独立于 Electric Coin Company 和 Zcash Foundation 的组织。

## 资金

根据 NU6.1 制定、由 [ZIP 1016](https://zips.z.cash/zip-1016) 确立的资金模式，Zcash Community Grants 获得区块（block）补贴的 8%。该资金流在较早的 [ZIP 1015](https://zips.z.cash/zip-1015) 资金流到期后开始，并将在当前区块间隔下 Zcash 的第 3 次减半（halving）、即区块 4,406,400 时结束。ZCG 使用这些资金支持 Zcash 生态系统中的独立团队。

### 第 1 步：准备你的提案
创建一份清晰的提案，包括：
- 项目标题和申请人详情
- 问题陈述和拟议解决方案
- 交付成果、时间表和里程碑
- 预算和资金请求
- 相关经验和风险

---

### 第 2 步：在 GitHub 上提交
1. 前往 **Zcash Community Grants GitHub 代码库**
2. 打开 **Issues** 标签页并点击 **New Issue**
3. 选择合适的 **拨款申请模板**
4. 填写所有必填字段并提交

GitHub issue 是**官方申请记录**。

---

### 第 3 步：创建社区论坛帖子
1. 前往 **Zcash 社区论坛**
2. 在 **Zcash Community Grants** 分类中创建新主题
3. 使用与 GitHub issue 相同的标题
4. 添加简短摘要，并包含**GitHub issue 的链接**

---

### 第 4 步：参与审查
- 关注 GitHub issue 和论坛主题
- 回应 ZCG 委员会及社区提出的问题和反馈

---

### 第 5 步：结果
- 获批提案将进入资金发放和报告阶段
- 未获批准的提案**可以**修改后重新提交

---

**注意：**GitHub 是正式记录来源；论坛用于公开讨论。
