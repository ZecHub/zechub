# Sovright
![Sovright](/content-images/sovright-16a27c0d24.webp)

**Sovright** 是一家美国 501(c3) 非营利组织，致力于支持人类自主权。该项目最初专注于 Zcash 基础设施、挖矿、协议开发和生态系统支持，构建旨在强化私密数字货币基础设施并支持 Zcash 网络长期韧性的工具和服务。

Sovright 此前名为 **Bootstrap**。原名称反映了该组织早期从零开始创建 Zcash 基础设施公司的目标。

[访问网站](https://sovright.com/)

## 名称

名称 **Sovright** 是由 **sovereign** 和 **right** 组成的复合词。它体现了该组织对个人主权、隐私 [privacy] 以及选择如何控制个人数据、资金、通信、计算和在线活动之权利的关注。

Sovright 的工作始于 Zcash，这是一种使用零知识 [zero-knowledge] 密码学来支持屏蔽交易 [shielded transactions] 的隐私保护型加密货币。随着时间推移，该组织的关注范围从私密货币扩展至更广泛的基础设施议题，包括安全通信、有韧性的网络、私密计算和安全的 AI 交互。

## 挖矿 pool

Sovright 在以下地址运营一个 Zcash 挖矿 pool：

[mining.sovright.com](https://mining.sovright.com/)

Sovright 挖矿 pool 旨在支持矿工主权并减少挖矿 pool 的集中化。挖矿 pool 的集中化是工作量证明 [proof-of-work] 网络中反复出现的问题，因为少数几个 pool 最终可能控制网络哈希率的大部分。这可能削弱去中心化 [decentralization]，并增加对主要 pool 运营者行为的依赖。

Sovright 挖矿 pool 面向希望支持更去中心化 Zcash 挖矿生态系统的独立矿工、小型运营者及其他参与者。该 pool 强调透明的支付逻辑、可审计性和最低运营手续费 [fees]。

当前测试网版本不提供支付，且仅用于测试。

## （即将推出）

### 网络韧性

网络韧性是指承载 Zcash 交易的基础设施的可靠性和稳健性。私密交易不仅依赖密码学，也依赖其底层网络基础设施的可用性和可靠性。

Sovright 将网络韧性视为维持 Zcash 实际安全性和可用性的基础工作领域。

### 金融主权

金融主权是指个人无需依赖中介机构的许可，即可控制和访问自身资金的能力。在 Zcash 的背景下，这包括私密支付 [payments]、自托管以及使用户能够按自身条件进行交易的基础设施。

Sovright 将金融访问和用户控制的资金视为个人主权的核心组成部分。
