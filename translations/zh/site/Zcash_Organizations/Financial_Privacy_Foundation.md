# 金融隐私基金会（Financial Privacy Foundation，FPF）
![FPF](/content-images/FPFgrants-226bdea4bb.webp)

## 关于 FPF
金融隐私基金会（FPF）是在开曼群岛注册成立的非营利组织。FPF 的主要目标是教育并赋能个人和社区，使其掌控自身的金融隐私（financial privacy）与安全。FPF 也致力于推动一个尊重个人隐私的公平公正金融体系。FPF 与金融隐私相关的主要活动，是向个人和社区提供信息、资源和支持，以保护并优化其金融隐私。金融隐私基金（FPF）目前正在创建一项名为 FPF X FPF 的拨款计划。

## 关于 FPF X FPF 的信息

FPF X FPF 是 FPF 的首个实验性拨款计划，即金融隐私基金（FPF x FPF）。该计划将资助 Zcash 生态系统中接近完成的工程项目，或能够立即为生态系统作出贡献，并可在规定的时间和资金限制内完成的项目。FPF X FPF 以非常有限的资金启动，以完善拨款资助流程，并希望在未来推出更多轮次。

## FPF X FPF 计划详情

FPF X FPF 计划详情：FPF 的计划包含以下若干细节：

- 资金总额：最高 50,000 美元
- 最高申请金额：25,000 美元
- KYC 要求：无
- 项目类型：仅考虑能够直接惠及 Zcash 生态系统且可完全完成的工程项目。
- 支付：项目成功完成后
- 启动日期：2024 年 3 月 18 日

## 拨款申请流程

FPF X FPF 拨款申请流程包含多个步骤。首先，申请人必须通过提供的安全表单申请拨款。随后，FPF 将审核申请是否符合资格，并将在申请截止日期后 5 个日历日内通知申请人其状态。接下来，临时审查委员会将在提交截止日期后 20 个日历日内审查并决定拨款授予事宜。为确保透明度和问责制，获授拨款的详情将发布在 FPF 网站上。
