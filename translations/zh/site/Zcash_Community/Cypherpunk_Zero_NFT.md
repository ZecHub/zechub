# Cypherpunk Zero

Cypherpunk Zero 是一个以 Zero 为中心的故事系列；她是一名年轻的 cypherpunk 黑客兼自由斗士。Zero 目前生活在反乌托邦噩梦中，并利用代码对抗束缚社会的中心化守门人。该故事的灵感来自 Zcash 以及 Halo 密码学。该创作项目由 ECC、Stranger World、Might Jaxx 和部分生态系统合作伙伴共同完成。该创作项目最为人所知的是推出了一个 [NFT 系列](https://opensea.io/collection/cypherpunk-zero)，以及 [收藏玩具](https://mightyjaxx.com/products/cypherpunk-zero)。主要活跃于 Twitter 的 NFT 社区甚至创建了一个 [去中心化 [decentralized] 组织（DAO）](https://twitter.com/CypherpunkDAO)，用于组织并完成支持该活动及更广泛 Zcash 社区的项目。

## 代币 [token] 分配情况如何？

*总供应量*：Ethereum Mainnet 上的 10,000 个独特生成式 NFT  
供应量的 4%（前 400 个 NFT）已空投给购买了 Zcash X Mighty Jaxx: Cypherpunk Zero Genesis Edition Toy 59 的项目早期支持者。

供应量的 72%（7,200 个 NFT）将通过一种新颖的白名单机制向公众发放，该机制要求使用支持加密 [encryption] 备忘录 [memo] 的 Zcash 钱包 [wallet]（更多详情见下文）。

供应量的 24%（2,400 个 NFT）将由 ECC 保留在 Cypherpunk Reserve 中，用于未来推动 Zcash 及 Web3 领域内隐私 [privacy] 的计划。
