# Cypherpunk Zero

Cypherpunk Zero 是一个以年轻的 cypherpunk 黑客兼自由斗士 Zero 为中心的故事系列。Zero 目前生活在一场反乌托邦噩梦中，她利用代码对抗束缚社会的中心化把关人。该故事的灵感来自Zcash和Halo密码学。该创意作品由ECC、Stranger World、Might Jaxx 及精选生态系统合作伙伴共同打造。这项创意工作最引人注目地聚焦于一个[NFT 系列](https://opensea.io/collection/cypherpunk-zero)，并且还发布了[收藏玩具](https://mightyjaxx.com/products/cypherpunk-zero)。NFT 社区主要活跃于Twitter，甚至创建了一个[去中心化组织（DAO）](https://twitter.com/CypherpunkDAO)，以组织和完成支持该活动及更广泛Zcash社区的项目。
