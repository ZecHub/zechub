# Nym VPN 

Nym è una mixnet in evoluzione, un tipo di infrastruttura di rete informatica per la privacy che maschera i metadati degli utenti, separando gli indirizzi IP di origine e di destinazione. Anonimizza vari tipi di comunicazione, tra cui messaggistica, trasferimenti di file, transazioni di pagamento e navigazione web su siti web di base.
