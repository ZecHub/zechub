# Aiuta a costruire ZecHub 

Se fai parte della community di Zcash e vuoi contribuire a costruire ZecHub, ci sono alcune cose che sono davvero utili.

Seleziona link per la newsletter e aggiungili alla pagina GitHub della newsletter: -> [Clicca qui per le istruzioni](https://github.com/ZecHub/zechub/blob/main/site/contribute/ZecWeekly_Newsletter.md)

Verifica i fatti nella documentazione wiki, suggerisci modifiche e proponi nuove pagine su Github

Crea contenuti video nelle seguenti categorie:
```
* Zcash explainer videos
* Zcash wallet guide/tutorials
* Third-party application demos
```

Realizza design come poster/grafiche/animazioni per l'ecosistema di Zcash e Privacy 

Traduci una qualsiasi delle pagine wiki esistenti.

Segnalazione di bug

#### Per i dettagli sugli importi delle ricompense, leggi la nostra pagina per i contributori -> [qui](https://zechub.wiki/contribute/contributing-guide#content).

Ogni lunedì pubblichiamo issue per le attività per cui al momento sono aperte ricompense. Puoi anche suggerire ricompense! Principalmente si trovano su ZEC Bounties.

![zecbounties](/content-images/0e4f5109-c0c9-4a0a-8d71-8172e36b9726-1a94469edf.webp)



[ZEC Bounties](https://bounties.zechub.wiki/)

[ZecHub Issue Github](https://github.com/ZecHub/zechub/issues)

[ZecHub-Wiki Issue Github](https://github.com/ZecHub/zechub-wiki/issues)



Se ci sono altri modi in cui vorresti contribuire, invia un messaggio a ZecHub ([@ZecHub](https://twitter.com/zechub)) su Twitter oppure unisciti al nostro [Discord](https://discord.gg/zcash).
