# <img src="/content-images/send-svgrepo-com-b62f643de0.svg" width="24" height="24" alt="Journalist icon"/> 신원을 연결하지 않고 송금하기

<span className="inline-flex items-center gap-[6px]"><span className="inline-block w-[12px] h-[12px] bg-green-500 rounded-full"></span>중급 - 7분</span>

## 요약

- 항상 **거래정보 보호 주소**에서 송금하세요
- 투명 주소에서 투명 주소로 직접 거래하지 마세요
- 신원 간 연결 가능성을 끊으세요
- 송금 시점과 패턴에 유의하세요

<br/>

## <img src="/content-images/user-svgrepo-com-21adf62b7c.svg" width="24" height="24" className="inline-block align-middle mr-1 p-[2px]" alt="user icon"/> 대상 독자

- 민감한 결제를 하는 사람
- 프라이버시를 중시하는 사용자
- 감시 위험이 있는 환경에서 활동하는 사람

<br/>

## <img src="/content-images/warning-error-svgrepo-com-b7ea8a50da.svg" width="24" height="24" className="inline-block align-middle mr-1 p-[2px]" alt="warning icon"/> 문제점

암호화폐를 송금하면 다음 정보가 드러나는 경우가 많습니다.
- 지갑의 신원
- 거래 내역
- 누구와 거래하는지

이로 인해 **추적 가능한 금융 그래프**가 만들어집니다.

<br/>

## <img src="/content-images/icons8-lock-2f8e221321.svg" width="24" height="24" className="inline-block align-middle mr-1 p-[2px]" alt="toolbox icon"/> Zcash을 사용하는 이유


Zcash은 거래정보 보호 거래를 사용해 **완전히 비공개로 자금을 전송**할 수 있습니다.

이를 통해 다음을 차단합니다.
- 주소 간 연결 가능성
- 공개 거래 추적

<br/>

## <img src="/content-images/icons8-toolbox-9bebbb1619.svg" width="24" height="24" className="inline-block align-middle mr-1 p-[2px]" alt="toolbox icon"/> 필요한 것

- 거래정보 보호 거래를 지원하는 지갑
- z 주소에 대한 기본적인 이해

<br/>

## <img src="/content-images/ladder-svgrepo-com-7232bf46ed.svg" width="24" height="24" className="inline-block align-middle mr-1 p-[2px]" alt="step icon"/> 단계별 안내

### 1단계: 자금이 거래정보 보호 상태인지 확인하기

자금이 투명 주소에 있다면 다음을 수행하세요.
- 먼저 거래정보 보호 주소로 옮기세요


### 2단계: 거래정보 보호 주소에서 거래정보 보호 주소로 송금하기
항상 `z to z` 거래를 우선하세요

이렇게 하면 프라이버시를 최대한 보호할 수 있습니다.


### 3단계: 신원 연결 피하기

다음 행동은 하지 마세요.
- 거래를 공개적으로 알리기
- 여러 상황에서 같은 주소 재사용하기
- 주소를 알려진 신원과 연결하기

### 4단계: 송금 시점의 패턴 고려하기

고급 팁:
- 큰 금액을 받은 직후 송금하지 마세요
- 가능하면 예측 가능한 패턴을 깨세요

<br/>

## <img src="/content-images/icons8-cancel-7f786be3c1.svg" width="24" height="24" className="inline-block align-middle mr-1 p-[2px]" alt="cancel icon"/> 피해야 할 흔한 실수

- 투명 주소에서 직접 송금하기  
- 여러 사람과 주소를 재사용하기  
- 거래를 공개적으로 확인해 주기  
- 메타데이터(시점, 빈도)를 무시하기

<br/>

- 신원 연결 피하기
- 추적 가능성 낮추기
