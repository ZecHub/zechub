- 모든 거래에 거래정보 보호 주소를 사용하세요
- 지갑의 정체를 공개적으로 절대 노출하지 마세요
- 추적 가능한 결제를 피하여 취재원을 보호하세요
- 안전한 소통을 위해 메모를 신중하게 사용하세요

## <img src="/content-images/user-svgrepo-com-21adf62b7c.svg" width="24" height="24" className="inline-block align-middle mr-1 p-[2px]" alt="사용자 아이콘"/> 대상

## <img src="/content-images/warning-error-svgrepo-com-b7ea8a50da.svg" width="24" height="24" className="inline-block align-middle mr-1 p-[2px]" alt="경고 아이콘"/> 문제점

기자는 다음과 같은 위험에 직면합니다.
- 감시
- 취재원 노출 위험
- 적대 세력의 금융 추적

투명한 암호화폐를 사용하면 다음 정보가 드러날 수 있습니다.
- 누가 기자에게 결제했는지
- 기자가 누구에게 결제했는지
- 언제, 얼마를 결제했는지

<br/>

## <img src="/content-images/icons8-lock-2f8e221321.svg" width="24" height="24" className="inline-block align-middle mr-1 p-[2px]" alt="도구 상자 아이콘"/> Zcash를 사용하는 이유


Zcash는 다음을 제공합니다.
- 강력한 금융 프라이버시
- 민감한 거래 보호
- 기자와 취재원이 연결될 위험 감소

<br/>

## <img src="/content-images/icons8-toolbox-9bebbb1619.svg" width="24" height="24" className="inline-block align-middle mr-1 p-[2px]" alt="도구 상자 아이콘"/> 필요한 항목

- 거래정보 보호 기능을 지원하는 Zcash 지갑
- 안전한 소통 채널(블록체인 외부)
- 철저한 보안 수칙 준수

<br/>

## <img src="/content-images/ladder-svgrepo-com-7232bf46ed.svg" width="24" height="24" className="inline-block align-middle mr-1 p-[2px]" alt="단계 아이콘"/> 단계별 안내


### 1단계: 전용 지갑 만들기

- 민감한 업무에만 사용할 지갑을 만드세요
- 개인 거래와 섞지 마세요

### 2단계: 거래정보 보호 주소만 사용하기

- 항상 z 주소를 사용해 거래하세요
- 투명 거래는 일절 피하세요


### 3단계: 취재원 결제 보호하기

취재원에게 결제할 때:
- 거래정보 보호 거래(z → z)를 사용하세요
- 예측 가능한 시간 패턴을 피하세요
- 주소를 재사용하지 마세요


### 4단계: 메모를 신중하게 사용하기

- 메모에 민감한 정보를 절대 포함하지 마세요
- 필요하다면 중립적이거나 암호화된 참조 내용을 사용하세요


### 5단계: 보안 수칙 유지하기

- 지갑을 본인의 신원과 연결하지 마세요
- 거래 사실을 공개적으로 확인해 주지 마세요
- 소통에 별도의 채널을 사용하세요


<br/>
