# Arborist Calls

Zcash Arborist Calls은 네트워크 업그레이드 계획, 합의 노드 구현 작업, 지갑 및 인프라 의존성, 프로토콜 연구에 중점을 두고 정기적으로 열리는 프로토콜 개발 회의입니다.

공식 Arborist Calls 페이지는 Zcash Foundation에서 관리합니다.

**[https://zfnd.org/arborist-calls/](https://zfnd.org/arborist-calls/)**

## 참여 방법

여러 지역의 기여자가 참여할 수 있도록 회의는 2개의 정기 시간대를 번갈아 가며 진행합니다. 현재 일정 파일과 Zoom 링크는 공식 Zcash Foundation 페이지에서 확인하세요.

- **15:00 UTC** 시간대

회의 링크는 변경될 수 있으므로 등록 링크, 일정 파일 및 회의 참여 방법을 확인할 때는 재단 페이지를 공식 정보 출처로 삼으세요.

## 참석 대상

Arborist Calls은 다음 분들에게 유용합니다.

- 프로토콜 엔지니어 및 연구자
- 노드, 지갑, SDK 및 라이트월렛 인프라 개발자
- 합의, 네트워크 업그레이드 또는 프로토콜 의존성과 관련된 개발 지원금을 받은 사람
- 공개적으로 이루어지는 기술 의사 결정 과정을 살펴보고 싶은 커뮤니티 구성원
