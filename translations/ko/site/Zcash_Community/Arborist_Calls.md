# Arborist Calls

Zcash Arborist Calls는 네트워크 업그레이드 계획, 합의 노드 구현 작업, 지갑 및 인프라 의존성, 그리고 프로토콜 연구에 초점을 맞춘 정기적인 프로토콜 개발 회의입니다.

공식 Arborist Calls 페이지는 Zcash Foundation에서 관리합니다:

**[https://zfnd.org/arborist-calls/](https://zfnd.org/arborist-calls/)**


## 참여 방법

이 회의는 서로 다른 지역의 기여자들이 참여할 수 있도록 두 개의 정기 시간대로 번갈아 진행됩니다. 현재 캘린더 파일과 Zoom 링크는 공식 Zcash Foundation 페이지를 이용하세요:

- **15:00 UTC** 시간대


회의 링크는 변경될 수 있으므로, 등록 링크, 캘린더 파일, 회의 접속 정보는 Foundation 페이지가 기준 정보입니다.

## 누가 참여하면 좋은가

Arborist Calls는 다음과 같은 이들에게 유익합니다:

- 프로토콜 엔지니어 및 연구자
- 노드, 지갑, SDK 및 lightwallet 인프라 개발자
- 작업이 합의, 네트워크 업그레이드 또는 프로토콜 의존성과 맞닿아 있는 그랜트 수혜자
- 공개적으로 이루어지는 기술적 의사결정을 따라가고 싶은 커뮤니티 구성원
