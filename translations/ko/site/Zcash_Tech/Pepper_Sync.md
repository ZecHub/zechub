# Zingo 2.0 - Pepper Sync

## 요약

* Pepper Sync는 Zingo! 2.0에서 도입된 동기화 엔진으로, Zingo Labs가 개발한 오픈소스 Zcash 지갑입니다.
* 체인을 큰 순차 단위로 스캔하는 대신 비선형 동기화를 사용하므로 잔액과 거래 내역이 훨씬 빠르게 표시됩니다.
* 진행 상황은 계속 저장됩니다. 연결이 끊기거나 앱이 닫혀도 처음부터 다시 시작하는 대신 중단된 지점부터 동기화를 재개합니다.
* 동기화가 완료되기 전에도 자금을 사용할 수 있습니다.
* 거래정보 보호 거래는 전체 과정에서 프라이버시가 보호됩니다.

## 핵심 설명

Zingo 2.0은 Zcash 커뮤니티를 위해 개발된 경량 오픈소스 지갑인 Zingo! 지갑의 출시 버전으로, 지갑이 블록체인에 연결되는 방식을 완전히 새롭게 바꾸는 주요 업그레이드인 Pepper Sync를 도입했습니다. 이후 버전에도 Pepper Sync가 계속 포함됩니다. 현재 모바일 버전인 [Zingo 3.0](https://github.com/zingolabs/zingo-mobile/releases/tag/zingo-3.0.0-324)(2026년 10월 31일)은 NU7 지원과 내장 스왑 기능을 추가합니다.

이전에는 동기화가 매우 느리고 오류가 잦으며 리소스를 많이 사용해, 사용자가 처음부터 다시 시작해야 하는 경우도 있었습니다. Pepper Sync는 이 모든 문제를 해결합니다. 동기화 속도를 높이고, 과정은 더 매끄럽고 안정적으로 만들며, 기기의 부담은 줄이는 동시에 거래정보 보호 거래의 프라이버시를 온전히 지킵니다.

Zcash를 처음 사용해 보는 신규 사용자든 거래정보 보호 지갑을 여러 개 관리하는 오랜 커뮤니티 구성원이든, Pepper Sync를 통해 훨씬 실용적이고 쾌적하게 사용할 수 있습니다.

### Pepper Sync의 주요 기능

Pepper Sync는 여러 가지 개선 사항을 제공합니다.

- 훨씬 빠른 동기화 - 몇 시간이 아니라 몇 분이면 지갑을 사용할 수 있습니다.
- 스마트 업데이트 - 데이터를 더 작은 단위로 처리해 전체 재스캔을 피합니다.
- 중단에 강한 동기화 - 연결이 끊겨도 중단된 지점부터 동기화를 재개합니다.
- 가볍고 효율적 - 휴대폰, 노트북 및 성능이 낮은 기기에 최적화되어 있습니다.
- 명확한 피드백 - 실시간 진행 상황 업데이트로 혼란을 줄입니다.
- 프라이버시 보호 - 거래정보 보호 거래는 전체 과정에서 프라이버시가 보호됩니다.

### 이전보다 개선된 점

Zingo의 이전 버전은 긴 동기화 시간, 불명확한 오류 처리, 과도한 리소스 사용으로 사용자를 불편하게 하는 경우가 많았습니다. Pepper Sync는 이러한 일반적인 문제를 해결합니다.

| 기능            | 이전 Zingo 버전                         | Pepper Sync를 적용한 Zingo 2.0                 |
| ------------------ | -------------------------------------- | -------------------------------------------- |
| 동기화 속도         | 특히 최초 설정 시 느림      | 최초 및 이후 동기화 모두 훨씬 빠름         |
| 오류 처리     | 간헐적으로 멈추고 실패 원인이 불명확함 | 자동 복구로 안정성 향상   |
| 사용자 경험    | 신규 사용자에게 동기화 과정이 “불투명”하게 느껴짐        | 상태와 업데이트가 더 명확하고 투명함 |
| 기기 성능 | CPU 및 메모리 사용량이 높음                  | 리소스를 원활하게 사용하도록 최적화됨            |

요컨대, 이제 동기화가 더 빠르고 안정적이며 이해하기 쉬워졌습니다.

## 시각 자료 / 비유

이전 지갑의 동기화는 책에 대해 이야기하기 전에 아주 긴 책을 첫 페이지부터 소리 내어 읽는 것과 같다고 생각해 보세요. 중간에 멈추면 첫 페이지부터 다시 시작해야 합니다. Pepper Sync는 같은 책을 읽지만 책갈피를 남기고, 먼저 필요한 장을 읽으며, 마지막 페이지까지 다 읽기 전에도 이야기의 내용을 말할 수 있게 해 줍니다.

중요한 점은 책갈피입니다. 이전 버전은 중단된 동기화를 모두 헛수고로 취급했지만, Pepper Sync는 일시 중지로 처리합니다.

## 자세히 알아보기

### Pepper Sync 작동 방식(간단한 설명)

Pepper Sync는 블록체인을 크고 다루기 힘든 단위로 재스캔하는 대신, 작고 관리하기 쉬운 단계로 작업하며 진행하는 동안 현재 위치를 계속 저장합니다.

1. 연결 - 지갑이 네트워크에 접속합니다.
2. 블록 가져오기 - 데이터를 조금씩 다운로드합니다.
3. 검증 - 거래를 검증합니다.
4. 거래정보 보호 노트 처리 - 항상 프라이버시를 보호합니다.
5. 잔액 업데이트 - 지갑을 안전하게 새로 고칩니다.
6. 진행 상황 저장 - 원활하게 중지하고 재개합니다.
7. 완료 - 지갑으로 거래할 준비가 됩니다.

## 실제 영향

### Pepper Sync의 혜택을 받는 사람은 누구인가요?

- 신규 사용자 - 지연 때문에 포기하지 않고 지갑을 빠르게 설정할 수 있습니다.
- 일상적인 사용자 - 안정적인 동기화 덕분에 거래정보 보호 결제를 일상적으로 사용할 수 있습니다.
- 개발자 및 테스터 - 동기화 시간이 줄어 테스트 주기가 빨라집니다.
- 모바일 기기 및 저사양 기기 사용자 - Zingo는 리소스가 제한된 하드웨어에서도 효율적으로 실행됩니다.

### Zcash에서 중요한 이유

Zcash는 암호화폐에서 가장 강력한 프라이버시 도구 중 하나인 거래정보 보호 거래를 중심으로 설계되었습니다. 하지만 프라이버시는 누구나 이용할 수 있어야 비로소 유용합니다.

Pepper Sync는 다음과 같은 방식으로 도움을 줍니다.

- 진입 장벽 완화 - 신규 사용자가 빠르게 시작할 수 있습니다.
- 일상적인 사용성 지원 - 거래정보 보호 주소를 더 신뢰하기 쉬워집니다.
- 생태계 성장 촉진 - 더 나은 지갑 사용 경험이 도입, 앱 및 서비스의 증가로 이어집니다.

지갑 사용 경험을 개선함으로써 Pepper Sync는 전체 Zcash 생태계를 강화합니다.

### 시작하기: Zingo 2.0 설정

1. 지갑 다운로드 - [zingolabs.org](https://zingolabs.org/) 또는 [모바일](https://github.com/zingolabs/zingo-mobile/releases) 및 [데스크톱](https://github.com/zingolabs/zingo-pc/releases)용 GitHub 릴리스 페이지에서 적절한 버전을 받습니다.
2. 지갑 설정 - 새 지갑을 만들거나 기존 seed phrase로 복원합니다. [Zingo 2.0 및 Zingo Labs](https://www.youtube.com/watch?v=FREwMzf_LlM)
3. Pepper Sync 실행 - 지갑이 업데이트되는 동안 진행 표시기를 확인합니다. [Pepper Sync 실행](https://x.com/ZingoLabs/status/1961871338441724191)
4. Zcash 사용 시작 - 동기화가 완료되면 거래정보 보호 ZEC를 보내고 받을 수 있습니다.
5. 중단을 걱정하지 마세요 - 앱이 닫히거나 연결이 끊기면 Pepper Sync가 자동으로 동기화를 재개합니다.

## 흔히 하는 실수

**Pepper Sync를 독립된 지갑으로 생각하기**. Pepper Sync는 Zingo! 지갑 안에서 작동하는 동기화 엔진이지 별도의 앱이 아닙니다. Zingo를 설치하면 그 아래에서 Pepper Sync가 작동합니다.

**동기화가 빨라지면 프라이버시가 약해진다고 생각하기**. 속도 향상은 블록 데이터를 가져오고 정렬하고 캐시하는 방식에서 비롯되며, 더 많은 정보를 공개해서 얻는 것이 아닙니다. 거래정보 보호 거래는 전체 과정에서 프라이버시가 보호됩니다.

**자금을 사용하려면 완전히 동기화될 때까지 기다려야 한다고 생각하기**. 동기화가 완료되기 전에 자금을 사용할 수 있다는 점은 Pepper Sync의 주요 기능 중 하나이므로, 지갑이 체인의 최신 상태에 도달할 때까지 기다릴 필요가 없습니다.

## FAQ - 자주 묻는 질문

**Q: 지갑을 열 때마다 다시 스캔해야 하나요?**

A: 아니요. Pepper Sync는 진행 상황을 저장하므로 마지막 지점부터 업데이트하면 됩니다.

**Q: 인터넷 연결이 끊기면 어떻게 되나요?**

A: 동기화가 일시 중지되었다가 처음부터 다시 시작하지 않고 나중에 이어집니다.

**Q: 동기화 중에도 프라이버시가 안전하게 보호되나요?**

A: 예. 거래정보 보호 거래의 프라이버시는 온전히 보호됩니다.

**Q: 최초 동기화에는 얼마나 걸리나요?**

A: 기기와 인터넷 연결에 따라 다르지만, 보통 몇 시간이 아니라 몇 분 정도 걸립니다.

**Q: 동기화가 끝나기 전에 지갑을 사용할 수 있나요?**

A: 예. Pepper Sync는 동기화가 완료되기 전에 자금을 사용할 수 있도록 지원하므로, 지갑이 체인의 최신 상태에 도달할 때까지 기다릴 필요가 없습니다.

## 결론

Zingo 2.0의 Pepper Sync로 거래정보 보호 지갑의 가장 큰 불편 사항이었던 동기화 문제가 해결되었습니다. 이제 빠르고 안정적이며 사용하기 쉬워져 신규 사용자의 진입 장벽을 낮추고 일상적인 사용을 훨씬 더 실용적으로 만듭니다.

사용자에게는 기다리는 시간이 줄고 프라이버시가 강화됩니다. 개발자에게는 더 나은 기반에서 개발할 수 있다는 의미입니다. Zcash 생태계에는 거래정보 보호 거래를 누구나 이용할 수 있도록 하는 또 하나의 진전입니다.

Zingo 2.0의 Pepper Sync는 단순한 업그레이드가 아니라, 프라이버시를 지키면서 실용적으로 사용할 수 있는 암호화폐를 향한 큰 도약입니다.
