# ZecHub 구축을 도와주세요 

Zcash 커뮤니티의 일원으로서 ZecHub 구축에 기여하고 싶다면, 매우 도움이 되는 몇 가지 방법이 있습니다.

뉴스레터용 링크를 선별하여 뉴스레터의 GitHub 페이지에 추가하세요: -> [지침을 보려면 여기를 클릭하세요](https://github.com/ZecHub/zechub/blob/main/site/contribute/ZecWeekly_Newsletter.md)

위키 문서를 사실 확인하고, 편집을 제안하며, Github에서 새 페이지를 제안하세요

다음 카테고리의 동영상 콘텐츠를 제작하세요:
```
* Zcash explainer videos
* Zcash wallet guide/tutorials
* Third-party application demos
```

Zcash 및 프라이버시 생태계를 위한 포스터/그래픽/애니메이션 등의 디자인을 제작하세요

기존 위키 페이지를 번역하세요.

버그 신고

#### 바운티 금액에 대한 자세한 내용은 기여 페이지를 읽어주세요 -> [여기](https://zechub.wiki/contribute/contributing-guide#content).

현재 바운티가 열려 있는 작업의 이슈를 매주 월요일에 게시합니다. 바운티를 제안할 수도 있습니다! 주로 ZEC Bounties에서 확인할 수 있습니다.

[ZecHub-Wiki Github 이슈](https://github.com/ZecHub/zechub-wiki/issues)



다른 방식으로 기여하고 싶으시다면 Twitter에서 ZecHub ([@ZecHub](https://twitter.com/zechub))에게 메시지를 보내거나 [Discord](https://discord.gg/zcash)에 참여하세요.
