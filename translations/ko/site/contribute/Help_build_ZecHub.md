# ZecHub 구축에 참여하기 

Zcash 커뮤니티 회원으로서 ZecHub 구축에 기여하고 싶으시다면, 큰 도움이 될 만한 몇 가지 방법이 있습니다.

뉴스레터에 실을 링크를 선별하고 뉴스레터의 GitHub 페이지에 추가해 주세요: -> [안내를 보려면 여기를 클릭하세요](https://github.com/ZecHub/zechub/blob/main/site/contribute/ZecWeekly_Newsletter.md)

위키 문서의 사실을 확인하고 수정 사항을 제안하며, GitHub에 새 페이지를 제안해 주세요.

다음 카테고리의 동영상 콘텐츠를 제작해 주세요:
```
* Zcash explainer videos
* Zcash wallet guide/tutorials
* Third-party application demos
```

Zcash 및 프라이버시 생태계를 위한 포스터/그래픽/애니메이션 등의 디자인을 제작해 주세요.

기존 위키 페이지를 번역해 주세요.

버그를 신고해 주세요.

### 보상

ZEC의 보상 금액은 정해져 있지 않습니다. [바운티 금액 정책](https://bounties.zechub.wiki/docs/bounty-amounts)을 따르세요. 작업 유형에 맞는 USD 구간을 선택하고, 현재 환율로 환산한 뒤, 게시판에 ZEC을 입력하세요. 해당 정책이 기준이 됩니다.

기여자 작업 절차 및 작업 유형: [ZecHub에 기여하기](https://zechub.wiki/contribute/contributing-guide).
