# ZecHub 커뮤니티 인프라 프레임워크


### 커뮤니티 인프라

ZecHub 바운티 프로그램은 개별 작업 대신, 개발자들이 더 자유롭고 간소화된 방식으로 참여할 수 있는 [ZEC Bounties](https://bounties.zechub.wiki/)를 제공합니다.


## 유용한 가이드

- [ZecHub 개발자 가이드](https://zechub.wiki/developers)

- [Zcash Readthedocs](https://zcash.readthedocs.io/en/latest/)

- [The Zebra Book](https://zebra.zfnd.org)

- [Akash Network 문서](https://akash.network/docs/)

- [Akash Network에서 Zebrad 설정하기](https://zechub.wiki/guides/akash-network-zebra#content)

- [Zcash Payment Requests 설명 (영상)](https://www.youtube.com/watch?v=l5auYQIzYsQ)

- [ZIP-321 명세](https://zips.z.cash/zip-0321)

Zcash 개발자들의 심층적인 조언이 필요하다면 [커뮤니티 포럼](https://forum.zcashcommunity.com)에 글을 올려보세요.
