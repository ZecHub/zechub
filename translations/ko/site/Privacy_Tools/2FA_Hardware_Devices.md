# 2FA 하드웨어 장치

데이터 보안과 프라이버시는 개인과 기업 모두에게 매우 중요한 문제입니다. 사이버 공격과 데이터 유출이 점점 더 흔해지고 있으며, 민감한 데이터를 보호하고 프라이버시를 지키기 위해 선제적으로 조치를 취하는 것이 중요합니다. 하드웨어 보안 키를 사용하는 것도 이러한 조치 중 하나로, 장치와 데이터를 보호하는 추가적인 보안 계층을 제공합니다.

## 하드웨어 보안 키란 무엇인가요?

하드웨어 보안 키는 계정과 장치를 보호하기 위한 2단계 인증(2FA)에 사용하는 물리적 장치입니다. 사용자 이름 및 비밀번호와 함께 작동해 권한이 있는 사용자만 계정과 데이터에 접근할 수 있도록 합니다.

이 키는 사용자 이름 및 비밀번호와 함께 작동해 권한이 있는 사용자만 계정과 데이터에 접근할 수 있도록 설계되었습니다. USB 메모리, NFC 카드, 블루투스 장치 등 다양한 형태로 제공됩니다.

![Hardware Security Key Example](/content-images/1dff66a4-d8e6-483f-9a1e-065d3974d665-a4c6c73e00.webp)

## 하드웨어 보안 키 작동 방식

이 기술을 지원하는 웹사이트나 플랫폼에서 하드웨어 보안 키를 통한 2FA를 활성화해야 합니다. 예를 들면 Binance 및 Coinbase 거래소에서 사용할 수 있습니다.

YubiKey와 같은 하드웨어 보안 키를 사용할 때는 하드웨어 키를 데스크톱, 노트북 또는 스마트폰의 USB나 Type-C 포트에 꽂기만 하면 됩니다. 그러면 키가 인증을 완료합니다.

## 하드웨어 보안 키를 사용하면 어떤 이점이 있나요?

FIDO U2F 또는 FIDO2/WebAuthn와 함께 사용하면 하드웨어 보안 키는 입력할 코드를 생성하는 대신 새로운 인증 요청에 서명해 사용자를 인증합니다. 서비스에는 공개 키가 저장되고, 개인 키는 인증 장치에 보관됩니다. 인증 정보는 해당 서비스에만 연결되며, 브라우저는 피싱을 방지하기 위해 접속하려는 서비스의 신원을 확인합니다. 이러한 이점은 FIDO 인증에 해당하며, 멀티 프로토콜 키가 지원할 수 있는 모든 방식을 뜻하지는 않습니다. 이용하려는 방식을 서비스, 브라우저, 장치 및 연결 유형에서 지원하는지 확인하세요. [Yubico의 WebAuthn 소개](https://developers.yubico.com/WebAuthn/)와 [FIDO2/WebAuthn 개발자 가이드](https://developers.yubico.com/WebAuthn/WebAuthn_Developer_Guide/)를 참조하세요.

## 하드웨어 보안 키는 모든 장치 및 운영체제와 호환되나요?

아니요. 하드웨어 보안 키는 다양한 형식으로 제공되며, 모든 장치 및 운영체제와 호환되지 않을 수 있습니다. 키를 구매하기 전에 사용 중인 장치 및 운영체제와 호환되는지 확인하세요.

![Hardware Security Key Form Factors](/content-images/a830c435-ad20-4183-b381-475afe1089b3-5537cd7388.webp)

## 하드웨어 보안 키 하나를 여러 계정에 사용할 수 있나요?

예. 하드웨어 보안 키 하나로 여러 웹사이트와 서비스의 계정을 보호할 수 있습니다.

## 하드웨어 보안 키를 분실하면 어떻게 되나요?

하드웨어 보안 키를 분실하면 계정에 접근하지 못할 수 있습니다. 이런 상황을 피하려면 예비 키를 준비하거나 다른 인증 방식을 마련해 두는 것이 좋습니다.

## 2FA 하드웨어 장치의 예

시중에서 구할 수 있는 2FA 하드웨어 장치의 예를 소개합니다.

**Yubico YubiKey 5 NFC**

![Yubico YubiKey 5 NFC](/content-images/bf1ac95e-7277-4559-b5ef-63117b66971b-3aa542aba7.webp)

많은 보안 키에서 사용하는 개방형 인증 표준인 FIDO U2F의 공동 개발사 Yubico가 제조한 YubiKey 5 NFC는 장치를 안전하게 보호하는 데 믿고 사용할 수 있습니다. 이름에서 알 수 있듯이 USB A(어댑터를 사용하면 USB C) 또는 NFC로 작동합니다.  
Google Chrome, Facebook, Dropbox, LastPass, 1Password 등 다양한 서비스와 별도의 설정 없이 호환됩니다. YubiKey 5는 작고 튼튼하며 가벼울 뿐 아니라 방수 기능도 갖추고 있습니다.  
서비스 안내에 따라 키를 USB 포트에 꽂으면 문제없이 YubiKey를 두 번째 U2F 인증 요소로 설정할 수 있습니다. 키의 금색 원을 누르거나 터치하면 키가 등록됩니다. 다음에 로그인할 때는 비밀번호를 입력하고 키를 꽂은 다음 터치하면 됩니다.

**Thetis Fido U2F 보안 키**

![Thetis Fido U2F Security Key](/content-images/b83e42e5-bba6-4175-ad6c-d64972ef54ef-a2ef17a10d.webp)

가격 대비 성능이 뛰어난 보안 키를 찾고 있다면 Thetis의 이 모델을 후보에 넣어 보세요. 내장 블루투스는 없으며(더 비싼 모델에는 탑재되어 있습니다), FIDO U2F 표준만 지원하므로 UAF나 OTP와는 호환되지 않습니다. 하지만 Windows, macOS 또는 Linux에서 Chrome이나 Opera를 브라우저로 사용하면 웹사이트에 안전하게 접속할 수 있습니다.  
이 합리적인 가격의 보안 키는 휴대 중 커넥터가 손상될 위험을 막아 주는 회전식 알루미늄 케이스와 접이식 디자인을 갖추고 있습니다. 검정, 금색, 은색의 세 가지 색상으로 제공됩니다.  
플라스틱 케이스는 튼튼하고 내구성도 꽤 좋아 보이지만, 가방 안에서 무거운 물건과 함께 두지 않는 것이 좋습니다. 키의 구멍은 크기가 충분하지 않아 열쇠고리나 랜야드를 연결할 수 있는 방법이 제한적입니다.

**CryptoTrust OnlyKey**

![CryptoTrust OnlyKey](/content-images/13be6ecc-227e-498c-8a36-6d52c023cd78-06e3e924dc.webp)

이름에서 알 수 있듯이 OnlyKey에는 경쟁 제품에는 없는 편리한 기능이 있습니다. 컴퓨터에 설치된 키 입력 기록 프로그램을 우회할 수 있는 내장 키패드 덕분에 컴퓨터나 웹사이트가 침해되어도 온라인 계정을 안전하게 보호할 수 있습니다. FIDO 2 U2F, Yubico OTP, TOTP 등 여러 2FA 방식을 지원합니다.  
일반적인 용도에 가장 적합한 비밀번호 관리자는 아니지만, OnlyKey 하나에 OTP 계정 24개, 비밀번호 24개, 사용자 이름/URL 24개를 저장할 수 있습니다. 여러 비밀번호를 외우기 번거롭고 키가 대신 관리해 주기를 바란다면 이 기능이 상당히 편리합니다.  
암호화된 백업, 일정 횟수 이상 잘못 입력하면 장치의 데이터를 삭제하는 자폭 기능, 새로운 기능을 이용할 수 있도록 펌웨어를 업데이트하는 기능 등을 제공합니다. 단점은 사용자 인터페이스가 그다지 편리하지 않다는 것입니다.

## 2FA 하드웨어 키를 Google 계정에 연결하기

이제 2FA 하드웨어 키가 무엇이고 어떻게 작동하는지 알아보았으니, 키를 Google 계정에 연결하는 방법을 살펴보겠습니다.

**1단계**  
Gmail 계정에 로그인한 다음 **Google 계정 관리**를 클릭합니다.

![Google Account - Manage Account](/content-images/995fc955-791a-4456-9218-7e5964da48b5-31c64640b2.webp)

**2단계**  
**보안**을 클릭합니다.

![Google Security Settings](/content-images/246db235-6596-41ff-bd7a-f8ee4f80962b-340193c2c3.webp)

**3단계**  
**2단계 인증**을 클릭합니다.

![2-Step Verification Screen](/content-images/19cd202a-1a70-47e6-a02a-aa24f6e199fa-a9fcb911ce.webp)

**4단계**  
**옵션 더보기**를 선택합니다.

![Show More Options](/content-images/2ade9531-1cf6-48e8-b9a8-178d41a4cd30-b1e9ea1400.webp)

**5단계**  
이제 **보안 키**를 선택한 다음 **다음**을 클릭합니다.

**6단계**  
2FA 보안 키를 연결합니다.

**7단계**  
장치 이름을 입력하고 **완료**를 클릭합니다.
