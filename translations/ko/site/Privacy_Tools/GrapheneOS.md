# Graphene OS

## 요약

- **GrapheneOS**는 프라이버시와 보안에 중점을 둔 비영리 오픈 소스 모바일 운영체제로, 일상적으로 사용하는 Android 앱과 완벽하게 호환됩니다.
- 핵심 강점: 강화된 앱 샌드박스, 메모리 안전 코드와 익스플로잇 완화, 하드웨어 기반 검증 부팅, 세분화된 권한 설정, 기기가 잠겨 있을 때 USB-C 포트 보호
- 공식 **WebUSB 설치 프로그램**(대부분의 사용자에게 권장) 또는 기술에 익숙한 사용자를 위한 **명령줄 설치 절차**를 통해 설치할 수 있습니다.
- Zcash 사용자라면 유지 관리가 잘되는 거래정보 보호 지갑과 기본적인 OPSEC 보안 수칙을 함께 적용해 모바일 자기 수탁을 위한 탄탄한 기반으로 활용할 수 있습니다.

GrapheneOS는 Android 앱과의 호환성을 유지하면서 모바일 기기의 프라이버시와 보안을 강화하는 데 전념하는 비영리 오픈 소스 프로젝트입니다. 이 운영체제는 프라이버시 및 보안 기술의 발전, 특히 샌드박싱 강화, 익스플로잇 완화, 권한 모델 개선에 중점을 둡니다. 2014년 **CopperheadOS**라는 이름으로 시작된 이 프로젝트는 이후 디지털 프라이버시와 보안을 지키는 강력한 수호자로 발전했습니다.

GrapheneOS의 주요 목표는 사용자 경험에 부정적인 영향을 주지 않으면서 앱 샌드박스와 같은 보안 경계를 강화하는 것입니다.

GrapheneOS에는 네트워크 권한, 센서 권한 또는 기기가 잠겨 있을 때의 제한(USB 주변기기, 카메라 접근, 빠른 설정 타일 등)과 같은 특정 기능을 위한 여러 전환 설정이 포함될 수 있습니다. 또한 사용자가 직접 이용하는 더 복잡한 프라이버시 및 보안 기능도 각각의 사용자 인터페이스 개선 사항과 함께 사용자 친화적인 경험을 유지하도록 세심하게 설계되어 있습니다.

## **GrapheneOS의 기능**

**보안 강화** GrapheneOS에는 일반적인 취약점을 줄이기 위한 메모리 안전 프로그래밍 언어와 컴파일러 기반 보안 기능 등 광범위한 보안 개선 사항이 포함됩니다.

**샌드박싱** 앱을 서로 격리해 잠재적인 공격 경로를 제한하도록 앱 샌드박싱을 강화합니다.

**검증 부팅** GrapheneOS는 하드웨어 기반 키와 검증 가능한 부팅 절차를 사용해 운영체제의 무결성을 보장합니다.

**향상된 권한 관리** 앱 권한을 더욱 세밀하게 제어할 수 있어, 앱이 접근할 수 있는 데이터를 사용자가 조정하고 관리할 수 있습니다.

**프라이버시 대시보드** 사용자는 프라이버시 대시보드를 통해 앱 동작을 모니터링하고 제어할 수 있으며, 데이터 사용 내역을 투명하게 확인할 수 있습니다.

**보안 업데이트 기본 제공** GrapheneOS는 시기적절한 보안 업데이트를 제공해 사용자가 최신 취약점 방어 기능을 이용할 수 있도록 합니다.

**강력한 암호화** 기본적으로 전체 디스크 암호화를 적용해 기기에 저장된 데이터를 보호합니다.

**향상된 브라우저 보안** 기본 브라우저는 추적 방지 기능을 포함해 보안이 강화되도록 설정되어 있습니다.

**최소한의 사전 설치 앱** GrapheneOS에는 사전 설치된 앱이 최소한으로 포함되어 잠재적인 보안 및 프라이버시 위험을 줄입니다.

**USB 포트 공격 방지** 기기가 잠겨 있을 때 USB 포트를 통한 무단 접근을 방지합니다.

**악성코드 방지 기능** GrapheneOS에는 알려진 악성코드를 탐지하고 차단하는 기능이 포함됩니다.

**프라이버시 중점 설계** 이 운영체제는 사용자 프라이버시를 중시하도록 설계되어 데이터 수집과 노출을 최소화합니다.

**오픈 소스** 오픈 소스 프로젝트이므로 보안 개선을 위한 투명성과 커뮤니티 기여가 가능합니다.

**사용자 지정 보안 정책** 사용자는 각자의 선호에 맞게 다양한 보안 정책을 설정할 수 있습니다.

**호환성** GrapheneOS는 Android 앱과의 호환성을 유지하기 위해 노력하므로, 사용자는 향상된 보안 및 프라이버시 기능의 혜택을 누리면서도 즐겨 사용하는 애플리케이션을 계속 이용할 수 있습니다.

## **GrapheneOS 설치**

모범 사례 섹션에서 언급했듯이 권장되는 공식 설치 안내서를 이용하는 것이 좋습니다. GrapheneOS 설치 방법은 2가지입니다. [WebUSB 기반 설치 프로그램](https://grapheneos.org/install/web)을 이용하거나 [명령줄 설치 안내서](https://grapheneos.org/install/cli)를 이용할 수 있습니다.

**웹 USB 기반 설치** 웹 설치 프로그램을 사용해 GrapheneOS를 설치하려면 일반적으로 다음 자료와 리소스가 필요합니다.

- 여유 메모리 2GB 및 여유 저장 공간 32GB
- USB 케이블(A 또는 C)
- 지원되는 호스트 운영체제와 정상 작동하는 WebUSB 지원 브라우저를 사용합니다. 지원 버전 및 브라우저 패키지 제한은 최신 [공식 WebUSB사전 요구 사항](https://grapheneos.org/install/web#prerequisites)을 확인하세요. 지원이 종료된 구형 시스템은 공식적으로 지원되지 않습니다.
- 지원되는 Android 기기, ChromeOS 또는 GrapheneOS에서도 웹 설치 프로그램을 실행할 수 있습니다. 모든 Chromium 패키지가 WebUSB를 지원한다고 가정하지 말고, 공식 안내서에서 브라우저별 참고 사항을 확인하세요.

아래 링크의 설치 안내서를 확인하고 설치 절차를 따르세요.

[GrapheneOS 웹 설치 프로그램 안내서](https://grapheneos.org/install/web#prerequisites)

**명령줄 설치** 명령줄 설치는 기술에 익숙하지 않은 사용자에게 권장되지 않습니다. 명령줄로 설치하려면 다음 도구와 리소스가 필요합니다.

- 여유 메모리가 최소 2GB이고 여유 저장 공간이 32GB 이상이어야 합니다.
- USB 케이블(A 또는 C)
- [최신 명령줄 설치 사전 요구 사항](https://grapheneos.org/install/cli#prerequisites)에서 지원하는 호스트 운영체제를 사용하고, 필요한 도구는 해당 안내서를 따르세요.
- Android, ChromeOS 및 GrapheneOS 호스트에서는 웹 설치 프로그램을 사용해야 합니다. 해당 운영체제는 지원되는 명령줄 설치 호스트 목록에 포함되어 있지 않습니다.

아래 링크의 설치 안내서를 확인하고 설치 절차를 따르세요.

[명령줄 설치](https://grapheneos.org/install/cli#prerequisites)

## **모범 사례**

**운영체제를 최신 상태로 유지하세요** GrapheneOS를 정기적으로 업데이트해 최신 보안 패치와 개선 사항을 적용하세요.

**강력한 비밀번호를 사용하세요** 무단 접근을 방지하려면 기기 암호화와 앱 로그인에 강력하고 고유한 비밀번호를 설정하세요.

**앱 권한** 앱 권한을 주의 깊게 검토하고 관리해 각 앱의 작동에 필요한 권한만 허용하세요.

**정기적으로 백업하세요** 기기를 잃어버리거나 데이터가 손상될 경우에 대비해 데이터를 정기적으로 백업하세요.

**저장 공간을 암호화하세요** 기본적으로 암호화가 활성화되어 있지 않다면 기기를 분실하거나 도난당했을 때 데이터를 보호할 수 있도록 저장 공간을 암호화하세요.

**안전한 잠금 화면** 무단 접근을 방지하려면 PIN, 비밀번호 또는 생체 인증과 같은 안전한 잠금 화면을 사용하세요.

**설치 후 부트로더를 다시 잠그세요** 공식 설치 절차에서는 GrapheneOS를 플래시하기 위해 부트로더를 [일시적으로 잠금 해제](https://grapheneos.org/install/web#unlocking-the-bootloader)한 다음, 완전한 검증 부팅을 활성화할 수 있도록 사용 전에 [다시 잠가야 합니다](https://grapheneos.org/install/web#locking-the-bootloader). 잠금을 해제하거나 다시 잠글 때마다 모든 사용자 데이터가 지워지므로 먼저 백업하고 공식 절차를 순서대로 따르세요. 설치된 운영체제를 루팅하지 마세요.

**앱 출처를 확인하세요** 악성 소프트웨어 설치를 피하려면 앱과 앱 출처의 진위를 확인하세요.

**프라이버시 중심 브라우저를 설치하세요** 안전한 웹 탐색을 위해 Brave 브라우저, Firefox 또는 Bromite와 같은 프라이버시 중심 브라우저를 사용해 보세요.

**앱을 정기적으로 점검하세요** 공격 표면을 줄이려면 더 이상 사용하지 않거나 신뢰하지 않는 앱을 주기적으로 검토하고 삭제하세요.

**2단계 인증(2FA)을 활성화하세요** 보안을 한층 강화하려면 온라인 계정에서 2FA를 활성화하세요.

**공용 Wi-Fi를 피하세요** 공용 Wi-Fi 네트워크는 보안이 취약할 수 있으므로 연결할 때 주의하세요. 필요한 경우 VPN을 사용하세요.

**위치 데이터에 주의하세요** 앱의 위치 추적을 제한하고, 프라이버시를 중요하게 여긴다면 위치를 속이는 도구 사용을 고려하세요.

**알 수 없는 링크와 첨부 파일을 피하세요** 요청하지 않은 링크와 이메일 첨부 파일은 피싱 시도나 악성코드일 수 있으므로 주의하세요.

**기본 설정을 검토하세요** 기본 설정을 꼼꼼히 검토하고 프라이버시 선호에 맞게 조정하세요.

**커뮤니티 지원** GrapheneOS 커뮤니티와 포럼에 참여해 팁, 업데이트, 보안 조언을 확인하세요. 팀에 문의하고 최신 정보를 확인하려면 [여기](https://grapheneos.org/contact)를 클릭해 추가 연락처를 확인하세요.

**공식 설치 방법을 사용하세요** GrapheneOS는 공식적으로 지원되는 설치 방법 2가지를 제공합니다. 대부분의 사용자에게 권장되는 WebUSB 기반 설치 프로그램을 선택하거나, 기술에 더 익숙한 사용자를 위한 명령줄 설치 안내서를 따를 수 있습니다.

## **결론**

요컨대 GrapheneOS는 사용자의 프라이버시와 보안을 우선시하는 대안적인 모바일 운영체제를 제공해, 사용자가 의존하는 앱과의 호환성을 유지하면서 디지털 생활을 더 폭넓게 통제할 수 있도록 합니다. 프라이버시와 보안이 무엇보다 중요한 시대에 모바일 기기의 보안과 프라이버시에 대한 높은 기준을 세우려는 프로젝트입니다.
