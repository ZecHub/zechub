# 웹 브라우저

1. **Brave:** 현재 시장에서 가장 두드러지고 안전한 브라우저 중 하나입니다. 프라이버시(privacy)를 침해하는 광고와 트래커를 차단합니다. 제3자 데이터 저장도 차단합니다.

2. **Mullvad:** Mullvad VPN과 Tor Project가 협력하여 개발한 프라이버시 중심 웹 브라우저입니다. 추적과 핑거프린팅을 최소화하도록 제작되었습니다.

3. **Tor:** 이 브라우저는 Flash, RealPlayer, QuickTime 등의 플러그인을 차단합니다. 이러한 플러그인은 사용자의 IP 주소를 노출하도록 조작될 수 있습니다. Tor Browser에 추가 애드온이나 플러그인을 설치하는 것은 권장하지 않습니다.


## 웹 브라우저를 선택할 때 고려해야 할 보안 사항은 무엇인가요?

웹 브라우저를 선택할 때는 몇 가지 유념해야 할 사항이 있습니다. 보안 취약점과 악용 사례는 대개 정기적으로 발견됩니다. 일부 브라우저는 어떤 식으로든 추적될 수 있지만, 익명으로 인터넷을 이용할 수 있게 해 주는 브라우저도 있습니다. 예를 들어 [Tor 브라우저](https://download.torproject.org/)가 있습니다.

**핑거프린팅**: 컴퓨터에 설치된 소프트웨어, 하드웨어 구성 등을 비공개로 유지하려면 핑거프린팅 방지 기능을 지원하는 웹 브라우저를 찾아보세요.

**HTTPS 테스트**: 웹 브라우저를 선택할 때 고려해야 할 또 다른 보안 사항은 HTTPS 테스트 프로토콜입니다. 이 프로토콜은 웹사이트 연결을 암호화하고 쿠키, URL 및 기타 민감한 메타데이터를 숨기는 데 도움을 줍니다. HTTPS를 사용하면 연결이 암호화되므로 네트워크상의 제3자는 서버와 브라우저 간에 전송되는 콘텐츠를 읽을 수 없습니다.

**추적 쿠키 보호**: 또한 월드 와이드 웹의 상당수 웹페이지에는 숨겨진 제3자 트래커가 있습니다. 이러한 트래커는 브라우저의 쿠키를 읽고 기록합니다. 쿠키는 웹사이트를 이용하는 동안 사용자의 활동을 추적하는 데 사용될 수 있으므로 악의적인 위협이 될 수 있습니다. 이러한 추적을 막으려면 출처가 확인되지 않은 브라우징 쿠키를 차단하는 웹 브라우저를 선택하세요.

**탐색 테스트**: 한 웹페이지에서 다른 웹페이지로 이동하다 보면 많은 링크를 접하게 됩니다. 일부는 내부 링크이고, 나머지는 다른 웹사이트로 연결되는 링크입니다. 이러한 링크를 클릭하면 특정 브라우저 API를 통해 첫 번째 사이트가 두 번째 사이트와 통신할 수 있습니다. 이 문제를 해결하려면 링크를 클릭할 때 웹사이트가 추적 데이터를 공유하지 못하게 하는 웹 브라우저를 선택하세요. 필요에 맞는 브라우저를 선택할 때는 강력한 프라이버시 기능과 광고 차단기 같은 필수 기능이 내장되어 있는지 확인하세요. 또한 이러한 웹 브라우저 중 다수는 확장 프로그램과 애드온을 지원하지만, 때로는 확장 프로그램이 보안 위험을 초래할 수 있습니다. 확장 프로그램은 항상 안전한 생태계나 신뢰할 수 있는 출처에서 설치하세요.
 
## Brave 브라우저 Zcash 지갑 통합

Brave 브라우저는 Web3 생태계의 길을 열고 있습니다. 어떻게 가능할까요? 이제 2백만 개가 넘는 검열 불가능한 도메인을 탈중앙화 웹사이트 표시용으로 활용할 수 있습니다. Brave Browsers의 강력한 보안 기능을 통해 사람들은 추적당하지 않고 인터넷을 이용할 수 있습니다. Brave와 Zcash는 Web3 생태계에 새로운 프라이버시 도구를 제공하기 위해 협력하고 있습니다. 더 큰 혜택을 위해 Brave는 Brave에 내장된 암호화폐 지갑을 통해 Zcash 프로토콜과 신속하게 통합될 예정입니다. 이를 통해 암호화폐 거래를 혁신할 수 있습니다. 이 통합으로 사용자는 ZEC를 비롯한 다른 암호화폐를 매우 간편하고 안전하게 보관하고 전송하며 수신할 수 있습니다. Brave 웹 브라우저와 Zcash의 협력은 사용자가 자신의 Web3 활동을 더 폭넓게 통제할 수 있게 하여 판도를 바꿀 것입니다.

Brave 브라우저와 Zcash의 통합에는 또 다른 흥미로운 점이 있습니다. 바로 프라이빗하고 탈중앙화된 메시지 기능입니다. Brave, ECC, Filecoin Foundation 팀은 Brave 브라우저에 프라이버시 기반 기능을 도입하기 위해 길을 열고 있습니다. 이 협력은 Zcash 프로토콜을 통해 비공개 메시지와 미디어를 전송하는 기능을 제공하는 것을 목표로 합니다. 여기서 행성 간 파일 시스템(Interplanetary File System, IPFS)은 암호화된 콘텐츠를 안전하게 저장할 수 있도록 하는 데 중요한 역할을 합니다.
