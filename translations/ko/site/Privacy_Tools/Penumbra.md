# Penumbra 

Penumbra은 Cosmos 생태계의 완전 차폐형 지분증명 레이어 1 네트워크이자 탈중앙화 거래소입니다. 인터체인 차폐 풀은 IBC로 연결된 체인의 자산을 보유할 수 있습니다. 사용자는 개별 계정 잔액을 공개하거나 해당 활동을 자신의 신원과 연결하지 않고 Penumbra 내에서 전송, 스테이킹, 스왑 및 유동성 제공을 할 수 있습니다. 그렇다고 모든 네트워크 또는 DEX 데이터가 비공개라는 의미는 아닙니다.

## Penumbra IBC에서 사용되는 기술 

IBC 통합: 인터블록체인 통신(IBC) 프로토콜은 Penumbra을 다른 IBC 지원 체인에 연결합니다. 수신 IBC 전송은 자금이 Penumbra에 들어올 때 이를 차폐하고, 송신 전송은 자금이 나갈 때 차폐를 해제합니다. 수신 예치금의 목적지 주소를 포함하여 투명한 상대방 체인에서의 활동은 공개 상태로 유지됩니다. [프라이버시 경계는 IBC 경계를 따릅니다](https://guide.penumbra.zone/overview/interchain-privacy).

영지식 증명(ZKP): Penumbra은 사용자의 비공개 거래 데이터를 공개하지 않고도 암호화된 상태 업데이트가 유효함을 보여 주기 위해 클라이언트 측 영지식 증명을 사용합니다. 지갑은 자신에게 보이는 데이터를 로컬에서 스캔하고 복호화하며, 공개 노드는 사용자의 비공개 잔액을 단순히 반환할 수 없습니다.

프라이버시를 갖춘 탈중앙화 거래소: Penumbra에는 차폐 풀 내에서 자산을 거래하기 위한 DEX가 포함되어 있습니다. 개별 스왑 결과물은 비공개이지만, 배치 실행 결과와 익명 유동성 포지션은 공개됩니다. 거래소가 무엇을 숨기는지 설명할 때 이러한 차이가 중요합니다.

## 사용 사례

안전한 거래: Penumbra의 차폐 풀 내 전송은 송신자, 수신자, 금액 및 자산 유형을 보호합니다. 사용자는 권한을 부여받은 제3자에게 활동을 선택적으로 공개할 수 있습니다. 수신 주소만 공유한다고 해서 해당 소유자의 잔액이 노출되지는 않습니다. 자금이 출금된 후 다른 체인에서 이루어지는 공개 활동에는 이러한 특성이 적용되지 않습니다.

스테이킹: Penumbra의 네이티브 스테이킹 토큰은 **UM**입니다. UM을 검증인에게 위임하면 해당 검증인의 위임 풀 지분을 나타내는 위임 토큰을 받습니다. 각 검증인 풀의 총 스테이킹은 공개되지만, 개별 위임은 익명입니다. 위임 해제는 먼저 검증인별 언본딩 토큰을 생성하며, 이는 언본딩 지연 기간이 끝날 때까지 슬래싱에 노출된 상태로 유지됩니다. 공식 [차폐 스테이킹 가이드](https://guide.penumbra.zone/overview/staking)를 참조하세요.

토큰 스왑: 스왑 의도는 거래 쌍별로 그룹화되어 각 블록의 끝에서 배치로 실행됩니다. 이로써 트레이더가 스왑 의도의 블록 내 순서를 활용할 수 없게 됩니다. 이는 특정 메커니즘일 뿐, 어떠한 형태의 MEV도 존재할 수 없다는 보장은 아닙니다. 배치 결과는 공개 체인 상태에 기록되며, 사용자는 결과 중 자신의 몫을 비공개로 차폐 풀에 청구합니다. [DEX 가이드](https://guide.penumbra.zone/overview/dex)는 배치 실행과 프로토콜의 자동 차익거래를 설명합니다.

마켓 메이킹: 유동성 제공자는 익명의 집중 유동성 포지션을 생성합니다. 포지션의 유동성과 거래 기능은 공개되지만 제공자의 신원과 연결되지는 않습니다.
