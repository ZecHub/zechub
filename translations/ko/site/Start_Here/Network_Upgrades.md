# Zcash 네트워크 업그레이드

Zcash는 네트워크 업그레이드를 통해 개선됩니다. 이는 모든 노드가 동의하는 규칙을 조정하는 변경으로, 각각 정해진 블록 높이에서 활성화됩니다. 아래의 모든 업그레이드에는 무엇이 왜 변경되었는지를 쉬운 말로 설명하는 자체 페이지가 있습니다. Zcash가 처음이신가요? Sprout부터 Ironwood까지 순서대로 읽어 보세요.

이러한 업그레이드 전반에 걸쳐 Zcash의 프라이버시가 어떻게 발전해 왔는지 시각적으로 살펴보려면 [프라이버시의 진화](https://zechub.wiki/zcash-evolution)를 참조하세요. 이 페이지는 색인입니다. 해당 페이지는 타임라인입니다.

### NU7 상태

NU7는 높이 **4,465,026**에서 공개 테스트넷에 활성화되어 있습니다(2026년 10월 4일 활성화). 메인넷 활성화 높이는 **2026년 10월 20일**에 선택될 예정이며, 현재 목표일은 **2026년 11월 5일**입니다.

범위(ZIP 259):

- **25초 블록**(ZIP 218) — 첫 번째 확인이 약 3배 더 빨라지며, 일일 ZEC 발행량은 변하지 않습니다.
- **네트워크 지속 가능성 메커니즘**(ZIP 235 + ZIP 237) — 트랜잭션 수수료의 60%를 유통에서 제거하여 준비금으로 적립하고, 약 2031년 2월부터 반감기를 유지하는 일정에 따라 채굴자에게 재발행합니다.
- **Sprout 폐기**(ZIP 2003) — 버전 4 트랜잭션이 무효화되며, 남아 있는 Sprout 자금은 사용할 수 없게 됩니다.
- 실드 액션 한도 및 더 넓어진 난이도 평균 산정 기간(17 → 102블록).

새로운 트랜잭션 형식은 도입되지 않습니다. 합의 브랜치 ID: `0x77190ad9`.

전체 세부 정보는 [프라이버시의 진화](https://zechub.wiki/zcash-evolution) 타임라인과 [ZIP 259](https://zips.z.cash/zip-0259)를 참조하세요. 포럼 타임라인: [NU7 타임라인](https://forum.zcashcommunity.com/t/nu7-timeline/57655).
