# Zcash 개발 기금

Zcash은(는) 자체 자금으로 운영된다는 점에서 독특한 블록체인 프로토콜입니다. 이는 Zcash에서 작업하는 팀들이 외부 투자자로부터 자금을 받을 필요가 없으며, Zcash의 더 넓은 정신과 사명에 부합하는 동시에 채택을 촉진하는 데 집중할 수 있음을 의미합니다.
