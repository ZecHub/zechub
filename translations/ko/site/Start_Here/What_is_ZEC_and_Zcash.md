# Zcash 기초

## 핵심 요약

- **ZEC**는 Zcash 블록체인을 기반으로 구축된 프라이버시 우선 디지털 화폐입니다
- Bitcoin과 달리 ZEC는 영지식 증명(zero-knowledge proofs)을 사용해 완전히 **거래정보 보호(비공개) 거래**를 지원합니다
- 금융 프라이버시를 직접 관리할 수 있습니다. 무엇을 누구에게 공개할지 선택하세요
- Zcash는 오픈 소스이며, 무허가이고 탈중앙화되어 있습니다

ZEC는 Zcash 블록체인을 기반으로 한 디지털 화폐입니다. 웹에서 현금과 가장 비슷한 형태입니다. Bitcoin과 여러 특징을 공유하지만, 사용자가 완전히 비공개로 금전 거래를 할 수 있게 해 Bitcoin의 가장 큰 결함을 해결합니다.

#### 비공개 화폐가 중요한 이유는 무엇인가요?

ZEC는 사람들이 무허가 방식으로 데이터를 전송할 수 있게 합니다. P2P 방식의 무허가 화폐 시스템을 통해 사람들은 중앙화된 기관과 독립적으로 가치를 저장하거나 다른 사람과 거래할 수 있습니다. ZEC를 사용하면 자신의 금융 정보 공개 시점을 선택할 수 있습니다.

## Zcash란 무엇인가요?

Zcash는 “Zerocash” 프로토콜을 구현한 것입니다. 정교한 영지식 증명 시스템을 갖춘 오픈 소스 블록체인 기반 원장입니다. Bitcoin의 코드를 기반으로 하며, 증명 시스템을 통해 [거래 메타데이터](https://nym.com/blog/what-is-metadata)의 기밀성을 유지하여 더 높은 수준의 프라이버시를 제공합니다. Zcash의 핵심은 비공개 데이터 소유권이며, 거래가 이루어질 때 무허가 방식으로 이전됩니다.

#### 왜 중요한가요?

Zcash는 Bitcoin의 가장 큰 결함인 비공개 데이터 소유와 이전 문제를 해결합니다. 블록체인 애플리케이션과 암호화폐가 널리 받아들여지는 세상에서 가명 거래만으로는 더 이상 사용자의 프라이버시를 보호할 수 없습니다. 블록체인 거래를 분석하는 감시 애플리케이션의 사용이 점점 늘고 있습니다.
