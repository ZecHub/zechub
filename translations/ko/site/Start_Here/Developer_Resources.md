# 개발자 리소스

[Zcash 문서](https://zcash.readthedocs.io/en/latest/)

[Mastering Bitcoin: 오픈 블록체인 프로그래밍](https://www.amazon.com/Mastering-Bitcoin-Programming-Open-Blockchain-ebook/dp/B071K7FCD4)

[Zcashd RPC](https://zcash.github.io/rpc/)

[The Zcashd Book](https://zcash.github.io/zcash/)

이 목록은 Zcash Foundation 및 ECC의 개발자들이 제공한 추천 자료를 바탕으로 작성되었습니다. 

목록을 업데이트할 수 있는 추가 리소스(링크, 책, 채널 등)가 있다면 자유롭게 포함해 주세요!

*팀이 항상 모든 것을 완전히 최신 상태로 유지할 자원을 갖추고 있는 것은 아니지만, 사용 중 마주친 문제에 대해 이슈를 열면 가이드와 리소스의 방향을 잡는 데 도움이 됩니다*
