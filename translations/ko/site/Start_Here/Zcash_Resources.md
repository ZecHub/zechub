# Zcash 리소스

사용자가 Zcash를 이해하는 데 도움이 되는 다양한 리소스가 있습니다.

**[Zcash Media](https://www.youtube.com/c/ZcashMedia)**

Zcash Media는 Zcash에 관한 교육 다큐멘터리를 제작하는 독립 조직입니다. 첫 번째 영상인 "Built to Fix Bitcoin's Fatal Flaw, What is Zcash (ZEC)?"는 Zcash를 훌륭하게 소개합니다.

**[X (구 Twitter)](https://x.com)**

Twitter는 Zcash 커뮤니티와 더 넓은 암호화폐 분야의 사실상 소통 허브입니다. Zcash 관련 모든 소식의 흐름을 파악하고 저명한 커뮤니티 구성원을 팔로우하기에 좋은 곳입니다. 팔로우할 주요 계정을 나열한 [문서](https://www.notion.so/zechub/Social-Media-Links-05b9df645af54de7a1989d9c4ccc4d05)가 있습니다.

**[Zcash Community](https://www.zcashcommunity.com/)**

Zcash Community는 Zcash 생태계를 지원하는 커뮤니티 주도 프로젝트를 소개하는 커뮤니티 운영 사이트입니다. Zcash 커뮤니티와 화폐로서의 다양한 활용 사례를 처음 접하기에 좋은 방법입니다.

**[Zcash 포럼](https://forum.zcashcommunity.com/)**

신규 사용자 가이드에서 언급했듯이, Zcash 포럼은 Zcash 주제와 제안된 아이디어에 관해 긴 형식의 토론을 나누기 좋은 장소입니다. 제안은 항상 포럼에 게시되므로 커뮤니티가 제안된 아이디어를 논의하고 토론할 기회를 얻습니다.

**[Z.cash](https://z.cash/)**

Z.cash는 Zcash의 주요 웹사이트입니다. 폭넓은 사용자를 위한 Zcash 콘텐츠와 문서를 제공하며, 신규 사용자가 Zcash의 기술적 설명을 더 깊이 살펴볼 수 있게 합니다.

**[Zcash Github](https://github.com/zcash/zcash)**

코딩 실력이 있고 Zcash의 기술적 측면을 더 깊이 탐구하고 싶으신가요? Zcash Github Repo는 최초의 Zcash 노드 구현체인 zcashd의 저장소입니다. zcashd는 2026년 7월 18일 자동 지원 종료에 도달하여 더 이상 유지보수되지 않으며, 이 항목이 이전에 연결하던 다운로드 페이지도 더 이상 제공되지 않습니다. 유지보수되는 스택은 노드용 [Zebra](https://github.com/ZcashFoundation/zebra)와 지갑용 [Zallet](https://github.com/zcash/zallet)입니다 — [zcashd에서 Zebra 및 Zallet으로의 마이그레이션 가이드](https://zechub.wiki/guides/migration-guide-zcashd-to-zebrad-zallet)를 참조하세요.

**[Zcash Foundation Github](https://github.com/ZcashFoundation)**

Rust로 작성된 Zcash 노드 구현체 [zebra](https://github.com/ZcashFoundation/zebra)를 포함하여 Zcash Foundation의 프로젝트를 호스팅하는 또 다른 GitHub 저장소입니다.

**[Halo2](https://zcash.github.io/halo2/index.html)**

영지식 증명 시스템의 기반이 되는 개념입니다.

**[Zcash RPC 문서](https://zcash.github.io/rpc/)**

zcashd가 노출한 RPC 명령 목록입니다. 유지보수되는 지갑 RPC 인터페이스는 [Zallet Book](https://zcash.github.io/zallet/)을 참조하세요.
