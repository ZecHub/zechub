# Zcash 자료

사용자들이 Zcash을 이해하는 데 도움이 되는 자료가 많이 있습니다.

**[Zcash 미디어](https://www.youtube.com/c/ZcashMedia)**

Zcash 미디어는 Zcash에 관한 교육 다큐멘터리를 제작하는 독립 단체입니다. 첫 번째 영상인 “”비트코인의 치명적인 결함을 해결하도록 설계된 Zcash(ZEC)란 무엇인가?””는 Zcash을 소개하는 훌륭한 자료입니다.

**[X(구 Twitter)](https://x.com)**

Twitter는 Zcash 커뮤니티뿐 아니라 더 넓은 암호화폐 업계의 사실상 소통 중심지입니다. Zcash 관련 소식을 전반적으로 파악하고 주요 커뮤니티 구성원을 팔로우하기에 좋은 곳입니다. 팔로우할 주요 계정을 정리한 [문서](https://www.notion.so/zechub/Social-Media-Links-05b9df645af54de7a1989d9c4ccc4d05)도 참고해 보세요.

**[Zcash 커뮤니티](https://www.zcashcommunity.com/)**

Zcash 커뮤니티는 Zcash 생태계를 지원하는 커뮤니티 주도 프로젝트를 소개하는 커뮤니티 운영 사이트입니다. Zcash 커뮤니티와 화폐로서의 다양한 활용 사례를 알아보기에 좋습니다.

**[Zcash 포럼](https://forum.zcashcommunity.com/)**

신규 사용자 가이드에서 언급했듯이, Zcash 포럼은 Zcash 관련 주제와 제안된 아이디어를 놓고 심도 있는 토론을 나누기에 좋은 곳입니다. 제안은 언제나 포럼에 게시되므로 커뮤니티 구성원들이 제안된 아이디어를 논의하고 토론할 수 있습니다.

**[Z.cash](https://z.cash/)**

Z.cash는 Zcash의 주요 웹사이트입니다. 다양한 사용자를 위해 Zcash의 콘텐츠와 문서를 제공하며, 신규 사용자가 Zcash에 관한 기술 설명을 더 깊이 살펴볼 수 있도록 합니다.

**[Zcash GitHub](https://github.com/zcash/zcash)**

코딩에 능숙하고 Zcash의 기술적인 측면을 더 깊이 알아보고 싶으신가요? Zcash GitHub 저장소는 최초의 Zcash 노드 구현체인 zcashd의 저장소입니다. zcashd은 2026년 7월 18일에 자동 지원 종료에 따라 작동이 중단되었으며 더 이상 유지 관리되지 않습니다. 또한 이 항목에서 연결하던 다운로드 페이지도 더 이상 제공되지 않습니다. 현재 유지 관리되는 스택은 노드용 [Zebra](https://github.com/ZcashFoundation/zebra)과 지갑용 [Zallet](https://github.com/zcash/zallet)입니다. [zcashd에서 Zebra 및 Zallet로 이전하는 안내서](https://zechub.wiki/guides/migration-guide-zcashd-to-zebrad-zallet)를 참조하세요.

**[Zcash Foundation GitHub](https://github.com/ZcashFoundation)**

Zcash Foundation의 프로젝트를 호스팅하는 또 다른 GitHub 저장소로, Rust의 Zcash 노드 구현체인 [zebra](https://github.com/ZcashFoundation/zebra)도 포함되어 있습니다.

**[Halo2](https://zcash.github.io/halo2/index.html)**

영지식 증명 시스템의 기본 개념입니다.

**[Zcash RPC 문서](https://zcash.github.io/rpc/)**

zcashd에서 제공하는 RPC 명령어 목록입니다. 현재 유지 관리되는 지갑 RPC 인터페이스는 [Zallet Book](https://zcash.github.io/zallet/)을 참조하세요.
