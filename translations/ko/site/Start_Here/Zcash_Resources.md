# Zcash 리소스

사용자가 Zcash를 이해하는 데 도움이 되는 여러 리소스가 있습니다.

**[Zcash Media](https://www.youtube.com/c/ZcashMedia)**

Zcash Media는 Zcash에 관한 교육 다큐멘터리를 제작하는 독립 기관입니다. 이들의 첫 번째 영상인 "Bitcoin의 치명적 결함을 고치기 위해 만들어진 Zcash (ZEC)란 무엇인가?"는 Zcash를 훌륭하게 소개합니다.

**[X (구 Twitter)](https://x.com)**

Twitter는 Zcash 커뮤니티와 더 넓은 암호화폐 분야의 사실상 소통 허브입니다. Zcash와 관련된 모든 소식을 빠르게 파악하고 주요 커뮤니티 구성원을 팔로우하기에도 좋은 곳입니다. 팔로우할 주요 계정을 정리한 [문서](https://www.notion.so/zechub/Social-Media-Links-05b9df645af54de7a1989d9c4ccc4d05)가 있습니다.

**[Zcash Community](https://www.zcashcommunity.com/)**

Zcash Community는 Zcash 생태계를 지원하는 커뮤니티 운영 프로젝트를 소개하는 커뮤니티 운영 사이트입니다. Zcash 커뮤니티와 화폐로서의 다양한 활용 사례를 알아보는 좋은 방법입니다.

**[Zcash 포럼](https://forum.zcashcommunity.com/)**

신규 사용자 가이드에서 언급했듯이, Zcash 포럼은 Zcash 관련 주제와 제안된 아이디어를 장문의 형식으로 논의하기에 좋은 곳입니다. 제안은 항상 포럼에 게시되므로 커뮤니티는 제안된 아이디어를 논의하고 토론할 기회를 얻습니다.

**[Z.cash](https://z.cash/)**

Z.cash는 Zcash의 주요 웹사이트입니다. 폭넓은 사용자를 위한 Zcash 콘텐츠와 문서를 제공하며, 신규 사용자가 Zcash의 기술적 설명을 더 깊이 살펴볼 수 있도록 합니다.

**[Zcash GitHub](https://github.com/zcash/zcash)**

코딩 실력이 있고 Zcash의 기술적 측면을 더 깊이 살펴보고 싶으신가요? Zcash GitHub 리포지토리는 최초의 Zcash 노드 구현인 zcashd의 리포지토리입니다. zcashd는 2026년 7월 18일 자동 지원 종료에 도달하여 더 이상 유지 관리되지 않으며, 이 항목이 이전에 연결했던 다운로드 페이지도 더 이상 제공되지 않습니다. 유지 관리되는 스택은 노드용 [Zebra](https://github.com/ZcashFoundation/zebra)와 지갑용 [Zallet](https://github.com/zcash/zallet)입니다 — [zcashd에서 Zebra 및 Zallet로의 마이그레이션 가이드](https://zechub.wiki/guides/migration-guide-zcashd-to-zebrad-zallet)를 참조하세요.

**[Zcash Foundation GitHub](https://github.com/ZcashFoundation)**

Rust로 작성된 Zcash 노드 구현인 [zebra](https://github.com/ZcashFoundation/zebra)를 포함하여 Zcash Foundation의 프로젝트를 호스팅하는 또 다른 GitHub 리포지토리입니다.

**[Halo2](https://zcash.github.io/halo2/index.html)**

영지식 증명 시스템의 기반 개념입니다.

**[Zcash RPC 문서](https://zcash.github.io/rpc/)**

zcashd가 제공했던 RPC 명령 목록입니다. 유지 관리되는 지갑 RPC 인터페이스는 [Zallet Book](https://zcash.github.io/zallet/)을 참조하세요.

_이 문서는 아직 완성되지 않았습니다_
