# Zcash 지갑 트래픽을 Nym 믹스넷으로 라우팅하기

> 마지막 확인: 2026년 9월 29일

Zcash 거래정보 보호 거래는 온체인 거래 데이터를 보호하지만, 지갑은 여전히 인터넷을 통해 통신합니다. 네트워크 관찰자는 사용자의 IP 주소, 지갑이 연결되는 시점, 접속하는 인프라와 같은 메타데이터를 알아낼 수 있습니다.

Nym은 별도의 네트워크 프라이버시 계층을 추가합니다. 2026년 9월 기준, 가장 적합한 방법은 지갑에 따라 다릅니다.

1. **지갑에 기본 Nym 통합 기능이 있으면 이를 우선 사용하세요.**
2. 그렇지 않으면 **시스템 수준의 NymVPN 믹스넷 모드**를 사용해 지갑별 프록시 지원에 의존하지 않고 지갑의 네트워크 트래픽을 Nym을 통해 라우팅하세요.

VPN 및 dVPN에 대한 일반적인 배경 설명은 [VPN 및 dVPN](../Privacy_Tools/VPN_and_DVPN.md)을 참조하세요.

## Nym이 추가하는 것과 추가하지 않는 것

거래정보 보호 Zcash 결제와 네트워크 프라이버시 도구는 서로 다른 문제를 해결합니다.

- **Zcash 거래정보 보호 구역**은 온체인 거래 세부 정보를 보호합니다.
- **Nym 믹스넷 라우팅**은 실제 네트워크 신원과 지갑 트래픽을 받는 서비스 간의 연결 가능성을 낮추도록 설계되었습니다.
- 시스템 수준의 NymVPN 터널을 통해 접속하는 대상에는 집이나 모바일 기기의 IP가 아니라 Nym 출구 IP가 표시되어야 합니다.

Nym의 믹스넷은 네트워크 메타데이터 유출을 줄이기 위해 여러 홉, 패킷 혼합, 무작위 지연, 커버 트래픽, 어니언 암호화를 사용합니다.

Nym은 기기 침해, 악성 지갑 소프트웨어, 노출된 복구 문구, 거래소 계정을 통해 공개하는 신원 정보, 투명 Zcash 활동으로 인한 프라이버시 침해를 **막지 않습니다**.

## 기본 Nym 지원: 제공되는 경우 우선 사용하세요

Nym은 2026년 9월 24일, Zcash 커뮤니티 개발 지원금으로 진행한 작업이 완료되었으며 실제 Zcash 지갑에 기본 믹스넷 지원이 제공되고 있다고 발표했습니다.

### Zingo! 지갑

Zingo PC에는 기본 Nym 전송 기능이 포함되어 있습니다. Zingo 모바일에도 앱 내 Nym 프록시를 사용하는 믹스넷 모드가 iOS와 Android에서 제공됩니다.

Zingo에 문서화된 현재 동작은 다음과 같습니다.

- Nym 제어 기능은 **설정 → Nym 믹스넷**에 있습니다.
- 결제를 보내면 믹스넷을 통해 라우팅됩니다.
- Ironwood 마이그레이션 전송에도 동일한 보호된 전송 경로가 적용됩니다.
- ZEC 가격 요청도 믹스넷을 통해 라우팅됩니다.
- Nym이 활성화된 동안에는 전송이 실패 시 닫힘 방식으로 동작합니다. 믹스넷 전송을 사용할 수 없으면 결제가 클리어넷으로 조용히 전송되지 않습니다.
- Zingo PC에서는 **체인 동기화가 현재 믹스넷을 통해 라우팅되지 않습니다**. 컴팩트 블록, nullifier 조회, 거래 가져오기, 멤풀 트래픽, 서버 상태 확인은 여전히 일반 서버 연결을 사용합니다.

이 차이는 중요합니다. Zingo의 기본 통합 기능은 연결 가능성이 가장 높은 브로드캐스트 경로를 보호하지만, 아직 기기 전체를 위한 네트워크 터널은 아닙니다.

위협 모델상 서버에 동기화 트래픽이 노출되지 않도록 해야 한다면, NymVPN과 같은 시스템 수준의 프라이버시 터널을 사용하세요. 이로 인해 추가되는 지연 시간과 복잡성도 고려해야 합니다.

출처:

- https://github.com/zingolabs/zingo-pc#the-nym-mixnet
- https://github.com/zingolabs/zingo-mobile
- https://nym.com/blog/nym-mixnet-zcash-wallets

### Zkool

Nym에 따르면, 이제 **Zkool**에서 기본 토글을 사용해 Nym 믹스넷을 통해 Zcash RPC 인프라에 연결할 수 있습니다.

Zkool은 현재 유지 관리 중인 YWallet의 후속 프로젝트입니다. 이 프로젝트는 Zcash 서버 연결에 사용할 Tor 프록시 및 어니언 서비스도 지원합니다.

문서화되지 않은 프록시 경로를 통해 구버전 YWallet 빌드를 억지로 사용하기보다는 Zkool의 기본 Nym 옵션을 우선 사용하세요.

출처:

- https://nym.com/blog/nym-mixnet-zcash-wallets
- https://github.com/hhanh00/zkool2

### Nozy

NozyWallet에도 Nym을 인식하는 전송 경로가 있습니다. 현재 구현에서는 Nym 믹스넷을 통해 발신 거래 제출을 라우팅하고, 컴팩트 블록 동기화에는 별도의 Nym dVPN 경로를 사용합니다. 모든 지갑 요청이 자동으로 믹스넷을 사용한다고 가정하지 말고, 이 경로들을 서로 다른 보호 기능으로 간주하세요.

출처:

- https://github.com/LEONINE-DAO/Nozy-wallet
- https://github.com/LEONINE-DAO/Nozy-wallet/blob/master/docs/reference/NYM_SEND_EGRESS_CASE_BREAKDOWN.md
- https://github.com/LEONINE-DAO/Nozy-wallet/blob/master/docs/reference/NYM_DVPN_SYNC_CASE_BREAKDOWN.md

### Zodl

Zodl에는 현재 기본 **Tor 보호 기능**이 있으며, 이는 앞서 Zingo, Zkool, Nozy에 대해 설명한 기본 Nym 통합 기능과는 다릅니다.

Zodl의 Tor 기능은 거래 제출, 거래 데이터 가져오기, 환율 요청, 서드파티 API 호출을 Tor을 통해 라우팅할 수 있습니다. Nym은 2026년 9월 24일, 더 폭넓은 믹스넷 통합을 두고 Zodl 팀과 활발히 논의 중이라고 밝혔습니다.

현재 Zodl을 사용하려면 다음 중 하나를 선택하세요.

- Zodl에 문서화된 Tor 보호 기능
- 지갑의 일반적인 기기 트래픽을 Nym을 통해 라우팅하려는 경우 시스템 수준의 NymVPN

둘 다 프라이버시 네트워크라는 이유만으로 지갑 내 Tor과 Nym가 서로 바꿔 쓸 수 있는 전송 방식이라고 가정하지 마세요.

Zodl Tor 설정:

**더 보기 → 고급 기능 → 베타: Tor 보호 → 활성화 → 변경 사항 저장**

출처:

- https://support.zodl.com/article/17-enabling-tor-protection
- https://nym.com/blog/nym-mixnet-zcash-wallets

## 대안: 시스템 수준의 NymVPN

지갑이 Nym 전용 프록시 설정을 이해할 필요가 없으므로, 호환성이 가장 폭넓은 Nym 옵션입니다.

### 1. NymVPN 설치하기

NymVPN은 Nym의 공식 웹사이트나 공식 플랫폼 스토어에서만 다운로드하세요.

- https://nym.com/
- https://nym.com/blog/nymvpn-v2026.12

NymVPN은 Android, iOS, Linux, Windows, macOS를 지원합니다.

### 2. 믹스넷 모드 선택하기

NymVPN에는 지연 시간이 짧도록 최적화된 2홉 dVPN 경로인 **빠른 모드**와 네트워크 메타데이터를 더 강력하게 보호하도록 최적화된 5홉 믹스넷 경로인 **믹스넷 모드**가 있습니다. 민감한 지갑 활동에는 믹스넷 모드를 선택하고, 지갑을 열거나 새로고침하기 전에 클라이언트에서 연결이 설정되었다고 표시될 때까지 기다리세요.

### 3. 지갑의 네트워크 설정은 기본값으로 두기

운영체제에서 이미 NymVPN을 통해 트래픽을 터널링하고 있다면, 대부분의 지갑에는 사용자 지정 프록시 설정이 필요하지 않습니다.

평소처럼 지갑을 열고 동기화가 진행되도록 하세요.

플랫폼에서 NymVPN의 분할 터널링 기능을 사용할 수 있다면, 지갑이 우회 또는 제외 목록에 들어 있지 않고 **보호된 터널에 포함되어 있는지** 확인하세요.

### 4. 지갑을 사용하기 전에 터널 확인하기

시스템 수준에서 간단히 확인하는 방법은 다음과 같습니다.

1. NymVPN 연결을 끊습니다.
2. 공개 IP 확인 서비스에 접속하거나, 데스크톱에서 다음 명령을 실행합니다.

   ```bash
   curl https://api.ipify.org
   ```

3. 표시된 IP를 기록합니다.
4. NymVPN을 믹스넷 모드로 연결합니다.
5. 확인을 다시 진행합니다.

표시되는 공개 IP가 바뀌어야 합니다.

이 방법으로 시스템 터널이 작동하는지 확인할 수 있습니다. 하지만 앱이나 운영체제에 특별한 라우팅 규칙이 있는 경우, 특정 지갑에서 발생하는 모든 요청이 같은 경로를 따른다는 사실까지 입증하지는 않습니다.

데스크톱에서 더 확실하게 확인하려면 다음을 수행하세요.

- 운영체제의 네트워크 모니터에서 지갑 프로세스를 확인합니다.
- 분할 터널링 제외 규칙이 없는지 확인합니다.
- NymVPN 연결을 끊었을 때 예상한 대로 지갑 동작이 달라지는지 확인합니다.

문제를 해결하는 동안 지갑 주소, 잔액, 거래 ID, IP 주소 또는 복구 정보를 포함한 스크린샷을 게시하지 마세요.

## NymVPN dApp / 지갑 프록시 모드

NymVPN은 믹스넷을 통해 SOCKS5 / RPC 라우팅을 사용하는 앱 및 지갑 프록시 모드도 제공합니다.

Nym의 공개 설정 문서에서는 주로 이더리움 방식의 RPC 구성을 예시로 보여 줍니다. 호환되는 일반 프록시/RPC 경로를 명시적으로 지원하는 소프트웨어에는 유용하지만, 모든 Zcash 지갑에서 작동한다고 **가정해서는 안 됩니다**.

지갑 자체의 문서에서 호환되는 프록시 또는 RPC 지원을 확인한 경우에만 이 경로를 사용하세요.

그렇지 않으면 다음을 우선 사용하세요.

- 지갑의 기본 Nym 통합 기능
- 시스템 수준의 NymVPN

## 성능과 시간 초과 간의 절충

믹스넷은 메타데이터를 더 강력하게 보호하는 대신 속도를 낮추도록 설계되었습니다.

다음 항목에 영향이 있을 수 있습니다.

- 지갑의 초기 동기화
- 대량의 누락 데이터 동기화
- 거래 내역 조회
- RPC 시간 초과
- 서드파티 API 호출

실용적인 지침:

- 기본 Nym 설정으로 시작하세요.
- 첫 동기화나 장시간의 누락 데이터 동기화에 더 오래 걸릴 수 있습니다.
- 시간 초과가 발생하면 프라이버시 설정을 완화하기 전에 다시 시도하세요.
- 민감한 거래를 하기 직전에 프라이버시 모드를 반복해서 전환하지 마세요.
- 대량 동기화에 더 빠른 경로를 사용한다면, 그동안 접속한 인프라에 실제 네트워크 신원이 노출될 수 있음을 이해하세요.
- 특히 Zingo PC의 경우, 기본 Nym 전송 기능은 현재 전송과 가격 조회를 보호하지만 동기화는 직접 연결된다는 점을 기억하세요.

## 모바일 고려 사항

Android 및 iOS에서는 운영체제의 VPN 슬롯을 사용하는 것이 일반적인 지갑 트래픽을 NymVPN을 통해 라우팅하는 가장 간단한 방법인 경우가 많습니다. 먼저 NymVPN을 연결한 다음 지갑을 여세요.

다른 VPN, 방화벽 또는 로컬 VPN 기반 광고 차단기가 이미 시스템 VPN 인터페이스를 사용 중이라면 두 제품이 동시에 작동하지 않을 수 있습니다. 지갑이 보호되고 있다고 가정하기 전에 운영체제의 VPN 상태를 확인하세요.

## 위협 모델 점검 목록

이 설정을 신뢰하기 전에 다음 사항을 확인하세요.

- 적절한 경우 거래정보 보호 Zcash 주소를 사용하고 있나요?
- 지갑에 기본 Nym 지원 기능이 있나요?
- 있다면, 기본 통합 기능이 어떤 트래픽을 보호하나요?
- 더 폭넓은 보호가 필요하다면, 지갑이 네트워크 활동을 시작하기 전에 NymVPN이 연결되어 있나요?
- 분할 터널링 규칙으로 지갑이 제외되어 있지는 않나요?
- 지갑 문서에 실제로 명시된 프록시 모드를 사용하고 있나요?
- 거래소, 브라우저 세션, 서드파티 API 또는 투명 주소를 통해 신원 정보가 유출되고 있지는 않나요?
- 동기화 속도 저하와 간헐적인 시간 초과를 감수할 수 있나요?
