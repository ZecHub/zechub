# ZIP란 무엇인가요?
Zcash 개선 제안(ZIP)은 Zcash 커뮤니티에 정보를 제공하거나, Zcash 또는 그 절차와 환경을 위한 새 기능을 설명하는 설계 문서입니다. ZIP에는 해당 기능에 대한 간결한 기술 사양과 기능의 근거가 제시되어야 합니다.

새 기능을 제안하고, 문제에 대한 커뮤니티 의견을 수렴하며, Zcash에 반영된 설계 결정을 문서화하는 주요 수단으로 ZIP을 사용하고자 합니다. ZIP의 소유자(대개 작성자)는 커뮤니티의 합의를 이끌어 내고 반대 의견을 문서화할 책임이 있습니다.

ZIP은 버전 관리 저장소에서 텍스트 파일로 관리되므로, 수정 이력은 기능 제안의 기록으로 남습니다.

-> [zips.z.cash](https://zips.z.cash)


## ZIP 편집자

제출되는 모든 ZIP는 검토 절차를 거쳐야 합니다. ZIP 편집자는 각 ZIP에 용어, 근거, 기술적 변경 사항이 충분히 설명되어 있는지, 형식과 내용을 확인합니다.

```markdown
* Conrado, and Arya, associated with the ZF.
* Sam and Mark, associated with SL.
```
