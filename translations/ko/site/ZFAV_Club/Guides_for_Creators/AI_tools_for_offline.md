### 이미지 생성

이미지 생성 모델은 어디서 다운로드할 수 있나요?  
[**HuggingFace**](https://huggingface.co/models?pipeline_tag=text-to-image&sort=trending)와 [**Civitai](https://civitai.com/)**에는 다양한 모델이 있습니다.

## Windows - 커스텀 모델 다운로드

일반적으로 AI 도구를 사용하려면 최소 4GB의 GPU 메모리 또는 비디오 메모리가 필요합니다.

Nvida GPU가 가장 잘 작동합니다.

- [InvokeAI](https://invoke-ai.github.io/InvokeAI/) (GPU 메모리 4GB 필요)
- [NMKD Stable Diffusion GUI](https://nmkd.itch.io/t2i-gui)
- [EasyDiffusion 3.0](https://github.com/easydiffusion/easydiffusion)

### Mac OS - 커스텀 모델 다운로드

- [Draw Things: AI Generation](https://apps.apple.com/ee/app/draw-things-ai-generation/id6444050820) AppStore에서 무료로 제공
(다양한 StableDiffusion 모델 사용 가능)
- [DiffusionBee](https://diffusionbee.com/) - 무료
(다양한 StableDiffusion 모델 사용 가능)
- [InvokeAI](https://invoke-ai.github.io/InvokeAI/) (GPU 메모리 4GB 필요)

### Linux - 커스텀 모델 다운로드

- [InvokeAI](https://invoke-ai.github.io/InvokeAI/) (GPU 메모리 4GB 필요)
