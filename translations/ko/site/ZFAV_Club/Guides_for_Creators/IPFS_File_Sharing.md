# IPFS 및 Brave 브라우저로 P2P 파일 공유

IPFS를 사용하면 대용량 미디어 파일을 P2P 방식으로 서로 공유할 수 있습니다.

문제는 무엇일까요? IPFS 게이트웨이는 대용량 파일을 처리하지 못하고 시간 초과가 발생합니다.

**요구 사항**: [IPFS 데스크톱](https://docs.ipfs.tech/install/ipfs-desktop/) + [Brave 브라우저](https://brave.com/)

요약하면, 영상은 맨 끝에 있습니다.

ZF AV Club에서 대용량 미디어 파일을 주고받을 때 이 방법을 사용할 수 있습니다. 재미있고 정말 멋진 방법이라 여러분을 위해 문서로도 정리했습니다!

*게다가*, 이 사용 사례를 개발하기 위해 Protocol Labs의 IPFS 팀과 직접 협력할 예정입니다.
dWeb Camp에서 맺은 인연 덕분에 얻은 또 다른 이점입니다!

수신하는 컴퓨터에 IPFS가 설치되어 있지 않고 Brave가 아닌 브라우저를 사용하는 경우, 게이트웨이가 파일을 불러올 때까지 기다려야 합니다. *대용량 파일에서는 504 오류가 발생합니다.*

다음 단계: 원본 노드가 오프라인이 되어도 단일 장애 지점 문제가 생기지 않도록 다른 사람의 파일을 내 컴퓨터에 고정하는 방법입니다.
