# Zcash 테스트넷

## Zcash 테스트넷이란 무엇인가요?

**Zcash 테스트넷**은 실제 Zcash 메인 네트워크(메인넷)와 병렬로 운영되는 블록체인으로, 프로토콜, 규칙, 거래 로직을 똑같이 재현하지만 2가지 중요한 차이점이 있습니다.

1. **코인에 실제 금전적 가치가 없습니다**. ZEC가 아니라 **TAZ**라고 부르며, 테스트 목적으로만 사용합니다.  
2. 실제 Zcash 블록체인에 배포하기 전에 **네트워크 업그레이드, 도구, 소프트웨어를 먼저 여기서 테스트합니다**.  

다시 말해, 테스트넷은 개발자, 감사자, 빌더가 실제 자금을 위험에 빠뜨리지 않고 아이디어를 시험해 볼 수 있는 **샌드박스 또는 실험 환경**과 같습니다.


## 테스트넷은 왜 존재하나요?

테스트넷은 블록체인 개발에 매우 중요합니다. Zcash 같은 **실제 블록체인은 변경할 수 없기** 때문입니다. 메인 네트워크에서 거래가 확정되면 되돌릴 수 없습니다. 테스트넷은 메인넷에 배포하기 전에 기능을 실험하고, 테스트하고, 디버깅할 수 있는 **안전한 복제 환경**을 제공합니다.

### 테스트넷의 용도

#### 1. 소프트웨어 개발 및 통합

지갑, 거래소, 채굴 소프트웨어 또는 프라이버시 도구를 만드는 개발자는 테스트넷에서 안전하게 테스트할 수 있습니다. 다음과 같은 작업이 가능합니다.

- 거래 전송 및 수신  
- 가치가 0인 TAZ 코인으로 새 블록 채굴  
- 사용자 인터페이스 및 API 구축  
- 거래 프라이버시 기능 테스트(투명 거래와 거래정보 보호 거래 비교)  

**예시:**  
[`zcash_tx_tool`](https://github.com/QED-it/zcash_tx_tool) 같은 도구는 테스트넷을 사용해 거래를 생성하고 Zcash 거래정보 보호 자산 기능을 테스트합니다.  

**실제 사례:**  
지갑 개발자는 소프트웨어를 테스트넷 RPC 엔드포인트에 연결해 주소 생성, 거래정보 보호 거래 전송, 잔액 확인 등 전체 과정을 시뮬레이션한 뒤 메인넷에서 운영을 시작할 수 있습니다.

#### 2. 네트워크 업그레이드 테스트

Zcash는 핵심 프로토콜을 주기적으로 업그레이드합니다(예: NU6.1, NU6.2 및 Ironwood). 테스트넷은 **메인넷보다 먼저** 새 업그레이드를 활성화하므로 개발자와 커뮤니티가 버그를 찾아 수정할 수 있습니다.

**예시:**  
새 합의 규칙이나 거래 유형을 먼저 테스트넷에 적용합니다. 테스트가 성공적으로 끝나면 사전에 정한 블록 높이에서 메인넷에 활성화됩니다.

#### 3. 노드 구현 테스트

Zcash에서 유지 관리하는 노드는 **Zebra**(Zcash Foundation에서 유지 관리하는 Rust 기반 노드)이며, 유지 관리하는 지갑은 [Zallet](https://github.com/zcash/zallet)입니다. 기존 노드 구현인 `zcashd`는 2026년 7월 18일 자동 지원 종료로 작동을 중단했으며 더 이상 유지 관리되지 않습니다. [zcashd에서 Zebra 및 Zallet로 이전하는 안내](https://zechub.wiki/guides/migration-guide-zcashd-to-zebrad-zallet)를 참조하세요. 테스트넷에서는 금전적 위험 없이 실제 환경에서 노드를 테스트할 수 있습니다.

노드 개발자는 다음을 수행할 수 있습니다.

- 블록 전파 확인  
- RPC 인터페이스 테스트  
- 부하가 걸릴 때 노드 동작 관찰  
- 채굴 소프트웨어와의 상호작용 테스트  

#### 4. 학습 및 교육

초보자는 채굴, 거래정보 보호 거래 생성, 통합 주소 사용 등 Zcash의 기능을 배울 수 있습니다.  
커뮤니티 튜토리얼과 문서를 통해 **테스트넷 파우셋, 블록 탐색기, 안내 자료**를 이용할 수 있습니다.


## 테스트넷의 실제 사용 사례

### 1. 개발자 테스트(지갑 / 앱)

- Zcash 테스트넷에 연결  
- 파우셋에서 TAZ 요청  
- 거래정보 보호 거래 전송  
- 프라이버시 및 UI 안정성 확인  

실수하더라도 실제 ZEC를 잃지 않습니다.

### 2. 거래소 통합 테스트

- 테스트넷 노드 실행  
- Zebrad JSON-RPC 엔드포인트를 사용해 거래 처리  
- 자동 입금 및 출금 로직 테스트  

안전한 운영용 코드를 보장하고 금전적 손실을 방지합니다.

### 3. 채굴 설정 시험

- 채굴 템플릿 사용  
- 블록 검증 테스트  
- 채굴 보상 관찰(TAZ만 해당)  
- 채굴 성능 조정  

메인넷으로 옮길 때 서비스 중단이나 수익 손실을 방지합니다.

### 4. 학술 연구 / 프로토콜 연구

연구자는 **무상태 검증**, **영지식 증명 최적화** 등의 혁신이나 기타 프로토콜 실험을 테스트넷에서 시험할 수 있습니다.  
숙련된 사용자도 특수한 실험을 위해 **사용자 지정 테스트넷이나 regtest 환경**을 운영할 수 있습니다.


## 메인넷과 테스트넷의 주요 차이점

| 기능               | 메인넷           | 테스트넷                  |
|-----------------------|-----------------|--------------------------|
| 코인의 가치        | 실제 ZEC         | TAZ(금전적 가치 없음)  |
| 위험                  | 금전적 위험   | 안전한 테스트 환경         |
| 프로토콜 업그레이드     | 운영 환경       | 조기 활성화         |
| 채굴 보상        | 실제 발행    | 테스트 보상만 제공         |
| 네트워크 활용도       | 실제 거래| 테스트 및 개발  |

## 흔한 오해

- **테스트넷 코인은 가치가 있다** -> 사실이 아닙니다. TAZ의 가치는 0입니다.  
- **테스트넷 코인을 잃으면 문제가 된다** -> 사실이 아닙니다. 실제 가치는 손실되지 않습니다.  
- **테스트넷과 메인넷은 동일하다** -> 사실이 아닙니다. 테스트넷은 자주 초기화되며 메인넷처럼 경제적으로 보호되지 않습니다.

---

## TAZ란 무엇인가요?

**TAZ**는 Zcash 코인의 테스트넷 버전입니다.  

- 실제 화폐가 아니며, ZEC나 법정화폐로 교환할 수 없습니다.  
- 테스트, 개발, 학습에 사용합니다.  
- 모든 Zcash 규칙을 따릅니다. 전송하거나 채굴할 수 있으며 거래정보 보호 주소에서 사용할 수 있습니다.  

**예시:**  
개발자는 실제 ZEC를 위험에 빠뜨리지 않고 지갑 기능을 테스트하기 위해 테스트넷 주소에서 다른 테스트넷 주소로 TAZ 100개를 전송할 수 있습니다.  

TAZ를 **Zcash 테스트넷에서 사용하는 ‘놀이용 돈’**이라고 생각해 보세요.


## 파우셋이란 무엇인가요?

**파우셋(faucet)**은 테스트용 TAZ 코인을 무료로 제공하는 서비스입니다.

- 보통 웹사이트나 API 형태로 제공됩니다.  
- 사용자가 테스트넷 주소를 제공하면 파우셋이 소량의 TAZ를 보냅니다.  
- TAZ를 직접 채굴할 필요가 없습니다.  

**예시:**  
1. 테스트넷 파우셋을 방문합니다(예: [fauzec.com](https://fauzec.com/) | [zcashfaucet.jinolabs.xyz](https://zcashfaucet.jinolabs.xyz/)).  
2. 테스트넷 주소를 입력합니다.  
3. TAZ를 요청합니다.  
4. TAZ를 즉시 받아 테스트를 시작합니다.  

**중요한 이유:**  
- ZEC를 위험에 빠뜨리지 않고 안전하게 테스트할 수 있습니다.  
- 초보자와 개발자가 쉽게 이용할 수 있습니다.  
- 지갑, 거래소, 앱을 신속하게 프로토타이핑할 수 있습니다.



## Zkool 및 Zingo! 지갑

### Zkool

- 숙련된 Zcash 사용자를 위한 다중 계정 지갑  
- seed phrase, viewing key, 투명 주소 및 거래정보 보호 주소 지원  
- 풀 노드나 경량 지갑 서버를 통해 메인넷, 테스트넷 또는 Regtest에 연결 가능  

### Zingo!

- 프라이버시와 간편성에 중점을 둔 모바일 지갑  
- 거래정보 보호 주소 및 통합 주소 지원  
- NU6 테스트넷을 포함한 테스트넷 프로토콜 지원을 위해 업데이트됨

## 테스트넷 활성화 후

- 거래는 메인넷과 같은 방식으로 처리되지만 **TAZ의 가치는 0입니다**.  
- 거래정보 보호 거래, 여러 주소, 프라이버시 기능을 테스트할 수 있습니다.  
- 개발자는 실제 ZEC를 위험에 빠뜨리지 않고 기능을 디버깅하고 테스트할 수 있습니다.  


## 요약

- **Zcash 테스트넷**은 구축, 테스트, 실험을 위한 안전한 샌드박스 환경입니다.  
- 사용 사례: 개발자 테스트, 노드 테스트, 거래소 통합, 연구, 교육  
- **TAZ 코인**은 ZEC 대신 사용하며 실제 가치는 없습니다.  
- 테스트넷은 메인넷에 기능을 배포하기 전에 반드시 거쳐야 합니다.
