# Zcash 크리에이터 도구: 팁 & 프로필 플랫폼

## 요약

* 두 가지 Zcash 도구는 크리에이터가 비공개로 대금을 받을 수 있도록 돕습니다. Zcash.me는 차폐 주소가 포함된 프로필 페이지를 제공하며, TIPZ를 통해 팬들이 팁을 보낼 수 있습니다.
* Zcash.me를 사용하면 통합 주소와 소셜 계정을 보여주는 링크 하나, `zcash.me/[username]`를 공유할 수 있습니다.
* TIPZ를 사용하면 팬들은 다른 암호화폐로 팁을 보낼 수 있으며, 모든 팁은 차폐된 ZEC로 전달됩니다.
* 두 도구 모두 통합 주소(`u1...`)를 요청합니다.
* 차폐 주소로 보내는 팁은 수입과 잔액을 공개적으로 노출하지 않습니다.

## 핵심 설명

### Zcash.me

![Zcash.me Logo](/content-images/_unavailable.svg)

#### 개요

**Zcash.me**는 누구나 Zcash 사용자를 쉽게 찾고 ZEC를 보낼 수 있도록 해주는 프로필 디렉터리 및 검색 플랫폼입니다. 이는 "Zcash를 위한 Linktree" 역할을 하며, 링크 하나로 차폐 주소와 소셜 활동을 공유하는 간단한 방법입니다.

| 항목              | 세부 정보 |
|-------------------|---------|
| **웹사이트**       | [https://zcash.me/](https://zcash.me/) |
| **Twitter**       | [@zcashme](https://x.com/zcashme) |
| **프로필 형식**| `zcash.me/[username]` |
| **상태**        | 운영 중(기능 개발 진행 중) |

#### 주요 기능

##### 현재 이용 가능
- **맞춤 프로필 페이지** - 사용자 이름, 자기소개, 아바타 및 위치가 포함된 개인화된 페이지
- **차폐 주소 표시** - 통합 주소를 한 번의 클릭으로 복사하는 버튼
- **소셜 링크 연동** - X, LinkedIn, Telegram 및 맞춤 웹사이트
- **인증 시스템** - 커뮤니티 신뢰를 위한 인증 배지
- **추천인 리더보드** - 상위 추천인과 커뮤니티 리더 추적
- **활동 상태** - 마지막 활동 시간을 표시합니다.

##### 출시 예정
| 기능            | 설명 |
|--------------------|-------------|
| 위치 지도       | 주변 Zcash 사용자 찾기 |
| 플랫폼 통계| 성장 지표 보기 |
| 커뮤니티 설문    | 생태계 주제에 투표 |
| 뉴스 및 공지 | 공식 업데이트 |
| 포럼              | 커뮤니티 토론 |
| 모바일 앱         | 완전한 모바일 경험 |

#### 시작하기
1. [https://zcash.me/](https://zcash.me/)를 방문하여 **Join**을 클릭합니다.
2. 고유한 사용자 이름을 선택하고, 자기소개와 프로필 사진을 추가합니다.
3. Zcash 통합 주소(`u1...`)를 붙여넣습니다.
4. 소셜 계정을 연결합니다.
5. 링크를 공유합니다: `zcash.me/[yourusername]`

### TIPZ

![TIPZ Logo](/content-images/BbXM8cDV_400x400-e6071ba983.webp)

#### 개요

**TIPZ**는 크리에이터와 사이퍼펑크를 위해 특별히 설계된 **비공개 팁 프로토콜**입니다. 팬들은 주요 암호화폐로 팁을 보내며, 이는 자동으로 전환되어 **차폐된 ZEC**로 전달됩니다.

| 항목              | 세부 정보 |
|-------------------|---------|
| **웹사이트**       | [https://tipz.cash/](https://tipz.cash/) |
| **Twitter**       | [@tipz_cash](https://x.com/tipz_cash) |
| **프로필 형식**| `tipz.cash/@[username]` |
| **상태**        | 운영 중 |

> *"tipz.cash는 크리에이터와 사이퍼펑크를 위한 비공개 팁 프로토콜입니다."*

#### 크리에이터에게 개인정보 보호가 중요한 이유

##### 재정적 자유
- 플랫폼 수수료 0%
- 비수탁형 및 자기 보관
- 중개자 없음

##### 개인정보 보호 우선 설계
- 모든 팁은 차폐된 ZEC로 도착합니다.
- 비공개 지갑 잔액
- 팁과 함께 제공되는 암호화 메시지
- 완전한 크리에이터 익명성 옵션

##### 크로스체인 결제
| 통화 | 네트워크 |
|----------|---------|
| ETH      | Ethereum |
| USDC     | 여러 체인 |
| SOL      | Solana |
| ZEC      | 직접 Zcash |

##### 크리에이터 보호
- 플랫폼 퇴출 위험 없음
- 검열 저항성
- KYC 불필요

## 시각 자료 / 비유

카페 카운터 위의 팁 항아리는 유리로 되어 있습니다. 방 안의 모든 사람이 누가 동전을 넣었는지, 그리고 항아리가 얼마나 찼는지 볼 수 있습니다.

차폐 주소는 투입구가 있는 잠긴 우편함처럼 작동합니다. 팬들은 동전과 메모가 담긴 봉투를 넣고, 상자를 여는 사람은 크리에이터뿐입니다. TIPZ는 문 앞에 환전 기능을 추가합니다. 팬은 ETH 또는 SOL을 가지고 올 수 있고, 우편함에 들어가는 것은 ZEC입니다.

```
TIPZ Payment Flow

Fan -> tipz.cash Protocol -> Creator's Wallet (Shielded ZEC)

Fan selects amount + message -> Protocol auto-converts -> Creator receives private shielded ZEC.
```
