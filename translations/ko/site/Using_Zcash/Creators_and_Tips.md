# Zcash 크리에이터를 위한 도구: 팁 및 프로필 플랫폼

> **크리에이터, 사이퍼펑크, 프라이버시를 중시하는 커뮤니티를 위해 Zcash 기반으로 구축된 프라이버시 보호 팁 및 프로필 도구 종합 안내서입니다.**

## 핵심 요약

* Zcash 도구를 사용하면 크리에이터가 프라이버시를 지키며 대가를 받을 수 있습니다. Zcash.me에서는 거래정보 보호 주소가 포함된 프로필 페이지를 만들 수 있고, TIPZ에서는 팬들이 팁을 보낼 수 있습니다.
* Zcash.me를 이용하면 통합 주소와 소셜 계정을 보여주는 링크 하나인 `zcash.me/[username]`를 공유할 수 있습니다.
* TIPZ에서는 팬들이 다른 암호화폐로 팁을 보낼 수 있으며, 모든 팁은 거래정보 보호 ZEC로 도착합니다.
* 두 도구 모두 통합 주소(`u1...`)를 요청합니다.
* 거래정보 보호 주소로 받은 팁은 수입과 잔액이 공개되지 않도록 보호합니다.

## 핵심 설명

### Zcash.me

![Zcash.me Logo](/content-images/_unavailable.svg)

#### 개요

**Zcash.me**는 누구나 Zcash 사용자에게 ZEC를 쉽게 보내고 사용자를 찾을 수 있도록 돕는 프로필 디렉터리 및 검색 플랫폼입니다. “Zcash를 위한 Linktree” 역할을 하며, 링크 하나로 거래정보 보호 주소와 소셜 활동 정보를 간편하게 공유할 수 있습니다.

| 항목              | 세부 정보 |
|-------------------|---------|
| **웹사이트**       | [https://zcash.me/](https://zcash.me/) |
| **Twitter**       | [@zcashme](https://x.com/zcashme) |
| **프로필 형식**| `zcash.me/[username]` |
| **상태**        | 운영 중 (기능 개발 진행 중) |

#### 주요 기능

##### 현재 이용 가능
- **맞춤 프로필 페이지** - 사용자 이름, 자기소개, 아바타, 위치를 포함한 개인화 페이지
- **거래정보 보호 주소 표시** - 통합 주소를 한 번의 클릭으로 복사하는 버튼
- **소셜 링크 연동** - X, LinkedIn, Telegram 및 사용자 지정 웹사이트
- **인증 시스템** - 커뮤니티 신뢰를 위한 인증 배지
- **추천인 순위표** - 상위 추천인 및 커뮤니티 리더 확인
- **활동 상태** - 마지막 활동 시간을 표시합니다.

##### 출시 예정
| 기능            | 설명 |
|--------------------|-------------|
| 위치 지도       | 주변의 Zcash 사용자 찾기 |
| 플랫폼 통계| 성장 지표 확인 |
| 커뮤니티 투표    | 생태계 주제에 투표 |
| 소식 및 공지 | 공식 업데이트 |
| 포럼              | 커뮤니티 토론 |
| 모바일 앱         | 완전한 모바일 경험 |

#### 시작하기
1. [https://zcash.me/](https://zcash.me/)에 방문해 **가입**을 클릭합니다.
2. 고유한 사용자 이름을 정하고 자기소개와 프로필 사진을 추가합니다.
3. Zcash 통합 주소(`u1...`)를 붙여 넣습니다.
4. 소셜 계정을 연결합니다.
5. 링크를 공유합니다: `zcash.me/[yourusername]`

### TIPZ

![TIPZ Logo](/content-images/BbXM8cDV_400x400-e6071ba983.webp)

#### 개요

**TIPZ**는 크리에이터와 사이퍼펑크를 위해 특별히 설계된 **프라이빗 팁 프로토콜**입니다. 팬들은 주요 암호화폐로 팁을 보낼 수 있으며, 팁은 자동으로 변환되어 **거래정보 보호 ZEC**로 전달됩니다.

| 항목              | 세부 정보 |
|-------------------|---------|
| **웹사이트**       | [https://tipz.cash/](https://tipz.cash/) |
| **Twitter**       | [@tipz_cash](https://x.com/tipz_cash) |
| **프로필 형식**| `tipz.cash/@[username]` |
| **상태**        | 운영 중 |

> *“tipz.cash는 크리에이터와 사이퍼펑크를 위한 프라이빗 팁 프로토콜입니다.”*

#### 크리에이터에게 프라이버시가 중요한 이유

##### 재정적 자유
- 플랫폼 수수료 0%
- 비커스터디형 및 자기 보관
- 중개자 없음

##### 프라이버시 우선 설계
- 모든 팁은 거래정보 보호 ZEC로 도착합니다.
- 지갑 잔액 비공개
- 팁과 함께 암호화된 메시지 전송
- 크리에이터 완전 익명 옵션

##### 크로스체인 결제
| 통화 | 네트워크 |
|----------|---------|
| ETH      | Ethereum |
| USDC     | 여러 체인 |
| SOL      | Solana |
| ZEC      | 직접 Zcash |

##### 크리에이터 보호
- 플랫폼에서 퇴출당할 위험 없음
- 검열에 강함
- KYC 불필요

## 시각 자료 / 비유

카페 카운터 위의 팁 병은 유리로 되어 있습니다. 방 안의 누구나 누가 동전을 넣었는지, 병이 얼마나 찼는지 볼 수 있습니다.

거래정보 보호 주소는 투입구가 달린 잠금 우편함과 같습니다. 팬들은 동전과 메모를 넣은 봉투를 넣고, 상자는 크리에이터만 열 수 있습니다. TIPZ는 입구에 환전 서비스를 더하는 것과 같습니다. 팬은 ETH나 SOL을 가지고 올 수 있고, 우편함에는 ZEC가 도착합니다.

```
TIPZ Payment Flow

Fan -> tipz.cash Protocol -> Creator's Wallet (Shielded ZEC)

Fan selects amount + message -> Protocol auto-converts -> Creator receives private shielded ZEC.
```
