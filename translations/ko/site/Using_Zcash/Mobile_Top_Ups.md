# Zcash로 모바일 충전하기

이 가이드에서는 ZEC로 휴대폰 충전 크레딧을 구매하는 방법을 알아봅니다.

## 다음 단계를 따르세요:

### 1. 계정 만들기
[Coinsbee.com](https://www.coinsbee.com/en/shop/mobile-top-ups/)에 방문하여 계정을 만드세요.

### 2. 국가와 통신사 선택하기
왼쪽 상단으로 스크롤하여 국가를 선택한 다음, 휴대폰 크레딧을 선택하고 충전하려는 통신사를 선택하세요(예: MTN).

![2단계 - 국가와 통신사 선택](/content-images/0-qvB7ZCWaVWa-C2d8-db0d4ea372.webp)

### 3. 세부 정보 입력 및 구매
올바른 정보를 입력하고 "Buy Now" 버튼을 누르세요. 장바구니를 열어 주문을 확인하고, 계속하기를 클릭한 뒤 $ZEC로 구매를 확정하세요.

![3단계 - 구매 화면](/content-images/0-ikF-ooBc9W7olfNt-7a4584edda.webp)

### 4. 결제 정보
해당하는 $ZEC 금액과 함께 자금을 보내야 하는 투명 주소가 제공됩니다.

![4단계 - ZEC 결제 정보](/content-images/0-6_YhAhQnsLbrMvHN-c9646f3604.webp)

### 5. 결제 보내기
금액과 주소를 주의해서 복사하여 붙여넣으세요. 환불이 발생할 경우를 대비해 메모 필드에 본인의 실드 주소를 추가하세요.

![5단계 - ZEC 보내기](/content-images/0-DNnpyemsKcW-k-u-bcaaa51d3a.webp)

### 6. 처리 중
자금이 전송되면 요청은 몇 분 안에 처리됩니다.

![6단계 - 처리 화면](/content-images/0-LgXuUVLVecqrUW5G-a894c7b2dd.webp)

### 7. 확인
오… 제 회선이 충전됐어요! 결제 과정에서 이메일도 확인하면 거래가 완료되었을 때 이메일로 알림을 받을 수 있습니다.

![7단계 - 충전 성공](/content-images/0-TJKIcqznQ4Y8_jgo-e725aed571.webp)

## 계정 없이 충전 구매하기

위 방법은 Coinsbee 계정을 만들어야 합니다. 원하지 않는 경우, CardsRelay는 등록 없이 ZEC로 모바일 충전권을 판매합니다.

### 1. 국가와 통신사 선택하기
[CardsRelay](https://cardsrelay.com)에 방문하여 Mobile Top Ups 섹션을 여세요. 전 세계적으로 750개 이상의 통신사가 지원됩니다.

### 2. 번호와 금액 입력하기
충전할 휴대폰 번호를 입력하고 충전 금액을 선택하세요. 표시된 가격은 나중에 별도의 환율 마진이 추가되지 않는 단일 총액입니다.

### 3. 이메일 입력하기
확인 정보를 전달하려면 이메일 주소가 필요하며, 주문하기 전에 확인됩니다. 계정은 생성되지 않으며 신분증도 요청되지 않습니다.

### 4. ZEC로 결제하기
결제 시 Zcash를 선택하세요. ZEC는 제3자에 의해 환전되지 않고 직접 사용됩니다. 결제 주소와 정확한 금액이 표시됩니다.

### 5. 확인
충전이 처리되고, 보통 몇 초 내에 이메일로 확인 정보가 도착합니다.

CardsRelay는 약 2,500개 브랜드의 기프트 카드도 판매하며, Zcash와 함께 Monero 및 Zano도 받습니다. 이 서비스는 Payzy ME FZ Ltd.가 운영합니다.
