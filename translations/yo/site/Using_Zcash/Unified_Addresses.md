# Àwọn Àdírẹ́sì Ìṣọ̀kan

> Àdírẹ́sì kan fún gbogbo Zcash. Pín in, àpò ìfiránṣẹ́ náà yóò sì rí ọ̀nà ìkọ̀kọ̀ jùlọ láti san owó fún ọ.

## TL;DR

* Àdírẹ́sì ìṣọ̀kan (UA) jẹ́ àdírẹ́sì Zcash kan tí ó ní ọ̀pọ̀lọpọ̀ àwọn olùgbà: Ironwood, Sapling, àti àwọn tí ó hàn gbangba.
* Awọn UA Mainnet bẹrẹ pẹlu `u1`. ZIP 316 ṣàlàyé wọn, wọ́n sì dé pẹ̀lú àtúnṣe NU5 ní ọjọ́ 31 oṣù karùn-ún ọdún 2022.
* Àpò ìpamọ́ tí olùránṣẹ́ náà ń lò ló máa ń yan adágún tó jẹ́ ti àdáni jùlọ tí àwọn àpò ìpamọ́ méjèèjì ń lò. O kò lè yan adágún fúnra rẹ.
* Ilé iṣẹ́ UA yín ń ṣiṣẹ́ nígbà tí adágún Ironwood bẹ̀rẹ̀ sí í ṣiṣẹ́ ní oṣù Keje ọdún 2026. O kò nílò láti pín àdírẹ́sì tuntun kan.
* Àpò owó rẹ lè ṣe UA tuntun fún olùránṣẹ́ kọ̀ọ̀kan, gbogbo wọn sì máa sanwó sínú àkọọ́lẹ̀ kan náà.

## Àlàyé Pàtàkì

Àdírẹ́sì ìṣọ̀kan (UA) jẹ́ àdírẹ́sì Zcash kan ṣoṣo tí ó so ọ̀pọ̀lọpọ̀ àwọn olùgbà pọ̀ mọ́ ara wọn. Àwọn olùgbà ni àwọn apá àdírẹ́sì tí ó gba owó nínú àpò iye pàtó kan: Ironwood, Sapling, àti transparent. UA bẹ̀rẹ̀ pẹ̀lú `u1` lórí mainnet àti pé a ti ṣàlàyé rẹ̀ nínú [ZIP 316](https://zips.z.cash/zip-0316), tí a ṣe àgbékalẹ̀ rẹ̀ pẹ̀lú àtúnṣe nẹ́tíwọ́ọ̀kì NU5 ní ọjọ́ 31 oṣù karùn-ún ọdún 2022.

Kí a tó so àwọn àdírẹ́sì pọ̀, gbígbà ZEC túmọ̀ sí ríronú nípa àwọn irú àdírẹ́sì `zs` àdírẹ́sì gba owó Sapling, `t` Àdírẹ́sì gba owó tí ó ṣe kedere, àti fífiránṣẹ́ láàárín àwọn irú náà gba àwọn ìgbésẹ̀ míràn. UA kan parí ìyẹn. O pín àdírẹ́sì kan, àwọn àpò owó náà sì ń ṣiṣẹ́ lórí ìyókù.

### Bó ṣe ń ṣiṣẹ́

Nígbà tí ẹnìkan bá fi ránṣẹ́ sí UA rẹ, àpò wọn máa ń ka àwọn olugba inú rẹ̀, wọ́n sì máa ń yan ibi ìdáná tó jẹ́ ti àdáni jùlọ tí àwọn àpò méjèèjì ń gbà:

1. Tí àwọn àpò méjèèjì bá ń gbé àpò ààbò lọ́wọ́lọ́wọ́, owó náà yóò dé pẹ̀lú ààbò. Kò sí ohun tí gbogbo ènìyàn lè fọwọ́ kan ẹ̀wọ̀n náà.
2. Tí olùránṣẹ́ bá lè fi ránṣẹ́ láti ọ̀dọ̀ adágún àtijọ́ kan, àpò owó náà yóò padà sí ọ̀dọ̀ olùgbà tí ó dára jùlọ tí ẹ̀yin méjèèjì ń pín, bíi Sapling.
3. Tí olùránṣẹ́ bá lè fi owó tó ṣe kedere ránṣẹ́ nìkan, ìsanwó náà yóò dé inú ẹ̀rọ ìgbàlejò UA rẹ, àpò owó rẹ yóò sì dáàbò bò ó kúrò níbẹ̀.

O kò lè ṣe èyí fúnra rẹ. Àdírẹ́sì náà dúró bẹ́ẹ̀; ọ̀nà ìṣiṣẹ́ náà ń ṣẹlẹ̀ nínú rẹ̀.

### Kí ló dé tí ó fi ṣe pàtàkì báyìí

Zcash ń tẹ̀síwájú láti máa ṣe àtúnṣe sí i. Nígbà tí adágún Ironwood ṣiṣẹ́ pẹ̀lú NU6.3 ní ọjọ́ 28 oṣù keje ọdún 2026, àwọn tó ni UA kò nílò àdírẹ́sì tuntun: àwọn àpò owó bẹ̀rẹ̀ sí í yan ẹni tó ń gba Ironwood nínú àwọn àdírẹ́sì tí wọ́n ti ní tẹ́lẹ̀. Àwọn tó ni àdírẹ́sì àtijọ́ gbọ́dọ̀ ṣí lọ sí ibòmíràn. Àwọn tó ni UA kò ṣe ohunkóhun.

Ète àwòrán ni èyí. Àwọn adágún tuntun dé pẹ̀lú àwọn àtúnṣe nẹ́tíwọ́ọ̀kì ọjọ́ iwájú, àdírẹ́sì kan ṣoṣo sì máa ń gbà wọ́n láìsí ẹnikẹ́ni tí yóò tún pín àdírẹ́sì tàbí kí ó fi ọwọ́ gbé owó [Àwọn adágún iye Zcash](/using-zcash/shielded-pools) fún ìtòlẹ́sẹẹsẹ adágún omi tó wà lọ́wọ́lọ́wọ́.

### Àdírẹ́sì tuntun fún gbogbo olùránṣẹ́

Àwọn àpò owó lè ṣe àkójọpọ̀ àdírẹ́sì tó yàtọ̀ síra fún àkọ́ọ́lù kan. Olúkúlùkù wọn ń san owó kan náà, ṣùgbọ́n kò sí méjì nínú wọn tí a lè so pọ̀ lórí ẹ̀wọ̀n. Fún ẹnìkọ̀ọ̀kan tàbí iṣẹ́ tí ó ń sanwó fún ọ ní UA, kò sì sí méjì nínú wọn tí ó lè fi àdírẹ́sì wéra láti mọ̀ pé wọ́n ń san owó kan náà.

## Ìwòran / Àfiwé

Fojú inú wo ilẹ̀kùn iwájú kan tí ó ní ihò ìfìwéránṣẹ́ mẹ́ta. Ihò tuntun náà ń ju àwọn lẹ́tà sínú àpótí ìpamọ́ tí a ti tì pa (Ironwood). Èkejì ń ju wọ́n sínú àpótí tí a ti tì pa (Sapling). Èkẹta ń ju wọ́n sínú àwo tí ó ṣí sílẹ̀ tí ẹnikẹ́ni lè kà láti inú fèrèsé (tí ó hàn gbangba).

Apò ìfìwéránṣẹ́ ni àpò ìfìwéránṣẹ́. Ó ń lo ibi ìpamọ́ tó wọ́pọ̀ jùlọ tí ó bá a mu. O máa ń fún ní àdírẹ́sì kan fún ilẹ̀kùn náà, nígbà tí ilé náà bá sì ní àpótí ìpamọ́ tuntun, àdírẹ́sì tó wà lórí ilẹ̀kùn náà yóò dúró gẹ́gẹ́ bí ó ti yẹ.

## Jíjìn Jìnnìjìnnì

### Àwọn irinṣẹ́ tó jọra

- **Wiwo awọn bọtini.** Gbogbo akọọlẹ ni awọn bọtini wiwo apapọ ti o pin ohun ti UA kan gba (tabi ohun gbogbo ti o fi ranṣẹ) laisi pinpin aṣẹ inawo `uview` àti `uivk`. Wo [awọn bọtini wiwo](/zcash-tech/viewing-keys).
- **Àdírẹ́sì TEX.** Àwọn pàṣípààrọ̀ kan, tí wọ́n ń pè Binance, nílò owó ìdókòwò láti orísun tí ó hàn gbangba. Àdírẹ́sì TEX kan ([ZIP 320](https://zips.z.cash/zip-0320)) jẹ́ alábáṣepọ̀ tí ó ṣe kedere sí UA rẹ fún irú ọ̀ràn bẹ́ẹ̀ [awọn adirẹsi paṣipaarọ ti o han gbangba](/using-zcash/transparent-exchange-addresses).
- **Àwọn ìbéèrè ìsanwó.** A lè fi UA sínú URI ìbéèrè ìsanwó pẹ̀lú iye owó àti àkọsílẹ̀ tí a ti fi kún tẹ́lẹ̀. Wo [ìbéèrè ìsanwó URIs](/using-zcash/payment-request-uris).

### Àwọn òtítọ́ kíákíá

| | |
|---|---|
| Àtúnṣe ìṣáájú | `u1` (àkójọpọ̀) |
| Ṣíṣe àkóónú | bech32m |
| A ti ṣalaye ninu | [ZIP 316](https://zips.z.cash/zip-0316) |
| Ṣíṣe àgbékalẹ̀ | NU5, ọjọ́ 31 oṣù karùn-ún, ọdún 2022 |
| Ó ní | Ironwood, Sapling, ati awọn olugba ti o han gbangba |
| Kókó ìnáwó | Ọkan fun akọọlẹ kan, ti gbogbo awọn UAs rẹ pin |

Ṣàyẹ̀wò àwọn àpò tí ó ṣe àtìlẹ́yìn fún àwọn àdírẹ́sì ìṣọ̀kan lórí [àwọn àpò owó](/wallets) ojú ìwé.

## Àwọn Àṣìṣe Tó Wọ́pọ̀

- **Pínpín ohun àtijọ́ kan `zs` or `t` Àdírẹ́sì.** Àdírẹ́sì kan ṣoṣo ló máa ń dé ibi ìdáná kan ṣoṣo, kò sì ní gba àwọn tuntun. Pin UA rẹ.
- **Fífún gbogbo ènìyàn ní UA kan náà.** Àwọn ènìyàn méjì tí wọ́n ń sanwó fún ọ lè fi àwọn àkọsílẹ̀ wéra kí wọ́n sì rí àdírẹ́sì kan náà. Fún olùránṣẹ́ kọ̀ọ̀kan ní UA tuntun láti inú àpò owó rẹ.
- **Mo n reti gbogbo owo sisan si UA lati jẹ ikọkọ.** Oluranṣẹ ti o le fi owo ti o han gbangba ranṣẹ nikan san owo si olugba ti o han gbangba rẹ, ati pe sisan naa jẹ ti gbogbo eniyan. Daabo bo o kuro ninu apamọwọ rẹ lẹhin naa.

- [Àwọn Kọ́kọ́rọ́ Wíwo](/zcash-tech/viewing-keys): pín ohun tí UA gbà láìsí pínpín àṣẹ ìnáwó.
- [Àwọn Àdírẹ́sì Pàṣípààrọ̀ Títọ́](/using-zcash/transparent-exchange-addresses): ọna kika TEX fun awọn paṣipaarọ ti o nilo orisun ti o han gbangba.
- [Ìbéèrè fún Ìsanwó Àwọn URI](/using-zcash/payment-request-uris): UA kan pẹlu iye ati akọsilẹ ti a kun sinu.
- [Àwọn Àpò Ìpamọ́](/using-zcash/wallets): àwọn àpò tí wọ́n ń ṣẹ̀dá àti san àwọn àdírẹ́sì ìṣọ̀kan.
- [Àwọn Pípàṣípààrọ̀ Tí Kì í Ṣe ti Ààbò](/using-zcash/non-custodial-exchanges): kini lati ṣayẹwo nigbati iyipada kan ba san ZEC sinu apamọwọ rẹ.
- [Ta ló lè rí ìsanwó Zcash rẹ](/start-here/who-can-see-your-zcash-payment): ohun tí ó máa hàn nígbà tí ìsanwó bá lo olùgbà kọ̀ọ̀kan.
