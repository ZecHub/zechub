# Àwọn Owó-ìṣúná Zcash

Àwọn ohun àmúṣọrọ̀ kan wà tí ó lè ran àwọn oníṣe lọ́wọ́ láti lóye Zcash.

**[Ìròyìn Zcash Media](https://www.youtube.com/c/ZcashMedia)**

Zcash Media jẹ́ àjọ aládàáni tí ó ń ṣe àwọn ìwé ìkọ̀wé nípa ẹ̀kọ́ lórí owó Bitcoin. Àwọn fídíò àkọ́kọ́ wọn, "Built to Fix Bitcoin's Fatal Fault, What is Zcash (ZEC)?", jé àlàyé tó dára fún ọ láti mọ bí o ti lè rí owó náà gbà.

**[X (tí ó jẹ́ Twitter tẹ̀lẹ̀)](https://x.com)**

Twitter ni de facto ibaraẹnisọrọ ibudo fun awọn Zcash awujo, ati ki o tobi cryptocurrency aaye bi daradara. O ti wa ni kan nla ibi lati gba a pulse ṣayẹwo lori gbogbo ohun Zcash, ati tun tẹle olokiki agbegbe omo egbe. nibi ni a diẹ ninu awọn alaye nipa rẹ nlo: [ìwé-ìwé](https://www.notion.so/zechub/Social-Media-Links-05b9df645af54de7a1989d9c4ccc4d05) èyí tó ṣe àkójọ àwọn àkọlé tí ó ga jùlọ láti tẹ̀ lé.

**[Ìjọ Zcash](https://www.zcashcommunity.com/)**

Zcash Community jẹ́ ojúlé tí àwọn aráàlú ń darí tó máa ń gbé iṣẹ́ àkànṣe ti àwùjọ ṣe láti ṣètìlẹyìn fún ètò ìgbé ayé àti ìṣètò owó orí-ayé Zcash. Ó jé ọ̀nà dídára kan láti fi ara mọ̀ sí agbègbè Zcash àti onírúurú ohun èlò rẹ gẹ́gẹ́ bí owó ìdókòwò.

**[Àjọ Ìjíròrò Zcash](https://forum.zcashcommunity.com/)**

As mentioned in the new user guide, the Zcash forum is a great place to have long form discussions about Zcash topics and also proposed ideas. Proposals always make it to the forum so the community has a chance to discuss and debate the proposed ideas.

**[Z. owó orí](https://z.cash/)**

Z.cash jẹ oju opo wẹẹbu akọkọ ti Zcash O pese akoonu ati iwe-ipamọ ti ZCash fun ọpọlọpọ awọn olumulo ati gba awọn olumulo tuntun laaye lati jinle sinu alaye imọ ẹrọ ni ayika ZCASH .

Ṣe o ni awọn ohun elo ti n ṣe awopọ ati pe o fẹ lati jinlẹ sinu ẹgbẹ imọ-ẹrọ Zcash?
