# Kí ni ZIP?
A Zcash Improvement Proposal (ZIP) jẹ iwe apẹrẹ ti o pese alaye si agbegbe Zcash, tabi ṣe apejuwe ẹya tuntun fun Zcash tabi awọn ilana rẹ tabi ayika. O yẹ ki ZIP pese alaye imọ-ẹrọ ṣoki kan ati idiwọ fun ẹya naa.

A nírètí pé ZIPs ni yóò jẹ́ ọ̀nà àkọkọ láti dá àwọn àfikún tuntun sílẹ, àti kíkó èrò àwùjọ jọ lórí ìṣòro kan, àti fún ìfọwọ́sí ìpinnu tí wọ́n ṣe nípa ètò ìṣètò ti wọn bá lọ sí inú Zcash. Olù-ní (Owner) ZIP náà (òǹṣèwé), ló sábà máa ń wà lábẹ́ àṣẹ láti kọ àdéhùn láàárín àwùjọ ati fífi ìwé hàn ojú ìwòye tó yàtọ̀ sóhun táwọn ẹlòmíràn sọ.

Nítorí pé àwọn ZIPs ni a tọ́jú gẹ́gẹ́ bí fáìlì ọ̀rọ̀ nínú ibi ìpamọ́ tí ó ní àdàkọ, ìtàn àtúnṣe wọn jẹ àkọsílẹ̀ ìṣáájú ti ètò ohun-èlò náà.

-> [ìdìpọ̀ owó. z. cash](https://zips.z.cash)


## Àwọn Oníṣàtúnṣe ZIP

Fun gbogbo ZIP ti o wọle, o gbọdọ faramọ ilana atunyẹwo. Awọn olootu ZIP ni iṣẹ pẹlu idaniloju ọna kika ati akoonu eyikeyi ZIP ṣe apejuwe awọn ofin to peye, iṣaro-ọrọ ati awọn ayipada imọ ẹrọ ti a ṣe. 

```markdown
* Jack Grigg, Kris Nuttycombe and Daira-Emma Hopwood associated with the ECC.
* Conrado, and Arya, associated with the ZF.
* Sam and Mark, associated with SL.
```
