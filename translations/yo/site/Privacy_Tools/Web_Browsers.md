# Àwọn ẹ̀rọ aṣàwákiri wẹ́ẹ̀bù

1. **Brave:** Ọ̀kan lára àwọn aṣàwákiri tó gbajúmọ̀ jùlọ àti tó ní ààbò jùlọ lórí ọjà lónìí. Ó ń dí àwọn ìpolówó àti àwọn olùtọpa ìpamọ́ tí ó lè fa ìpamọ́. Ó ń dí ìpamọ́ data ẹni-kẹta. 

2. **Mulvad:** Ẹ̀rọ lilọ kiri ayelujara kan tí ó da lórí ìpamọ́ ni a ṣe ní ìfọwọ́sowọ́pọ̀ láàárín Mullvad VPN àti Tor Project. A ṣe é láti dín ìtọ́pinpin àti ìtẹ̀lé ìka kù

3. **Tor:** Ẹ̀rọ aṣàwákiri yìí ń dí àwọn afikún bíi Flash, RealPlayer, QuickTime, àti àwọn mìíràn: a lè lò wọ́n láti fi àdírẹ́sì IP rẹ hàn. A kò gbà ọ́ nímọ̀ràn láti fi àwọn afikún tàbí afikún sínú ẹ̀rọ aṣàwákiri Tor


## Kí ni àwọn ohun tí ó yẹ kí a kíyèsí nígbà tí a bá ń yan ẹ̀rọ amóhùnmáwòrán wẹ́ẹ̀bù?

Nígbà tí o bá ń yan ẹ̀rọ amóhùnmáwòrán ayélujára, àwọn nǹkan díẹ̀ ló yẹ kí o fi sọ́kàn: Àwọn ìṣòro ààbò àti ìlòkulò ni a sábà máa ń rí nígbà gbogbo. Àwọn ẹ̀rọ amóhùnmáwòrán kan wà tí a lè tọ́pasẹ̀ wọn ní ọ̀nà kan, ṣùgbọ́n àwọn ẹ̀rọ amóhùnmáwòrán kan wà tí ó ń jẹ́ kí àwọn olùlò máa wo kiri láìsí orúkọ wọn - [Ẹ̀rọ lilọ kiri ayelujara Tor](https://download.torproject.org/) fun apere. 

**Ìtẹ̀wé ìka**: Tí o bá fẹ́ pa àwọn nǹkan mọ́ ní ìkọ̀kọ̀ bíi, àwọn sọ́fítíwè tí a fi sínú ẹ̀rọ rẹ, ìṣètò ohun èlò, àti bẹ́ẹ̀ bẹ́ẹ̀ lọ, ronú láti wá ẹ̀rọ aṣàwárí wẹ́ẹ̀bù tí ó ń ṣe àtìlẹ́yìn fún ìdènà ìka ìka. 

**Ìdánwò HTTPS**: Ààbò mìíràn tí a gbọ́dọ̀ kíyèsí nígbà tí a bá ń yan ẹ̀rọ aṣàwárí wẹ́ẹ̀bù ni ìlànà ìdánwò HTTPS tí ó ń ran lọ́wọ́ láti fi ìpamọ́ ìsopọ̀ wẹ́ẹ̀bù àti láti fi àwọn kúkì, URL àti àwọn irú ìwádìí míràn tí ó ṣe pàtàkì pamọ́. Pẹ̀lú HTTPS, ìsopọ̀ ni a ń fi ìpamọ́ pamọ́ àti pé kò sí ẹni kẹta lórí nẹ́tíwọ́ọ̀kì tí ó lè ka àkóónú tí a ń gbé láàrín ẹ̀rọ aṣàwárí àti ẹ̀rọ aṣàwárí rẹ. 

**Ààbò Ìtọ́pasẹ̀ Kúkì**: Jù bẹ́ẹ̀ lọ, apá púpọ̀ nínú àwọn ojú ìwé wẹ́ẹ̀bù ní gbogbo àgbáyé ní àwọn olùtọ́pasẹ̀ ẹni-kẹta tí a fi pamọ́; àwọn olùtọ́pasẹ̀ wọ̀nyí ń ka àti kọ àwọn kúkì nínú ẹ̀rọ aṣàwákiri rẹ. Àwọn kúkì wọ̀nyí lè fa àwọn ohun búburú nítorí wọ́n lè ṣeé lò láti tọ́pasẹ̀ ìtọ́pasẹ̀ ìtọ́pasẹ̀ rẹ káàkiri àwọn ojú ìwé wẹ́ẹ̀bù; láti dènà ìtọ́pasẹ̀ yìí, yan ẹ̀rọ aṣàwákiri wẹ́ẹ̀bù kan tí ó ń dí àwọn kúkì ìtọ́pasẹ̀ ...

**Ìdánwò Ìlọsíwájú**: Bí o ṣe ń lọ láti ojú ìwé wẹ́ẹ̀bù kan sí òmíràn, o máa rí ọ̀pọ̀lọpọ̀ ìjápọ̀ (àwọn kan jẹ́ ìjápọ̀ inú nígbà tí àwọn mìíràn ń so mọ́ ojú ìwé wẹ́ẹ̀bù mìíràn). Bí o ṣe ń tẹ àwọn ìjápọ̀ wọ̀nyí, àwọn API aṣàwákiri kan ń jẹ́ kí ojú ìwé àkọ́kọ́ bá ojú ìwé kejì sọ̀rọ̀. Láti yanjú èyí, yan aṣàwákiri wẹ́ẹ̀bù kan tí ó ń dènà àwọn ojú ìwé wẹ́ẹ̀bù láti pín ìtọ́pinpin ìtọ́pinpin nígbà tí o bá tẹ ìjápọ̀ kan. Nígbà tí o bá ń yan aṣàwákiri yẹn tí o rò pé ó lè bá àìní rẹ mu, rí i dájú pé ó pèsè àwọn ẹ̀yà ìpamọ́ tó lágbára àti àwọn ẹ̀yà pàtàkì bíi àwọn ìdènà ìpolówó tí a ṣe sínú àti àwọn nǹkan mìíràn tí kò bá a mu. Ní àfikún, ọ̀pọ̀lọpọ̀ nínú àwọn aṣàwákiri wẹ́ẹ̀bù wọ̀nyí ń ṣe àtìlẹ́yìn fún àwọn afikún àti àwọn afikún àti nígbà míìrán àwọn afikún wọ̀nyí lè fa ewu ààbò, rí i dájú pé o máa ń fi àwọn afikún wọ̀nyí sori ẹrọ láti inú ètò ìṣiṣẹ́ tàbí àwọn orísun tí a gbẹ́kẹ̀lé.
 
## Ìṣọ̀kan Àpò Ìpamọ́ Aláwòrán Brave Zcash

Brave browser ń ṣí ọ̀nà fún ètò ìṣẹ̀dá ayélujára web3. Báwo? Àwọn agbègbè tó lé ní mílíọ̀nù méjì tí kò ṣeé dúró ni a lè lò báyìí láti fi àwọn ojú òpó wẹ́ẹ̀bù tí kò ní ìṣọ̀kan hàn. Pẹ̀lú àwọn ẹ̀yà ààbò tó lágbára ti Brave Browsers, àwọn ènìyàn lè ṣe àwárí ìkànnì ayélujára láìsí ìtọ́pasẹ̀ wọn. Brave àti Zcash ń dara pọ̀ mọ́ ara wọn láti mú àwọn irinṣẹ́ ìpamọ́ tuntun wá sí ètò ìṣẹ̀dá ayélujára Web3. Fún àǹfààní tó ga jù, Brave yóò ṣepọ pẹ̀lú ìlànà Zcash kíákíá nípasẹ̀ àpò owó crypto tí Brave's ṣe láti yí àwọn ìṣòwò crypto padà - Ìṣọ̀kan yìí yóò jẹ́ kí àwọn olùlò lè tọ́jú, fi ránṣẹ́, àti gba ZEC láìléwu pẹ̀lú àwọn owó crypto mìíràn pẹ̀lú. Ìṣọ̀kan láàárín ẹ̀rọ aṣàwárí ayélujára Brave àti Zcash yóò yí eré náà padà nítorí pé àwọn olùlò yóò ní ìṣàkóso tó ga jù lórí iṣẹ́ Web3 wọn. 

Òtítọ́ mìíràn tó yani lẹ́nu nípa ẹ̀rọ amóhùnmáwòrán Brave àti ìṣọ̀kan Zcash ni ẹ̀yà ìfiránṣẹ́ ìkọ̀kọ̀ àti ti àìsí ìṣọ̀kan; Brave, ECC, àti ẹgbẹ́ Filecoin Foundation ń ṣí ọ̀nà sílẹ̀ fún ẹ̀yà ìpamọ́ nínú ẹ̀rọ amóhùnmáwòrán Brave - ìfọwọ́sowọ́pọ̀ yìí ní èrò láti pèsè àwọn ìránṣẹ́ ìkọ̀kọ̀ àti ìgbéjáde ìròyìn nípasẹ̀ ìlànà Zcash. Níbí, Ẹ̀rọ Amóhùnmáwòrán Interplanetary (IPFS) yóò kó ipa pàtàkì nínú fífúnni ní agbára ìpamọ́ ààbò fún àkóónú ìkọ̀kọ̀.
