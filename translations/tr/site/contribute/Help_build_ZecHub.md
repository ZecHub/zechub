# ZecHub'ün İnşasına Yardım Edin 

Zcash topluluğunun bir üyesiyseniz ve ZecHub'ün inşasına katkıda bulunmak istiyorsanız, son derece faydalı olan birkaç şey var.

Bülten için bağlantıları derleyin ve bültenin GitHub sayfasına ekleyin: -> Talimatlar için [buraya tıklayın](https://github.com/ZecHub/zechub/blob/main/site/contribute/ZecWeekly_Newsletter.md)

Wiki belgelerinin doğruluğunu kontrol edin, düzenleme önerin ve GitHub'da yeni sayfalar önerin

Aşağıdaki kategorilerde video içerikleri oluşturun:
```
* Zcash explainer videos
* Zcash wallet guide/tutorials
* Third-party application demos
```

Zcash ve Gizlilik ekosistemi için posterler/grafikler/animasyonlar gibi tasarımlar üretin

Mevcut wiki sayfalarından herhangi birini çevirin.

Hataları bildirme

#### Ödül miktarlarıyla ilgili ayrıntılar için lütfen katkıda bulunma sayfamızı okuyun -> [buradan](https://zechub.wiki/contribute/contributing-guide#content).

Her pazartesi, şu anda ödül sunduğumuz görevler için sorunlar yayımlıyoruz. Siz de ödül önerebilirsiniz! Bunlar öncelikle ZEC Bounties'de bulunur.

![zecbounties](/content-images/0e4f5109-c0c9-4a0a-8d71-8172e36b9726-1a94469edf.webp)



[ZEC Bounties](https://bounties.zechub.wiki/)

[ZecHub GitHub Sorunları](https://github.com/ZecHub/zechub/issues)

[ZecHub-Wiki GitHub Sorunları](https://github.com/ZecHub/zechub-wiki/issues)



Katkıda bulunmak istediğiniz başka yollar varsa, lütfen Twitter'da ZecHub ([@ZecHub](https://twitter.com/zechub)) adlı kişiye mesaj gönderin veya [Discord](https://discord.gg/zcash) sunucumuza katılın.
