# ZecHub के निर्माण में सहायता

यदि आप Zcash समुदाय के सदस्य हैं और ZecHub के निर्माण में योगदान देना चाहते हैं, तो कुछ काम बहुत मददगार हैं।

न्यूज़लेटर (newsletter) के लिए लिंक चुनें और उन्हें न्यूज़लेटर के GitHub पेज पर जोड़ें: -> [निर्देशों के लिए यहाँ क्लिक करें](https://github.com/ZecHub/zechub/blob/main/site/contribute/ZecWeekly_Newsletter.md)

विकी दस्तावेज़ों के तथ्यों की जाँच करें, संपादन सुझाएँ और GitHub में नए पेज प्रस्तावित करें।

निम्नलिखित श्रेणियों में वीडियो सामग्री बनाएँ:
```
* Zcash explainer videos
* Zcash wallet guide/tutorials
* Third-party application demos
```

Zcash और गोपनीयता (privacy) इकोसिस्टम के लिए पोस्टर/ग्राफ़िक्स/एनिमेशन जैसे डिज़ाइन तैयार करें।

मौजूदा विकी पेजों में से किसी का भी अनुवाद करें।

बग की रिपोर्टिंग

### पुरस्कार

ZEC में राशियाँ निश्चित नहीं हैं। [बाउंटी राशि नीति](https://bounties.zechub.wiki/docs/bounty-amounts) का उपयोग करें: काम की श्रेणी के लिए एक USD अंतराल चुनें, स्पॉट मूल्य पर बदलें, और बोर्ड पर ZEC दर्ज करें। वही नीति सत्य का स्रोत है।

योगदानकर्ता वर्कफ़्लो और काम के प्रकार: [ZecHub में योगदान](https://zechub.wiki/contribute/contributing-guide)।
