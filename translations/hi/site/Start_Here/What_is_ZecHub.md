# ZecHub क्या है?
---

ZecHub, Zcash के लिए एक डिसेंट्रलाइज़्ड (decentralized) शिक्षा हब है। [ZecHub](http://zechub.xyz) का लक्ष्य एक शैक्षिक प्लेटफ़ॉर्म प्रदान करना है, जहाँ कम्युनिटी के सदस्य मिलकर ऐसी सामग्री बना सकें, उसे सत्यापित कर सकें और उसका प्रचार कर सकें जो Zcash इकोसिस्टम (ecosystem) का समर्थन करती है। हम यह कुछ तरीकों से करते हैं।

1. [ट्यूटोरियल](https://www.youtube.com/playlist?list=PL6_epn0lASLFF28ePj7P5TvtMG_WE7p3O)
2. [विकी-डॉक्स](https://zechub.wiki/)
3. [कम्युनिटी के सदस्यों के साथ इंटरव्यू वाला एक पॉडकास्ट](https://www.youtube.com/playlist?list=PL6_epn0lASLHlNCMtUErX8UfaJK6N9K5O)।
4. [एक साप्ताहिक Zcash न्यूज़लेटर।](https://zechub.substack.com/)

ट्यूटोरियल, छोटे ब्लॉग और न्यूज़लेटर (newsletter) ओपन सोर्स (open source) हैं और GitHub पर होस्ट किए जाते हैं। इसका मतलब है कि कम्युनिटी का कोई भी व्यक्ति इनमें योगदान दे सकता है। ऐसा इसलिए किया जाता है ताकि सामग्री सटीक रहे और चैनल में कोई सिंगल पॉइंट ऑफ़ फ़ेलियर (single point of failure) न हो।

यदि आप Zcash पर नए हैं, तो [यह गाइड](/start-here/new-user-guide) देखें।****

## ZecHub में बदलाव कैसे करें

---

1. [ZecHub की GitHub रिपॉज़िटरी](https://github.com/ZecHub/zechub) पर जाएँ
   
2. एक नया GitHub अकाउंट बनाएँ या अपने अकाउंट से लॉग इन करें
   
3. पुल रिक्वेस्ट (pull request) करना सीखने के लिए यह गाइड देखें:
