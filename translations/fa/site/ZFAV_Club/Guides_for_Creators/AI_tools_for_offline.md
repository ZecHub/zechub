# ابزارهای هوش مصنوعی (محلی، آفلاین)

<aside>
*هنوز در حال نوشتن و ساختن این بخش هستیم...*

</aside>

### تولید تصویر

مدل‌های تولید تصویر را از کجا دانلود کنیم؟ 
در [**HuggingFace**](https://huggingface.co/models?pipeline_tag=text-to-image&sort=trending) و [**Civitai](https://civitai.com/)** مدل‌های مختلف بسیاری وجود دارد.

## Windows - دانلود مدل‌های سفارشی

معمولاً برای هر ابزار هوش مصنوعی دست‌کم به یک GPU با 4GB حافظهٔ ویدیویی نیاز است.

GPUهای Nvidia بهترین عملکرد را دارند.

- [InvokeAI](https://invoke-ai.github.io/InvokeAI/) (به 4GB حافظهٔ GPU نیاز دارد)
- [NMKD Stable Diffusion GUI](https://nmkd.itch.io/t2i-gui)
- [EasyDiffusion 3.0](https://github.com/easydiffusion/easydiffusion)

### Mac OS - دانلود مدل‌های سفارشی

- [Draw Things: AI Generation](https://apps.apple.com/ee/app/draw-things-ai-generation/id6444050820) از AppStore - رایگان
(می‌تواند از مدل‌های مختلف بسیاری از StableDiffusion استفاده کند)
- [DiffusionBee](https://diffusionbee.com/) - رایگان
(می‌تواند از مدل‌های مختلف بسیاری از StableDiffusion استفاده کند)
- [InvokeAI](https://invoke-ai.github.io/InvokeAI/) (به 4GB حافظهٔ GPU نیاز دارد)

### Linux - دانلود مدل‌های سفارشی

- [InvokeAI](https://invoke-ai.github.io/InvokeAI/) (به 4GB حافظهٔ GPU نیاز دارد)
