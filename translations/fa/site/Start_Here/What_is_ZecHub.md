# ZecHub چیست؟
---

ZecHub یک مرکز آموزشی غیرمتمرکز برای Zcash است. هدف [ZecHub](http://zechub.xyz) فراهم کردن یک پلتفرم آموزشی است که در آن اعضای کامیونیتی بتوانند با همکاری یکدیگر محتوایی را ایجاد، اعتبارسنجی و ترویج کنند که از اکوسیستم Zcash پشتیبانی می‌کند. ما این کار را از طریق چند سازوکار انجام می‌دهیم.

1. [آموزش‌ها](https://www.youtube.com/playlist?list=PL6_epn0lASLFF28ePj7P5TvtMG_WE7p3O)
2. [مستندات ویکی](https://zechub.wiki/)
3. [یک پادکست با مصاحبه‌هایی با اعضای کامیونیتی](https://www.youtube.com/playlist?list=PL6_epn0lASLHlNCMtUErX8UfaJK6N9K5O).
4. [یک خبرنامه هفتگی Zcash.](https://zechub.substack.com/)

آموزش‌ها، بلاگ‌های کوتاه و خبرنامه متن‌باز هستند و روی GitHub میزبانی می‌شوند، به این معنا که هر کسی از کامیونیتی می‌تواند در آن‌ها مشارکت کند. هدف از این کار، اطمینان از دقت محتوا و همچنین این است که خود این کانال هیچ نقطه شکست واحدی نداشته باشد.

اگر با Zcash تازه آشنا شده‌اید، از [این راهنما](/start-here/new-user-guide) استفاده کنید.****

## نحوه ایجاد تغییرات در ZecHub

---

1. به [مخزن GitHub متعلق به ZecHub](https://github.com/ZecHub/zechub) بروید
   
2. یک حساب GitHub جدید بسازید یا با حساب خود وارد شوید
   
3. برای یادگیری نحوه ایجاد یک pull request، این راهنما را دنبال کنید:
