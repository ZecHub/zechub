# به ساخت ZecHub کمک کنید 

اگر شما عضو کامیونیتی Zcash هستید و می‌خواهید در ساخت ZecHub مشارکت کنید، چند کار هست که بسیار مفید است.

لینک‌هایی را برای خبرنامه گردآوری کنید و آن‌ها را به صفحه GitHub خبرنامه اضافه کنید: -> [برای دیدن دستورالعمل‌ها اینجا کلیک کنید](https://github.com/ZecHub/zechub/blob/main/site/contribute/ZecWeekly_Newsletter.md)

مستندات ویکی را راستی‌آزمایی کنید، ویرایش پیشنهاد دهید و صفحه‌های جدید را در GitHub پیشنهاد کنید

در دسته‌های زیر محتوای ویدیویی بسازید:
```
* Zcash explainer videos
* Zcash wallet guide/tutorials
* Third-party application demos
```

طرح‌هایی مانند پوستر، گرافیک یا انیمیشن برای اکوسیستم Zcash و حریم خصوصی تولید کنید 

هر یک از صفحه‌های موجود ویکی را ترجمه کنید.

گزارش باگ‌ها

### پاداش‌ها

مبالغ در ZEC ثابت نیستند. از [سیاست مبالغ پاداش‌ها](https://bounties.zechub.wiki/docs/bounty-amounts) استفاده کنید: یک بازه دلاری برای نوع کار انتخاب کنید، آن را با نرخ لحظه‌ای تبدیل کنید و ZEC را در برد وارد کنید. مرجع اصلی همان سیاست است.

روند کاری مشارکت‌کنندگان و انواع کار: [مشارکت در ZecHub](https://zechub.wiki/contribute/contributing-guide).
