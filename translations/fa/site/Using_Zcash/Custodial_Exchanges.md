# <img src="/content-images/image-2024-02-03-173258092-a5440e5ee2.webp" alt="Alt Text" width="50"/>   صرافی‌های امانی

Ironwood استخر محافظت‌شده‌ای است که با ارتقای شبکه در جولای 2026 معرفی شد. صرافی‌هایی که فقط با آدرس‌های شفاف t کار می‌کنند هرگز با آن سروکار ندارند، بنابراین برای آن‌ها «قابل اعمال نیست» درج شده است. در مواردی که یک صرافی از آدرس‌های محافظت‌شده پشتیبانی می‌کند اما اعلام نکرده از کدام استخر استفاده می‌کند، به‌جای حدس زدن همین نکته ذکر شده است.
