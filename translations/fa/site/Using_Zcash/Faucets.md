# فاست‌ها

<img width="2138" height="878" alt="Screenshot_2025-10-30_10-36-45" src="/content-images/bba0da3b-7064-4680-9535-a0dfcf50cc00-1827fccf4b.webp" />


فاست‌ها سرویس‌هایی هستند که مقادیر کمی ارز دیجیتال را به‌صورت رایگان توزیع می‌کنند. توسعه‌دهندگان اغلب از آن‌ها برای آزمایش با ارز دیجیتال استفاده می‌کنند و کاربران نیز از آن‌ها برای به دست آوردن مقادیر کمی ارز دیجیتال بدون نیاز به خرید آن بهره می‌برند. این سرویس‌ها معمولاً مقدار ارز دیجیتالی را که یک کاربر می‌تواند در یک بازه زمانی مشخص دریافت کند محدود می‌کنند.
