# راهنمای Raspberry Pi 4 برای اجرای Zebra

<img src="/content-images/image-2023-11-28-172907488-e7e9fd4ac5.webp" alt="raspberry pi" width="300" height="300"/>

اجرای نرم‌افزار نود Zebra روی Raspberry Pi 4 به شما امکان می‌دهد به‌عنوان یک نود مستقل و سازگار با اجماع در شبکه Zcash مشارکت کنید. این راهنما شما را گام‌به‌گام در راه‌اندازی و اجرای Zebra روی Raspberry Pi 4 همراهی می‌کند.

## پیش‌نیازها

1. Raspberry Pi 4 (رم 2GB یا بیشتر توصیه می‌شود).

2. کارت MicroSD (ظرفیت 16GB یا بیشتر توصیه می‌شود) با سیستم‌عامل Raspberry Pi OS (Raspbian) نصب‌شده.

3. اتصال پایدار به اینترنت.

4. صفحه‌کلید، ماوس و یک مانیتور (برای راه‌اندازی اولیه).

5. کلاینت SSH (اختیاری، برای دسترسی از راه دور).

## نصب

1. __سیستم خود را به‌روزرسانی کنید__
   یک ترمینال باز کنید یا از طریق SSH به Raspberry Pi خود وصل شوید و با اجرای دستورات زیر مطمئن شوید که سیستم شما به‌روز است:

   __sudo apt update__

   __sudo apt upgrade__

2. __وابستگی‌ها را نصب کنید__
   شما باید برخی وابستگی‌های لازم برای ساخت و اجرای Zebra را نصب کنید:

   __sudo apt install build-essential cmake git clang libssl-dev pkg-config__

3. __مخزن Zebra را کلون کنید__
   یک ترمینال باز کنید و مخزن Zebra را روی Raspberry Pi خود کلون کنید:

   __git clone https://github.com/ZcashFoundation/zebra.git__

   __cd zebra__

4. __Zebra را بسازید__
   برای ساخت Zebra از دستور زیر استفاده کنید:

   __cargo build --release__

   این فرایند ممکن است مدتی طول بکشد. مطمئن شوید که Raspberry Pi شما به‌اندازه کافی خنک می‌شود، زیرا کامپایل کردن می‌تواند گرما تولید کند.

5. __پیکربندی__
   یک فایل پیکربندی برای Zebra ایجاد کنید. شما می‌توانید از پیکربندی پیش‌فرض به‌عنوان نقطه شروع استفاده کنید:

   __cp zcash.conf.example zcash.conf__

   فایل zcash.conf را ویرایش کنید تا تنظیمات نود خود را سفارشی کنید. شما می‌توانید شبکه را مشخص کنید، استخراج را فعال کنید، اتصال به همتایان را تنظیم کنید و موارد دیگر.

6. __Zebra را اجرا کنید__
   اکنون می‌توانید Zebra را با پیکربندی سفارشی خود اجرا کنید:

   __./target/release/zebrad -c zcash.conf__

   __git comment__ 

   این دستور نود Zebra را اجرا می‌کند و همگام‌سازی آن با بلاک‌چین Zcash آغاز می‌شود.

7. __پایش__
   شما می‌توانید پیشرفت و وضعیت نود Zebra خود را با باز کردن یک مرورگر وب و رفتن به __http://127.0.0.1:8233/status__. پایش کنید.

## عیب‌یابی

اگر در ساخت یا اجرای Zebra با مشکلی روبه‌رو شدید، برای نکات عیب‌یابی و اطلاعات بیشتر به [Zebra مستندات](https://zebra.zfnd.org/user/troubleshooting.html) مراجعه کنید.

حتماً Raspberry Pi خود را خنک نگه دارید، زیرا اجرای یک نود می‌تواند گرما تولید کند. ممکن است بخواهید از یک راهکار خنک‌کننده مانند فن یا هیت‌سینک استفاده کنید.

## نتیجه‌گیری

با دنبال کردن این راهنما، شما باید Zebra را با موفقیت روی Raspberry Pi 4 خود راه‌اندازی و اجرا کرده باشید. اکنون شما به‌عنوان یک نود مستقل در شبکه Zcash مشارکت می‌کنید و به حفظ حریم خصوصی تراکنش‌های Zcash کمک می‌کنید.
