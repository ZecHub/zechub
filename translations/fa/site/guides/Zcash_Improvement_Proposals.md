# ZIP چیست
پیشنهاد بهبود Zcash (ZIP) یک سند طراحی است که اطلاعاتی را در اختیار کامیونیتی Zcash قرار می‌دهد یا یک قابلیت جدید را برای Zcash، فرایندها یا محیط آن توصیف می‌کند. ZIP باید مشخصات فنی مختصری از قابلیت و دلیل منطقی آن را ارائه دهد.

هدف ما این است که ZIPها سازوکار اصلی برای پیشنهاد قابلیت‌های جدید، جمع‌آوری نظرات کامیونیتی درباره‌ی یک موضوع و مستندسازی تصمیم‌های طراحی به‌کاررفته در Zcash باشند. مالک یا مالکان ZIP (معمولاً نویسنده یا نویسندگان آن) مسئول ایجاد اجماع در کامیونیتی و مستندسازی دیدگاه‌های مخالف هستند.

از آنجا که ZIPها به‌صورت فایل‌های متنی در یک مخزن نسخه‌بندی‌شده نگهداری می‌شوند، تاریخچه‌ی بازبینی آن‌ها سابقه‌ی تاریخی پیشنهاد قابلیت به شمار می‌رود.

-> [zips.z.cash](https://zips.z.cash)


## ویراستاران ZIP

هر ZIP که ارسال می‌شود باید فرایند بازبینی را طی کند. ویراستاران ZIP وظیفه دارند اطمینان حاصل کنند که قالب و محتوای هر ZIP اصطلاحات، دلیل منطقی و تغییرات فنی اعمال‌شده را به‌درستی توصیف می‌کند. 

```markdown
* Jack Grigg, Kris Nuttycombe and Daira-Emma Hopwood associated with the ECC.
* Conrado, and Arya, associated with the ZF.
* Sam and Mark, associated with SL.
```

## ZIPهای NU6.3 (Ironwood)
