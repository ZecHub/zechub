# **Arti: کلاینت نسل بعدی Tor به زبان Rust**
![Atri Logo](/content-images/_unavailable.svg)

**Arti** ابتکار پروژه Tor برای ساخت یک کلاینت نسل بعدی **Tor** با استفاده از زبان برنامه‌نویسی **Rust** است. Arti به‌گونه‌ای طراحی شده است که ماژولار، قابل جاسازی و آماده برای محیط عملیاتی باشد و پیاده‌سازی امن‌تر و کارآمدتری از پروتکل‌های ناشناس‌سازی **Tor** ارائه دهد. با **Arti نسخه 1.4.0**، چندین به‌روزرسانی مهم معرفی شده است:

- یک **رابط RPC جدید** برای تعامل بهتر.
- کارهای مقدماتی برای **پشتیبانی از رله**.
- بهبودهایی در **مقاومت سرویس‌های onion در سمت سرویس در برابر حملات منع سرویس**.

این نسخه ادامه تلاش‌های پروژه Tor برای ارائه امنیت، کارایی و ماژولار بودن بهتر برای کاربران و توسعه‌دهندگان Tor است.


---


## **نصب کلاینت Arti**

برای نصب و اجرای **Arti** به‌عنوان یک پراکسی SOCKS روی سیستم خود، این مراحل را دنبال کنید.

---

### **مرحله 1: راه‌اندازی محیط توسعه Rust**

پیش از آنکه بتوانید Arti را از کد منبع بسازید، باید آخرین نسخه پایدار **Rust** را نصب کرده باشید.

#### برای نصب Rust:

1. به [وب‌سایت رسمی Rust](https://www.rust-lang.org/) مراجعه کنید.
2. دستورالعمل‌های نصب را برای سیستم‌عامل خود دنبال کنید.
3. نصب را با اجرای دستور زیر بررسی کنید:
   
   ```sh
   rustc --version
   ```

این کار تأیید می‌کند که آخرین نسخه پایدار Rust روی سیستم شما نصب شده است.

#### **note برای کاربران Windows**:
- Rust را می‌توان روی Windows از طریق [**rustup**](https://rustup.rs/)، که یک نصب‌کننده زنجیره ابزار است، نصب کرد. اطمینان حاصل کنید که یک محیط ساخت سازگار نیز راه‌اندازی کرده‌اید (ممکن است روی Windows به **Visual Studio Build Tools** نیاز داشته باشید).
  
---

### **مرحله 2: کلون کردن مخزن Arti**

برای دریافت آخرین نسخه کلاینت Arti، باید مخزن را از [**GitLab**](https://gitlab.torproject.org/tpo/core/arti) کلون کنید.

#### مراحل:
1. ترمینال خود را باز کنید (Command Prompt، PowerShell یا Git Bash روی Windows).
2. دستور زیر را برای کلون کردن مخزن اجرا کنید:
   
   ```sh
   git clone https://gitlab.torproject.org/tpo/core/arti.git
   ```
4. به پوشه *arti* که تازه ایجاد شده است بروید:
   
   ```sh
   cd arti
   ```

این کار کد منبع Arti را به دستگاه محلی شما منتقل می‌کند.

---

### **مرحله 3: ساخت فایل اجرایی Arti**

پس از کلون کردن مخزن، باید Arti را با استفاده از **Cargo**، که مدیر بسته و ابزار ساخت Rust است، بسازید.

#### برای ساخت Arti:
1. در ترمینال، دستور زیر را اجرا کنید:
   ```sh
   cargo build --release
   ```

این دستور کد Arti را کامپایل کرده و آن را برای محیط عملیاتی بهینه می‌کند (پرچم *--release*). فایل اجرایی در پوشه *target/release* ایجاد خواهد شد.

#### محل فایل اجرایی کامپایل‌شده:
- پس از ساخت، فایل اجرایی Arti در این مسیر قرار خواهد داشت:  
  ```sh
  target/release/arti
  ```

شما می‌توانید این فایل اجرایی را مستقیماً از ترمینال اجرا کنید.

---

### **مرحله 4: اجرای پراکسی SOCKS در Arti**

برای استفاده از Arti به‌عنوان یک پراکسی SOCKS (که ترافیک اینترنت شما را از طریق شبکه Tor هدایت می‌کند)، باید پراکسی را راه‌اندازی کنید.

#### برای راه‌اندازی پراکسی SOCKS:
1. دستور زیر را اجرا کنید:
   ```sh
   ./target/release/arti proxy -p 9150
   ```

این دستور Arti را به‌عنوان یک **پراکسی SOCKS5** روی **پورت 9150** راه‌اندازی می‌کند که پورت پیش‌فرضی است که Tor برای ترافیک SOCKS از آن استفاده می‌کند.

---

### **مرحله 5: پیکربندی برنامه‌ها برای استفاده از Arti**

هنگامی که Arti به‌عنوان پراکسی SOCKS در حال اجراست، باید برنامه‌های خود را طوری پیکربندی کنید که از آن برای هدایت ترافیک از طریق شبکه Tor استفاده کنند.

#### مراحل:
1. در تنظیمات برنامه خود (برای مثال، مرورگر وب یا برنامه ترمینال)، به دنبال **تنظیمات پراکسی** بگردید.
2. **پراکسی SOCKS5** را روی *localhost:9150* تنظیم کنید.

این کار تمام ترافیک برنامه‌های شما را با استفاده از Arti به‌عنوان واسطه، از طریق **شبکه Tor** هدایت می‌کند.

---

## **یکپارچگی Arti با شبکه Tor**

در اینجا یک نمودار ساده‌شده آمده است که نشان می‌دهد Arti چگونه همراه با شبکه Tor کار می‌کند:


```plaintext
[Application] --(SOCKS5)--> [Arti SOCKS Proxy] --(Tor Protocol)--> [Tor Network]
```

- **برنامه** با استفاده از پروتکل **SOCKS5** به **پراکسی SOCKS در Arti** متصل می‌شود.
- سپس Arti با **شبکه Tor** ارتباط برقرار می‌کند و اطمینان حاصل می‌کند که ترافیک شما هنگام عبور از شبکه ناشناس می‌شود.

## **مخزن GitLab و مشارکت**

اگر به مشارکت در توسعه **Arti** علاقه‌مند هستید، می‌توانید کد را بررسی کرده و از طریق **GitLab** مشارکت کنید.

- **پیوند مخزن**: [مخزن GitLab پروژه Arti](https://gitlab.torproject.org/tpo/core/arti)
- **کلون کردن مخزن**:
  ```sh
  git clone https://gitlab.torproject.org/tpo/core/arti.git
  ```

### **فورک کردن و مشارکت**:
1. مخزن را در GitLab **فورک** کنید (به حساب کاربری GitLab نیاز دارد).
2. مخزن فورک‌شده خود را به محیط محلی خود متصل کنید:
   ```sh
   git remote add _name_ git@gitlab.torproject.org:_name_/arti.git
   git fetch _name_
   ```
   به‌جای *_name_* نام کاربری GitLab خود را قرار دهید.

3. **تغییرات را به فورک خود push کنید**:
   ```sh
   git push _name_ main
   ```

4. **یک Merge Request (MR) در GitLab ایجاد کنید**:
   به بخش Merge Request در فورک GitLab خود بروید:
   ```plaintext
   https://gitlab.torproject.org/_name_/arti/-/merge_requests
   ```

### **راهنمای Merge Request**:
- **در طول بازبینی، commitها را rebase و squash نکنید**.
- در صورت لزوم، از *fixup!* یا *squash!* برای squash خودکار commitها استفاده کنید.
- در طول چرخه بازبینی، به‌جای squash کردن، سعی کنید **commitهای جدید اضافه کنید**.
