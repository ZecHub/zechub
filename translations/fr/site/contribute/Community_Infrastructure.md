# Cadre de l'infrastructure communautaire ZecHub


### Infrastructure communautaire

Le programme de primes ZecHub est la voie rémunérée pour ce travail : [ZEC Bounties](https://bounties.zechub.wiki/). Pour choisir un montant en ZEC, consultez la [politique relative aux montants des primes](https://bounties.zechub.wiki/docs/bounty-amounts). Processus pour les contributeurs : [Contribuer à ZecHub](https://zechub.wiki/contribute/contributing-guide).
