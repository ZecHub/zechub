# <img src="/content-images/image-2024-02-03-173258092-a5440e5ee2.webp" alt="Alt Text" width="50"/>   Plateformes d'échange custodiales

Ironwood est le pool protégé arrivé avec la mise à niveau du réseau de juillet 2026. Les plateformes d'échange qui ne traitent que les t-adresses transparentes n'y ont jamais accès ; elles sont donc indiquées comme non applicables. Lorsqu'une plateforme prend en charge les adresses protégées mais n'a pas précisé quel pool elle utilise, la ligne l'indique plutôt que de deviner.
