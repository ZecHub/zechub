# <img src="/content-images/image-2024-02-03-173258092-a5440e5ee2.webp" alt="Alt Text" width="50"/>   Exchanges dépositaires

Ironwood est le pool protégé arrivé avec la mise à niveau du réseau de juillet 2026. Les exchanges qui ne gèrent que des adresses t transparentes n'y touchent jamais : ils sont donc indiqués comme non concernés. Lorsqu'un exchange gère des adresses protégées sans avoir précisé quel pool il utilise, la ligne l'indique plutôt que de faire une supposition.
