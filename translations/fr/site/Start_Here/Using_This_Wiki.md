# Utiliser ce wiki

Tout cela peut sembler un peu intimidant. Nous le comprenons ! Ce wiki contient beaucoup d'informations. Voici un guide simple, étape par étape, qui vous montre comment le parcourir.

## Nouveau sur Zcash

Si vous découvrez Zcash, vous êtes au bon endroit pour vous mettre à niveau. Commencez par consulter ces pages :

[Zcash Guide du nouvel utilisateur](https://zechub.wiki/start-here/new-user-guide#content)

[Zcash Ressources](https://zechub.wiki/start-here/zcash-resources#content)

[Zcash Notions de base](https://zechub.wiki/start-here/what-is-zec-and-zcash#content)

## Prêt à utiliser Zcash

Après avoir lu les documents d'introduction et les ressources qui les accompagnent, consultez les vidéos [Utiliser ZEC](https://zechub.wiki/guides/using-zec-privately#content) et [Tutoriels](https://youtube.com/playlist?list=PL6_epn0lASLFF28ePj7P5TvtMG_WE7p3O&si=4vleWUbCGbNJu1-M) pour apprendre à utiliser ZEC.

## Je suis membre de la communauté Zcash

Si vous êtes membre de la communauté, c'est formidable ! Le meilleur moyen de rester informé est de suivre la newsletter hebdomadaire [Zcash Ecosystem Digest](https://zechub.substack.com/s/zcash-ecosystem-digest) et de suivre tous les comptes de la [Liste des pages communautaires Zcash](https://zechub.wiki/zcash-community/community-links#content).

## Je veux contribuer à ZecHub

Parfait ! Veuillez lire [Qu'est-ce que ZecHub](https://zechub.wiki/start-here/what-is-zechub#content), puis consultez [Aider à construire ZecHub](https://zechub.wiki/contribute/help-build-zechub) pour savoir comment contribuer.
