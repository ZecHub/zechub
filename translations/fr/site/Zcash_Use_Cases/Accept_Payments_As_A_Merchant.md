## En bref

- Acceptez des paiements avec une adresse protégée
- Évitez d'exposer les données de transaction de vos clients
- Utilisez des mémos ou des systèmes hors chaîne pour le suivi des commandes
- Gardez confidentiels les revenus de votre entreprise

## <img src="/content-images/warning-error-svgrepo-com-b7ea8a50da.svg" width="24" height="24" className="inline-block align-middle mr-1 p-[2px]" alt="warning icon"/> Le problème

Les paiements en cryptomonnaie traditionnels exposent :
- Le comportement d'achat des clients
- Les revenus du commerçant
- L'historique des transactions

Cela entraîne :
- Une perte de confidentialité pour les clients
- Des fuites d'informations utiles à la concurrence
- Une transparence financière que vous ne souhaitez peut-être pas

<br/>

## <img src="/content-images/icons8-lock-2f8e221321.svg" width="24" height="24" className="inline-block align-middle mr-1 p-[2px]" alt="toolbox icon"/> Pourquoi Zcash ?

Zcash permet :
- Des paiements confidentiels pour les clients
- Un suivi confidentiel des revenus
- La protection de l'activité de l'entreprise


<br/>

## <img src="/content-images/icons8-toolbox-9bebbb1619.svg" width="24" height="24" className="inline-block align-middle mr-1 p-[2px]" alt="toolbox icon"/> Ce dont vous avez besoin

- Un portefeuille Zcash prenant en charge les transactions protégées
- Un processus de paiement simple (manuel ou intégré)
- Facultatif : un système de suivi des commandes


<br/>

## <img src="/content-images/ladder-svgrepo-com-7232bf46ed.svg" width="24" height="24" className="inline-block align-middle mr-1 p-[2px]" alt="step icon"/> Guide étape par étape

### Étape 1 : configurez une adresse de paiement

- Générez une adresse protégée (z)
- Utilisez-la pour recevoir les paiements


### Étape 2 : affichez les instructions de paiement

Pour chaque transaction :
- Indiquez votre adresse z
- Précisez le montant à payer
- Ajoutez éventuellement une référence dans le mémo

### Étape 3 : suivez les commandes

Utilisez :
- Les mémos (p. ex. le numéro de commande)
- Ou un suivi hors chaîne (base de données, tableur)


Exemple :
- Commande n° 4821


### Étape 4 : confirmez le paiement

- Surveillez les transactions protégées entrantes
- Faites correspondre le mémo ou le montant à la commande


### Étape 5 : appliquez de bonnes pratiques de confidentialité

- Évitez si possible de réutiliser publiquement les mêmes adresses
- N'exposez pas l'historique des transactions
- Utilisez des portefeuilles distincts pour les différentes unités de votre entreprise si nécessaire


<br/>

## <img src="/content-images/icons8-cancel-7f786be3c1.svg" width="24" height="24" className="inline-block align-middle mr-1 p-[2px]" alt="cancel icon"/> Erreurs courantes à éviter

- Utiliser des adresses transparentes pour les paiements  
- Publier les preuves de transaction  
- Associer l'identité des clients aux données de la blockchain  
- Ne pas suivre correctement les paiements
