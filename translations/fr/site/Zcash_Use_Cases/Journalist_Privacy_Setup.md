## En bref

- Utilisez des adresses protégées pour toutes vos transactions
- N'exposez jamais publiquement l'identité de votre portefeuille
- Protégez vos sources en évitant les paiements traçables
- Utilisez les mémos avec prudence pour communiquer de façon sécurisée

<br/>

- Journalistes
- Enquêteurs
- Militants
- Personnes à haut risque qui gèrent des paiements sensibles

## <img src="/content-images/warning-error-svgrepo-com-b7ea8a50da.svg" width="24" height="24" className="inline-block align-middle mr-1 p-[2px]" alt="warning icon"/> Le problème

Les journalistes sont exposés à :
- La surveillance
- Des risques d'exposition de leurs sources
- Un traçage financier par des adversaires

L'utilisation de cryptomonnaies transparentes peut révéler :
- Qui vous a payé
- Qui vous avez payé
- Quand et combien

<br/>

## <img src="/content-images/icons8-lock-2f8e221321.svg" width="24" height="24" className="inline-block align-middle mr-1 p-[2px]" alt="toolbox icon"/> Pourquoi Zcash ?


Zcash offre :
- Une solide confidentialité financière
- Une protection pour les transactions sensibles
- Un risque réduit de relier les journalistes à leurs sources

<br/>

## <img src="/content-images/icons8-toolbox-9bebbb1619.svg" width="24" height="24" className="inline-block align-middle mr-1 p-[2px]" alt="toolbox icon"/> Ce dont vous avez besoin

- Un portefeuille Zcash compatible avec les adresses protégées
- Un canal de communication sécurisé (en dehors de la blockchain)
- De la discipline opérationnelle

<br/>

## <img src="/content-images/ladder-svgrepo-com-7232bf46ed.svg" width="24" height="24" className="inline-block align-middle mr-1 p-[2px]" alt="step icon"/> Guide étape par étape


### Étape 1 : créez un portefeuille dédié

- Utilisez un portefeuille réservé à votre travail sensible
- Ne le mélangez pas avec vos transactions personnelles

### Étape 2 : utilisez uniquement des adresses protégées

- Effectuez toujours vos transactions avec des adresses z
- Évitez totalement les transactions transparentes


### Étape 3 : protégez les paiements à vos sources

Si vous payez des sources :
- Utilisez des transactions protégées (z → z)
- Évitez les schémas temporels prévisibles
- Ne réutilisez pas les adresses


### Étape 4 : soyez prudent avec les mémos

- N'incluez JAMAIS d'informations sensibles dans les mémos
- Utilisez des références neutres ou codées si nécessaire


### Étape 5 : maintenez votre sécurité opérationnelle

- Évitez de relier votre portefeuille à votre identité
- Ne confirmez pas publiquement les transactions
- Utilisez des canaux distincts pour communiquer


<br/>

## <img src="/content-images/icons8-cancel-7f786be3c1.svg" width="24" height="24" className="inline-block align-middle mr-1 p-[2px]" alt="cancel icon"/> Erreurs courantes à éviter

- Utiliser des adresses transparentes  
- Réutiliser les mêmes adresses pour plusieurs sources  
- Inclure des données sensibles dans les mémos  
- Relier votre portefeuille à votre identité publique
