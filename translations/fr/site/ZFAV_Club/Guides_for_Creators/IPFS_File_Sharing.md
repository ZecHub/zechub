# Partage de fichiers P2P avec IPFS et le navigateur Brave

Nous pouvons utiliser IPFS pour partager entre nous des fichiers multimédias volumineux, de pair à pair.

Quel est donc le problème ? Les passerelles IPFS ne fonctionnent pas pour les fichiers volumineux : elles expirent.

**Prérequis** : [IPFS Desktop](https://docs.ipfs.tech/install/ipfs-desktop/) + [navigateur Brave](https://brave.com/)

En bref, la vidéo se trouve à la fin.

Nous pouvons l'utiliser entre nous au sein du ZF AV Club pour transférer des fichiers multimédias volumineux, et le documenter pour vous tous, parce que c'est amusant et super cool !!

*EN PLUS*, nous collaborerons directement avec l'équipe IPFS de Protocol Labs pour développer ce cas d'utilisation.
Un autre avantage issu des contacts noués au dWeb Camp !

Sans IPFS installé sur la machine de réception ET avec un navigateur autre que Brave : vous devrez attendre que la passerelle charge le fichier. *Cela renverra une erreur 504 pour les fichiers volumineux.*

Prochaine étape : comment épingler les fichiers d'autres personnes sur votre machine, afin d'éviter le problème du point de défaillance unique lorsque le nœud d'origine se déconnecte.
