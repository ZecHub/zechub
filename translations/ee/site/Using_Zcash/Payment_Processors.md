# Zcash Fexexe ƒe Mɔwɔlawo

Mɔ siwo dzi woate ŋu axɔ ZEC abe asitsalá ene, woɖe wo ɖe eme kple wo nɔ anyi kpɔ. Woɖo nyati sia ƒe akpa sia akpa kple provider la ƒe asaŋuti kple API le **29 July 2026** dzi, Zcash Payment Service koe wotsɔ kpe ɖe eŋu le **1 November 2026** dzi.

Ɣaɣla [privacy] ƒe assetwo ƒe kpekpeɖeŋu trɔa zi geɖe, eyata xexlẽ sia xɔ nyateƒe ƒe ŋkeke si woda ƒo. Ne èle esrɔ̃m ɣleti aɖe megbe la, kpɔ provider la ƒe asaŋuti hafi nàtsɔe akpe ɖe wò dɔwɔwɔ ŋu.

### Nu si columnwo gɔme fia

**Dɔmetɔxɔxɔ** nye ne processor la léa wò ZEC. Menye asikplɔ-dzralá o fia be woyia ɖe gakotoku si wò nèdzra la me.

**Ɣaɣla ZEC** nye ne woate ŋu axe wò ɣaɣla gaƒuƒoƒo me. Nuwo ƒe ʋuʋuɖi ko fia be asixɔxɔ la kple gaɖoƒe ƒe dzesiwo katã le ƒeƒe le gaɖoɖowo ƒuƒoƒo ƒe ɖoɖonu dzi.

**Ɖo wò ŋutɔ ƒe host** nye ne nàte ŋu awɔ software la wò ŋutɔ, company aɖeke manɔ titina o.

**Asitsalá ƒe adzɔ** mekpɔ Zcash network adzɔwo o, ame aɖe xe wo le nu sia nu me.

Afisi provider aɖe metsɔ nu aɖe ɖe go o la, entry la gblɔ "wometsɔ fia o" alo "wometsɔ ɖe agbalẽ me o" le nuteƒe me, eye menya eƒe susu o. Esia menye "ao" o.

### Ame ka nàtia

Ne èdi ɣaɣla kple dzikpɔkpɔ sɔŋ wu la, zã **BTCPay Server**, **CipherPay** si wò ŋutɔ nèɖo host, alo **Zcash Payment Service** ne nàte ŋu akpe code sue aɖe ɖe wò asaŋuti ŋu. Wo katã nye ɣaɣla, open source, eye womelè ga na wò o.

Ne èdi be nàxɔ fexexewo le fiadze me le internet dzi ke o la, zã **Flexa**.

Ne èdi hosted gateway afi si nuwo ƒe ʋuʋuɖi fexexewo wɔa dɔ la, zã **NOWPayments** alo **Plisio**.

Nu vevi aɖe si woagblɔ ake: processor si xɔa nuwo ƒe ʋuʋuɖi ko ɖea fexexe sia fexexe ƒe asixɔxɔ kple gaɖoƒe ƒe dzesi ɖe gaɖoɖowo ƒuƒoƒo ƒe ɖoɖonu dzi. Eye kple hosted processor siawo katã siwo menye asikplɔ-dzralá o la, nèna wò nukpɔsafui na wo, ale be company la ate ŋu akpɔ wò fexexewo togbɔ be mate ŋu axɔ wo o. Wò ŋutɔ ƒe hosting ko nye mɔ si ate ŋu aɖe esia ɖa.

Nèna nukpɔsafui si kpɔa nu ko na CipherPay, ale be fexexewo yia tẽ ɖe wò ŋutɔ ƒe gakotoku me, eye wòmelè ga o. Ezãa gaɖoƒe ƒe dzesi yeye ɖe invoice sia fexexe ta.

## [Zcash Payment Service](https://github.com/nerdcash/zcash-payment-service)
- **Kpekpeɖeŋu ƒe ƒomevi**: Ɣaɣla ko (Sapling kple Orchard)
- **Nuxlɔɖi**: Zcash fexexe processor si nye ablɔɖe, si wò ŋutɔ nàɖo host na asitsaláwo siwo wɔa dɔ le internet dzi, woate ŋu awɔe abe Docker container ene alo aɖe eƒe Rust crate ɖe eme.
- **URL**: [Zcash Payment Service](https://github.com/nerdcash/zcash-payment-service)

Processor si nye ablɔɖe, open-source (MIT), si Andrew Arnott wɔ, ame si zãa eya ŋutɔ na fexexewo le eƒe app me.

Enaa incoming viewing key (UIVK) ko. Ate ŋu akpɔ fexexewo ƒe va, gake mate ŋu axɔ wo o, eyata server si wogbã ɖe eme hã mate ŋu aɖe wò ga o. Key la nɔa le wò ŋutɔ ƒe server dzi, eyata company aɖeke hã makpɔ wò fexexewo o.

Checkout sia fexexe xɔa unified address yeye kple Sapling kple Orchard receivers, eye nuwo ƒe ʋuʋuɖi aɖeke mele o. Fexexewo yia tẽ ɖe wò ŋutɔ ƒe gakotoku me.

Adzɔ, account, alo usage meter aɖeke mele o. Nàxe Zcash network adzɔwo kple wò hosting.

Wò ŋutɔ ƒe hosting ko: Docker container ɖeka, alo Rust crate le app si nèwɔa dɔ kple xoxo me. Exlẽa ɖoɖonu la tso lightwalletd server si wò ŋutɔ nètia, eyata full node hia wò o.

Eƒe ɖoɖo hia code, menye plugin o. Wò asaŋuti bia fexexe ƒe gaɖoƒe ƒe dzesi kple QR code tso service la gbɔ le checkout me, eye service la gblɔa na wò asaŋuti ne ga va le signed webhooks to. npm client le JavaScript kple TypeScript backendwo ta, eye open-source [demo store](https://github.com/nerdcash/zcash-payment-demo-store) le afi si nàte ŋu akɔ nu tso. Shopify alo WooCommerce plugin mele o, eyata èhia mɔ be nàkpɔ wò asaŋuti ƒe code, alo mɔ̃ ƒe ɖoɖoŋlɔla si kpɔe.

Nu siwo nàbu. E nye yeye: repository la dze egɔme le June 2026, npm client la le version 0.1, tagged releases mele haɖe o, eye security audit si wotsɔ ɖe go mele o. Eƒe API me login ƒe mɔ ŋutɔ mele o, eyata lé eƒe dɔwɔwɔ le private network me, eye mègaʋu eƒe mɔ na internet o. Eye abe ɣaɣla fexexe sia fexexe ene la, refund hia be asitsɔla la nana gaɖoƒe ƒe dzesi na wò.

**Ŋkeke mamlɛtɔ si wokpɔ nyateƒe:** 2026-11-01

E nye asikplɔ-dzralá blibo. Fexexewo lia off-chain le Binance Pay gakotokuwo dome, eye èhia Binance account si wokpɔ nyateƒe le ŋu.

### Womagaxɔ ZEC o

Wode wo eve siawo le afisia kpɔ. Wokpɔ provider sia fexexe ŋutɔ ƒe currency list si le dɔ wɔm ƒe nyateƒe le 29 July 2026, eye Zcash bu tso wo evea me.

**CoinPayments** metsɔ ZEC de eƒe v2 coin list, eƒe legacy list, alo eƒe live currencies API me o, eye eƒe Zcash article fifia yia homepage la dzi.

**CoinGate** metsɔ ZEC de eƒe supported currencies page alo eƒe public API me o. Wometsɔ delisting ƒe nyagblɔɖi aɖe ɖe go o, eyata menya ta kple ŋkeke la o.

Ne ɖeka le wo me atsɔ Zcash va gbɔ ake la, tsɔe de eme ake kple verified date yeye.

### Ale si nàlé agbalẽ sia ƒe nyateƒe me

Privacy coin ƒe kpekpeɖeŋu liaa teƒe, eyata agbalẽ sia ƒe nyo le eƒe kpekpeɖeŋu ƒe ŋkeke mamlɛtɔ ko dzi. Ne nèkpɔe:

1. Kpɔ provider la ŋutɔ ƒe currency list alo API. Third-party listwo xɔ megbe na processor eve siwo woɖe le etame.
2. Kpɔ Zcash gaɖoƒe ƒe dzesi ƒomevi siwo wɔa dɔ. "Ekpɔ Zcash" fiaa nuwo ƒe ʋuʋuɖi gaɖoƒe ƒe dzesiwo ko zi geɖe.
3. Trɔ verified date le table la me kple provider ma ƒe section me.
