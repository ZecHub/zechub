## Innovation le Zcash DeFi ŋu 

**Layer 1 Ƒe Ŋuɖoɖo**

Wole mɔwo tom fifia be woana DeFi dɔwɔwɔwo le Zcash ƒe nuƒoƒo me to Layer 1 si le afima xoxo la me. Esia ate ŋu ava eme ne woawɔ contract ƒe dɔwɔwɔwo akpa gãtɔ le ɖoɖonu me o kple sequencer aɖe, eye woawɔ dɔwɔwɔ mawo ƒe ɖaseɖigbalɛ le ɖoɖonu dzi. Wo wɔ esia ƒe version aɖe kple JP Morgan le wɔn enterprise blockchain la ŋu. Tso NU5 me la, mɔ aɖe (TZE) le afima be woatsɔ extension ƒe nɔnɔme sia akpe ɖe Zcash ŋu. 

**zkEVM**

Esia atsɔ programmability dzidzɔ ava Zcash gbɔ kple virtual machine si sɔ kple EVM eye wòɖea asi zero-knowledge ɖaseɖigbalɛ ƒe akɔnta wɔwɔ ŋu. Esia ana Zcash ŋu wòate ŋu akpɔ ŋgɔyiyi to mɔ̃ ƒe ɖoɖoŋlɔla ƒe hat si lolo wu me, eye wòana ɣaɣla ƒe dɔwɔwɔwo kple token ƒe nuƒoƒo nanɔ anyi. Esia atsɔe asɔ kple L2 ɣaɣla ƒe ŋuɖoɖowo siwo le afima xoxo.

Proof-of-Stake ƒe nudzodzro kple Cosmos Interblockchain Communication Protocol ƒe nudzodzro ƒe yiɖeɖe le ECC ƒe asi. Wole afɔɖeɖe siwo gbɔna kpɔm kple Ethereum Merge ƒe dzɔdzɔ le PoS me kple nuxaxa siwo ate ŋu ava eme. 

**ZSA/UDA's**

Zcash Shielded Assets / User Defined Assets ƒe ŋgɔyiyi nɔ edzi kple hat aɖe si ɖo eŋu ƒe kpekpeɖeŋu. Le NU5 protocol ƒe upgrade la megbe la, woɖo teƒe si le vovototo aɖe ko kple wòva eme. Mɔwo si na ɖoɖonu geɖe dome ga ƒe lẽ si me mɔɖeɖe le o kple si le ɣaɣla me na nunɔamesi siawo be woawɔ dɔ ɖekae la le dɔ wɔm fifia. Ƒoɖoɖo aɖe le Zcon3 ƒe presentation sia ŋu le afisia.
