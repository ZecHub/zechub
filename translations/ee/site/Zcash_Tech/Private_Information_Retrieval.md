# Nukaɣaɣla ƒe nyatakakawo didi

## Nyatakakakpa

- Ŋutɔ̃nu ƒe ŋuɖoɖo si le ɣaɣla me, alo PIR, na dɔwɔnu aɖe ate ŋu aƒo nu ɖeka le server ƒe database me, eye server la maganya nu si wobia la o
- Zcash hiã esia elabena gakotoku si le ɣaɣla me mate ŋu abia server be gaɖoɖowo kae nye eƒe tɔwo, ne mele be yeƒe ɣaɣlaɖeɖe nakpɔ o
- Egbe la, gakotokuwo tsɔa data bubu geɖe wu esi wokpɔa, eye wotsɔe doa ŋku edzi, esiae nye gɔmeɖeɖe vevi aɖe si ta syncing le kɔkɔe
- PIR ana gakotoku aƒo eya ŋutɔ ƒe data ko le ɣaɣla me, eye wòasi nu si wòwɔna be nuwo le kɔkɔe, ne ɣaɣlaɖeɖe le dedie
- Esiae nye nyadzɔdzɔ ƒe dɔwɔwɔ si le dɔ dzi na Zcash, eye wòli ŋutɔ le tɔtrɔ me, eye wowɔe be ne gakotoku nyateƒewo ate ŋu azãe
- Nɔnɔme ƒe ɖoɖo si le agbe me le afi sia: [ZecBlock Private](https://private.zecblock.com) nye Zcash ƒe gaɖoɖowo ƒuƒoƒe ƒe explorer si woɖo ɖe PIR ŋu, eye wònye etɔ̃ gbãtɔ (gaɖoɖowo, gaɖoɖowo ƒuƒoƒewo kple gaɖoƒe ƒe dzesiwo)

## Ame kae wòle esia na

- Ame sia ame si bia eɖokui be aleke gakotoku si ɣaɣla la kpɔ eƒe ga siwo nye tɔe, ne wòle nya la ɖe siawo ŋu
- Ame yeyewo siwo le PIR ŋu kpɔm ɖe Zcash nu ƒe dziyiyi ƒe dɔwɔwɔwo gbɔ
- Nusrɔ̃lawo siwo di be yewoadze gɔmeŋlɔ la gbã, eye le cryptography si le egbɔ la megbe
- Ame sia ame si lɔ̃ be yeakpɔ explorer si le PIR dzi wɔwɔ

## Nya siwo PIR ɖea nu le ŋu na Zcash

Zcash ɣaɣla amesi transaction la le na. Ɣaɣla sia wɔa nya vevie: ne network la mate ŋu kpɔ gaɖoɖo siwo nye tɔwò o la, aleke wò ŋutɔ ƒe gakotoku kpɔ wo?

Egbe la, ŋuɖoɖo la bɔbɔe. Gakotoku mate ŋu abia server be gaɖoɖo siwo nye nye tɔe la, elabena biabia sia aɖe nyatakaka si Zcash le edzi wɔm be wòɣaɣla la. Esi wòle esia ta la, gakotoku la ɖea nyatakaka geɖe, eye wòle eƒoƒo nu ɖe sia ɖeka le eŋu be yeakpɔ esiwo nye tɔe. Wòwɔa dɔ, eye wòɣaɣla nyatakaka, gake wòɖea wò ŋkeke. Nyatakaka siawo dzroƒoƒo nye dɔ gã siwo ta gakotoku ƒe sync dzea ŋgɔ bɔbɔe o.

Nu si dze ŋgɔ be wòanɔe nye mɔ si wòana gakotoku be wòabia server eya ŋutɔ ƒe nyatakaka ko, eye wòaxɔ wo, ne server la meganya biabia la ƒe nu o. Esia tututu nye nu si nukaɣaɣla ƒe nyatakakawo didi wɔna.

## PIR nye nu ka

Nukaɣaɣla ƒe nyatakakawo didi nye cryptography ƒe mɔ si na client be wòaxle database ƒe nyatakaka ɖeka, ne wòɖe server la fia nyatakaka si wòxle la o.

Bu library aɖe si me wòaxɔ agbalẽ si wòdi la ŋutɔ, gake agbalẽŋlɔla la manye agbalẽ si wòna la ŋu o. Wòaxɔ wò nu, eye wòdi la anɔ ɣaɣla me. PIR nye nya sia ƒe mathematics ƒe nɔnɔme, si wòtsɔna ɖe database sia database ŋu.

Wole cryptography me numekuku wɔm tso nya sia ŋu ƒe dzesi geɖe. Chor, Goldreich, Kushilevitz, kple Sudan ɖe nya sia fia gbã le 1995 me, eye woɖe server geɖe ƒe mɔ gɔme, eye Kushilevitz kple Ostrovsky wɔ server ɖeka ƒe mɔ gbãtɔ le 1997 me. Menye nu si Zcash wɔ o, ke nye ɣeyiɣi tsitsi ƒe numekuku ƒe dzesi si Zcash le fifia tsɔna ɖe nya vevi si le ŋu dzidzɔm la ŋu.

## Aleke PIR zãa dɔ le gɔmeɖeɖe gbãtɔ me

Mɔ gã eve le siwo wòate ŋu atsɔ awɔ PIR, eye woƒe vovototoa le vevie.

Gbãtɔ zãa server geɖe. Client la ɖoa query ƒe akpa ɖeka na server sia server, eye wòtsɔ woƒe ŋuɖoɖowo ƒoƒu le eya ŋutɔ ƒe device me. Server ɖeka pɛ mate ŋu akpɔ nu si wòhiã be wòanya biabia la o. Mɔ sia wòwɔa dɔ bɔbɔe, gake eɖoa ŋu be serverwo magblẽ nu ɖe wo nɔewo ŋu o, si le sesẽ be woaɖo kpe edzi le xexeame.

Evelia zãa server ɖeka kple cryptography ƒe nyakpɔkpɔ, eye metea nu ɖe ame geɖe ŋu o. Le esia me la, client la ɖoa ŋu ɖe dɔwɔnu tɔxɛ si woyɔna be homomorphic encryption, eye mɔ siae wòle vevie wu na dɔwɔwɔ nyateƒe, elabena mehiã server geɖe siwo magblẽ nu ɖe wo nɔewo ŋu o.

## Aleke wòwɔa dɔ: homomorphic encryption

Homomorphic encryption nye encryption ƒe nɔnɔme si na server be wòatsɔ dɔ awɔ nyatakaka ŋu, eye nyatakaka la anɔ encryption me. Server la wɔa ŋuɖoɖo si le encryption me, si nye ŋuɖoɖo nyateƒe, ne wòkpɔ nu siwo le eme la o.

Fiaɖoɖo si le server ɖeka ƒe PIR si wòwɔ le mɔ sia dzi la le alea. Client la di item namba etɔ̃ le lisi me. Wòwɔa query si, le eme la, nye encrypted "ee" na teƒe etɔ̃, kple encrypted "ao" na teƒe bubu ɖesiaɖe. Le server la ŋkume la, query sia nye dzodzro si me nyateƒe mele o; mate ŋu akpɔ teƒe si "ee" le o.

Esi megbe la, server la tsɔ database kple query si le encryption me la ƒoa ƒu zã homomorphic encryption ƒe nɔnɔme tɔxɛwo, eye wòwɔ item siwo wòɖo ɖe eme la ɖekaɖeka kple encrypted "ee" alo "ao" si sɔ la, eye wòtsɔ ŋuɖoɖowo ƒoƒu. Nu si wòtsɔna ɖo le eme nye encrypted package ɖeka si me item si client la di la pɛ le, eye nu aɖeke meɖea fia item si wònye la o. Client la ɖea package sia ƒe encryption, eye wòxlẽ eƒe item. Server la ɖo biabia la ŋu, ne wònya biabia la o.

Nɔnɔme si sesẽ wu la, si woyɔna be symmetric PIR, tsɔ kpeɖeŋu evea ɖe eme: Client la xɔa item si wòbia la ko, eye menya nu aɖeke tso database ƒe nyatakaka bubuwo ŋu o. Esia ɣaɣla database la hã, eye wòɣaɣla client la hã.

## Nya dɔdzɔwo la, na nusrɔ̃lawo siwo le mɔ̃ nyanyawo ŋu

Nɔnɔme yeyewo si zãa server ɖeka la ɖo ɖe lattice cryptography dzi, eye zi geɖe la yewotsɔa learning with errors assumption. Client la ƒe query nye ciphertexts ƒe vector, si nye encryption si wòɖoa ɖeka ɖe target index la, eye wòɖoa zero le teƒe bubuwo katã, eye encryption la zãa additive homomorphism, ale server la ate ŋu atsɔ ciphertexts ƒoƒu, eye wòatsɔ wo akplɔ database ƒe plaintext items, ne wòɖe encryption me o.

Server la bu database la be matrix, wòtsɔa encrypted selection vector la zãa, eye wòɖoa ciphertext ɖeka si wòɖea eƒe encryption la le row si wòdi la me. Esi query la to vovototo aɖeke me ko abe dzodzro si tso random me ene la ta, server la xɔa nyatakaka aɖeke tso index la ŋu o.

Nya vevi si le eŋu la nye asiƒe ƒe kuxi. Le mɔ si me ŋuɖoɖo kple lɔlɔ̃ me mele o la, server la ate ŋu atsɔ database ƒe nu sia nu awɔ dɔ le eŋu na query ɖesiaɖe, si le dɔwɔwɔ me vevie, eye ciphertexts la lolo, si le data ƒe ɖoɖo me vevie. Numekuku yeyewo le esia ŋu wɔm dɔ kple preprocessing; mɔnu siwo le abe SimplePIR kple FrodoPIR ene na server la be wòatsɔ database la adzra ɖo xoxo, eye wòana client ɖesiaɖe hint sue aɖe, si tsɔa dɔ geɖe ɖo offline phase me, ale be live queries la na wòwɔ dɔ bɔbɔe. Kpekpeɖeŋu si le vi vevie me nye be woɖoa nɔnɔme siwo zãa lattice hã abe siwo ate ŋu atsɔ akpɔ quantum attackwo ŋu ene, si sɔ kple Zcash ƒe mɔ si wòle dzi wɔm kple post-quantum ɣaɣla.

## PIR le Zcash

PIR nye dɔwɔwɔ si le mɔ si wòle dzɔm be wòana Zcash anɔ ɣaɣla me, eye wòawɔ dɔ bɔbɔe le dzi ƒe dziyiyi me.

Gakotoku ƒe nyatakaka dzroƒoƒo ƒe kuxi si wogblɔ xoxo lae nye nu si wole ŋu wɔm. Dɔ si wole wɔm le Valar Group me le nukaɣaɣla ƒe nyatakakawo didi ƒe mɔnuwo wɔm, ale be gakotoku ate ŋu axɔ eƒe nyatakaka le server aɖe si gbɔ, ne server la menya entries si wobia la o. Dɔwɔwɔ ɖeka si wòate ŋu awɔ nye gaɣaɣla ɖeɖe dzesiwo kpɔkpɔ le ɣaɣla me. Gaɣaɣla ɖeɖe dzesi nye dzesi ɖeka si woyɔna le ɖoɖo me ne didienu aɖe sã, si ɖea nu si wòate ŋu asã nudzɔdzɔ siawo ŋu eve o. Gakotoku la hiã be wòakpɔ ne gaɣaɣla ɖeɖe dzesi aɖe ɖo ha, si gɔme nye be didienu la le sã me hafi, eye egbe wòawɔ esia le server me la, wòate ŋu aɖe fia didienu si wobia la. Nukaɣaɣla ƒe nyatakakawo didi na gakotoku be wòabia biabia sia ne wòɖe gaɣaɣla ɖeɖe dzesi si wòle ŋu kpɔm la fia o. Esia nye dɔwɔwɔ si le nu ƒe dziyiyi ƒe dɔ bubuwo gbɔ, Project Tachyon kple ɣaɣla dzesi ŋɔŋlɔ ƒe software yeyeawo hã le eme, siwo le didi me be woaɖe dɔwɔwɔ ƒe lɔlɔ̃ siwo le gakotoku siwo ɣaɣla la ƒe ŋgɔe la ɖa.

Ele vevie be woagblɔ nu nyateƒe tso dɔwɔwɔ ƒe nɔnɔme ŋu. Esia nye numekuku kple engineering si le edzi, menye feature si wowɔ eye wòle zã ge o. Nya la ƒe gɔmeŋlɔ si nyo la le tsitsi, eye mɔ si dzi wole yiyi la kpe ɖe asi, gake PIR ƒe dɔwɔwɔ bɔbɔe ale be wòaxɔ mɔ na gakotoku siwo zãa dɔwɔwɔ nyateƒe le device siwo sɔ kple dziɖuɖu me lae nye nya sesẽ si wole edzi wɔm fifia.

## Dɔwɔwɔ nyateƒe: ZecBlock Private

Le 2026 ƒe November me, ZecBlock ɖe **ZecBlock Private** (private.zecblock.com) ɖe dzesi, si nye eƒe explorer ƒe nɔnɔme aɖe si zãa nukaɣaɣla ƒe nyatakakawo didi na gaɖoɖo, gaɖoɖowo ƒuƒoƒewo, kple gaɖoƒe ƒe dzesiwo didi.

Esia nye ŋgɔgbe blɔk si me katã Zcash ƒe blɔk ƒe nyatakakadzraɖoƒe (si kpɔa gaɖoɖowo, gaɖoɖowo ƒuƒoƒewo kple gaɖoƒe ƒe dzesiwo) si wotu ɖe PIR dzi. PIR nyatakakadzraɖoƒe ƒe demo siwo do ŋgɔ la, woɖe asi le biabia suewo ko gbɔ, abe gaɖoƒe ƒe dzesiwo ƒe gaƒomewo ene.

### Aleke gaɖoƒe ƒe dzesiwo kpɔkpɔ le ɣaɣla me

- Wole query la (gaɖoɖo ID, gaɖoɖowo ƒuƒoƒe ƒe dzi/ hash, alo gaɖoƒe ƒe dzesi) ɣaɣla blibo le browser la me hafi wòɖo ɖe mɔ dzi.
- Server la wɔa dɔ le dataset si wogblɔ ɖe public ŋu blibo, ne wòmenya record si wobia la o.
- Server la ɖoa encrypted response ɖeka, si browser la ɖeka pɛ ate ŋu aɖe encryption me.
- Nya aɖe si le browser la me, ne wòwɔe, to vovototo aɖeke me o kple nya si menɔ browser la me o (request ƒe ɖoɖo kple nɔnɔme sɔ).

Search ɖesiaɖe megbe la, site la ɖea summary sue aɖe fia tso nu siwo wòɖo ɖe mɔ dzi la ŋu pɛ, si na be ɣaɣla ƒe nɔnɔme la bɔbɔe be woakpɔ.

### Aleke woaɖo eƒe nyateƒe ŋu

Woɖoa data publication ɖesiaɖe ƒe asidede agbalẽ te. Browser la kpɔa asidede agbalẽ te la le ŋuɖoɖo ɖesiaɖe me hafi wòɖea eŋu, ale be server si dzro alo si wɔ gbegblẽ la mate ŋu atsɔ data bubu ɖo teƒe la o.

### Data ƒe yeyewɔwɔ

Wole gaɖoɖowo ƒuƒoƒe yeyewo ɖem ɣeyiɣi suewo ɖesiaɖe. Data si le explorer si ɣaɣla la me la zi geɖe nɔa ɣeyiɣi bubu 20 seconds ƒe gɔme le ZecBlock explorer si zãna ɖe mɔ nɔnɔme me ŋgɔ.

### Bandwidth ƒe asixɔxɔ

PIR xɔ asi wu lookup nɔkeke, elabena server la wòhiã be wòawɔ dɔ le dataset blibo la ŋu:

- Gaɖoɖo lookup: upload si le 1.2 MB ŋutɔ
- Gaɖoƒe ƒe dzesi lookup: upload si le 0.4 MB ŋutɔ

Esia nye asixɔxɔ si server la nɔa la, be wòaganya query la ŋu o.

### Client ƒe wɔwɔ

Browser ƒe client nye Rust → WebAssembly wrapper (le fifia la le ZecBlock repository me, si le `prototype/pir-browser` te). Woɖo eŋu ɖe open-source PIR libraries si tso Valar Group ŋu. Wrapper la meɖe dzesi abe npm package si le eya ŋutɔ ƒe teƒe o haɖe, gake wole esia ɖo ɖe ŋgɔ.

### Vovototo le gakotoku PIR kple esia dome

ZecBlock Private ɖea PIR fia na gaɖoɖonu data si le public (be wòadidi gaɖoɖo, gaɖoɖowo ƒuƒoƒe, alo gaɖoƒe ƒe dzesi si wònya la ne wòɖe esi wònye la fia o). Meɖea gakotoku ƒe kuxi sesẽ wu la ɖa o, si nye be woadi didienu siwo nye nukpɔsafui aɖe tɔe le ɣaɣla me alo wòakpɔ gaɣaɣla ɖeɖe dzesiwo le ɣaɣla me na didienu siwo mese o. Woƒe numekuku le edzi fifia.

## Nya siwo ame geɖe bu vɔ̃

- PIR ɣaɣla item si wòbia la, menye be wòɣaɣla be wòɖo mɔ kple server la o; network-level metadata nye nya bubu
- PIR nye dɔwɔnu si Zcash ɖeka ko zãa o; enye cryptography ƒe dɔwɔnu si Zcash zãa na gakotoku ƒe ɣaɣla
- Sync si wòawɔ bɔbɔe le PIR ta nye dzidzɔ si wole dzi wɔm, menye feature si le gakotokuwo me fifia o
- Data katã ƒe download kple dzro le local me, si nye mɔ si wozãna fifia, ɣaɣla, gake wòɖea ŋkeke; PIR le dzɔdzɔm be wòalĩ ɣaɣla la eye wòatsɔ ŋkeke la ɖa
