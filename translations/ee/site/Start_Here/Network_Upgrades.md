# Zcash Mɔ̃ ƒe sewo trɔtrɔ

Zcash Ŋgɔyiyi le mɔ̃ ƒe sewo trɔtrɔ me: trɔtrɔ siwo míewɔ ɖekae le se siwo ɣaɣla dzesi ŋɔŋlɔ ɖe sia ɖe lɔ̃ la me, eye trɔtrɔ ɖesiaɖe dzea egɔme le gaɖoɖowo ƒuƒoƒe ƒe ɖoɖoɖe si woti ŋu. Trɔtrɔ ɖesiaɖe si le afisia la ŋu nyagblɔɖi ƒe axa bɔbɔe, si gblɔ nu si wòtrɔ kple taɖodzinu. Ɖe wò nye Zcash yeye? Xlẽ wo le ɖoɖo nu, tso Sprout va se ɖe Ironwood.

Ne èdi nuŋlɔɖi si wɔa nɔnɔme na ale si Zcash ƒe ɣaɣla trɔ le trɔtrɔ siawo me la, kpɔ [ɣaɣla ƒe ƒoƒo](https://zechub.wiki/zcash-evolution). Axa sia nye ŋɔŋlɔɖoƒe si wɔa nu ƒuƒu. Esi akpae la nye ɣeyiɣi ƒe ɖoɖo.

### NU7 ƒe nɔnɔme

NU7 dze egɔme le Mainnet le kɔkɔɖe **3,543,405** ([ZIP 259](https://zips.z.cash/zip-0259)) dzi le **6 November 2026** ŋkeke (02:34 UTC; le November 5 ƒe fiẽ me le USA ƒe ɣeyiɣi ƒuƒoƒeawo me). Esi la dze egɔme le dutoƒe Testnet kpɔ, le kɔkɔɖe **4,465,026** dzi (4 October 2026).

Nu siwo de eme (ZIP 259):

- **Gaɖoɖowo ƒuƒoƒe le sekend 25 me** (ZIP 218) — Ŋkɔɖoɖe gbãtɔ vaa kaba zi ~3; ɣleti ɖeka me ZEC ƒe nuwɔwɔ mele trɔm o.
- **Mɔ̃ ƒe ŋusẽ dzraɖoɖo Ɖoɖo** (ZIP 235 + ZIP 237) — Gaɖoɖo adzɔ ƒe 60% ɖea le gaƒoƒo me, tsɔe dea dzraɖoƒe, eye woɖea gɔme na nukulawo le fetu ƒe afãmama ɖoɖo si wòna wòanɔ edzi dzi, si dzea egɔme le February 2031 ɣeyiɣi me.
- **Sprout ƒe ɖeɖe** (ZIP 2003) — Gaɖoɖowo version 4 gbɔna wòazu nu si meɖe o; Sprout ƒe ga si susɔ la mewɔa dɔ o.
- Gaɖoɖowo ɣaɣla ƒe dɔwɔwɔ ƒe sewo kple kɔkɔɖe ƒe xexlẽ ƒe ɖoɖo kɔkɔ ŋu (gaɖoɖowo ƒuƒoƒe 17 → 102).

Gaɖoɖo ƒe nɔnɔme yeye mele wɔm o. Gbɔgbɔbubu gbegbɔgblɔ ɖi ƒe ID: `0x77190ad9`.
