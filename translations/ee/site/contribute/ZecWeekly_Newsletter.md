# ZecWeekly Nyadzɔdzɔgbalẽ [Newsletter]

ZecWeekly nye nyadzɔdzɔgbalẽ si doa go every Sunday morning. Eme la, nyadzɔdzɔ siawo katã siwo dzɔ le kwasiɖa me le Zcash ecosystem la me. Hameviwo tia nyadzɔdzɔawo ɖe kwasiɖa sia kwasiɖa, eye wodzea kadodo siwo ƒo akpa le eme. Meɖe kuku be nàŋlɔ ŋkɔ ɖe nyadzɔdzɔgbalẽ la ŋu le [afisia](https://zechub.substack.com/).

## Kpe ɖe eŋu

Nyadzɔdzɔgbalẽ ƒe kpekpeɖeŋu wɔa dɔ nyuie ne ame ɖeka si ƒoa nu kpɔa ta la naŋlɔ tɔxɛ na kwasiɖa si dze o, wòto fiafi ƒe bounty alo hadede ƒe nuteƒe me, eye wòɖo pull request la ɖe asi le kwasiɖa me ƒe kadodowo vɔ megbe. Mègana edition si gbɔna o hafi ZecHub naɖo alo akaka ɣeyiɣi na edition ma. Pull request siwo va do ŋgɔ zi geɖe medzia nyadzɔdzɔ siwo va le kwasiɖa ƒe nuwuwu o, wotsɔa ɖe curator si woɖo xɔ se kplii o, alo wowɔa deadline si medze o.

### 1. Kaka edition si le fifia

Hafi nàdze ŋɔŋlɔ gɔme:

- Kpɔ [ZEC Bounties](https://bounties.zechub.wiki/) be nàkpɔ nyadzɔdzɔgbalẽ ƒe dɔ si le fifia.
- Lala be woɖo wò.
- Nyadzɔdzɔgbalẽ ƒe editionwo le XS band me le [bounty amounts policy](https://bounties.zechub.wiki/docs/bounty-amounts) me. ZEC ƒe nɔmba si le bounty si le agbe la ŋu nye esi woana, menye tanya kpa aɖeke si xoxo le contributing guides me o.

### 2. Wɔ repository fork

Ne èye yeye le GitHub la, zã mɔ sia:

1. Ʋu [ZecHub repository](https://github.com/ZecHub/zechub) la.
2. Zi **Fork** eye nàwɔ fork le wò GitHub account te.
3. Le wò fork me la, wɔ branch yeye na edition la. Branch ƒe ŋkɔ si ƒe gɔmesese le nyuie, abe `digest-may-30-2026` ene.
4. Kpɔ be wò pull request adze `ZecHub/zechub` dzi abe base repository ene, eye `main` abe base branch ene.

Ne èzã command line la, mɔ ma kee nɔ ale:

```bash
git clone https://github.com/YOUR-USERNAME/zechub.git
cd zechub
git checkout -b digest-month-day-year
```

Tsɔ wò ŋutɔ ƒe GitHub username ɖe `YOUR-USERNAME` te. URL si le etame la nye placeholder eye wòmawɔ dɔ abe woŋlɔe ene o.

### 3. Wɔ nyadzɔdzɔgbalẽ ƒe faɛl

Zã [nyadzɔdzɔgbalẽ ƒe template](https://github.com/ZecHub/zechub/blob/main/newsletter/newslettertemplate.md) abe wò gɔmedzedze ene. Nyadzɔdzɔgbalẽ ƒe editionwo le [`newsletter`](https://github.com/ZecHub/zechub/tree/main/newsletter) folder la me.

Ne èle faɛl la wɔm:

- Wɔ faɛl ƒe ŋkɔ ɖe format si issue la bia alo si edition siwo woaccept va yi zã la nu.
- Lée sectionwo ƒe ɖoɖo ma ke abe template la ene, negbe dɔ la bia format bubu.
- Tsɔ kadodowo tso kwasiɖa si dze o ko.
- Ŋlɔ nyatakaka kpui aɖe si meɖe kuku, na kadodo ɖesiaɖe be xexlẽlawo naɖe asi le nu si ta wòle vevie la ŋu.
- Trɔ alo wɔ nyatakaka kpui tso nuŋɔŋlɔ siwo menye Yevugbe o ŋu ɖe English me ne wòhiã.
- Ɖo kadodo ɖesiaɖe kpɔ hafi nàʋu pull request la.

### 4. Ɖu kadodowo le ɣeyiɣi si dze o

ZecWeekly ƒoa nu tso Zcash ecosystem ƒe dɔwɔwɔ le kwasiɖa si le fifia me, eye wodzea eŋu le kwasiɖa la ƒe nuwuwu ɖe te. Ɣeyiɣi si nyo wu la nye:

- Dze kadodo ƒuƒu gɔme le nyadzɔdzɔgbalẽ ƒe issue alo dɔ si le fifia la va do go megbe.
- Lée draft aɖe esi kwasiɖa la gale dzi.
- Ɖo pull request la ɖe asi ɖe ŋkeke si woɖe sia me be nàɖo asi le eŋu me, le esi nèkpɔ nyadzɔdzɔ siwo va le kwasiɖa ƒe nuwuwu la megbe.
- Mègana nyadzɔdzɔgbalẽ na kwasiɖa si gbɔna o hafi dɔ la na date ma va le, alo hafi ZecHub naɖe fia be ele be nàdzra eƒe ŋudɔ.

Ne issue aɖe gblɔ be nàɖo eɖe asi ɖe ŋkeke aɖe dzi la, wɔ ɖe ŋkeke ma nu. Ne vɔvɔ le axa sia kple issue si le fifia dome la, to issue si le fifia la nu.

### 5. Ʋu pull request la

Ne wò nyadzɔdzɔgbalẽ ƒe faɛl dzudzɔ:

1. Commit wò tɔtrɔwo ɖe wò fork me.
2. Ʋu pull request ɖe `ZecHub/zechub` me le `main` branch la ŋu.
3. Zã tanya si sɔ kple edition la, abe `Zcash Ecosystem Digest | May 30th` ene.
4. Tsɔ issue la ƒe kadodo ɖe pull request ƒe body me be reviewerwo naŋu dɔ la kple task la.

Pull request body ƒe kpɔɖeŋu:

```md
Closes #ISSUE_NUMBER

Summary:
- Adds the Zcash Ecosystem Digest for Month Day.
- Uses the newsletter template and the current issue deadline.
- Checks links and descriptions for the requested week.
```

Le pull request la ƒe ʋuʋu megbe la, léa ŋku ɖe review ƒe commentwo ŋu. Ne ZecHub bia tɔtrɔwo la, trɔe le branch ma kee me ɖe teƒe be nàʋu pull request evelia na edition ma.

### Vodadawo siwo mele be nàwɔ o

- Ʋu pull request hafi woakaka edition ƒe date alo dɔ la.
- Wɔ dɔ ɖe issue si xɔ pull request ƒe kadodo le xoxo la ŋu.
- Ɖo pull request la ɖe wò ŋutɔ ƒe fork me ɖe teƒe be nàɖoe ɖe `ZecHub/zechub` me.
- Zã faɛl ŋkɔ si mede o alo nàtsɔ faɛl la ade folder `newsletter` la ƒe gota.
- Kopi edition xoxo aɖe eye mènɔ date, kadodo, kple nyatakaka ɖesiaɖe trɔ o.
- Tsɔ kadodowo tso kwasiɖa si mede o.
- Ɖe kadodo siwo gbã, kadodo siwo woɖe wòle eve, alo placeholder ƒe nyagbalẽ tso template la me.
- Ʋu pull request yeye le review ƒe commentwo megbe ɖe teƒe be nàtrɔ original branch la.

### Nudzɔdzɔ ƒe xexlẽnu

Hafi nàbia review, kaka be:

- Issue alo task ƒe date sɔ kple wò nyadzɔdzɔgbalẽ ƒe faɛl.
- Pull request bubu aɖeke si gale ʋuʋum mele issue alo edition ma ŋu o.
- Faɛl la le `newsletter` folder la me.
- Template ƒe sectionwo katã complete.
- Kadodo ɖesiaɖe wɔa dɔ eye exɔ nyatakaka si na viɖe.
- Pull request ƒe body ƒe kadodo ɖe issue si dze o ŋu.
- Ète ŋu awɔ tɔtrɔwo ne reviewerwo bia be woawɔ tɔtrɔ.
