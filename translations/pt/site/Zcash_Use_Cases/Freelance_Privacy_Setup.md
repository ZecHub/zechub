## Resumo

- Receba pagamentos por meio de endereços blindados
- Separe identidades por cliente (se necessário)
- Use memorandos para controle interno
- Mantenha sua renda privada


<br/>

## <img src="/content-images/user-svgrepo-com-21adf62b7c.svg" width="24" height="24" className="inline-block align-middle mr-1 p-[2px]" alt="user icon"/> Para quem é este guia?

- Freelancers e prestadores de serviço
- Profissionais remotos pagos em cripto
- Profissionais preocupados com a privacidade

<br/>

## <img src="/content-images/warning-error-svgrepo-com-b7ea8a50da.svg" width="24" height="24" className="inline-block align-middle mr-1 p-[2px]" alt="warning icon"/> O problema

Freelancers que usam criptomoedas públicas expõem:
- Sua renda
- Seus clientes
- Seu histórico financeiro

Isso pode levar a:
- Perda de poder de negociação
- Riscos à privacidade
- Visibilidade indesejada
  

<br/>

## <img src="/content-images/icons8-lock-2f8e221321.svg" width="24" height="24" className="inline-block align-middle mr-1 p-[2px]" alt="toolbox icon"/> Por que Zcash?

O Zcash permite que você:
- Receba pagamentos de forma privada
- Oculte seus ganhos
- Proteja o relacionamento com seus clientes

<br/>

## <img src="/content-images/icons8-toolbox-9bebbb1619.svg" width="24" height="24" className="inline-block align-middle mr-1 p-[2px]" alt="toolbox icon"/> O que você precisa

- Uma carteira Zcash com suporte a memorandos
- Noções básicas sobre endereços blindados


<br/>

## <img src="/content-images/ladder-svgrepo-com-7232bf46ed.svg" width="24" height="24" className="inline-block align-middle mr-1 p-[2px]" alt="step icon"/> Guia passo a passo

### Passo 1: Crie um endereço para pagamentos

Gere um endereço blindado (z).

Opcionalmente:
- Use endereços diferentes para clientes diferentes


### Passo 2: Compartilhe o endereço com o cliente

Envie seu endereço z diretamente ao seu cliente.

Evite:
- Publicá-lo abertamente se não for necessário

### Passo 3: Use memorandos para controle

Ao receber pagamentos:
- Peça aos clientes que incluam um memorando (por exemplo, o número da fatura)

Isso ajuda você a:
- Controlar os pagamentos sem expor dados publicamente


### Passo 4: Mantenha as identidades separadas

Se necessário:
- Use carteiras ou endereços separados para cada cliente
- Evite vincular identidades entre si

<br/>

## <img src="/content-images/icons8-cancel-7f786be3c1.svg" width="24" height="24" className="inline-block align-middle mr-1 p-[2px]" alt="cancel icon"/> Erros comuns a evitar

- Usar endereços transparentes para pagamentos  
- Reutilizar o mesmo endereço para todos os clientes  
- Vincular publicamente a carteira à sua identidade  
- Não controlar os pagamentos (o que gera confusão)
