## TL;DR

- Use endereços blindados para todas as transações
- Nunca exponha publicamente a identidade da sua carteira
- Proteja suas fontes evitando pagamentos rastreáveis
- Use memorandos com cuidado para uma comunicação segura

## <img src="/content-images/warning-error-svgrepo-com-b7ea8a50da.svg" width="24" height="24" className="inline-block align-middle mr-1 p-[2px]" alt="warning icon"/> O problema

Jornalistas enfrentam:
- Vigilância
- Riscos de exposição das fontes
- Rastreamento financeiro por adversários

Usar criptomoedas transparentes pode revelar:
- Quem pagou você
- Para quem você pagou
- Quando e quanto

## <img src="/content-images/ladder-svgrepo-com-7232bf46ed.svg" width="24" height="24" className="inline-block align-middle mr-1 p-[2px]" alt="step icon"/> Guia passo a passo


### Passo 1: Crie uma carteira dedicada

- Use uma carteira apenas para trabalhos sensíveis
- Não misture com transações pessoais

### Passo 2: Use apenas endereços blindados

- Sempre faça transações usando endereços z
- Evite completamente transações transparentes


### Passo 3: Proteja os pagamentos às fontes

Se você for pagar fontes:
- Use transações blindadas (z → z)
- Evite padrões de horário previsíveis
- Não reutilize endereços


### Passo 4: Tenha cuidado com os memorandos

- NÃO inclua informações sensíveis nos memorandos
- Use referências neutras ou codificadas, se necessário


### Passo 5: Mantenha a segurança operacional

- Evite vincular a carteira à sua identidade
- Não confirme transações publicamente
- Use canais separados para a comunicação


<br/>

## <img src="/content-images/icons8-cancel-7f786be3c1.svg" width="24" height="24" className="inline-block align-middle mr-1 p-[2px]" alt="cancel icon"/> Erros comuns a evitar

- Usar endereços transparentes  
- Reutilizar endereços entre diferentes fontes  
- Incluir dados sensíveis nos memorandos  
- Vincular a carteira à sua identidade pública
