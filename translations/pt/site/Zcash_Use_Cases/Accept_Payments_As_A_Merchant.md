## <img src="/content-images/warning-error-svgrepo-com-b7ea8a50da.svg" width="24" height="24" className="inline-block align-middle mr-1 p-[2px]" alt="warning icon"/> O problema

Os pagamentos tradicionais em cripto expõem:
- O comportamento de compra dos clientes
- A receita do comerciante
- O histórico de transações

Isso leva a:
- Perda de privacidade dos clientes
- Vazamento de informações estratégicas para concorrentes
- Uma transparência financeira que você talvez não queira

<br/>

## <img src="/content-images/icons8-lock-2f8e221321.svg" width="24" height="24" className="inline-block align-middle mr-1 p-[2px]" alt="toolbox icon"/> Por que Zcash?

Zcash permite:
- Pagamentos privados dos clientes
- Acompanhamento confidencial da receita
- Proteção da atividade do negócio


<br/>

## <img src="/content-images/icons8-toolbox-9bebbb1619.svg" width="24" height="24" className="inline-block align-middle mr-1 p-[2px]" alt="toolbox icon"/> O que você precisa

- Uma carteira Zcash que suporte transações blindadas
- Um fluxo de pagamento simples (manual ou integrado)
- Opcional: um sistema de acompanhamento de pedidos


<br/>

## <img src="/content-images/ladder-svgrepo-com-7232bf46ed.svg" width="24" height="24" className="inline-block align-middle mr-1 p-[2px]" alt="step icon"/> Guia passo a passo

### Passo 1: Configure um endereço de pagamento

- Gere um endereço blindado (z)
- Use-o para receber pagamentos


### Passo 2: Exiba as instruções de pagamento

Para cada transação:
- Mostre seu endereço z
- Informe o valor do pagamento
- Opcionalmente, inclua uma referência no memorando

### Passo 3: Acompanhe os pedidos

Use:
- Memorandos (por exemplo, o ID do pedido)
- Ou acompanhamento off-chain (banco de dados, planilha)


Exemplo:
- Pedido nº 4821


### Passo 4: Confirme o pagamento

- Monitore as transações blindadas recebidas
- Associe o memorando ou o valor ao pedido


### Passo 5: Mantenha boas práticas de privacidade

- Evite reutilizar endereços publicamente, se possível
- Não exponha o histórico de transações
- Use carteiras separadas para diferentes unidades de negócio, se necessário


<br/>

## <img src="/content-images/icons8-cancel-7f786be3c1.svg" width="24" height="24" className="inline-block align-middle mr-1 p-[2px]" alt="cancel icon"/> Erros comuns a evitar

- Usar endereços transparentes para pagamentos  
- Publicar provas de transações publicamente  
- Vincular a identidade dos clientes a dados da blockchain  
- Não acompanhar os pagamentos adequadamente
