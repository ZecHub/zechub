## Resumo

- Use endereços blindados para guardar fundos compartilhados
- Limite a visibilidade de saldos e transações
- Separe as funções operacionais da identidade pública
- Use memorandos para a prestação de contas interna

## <img src="/content-images/warning-error-svgrepo-com-b7ea8a50da.svg" width="24" height="24" className="inline-block align-middle mr-1 p-[2px]" alt="warning icon"/> O problema

Fundos comunitários em blockchains públicas expõem:
- O saldo total do tesouro
- O histórico de gastos
- As identidades dos colaboradores

Isso gera riscos:
- Os fundos se tornam alvo
- Conflitos internos causados pela pressão da transparência
- Perda de privacidade estratégica

<br/>

## <img src="/content-images/icons8-lock-2f8e221321.svg" width="24" height="24" className="inline-block align-middle mr-1 p-[2px]" alt="toolbox icon"/> Por que Zcash?

O Zcash permite que as comunidades:
- Guardem fundos de forma privada
- Executem transações sem expor detalhes
- Mantenham a prestação de contas interna sem exposição pública

<br/>

## <img src="/content-images/icons8-toolbox-9bebbb1619.svg" width="24" height="24" className="inline-block align-middle mr-1 p-[2px]" alt="toolbox icon"/> O que você precisa

- Uma carteira Zcash (ou várias carteiras para separar as funções)
- Processos internos claros para gerenciar os fundos
- Opcional: documentação compartilhada para acompanhamento

<br/>

## <img src="/content-images/ladder-svgrepo-com-7232bf46ed.svg" width="24" height="24" className="inline-block align-middle mr-1 p-[2px]" alt="step icon"/> Guia passo a passo

### Passo 1: Crie um endereço blindado para o tesouro

- Gere um **z-address** para o tesouro
- Ele se torna a conta principal onde os fundos ficam guardados


### Passo 2: Defina as funções

Separe as responsabilidades:
- Tesoureiro (controla os fundos)
- Colaboradores (solicitam gastos)
- Revisores (aprovam internamente)

Evite vincular essas funções a identidades públicas.



### Passo 3: Receba fundos de forma privada

- Aceite contribuições pelo endereço blindado
- Incentive os colaboradores a enviar a partir de carteiras blindadas



### Passo 4: Acompanhe as transações internamente

Use:
- Memorandos da carteira
- Registros off-chain (por exemplo, documentos compartilhados)

Exemplo de memorando: 
 - Subsídio nº 12 - Pagamento ao desenvolvedor



### Passo 5: Execute pagamentos de forma privada

- Envie fundos por meio de transações blindadas (z → z)
- Evite expor publicamente a identidade dos destinatários

<br/>

## <img src="/content-images/icons8-cancel-7f786be3c1.svg" width="24" height="24" className="inline-block align-middle mr-1 p-[2px]" alt="cancel icon"/> Erros comuns a evitar

- Usar endereços transparentes para o tesouro  
- Publicar os saldos da carteira  
- Não acompanhar as transações internamente  
- Vincular o endereço do tesouro a pessoas identificáveis
