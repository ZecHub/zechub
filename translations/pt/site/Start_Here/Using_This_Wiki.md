# Usando esta wiki

Parte disso pode parecer demais. Nós entendemos! Há muita informação aqui. Este é um guia simples, passo a passo, que mostra como você deve navegar pela wiki.

## Novo no Zcash

Se você é novo no Zcash, este é um ótimo lugar para se atualizar. A primeira coisa que você deve fazer é conferir estas páginas:

[Zcash Guia do novo usuário](https://zechub.wiki/start-here/new-user-guide#content)

[Zcash Recursos](https://zechub.wiki/start-here/zcash-resources#content)

[Zcash Noções básicas](https://zechub.wiki/start-here/what-is-zec-and-zcash#content)

## Pronto para usar o Zcash

Depois de ler os documentos introdutórios e os recursos associados a eles, confira os vídeos [Usando o ZEC](https://zechub.wiki/guides/using-zec-privately#content) e [Tutoriais](https://youtube.com/playlist?list=PL6_epn0lASLFF28ePj7P5TvtMG_WE7p3O&si=4vleWUbCGbNJu1-M) para aprender a usar o ZEC.

## Sou membro da comunidade Zcash

Se você é membro da comunidade, incrível! A melhor coisa que você pode fazer para se manter atualizado é acompanhar a newsletter semanal [Zcash Ecosystem Digest](https://zechub.substack.com/s/zcash-ecosystem-digest) e seguir todas as contas da [Lista de páginas da comunidade Zcash](https://zechub.wiki/zcash-community/community-links#content).

## Quero contribuir com o ZecHub

Ótimo! Leia [O que é o ZecHub](https://zechub.wiki/start-here/what-is-zechub#content) e depois veja [Ajude a construir o ZecHub](https://zechub.wiki/contribute/help-build-zechub) para saber como contribuir.
