# Como usar esta wiki

Algumas dessas informações podem parecer avassaladoras. Entendemos! Há muita informação aqui. Veja abaixo um guia simples, passo a passo, que mostra como navegar pela wiki.

## Novo no Zcash

Se você está começando no Zcash, este é um ótimo lugar para se familiarizar com o assunto. A primeira coisa a fazer é conferir estas páginas:

[Guia para novos usuários do Zcash](https://zechub.wiki/start-here/new-user-guide#content)

[Recursos do Zcash](https://zechub.wiki/start-here/zcash-resources#content)

[Fundamentos do Zcash](https://zechub.wiki/start-here/what-is-zec-and-zcash#content)

## Pronto para usar o Zcash

Depois de ler os textos introdutórios e os materiais indicados neles, confira [Usar ZEC](https://zechub.wiki/guides/using-zec-privately#content) e os vídeos de [Tutoriais](https://youtube.com/playlist?list=PL6_epn0lASLFF28ePj7P5TvtMG_WE7p3O&si=4vleWUbCGbNJu1-M) para aprender a usar o ZEC.

## Sou membro da comunidade do Zcash

Se você já faz parte da comunidade, que ótimo! A melhor forma de ficar por dentro das novidades é acompanhar a newsletter semanal [Zcash Ecosystem Digest](https://zechub.substack.com/s/zcash-ecosystem-digest) e seguir todas as contas da [Lista de páginas da comunidade do Zcash](https://zechub.wiki/zcash-community/community-links#content).

## Quero contribuir com o ZecHub

Ótimo! Leia [O que é o ZecHub](https://zechub.wiki/start-here/what-is-zechub#content) e depois veja [Ajude a construir o ZecHub](https://zechub.wiki/contribute/help-build-zechub) para saber como contribuir.
