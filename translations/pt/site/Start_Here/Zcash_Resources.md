# Recursos do Zcash

Existem vários recursos que ajudam os usuários a compreender o Zcash.

**[Zcash Media](https://www.youtube.com/c/ZcashMedia)**

Zcash Media é uma organização independente que produz documentários educativos sobre o Zcash. Seu primeiro vídeo, "Built to Fix Bitcoin's Fatal Flaw, What is Zcash (ZEC)?", é uma excelente introdução ao Zcash.

**[X (anteriormente Twitter)](https://x.com)**

O Twitter é o principal centro de comunicação da comunidade Zcash e também do ecossistema mais amplo de criptomoedas. É um excelente lugar para acompanhar tudo o que acontece no Zcash e seguir membros proeminentes da comunidade. Aqui está um [documento](https://www.notion.so/zechub/Social-Media-Links-05b9df645af54de7a1989d9c4ccc4d05) que lista as principais contas a seguir.

**[Comunidade Zcash](https://www.zcashcommunity.com/)**

Zcash Community é um site administrado pela comunidade que destaca projetos também administrados pela comunidade e que apoiam o ecossistema do Zcash. É uma excelente forma de conhecer a comunidade Zcash e suas várias aplicações como moeda.

**[O Fórum Zcash](https://forum.zcashcommunity.com/)**

Como mencionado no guia para novos usuários, o fórum Zcash é um excelente lugar para ter discussões aprofundadas sobre temas do Zcash e também sobre ideias propostas. As propostas sempre chegam ao fórum, para que a comunidade tenha a oportunidade de discutir e debater as ideias propostas.

**[Z.cash](https://z.cash/)**

Z.cash é o principal site do Zcash. Fornece conteúdo e documentação sobre o Zcash para uma ampla variedade de usuários e permite que novos usuários se aprofundem nas explicações técnicas sobre o Zcash.

**[GitHub do Zcash](https://github.com/zcash/zcash)**

Você tem habilidades de programação e quer se aprofundar no lado técnico do Zcash? O repositório GitHub do Zcash é o repositório do zcashd, a primeira implementação de nó do Zcash. O zcashd atingiu sua interrupção automática de fim de suporte em 18 de julho de 2026 e não recebe mais manutenção, e a página de download para a qual esta entrada apontava anteriormente não está mais disponível. A stack mantida é o [Zebra](https://github.com/ZcashFoundation/zebra) para o nó e o [Zallet](https://github.com/zcash/zallet) para a carteira — consulte o [guia de migração de zcashd para Zebra e Zallet](https://zechub.wiki/guides/migration-guide-zcashd-to-zebrad-zallet).

**[GitHub da Zcash Foundation](https://github.com/ZcashFoundation)**

Outro repositório GitHub que hospeda projetos da Zcash Foundation, incluindo o [zebra](https://github.com/ZcashFoundation/zebra), uma implementação de nó do Zcash em Rust.

**[Halo2](https://zcash.github.io/halo2/index.html)**

Os conceitos por trás dos sistemas de provas de conhecimento zero.

**[Documentação RPC do Zcash](https://zcash.github.io/rpc/)**

Lista dos comandos RPC que o zcashd disponibilizava. Para a interface RPC da carteira com manutenção, consulte o [Livro do Zallet](https://zcash.github.io/zallet/).
