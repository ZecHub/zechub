# <img src="/content-images/image-2024-02-03-173258092-a5440e5ee2.webp" alt="Alt Text" width="50"/>   Exchanges com Custódia

Ironwood é o pool protegido que chegou com a atualização de rede de julho de 2026. As exchanges que apenas lidam com endereços t transparentes nunca lhe tocam, pelo que estão assinaladas como não aplicável. Quando uma exchange lida com endereços protegidos, mas não indicou qual o pool que utiliza, a linha diz isso em vez de adivinhar.
