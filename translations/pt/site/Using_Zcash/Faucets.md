# Faucets

<img width="2138" height="878" alt="Screenshot_2025-10-30_10-36-45" src="/content-images/bba0da3b-7064-4680-9535-a0dfcf50cc00-1827fccf4b.webp" />


Faucets são serviços que distribuem pequenas quantidades de criptomoeda gratuitamente. Eles costumam ser usados por desenvolvedores para fazer experimentos com criptomoedas e por usuários para ganhar pequenas quantidades de criptomoeda sem precisar comprá-la. Normalmente, eles limitam a quantidade de criptomoeda que um usuário pode receber em um determinado período de tempo.

Mainnet: <a href="https://zecfaucet.com">zecfaucet</a>

Testnet: <a href="https://fauzec.com/">fauzec.com</a>

Testnet: <a href="https://zcashfaucet.jinolabs.xyz/">zcashfaucet.jinolabs.xyz</a>
