# Filtro de Log de Eleição

`./filterForElection.sh <logname> <election #>`    

mostra os sighashs e as alturas dos boletins para entradas que envolvem o número de eleição fornecido

`./numberOfBallets.sh <logname> <election #>`      

mostra a contagem da última entrada (a mais atual) para a altura do boletim dado um número de eleição
