# Помогите развивать ZecHub 

Если вы являетесь участником сообщества Zcash и хотите внести вклад в развитие ZecHub, есть несколько особенно полезных способов.

Подбирайте ссылки для рассылки и добавляйте их на GitHub-страницу рассылки: -> [Нажмите здесь, чтобы ознакомиться с инструкциями](https://github.com/ZecHub/zechub/blob/main/site/contribute/ZecWeekly_Newsletter.md)

Проверяйте факты в документах вики, предлагайте правки и новые страницы на GitHub

Создавайте видеоконтент в следующих категориях:
```
* Zcash explainer videos
* Zcash wallet guide/tutorials
* Third-party application demos
```

Создавайте дизайн, например плакаты/графику/анимации, для экосистемы Zcash и Privacy 

Переводите любые существующие страницы вики.

Сообщайте об ошибках

#### Подробнее о размерах вознаграждений читайте на нашей странице для участников -> [здесь](https://zechub.wiki/contribute/contributing-guide#content).

Каждый понедельник мы публикуем задачи, за которые в настоящее время предусмотрены вознаграждения. Вы также можете предлагать вознаграждения! В основном они находятся в разделе ZEC Bounties.

![zecbounties](/content-images/0e4f5109-c0c9-4a0a-8d71-8172e36b9726-1a94469edf.webp)



[ZEC Bounties](https://bounties.zechub.wiki/)

[ZecHub Задачи GitHub](https://github.com/ZecHub/zechub/issues)

[ZecHub-Wiki Задачи GitHub](https://github.com/ZecHub/zechub-wiki/issues)



Если вы хотите помочь другим способом, напишите ZecHub ([@ZecHub](https://twitter.com/zechub)) в Twitter или присоединяйтесь к нашему [Discord](https://discord.gg/zcash).

____

**Для осуществления выплат ZecHub требует от всех участников заполнить декларационную форму с указанием имени и Shielded:**

**( Zcash | Namada | Penumbra | Ycash ) адреса**
