# Arborist Calls

Arborist Calls Zcash — это регулярные встречи по разработке протокола, посвящённые планированию обновлений сети, работе над реализацией консенсусных нод, зависимостям кошельков и инфраструктуры, а также исследованиям протокола.

Официальная страница Arborist Calls поддерживается Zcash Foundation:

**[https://zfnd.org/arborist-calls/](https://zfnd.org/arborist-calls/)**


## Как присоединиться

Звонки чередуются между двумя регулярными временными слотами, чтобы участники из разных регионов могли присоединиться. Используйте официальную страницу Zcash Foundation для получения актуальных файлов календаря и ссылок Zoom:

- **15:00 UTC** временной слот


Страница Foundation является источником истины для ссылок на регистрацию, файлов календаря и доступа к встречам, поскольку ссылки на встречи могут меняться.

- Развёрнутое обсуждение: [Форум сообщества Zcash](https://forum.zcashcommunity.com/)

## Кому стоит участвовать

Arborist Calls будут полезны для:

- Инженеров и исследователей протокола
- Разработчиков нод, кошельков, SDK и инфраструктуры lightwallet
- Получателей грантов, чья работа связана с консенсусом, обновлениями сети или зависимостями протокола
- Участников сообщества, которые хотят публично следить за принятием технических решений
