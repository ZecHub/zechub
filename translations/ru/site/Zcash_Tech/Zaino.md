# Zaino Индексатор

Zaino — это индексатор Rust для блокчейна Zcash. Он считывает данные цепочки из полного узла Zebra и предоставляет данные, необходимые кошелькам, обозревателям, кранам и другим сервисам, не возлагая на саму Zebra ответственность за создание всех индексов для клиентских приложений.

## Кратко

* **Zebra** проверяет цепочку Zcash.
* **Zaino** индексирует данные цепочки Zebra и предоставляет API для клиентских приложений.
* **Zallet** — компонент кошелька в стеке Z3. В стандартной конфигурации Z3 Zallet напрямую взаимодействует с Zebra, и отдельный сервис Zaino не требуется.
* Отдельный сервис Zaino полезен, когда операторам нужна совместимая с lightwalletd конечная точка gRPC, прокси JSON-RPC или инфраструктура для лёгких кошельков, обозревателей, кранов и подобных сервисов.
* Zaino — действующая инфраструктура, однако перед запуском в производственной среде операторам следует проверить актуальные сведения о развёртывании в официальной документации Zaino и Z3.

## Что делает Zaino

Zaino находится между Zebra и клиентским программным обеспечением. Zebra — это узел консенсуса: он загружает, проверяет и отслеживает блокчейн Zcash. Zaino использует Zebra как источник данных цепочки, а затем подготавливает индексированные представления, которые клиентские приложения могут эффективно запрашивать.

Такое разделение помогает чётко разграничить роли:

| Компонент | Роль |
|:--|:--|
| Zebra | Полный узел и валидатор |
| Zaino | Индексатор и API-сервис для клиентских приложений |
| Zallet | Сервис кошелька |
| lightwalletd | Устаревший сервер лёгких кошельков, который Zaino призван заменить или дополнить |

Zaino предоставляет функциональность для лёгких клиентов, полнофункциональных клиентов или кошельков, а также обозревателей блоков. Он обеспечивает доступ к финализированной цепочке, нефинализированной лучшей цепочке и данным мемпула, хранящимся в Zebra.

## Как это вписывается в текущий стек Zcash Stack

Текущий стек Z3 построен на Zebra, Zallet и необязательном Zaino.

В стандартном развёртывании Z3 Zebra и Zallet работают вместе. Zallet напрямую подключается к Zebra, поэтому оператору, который запускает только локальный стек кошелька, не нужно запускать отдельный сервис Zaino.

Zaino добавляют, когда оператору нужно обслуживать внешних клиентов. В Z3 он работает за профилем Compose `indexer` и предоставляет:

* конечную точку gRPC, совместимую с lightwalletd, для клиентов лёгких кошельков
* прокси JSON-RPC для обозревателей, кранов и серверной части сервисов
* базу данных индексатора, отдельную от состояния цепочки Zebra

Поэтому Zaino особенно актуален для серверной части кошельков, операторов публичной инфраструктуры, обозревателей, кранов и разработчиков, тестирующих сервисы, которым нужны индексированные данные цепочки Zcash.

## Zaino и lightwalletd

lightwalletd — исходный сервер лёгких кошельков. Zaino — основанный на Rust преемник для этой роли. Его цель — по возможности предоставлять совместимые API, чтобы кошельки и сервисы могли перейти на него без необходимости сразу полностью переписывать код.

Это не означает, что все развёртывания lightwalletd уже перешли на Zaino. Операторам следует рассматривать Zaino как часть текущего стека на базе Zebra и перед выбором компонентов проверять актуальную документацию проекта, выпуски и панели мониторинга сервисов.

## Заметки для операторов

Самый простой авторитетный путь развёртывания — репозиторий Z3. В Z3 Zaino включён как необязательный сервис:

```bash
docker compose --env-file .env.<network> --profile indexer up -d
```

Сначала выполните стандартную настройку Z3 и дождитесь синхронизации Zebra, прежде чем запускать зависящие от него сервисы в основной или тестовой сети.

Zaino предоставляет два типа сетевых сервисов. Сервис gRPC — это API для lightwallet-клиентов. Сервис JSON-RPC предназначен для локального интерфейса или доверенных частных сетей, если только внешний уровень не обеспечивает защиту. Не выставляйте неаутентифицированную или незашифрованную конечную точку JSON-RPC в публичный интернет.

## Распространённые ошибки

**Считать Zaino полным узлом.** Zaino не является валидатором. Zebra проверяет цепочку, а Zaino индексирует данные из Zebra.

**Предполагать, что каждому развёртыванию Z3 нужен отдельный Zaino.** В стандартном стеке Z3 Zallet может напрямую подключаться к Zebra. Запускайте Zaino, если для внешних клиентов нужен отдельный сервис индексатора.

**Представлять запланированные функции как уже доступные.** Zaino активно развивается, поэтому перед тем, как объявлять функцию доступной, проверяйте актуальные примечания к выпускам и документацию.

**Неосторожно открывать JSON-RPC.** Интерфейс JSON-RPC Zaino предназначен для локального интерфейса или доверенных частных сетей, если его не защищает другой уровень.
