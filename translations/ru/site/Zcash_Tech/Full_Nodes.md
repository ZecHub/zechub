# Полные узлы

## Кратко

- Полный узел хранит полную копию блокчейна Zcash и проверяет каждый новый блок и транзакцию на соответствие правилам консенсуса.
- Zebra (`zebrad`) — узел, который следует установить сегодня. Zakura — вторая реализация, ответвлённая от Zebra.
- zcashd выведен из эксплуатации. Его автоматическая остановка по окончании поддержки произошла 18 июля 2026 года на высоте блока 3417100, и эти узлы больше не запускаются.
- Узел и кошелёк теперь являются отдельными программами. [Zallet](https://github.com/zcash/zallet) работает с узлом и хранит ключи.
- Запуск собственного узла даёт вам независимую проверку и устраняет необходимость доверять чужому серверу.

## Основное объяснение

Полный узел — это программное обеспечение, которое запускает полную копию блокчейна криптовалюты, предоставляя вам доступ к функциям протокола.

Он хранит полную запись каждой транзакции, произошедшей с момента генезиса, и поэтому может проверять действительность новых транзакций и блоков, добавляемых в блокчейн.

## Реализации узлов

### Zebra

Zebra — независимая, готовая к промышленному использованию реализация полного узла протокола Zcash, созданная Zcash Foundation и написанная на Rust. Поскольку zcashd выведен из эксплуатации, Zebra (`zebrad`) — рекомендуемый полный узел для новых развёртываний.

Zebra проверяет блоки и транзакции, участвует в одноранговой сети и предоставляет интерфейс RPC для приложений. Кошелёк теперь является отдельным компонентом: [Zallet](https://github.com/zcash/zallet) работает с узлом Zebra и управляет ключами и балансами. Это заменяет zcashd, который объединял узел и кошелёк в одном процессе.

Для обслуживания экранированных лёгких кошельков узел запускается вместе с индексатором: либо устоявшимся [lightwalletd](https://github.com/zcash/lightwalletd), либо более новым [Zaino](https://zechub.wiki/zcash-tech/zaino).

Обязательно прочитайте книгу Zebra с инструкциями по настройке и присоединяйтесь к серверу R&D Discord для получения поддержки.

[Github](https://github.com/ZcashFoundation/zebra/)

[Книга Zebra](https://zebra.zfnd.org)

См. [Zebra «Полный узел»](/zcash-tech/zebra-full-node), чтобы узнать об установке, настройке и требованиях к оборудованию.

### Zakura

Zakura — второй совместимый с консенсусом полный узел, ответвлённый от Zebra и разработанный Valar Group совместно с Project Tachyon. Он следует тем же правилам протокола и добавляет более быструю синхронизацию, очистку блоков и слой совместимости RPC zcashd. См. [Zakura «Узел»](/zcash-tech/zakura-node).

### zcashd (выведен из эксплуатации)

> **Примечание:** zcashd выведен из эксплуатации. Electric Coin Company [объявила об устаревании](https://z.cash/support/zcashd-deprecation/), а автоматическая остановка по окончании поддержки произошла 18 июля 2026 года на высоте блока 3417100. Каждый неизменённый узел zcashd 6.20.0 завершил работу на этой высоте и отказывается перезапускаться, а программное обеспечение не поддерживает NU6.3. Используйте Zebra. Если у вас есть zcashd `wallet.dat`, следуйте [руководству по миграции: zcashd на Zebrad/Zallet](https://zechub.wiki/guides/migration-guide-zcashd-to-zebrad-zallet).

zcashd была исходной реализацией полного узла для Zcash, разработанной и поддерживаемой Electric Coin Company. Приведённые ниже инструкции по сборке сохранены для справки и для операторов, переходящих с zcashd.

Zcashd предоставляет набор API через свой интерфейс RPC. Эти API предоставляют функции, позволяющие внешним приложениям взаимодействовать с узлом.

[Lightwalletd](https://github.com/zcash/lightwalletd) — пример приложения, использующего полный узел, чтобы позволить разработчикам создавать и поддерживать удобные для мобильных устройств экранированные лёгкие кошельки без прямого взаимодействия с Zcashd.

[Полный список поддерживаемых команд RPC](https://zcash.github.io/rpc/)

[Книга Zcashd](https://zcash.github.io/zcash/)

#### Запуск узла (Linux)

- Установите зависимости

      sudo apt update

      sudo apt-get install \
      build-essential pkg-config libc6-dev m4 g++-multilib \
      autoconf libtool ncurses-dev unzip git python3 python3-zmq \
      zlib1g-dev curl bsdmainutils automake libtinfo5

- Клонируйте последний релиз, выполните checkout, настройте и соберите:

      git clone https://github.com/zcash/zcash.git

      cd zcash/

      git checkout v5.4.1
      ./zcutil/fetch-params.sh
      ./zcutil/clean.sh
      ./zcutil/build.sh -j$(nproc)

- Синхронизируйте блокчейн (это может занять несколько часов)

    Чтобы запустить узел, выполните:

      ./src/zcashd

- Приватные ключи хранятся в ~/.zcash/wallet.dat

[Руководство по Zcashd на Raspberry Pi](https://zechub.notion.site/Raspberry-Pi-4-a-zcashd-full-node-guide-6db67f686e8d4b0db6047e169eed51d1)

## Практические последствия

### Сеть

Запуская полный узел, вы помогаете укреплять сеть Zcash, поддерживая её децентрализацию.

Это помогает предотвратить враждебный контроль и сохранить устойчивость сети к некоторым формам сбоев.

DNS-сидеры предоставляют список других надёжных узлов через встроенный сервер. Это позволяет транзакциям распространяться по всей сети.

### Статистика сети

Вот примеры платформ, предоставляющих доступ к данным сети Zcash:

[Zcash Обозреватель блокчейна](https://zcashblockexplorer.com)

[Coinmetrics](https://docs.coinmetrics.io/info/assets/zec)

[Blockchair](https://blockchair.com/zcash)

Вы также можете внести вклад в развитие сети, запуская тесты, предлагая новые улучшения и предоставляя метрики.

### Майнинг

Майнерам необходимы полные узлы для доступа ко всем RPC, связанным с майнингом, таким как getblocktemplate и getmininginfo.

Zcashd также позволяет майнинг с экранированными coinbase-транзакциями. Майнеры и майнинговые пулы могут майнить напрямую, по умолчанию накапливая экранированные ZEC на z-адресе.

Прочитайте [руководство по майнингу](https://zcash.readthedocs.io/en/latest/rtd_pages/zcash_mining_guide.html) или присоединяйтесь к странице форума сообщества для [Zcash майнеров](https://forum.zcashcommunity.com/c/mining/13).

### Конфиденциальность

Запуск полного узла позволяет вам независимо проверять все транзакции и блоки в сети Zcash.

Запуск полного узла устраняет некоторые риски для конфиденциальности, связанные с использованием сторонних сервисов для проверки транзакций от вашего имени.

Использование собственного узла также позволяет подключаться к сети через [Tor](https://zcash.github.io/zcash/user/tor.html).
Это даёт дополнительное преимущество: другие пользователи могут конфиденциально подключаться к .onion-адресу вашего узла.

## Распространённые ошибки

- Сборка zcashd по приведённым выше инструкциям с ожиданием работающего узла. Эти бинарные файлы останавливаются на высоте устаревания.
- Запуск узла с предположением, что ваш мобильный кошелёк теперь его использует. Лёгкий кошелёк продолжает обращаться к серверу, который в нём настроен, пока вы не укажете собственный. См. [Узлы Lightwallet](/zcash-tech/lightwallet-nodes).
- Запуск только `zebrad` с ожиданием, что лёгкие кошельки смогут подключаться. Рядом с узлом нужен индексатор: либо lightwalletd, либо [Zaino](/zcash-tech/zaino).
- Поиск RPC кошелька на узле. Ключи и балансы перемещены в Zallet.
