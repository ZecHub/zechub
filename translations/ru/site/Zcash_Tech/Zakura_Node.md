# Zakura Узел

> 🇧🇷 [Версия на португальском](/zechubglobal/zcashbrasil/zcashtech/zakura)

Zakura — это бесплатная реализация полноценного узла с открытым исходным кодом для Zcash, созданная для масштабирования. Ответвлённый от [Zebra](Zebra_Full_Node.md) и разработанный в сотрудничестве между **Valar Group** и **Project Tachyon**, Zakura обеспечивает значительно более быструю синхронизацию, встроенную очистку блоков и слой совместимости для устаревших инструментов `zcashd`. Версия 1.0.0 была выпущена 15 июля 2026 года.

---

## Кратко

- Zakura — это **полноценный узел Zcash, совместимый с консенсусом** — альтернатива Zebra и zcashd, ответвлённая от Zebra.
- Синхронизация блокчейна примерно **в 5 раз быстрее, чем у Zebra**; начальная загрузка из снимка занимает **менее 2 минут**.
- **Встроенная очистка блоков** позволяет операторам запускать полноценный узел, используя значительно меньше дискового пространства (~11 ГБ для очищенного снимка против 300 ГБ для полноценного узла Zebra).
- **Режим совместимости RPC zcashd** позволяет существующим кошелькам и интеграциям работать без изменений.
- **Экспериментальный транспортный уровень P2P** (по умолчанию отключён) нацелен на распространение блоков менее чем за 500 мс с gossip-протоколом, устойчивым к DoS-атакам.
- Совместим с Ironwood (NU6.3), обновлением сети Zcash, активированным в середине 2026 года.
- **Zakura Common** (v1.3.0, август 2026 года) ускоряет криптографические операции, используемые кошельками для создания приватных транзакций: во многих случаях с более чем 3 секунд до менее чем 200 мс, согласно бенчмаркам Zakura.
- Руководят **Sean Bowe** (сооснователь Zcash, Project Tachyon) и **Dev Ojha** (Valar Group).

---

## Что такое Zakura?

Zakura — это полноценный узел Zcash, спроектированный с нуля для промышленного использования в масштабе. Хотя он совместим по консенсусу с Zebra — то есть проверяет и соблюдает те же правила протокола Zcash, — Zakura внедряет значительные инженерные улучшения, направленные на снижение барьера для запуска полноценного узла Zcash.

Проект является совместной работой **Project Tachyon** (под руководством Sean Bowe, одного из первоначальных криптографических инженеров Zcash) и **Valar Group** (под руководством Dev Ojha). Вместе они сосредоточены на улучшениях протокола следующего поколения Zcash, а Zakura служит эталонным узлом для этой работы.

## Ключевые возможности

### Синхронизация цепочки в 5 раз быстрее

Zakura обеспечивает примерно в 5 раз более быструю синхронизацию блокчейна по сравнению с Zebra. Это делает его значительно более практичным для операторов, которым нужно быстро запустить узел или восстановиться после простоя.

### Начальная загрузка из снимка

Zakura публикует готовые снимки цепочки, которые значительно сокращают время первоначальной синхронизации:

| Метод начальной загрузки | Время |
|-----------------|------|
| Архивный снимок | ~37 минут |
| Очищенный снимок | **Менее 2 минут** |
| Zebra (полная синхронизация) | ~20 часов |

Очищенные снимки занимают примерно **11 ГБ**, обеспечивая **в 680 раз более быструю** начальную загрузку узла по сравнению с синхронизацией от генезис-блока.

### Встроенная очистка блоков

Zakura поддерживает настраиваемую очистку блоков, позволяя операторам узлов определять, какой объём истории цепочки хранить. Это делает практичным запуск полноценного узла на оборудовании с ограниченным хранилищем — полезно для валидаторов, разработчиков и поставщиков инфраструктуры, которым не требуется полная историческая цепочка.

### Режим совместимости RPC zcashd

Zakura включает режим совместимости, который воспроизводит устаревший интерфейс JSON-RPC `zcashd`. Существующие кошельки, биржи и интеграции, использующие RPC `zcashd`, могут перейти на Zakura без необходимости изменять код.

### Экспериментальный транспортный уровень P2P

Zakura поставляется с транспортным уровнем peer-to-peer следующего поколения, который сейчас **по умолчанию отключён**. При включении он нацелен на:

- Распространение блоков по сети в худшем случае менее чем за 500 мс
- Агрегацию мемпула для более эффективной передачи транзакций
- Gossip-протокол, устойчивый к DoS-атакам, для повышения устойчивости сети

Этот уровень представляет собой предварительный обзор будущих улучшений Zcash на сетевом уровне, разрабатываемых в рамках Project Tachyon.

### Совместимость с Ironwood (NU6.3)

Zakura полностью совместим с обновлением сети Ironwood (NU6.3), активированным в основной сети Zcash в середине 2026 года.

## Zakura Common: более быстрая криптография кошельков

В августе 2026 года команда Zakura выпустила Zakura Common — набор ускоренных форков криптографических библиотек, от которых зависят кошельки и узлы Zcash. Zakura перешёл на новый стек в версии 1.3.0, а Vizor Wallet стал одним из первых кошельков, интегрировавших его.

![Private Zcash payment: zk-SNARK verification 4 to 8 times faster, transaction building from over 3 seconds to under 200 ms, proof generation over 14 times faster on mobile, hashing 21 times faster, trial decryption 1.5 times faster, and open source libraries that need no protocol upgrade](/content-images/zakuracommonspeedups.webp)

Согласно собственным бенчмаркам Zakura:

| Операция | Ускорение |
|--|--|
| Генерация доказательства на мобильных устройствах | более чем в 14 раз (на настольных устройствах: более чем в 5 раз) |
| Хеширование Sinsemilla | более чем в 21 раз |
| Проверка zk-SNARK | в 4–8 раз |
| Пробное расшифрование | более чем в 1,5 раза |

Для пользователей наиболее заметным изменением будет время ожидания. Раньше создание приватной транзакции занимало у кошелька более трёх секунд. С Zakura Common во многих случаях это может занять менее 200 мс. Это время, которое ваше устройство тратит на подготовку транзакции, а не время, необходимое сети для её подтверждения.

## Как Zakura соотносится с другими узлами Zcash

| | zcashd | Zebra | Zakura |
|--|--------|-------|--------|
| Язык | C++ (ответвлён от Bitcoin) | Rust | Rust (ответвлён от Zebra) |
| Статус | Устаревший | Активный | Активный (v1.0.0, июль 2026) |
| Скорость синхронизации | Базовая | ~1× | ~5× быстрее |
| Очистка блоков | Нет | Нет | Да |
| Совместимость с RPC zcashd | Нативная | Частичная | Да (режим совместимости) |
| Начальная загрузка из снимка | Нет | Нет | Да (менее 2 мин) |
| Экспериментальный P2P | Нет | Нет | Да (по выбору) |
