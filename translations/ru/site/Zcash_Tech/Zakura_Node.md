# Zakura Node

> 🇧🇷 [Версия на португальском](/zechubglobal/zcashbrasil/zcashtech/zakura)

Zakura — это бесплатная полная реализация узла Zcash с открытым исходным кодом, созданная для масштабирования. Будучи форком [Zebra](Zebra_Full_Node.md) и разрабатываясь в рамках сотрудничества между **Valar Group** и **Project Tachyon**, Zakura обеспечивает значительно более быструю синхронизацию, встроенную обрезку блоков и слой совместимости с устаревшими инструментами `zcashd`. Версия 1.0.0 была выпущена 15 июля 2026 года.

---

## Кратко

- Zakura — это **совместимый по консенсусу полный узел Zcash** — альтернатива Zebra и zcashd, основанная на форке Zebra.
- Синхронизация блокчейна примерно в **5 раз быстрее, чем у Zebra**; загрузка из снимка завершается **менее чем за 2 минуты**.
- **Встроенная обрезка блоков** позволяет операторам запускать полный узел, используя значительно меньше дискового пространства (~11 ГБ для обрезанного снимка против 300 ГБ для полного узла Zebra).
- **Режим совместимости с RPC zcashd** позволяет существующим кошелькам и интеграциям работать без изменений.
- **Экспериментальный транспортный слой P2P** (по умолчанию отключён) нацелен на распространение блоков менее чем за 500 мс и gossip-протокол с защитой от DoS.
- Совместим с **Ironwood (NU6.3)**, обновлением сети Zcash, активированным в середине 2026 года.
- Проект возглавляют **Sean Bowe** (сооснователь Zcash, Project Tachyon) и **Dev Ojha** (Valar Group).

---

## Что такое Zakura?

Zakura — это полный узел Zcash, спроектированный с нуля как готовое к промышленной эксплуатации решение в масштабе. Хотя он сохраняет совместимость по консенсусу с Zebra — то есть проверяет и следует тем же правилам протокола Zcash, — Zakura внедряет значительные инженерные улучшения, направленные на снижение порога для запуска полного узла Zcash.

Проект является совместной инициативой **Project Tachyon** (под руководством Sean Bowe, одного из оригинальных криптографических инженеров Zcash) и **Valar Group** (под руководством Dev Ojha). Вместе они сосредоточены на улучшениях протокола Zcash следующего поколения, и Zakura служит эталонным узлом для этой работы.

## Ключевые особенности

### Синхронизация цепочки в 5 раз быстрее

Zakura обеспечивает примерно в 5 раз более быструю синхронизацию блокчейна по сравнению с Zebra. Это делает его значительно более практичным для операторов, которым нужно быстро развернуть узел или восстановиться после простоя.

### Загрузка из снимка

Zakura публикует предварительно собранные снимки цепочки, которые значительно сокращают время начальной синхронизации:

| Метод начальной загрузки | Время |
|-----------------|------|
| Архивный снимок | ~37 минут |
| Обрезанный снимок | **Менее 2 минут** |
| Zebra (полная синхронизация) | ~20 часов |

Размер обрезанных снимков составляет примерно **11 ГБ**, что обеспечивает **ускорение начальной загрузки узла в 680 раз** по сравнению с синхронизацией с genesis.

### Встроенная обрезка блоков

Zakura поддерживает настраиваемую обрезку блоков, позволяя операторам узлов определять, какой объём истории цепочки сохранять. Это делает практичным запуск полного узла на оборудовании с ограниченным объёмом хранилища — полезно для валидаторов, разработчиков и инфраструктурных провайдеров, которым не нужна полная историческая цепочка.

### Режим совместимости с RPC zcashd

Zakura включает режим совместимости, воспроизводящий устаревший интерфейс JSON-RPC `zcashd`. Существующие кошельки, биржи и интеграции, зависящие от RPC `zcashd`, могут перейти на Zakura без необходимости изменять код.

### Экспериментальный транспортный слой P2P

Zakura поставляется с транспортным слоем peer-to-peer нового поколения, который в настоящее время **по умолчанию отключён**. При включении он нацелен на:

- Наихудшее время распространения блока по сети менее 500 мс
- Агрегацию mempool для более эффективной ретрансляции транзакций
- Gossip-протокол с защитой от DoS для повышения устойчивости сети

Этот слой представляет собой предварительный взгляд на будущие улучшения сетевого уровня Zcash, разрабатываемые в рамках Project Tachyon.

### Совместимость с Ironwood (NU6.3)

Zakura полностью совместим с обновлением сети Ironwood (NU6.3), активированным в основной сети Zcash в середине 2026 года.

## Как Zakura соотносится с другими узлами Zcash

| | zcashd | Zebra | Zakura |
|--|--------|-------|--------|
| Язык | C++ (форк Bitcoin) | Rust | Rust (форк Zebra) |
| Статус | Устарел | Активен | Активен (v1.0.0, июль 2026) |
| Скорость синхронизации | Базовая | ~1× | ~в 5 раз быстрее |
| Обрезка блоков | Нет | Нет | Да |
| Совместимость с RPC zcashd | Встроенная | Частичная | Да (режим совместимости) |
| Начальная загрузка из снимка | Нет | Нет | Да (<2 мин) |
| Экспериментальный P2P | Нет | Нет | Да (по желанию) |
