# Руководства по полным узлам

Полные узлы Zcash проверяют прозрачные и экранированные транзакции в сети. Запуская полный узел, вы вносите вклад в устойчивость и стабильность сети. Кроме того, эксплуатация полного узла обеспечивает пользователю повышенные гарантии безопасности и защищённости. Ниже приведены видеоинструкции по настройке/обновлению полных узлов zcashd или zebrad.

> **Примечание:** zcashd [выводится из эксплуатации](https://z.cash/support/zcashd-deprecation/) в пользу [Zebra](https://github.com/ZcashFoundation/zebra) (`zebrad`) для узла и [Zallet](https://github.com/zcash/zallet) для кошелька. Приведённые ниже видео по zcashd сохранены для справки; для новых установок следуйте [Руководству по миграции: zcashd на Zebrad/Zallet](https://zechub.wiki/migration-guide-zcashd-to-zebrad-zallet).

Пожалуйста, прочитайте наше [руководство по полным узлам](https://zechub.wiki/full-nodes), чтобы получить дополнительную информацию.
