> **Полное руководство по инструментам для чаевых и профилей с сохранением приватности, созданным на базе Zcash для создателей контента, киберпанков и сообщества, заботящегося о приватности.**

## Кратко

* Два инструмента Zcash помогают создателям получать оплату конфиденциально. Zcash.me предоставляет страницу профиля с вашим экранированным адресом, а TIPZ позволяет поклонникам отправлять вам чаевые.
* С Zcash.me вы делитесь одной ссылкой, `zcash.me/[username]`, в которой отображаются ваш унифицированный адрес и ваши аккаунты в социальных сетях.
* С TIPZ поклонники могут отправлять чаевые в других криптовалютах, и каждые чаевые поступают к вам как экранированные ZEC.
* Оба инструмента запрашивают ваш унифицированный адрес (`u1...`).
* Чаевые на экранированный адрес скрывают ваш доход и баланс от публичного просмотра.

## Основное объяснение

### Zcash.me

![Zcash.me Logo](/content-images/_unavailable.svg)

#### Обзор

**Zcash.me** — это каталог профилей и платформа для поиска, которая позволяет любому легко находить пользователей Zcash и отправлять им ZEC. Она служит «Linktree для Zcash» — простым способом поделиться своим экранированным адресом и присутствием в социальных сетях с помощью одной ссылки.

| Элемент              | Подробности |
|-------------------|---------|
| **Веб-сайт**       | [https://zcash.me/](https://zcash.me/) |
| **Twitter**       | [@zcashme](https://x.com/zcashme) |
| **Формат профиля**| `zcash.me/[username]` |
| **Статус**        | Работает (функции находятся в разработке) |

#### Ключевые возможности

##### Уже доступно
- **Настраиваемые страницы профиля** — персонализированная страница с именем пользователя, биографией, аватаром и местоположением
- **Отображение экранированного адреса** — кнопка копирования вашего унифицированного адреса в один клик
- **Интеграция ссылок на социальные сети** — X, LinkedIn, Telegram и пользовательские веб-сайты
- **Система верификации** — значок подтверждения для доверия сообщества
- **Рейтинг рефералов** — отслеживание лучших рефереров и лидеров сообщества
- **Статус активности** — показывает время последней активности.

##### Скоро появится
| Функция            | Описание |
|--------------------|-------------|
| Карта местоположений       | Находите пользователей Zcash поблизости |
| Статистика платформы| Просматривайте показатели роста |
| Опросы сообщества    | Голосуйте по темам экосистемы |
| Новости и объявления | Официальные обновления |
| Форум              | Обсуждение в сообществе |
| Мобильное приложение         | Полноценный мобильный опыт |

#### Начало работы
1. Перейдите на [https://zcash.me/](https://zcash.me/) и нажмите **Join**.
2. Выберите уникальное имя пользователя, добавьте биографию и изображение профиля.
3. Вставьте свой унифицированный адрес Zcash (`u1...`)
4. Подключите свои аккаунты в социальных сетях.
5. Поделитесь своей ссылкой: `zcash.me/[yourusername]`

### TIPZ

![TIPZ Logo](/content-images/BbXM8cDV_400x400-e6071ba983.webp)

#### Обзор

**TIPZ** — это **протокол приватных чаевых**, специально созданный для создателей и киберпанков. Поклонники отправляют чаевые в любой крупной криптовалюте; она автоматически конвертируется и доставляется как **экранированные ZEC**.

| Элемент              | Подробности |
|-------------------|---------|
| **Веб-сайт**       | [https://tipz.cash/](https://tipz.cash/) |
| **Twitter**       | [@tipz_cash](https://x.com/tipz_cash) |
| **Формат профиля**| `tipz.cash/@[username]` |
| **Статус**        | Работает |

> *«tipz.cash — это приватный протокол чаевых для создателей и киберпанков.»*

#### Почему приватность важна для создателей

##### Финансовая свобода
- Комиссия платформы 0%
- Некастодиальное хранение и самостоятельное хранение
- Без посредников

##### Приватность прежде всего
- Каждые чаевые поступают как экранированные ZEC.
- Приватный баланс кошелька
- Зашифрованные сообщения вместе с чаевыми
- Возможность полной анонимности создателя

##### Межсетевые платежи
| Валюта | Сеть |
|----------|---------|
| ETH      | Ethereum |
| USDC     | Несколько сетей |
| SOL      | Solana |
| ZEC      | Напрямую в Zcash |

##### Защита создателя
- Нет риска деплатформинга
- Устойчивость к цензуре
- KYC не требуется

## Визуализация / Аналогия

Банка для чаевых на стойке кафе стеклянная. Все в помещении видят, кто бросил монету и насколько полна банка.

Экранированный адрес работает как запертый почтовый ящик с прорезью. Поклонники опускают конверт с монетой и запиской, и только создатель открывает ящик. TIPZ добавляет у входа обмен валют: поклонник может прийти с ETH или SOL, а в почтовый ящик попадёт ZEC.

```
TIPZ Payment Flow

Fan -> tipz.cash Protocol -> Creator's Wallet (Shielded ZEC)

Fan selects amount + message -> Protocol auto-converts -> Creator receives private shielded ZEC.
```
