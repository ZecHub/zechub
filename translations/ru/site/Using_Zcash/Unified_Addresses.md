# Унифицированные адреса

> Один адрес для всего Zcash. Поделитесь им, и кошелёк отправителя найдёт наиболее приватный способ отправить вам платёж.

Унифицированный адрес (UA) — это единый адрес Zcash, объединяющий несколько получателей в одном адресе. Получатели — это части адреса, принимающие средства в конкретном пуле ценностей: Ironwood, Sapling и прозрачном. UA в основной сети начинается с `u1` и определён в [ZIP 316](https://zips.z.cash/zip-0316); он был представлен вместе с обновлением сети NU5 31 мая 2022 года.

До унифицированных адресов получение ZEC требовало учитывать типы адресов. Адрес `zs` принимал средства Sapling, адрес `t` принимал прозрачные средства, а отправка между типами требовала дополнительных действий. UA устраняет эту необходимость. Вы делитесь одним адресом, а кошельки сами разбираются со всем остальным.

## Как это работает

Когда кто-то отправляет средства на ваш UA, его кошелёк считывает содержащихся в нём получателей и выбирает наиболее приватный пул, поддерживаемый обоими кошельками:

1. Если оба кошелька поддерживают текущий защищённый пул, платёж поступает защищённо. Никакие публичные данные не попадают в блокчейн.
2. Если отправитель может отправлять только из более старого пула, кошелёк переключается на лучшего получателя, общего для вас обоих, например Sapling.
3. Если отправитель может отправлять только прозрачные средства, платёж поступает на прозрачного получателя вашего UA, а ваш кошелёк может защитить его оттуда.

Вам никогда не нужно управлять этим самостоятельно. Адрес остаётся тем же; маршрутизация происходит внутри него.

## Почему это важно сейчас

Zcash продолжает обновляться. Когда пул Ironwood был активирован вместе с NU6.3 28 июля 2026 года, владельцам UA не понадобился новый адрес: кошельки просто начали выбирать получателя Ironwood внутри уже имеющихся у людей адресов. Пользователям со старыми отдельными адресами пришлось мигрировать. Владельцам UA ничего делать не пришлось.

В этом и состоит цель дизайна. Новые пулы появляются с будущими обновлениями сети, а унифицированный адрес включает их без необходимости заново делиться адресами или вручную перемещать средства. Актуальный перечень пулов смотрите в разделе [Zcashпулы ценностей](/using-zcash/shielded-pools).

## Новый адрес для каждого отправителя

Кошельки могут создавать множество диверсифицированных унифицированных адресов для одной учётной записи. Каждый из них направляет платежи в одни и те же средства, но ни один из них нельзя связать с другим в блокчейне. Дайте отдельный UA каждому человеку или сервису, который платит вам, и ни одна пара из них не сможет сравнить адреса и узнать, что они платят в один и тот же кошелёк.

## Связанные инструменты

- **Ключи просмотра.** У каждой учётной записи есть унифицированные ключи просмотра, позволяющие показывать, что получает UA (или всё, что он отправляет), без передачи права на расходование. Префиксы `uview` и `uivk`. См. [ключи просмотра](/zcash-tech/viewing-keys).
- **TEX-адреса.** Некоторые биржи, в настоящее время Binance, требуют, чтобы депозиты поступали из прозрачного источника. TEX-адрес ([ZIP 320](https://zips.z.cash/zip-0320)) — это прозрачный адрес-компаньон вашего UA именно для такого случая. См. [прозрачные адреса для бирж](/using-zcash/transparent-exchange-addresses).
- **Платёжные запросы.** UA можно встроить в URI платёжного запроса с заранее указанными суммой и заметкой. См. [URI платёжных запросов](/using-zcash/payment-request-uris).

## Краткие сведения

| | |
|---|---|
| Префикс | `u1` (основная сеть) |
| Кодировка | bech32m |
| Определён в | [ZIP 316](https://zips.z.cash/zip-0316) |
| Представлен | NU5, 31 мая 2022 года |
| Содержит | получателей Ironwood, Sapling и прозрачных получателей |
| Ключ расходования | Один на учётную запись, общий для всех её UA |
