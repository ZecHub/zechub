# Унифицированные адреса

> Один адрес для всего в Zcash. Поделитесь им, и кошелёк отправителя найдёт наиболее приватный способ заплатить вам.

## Кратко

* Унифицированный адрес (UA) — это один адрес Zcash, содержащий несколько получателей: Ironwood, Sapling и прозрачный.
* UA основной сети начинаются с `u1`. Их определил ZIP 316, и они появились с обновлением NU5 31 мая 2022 года.
* Кошелёк отправителя выбирает наиболее приватный пул, поддерживаемый обоими кошельками. Вам никогда не нужно выбирать пул самостоятельно.
* Ваш UA продолжил работать, когда пул Ironwood был запущен в июле 2026 года. Вам не пришлось делиться новым адресом.
* Ваш кошелёк может создать новый UA для каждого отправителя, и все они будут зачислять средства на один и тот же счёт.

## Основное объяснение

Унифицированный адрес (UA) — это единый адрес Zcash, объединяющий несколько получателей в одном. Получатели — это части адреса, принимающие средства в определённом пуле ценностей: Ironwood, Sapling и прозрачном. В основной сети UA начинается с `u1` и был определён в [ZIP 316](https://zips.z.cash/zip-0316), представленном вместе с обновлением сети NU5 31 мая 2022 года.

До унифицированных адресов получение ZEC требовало учитывать типы адресов. Адрес `zs` принимал средства Sapling, адрес `t` принимал прозрачные средства, а отправка между типами требовала дополнительных действий. UA избавляет от этого. Вы делитесь одним адресом, а кошельки сами разбираются с остальным.

### Как это работает

Когда кто-то отправляет средства на ваш UA, его кошелёк считывает содержащихся в нём получателей и выбирает наиболее приватный пул, поддерживаемый обоими кошельками:

1. Если оба кошелька поддерживают текущий экранированный пул, платёж поступает экранированным. В блокчейн не попадает ничего публичного.
2. Если отправитель может отправлять средства только из более старого пула, кошелёк переключается на лучшего получателя, общего для вас обоих, например Sapling.
3. Если отправитель может отправить только прозрачные средства, платёж поступает на прозрачного получателя в вашем UA, а ваш кошелёк сможет экранировать его оттуда.

Вам не нужно управлять этим самостоятельно. Адрес остаётся прежним; маршрутизация происходит внутри него.

### Почему это важно сейчас

Zcash продолжает обновляться. Когда пул Ironwood активировался с NU6.3 28 июля 2026 года, владельцам UA не понадобился новый адрес: кошельки просто начали выбирать получателя Ironwood внутри уже имеющихся адресов. Пользователям со старыми отдельными адресами пришлось выполнить миграцию. Владельцам UA ничего делать не пришлось.

Такова цель этого дизайна. Новые пулы появляются с будущими обновлениями сети, а унифицированный адрес включает их без необходимости повторно делиться адресами или вручную перемещать средства. Текущий состав пулов смотрите в разделе [Zcash пулы ценностей](/using-zcash/shielded-pools).

### Новый адрес для каждого отправителя

Кошельки могут создавать множество диверсифицированных унифицированных адресов для одного счёта. Каждый из них зачисляет средства на один и тот же счёт, но ни два из них нельзя связать в блокчейне. Дайте отдельный UA каждому человеку или сервису, который платит вам, и никакая пара из них не сможет сравнить адреса и узнать, что они платят на один и тот же кошелёк.

## Визуализация / аналогия

Представьте входную дверь с тремя почтовыми прорезями. Новейшая прорезь опускает письма в запертый сейф (Ironwood). Вторая опускает их в запертый ящик (Sapling). Третья кладёт их на открытую подставку, которую любой может прочитать через окно (прозрачный).

Почтальон — это кошелёк отправителя. Он использует наиболее приватную прорезь, через которую может пройти. Вы даёте один адрес для двери, и когда в доме появляется новый сейф, адрес на двери остаётся прежним.

## Подробности

### Связанные инструменты

- **Ключи просмотра.** У каждой учётной записи есть унифицированные ключи просмотра, которые позволяют увидеть, что получает UA (или всё, что он отправляет), без передачи права на расходование средств. Префиксы `uview` и `uivk`. См. [ключи просмотра](/zcash-tech/viewing-keys).
- **Адреса TEX.** Некоторые биржи, в настоящее время Binance, требуют, чтобы депозиты поступали из прозрачного источника. Адрес TEX ([ZIP 320](https://zips.z.cash/zip-0320)) — это прозрачный адрес-компаньон вашего UA именно для такого случая. См. [прозрачные адреса для бирж](/using-zcash/transparent-exchange-addresses).
- **Платёжные запросы.** UA можно встроить в URI платёжного запроса с заранее заполненными суммой и памяткой. См. [URI платёжных запросов](/using-zcash/payment-request-uris).

### Краткие сведения

| | |
|---|---|
| Префикс | `u1` (основная сеть) |
| Кодировка | bech32m |
| Определён в | [ZIP 316](https://zips.z.cash/zip-0316) |
| Представлен | NU5, 31 мая 2022 года |
| Содержит | получателей Ironwood, Sapling и прозрачного |
| Ключ расходования | Один на учётную запись, общий для всех её UA |

Узнайте, какие кошельки поддерживают унифицированные адреса, на странице [кошельки](/wallets).

## Распространённые ошибки

- **Использование старого адреса `zs` или `t`.** Отдельный адрес ведёт только в один пул и не получает новые. Делитесь своим UA.
- **Передача одного и того же UA всем.** Два человека, которые платят вам, могут сравнить данные и увидеть один и тот же адрес. Давайте каждому отправителю новый UA из своего кошелька.
- **Ожидание, что каждый платёж на UA будет приватным.** Отправитель, который может отправлять только прозрачные средства, платит на вашего прозрачного получателя, и этот платёж является публичным. Затем экранируйте его в своём кошельке.
