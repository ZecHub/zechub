# Руководство по майнингу Zcash: присоединение к майнинг-пулу с помощью личного оборудования

## Введение

Zcash (ZEC) — это криптовалюта, ориентированная на приватность, которая использует алгоритм доказательства работы Equihash для майнинга. Майнинг Zcash включает использование вычислительной мощности для решения сложных математических задач, подтверждения транзакций и защиты сети в обмен на вознаграждение в ZEC. Из-за высокой сложности сети соло-майнинг не рекомендуется большинству пользователей. Присоединение к майнинг-пулу — лучший способ получать стабильные вознаграждения, объединяя свой хешрейт с другими участниками.

Это руководство посвящено майнингу Zcash с использованием личного оборудования (например, домашнего ПК с GPU или ASIC начального уровня). Обратите внимание, что хотя GPU всё ещё могут майнить Zcash, в 2026 году ASIC значительно эффективнее и прибыльнее из-за сложности сети. Всегда проверяйте текущую прибыльность с помощью таких инструментов, как WhatToMine.com, поскольку на жизнеспособность влияют стоимость электроэнергии, цены на оборудование и стоимость ZEC. Майнинг может быть прибыльным не для всех; изучите местные нормы и тарифы на электроэнергию (ориентируйтесь на < $0.08/кВт⋅ч).


## Требования

### Оборудование
- **Майнинг на GPU (личная установка рекомендуется для новичков):**
  - GPU NVIDIA или AMD с минимум 4 ГБ VRAM (например, NVIDIA GTX 1070, RTX 3060; AMD RX 580 или лучше).
  - Совместимая материнская плата, достаточный блок питания (минимум 750 Вт для нескольких GPU) и хорошее охлаждение для предотвращения перегрева.
  - Установки с несколькими GPU распространены для достижения более высокого хешрейта (например, 6 GPU могут обеспечить 1–2 kSol/s).
- **Майнинг на ASIC (эффективнее, но дороже):**
  - ASIC, совместимые с Equihash, такие как Bitmain Antminer Z15 (420 kSol/s) или Innosilicon A9 (50 kSol/s).
  - Они более шумные, горячие и потребляют больше энергии (например, 1500 Вт+); подходят для отдельных помещений. Покупайте у надёжных источников, таких как Bitmain.com или реселлеры (Blockware Mining).
- **Общее:** Стабильный интернет, компьютер для настройки/мониторинга. ASIC доминируют в сети (~13 GSol/s общего хешрейта в 2026 году), из-за чего майнинг на GPU менее конкурентоспособен, но всё ещё возможен для энтузиастов.

### Программное обеспечение
- **Операционная система:** Windows 10/11, Linux (Ubuntu рекомендуется для стабильности).
- **Программное обеспечение для майнинга:**
  - Для GPU: lolMiner (поддерживает AMD/NVIDIA), GMiner или miniZ (ориентирован на NVIDIA). Загружайте из официальных репозиториев GitHub (например, github.com/Lolliedieb/lolMiner-releases).
  - Для ASIC: используйте встроенную прошивку/панель управления производителя (например, веб-интерфейс Bitmain).
- **Кошелёк:** Кошелёк Zcash для получения выплат. Рекомендуются:
  - Shielded (приватные): Zashi Wallet, Zingo (Mobile/Desktop) YWallet (mobile/desktop).
  - Transparent (проще, но менее приватные): Edge Wallet, Zecwallet Lite.
  - Загружайте с [кошельки](https://zechub.wiki/wallets). Создайте shielded-адрес (начинается с 'zs') для приватности, если пул его поддерживает.

### Прочее
- Электроэнергия: рассчитайте расходы. GPU потребляют 150–300 Вт на карту; ASIC — 1000 Вт+.
- Антивирус: отключите на время настройки, так как он может помечать майнеры как угрозы.

## Пошаговое руководство по присоединению к майнинг-пулу

### Шаг 1: Настройте ваш кошелёк Zcash
1. Загрузите и установите кошелёк с официального сайта Zcash [кошельки](https://zechub.wiki/wallets).
2. Создайте новый кошелёк и надёжно сохраните резервную копию seed-фразы.
3. Сгенерируйте адрес для получения средств (предпочтительно shielded для приватности). Запишите его, например: `zs1exampleaddress...`.
4. Если вы используете transparent-адрес (начинается с 't'), это проще, но обеспечивает меньшую приватность.

### Шаг 2: Подготовьте ваше оборудование
- Для GPU:
  1. Установите GPU в ваш ПК и обновите драйверы (NVIDIA: GeForce Experience; AMD: Radeon Software).
  2. Выполните разгон, если у вас есть опыт (используйте MSI Afterburner для стабильности; ориентируйтесь на +100–200 по частоте ядра, -500 по памяти для эффективности).
- Для ASIC:
  1. Подключите ASIC к питанию и Ethernet.
  2. Найдите его IP-адрес с помощью таких инструментов, как Advanced IP Scanner или приложения производителя.
  3. Откройте веб-панель управления (например, введите IP в браузере, логин по умолчанию: root/root для Bitmain).

**Предупреждение:** Обеспечьте надлежащую вентиляцию; майнинг выделяет тепло. Начинайте с малого, чтобы протестировать всё.

### Шаг 3: Выберите и подключитесь к майнинг-пулу
Майнинг-пулы распределяют работу и делят вознаграждения в зависимости от внесённого вами хешрейта. Выбирайте на основе комиссий (0–2%), минимальной выплаты (0.01–0.1 ZEC), расположения (низкий пинг) и надёжности.

**Рекомендуемые пулы (на основе хешрейта, комиссий и отзывов):**
- **2Miners (zec.2miners.com)**: комиссия 1%, выплаты PPLNS, поддержка GPU/ASIC/NiceHash. Высокий хешрейт (~1.17 GSol/s), надёжные серверы.
- **F2Pool (zec.f2pool.com)**: комиссия 2%, выплаты PPS+, поддержка нескольких монет. Крупный пул (~2.57 GSol/s).
- **ViaBTC (zec.viabtc.com)**: комиссия 2% (PPS+), удобная панель управления, глобальные серверы.
- **AntPool (zec.antpool.com)**: комиссия 1%, от Bitmain, хорошо подходит для ASIC (~494 MSol/s).
- **Sovright (mining.sovright.com)**: пул Zcash, построенный на Stratum V2, в настоящее время работает как публичный testnet. Живых выплат в ZEC пока нет, поэтому рассматривайте его как способ протестировать вашу настройку, а не как источник дохода. Подробности смотрите в специальном разделе ниже.
- Другие: Kryptex Pool, Luxor (проверяйте poolwatch.io/coin/zcash для статистики в реальном времени).

1. Перейдите на сайт пула и создайте аккаунт (по email или без регистрации, как у некоторых, например 2Miners).
2. Добавьте адрес вашего кошелька Zcash в настройки для выплат.
3. Запишите stratum-сервер пула (например, zec.2miners.com:1010) и порт.

### Шаг 4: Установите и настройте программное обеспечение для майнинга
- Для GPU (пример: lolMiner на Windows/Linux):
  1. Загрузите lolMiner с GitHub (последнюю версию, например 1.88).
  2. Распакуйте в папку.
  3. Создайте batch-файл (start.bat) с конфигурацией:
     ```
     lolMiner.exe --coin ZEC --pool zec.2miners.com:1010 --user YOUR_WALLET_ADDRESS.WORKER_NAME --pass x
     ```
     - Замените `YOUR_WALLET_ADDRESS` на ваш адрес ZEC.
     - `WORKER_NAME`: имя для вашей установки (например, Rig1).
     - Для серверов ЕС: eu.zec.2miners.com:1010.
  4. Запустите batch-файл. Он подключится к пулу и начнёт майнинг.
- Для ASIC (пример: Bitmain Antminer):
  1. Войдите в веб-панель управления.
  2. Перейдите в Miner Configuration.
  3. Добавьте данные пула:
     - URL: stratum+tcp://zec.2miners.com:1010
     - Username: YOUR_WALLET_ADDRESS.WORKER_NAME
     - Password: x (или пусто).
  4. Сохраните настройки и перезагрузите майнер.
- Для другого ПО (например, GMiner):
  ```
  miner.exe --algo 125_4 --server zec.2miners.com:1010 --user YOUR_WALLET_ADDRESS.WORKER_NAME --pass x
  ```

**Тест:** Дайте поработать 10–15 минут; проверьте консоль на наличие принятых шар и хешрейта.

### Шаг 5: Запустите майнинг и мониторьте
1. Запустите майнер: он подключится к пулу и начнёт отправлять шары.
2. Мониторинг через:
   - Панель управления пула: введите адрес вашего кошелька, чтобы увидеть хешрейт, невыплаченный баланс и статистику.
   - Консоль программы: следите за ошибками, температурой (держите < 80 градусов C).
   - Инструменты: используйте HiveOS или SimpleMining OS для удалённого управления установкой.
3. Выплаты: большинство пулов выплачивают автоматически, когда вы достигаете минимума (например, 0.05 ZEC). Проверяйте правила пула.

## Sovright: testnet-пул и сеть ретрансляции

Sovright (sovright.com) управляет майнинг-пулом Stratum V2 и отдельной сетью ретрансляции блоков. Они выполняют разные задачи, поэтому рассматриваются отдельно ниже.

### Майнинг-пул (mining.sovright.com)

Пул Sovright работает в публичном testnet Zcash (NU6, Stratum V2), а не в mainnet. Testnet не выплачивает реальные ZEC. Используйте его для тестирования конфигурации майнера, а не для заработка.

- Для начала не требуется аккаунт. Направьте CPU- или ASIC-майнер Equihash на пул, и ваши шары появятся на панели в реальном времени.
- Sovright также публикует open source прокси Stratum V2 для майнеров, которые хотят выбирать собственные шаблоны блоков, а не просто брать задания пула:
  ```
  git clone https://github.com/sovright/mining-infra
  cd mining-infra
  cargo build --release -p sovright-v1-stratum-proxy
  ./target/release/sovright-v1-stratum-proxy --listen 0.0.0.0:3334 --upstream 34.28.134.13:3333
  ```
  Направьте ваш майнер на прокси вместо прямого подключения к пулу:
  ```
  stratum+tcp://<your-proxy-ip>:3334
  ```
  используя имя воркера вроде `yourname.rig1`.
- На странице прозрачности Sovright указана политика «include all» для shielded-транзакций, в отличие от некоторых пулов, которые их отфильтровывают. Каждый блок получает подписанную аттестацию, так что политику можно проверять независимо.
- Создайте аккаунт на mining.sovright.com (вход через Google или email), чтобы отслеживать собственных воркеров вместо демонстрационных данных панели.

### Сеть ретрансляции (relay.sovright.com)

Sovright отдельно управляет публичной сетью ретрансляции блоков в mainnet Zcash. Когда пул находит блок, скорость, с которой этот блок достигает остальной сети, определяет, как часто он становится orphaned, то есть проигрывает гонку распространения, и вознаграждение за него теряется. Сеть ретрансляции пересылает блоки через четыре региона, используя compact block relay с прямой коррекцией ошибок.

Публичная панель показывает эффект в реальном времени: регионы, подключённые к relay, получают новые блоки намного быстрее, чем при обычном peer-to-peer gossip, а панель отслеживает текущий orphan rate сети.

Это инфраструктура для операторов пулов, а не для отдельных майнеров. В open source репозитории `mining-infra` Sovright задокументирован шлюз ретрансляции `submitblock` для отправки найденных блоков в mesh быстрее, чем нативный P2P. Для подключения свяжитесь с Sovright напрямую (support@sovright.com), чтобы получить адреса relay-пиров и auth key.


## Советы и лучшие практики
- **Прибыльность:** Используйте калькуляторы, такие как whattomine.com/coins/166-zec-equihash. Пример: RTX 3060 (~300 Sol/s) приносит ~0.001 ZEC/день при $50/ZEC, минус ~$0.50 за электричество.
- **Приватность:** Используйте shielded-пулы, если они доступны; избегайте повторного использования адресов.
- **Безопасность:** Используйте надёжные пароли; включайте 2FA в пулах/кошельках. Никогда не делитесь приватными ключами.
- **Устранение неполадок:** Если нет шар, проверьте firewall, антивирус или неверную конфигурацию. Присоединяйтесь к форумам, таким как forum.zcashcommunity.com или Reddit r/zec.
- **Альтернативы:** Если майнинг неприбылен, рассмотрите cloud mining или стейкинг других монет.
- **Экологическое примечание:** Майнинг потребляет энергию; по возможности используйте возобновляемые источники.
- **Обновления:** Zcash может развиваться дальше (например, возможен переход на PoS); следите за новостями на z.cash.
