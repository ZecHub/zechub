## A

| Term | Definition |
|------|-----------|
| Actions | Вместо создания нескольких отдельных доказательств для каждого Spend и Output, протокол Orchard объединяет их в одно Action. |
| Addresses | В Zcash есть экранированные адреса (Shielded, Z/zaddr) и прозрачные адреса (Transparent, T/taddr). Unified addresses (UA) постепенно заменяют Z и T после обновления NU5. |
| Arborist Call | Созвон раз в две недели, посвящённый обновлениям разработки протокола Zcash и исследовательской деятельности. Проводится на форуме сообщества Zcash и в Discord. [Заметки встреч](https://github.com/ZcashCommunityGrants/arboretum-notes) / [Объявления на форуме](https://forum.zcashcommunity.com) |
| Auto-shielding | Позволяет пользователям (точнее, их кошелькам) автоматически переводить средства с прозрачного адреса в новейший экранированный пул ZEC. |

## B

| Term | Definition |
|------|-----------|
| Benchmarking | Майнеры могут отправлять метрики об эффективности различного оборудования, используемого для майнинга Zcash. [Смотреть здесь](https://zcashbenchmarks.info) |
| Block | Блок — это запись в блокчейне Zcash, содержащая набор транзакций, отправленных в сети. В среднем примерно каждые 75 секунд в блокчейн добавляется новый блок. |
| Block Explorer | Онлайн-инструмент для просмотра всех транзакций в блокчейне, как прошлых, так и текущих. [Обозреватель блоков Zcash](https://zcashexplorer.app/) |
| Blogs | [Блог ZODL (ранее Electric Coin Co)](https://zodl.com/blog/) / [Блог Zcash Foundation](https://zfnd.org/blog/) / [Блог ZecHub](https://zechub.wiki/zechub-dao) |
| Blossom | 3-е крупное сетевое обновление Zcash. [Подробнее](https://zcash.readthedocs.io/en/latest/rtd_pages/nu_dev_guide.html?highlight=orchard#blossom) |

[Сайт Cypherpunk Zero](https://halo.electriccoin.co/?utm_source=ECC&utm_medium=Website&utm_campaign=None) / [Коллекция Opensea](https://opensea.io/collection/cypherpunk-zero) |

## D

| Term | Definition |

## E

| Term | Definition |
|------|-----------|
| ECC | Electric Coin Company, команда, стоящая за протоколом Zcash, ранее известная как Zcash Company. |
| ECDSA | Elliptic Curve Digital Signature Algorithm — это криптографически защищённая схема цифровой подписи. Алгоритм подписи/проверки ECDSA опирается на умножение точек эллиптической кривой. |
| Education | Обучающие видео с объяснением Zcash доступны [здесь](https://www.zcashcommunity.com/zcash-education/) |
| Encrypted Memos | Дополнительное поле для транзакций, отправляемых на экранированные адреса, которое видно получателю платежа. Зашифрованная заметка видна только отправителю и получателю. |
| Equihash | Алгоритм майнинга proof-of-work, ориентированный на память, который используется в Zcash. |
| Events | Календарь событий, связанных с Zcash, можно посмотреть на [Luma](https://luma.com/zcash) и [Zcash Foundation](https://zfnd.org/zf-events/) |
| Exchanges | [Список бирж, поддерживающих Zcash](https://z.cash/exchanges/) |

## F

| Term | Definition |
|------|-----------|
| Fiat-Shamir | Техника преобразования интерактивного доказательства знания в цифровую подпись, основанную на нём. Таким образом можно публично доказать некоторый факт (например, знание секрета), не раскрывая лежащую в основе информацию. |
| Founders Reward | Вознаграждение основателей составляет 20 процентов от общего вознаграждения за блок; оно вычитается из стоимости каждого блока и прозрачно распределяется для развития и роста протокола. |
| Free2z | Инструмент для анонимного контента и приватных пожертвований на базе Zcash. [Free2z](https://free2z.com) |
| FROST | Flexible Round-Optimized Schnorr Threshold — схема пороговой подписи Шнорра. [Исследовательская статья](https://eprint.iacr.org/2020/852) |

## G

| Term | Definition |
|------|-----------|
| Governance | Решения из процесса ZIP записываются в спецификацию Zcash, а также в программное обеспечение, на котором работает сеть. Изменения утверждаются в блокчейне, когда большинство сети принимает обновление и не нарушает консенсус. [Полная история протокола](https://zfnd.org/protocol-governance/) |

## H

| Term | Definition |
|------|-----------|
| Halo | Позволяет обновлять схемы без необходимости в trusted setup, делая экранированный протокол Zcash более гибким для будущих улучшений и расширений. [Техническое объяснение](https://z.cash/learn/what-is-halo-for-zcash/) |
| HD Wallet | Иерархически детерминированные кошельки генерируют серию пар ключей из одной seed-фразы, обеспечивая удобство, управляемость и высокий уровень безопасности. |
| Heartwood | 4-е крупное сетевое обновление Zcash. [Подробнее](https://z.cash/upgrade/heartwood/) |

## I

| Term | Definition |

| Integrations | Вы можете принимать платежи в Zcash через ряд сторонних провайдеров. [Платёжные процессоры](https://z.cash/zcash-for-business/) |
| Interactive Proof System | Абстрактная машина, моделирующая вычисления как обмен сообщениями между двумя сторонами: Prover и Verifier. |
| Investment | Для институциональных инвесторов или family office, желающих получить доступ к Zcash, доступен ряд финансовых инструментов. [Полный список](https://z.cash/investors/) |

## J

| Term | Definition |
|------|-----------|
| JubJub | Эллиптическая кривая, разработанная для эффективной реализации в схемах zk-SNARK. |

## K

| Term | Definition |
|------|-----------|
| Keystone Wallet | Аппаратный кошелёк с воздушным зазором и нативной поддержкой Zcash (Orchard shielded), совместимый с ZODL для холодной подписи. [Keystone](https://keyst.one) |

## L

| Term | Definition |
|------|-----------|
| Layer-1 | Относится к базовой сети и лежащей в её основе инфраструктуре. Блокчейны Layer-1 могут проверять и финализировать транзакции без необходимости в другой сети. Zcash — это блокчейн L1. |
| librustzcash | Рабочее пространство Rust, содержащее все crates и зависимости для работы с Zcash. [репозиторий](https://github.com/zcash/librustzcash) |
| Lightwalletd | Stateless-сервер, который предоставляет лёгким клиентам информацию о блокчейне. [Lightwalletd](https://zcash.readthedocs.io/en/latest/rtd_pages/lightclient_support.html) |

## M

| Term | Definition |
|------|-----------|
| Metrics | Метрики сети доступны [здесь](https://tokenterminal.com/explorer/projects/zcash/metrics/all) |
| Metadata | Данные, которые создаются вместе с транзакцией пользователя в Zcash. Это может включать высоту блока, версию транзакции, высоту истечения и т. д. |
| Mobile SDK | Лёгкий SDK, который подключает Android к Zcash, позволяя сторонним Android-приложениям отправлять и получать экранированные транзакции. [Github](https://github.com/zcash/zcash-android-wallet-sdk) |
| Mining | Процесс, в котором для каждого блока узлы сети Zcash соревнуются, выполняя сложные математические вычисления, чтобы найти решение на основе самонастраивающейся сложности. [Руководство](https://z.cash/mining-zcash/) |
| Multisignature | Адрес, для расходования средств с которого требуется несколько подписей приватными ключами. В настоящее время функциональность multisig поддерживается только прозрачными адресами. |

## N

| Term | Definition |
|------|-----------|
| Nighthawk | Мобильный кошелёк для Zcash. [Сайт](https://nighthawkwallet.com) |
| NU5 | 6-е крупное сетевое обновление Zcash, вводящее экранированный пул Orchard и Unified Addresses. [Подробнее](https://zcash.readthedocs.io/en/latest/rtd_pages/nu_dev_guide.html#nu5) |
| NU6 | 7-е крупное сетевое обновление Zcash, корректирующее субсидию за блок для финансирования программы Zcash Community Grants и Shielded Labs. Активировано в конце 2024 года. [Подробнее](https://zcash.readthedocs.io/en/latest/rtd_pages/nu_dev_guide.html#nu6) |
| NU7 | Предстоящее 8-е крупное сетевое обновление Zcash. В 2026 году через ZODL открыто голосование по настроениям сообщества. Ожидается, что оно будет включать дальнейшие улучшения экранированного пула и обновления управления. [Обсуждение на форуме](https://forum.zcashcommunity.com/t/nu7-sentiment-polling-questions-for-community-review-coinholder-voting-via-zodl/55713) |

| Overwinter | 1-е сетевое обновление Zcash. [Подробнее](https://zcash.readthedocs.io/en/latest/rtd_pages/nu_dev_guide.html#overwinter) |

## P

| Term | Definition |
|------|-----------|
| Payments | Можно использовать Zcash для повседневных покупок через ряд различных платёжных провайдеров. [Платёжные приложения](https://z.cash/pay-with-zcash/) |
| Peer-to-Peer Network | Сети P2P основаны на концепции децентрализации. Это базовая архитектура технологии блокчейн. |

## Q

| Term | Definition |
|------|-----------|
| QR Code | Машиночитаемый код, используемый для кодирования адресов Zcash для удобного сканирования. Unified Addresses (UA) обычно передаются через QR-коды в современных кошельках Zcash. |

## R

| Term | Definition |
|------|-----------|
| Recovery Phrase | Последовательность из 12 или 24 букв и цифр, используемая для резервного копирования и восстановления кошелька. В Zcash эта фраза заново генерирует ключи расходования и Viewing Key, что делает её критически важной для восстановления средств и безопасности. |

## S

| Term | Definition |
|------|-----------|
| Sapling | Крупное сетевое обновление, которое внесло значительные улучшения эффективности экранированных транзакций и проложило путь к мобильному использованию. Активировано на блоке 419200. |
| Selective Disclosure | Позволяет владельцу экранированного адреса выборочно делиться viewing keys или раскрытиями платежей с третьими лицами, сохраняя данные приватными для всех остальных. |
| Shielded Address | Также называется zaddr. Начинается с z. Скрывает отправителя, получателя, сумму и memo с помощью zk-SNARKs. |
| Shielded Transaction | Транзакция исключительно между экранированными адресами. Полностью приватна в блокчейне. |
| Sol/s | Решений в секунду — измеряет производительность майнинга Equihash. |
| Spending Key | Приватный ключ, который позволяет тратить средства с экранированного адреса (а также просматривать баланс и историю). |
| Sprout | Изначальная версия экранированного протокола Zcash (запущена в 2016 году). |

## T

| Term | Definition |
|------|-----------|
| TAZ | Testnet Zcash (тестовая валюта без стоимости). |
| Testnet | Отдельный блокчейн для тестирования обновлений и функций перед запуском в основной сети. |
| Transaction | Платёж между пользователями, отправляемый в сеть и в конечном итоге подтверждаемый в блоке. |
| Transaction Expiry | Транзакции истекают примерно через 25 минут (20 блоков), если не подтверждены; средства возвращаются автоматически. |
| Transaction Fee | Комиссия по умолчанию составляет 0.0001 ZEC. Более высокие комиссии получают приоритет; очень низкие комиссии могут вызывать задержки или истечение срока действия. |
| Transparent Address | Также называется taddr. Начинается с t. Полностью публичный (как Bitcoin). |
| Transparent Transaction | Транзакция исключительно между прозрачными адресами — всё публично видно. |

## U

| Term | Definition |
|------|-----------|
| Unified Address | Современный формат адреса (введён в NU5), который работает и для прозрачных, и для экранированных платежей в одной строке. |
| Upgrade Activation | Конкретная высота блока, на которой сетевое обновление (например, NU5, NU6) активируется автоматически. |

## V

| Term | Definition |
|------|-----------|
| Viewing Key | Приватный ключ, который позволяет просматривать баланс и историю транзакций экранированного адреса без возможности тратить средства. |

## W

| Term | Definition |
|------|-----------|
| Wallet | Программное или аппаратное средство, которое хранит приватные ключи и позволяет отправлять/получать ZEC. Активные кошельки включают ZODL (iOS/Android), Zingo! (mobile/desktop), Nighthawk (Android), YWallet, Zallet (в разработке) и Keystone (аппаратный). Полный список см. в [Кошельки экосистемы Zcash](https://z.cash/ecosystem/?wallets=#tag-wallets) |

## X

| Term | Definition |
|------|-----------|
| XZC | Старый тикер Zcash, используемый на некоторых устаревших биржах. Официальный тикер — ZEC. |

## Y

| Term | Definition |
|------|-----------|
| YWallet | Высокопроизводительный, ориентированный на приватность кошелёк Zcash с поддержкой Orchard, Sapling и прозрачных адресов. Известен высокой скоростью синхронизации. Доступен для iOS и Android. [YWallet](https://ywallet.app) |

## Z

| Term | Definition |
|------|-----------|
| Zcash | Криптовалюта, ориентированная на приватность, использующая zk-SNARKs. Соединяет прозрачные платежи в стиле Bitcoin и полностью экранированные платежи. |
| Zcash Foundation | Независимая некоммерческая организация, поддерживающая экосистему Zcash, финансирующая разработку и продвигающая приватность. |
| Zcash Network | Одноранговая сеть узлов, которая проверяет транзакции и поддерживает блокчейн. |
| ZEC | Официальный валютный код Zcash (на некоторых биржах всё ещё отображается XZC). |
| Zerocash | Академический протокол (2014), на котором основан Zcash. |
| Zaino | Индексатор Zcash нового поколения, заменяющий lightwalletd, созданный Zcash Foundation. Позволяет лёгким клиентам синхронизироваться быстрее и более приватно. Является частью обновления инфраструктуры Zcash Z3. |
| Zallet | Будущий официальный кошелёк Zcash от команды Electric Coin Co / ZODL, построенный на Zaino. Zallet Alpha находится в активной разработке по состоянию на 2026 год. [Форум](https://forum.zcashcommunity.com/t/zcash-z3-updates-formerly-zcashd-deprecation/48965) |
| Zebra | Реализация полного узла Zcash на Rust от Zcash Foundation (альтернатива zcashd). Готова к промышленному использованию и активно поддерживается. [GitHub](https://github.com/ZcashFoundation/zebra) |
| ZIP | Zcash Improvement Proposal — процесс управления сообществом, используемый для предложения и утверждения изменений протокола. [Репозиторий ZIP](https://github.com/zcash/zips) |
| ZODL | Новое название потребительских продуктов Electric Coin Company, включая приложение-кошелёк ZODL (ранее назывался ECC Wallet) и платформу управления ZODL для опросов держателей монет. [zodl.com](https://zodl.com) |
| zk-SNARKs | Zero-Knowledge Succinct Non-Interactive Arguments of Knowledge — криптография, обеспечивающая экранированные транзакции Zcash. Позволяет доказать утверждение (например, корректное расходование), не раскрывая никакой секретной информации. |
