## A

| Term | Definition |
|------|-----------|
| Actions | Вместо создания нескольких отдельных доказательств для каждого Spend и Output, протокол Orchard объединяет их в одно Action. |
| Addresses | В Zcash есть экранированные адреса (Shielded, Z/zaddr) и прозрачные адреса (Transparent, T/taddr). Unified addresses (UA) постепенно заменяют Z и T после обновления NU5. |
| Arborist Call | Созвон раз в две недели, посвящённый обновлениям разработки протокола Zcash и исследовательской деятельности. Проводится на форуме сообщества Zcash и в Discord. | Auto-shielding | Позволяет пользователям (точнее, их кошелькам) автоматически переводить средства с прозрачного адреса в новейший экранированный пул ZEC. |

## F

| Term | Definition |
|------|-----------|

## Q

| Term | Definition |
|------|-----------|
| QR Code | Машиночитаемый код, используемый для кодирования адресов Zcash для удобного сканирования. Unified Addresses (UAs) обычно передаются через QR-коды в современных кошельках Zcash. |
| Quantum Recoverability | Свойство заметок Ironwood, указанное в [ZIP 2005](https://zips.z.cash/zip-2005), которое сохраняет возможность восстановить запись монеты в блокчейне, если будущий квантовый компьютер взломает криптографию, защищающую её сегодня. Это путь восстановления, а не квантовая устойчивость, и он применяется к заметкам Ironwood, а не к существующим средствам Sprout, Sapling или Orchard. |

## T

| Term | Definition |
|------|-----------|
| Tachyon | Программа масштабирования Zcash, ориентированная на NU7. Она переводит кошельки от сканирования каждого блока к состоянию кошелька с доказательствами, oblivious synchronization и состоянию узла с возможностью обрезки, с целью достичь пропускной способности экранированных транзакций в тысячи транзакций в секунду. [Сайт проекта](https://tachyon.z.cash/overview/) |
| TAZ | Testnet Zcash (тестовая валюта без стоимости). |
| Testnet | Отдельный блокчейн для тестирования обновлений и функций перед запуском в основной сети. |
| Trailing Finality Layer (TFL) | Исследование по добавлению слоя финализации поверх цепочки доказательства выполнения работы Zcash, чтобы недавние блоки можно было финализировать без замены майнинга. Crosslink — это проектное решение, возникшее в результате этой работы. |
| Transaction | Платёж между пользователями, отправляемый в сеть и в конечном итоге подтверждаемый в блоке. |
| Transaction Expiry | Транзакции истекают примерно через 25 минут (20 блоков), если не подтверждены; средства возвращаются автоматически. |
| Transaction Fee | Комиссия по умолчанию составляет 0.0001 ZEC. Более высокие комиссии получают приоритет; очень низкие комиссии могут вызывать задержки или истечение срока действия. |
| Transparent Address | Также называется taddr. Начинается с t. Полностью публичный (как Bitcoin). |
| Transparent Transaction | Транзакция исключительно между прозрачными адресами — всё публично видно. |
| Turnstile | Правило учёта, которое отслеживает, сколько ценности входит в каждый экранированный пул и выходит из него, чтобы ни один пул не мог выпустить больше, чем в него поступило. Используется при каждом переходе между пулами в истории Zcash и в настоящее время защищает миграцию из Orchard в Ironwood. [Подробнее](/zcash-tech/the-turnstile) |

## U

| Term | Definition |
|------|-----------|
| Unified Address | Современный формат адреса (введён в NU5), который работает и для прозрачных, и для экранированных платежей в одной строке. |
| Upgrade Activation | Конкретная высота блока, на которой сетевое обновление (например, NU5, NU6) активируется автоматически. |

## V

| Term | Definition |
|------|-----------|
| Viewing Key | Приватный ключ, который позволяет просматривать баланс и историю транзакций экранированного адреса без возможности тратить средства. |

## W

| Термин | Определение |
|------|-----------|
| Кошелёк | Программное или аппаратное средство, которое хранит приватные ключи и позволяет отправлять/получать ZEC. Активные кошельки включают ZODL (iOS/Android), Zingo! (mobile/desktop), Nighthawk (Android), YWallet, Zallet (в разработке) и Keystone (аппаратный). Полный список см. в [Кошельки экосистемы Zcash](https://z.cash/ecosystem/?wallets=#tag-wallets) |
| WebZjs | Первый JavaScript SDK для Zcash, созданный ChainSafe для браузерных сред. Он лежит в основе snap-а Zcash Shielded Wallet, который привнёс экранированный ZEC в MetaMask. |

## X

| Term | Definition |
|------|-----------|
| XZC | Старый тикер Zcash, используемый на некоторых устаревших биржах. Официальный тикер — ZEC. |

## Y

| Term | Definition |
|------|-----------|
| YWallet | Ориентированный на приватность кошелёк Zcash с поддержкой Orchard, Sapling и прозрачных адресов, известный быстрой синхронизацией. Больше не поддерживается: его разработчик подтвердил, что он не будет обновлён для Ironwood, поэтому больше не может следовать за сетью. Zkool от того же разработчика — поддерживаемый преемник. |

## Z

| Term | Definition |
|------|-----------|
| Zcash | Криптовалюта, ориентированная на приватность, использующая zk-SNARKs. Соединяет прозрачные платежи в стиле Bitcoin и полностью экранированные платежи. |
| Zcash Foundation | Независимая некоммерческая организация, поддерживающая экосистему Zcash, финансирующая разработку и продвигающая приватность. |
| Zcash Network | Одноранговая сеть узлов, которая проверяет транзакции и поддерживает блокчейн. |
| ZEC | Официальный валютный код Zcash (на некоторых биржах всё ещё отображается XZC). |
| Zerocash | Академический протокол (2014), на котором основан Zcash. |
| Zaino | Индексатор Zcash нового поколения, заменяющий lightwalletd, созданный Zcash Foundation. Позволяет лёгким клиентам синхронизироваться быстрее и более приватно. Является частью обновления инфраструктуры Zcash Z3. |
| Zakura | Реализация полного узла Zcash, выпущенная в июле 2026 года, созданная как форк Zebra группой Valar Group и Project Tachyon. Ориентирована на высокую пропускную способность и скорость синхронизации, с загрузкой начального состояния из snapshot и заявленной целью достичь масштаба карточных сетей — около 50 000 транзакций в секунду. [zakura.com](https://zakura.com) |
| Zallet | Компонент кошелька, который взял на себя функции кошелька zcashd после его вывода из эксплуатации, построенный на Zaino как часть работ по инфраструктуре Zcash Z3. |
| Zebra | Реализация полного узла Zcash на Rust от Zcash Foundation (альтернатива zcashd). Готова к промышленному использованию и активно поддерживается. [GitHub](https://github.com/ZcashFoundation/zebra) |
| zcashd | Исходный полный узел Zcash, ответвлённый от Bitcoin Core. Выведен из эксплуатации в июле 2026 года после длительного периода устаревания, при этом его роли были разделены между Zebra для консенсуса и Zallet для функций кошелька. |
| ZIP | Zcash Improvement Proposal — процесс управления сообществом, используемый для предложения и утверждения изменений протокола. [Репозиторий ZIP](https://github.com/zcash/zips) |
| ZODL | Zcash Open Development Lab. Независимая организация, основанная в начале 2026 года Джошем Свихартом и бывшей инженерной командой Electric Coin Company после их ухода из-за спора об управлении с Bootstrap. В марте 2026 года она привлекла более 25 миллионов долларов посевного финансирования и поддерживает кошелёк Zodl, который был переименован из Zashi в феврале 2026 года. [zodl.com](https://zodl.com) |
| zk-SNARKs | Zero-Knowledge Succinct Non-Interactive Arguments of Knowledge — криптография, обеспечивающая экранированные транзакции Zcash. Позволяет доказать утверждение (например, корректное расходование), не раскрывая никакой секретной информации. |
| ZSA (Zcash Shielded Assets) | Выпускаемые пользователями токены, которые наследуют экранированную приватность Zcash, позволяя активам помимо ZEC перемещаться по сети приватно. Описаны в [ZIP 226](https://zips.z.cash/zip-0226) и рассматриваются как кандидатная функция для NU7. |
