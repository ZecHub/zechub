# Zcash Обновления сети

Zcash развивается благодаря обновлениям сети — согласованным изменениям правил, которые принимает каждый узел и которые активируются на заданной высоте блока. Для каждого обновления ниже есть отдельная страница, где простым языком объясняется, что оно изменило и почему. Впервые знакомитесь с Zcash? Читайте страницы по порядку: от Sprout до Ironwood.

Наглядную историю изменений конфиденциальности Zcash в ходе этих обновлений см. в материале [Эволюция конфиденциальности](https://zechub.wiki/zcash-evolution). Эта страница — указатель, а та — хронология.

### Состояние NU7

NU7 активировалось в Mainnet на высоте **3,543,405** ([ZIP 259](https://zips.z.cash/zip-0259)) **6 ноября 2026 года** (02:34 UTC; в часовых поясах США это был вечер 5 ноября). Ранее обновление заработало в публичной Testnet на высоте **4,465,026** (4 октября 2026 года).

Состав обновления (ZIP 259):

- **Блоки каждые 25 секунд** (ZIP 218) — первое подтверждение примерно в 3 раза быстрее; ежедневная эмиссия ZEC не меняется.
- **Механизм устойчивого развития сети** (ZIP 235 + ZIP 237) — 60% комиссий за транзакции изымается из обращения и направляется в резерв, откуда средства будут повторно выпускаться майнерам по графику с сохранением периодичности уменьшения награды вдвое, начиная примерно с февраля 2031 года.
- **Вывод Sprout из обращения** (ZIP 2003) — транзакции версии 4 становятся недействительными; оставшиеся средства Sprout нельзя будет потратить.
- Лимиты на действия с защитой и более широкое окно усреднения сложности (17 → 102 блока).

Новый формат транзакций не вводится. Идентификатор ветви консенсуса: `0x77190ad9`.

Полное описание см. в хронологии [«Эволюция конфиденциальности»](https://zechub.wiki/zcash-evolution) и [ZIP 259](https://zips.z.cash/zip-0259). Хронология на форуме: [NU7 Хронология](https://forum.zcashcommunity.com/t/nu7-timeline/57655).
