# Zcash: обновления сети

Zcash совершенствуется посредством обновлений сети: скоординированных изменений правил, с которыми согласен каждый узел и каждое из которых активируется на заданной высоте блока. Для каждого указанного ниже обновления есть собственная страница, где простым языком объясняется, что именно оно изменило и почему. Впервые знакомитесь с Zcash? Читайте их по порядку — от Sprout до Ironwood.

Визуальную историю развития конфиденциальности Zcash в ходе этих обновлений смотрите в разделе [Эволюция конфиденциальности](https://zechub.wiki/zcash-evolution). Эта страница — указатель. Та — временная шкала.

### Статус NU7

NU7 работает в публичной Testnet на высоте **4,465,026** (активировано 4 октября 2026 года). Высота активации Mainnet будет выбрана **20 октября 2026 года**; текущая цель — **5 ноября 2026 года**.

Область действия (ZIP 259):

- **25-секундные блоки** (ZIP 218) — первое подтверждение примерно в 3 раза быстрее; ежедневная эмиссия ZEC не изменяется.
- **Механизм устойчивости сети** (ZIP 235 + ZIP 237) — 60% комиссий за транзакции изымаются из обращения в резерв и повторно выпускаются майнерам по графику, сохраняющему уменьшение награды вдвое, начиная примерно с февраля 2031 года.
- Вывод Sprout из эксплуатации (ZIP 2003) — транзакции версии 4 становятся недействительными; оставшиеся средства Sprout становятся непригодными для расходования.
- Ограничения на экранированные действия и более широкое окно усреднения сложности (17 → 102 блока).

Новый формат транзакций не вводится. Идентификатор ветви консенсуса: `0x77190ad9`.
