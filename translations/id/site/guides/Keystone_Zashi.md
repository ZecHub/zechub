## Persiapan
Pesan & Terima Keystone 3 Pro atau Keystone 3](https://keyst.one) milikmu dari [

Level Baterai: Pastikan perangkat keystone kamu memiliki level baterai di atas 20%.

Kabel USB atau Kartu SD:

- Kabel USB untuk pembaruan firmware (sudah termasuk).
- Kartu Micro SD (di bawah 1 TB) untuk peningkatan (dibeli terpisah).

Akses ke situs web resmi Keystones untuk Verifikasi dan Pembaruan Firmware.

Pengaturan aplikasi Zashi di perangkat seluler kamu.

## Panduan Langkah demi Langkah (Perangkat Keystone) [](https://keyst.one/get-started)


**Pilih Bahasa Kamu**
-Verifikasi Perangkat(via QR): Verifikasi Perangkat sangat krusial untuk mendeteksi potensi kontaminasi selama transportasi, mencegah serangan rantai pasokan, dan memastikan keamanan firmware yang terinstal.
  - Kunjungi halaman Verifikasi Perangkat di situs web Keystone.
  - Klik Scan QR Code pada situs web resmi.
  - Gunakan kamera Keystone kamu untuk memindai kode QR yang ditampilkan di situs web.
  - Kode verifikasi akan muncul di layar Keystone kamu.
  - Masukkan kode ini di situs web untuk menyelesaikan proses verifikasi.

- **Pembaruan Firmware:**
  - Pembaruan via kartu MicroSD
    - Pastikan dompet Keystone kamu memiliki daya baterai setidaknya 20%.
    - Masukkan kartu SD ke komputer kamu dan format sebagai FAT32.
    - Unduh versi firmware Cypherpunk terbaru dari halaman Pembaruan Firmware [Keystone](https://keyst.one/firmware) dan simpan file keystone3.bin ke root kartu MicroSD kamu.
    - Masukkan kartu SD berisi firmware tersebut ke dalam dompet Keystone kamu.
    - Akses opsi "Upgrade" pada dompet Keystone kamu, lalu ikuti instruksi di layar untuk memulai proses pembaruan.
  - **Pembaruan via Kabel USB**
    - Jika versi firmware kamu di bawah 1.0.4, kamu perlu melakukan pembaruan awal menggunakan kartu MicroSD sebelum dapat melanjutkan dengan pembaruan USB.
    - Pastikan dompet Keystone kamu memiliki daya baterai setidaknya 20%.
    - Ketuk via USB dan gunakan kabel USB untuk menghubungkan dompet Keystone kamu ke komputer. Ketuk [Approve] untuk memberikan akses USB pada dompet Keystone kamu, karena jika tidak, perangkat mungkin hanya akan mengizinkan pengisian daya.
    - Buka browser web komputer kamu dan buka halaman Pembaruan Firmware [Keystone](https://keyst.one/firmware)
    - Pada halaman pembaruan, klik tombol Install Update dan ikuti instruksi yang tersedia untuk menginstal firmware terbaru.
- **Membuat Dompet:**
    - Kata Sandi Aman: Pilih PIN atau kata sandi yang kuat untuk melindungi dompet kamu.
    - Beri Nama Dompet Kamu (Opsional): Kamu dapat memberi nama pada dompet kamu agar mudah diidentifikasi atau lewati langkah ini.
    - Pilih Create New Wallet jika kamu sedang menyiapkan dompet untuk pertama kalinya.
    - Perangkat kamu akan menghasilkan frasa pemulihan berisi 24 kata.
    - Tulis frasa pemulihan ini dan simpan dengan aman.
    - Konfirmasi frasa pemulihan dengan memverifikasi kata-kata dalam urutan yang benar seperti yang ditampilkan di layar.
- **Menghubungkan Zashi + Dompet Keystone:**
    - Pada perangkat Keystone: Ketuk … pada halaman utama
    - Ketuk Connect Software Wallet dan pilih Zashi. Kode QR untuk koneksi ke Zashi akan muncul.
    - Di Aplikasi Zashi: Ketuk dropdown zashi (kiri atas layar)
    - Ketuk Connect Hardware Wallet
    - Ketuk Ready to Scan
    - Pindai QR yang ditampilkan pada Perangkat Keystone
    - Di Aplikasi Zashi: Konfirmasi Akun Dompet Keystone dengan mengetuk akun yang ditampilkan
    - Ketuk Connect di bagian bawah layar
