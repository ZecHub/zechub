# Bantu Bangun ZecHub

Jika kamu adalah anggota komunitas Zcash, dan ingin berkontribusi dalam membangun ZecHub, ada beberapa hal yang sangat membantu.

Kurasi tautan untuk buletin dan tambahkan ke halaman GitHub buletin: -> [Klik di sini untuk instruksi](https://github.com/ZecHub/zechub/blob/main/site/contribute/ZecWeekly_Newsletter.md)

Lakukan pemeriksaan fakta pada dokumen wiki, sarankan pengeditan, dan usulkan halaman baru di Github

Buatlah konten video dalam kategori berikut:```
* Zcash explainer videos
* Zcash wallet guide/tutorials
* Third-party application demos
```

Buatlah desain seperti poster/grafik/animasi untuk Zcash & ekosistem Privasi

### Imbalan

Jumlah tidak ditetapkan secara tetap di ZEC. Gunakan kebijakan jumlah bounty [bounty amounts policy](https://bounties.zechub.wiki/docs/bounty-amounts): pilih interval USD untuk kelas pekerjaan tersebut, konversi dengan kurs saat ini, lalu masukkan ZEC ke papan pengumuman. Kebijakan itulah yang menjadi sumber kebenaran tunggal.

Alur kerja kontributor dan jenis pekerjaan: [Berkontribusi ke ZecHub](https://zechub.wiki/contribute/contributing-guide).
