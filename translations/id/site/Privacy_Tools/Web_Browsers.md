# Browser Web

1. **Brave:** Salah satu browser paling terkemuka dan paling aman di pasar saat ini. Browser ini memblokir iklan & tracker yang melanggar privasi. Browser ini juga memblokir penyimpanan data pihak ketiga.

2. **Mulvad:** Sebuah browser web yang berfokus pada privasi yang dikembangkan melalui kolaborasi antara Mullvad VPN dan Tor Project. Browser ini dibuat untuk meminimalkan pelacakan dan fingerprinting

3. **Tor:** Browser ini memblokir plugin seperti Flash, RealPlayer, QuickTime, dan lainnya: plugin tersebut dapat dimanipulasi untuk mengungkap alamat IP kamu. Kami tidak menyarankan untuk menginstal add-on atau plugin tambahan ke dalam Tor Browser


## Apa Saja Pertimbangan Keamanan Saat Memilih Web Browser?

Saat memilih browser web, ada beberapa hal yang perlu kamu perhatikan: Kerentanan keamanan dan eksploitasi biasanya ditemukan secara rutin. Beberapa browser dapat dilacak dengan cara tertentu, namun, ada browser yang memungkinkan pengguna untuk menjelajah secara anonim - contohnya [Tor browser](https://www.torproject.org/download/).

**Fingerprinting**: Jika kamu ingin menjaga privasi hal-hal seperti perangkat lunak yang terinstal di mesinmu, konfigurasi perangkat keras, dan banyak lagi, pertimbangkanlah untuk mencari web browser yang mendukung fitur resistensi fingerprinting.

**HTTPS Test**: Pertimbangan keamanan lain yang perlu diperhatikan saat memilih web browser adalah protokol HTTPS Test yang membantu mengenkripsi koneksi situs web dan menyembunyikan cookie, URL, serta jenis metadata sensitif lainnya. Dengan HTTPS, koneksi dienkripsi sehingga tidak ada pihak ketiga pada jaringan yang dapat membaca konten yang sedang ditransfer antara server dan browser kamu.

**Perlindungan Cookie Pelacak**: Terlebih lagi, sebagian besar halaman web di world wide web memiliki pelacak pihak ketiga yang tersembunyi; pelacak ini membaca dan menulis cookie di browsermu. Cookie ini dapat menimbulkan ancaman berbahaya karena dapat digunakan untuk melacak penjelajahanmu di berbagai situs web; untuk mencegah pelacakan ini, pilihlah web browser yang memblokir cookie penjelajahan yang tidak dikenal.

**Uji Navigasi**: Saat kamu menavigasi dari satu halaman web ke halaman lainnya, kamu akan menemukan banyak tautan (beberapa adalah tautan internal sementara yang lain menautkan ke situs web lain). Saat kamu mengklik tautan ini, API browser tertentu memungkinkan situs pertama untuk berkomunikasi dengan situs kedua. Untuk mengatasi hal ini, pilihlah browser web yang mencegah situs web berbagi data pelacakan saat kamu mengklik sebuah tautan. Saat memilih browser tersebut yang menurutmu mungkin sesuai dengan kebutuhanmu, pastikan browser tersebut menyediakan fitur privasi yang kuat dan fitur penting seperti pemblokir iklan bawaan dan sebagainya. Selain itu, banyak dari browser web ini mendukung ekstensi serta add-on dan terkadang ekstensi ini dapat menimbulkan risiko keamanan, pastikan untuk selalu menginstal ekstensi ini dari ekosistem yang aman atau sumber terpercaya.
 
## Integrasi Dompet Brave Browser Zcash

Browser Brave sedang membuka jalan bagi ekosistem web3. Bagaimana caranya? Lebih dari 2 juta domain yang tak terhentikan kini dapat dimanfaatkan untuk menampilkan situs web terdesentralisasi. Dengan fitur keamanan Brave Browsers yang kuat, orang-orang dapat menjelajahi internet tanpa dilacak. Brave dan Zcash sedang menyatukan kekuatan untuk menghadirkan alat privasi baru ke ekosistem Web3. Untuk manfaat yang lebih besar, Brave akan berintegrasi dengan cepat dengan protokol Zcash melalui dompet kripto bawaan Brave untuk merevolusi transaksi kripto - Integrasi ini akan memungkinkan pengguna untuk menyimpan, mengirim, dan menerima ZEC dengan sangat mudah serta mata uang kripto lainnya juga. Kolaborasi antara browser web Brave dan Zcash benar-benar akan mengubah keadaan karena pengguna akan memiliki kendali yang lebih besar atas aktivitas Web3 mereka.

Fakta menarik lainnya tentang integrasi browser Brave dan Zcash adalah fitur pesan privat dan terdesentralisasi; tim Brave, ECC, dan Filecoin Foundation sedang merintis jalan bagi fitur berbasis privasi di browser Brave - kolaborasi ini bertujuan untuk menawarkan pengiriman pesan pribadi dan media melalui protokol Zcash. Di sini, Interplanetary File System (IPFS) akan memainkan peran penting dalam menawarkan kemampuan penyimpanan yang aman untuk konten terenkripsi.
