# Berbagi File P2P dengan IPFS dan Browser Brave

Kita dapat menggunakan IPFS untuk berbagi file media berukuran besar di antara kita dengan cara Peer-to-Peer.

Jadi apa masalahnya: gateway IPFS tidak berfungsi untuk file berukuran besar, karena akan mengalami timeout.

**Persyaratan**: [IPFS Desktop](https://docs.ipfs.tech/install/ipfs-desktop/) + [Browser Brave](https://brave.com/)

tl;dr, Videonya ada di bagian akhir.

Kita bisa menggunakan ini di antara kita di ZF AV Club untuk mentransfer file media berukuran besar dan mendokumentasikannya untuk kalian semua karena ini menyenangkan dan sangat keren!!

*TAMBAHAN*, kami akan berkolaborasi secara langsung dengan tim IPFS di Protocol Labs untuk mengembangkan use case ini.
Manfaat lain yang didapat dari koneksi yang terjalin di dWeb Camp!

Tanpa IPFS yang terinstal pada mesin penerima DAN menggunakan browser yang bukan Brave: Kamu perlu menunggu gateway untuk memuat file tersebut. *Ini akan menghasilkan error 504 pada file berukuran besar.*

Berikutnya: Cara menyematkan file orang lain di mesin kamu agar kita tidak menghadapi masalah single point of failure saat node asli sedang offline.
