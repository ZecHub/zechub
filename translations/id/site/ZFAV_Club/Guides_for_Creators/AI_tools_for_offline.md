### Menghasilkan gambar

Di mana tempat untuk mengunduh model untuk pembuatan gambar? 
Di [**HuggingFace**](https://huggingface.co/models?pipeline_tag=text-to-image&sort=trending) dan [**Civitai](https://civitai.com/)** terdapat banyak model yang berbeda.

## Windows - unduh model kustom

Biasanya minimal GPU dengan 4GB memori video diperlukan untuk alat AI apa pun.

GPU Nvidia bekerja paling baik.

- [InvokeAI](https://invoke-ai.github.io/InvokeAI/) (memerlukan 4GB memori GPU)
- [NMKD Stable Diffusion GUI](https://nmkd.itch.io/t2i-gui)
- [EasyDiffusion 3.0](https://github.com/easydiffusion/easydiffusion)

### Mac OS - unduh model kustom

- [Draw Things: AI Generation](https://apps.apple.com/ee/app/draw-things-ai-generation/id6444050820) dari AppStore - gratis
(Dapat menggunakan banyak model StableDiffusion yang berbeda)
- [DiffusionBee](https://diffusionbee.com/) - gratis
(Dapat menggunakan banyak model StableDiffusion yang berbeda)
- [InvokeAI](https://invoke-ai.github.io/InvokeAI/) (memerlukan memori GPU 4GB)

### Linux - unduh model kustom

- [InvokeAI](https://invoke-ai.github.io/InvokeAI/) (memerlukan 4GB memori GPU)
