# Pembuatan dan penerjemahan subtitle video

Alat yang digunakan dalam panduan ini:

1. CapCut
2. Ekspor SRT [CapCut](https://www.biyaoyun.com/capcutsrt)
3. Editor teks
4. [Penerjemah & Editor Subtitle Online](https://www.syedgakbar.com/projects/dst)

Mulailah dengan mengimpor hasil editan akhir video kamu ke dalam CapCut. Sebagai alternatif, kamu bisa menggunakan CapCut untuk mengedit video sebelum melanjutkan proses ini.

Setelah video terakhir dimuat di CapCut, gunakan [Ekspor SRT CapCut](https://www.biyaoyun.com/capcutsrt) untuk mendapatkan file subtitle, lengkap dengan timestamp, dari proyek CapCut tersebut.

Buka file SRT di editor teks dan tonton videonya sambil membaca file SRT tersebut, lalu lakukan perubahan pada file SRT jika ditemukan kesalahan. Gunakan fitur cari dan ganti untuk **mengganti semua** setiap kesalahan yang ada.

Tip: Tonton videonya pada kecepatan 2x sambil memeriksa subtitle

Setelah transkrip asli telah diperiksa dan dikoreksi, unggah file SRT ke [Online Subtitle Translator & Editor](https://www.syedgakbar.com/projects/dst) untuk menerjemahkan file SRT ke bahasa lain dengan biaya kecil.

File SRT yang telah diterjemahkan harus diperiksa menggunakan perangkat lunak pengeditan video oleh seseorang yang memahami bahasa hasil terjemahan tersebut.

File SRT yang telah diterjemahkan terkadang memerlukan penyesuaian pada timecode, yang mudah ditemukan dan diperbaiki dengan sebagian besar perangkat lunak pengeditan video.
