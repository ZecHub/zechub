# Podcast Z2Z

Podcast Z2Z menyajikan percakapan berdurasi panjang antara Ian Sagstetter (dari Electric Coin Company) dan anggota lain dari komunitas Zcash.

Podcast ini membahas beragam topik, tetapi terutama berfokus pada Zcash dan pengalaman para penggunanya.
