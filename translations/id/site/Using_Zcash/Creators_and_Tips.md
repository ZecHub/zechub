## Zcash.me

![Zcash.me Logo](/content-images/_unavailable.svg)

### Ringkasan

**Zcash.me** adalah direktori profil dan platform penemuan yang memudahkan siapa saja untuk menemukan dan mengirim ZEC ke pengguna Zcash. Ini berfungsi sebagai "Linktree untuk Zcash" - cara sederhana untuk membagikan alamat terlindungi dan kehadiran sosial kamu dengan satu tautan tunggal.

| Item              | Detail |
|-------------------|---------|
| **Situs Web**     | [https://zcash.me/](https://zcash.me/) |
| **Twitter**         | [@zcashme](https://x.com/zcashme) |
| **Format Profil** | `zcash.me/[username]` |
| **Status**        | Live (dengan fitur yang sedang dalam pengembangan) |

### Fitur Utama

#### Tersedia Saat Ini
- **Halaman Profil Kustom** - Halaman personal dengan nama pengguna, bio, avatar, dan lokasi
- **Tampilan Alamat Terlindungi** - Tombol salin satu klik untuk alamat terpadu kamu
- **Integrasi Tautan Sosial** - X, LinkedIn, Telegram, dan situs web kustom
- **Sistem Verifikasi** - Lencana terverifikasi untuk kepercayaan komunitas
- **Papan Peringkat Referal** - Pantau pemberi referal terbaik dan pemimpin komunitas
- **Status Aktivitas** - Menampilkan waktu terakhir aktif

#### Segera Hadir
| Fitur               | Deskripsi                   |
|---------------------|-----------------------------|
| Peta Lokasi         | Temukan pengguna Zcash di sekitar kamu |
| Statistik Platform | Lihat metrik pertumbuhan    |
| Polling Komunitas   | Berikan suara pada topik ekosistem |
| Berita & Pengumuman| Pembaruan resmi             |
| Forum               | Diskusi komunitas           |
| Aplikasi Seluler    | Pengalaman seluler penuh    |

### Memulai
1. Kunjungi [https://zcash.me/](https://zcash.me/) dan klik **Join**
2. Pilih nama pengguna yang unik, tambahkan bio dan foto profil
3. Tempelkan alamat terpadu Zcash kamu (`u1...`)
4. Hubungkan akun media sosial kamu
5. Bagikan tautan kamu: `zcash.me/[yourusername]`

## TipZ

![TipZ Logo](/content-images/BbXM8cDV_400x400-e6071ba983.webp)

### Ringkasan

**TipZ** adalah **protokol tipping privat** yang dibuat khusus untuk kreator dan cypherpunk. Penggemar dapat memberikan tip dalam mata uang kripto utama apa pun; tip tersebut akan dikonversi secara otomatis dan dikirim sebagai **ZEC terlindungi**.

| Item              | Detail |
|-------------------|---------|
| **Situs Web**     | [https://tipz.cash/](https://tipz.cash/) |
| **Twitter**         | [@tipz_cash](https://x.com/tipz_cash) |
| **Format Profil** | `tipz.cash/@[username]` |
| **Status**        | Live |

> *"tipz.cash adalah protokol tipping privat untuk para kreator dan cypherpunks."*

### Mengapa Privasi Penting bagi Kreator

#### Kebebasan Finansial
- 0% biaya platform
- Non-kustodial & self-custody
- Tanpa perantara

#### Desain Mengutamakan Privasi
- Setiap tip tiba sebagai ZEC terlindungi
- Saldo dompet pribadi
- Pesan terenkripsi dengan tip
- Opsi anonimitas kreator sepenuhnya

#### Pembayaran Cross-Chain
| Mata Uang | Jaringan |
|----------|---------|
| ETH      | Ethereum |
| USDC     | Berbagai chain |
| SOL      | Solana |
| ZEC      | Zcash Langsung |

#### Perlindungan Kreator
- Tidak ada risiko deplatforming
- Tahan sensor
- Tidak memerlukan KYC

### Sumber Daya Tambahan

```
TipZ Payment Flow

Fan -> tipz.cash Protocol -> Creator's Wallet (Shielded ZEC)

Fan selects amount + message -> Protocol auto-converts -> Creator receives private shielded ZEC
```
