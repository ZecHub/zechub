# <img src="/content-images/image-2024-02-03-173258092-a5440e5ee2.webp" alt="Alt Text" width="50"/>   Exchange Kustodial

Ironwood adalah pool terlindungi yang hadir bersama peningkatan jaringan Juli 2026. Exchange yang hanya menangani t-address transparan tidak pernah menyentuhnya, jadi bagian tersebut ditandai tidak berlaku. Jika sebuah exchange menangani alamat terlindungi tetapi belum menyatakan pool mana yang digunakannya, baris tersebut akan mengatakannya alih-alih menebak.
