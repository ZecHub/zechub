# Zcashにおけるポスト量子セキュリティ

## 要約

- 量子コンピューターは、現在ブロックチェーンで使用されている一部の公開鍵暗号を破る可能性があるため、将来のリスクです。
- 「ポスト量子」とは、通常のコンピューターで動作しながら、将来の量子コンピューターによる攻撃に耐えるよう設計された暗号技術を意味します。
- Zcashは、現在完全なポスト量子対応ではありません。
- シールドされたZcashは、将来の攻撃者が分析できる公開トランザクションデータの量を減らしますが、シールドされた利用は完全な量子耐性と同じではありません。
- Zcashは、研究、ZIP、ZIP 2005やProject Tachyonなどのアップグレード提案を通じて準備を進めています。
- 安全なポスト量子移行では、資金、プライバシー、ウォレット、取引所、コンセンサスルールを同時に保護する必要があります。

Ironwoodで何が変更されたか、および各要素の日時付きステータスについては、[Zcashはポスト量子対応ですか？](/zcash-tech/is-zcash-post-quantum)をご覧ください。

## 量子コンピューティングとは？

通常のコンピューターは、情報をビットとして保存します。各ビットは`0`または`1`のいずれかです。

量子コンピューターは、量子ビット（qubit）と呼ばれる量子ビットを使用します。量子ビットは、通常のコンピューターよりもはるかに高速に一部の数学問題を解く特殊なアルゴリズムで使用できます。

これは、量子コンピューターがあらゆる処理で高速であることを意味するわけではありません。リスクは限定的です。一部の暗号技術は、通常のコンピューターには非常に難しい一方、十分に大規模な量子コンピューターにははるかに容易な数学問題に依存しています。

ブロックチェーンにとって最も重要な例は、公開鍵暗号です。公開鍵と署名（signature）は、ユーザーがコインを支出する権限を持つことを証明するために使用されます。

## ブロックチェーンが重視する理由

ブロックチェーンは、複数の異なる役割のために暗号技術を使用します。

| 暗号ツール | 機能 | 量子による影響 |
| --- | --- | --- |
| デジタル署名 | 所有者が支出を承認したことを証明します | 一般的な楕円曲線システムでは高リスクです |
| ハッシュ関数 | アドレス、コミットメント、Merkleツリー、チャレンジを構築します | リスクは低いものの、セキュリティマージンは重要です |
| ゼロ知識プルーフ | 詳細を明かさずに、シールドされたトランザクションが有効であることを証明します | プルーフシステムと前提に依存します |
| 鍵合意 | ウォレットが受信者向けのノートデータを暗号化するのに役立ちます | 量子脅威モデルの下で慎重なレビューが必要です |

十分に強力な量子コンピューターは、楕円曲線署名を含む、今日使用されている多くの署名方式を脅かす可能性があります。これは、署名によってネットワークがトランザクションを正しい鍵が承認したと確認できるため重要です。

ハッシュ関数は異なります。Groverのアルゴリズムは総当たり検索を高速化できますが、ハッシュ関数を同じ直接的な方法で破るものではありません。より大きなセキュリティマージンが役立つ可能性があります。

## ポスト量子暗号とは？

ポスト量子暗号は、通常のコンピューターと将来の量子コンピューターの両方に対して安全性を維持するよう設計された暗号技術です。

これは、その暗号技術が量子コンピューターを使用することを意味しません。異なる難しい数学問題に基づくシステムであることを意味します。

2024年に、NISTは最初に確定したポスト量子標準を公開しました。

- 鍵確立のための**ML-KEM**
- デジタル署名のための**ML-DSA**
- ハッシュベースのデジタル署名のための**SLH-DSA**

これらの標準は大きな節目ですが、ブロックチェーンは一晩で単純にあるアルゴリズムを別のものに置き換えることはできません。コンセンサスルール、ウォレット、ハードウェアウォレット、トランザクションサイズ、手数料、プライバシーのすべてを考慮する必要があります。

## 量子リスクがオンチェーンで現れる仕組み

リスクを考える簡単な方法は次のとおりです。

1. ユーザーが鍵ペアを作成します。
2. 公開鍵または署名データがオンチェーンに現れる場合があります。
3. 将来の量子攻撃者は、その公開情報を用いて秘密鍵を知ることができる可能性があります。
4. 資金がその鍵によってまだ管理されている場合、リスクにさらされる可能性があります。

公開型ブロックチェーンは、設計上、多くの情報を公開します。アドレス、金額、トランザクション間の関係は公開されています。コインが支出されると、公開鍵情報も見えるようになる場合があります。

これがアドレス再利用が有害である理由の1つです。再利用は、観察者が現在結び付けられるデータを増やし、将来の攻撃者に分析する過去の情報をより多く与えます。

## Zcashの違いは何ですか？

Zcashは、公開型トランザクションとシールドされたトランザクションの両方をサポートしています。

公開型Zcashは、Bitcoinスタイルの公開ブロックチェーン利用により近い仕組みです。アドレス、金額、トランザクション間の関係が可視化されます。

シールドされたZcashは異なります。シールドされたトランザクションはゼロ知識プルーフを使用するため、送信者、受信者、金額を明かすことなく、ネットワークはトランザクションがルールに従っていることを検証できます。

これにより、Zcashには重要なプライバシー上の利点があります。

- すべての人が閲覧できるトランザクションデータの公開量が少なくなります。
- ユーザーは、シールドされた状態を維持することで公開された支払いグラフを作成せずに済みます。
- 将来の観察者が分析できる公開金融履歴が少なくなります。
- 選択的開示（selective disclosure）は、公開がデフォルトの記録ではなくビューイングキーを通じて行えます。

ただし、シールドされたZcashが自動的にポスト量子対応になるわけではありません。シールドされたプールは依然として暗号学的前提に依存します。支出承認、ノートコミットメント、ヌリファイア、プルーフシステム、暗号化、ウォレット鍵のすべてに慎重なレビューが必要です。

簡潔に言うと、次のとおりです。

> シールドされた利用は公開される情報を減らしますが、Zcashには依然として意図的なポスト量子アップグレードが必要です。

## Zcashのリスクマップ

| 領域 | 初心者向けの説明 | ポスト量子に関する懸念 |
| --- | --- | --- |
| 公開型アドレス | 公開アドレスと公開トランザクショングラフ | 他の公開型ブロックチェーンと同様のリスク |
| 支出承認 | ユーザーに支出の権限があることを示すプルーフ | 署名方式は置換または移行が必要になる可能性があります |
| シールドされたノート | シールドされたプール内の価値に関する非公開の記録 | 一部の構成要素には新たな前提または復旧ツールが必要になる可能性があります |
| zk-SNARKs | シールドされたトランザクションが有効であることを示すプルーフ | プルーフシステムの前提にはレビューが必要です |
| ウォレットのスキャン | ウォレットが受信したノートを見つけて復号する方法 | 鍵合意とノート暗号化にはレビューが必要です |
| 移行 | より安全な暗号技術へ資金を移すこと | 資金損失とプライバシー漏えいの両方を避ける必要があります |

## Zcashの準備状況

### Zcashにはネットワークアップグレードのプロセスがあります

Zcashは以前にも暗号技術を変更してきました。Saplingにより、シールドされたトランザクションはより使いやすくなりました。NU5ではOrchard、Unified Addresses、Halo 2が導入されました。

これは、ポスト量子対応が1行のソフトウェアパッチではないため重要です。協調したネットワークアップグレード、ウォレットの変更、監査、そしてユーザーが移行するための時間を要します。

過去のZcashアップグレードは、このエコシステムが古い暗号技術から新しい設計へ移行した経験を持つことを示しています。

### HaloとOrchardは古い前提を減らしました

Halo 2は、Zcashの最新のシールドされたプールであるOrchardで使用されています。重要な改善の1つは、HaloがOrchardプルーフシステムのトラステッドセットアップを不要にしたことです。

これはポスト量子セキュリティと同じものではありません。それでも、より良い設計が利用可能になったときに、Zcashが主要な暗号学的構成要素を置き換えられることを示すため、関連しています。

### ZIP 2005は量子復旧可能性に焦点を当てています

ZIP 2005の題名は「Orchard Quantum Recoverability」です。これは、古い前提に対する量子攻撃が現実的になった場合に、Orchardのユーザーが資金を復旧または移行できるようにするための変更を提案しています。

復旧可能性は、完全なポスト量子セキュリティと同じではありません。より限定的ですが、有用です。

- 完全なポスト量子セキュリティは、量子攻撃が成功しないようにすることを目指します。
- 復旧可能性は、古い暗号技術が安全でなくなった場合に、正当なユーザーへより良い経路を提供します。

初心者向けに言えば、これは非常口の計画のようなものです。建物全体を置き換えるものではありませんが、古い錠が弱くなった場合に、人々が古い部屋から安全に出る助けになります。

### Project Tachyonは、より大規模なプロトコル改善を目指しています

Project Tachyonは、規模、同期、状態の増大に焦点を当てた提案中のZcashアップグレードです。公開サイトでは、この提案はトランザクションの縮小、バリデーターの状態増大の削減、そして副次的効果として完全なポスト量子プライバシーの実現を目指すと述べています。

Tachyonは提案であるため、有効化前にはエンジニアリング作業、レビュー、コミュニティの承認が依然として必要です。これは、ユーザーがすでに利用できる機能ではなく、Zcashの進行中の研究およびアップグレードの方向性の一部として理解するのが最適です。

### 研究と標準は進展しています

より広い暗号技術の世界も進展しています。NISTのポスト量子標準は、実装者に署名と鍵確立のためのより強力な構成要素を提供します。ゼロ知識研究者は、量子の前提の下でも耐えられるプルーフシステムを継続して研究しています。

Zcashはその成果から恩恵を受けられますが、プライバシーを保護するブロックチェーンに適応させる必要があります。

## 将来のアップグレードで考えられるアプローチ

### ポスト量子の支出承認

Zcashは最終的に、量子に脆弱な署名方式に依存しない支出承認を必要とする可能性があります。

これは、ポスト量子署名、ハイブリッド署名、または別の設計を使用する可能性があります。ハイブリッド設計では、移行期間中に従来型とポスト量子の両方のチェックを使用するため、システムが1つの前提だけに依存しません。

課題はサイズとコストです。ポスト量子署名は今日の署名より大きくなる場合があり、トランザクションサイズ、帯域幅、手数料、モバイルウォレット、ハードウェアウォレットに影響します。

### 新しいアドレスと鍵の形式

新しい暗号技術には、多くの場合、新しい鍵とアドレスが必要です。ユーザーには、古い形式からより安全な形式への明確な移行経路が必要です。

移行はウォレット内で簡単であるべきです。ほとんどのユーザーは、安全を維持するためにすべての暗号学的詳細を理解する必要があるべきではありません。

### プライバシーを保護する移行

移行は、Zcashにとって特に慎重さが求められます。多くのユーザーが明白なパターンで古いプールから新しいプールへ資金を移す場合、移行自体が情報を漏らす可能性があります。

優れた移行計画では、次を保護する必要があります。

- ユーザー資金
- ユーザープライバシー
- ウォレットの互換性
- 取引所のサポート
- ハードウェアウォレットのサポート
- ネットワークコンセンサスの安全性

### ポスト量子プルーフシステムのレビュー

署名を置き換えるだけでは不十分です。Zcashのシールドされた設計は、ゼロ知識プルーフとコミットメントにも依存しています。

将来の作業では、次をレビューまたは置換する必要があるかもしれません。

- zk-SNARKの前提
- 多項式コミットメント
- Fiat-Shamirチャレンジハッシュ
- ノートコミットメント
- ヌリファイアの構成
- Merkleツリーの前提
- ノート暗号化とビューイングキーの挙動

一部の構成要素は、パラメーターを調整すれば許容できる場合があります。その他の構成要素には新しい設計が必要になる可能性があります。

## 初心者向けの例

### 例1：古い錠

今日では強力な錠が付いた金庫を想像してください。将来発明される新しいツールは、その古い錠を迅速に開けられるかもしれません。

ポスト量子暗号は、新しいツールでも破れないと見込まれる設計へ錠を置き換えることに似ています。

ブロックチェーンでは、すべてのウォレット、ノード、取引所、ハードウェアデバイスが新しい設計を理解しなければならないため、錠の置換は困難です。

### 例2：公開レシートボックス

公開型ブロックチェーンのデータは、すべてのレシートを永久に公開ボックスへ入れるようなものです。今日では誰もあらゆるパターンを読み取れなくても、将来のツールが後からより多くを読み取る可能性があります。

シールドされたZcashは、そもそもそれらのレシートを公開しないようにします。これは長期的なプライバシーに役立ちますが、シールドされたシステムを保護する錠についても、量子時代に備えてレビューが必要です。

### 例3：退出計画

復旧可能性は、火災が発生する前に避難経路を計画することに似ています。必要にならないことを願いますが、緊急時に設計するよりも早期に設計するほうがはるかに安全です。

ZIP 2005は、Orchardノートについてこの考え方に当てはまります。

## ユーザーが今日できること

ユーザーは慌てる必要はありません。展開済みのブロックチェーン暗号を破れる大規模な公開量子コンピューターは、現在利用できません。

良い習慣は依然として役立ちます。

- 可能な場合はシールドされたZcashの利用を優先します。
- アドレスの再利用を避けます。
- ウォレットを最新の状態に保ちます。
- Zcashのネットワークアップグレードに関する発表を確認します。
- 復旧可能性や移行に関するZIPとウォレットのガイダンスを注視します。
- 公開型の活動がプライベートであると想定しません。
- うわさに基づいて資金を移動せず、信頼できるZcashのデベロッパーとウォレットチームによる明確なガイダンスを待ちます。

## 課題

ポスト量子アップグレードは、すべてのブロックチェーンにとって困難です。

一般的な課題には、次が含まれます。

- より大きな鍵と署名
- より大きなトランザクション
- より高い検証コスト
- より多い帯域幅使用量
- 新しいセキュリティ監査
- ハードウェアウォレットのサポート
- モバイルウォレットの性能
- 取引所およびカストディの統合
- 移行中のプライバシー漏えい
- コンセンサス変更に関するコミュニティの合意

Zcashにとって最も難しいのは、単にコインを支出可能な状態に保つことではありません。Zcashを異なるものにしているプライバシーを維持しながら、コインを支出可能な状態に保つことが難しいのです。

## まとめ

量子コンピューターは、最終的にブロックチェーンで使用される一部の暗号技術を脅かす可能性があります。ポスト量子暗号は長期的な答えですが、慎重に展開する必要があります。

Zcashは、現在完全なポスト量子対応ではありません。しかし、Zcashには有用な強みがあります。シールドされたトランザクションは公開される情報を減らし、ネットワークには暗号技術をアップグレードしてきた歴史があり、ZIP 2005やProject Tachyonといった現在の研究は、すでに将来の量子リスクを対象としています。

初心者にとっての主な考え方はシンプルです。今日のプライバシーは将来のデータ露出を減らし、慎重なアップグレードは、使いやすさを犠牲にせずにZcashをより強力な量子時代のセキュリティへ近づける助けになります。
