# ネットワーク持続可能性メカニズム（NSM）

> NSMは、2026年11月6日にMainnetのブロック3,543,405で[NU7](./NU7.md)が有効化されて以来、Zcashのコンセンサスの一部となっています。現在、手数料が取り分けられています。マイナーへの再発行はブロック8,939,664（2031年2月頃の見込み）から始まります。

この記事では、ネットワーク持続可能性メカニズムが何をするのか、各ブロックの手数料からどれだけを取り除くのか、そのZECがどこへ行くのか、いつ、どのくらいの速さでブロック報酬として戻るのか、そして2,100万の上限と半減期のスケジュールが変わらない理由を説明します。

ネットワーク持続可能性メカニズム（NSM）は、一部のZECを流通から取り除き、長年にわたって分配しながら後でマイナーに支払うコンセンサスルールの集合です。NU7はその2つの部分を導入しました。1つは、各ブロックのトランザクション手数料の60%を流通から取り除く[ZIP 235](https://zips.z.cash/zip-0235)、もう1つは、取り除かれたZECを滑らかなカーブに沿って通常のブロック補助金に上乗せして再発行する[ZIP 237](https://zips.z.cash/zip-0237)です。どちらも[ZIP 259](https://zips.z.cash/zip-0259)によって有効化されました。

これが重要な理由。Zcashは、各ブロックで新しいZECを発行してセキュリティを支えており、その補助金は約4年ごとに半減します。補助金が小さくなると、マイナーは主に手数料で収入を得る必要があります。NSMはその未来に向けた第一歩です。供給上限を引き上げたり、すでに定着している半減期のスケジュールを変更したりせずに、現在の手数料の一部を蓄え、将来のマイナーに支払います。

## 要約

- **取り除く仕組み（[ZIP 235](https://zips.z.cash/zip-0235)）：**各ブロックで、トランザクション手数料の合計の60%（切り捨て、マイナーに有利な丸め方）が流通から取り除かれます。残りの40%はマイナーが受け取ります。
- **NSM残高：**流通から取り除かれ、まだ再発行されていないZECの累計を示す公開の値です。コンセンサス状態の一部であり、誰かが支出できるプールではありません。
- **初期残高：**NU7の時点で、残高は**368.58445520 ZEC**でした。これは、初期のマイナーがNU6より前に請求しなかったブロック報酬と手数料です。
- **再発行（[ZIP 237](https://zips.z.cash/zip-0237)）：**ブロック**8,939,664**から、各ブロックで残高の一定割合（0.00001375%）がブロック補助金に加算されます。これにより、4年間の半減期ごとに残高のおよそ半分が支払われます。
- **変わらないもの：**半減期のスケジュールと、上限としての2,100万ZEC。残高がゼロになれば、発行量は従来のスケジュールと完全に同じです。

## イメージで理解する

レジの横にある貯金瓶を思い浮かべてください。ブロックがマイニングされるたびに、チップ（手数料）の60%がマイナーの懐ではなく瓶に入ります。瓶から手でお金を取り出すことはできません。2031年以降は、瓶に入っている残高の一定割合が各ブロック報酬に加算されるため、瓶はゆっくり空になります。4年ごとに約半分ずつ、半減期と同じリズムです。

## 取り除く仕組み（ZIP 235）

- ルールはトランザクションごとではなく、ブロックごとに適用されます。手数料の合計が`F`（zatoshi単位）のブロックでは、取り除かれる額は`floor(6 × F / 10)`で、マイナーが請求できるのは`F`からその額を差し引いた分です。
- 丸めはブロック全体に対して1回だけ行い、常にマイナーに有利な方法を使います。トランザクションごとに丸めると、合計で60%より少ない額しか取り除かれません（1 zatoshiの手数料が2件ある場合、各件から取り除かれる額は0になります）。
- 例：手数料として合計50,000 zatoshi（0.0005 ZEC）を支払うトランザクションを含むブロックでは、30,000 zatoshiが取り除かれ、マイナーは20,000を受け取ります。手数料が15 zatoshiのブロックでは、9が取り除かれ、マイナーは6を受け取ります。
- トランザクションに特別なフィールドは必要ありません。各ノードは検証済みの手数料から金額を計算し、[ZIP 236](https://zips.z.cash/zip-0236)によってコインベーストランザクションはマイナーが受け取るべき額だけを請求するため、マイナーが取り除く額を減らしたり、請求額を増やしたりすることはできません。
- 規模：ZIP 235は、NU7以前のトラフィックに基づき、年間約370 ZECの手数料を見込んでいました。したがって、年間およそ222 ZECが取り除かれる計算です。現在、手数料はブロック補助金に比べて少額であるため、提案者はマイナーへの影響は小さいと予想していました。

## 再発行の仕組み（ZIP 237）

- **残高。**`NSMValueBalance`はNU7の有効化時点で368.58445520 ZEC（36,858,445,520 zatoshi）から始まります。各ブロックで、ZIP 235が取り除いた額が加算され、再発行された額が差し引かれます。残高がマイナスになるブロックは無効です。
- **初期残高の由来。**NU6より前は、コインベーストランザクションでブロック報酬と手数料の全額より少ない額を請求できました。チェーンの最初の2,726,400ブロックで、マイナーは368.58445520 ZECを請求せずに残しました。この高さまでに予定されていた補助金は15,750,000 ZECで、発行済みの供給量は15,749,631.41554480 ZECでした。ZIP 237はこの額をNSMに加え、失われる代わりに支払われるようにします。
- **ブロック8,939,664までは再発行されません。**NU7からその高さまで、残高は増えるだけです。
- **計算式。**ブロック8,939,664から、各ブロックの補助金に`ceiling(0.0000001375 × NSMValueBalance)`が加算されます。これは前のブロック後の残高に基づいて計算されます。その割合は`floor(LN2_SCALED / HalvingInterval) / 10^10` = 1375 / 10,000,000,000で、NU7後の半減期の間隔は5,040,000ブロックです。
- **この割合の理由。**`(1 − 0.0000001375)^5,040,000 ≈ 0.5`であるため、新たに取り除かれる額がなければ、各半減期の期間に残高のおよそ半分が再発行されます。これは、変更されていない半減期の段階に重ねて、NSM残高だけに適用される指数関数的な減衰です。
- **計算例。**ブロック8,939,664の時点で残高が初期の368.58 ZECだけだった場合、最初のブロックで5,069 zatoshi（約0.00005 ZEC）が再発行されます。1日あたり3,456ブロックとすると、約0.175 ZECです。実際の額は、それまでに取り除かれた手数料の分だけ増えます。
- **ブロック8,939,664となった理由。**ZIP 237は、実際に取り除かれた額とは無関係の固定ルールでこの高さを定めています。第3回半減期（ブロック6,132,390、2028年11月頃の見込み）以降で、まだ発行が予定されていないすべてのZECにNSMの割合を適用したときの支払額が、その期間の通常のブロック補助金（0.26041666 ZEC）を下回る最初のブロックです。NU7のコイン保有者とコミュニティによる投票では、再発行の開始時期について過半数の合意に至らなかったため、ZIP 259はこの交差点を採用しています。

## 変更されなかったこと

- **半減期のスケジュール。**ZIP 237は4年ごとの半減期を維持します。却下された代替案である[ZIP 234](https://zips.z.cash/zip-0234)は、それを滑らかな発行曲線に置き換えるものでした。2026年8月と9月のNU7投票では、半減期を維持するか、発行を平滑化するかが問われ、NU7は半減期を維持する設計を採用しました。
- **供給上限。**発行済み供給量とNSM残高の合計は、各ブロックで予定されたブロック補助金の分だけ増えるため、発行量が上限を超えることはありません。実際には上限はわずかに下がりました。ZIP 218でNU7後の補助金を丸めた結果、総発行量が約0.50 ZEC減少し、NSMはその不足分を再発行しません。
- **任意の取り除き。**誰でも明示的なトランザクションフィールドを使ってZECをNSMに送れるようにする[ZIP 233](https://zips.z.cash/zip-0233)は、NU7では導入されませんでした。現在、取り除かれる対象は手数料だけです。ZIP 237では、後続のZIPで別の対象を追加できます。
- **プライバシー。**残高と追加の補助金はすでに公開されている値から計算されるため、NSMによってトランザクションに関する新たな情報が明らかになることはありません。

## よくある誤解

- **「手数料の60%が焼却される。」**永久に失われるわけではありません。通常、EthereumのEIP-1559と比較される焼却とは異なり、取り除かれたZECは記録され、将来のマイナーに再発行されます。
- **「NSMは追加のZECを発行する。」**いいえ。取り除かれた、または請求されなかった価値を再発行するだけで、総発行量は既存の上限を超えません。
- **「再発行はすでに始まっている。」**まだです。ブロック8,939,664までは残高が積み上がるだけです。
- **「NSMは誰かが管理する基金だ。」**違います。これはコンセンサス状態に含まれる数値であり、そこから価値が出るのはブロック補助金の計算式を通じてのみです。
- **「半減期はなくなった。」**それはZIP 234の設計であり、NU7は導入していません。

## 用語集

| 用語 | 平易な説明 |
|---|---|
| Network Sustainability Mechanism (NSM) | ZECを流通から取り除き、後でマイナーに再発行するコンセンサスルール |
| NSM Value Balance | 流通から取り除かれた（または請求されなかった）ものの、まだ再発行されていないZECの公開累計 |
| Removal from circulation | ZECを発行済み供給量からNSM残高に移すこと。NU7以降は、各ブロックの手数料の60%が対象です |
| Reissuance | NSM残高からZECをブロック補助金に上乗せして支払うこと。ブロック8,939,664から始まります |
| Issued Supply | チェーン上の価値プールにあるすべてのZEC。NSM残高は含みません |
| Block subsidy | 各ブロックで生成され、マイナーと開発基金の資金配分先に分配される新しいZEC |
| Halving interval | 半減期の間にあるブロック数。NU7以降は5,040,000ブロックです（ブロック生成間隔が25秒の場合、約4年） |

## よくある質問

**NSMには現在どれだけありますか？**初期残高の368.58445520 ZECに、ブロック3,543,405以降の各ブロックの手数料の60%を加えた額です。これはすべてのフルノードが追跡するコンセンサス状態です。

**再発行されたZECは誰が受け取りますか？**ブロック補助金に加算されるため、同じ方法で分配されます。開発基金の資金配分先は、予定分と再発行分を合わせた補助金の固定割合を受け取り、残りをマイナーが受け取ります。

**再発行はいつ始まりますか？**Mainnetではブロック8,939,664からです。ブロック生成間隔の平均が25秒であれば、2031年2月頃の見込みです。Testnetでは、TestnetのNU7有効化高さを起点に、同じルールで高さが決まります。

**NSMによって手数料は上がりますか？**いいえ。手数料の行き先が変わるだけで、トランザクションの支払額は変わりません。

**60/40の配分は変更できますか？**将来のZIPとネットワークアップグレードを通じてのみ変更できます。ZIP 235では、たとえば手数料がブロック補助金を上回るようになった場合、配分を再検討できると述べられています。

## 理解度を確認しましょう

1. あるブロックのトランザクションが、手数料として合計100,000 zatoshiを支払います。マイナーが受け取るのはいくらですか？
2. NSMの初期残高はどこから来ましたか？
3. 新たに取り除かれるものがない場合、半減期ごとにNSM残高のおよそ何割が再発行されますか？
4. 再発行によって総発行量が2,100万ZECを超えないのはなぜですか？

回答：（1）40,000 zatoshiです。60,000が取り除かれます。（2）NU6より前にコインベーストランザクションで請求されなかったブロック報酬と手数料で、368.58445520 ZECです。（3）約半分です。（4）再発行されるのは取り除かれた、または請求されなかった価値だけなので、発行済み供給量とNSM残高の合計は各ブロックで予定された補助金の分だけ増えるからです。
