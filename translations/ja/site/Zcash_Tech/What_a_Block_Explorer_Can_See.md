# ブロックエクスプローラーがZcash上で見られるもの

## TL;DR

- Bitcoinでは、ブロックエクスプローラーにすべてが表示されます。送信者、受信者、金額です。
- Zcashでは、それが当てはまるのは透明な（t-address）アクティビティに限られます。
- エクスプローラーは資金がシールドプールに入ることと出ることは確認できますが、その内部で何が起きているかは分かりません。
- 完全にシールドされた（z から z へ）トランザクションでは、送信者も受信者も金額も明らかになりません。
- 公開されている「shield rate」の数値はすべて下限です。完全にプライベートなアクティビティは外部から見えないからです。

---

## 2種類のアドレス

Zcashには2種類のアドレスがあります。

**透明アドレス**は `t` で始まり、Bitcoinのアドレスのように機能します。残高と支払いは公開されています。

**シールドアドレス**は `z` で始まり、ゼロ知識証明によって保護されています。ネットワークは、送信者、受信者、金額を明かさずに、シールドされた支払いが有効であることを確認できます。

2種類のアドレスがあるため、価値は4つの方法で移動できます。透明から透明へ（t から t）、透明からシールドへ（t から z、shieldingと呼ばれます）、シールドから透明へ（z から t、deshieldingと呼ばれます）、そしてシールドからシールドへ（z から z、完全にプライベート）です。

## エクスプローラーが見られるもの

[Blockchair](https://blockchair.com/zcash) のような公開エクスプローラーは、次のものを明確に読み取れます。

- 完全に透明な（t から t）支払いは、最初から最後まで。
- 資金がシールドプールに入ること（透明な側と金額）。
- 資金がシールドプールから出ること（透明な側と金額）。
- 各シールドプールに保有されているZECの総量。これは、どこからもコインが作られていないことをネットワークが証明できるように公開されています。

要するに、シールドプールの境界は見えています。価値が出入りする様子は追跡できます。

## エクスプローラーが見られないもの

公開エクスプローラーは、次のものを読み取れません。

- 完全にシールドされた（z から z へ）トランザクション。送信者、受信者、金額は隠されたままです。
- シールドされた支払いの背後にいる送信者または受信者。
- 個々のシールドアドレスの残高。
- 資金がプール内に入った後に何が起こるか。

生データを照会すると、シールドされた送信者フィールドと受信者フィールドは空で返ってきます。これはエクスプローラーが意図的に隠しているのではありません。そもそも公開チェーン上に、読める形では存在していなかったのです。情報は暗号化されており、正しい Viewing Key を持つ人だけが読むことができます。

## なぜ重要なのか

**あなたのプライバシーは、企業を信頼することではなく、暗号技術から生まれます。** データ提供者は、見ようと思ってもシールドされたトランザクションの中身を見ることができません。

**公開されている shield-rate の数値は、プライバシーを過少に数えています。** 研究者が測定できるのは公開された境界をまたぐものだけなので、実際のプライベートなアクティビティの量は、彼らが報告する数値以上であり、通常はそれより多いです。

**より大きなシールドプールは、すべての人を守ります。** シールドアドレスを使う人が増えるほど、個々のプライベートな支払いが紛れ込める集団は大きくなります。シールドアドレスを使うことは、自分自身とプール内の他のすべての人を守る助けになります。

## 実践してみましょう

- [Zodl](https://zodl.com) や [Ywallet](https://ywallet.app/) のように、デフォルトでシールドアドレスを使うウォレットを使いましょう。
- 透明アドレスでZECを受け取ったら、使う前にシールドアドレスへ移しましょう。
- 可能な限り、シールドアドレスに支払いましょう。透明な支払いはすべて完全に公開されますが、シールドされた支払いはそうではありません。
