# Zcashでブロックエクスプローラーが確認できること

## TL;DR

- Bitcoinでは、ブロックエクスプローラーに送信者、受信者、金額のすべてが表示されます。
- Zcashでは、これは公開型（transparent）のtアドレスのアクティビティにのみ当てはまります。
- エクスプローラーは資金がシールドされた（shielded）プールに入ることと出ることを確認できますが、その内部で何が起きているかは確認できません。
- 完全にシールドされたzからzへのトランザクション（transaction）では、送信者、受信者、金額はいずれも公開されません。
- 公開されている「シールド率」の数値は、完全にプライベートなアクティビティが外部からは見えないため、下限値にすぎません。

---

## 2種類のアドレス

Zcashには2種類のアドレス（address）があります。

**公開型アドレス**は`t`で始まり、Bitcoinアドレスのように機能します。残高と支払い（payment）は公開されます。

**シールドされたアドレス**は`z`で始まり、ゼロ知識（zero-knowledge）proofによって保護されています。ネットワークは、送信者、受信者、金額を明かすことなく、シールドされた支払いが有効であることを確認できます。

2種類のアドレスがあるため、価値は4通りの方法で移動できます。公開型から公開型（tからt）、公開型からシールドされたもの（tからz、シールド化と呼ばれます）、シールドされたものから公開型（zからt、シールド解除と呼ばれます）、そしてシールドされたものからシールドされたもの（zからz、完全にプライベート）です。

## エクスプローラーが確認できること

[ZecBlock](https://zecblock.com/)のような公開エクスプローラーでは、次の内容を明確に確認できます。

- 完全に公開型のtからtへの支払いの全過程。
- 資金がシールドされたプールに入ること（公開型側と金額）。
- 資金がシールドされたプールから出ること（公開型側と金額）。
- 各シールドされたプールに保有されているZECの総額。これは、コインが何もないところから作られていないことをネットワークが証明できるよう、公開されています。

要するに、シールドされたプールの境界は見えます。価値が入出する様子を確認できます。

## エクスプローラーが確認できないこと

公開エクスプローラーでは、次の内容を確認できません。

- 完全にシールドされたzからzへのトランザクション。送信者、受信者、金額は隠されたままです。
- シールドされた支払いの背後にいる送信者または受信者。
- 個々のシールドされたアドレスの残高。
- 資金がプール内に入った後に何が起こるか。

生データを照会しても、シールドされた送信者と受信者のフィールドは空のまま返されます。エクスプローラーが意図的にこれを隠しているわけではありません。読み取れる形式では、そもそも公開チェーン（chain）上に存在していなかったのです。情報は暗号化（encryption）されており、適切なビューイングキー（viewing key）を持つ人だけが読み取れます。

## なぜ重要なのか

**あなたのプライバシーは、企業を信頼することではなく、暗号技術によって守られています。** データプロバイダーは、望んだとしてもシールドされたトランザクションの内部を確認できません。

**公開されているシールド率の数値はプライバシーを過小評価しています。** 研究者が測定できるのは公開境界を越えるものだけなので、実際のプライベートなアクティビティの量は、少なくとも報告される値と同じであり、通常はそれ以上です。

**より大きなシールドされたプールは、すべての人を保護します。** シールドされたアドレスを使用する人が多いほど、個々のプライベートな支払いが紛れ込む集団は大きくなります。シールドされたアドレスを使用することは、あなた自身とプール内の他のすべての人を保護する助けになります。

## 実践してみましょう

- [ZODL](https://zodl.com)または[Zingo!](https://www.zingolabs.org/)のように、シールドされたアドレスをデフォルトで使用するウォレット（wallet）を利用してください。
- 公開型アドレスでZECを受け取った場合は、使う前にシールドされたアドレスへ移動してください。
- 可能な限り、シールドされたアドレスへ支払ってください。すべての公開型の支払いは完全に公開されますが、シールドされた支払いはそうではありません。
