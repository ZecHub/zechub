# Zcash シールドされた資産（Shielded Assets）

## 要約

Zcash シールドされた資産（ZSA）は、ZEC以外の資産、すなわちステーブルコイン、ガバナンストークン、または任意のカスタム資産を、Zcashのシールドされたプール内で利用可能にするプロトコル拡張の提案です。送信者、受信者、金額は非公開に保たれます。

- **概要:** ERC-20形式のカスタム資産ですが、デフォルトでシールドされています。
- **開発者:** [QEDIT](https://qed-it.com/)が、Zcash Foundationからの助成金を受け、Electric Coin Companyと協力して開発しています。
- **仕様:** [ZIP 226](https://zips.z.cash/zip-0226)（転送とバーン）と、[ZIP 227](https://zips.z.cash/zip-0227)（発行）で定義されています。
- **ステータス:** メインネットではまだ稼働しておらず、Network Upgrade 7（NU7）の一部でもありません。[ZIP 259](https://zips.z.cash/zip-0259)には、NU7が展開するすべての内容が記載されていますが、ZIP 226およびZIP 227は含まれておらず、ZSAの有効化日は設定されていません。
- **手数料:** 移動する資産にかかわらず、常にZECで支払われます。

## 基本的な説明

Zcash シールドされた資産（ZSA）は、Zcashプロトコルの改善提案であり、Zcashチェーン上でカスタム資産の作成、転送、バーンを可能にします。

Ethereumブロックチェーン上の[ERC-20](https://ethereum.org/en/developers/docs/standards/tokens/erc-20/)トークン標準をご存じであれば、ZSAとZcashの関係は、ERC-20トークンとEthereumの関係に相当します。

Zcash シールドされた資産により、Zcashブロックチェーン上でカスタムトークンを作成できます。これにより、[ZEC](/guides/using-zec-privately)以外のトークンも、Zcashブロックチェーン上のシールドされたトランザクションが提供する匿名性とプライバシーの恩恵を受けられます。

ZSAの主要な潜在的用途の1つは、Zcashプロトコル上でのステーブルコイン発行です。ステーブルコインは、米ドルやユーロなどの法定通貨に価値を連動させる暗号資産です。現在、広く流通しているステーブルコインには、[USDC](https://www.circle.com/en/usdc)や[Dai](https://docs.makerdao.com/)などのERC-20トークンがあります。

ZSAのもう1つの潜在的用途は、ガバナンストークンの発行です。たとえば、このWikiの発行元であるZecHubは分散型自律組織（DAO）であり、提案やガバナンス上の意思決定について投票するためのZSAを作成してメンバーに発行できます。

ZSAは、[QEDIT](https://qed-it.com/)が、[Zcash Foundation](/zcash-organizations/zcash-foundation)からの大規模な助成金を受け、[Electric Coin Company](/zcash-organizations/electric-coin-company)と協力して開発しています。このプロジェクトは現在も活発に開発されているため、更新情報は[](https://forum.zcashcommunity.com/t/grant-update-zcash-shielded-assets-monthly-updates/41153)のZcashフォーラムにあるこのスレッドで公開されています。QEDITによる[ZSA助成金申請](https://zcashgrants.org/gallery/25215916-53ea-4041-a3b2-6d00c487917d/33106640/)は、Zcash Foundation助成金ウェブサイトで閲覧できます。

## 視覚化 / たとえ

### 封印された封筒

Zcashのシールドされたトランザクションを、公衆郵便ポストに投函された無地で封印された封筒だと考えてください。誰でも封筒が投函されたことは分かります。しかし、誰が送ったのか、誰が受け取るのか、中に何が入っているのかは誰にも分かりません。また、すべての封筒は他のすべての封筒と同じように見えます。

現在、Zcashネットワーク上の封筒に入れられるものは1つだけです。それはZECです。

ZSAは封筒を変えません。変えるのは、**その中に入れられるもの**です。ZSAの後は、同じ封印された封筒にステーブルコイン、DAOのガバナンストークン、または企業のロイヤルティポイントを入れられます。外部からは、それでもネットワーク上の他のすべての封筒とまったく同じに見えます。

覚えておくべき詳細が1つあります。**郵送料は、封筒の中身にかかわらず常にZECで支払われます**。

### 外部の観察者が確認できるもの

| 観察者が確認できるもの... | Ethereum上のERC-20 | Zcash上のZSA |
| --- | --- | --- |
| 送信者 | 公開 | シールドされた |
| 受信者 | 公開 | シールドされた |
| 移動した金額 | 公開 | シールドされた |
| 個別の残高 | 公開 | シールドされた |
| 資産の総供給量 | 公開 | **公開 — 意図的に** |
| 手数料を支払う通貨 | ETH | ZEC |

### 供給量の行がバグではない理由

表の下2行に、ZSAの興味深い点があります。

ZIP 227は、各資産の流通供給量をオンチェーンで追跡できるよう、意図的に**発行を公開型**に保っています。個々の保有量と個々の支払いは非公開のままですが、存在するトークンの総数は非公開ではありません。

ステーブルコインの発行者にとって、この組み合わせは妥協ではなく目的そのものです。準備金は公開検証可能な供給量に対して監査できる一方、実際にトークンを使用する人々は残高と支払いを非公開に保てます。

### 1つの資産、1つの識別情報

すべての資産には、発行者の発行キーと資産のテキスト説明から導出される一意の**資産識別子**があります。異なる2つの発行者が同じ識別子を生成することはできず、資産のミントまたは変更には発行者からの暗号学的認可が必要です。封筒のたとえで言えば、誰でも封筒を投函できますが、特定の資産を所有する造幣所だけが、その資産をさらに印刷できます。

### Zcash改善提案（ZIP）

- [ZIP 226](https://zips.z.cash/zip-0226): Zcash シールドされた資産の転送とバーン
- [ZIP 227](https://zips.z.cash/zip-0227): Zcash シールドされた資産の発行
- [ZIP 230](https://zips.z.cash/zip-0230): バージョン6トランザクション形式

> **ZIP 230に関する注記:** ZIP 230はその後撤回され、展開されることはありません。トランザクションバージョン6は現在、[ZIP 229](https://zips.z.cash/zip-0229)で定義されています。[ZIP 230](https://zips.z.cash/zip-0230)ページ上部のお知らせを参照してください。

ZIP 226は、カスタム資産の転送とバーンを扱うOrchardプロトコルの拡張であるOrchardZSAプロトコルを定義しています。ZIP 227は、これらの資産を最初に作成する方法を定義しており、ZIP 226と併せてのみ実装する必要があります。

### ZSA助成金提案

シールドされた資産（ZSA/UDA）のZSA提案は、[QEDIT](https://qed-it.com/)チームにより、Zcashブロックチェーン上で汎用的なシールドされた資産を構築するために提示されました。これらは通常、ユーザー定義資産（UDA）またはZcash シールドされた資産（ZSA）と呼ばれます。

この提案により、[QEDIT](https://qed-it.com/)のチームは、ZcashエコシステムにDeFiをもたらすと同時に、既存のDeFiエコシステム内で最高水準のプライバシー技術を利用可能にする計画です。投票調査では、チームが質問し、コミュニティは[汎用的なシールドされた資産（ZSA/UDA）が現在最も求められている機能である](https://twitter.com/BenarrochDaniel/status/1428327864034791429)と回答しました。

これらの提案は技術的に[Zcash改善提案（ZIP）](https://zips.z.cash/zip-0000)仕様に準拠しており、ZIP 226およびZIP 227で定義されています。

1. [ZIP 226](https://zips.z.cash/zip-0226): Zcash シールドされた資産の転送とバーン
2. [ZIP 227](https://zips.z.cash/zip-0227): Zcash シールドされた資産の発行

## 実際的な影響

**ZECを保有または使用している場合**

- ZSAはOrchard（「OrchardZSA」）の拡張として定義されているため、ZECがすでに使用しているシールドされた仕組みを共有します。ウォレットがZSAを保有または送信するには、明示的なZSAサポートが必要です。
- 常にZECをある程度保有している必要があります。ZSAの発行および転送にかかる手数料は、資産自体ではなくZECで支払われます。
- 既存のZECトランザクションに変更はありません。

**ステーブルコイン、DAO、企業など、発行者になる可能性がある場合**

- 資産の発行には発行キーに紐づいた暗号学的認可が必要なため、自身の資産をミントまたは属性変更できるのはあなただけです。
- 資産の流通供給量は公開監査可能ですが、利用者の残高と転送は公開されません。規制対象の発行者にとって、これは通常、まさに必要とされる組み合わせです。
- 1回の発行トランザクションで、複数の資産を同時に作成できます。

**エコシステムにとって**

- すべてのZSA手数料はZEC建てであるため、Zcash上で今後発行されるあらゆる資産の活動は、ZEC自体への需要を生み出します。

## よくある誤解

| よくある考え | 実際の状況 |
| --- | --- |
| 「ZSAは現在Zcashで稼働している。」 | 稼働していません。ZSAはNetwork Upgrade 7（NU7）の一部ではなく、[ZIP 259](https://zips.z.cash/zip-0259)ではZIP 226またはZIP 227なしで定義されています。また、現在もレビューとテストが進行中です。 |
| 「ZSAはZcashにスマートコントラクトをもたらす。」 | ZSAは資産の発行、転送、バーンを規定します。汎用的にプログラム可能なコントラクト層ではありません。 |
| 「ZSAの手数料はZSAトークン自体で支払える。」 | 手数料はZECで支払われます。 |
| 「シールドされているなら、トークン供給量も秘密でなければならない。」 | ZIP 227は、各資産の供給量を公開追跡できるよう、意図的に発行を公開型にしています。残高と転送は非公開のままですが、供給量は非公開ではありません。 |
| 「ZIP 230が現在のバージョン6トランザクション形式である。」 | ZIP 230は撤回されました。バージョン6は現在、ZIP 229で定義されています。 |
