# NU6.1

> NU6.1は、Zcashのメインネットでブロック3,146,400（2025年11月24日 UTC）に稼働開始しました。

ここで学べること：Zcashが、管理する企業なしにどのように自身の開発費を賄うのか、そしてNU6.1がコミュニティとコイン保有者にその資金について直接発言する権限をどのように与えたのか。

NU6.1は、Zcash[ネットワークアップグレード（network upgrade）](../start-here/network-upgrades)であり、[ZIP 255](https://zips.z.cash/zip-0255)で定義されています。これはZcashの開発のための新たな資金調達およびガバナンス（governance）モデルを整備しました。ブロック報酬の一部をどこに配分し、誰がそれを管理するかを定めるとともに、いくつかの小規模な技術的修正も導入しました。NU6.1は、Electric Coin CompanyとZcash Foundationの両方から承認されました。

これが重要な理由。多くのソフトウェアは企業によって資金提供されています。Zcashは単一の所有者を持たない分散型（decentralized）ネットワークであるため、難しい課題に直面します。コミュニティが信頼できる形で、開発を続ける人々にどのように資金を提供するのでしょうか。NU6.1は、Zcashの現在の答えです。すべてのブロック報酬の一部を、コミュニティ助成金用とコイン保有者自身が管理するものという、2つのプール（pool）に振り分けます。

![The NU6.1 funding split: most of each block reward goes to miners, 8 percent to Zcash Community Grants, and 12 percent to a coin-holder-controlled fund](/content-images/nu6-1-funding-split-890dcf6881.webp)

## 資金調達モデル

NU6.1は、各ブロック報酬を3つに分割します。

1. 最大の割合である約80パーセントは、ネットワークを保護するマイナー（miner）に送られます。
2. 8パーセントは、コミュニティによる、コミュニティのための活動に資金提供するZcash Community Grants（ZCG）に送られます。
3. 12パーセントは、Deferred Dev Fund Lockboxから初期資金が供給される、コイン保有者が管理する新しい基金に送られます。

このモデルのルールは[ZIP 1016](https://zips.z.cash/zip-1016)で定義されており、3回目のZcash半減期（halving）まで維持されます。これにより、恒久化または変更を決める前に、コミュニティがその仕組みを確認する時間を得られます。

## コイン保有者基金を管理するのは誰か

12パーセントの配分は新しい考え方です。企業や財団がその使途を決めるのではなく、コイン保有者がこれらの資金を放出するか保持するかを共同で決定します。

1. 以前のNU6アップグレードで作られたDeferred Dev Fund Lockboxが、この基金に初期資金を供給します。
2. コイン保有者は、エコシステムの活動のために資金を配分するか、ロックしたままにするかを共同で決定します。
3. これにより、ZECを保有する人々は、Zcashが将来にどのように資金を提供するかについて直接発言できます。

![The NU6.1 governance flow: the Deferred Dev Fund Lockbox seeds the coin-holder fund, and coin holders decide whether to distribute grants or hold the funds](/content-images/nu6-1-governance-21210bcc35.webp)

## 小規模な修正

NU6.1は、2つの技術的な点も整理しました。

1. NU6.1以前は、一部のRPCメソッドがOrchardプールからシールド解除される資金を正しく認識しなかったため、ウォレットとエクスプローラーで残高や手数料（fee）が誤って表示される場合がありました。NU6.1はこれを修正しました。
2. zcashdウォレットのデフォルトを、バージョン4ではなく、NU5で初めて導入された形式であるバージョン5トランザクションに変更しました。バージョン4のトランザクションも引き続き有効です。

## Zcashの資金調達の変遷

NU6.1は、Zcashがどのように自身の開発費を賄うかという、より長い物語における1つの段階です。

1. Canopy（2020）は、当初の創設者報酬を終了し、[開発基金](../start-here/development-fund)を創設しました。
2. NU6（2024）は、Deferred Dev Fund Lockboxを設置し、将来コミュニティが決定する助成金のために発行量の一部を確保しました。
3. NU6.1（2025）は、ブロック報酬の8パーセントをコミュニティ助成金に継続して配分し、12パーセントをその準備金から初期資金が供給されるコイン保有者管理基金へ振り分けることで、NU6が残した「誰が、どのように決めるのか」という問いに答えました。

![How Zcash funding evolved: Canopy created the development fund, NU6 set up the lockbox, and NU6.1 set the rules for who controls it](/content-images/nu6-1-funding-history-bcf6a94ad4.webp)

## 用語集

| 用語 | 平易な意味 |
|---|---|
| Block reward | 各ブロックがマイニングされる際に新たに作成され、支払われるZEC |
| Zcash Community Grants (ZCG) | Zcashコミュニティによる、コミュニティのための活動に資金提供する委員会 |
| Deferred Dev Fund Lockbox | NU6で設けられ、将来コミュニティが決定する助成金のために発行量の一部を保有する準備金 |
| Coin-holder fund | ロックボックスから初期資金が供給され、ZEC保有者が共同で管理するNU6.1基金 |
| Halving | ブロック報酬が半分に削減される予定されたイベント |
| Network upgrade (NU) | 所定のブロック高で有効化される、Zcashのコンセンサス（consensus）ルールへの協調的な変更 |

## よくある質問

NU6.1は私のZECやプライバシーを変更しますか？ いいえ。NU6.1は開発資金の調達方法に関するものであり、トランザクションやプライバシーに関するものではありません。あなたの資金とシールドされたトランザクションは影響を受けません。

資金はどこから来るのですか？ ブロックのマイニング時に発行される新しいZEC、すなわちブロック報酬からです。一部はすべてをマイナーに送る代わりに、助成金基金とコイン保有者基金に振り分けられます。

コイン保有者基金は何のためのものですか？ コイン保有者が共同で資金提供を選ぶエコシステム助成金、または待つことを望む場合に保持するためのものです。

これは恒久的ですか？ いいえ。このモデルは3回目の半減期まで運用され、その後コミュニティは維持、変更、または置き換えを選べます。

NU6.1はNU6とどのように異なりますか？ NU6はロックボックスを作りました。NU6.1は誰がそれを管理するか、また資金をどのように分割するかのルールを定めました。

## 理解度を確認する

NU6はロックボックスに資金のプールを確保しましたが、1つの大きな問いを未解決のまま残しました。それは何であり、NU6.1はどのように答えましたか？

<details>
<summary>回答</summary>

未解決の問いは、誰がロックボックスの資金の使い道を決めるかでした。NU6.1は、資金を分割することでこれに答えました。8パーセントをZcash Community Grantsに、12パーセントをコイン保有者自身が管理し、配分するか保持するかを選ぶ基金に送ります。
</details>
