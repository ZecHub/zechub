# Crosslink Protocol

## 要点

* Crosslink protocol は、Zcash のハイブリッド Proof-of-Work/Proof-of-Stake（PoW/PoS）段階に向けて提案されている設計です。PoW と Byzantine Fault Tolerance（BFT）プロトコルを統合し、PoW または PoS のいずれかが安全である限り、保証されたファイナリティを実現します。
* ハイブリッド PoS では、公証人がステークされた ZEC に基づいてブロックを検証します。初期段階では固定式で、その後はステークされた ZEC に基づいて選出されます。
* Crosslink は 2 つの台帳、すなわちロールバック安全性のための **finalized ledger (LOG_fin)** と、それを最大でも *L* ブロックだけ先行する **lower-latency ledger (LOG_ba)** を提供することを目指しています。
* finalized ledger が *L* ブロックを超えて遅れた場合、**Safety Mode** が有効になります。この間も PoW は継続しますが、問題が解決するまで経済活動は停止します。
* 時間の経過とともに、PoS バリデータは報酬のより大きな割合を受け取るようになり、PoW マイナーの収益は減少します。このプロトコルは、変更を段階的に導入します。
* このプロトコルは Shielded Labs によって開発されており、Crosslink 2* を Zcash の Zebra クライアントに統合するためのロードマップがあります。

## 中核的な説明

### はじめに: Zcash ハイブリッド PoS と Crosslink Protocol

Crosslink Protocol は、Zcash の進化における画期的な開発であり、**Hybrid Proof-of-Stake (PoS)** と **Proof-of-Work (PoW)** のモデルへと導きます。従来の PoW は、ネットワークの安全性を確保するうえで信頼性が高い一方で、エネルギー消費や産業的なマイニングに伴う中央集権化リスクについて批判を受けてきました。Crosslink はハイブリッドシステムを導入し、実証済みの PoW の堅牢性と、PoS の効率性およびガバナンス上の利点を組み合わせます。

![image](/content-images/a2ffb19d-e570-4723-b669-a66e14fc6b71-a727c958de.webp)

この移行は、ブロックチェーンの革新における世界的な流れとも一致しており、各プロジェクトが環境的に持続可能で分散化された仕組みへと移行しています。Crosslink の二重コンセンサスモデルにより、Zcash は強力な暗号学的プライバシー保証を維持しつつ、現代的な課題に対応するために進化できます。

ハイブリッド Proof-of-Stake（PoS）アプローチは、従来の Proof-of-Work（PoW）と PoS を組み合わせたもので、分散性を維持しつつエネルギー消費を抑え、51% 攻撃のような脆弱性に対処することを目指しています。ハイブリッド PoS では、公証人がステークされた ZEC に基づいてブロックを検証します。この仕組みは、チェーンの安全性とチェックポイント検証を向上させ、純粋な PoW システムよりも堅牢な代替案を提供するよう設計されています。

### なぜ最初のテストとして Hybrid PoS/PoW なのか？

* 純粋な PoS への前進になるため。
* マイニングとステーキングのユースケース、およびエコシステム間の相互活用を同時に可能にするため。
* PoS プロトコルが十分なバリデータのステークと信頼を得るまで、起こりうるセキュリティ上の問題を緩和するため。
* この一般的なアプローチは、Ethereum によって本番環境で実証されているため。

### Crosslink とは何か

Crosslink protocol は、Zcash のハイブリッド Proof-of-Work/Proof-of-Stake（PoW/PoS）段階に向けて提案されている設計です。PoW と Byzantine Fault Tolerance（BFT）プロトコルを統合し、PoW または PoS のいずれかが安全である限り、保証されたファイナリティを実現します。この設計は、マイナーの参加を維持しながら、ステークによる検証を取り入れることで、ネットワークの安全性と分散性を強化することを目的としています。Crosslink 2 と呼ばれる提案の主要な特徴は、BFT の提案者とマイナーを統合してアーキテクチャを簡素化することです。この簡素化されたアプローチは、構造上の変更を最小限に抑え、「ダミー」の BFT レイヤーを利用可能にすることで、高いセキュリティ基準を維持しながら、プロトタイプ化と展開を容易にします。

実装計画には、Crosslink 2* を Zcash の Zebra クライアントに統合するための推定エンジニアリングコストを含むロードマップがあります。この段階的な展開は、ステークホルダーのインセンティブの均衡を取り、混乱を減らし、スケーラビリティ、使いやすさ、分散性に関する Zcash の目標と整合させることに重点を置いています。プロトコルの堅牢なセキュリティ特性に対する信頼の高まりは、Zcash の進化における重要な一歩としての可能性をさらに強固なものにしています。エネルギー効率に対処し、コンセンサスメカニズムを強化することで、Crosslink は進化するブロックチェーンの課題に対する前向きな解決策を提供します。詳細については、[GitHub repository](https://github.com/ShieldedLabs/crosslink-deployment) と [Zcash Community Forum](https://forum.zcashcommunity.com) を参照してください。

### Crosslink の狙いと目的

Crosslink Protocol は、Zcash の将来にとって重要ないくつかの戦略的目標に対処するよう設計されています。

1. **分散化**:
   * PoS を取り入れることで、Zcash は特殊化された PoW ハードウェア（ASIC）への依存を減らします。ASIC はしばしば少数の大規模事業者にマイニングパワーを集中させます。
   * PoS により、より幅広いコミュニティが参加できるようになり、コイン保有者が自らの資産をステークしてネットワークを保護することで、より分散したコンセンサスが実現します。
   * ステークによる検証を導入することで、このプロトコルは経済的参加者がコンセンサスに積極的な役割を果たすことを保証し、マイニングのみに依存する状態を減らします。
2. **ガバナンスの強化**:
   * コイン保有者はステーキングを通じて投票権を得て、ネットワークアップグレード、資金配分、エコシステムの優先事項に関する意思決定に影響を与えられます。この民主的な仕組みは、プロトコルの進化をコミュニティの利益と一致させます。
3. **エネルギー効率**:
   * 部分的に PoS へ移行することで、エネルギー需要を大幅に低減し、Zcash を世界的な持続可能性イニシアチブに適合させます。PoS は、本質的に計算負荷の高い PoW と比べて必要資源が少ない仕組みです。ハイブリッドシステムは、高い安全性を維持しながら、PoW のみのシステムと比べてエネルギー使用量を下げることを目指しています。
4. **経済的安全性と持続可能性**:
   * PoW と PoS を組み合わせることで、ネットワーク参加者への経済的インセンティブが多様化され、単一の仕組みへの過度な依存なしに堅牢な安全性が確保されます。
   * また、ステーキングは参加者に予測可能な報酬モデルをもたらし、長期投資家にとって魅力的な提案となります。
5. **安全性の向上**: Crosslink は、PoW と並行して PoS を統合することで、チェーン再編成攻撃に対するネットワークの耐性を高めることを目指しています。

## 図解 / たとえ話

![image](/content-images/b34afda4-fe33-448f-b0dd-279fd6cef1f5-73f58cdcc6.webp)

同じ配達に対して 2 種類の書類を発行する宅配サービスを考えてみてください。1 つ目は追跡スキャンです。これはすぐに表示され、荷物が現在どこにある可能性が高いかを示しますが、ときどき訂正されます。2 つ目は署名付きの配達受領書です。これは後から届きますが、ひとたび存在すれば誰もそれに異議を唱えません。

lower-latency ledger は追跡スキャンであり、finalized ledger は署名付き受領書です。どちらも同じ出来事の連なりを記述していますが、現れる速さと、どれだけ確固としているかが異なります。

Safety Mode は、署名付き受領書が届かなくなっているのにスキャンだけが積み上がっていくときに、集配所が取る対応です。荷物は建物の中を引き続き移動しますが、署名が追いつくまでは、事務所はスキャンだけを根拠に支払いを行いません。

## 詳細解説

### Crosslink のセキュリティ目標とパフォーマンス目標

Crosslink protocol は、Zcash に対して 2 種類の台帳、すなわち **finalized ledger (LOG_fin)** と **lower-latency ledger (LOG_ba)** を提供することを目指しています。finalized ledger は、Byzantine Fault Tolerance（BFT）または blockchain（BC）プロトコルのいずれかについて合理的な前提が成り立つ限り、ロールバック安全性を保証します。これは、ネットワーク分断下であってもライブ性と安全性を維持するよう設計されており、同等のブロック確認に対するレイテンシは、現在の Zcash ブロックチェーンの 2 倍をやや上回る程度です。

lower-latency ledger は、finalized ledger を最大でも *L* ブロックだけ拡張します。これは、blockchain protocol のみの前提でロールバック安全性を保証し、既存の Zcash モデルより悪化しないレイテンシと安全性を維持します。簡素化された Crosslink 2* の設計では、lower latency ledger は PoW チェーンとして機能することで、開発と採用を単純化します。

![image](/content-images/fd039664-4852-4fb0-8c88-0615f1ed116e-41459b81dc.webp)

### 制限付き可用性と Safety Mode

Crosslink は、lower-latency ledger が finalized ledger を大きく引き離して進んでしまうことに伴うリスクに対処するため、**Safety Mode** を組み込んでいます。これにより、一時的な対処策におけるアカウント状態の不均衡や、サービス提供者による未検証のセキュリティギャップといった不整合を防ぎます。Safety Mode は、finalized ledger が一定の *L* ブロックを超えて遅れた場合に有効化されます。この状態の間、ブロックチェーンは PoW の運用を継続し（基本的な安全性を確保）、問題が解決するまで経済活動は停止されます。この仕組みは、大規模な攻撃のような例外的状況から回復しつつ、ガバナンスに基づくロールバック方針を支えるよう設計されています。

### 技術的詳細と展開

Crosslink Protocol は、Zodl などの主要なエコシステムパートナーと協力して、Shielded Labs により積極的に開発および展開が進められています。プロトコルの実装には以下が含まれます。

* PoS 参加者向けの安全なステーキングメカニズムの確立。
* マイナーとステーカーの間でインセンティブの均衡を取るための報酬構造の変更。
* 移行期間中の後方互換性とシームレスなユーザー体験の確保。
* 公証人システム: このプロトコルには、ブロックに署名する公証人が組み込まれています。初期段階では固定の公証人が使われ、その後、ステークされた ZEC に基づいて公証人が選出される動的なシステムへ移行します。
* 有効化ロジック: Crosslink の導入には、ステーク分配プロセスの定義や、ハイブリッドコンセンサスをサポートするためのネットワークプロトコルルールの更新を含む、Zcash コンセンサスルールの変更が必要です。
* 段階的展開: ネットワークの安定性とコミュニティの適応を確保するため、このプロトコルは段階的に導入されます。初期段階では技術実装に重点が置かれ、その後、公証人選出のためのガバナンス統合が続きます。

技術的な詳細を確認し、進捗を追跡するには、[Crosslink Deployment Repository on GitHub](https://github.com/ShieldedLabs/crosslink-deployment) を参照してください。

## 実務上の意味合い

### PoW マイナー収益への影響

Crosslink は、Zcash の初期発展における PoW マイナーの基盤的役割を認識しつつ、段階的な移行に備えています。

* **ブロック報酬の減少**:
  * 時間の経過とともに、PoS バリデータは報酬のより大きな割合を受け取るようになり、PoW マイナーの収益は減少します。この再分配は、ハイブリッドモデルにおける PoW の役割が縮小していくことを反映しています。
* **公正な移行**:
  * このプロトコルは変更を段階的に導入し、マイナーが適応したり、ステーキングへの移行や他のネットワークサービスへの貢献といった Zcash エコシステム内の新たな役割を模索したりするための十分な時間を確保します。
* **中央集権化リスクの緩和**:
  * PoS のステーキングプールは、権力の集中を防ぐよう設計されており、小規模な参加者にも対等な立場で参加する機会を提供します。この包摂的なアプローチは、ASIC ベースのマイニングで現在見られる集中に対抗します。
* ブロック報酬の一部が PoS バリデータへ再配分されるため、PoW マイナーの収益は減少します。この再配分により、ネットワーク保護に貢献するマイナーとステーカーの双方に報いる、均衡の取れたインセンティブシステムが実現します。
* マイナーへの経済的影響を緩和しつつ、ステークホルダーの参加を促進するため、段階的な移行が計画されています。

この二重コンセンサスメカニズムは、プライバシー、持続可能性、分散化に対する Zcash の取り組みを強化し、ブロックチェーン分野における先進的なリーダーとしての地位を確かなものにします。

## よくある誤解

**Crosslink をすでに有効なコンセンサスルールとして読むこと**。このページで説明しているのは、段階的な展開計画を伴う提案設計です。これを導入するには Zcash のコンセンサスルールの変更が必要であり、そのためにロードマップと Zebra への統合作業があります。

**PoS がマイニングを置き換えると考えること**。Crosslink はハイブリッド設計です。PoW によるブロック生成は、ステークによる検証と並行して継続します。Safety Mode であっても、経済活動が停止している間、ブロックチェーンは PoW の運用を継続します。

**「ファイナリティ」をより速い確認と捉えること**。finalized ledger は、同等のブロック確認に対して、現在の Zcash ブロックチェーンの 2 倍をやや上回るレイテンシになるよう設計されています。これが追加するのは速度ではなくロールバック安全性であり、高速なビューは lower-latency ledger のほうです。

**2 つの台帳を混同すること**。LOG_ba は別個のチェーンではありません。これは finalized ledger を最大でも *L* ブロックだけ拡張するものであり、Crosslink 2* 設計では PoW チェーンとして機能します。
