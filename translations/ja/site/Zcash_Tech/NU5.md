# NU5

> NU5は、Zcashメインネットのブロック1,687,104で稼働を開始しました（2022年5月31日 UTC）。

ここで学べること：NU5が、トラステッドセットアップを必要としない新しいシールドされたプールをZcashにもたらした方法、およびプールをまたいで利用できる単一のアドレスタイプについて学びます。

NU5（ネットワークアップグレード 5）は、Zcashの6番目の[ネットワークアップグレード](../start-here/network-upgrades)であり、[ZIP 252](https://zips.z.cash/zip-0252)によって導入されました。これは主要な暗号学的アップグレードです。Halo 2プルーフシステムに基づくOrchardシールドされた支払いプロトコル、統合アドレス、および新しいバージョン5トランザクション形式が導入されました。NU5は、Electric Coin Companyのzcashd v5.0.0リリースで提供されました。

これが重要な理由です。シールドされたプールは、それを作成したセットアップと同程度にしか信頼できません。Zcashの最初の2つのシールドされたプール、SproutとSaplingでは、それぞれの秘密パラメータを生成するために1回限りのトラステッドセットアップの式典が必要でした。これらのパラメータが破棄されずに保持されていた場合、誰にも見られずに偽造ZECを発行できた可能性があります。NU5のOrchardプールは、そのような式典を必要としないHalo 2プルーフシステムを使用することで、この懸念を解消します。

## トラステッドセットアップ

Orchardは、NU5によって導入され、[ZIP 224](https://zips.z.cash/zip-0224)で定義されたシールドされたプロトコルです。これは、PallasおよびVesta曲線サイクル上でPLONKish算術化と呼ばれる技法を使用するHalo 2プルーフシステムに基づいています。実用面での利点は単純です。Halo 2はトラステッドセットアップも構造化参照文字列も必要としないため、悪用され得る秘密パラメータは存在しません。

SproutとSaplingはいずれもトラステッドセットアップに依存していました。人々のグループが各プールのパラメータを作る式典を行い、全員が少なくとも1人が秘密の一部を破棄したと信頼する必要がありました。Orchardはその前提を取り除きます。古いプールはNU5後も存在するため、セットアップ不要の保証はOrchardプールに保有する資金に適用されます。

![Before NU5, Sprout and Sapling needed a trusted setup ceremony. After NU5, the Orchard pool uses the Halo 2 system and needs no trusted setup](/content-images/nu5-trusted-setup-5447dbe3f2.webp)

## NU5が変更したこと

NU5は複数のコンセンサス変更をまとめており、すべてブロック1,687,104で同時に有効化されました。

1. Orchardシールドされたプール（ZIP 224）、すなわち前述のHalo 2ベースのプロトコルを追加しました。
2. バージョン5トランザクション形式（ZIP 225）を追加しました。これは公開型、Sapling、および新しいOrchardデータのための個別領域を持つ再構成されたレイアウトです。Sproutフィールドは削除され、古いバージョン4形式は有効化後も有効なままでした。
3. 次節で扱う統合アドレスと統合ビューイングキー（ZIP 316）を導入しました。
4. トランザクション識別子の非可鍛性（ZIP 244）を採用しました。これは、トランザクションが行うことと、それを認可するプルーフおよび署名を分離する新しいトランザクションID計算方法です。
5. 非標準のエンコーディングを排除し、有効なトランザクションと見なされる条件のルールを厳格化するため、正規Jubjubポイントエンコーディング（ZIP 216）を採用しました。
6. ピアツーピアネットワーク全体でのバージョン5トランザクションのリレーを有効にしました（ZIP 239）。

NU5は、既存の複数のZIP（32、203、209、212、213、221、および401）も更新し、新しいOrchardプールを考慮するようにしました。

## 統合アドレス

NU5以前は、各プールに独自のアドレスタイプがあり、送信者はあなたがどの種類を望むか知る必要がありました。[ZIP 316](https://zips.z.cash/zip-0316)で定義された統合アドレスは、それを変えます。1つの統合アドレスは複数のプール向けの受信者をまとめられるため、送信者のウォレットは対応している中で最適なものを選択するだけです。

![A unified address bundles receivers for several pools: a transparent receiver, a Sapling receiver, and a new Orchard receiver](/content-images/nu5-unified-address-6e2c84f66e.webp)

統合ビューイングキーも、閲覧について同じように機能します。アドレスが対象とするプール全体に対して読み取り専用の可視性を提供します。詳細は、[ビューイングキー](../zcash-tech/viewing-keys)ページを参照してください。

## NU5の位置づけ

NU5は、Zcashの以前のアップグレードであるOverwinter、Sapling、Blossom、Heartwood、およびCanopyに続くものです。2022年5月31日にメインネットで有効化されました。Orchardの曲線サイクルは再帰をサポートするために選ばれており、これは後のスケーリング作業の基盤となります。NU5は、Orchardプールを基盤とし、その後修正を加えたNU6およびNU6.x系アップグレードの直接の前身です。

## 用語集

| 用語 | 平易な説明 |
|---|---|
| Network upgrade (NU) | Zcashのコンセンサスルールに対する協調的な変更であり、設定されたブロック高で有効化されます |
| Orchard | NU5が導入した、Halo 2プルーフシステムに基づくシールドされたプール |
| Halo 2 | トラステッドセットアップを必要としない、Orchardを支えるプルーフシステム |
| Trusted setup | プールの秘密パラメータを生成し、それらを破棄することが信頼されなければならない1回限りの式典 |
| Unified Address | 複数のプール向けの受信者をまとめられる単一のアドレス（ZIP 316） |
| Consensus branch id | トランザクションがどのルールセットに属するかを示す識別子 |

## よくある質問

NU5は私のZECまたはプライバシーを変えますか？ いいえ。NU5は新しいシールドされたプールと新しいアドレス形式を追加しました。既存のZECは影響を受けず、プライバシーが低下することもありません。資金をOrchardへ移すと、トラステッドセットアップを必要としないプールを利用できます。

Orchardとは何ですか？ Orchardは、NU5によって導入されたZcashのシールドされたプロトコルです。Halo 2プルーフシステム上で動作するため、トラステッドセットアップの式典は必要ありません。

何かする必要はありますか？ いいえ。対応ウォレットがNU5を処理します。古いアドレスを使い続けることができ、ウォレットが提供した時点で統合アドレスの利用を始められます。

統合アドレスとは何ですか？ 複数のプール向けの受信者を保持できる単一のアドレスです。送信者のウォレットが対応しているプールを選ぶため、種類ごとに別のアドレスを渡す必要はありません。

NU5は古い資金からトラステッドセットアップを取り除きますか？ 遡及的には取り除きません。Orchardはトラステッドセットアップを必要としませんが、Saplingプールの以前のパラメータはNU5後も存在します。セットアップ不要の保証は、Orchardプールに保有されている資金に適用されます。

古いトランザクション形式は機能しなくなりましたか？ いいえ。NU5はバージョン5形式を追加し、古いバージョン4形式は有効化後も有効なままでした。

## 理解度を確認しましょう

SproutとSaplingはいずれもトラステッドセットアップの式典を必要としました。NU5のOrchardプールは、それをどのように変えたのでしょうか。また、なぜ重要なのでしょうか。

<details>
<summary>回答</summary>

Orchardは、トラステッドセットアップも構造化参照文字列も必要としないHalo 2プルーフシステムに基づいています。これにより、残存する秘密パラメータがZECの偽造に使われる可能性がなくなります。この保証はOrchardプールに保有されている資金に適用されます。古いSaplingパラメータはNU5後も存在します。
</details>
