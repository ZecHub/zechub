# ウェブブラウザ（Web Browsers）

1. **Brave:** 現在市場にある最も有名で安全なブラウザの1つです。プライバシーを侵害する広告とトラッカーをブロックします。サードパーティによるデータ保存もブロックします。 

2. **Mullvad:** Mullvad VPNとTor Projectが共同で開発した、プライバシー重視のウェブブラウザです。トラッキングとフィンガープリンティングを最小限に抑えるよう作られています。

3. **Tor:** このブラウザは、Flash、RealPlayer、QuickTimeなどのプラグインをブロックします。これらはIPアドレスを明らかにするよう操作される可能性があります。Tor Browserには追加のアドオンやプラグインをインストールしないことを推奨します。


## ウェブブラウザを選択する際のセキュリティ上の考慮事項は何ですか？

ウェブブラウザを選択する際には、いくつか留意すべき点があります。セキュリティの脆弱性やエクスプロイトは通常、定期的に発見されます。一部のブラウザは何らかの方法で追跡可能ですが、匿名で閲覧できるブラウザもあります。たとえば、[Torブラウザ](https://download.torproject.org/)です。 

**フィンガープリンティング**: マシンにインストールされているソフトウェア、ハードウェア構成などを非公開にしたい場合は、フィンガープリンティング耐性機能をサポートするウェブブラウザを探すことを検討してください。 

**HTTPSテスト**: ウェブブラウザを選択する際に考慮すべきもう1つのセキュリティ要素は、ウェブサイト接続の暗号化を支援し、Cookie、URL、その他の機密メタデータを隠すHTTPSテストプロトコルです。HTTPSでは接続が暗号化され、ネットワーク上のサードパーティはサーバーとブラウザ間で転送されるコンテンツを読み取れません。 

**トラッキングCookie保護**: さらに、ワールドワイドウェブ上のウェブページの大部分には、隠されたサードパーティ製トラッカーがあります。これらのトラッカーはブラウザ内のCookieを読み書きします。これらのCookieは、ウェブサイトをまたいだ閲覧行動の追跡に使用される可能性があるため、悪意のある脅威となり得ます。この追跡を防ぐため、未知の閲覧Cookieをブロックするウェブブラウザを選択してください。

**ナビゲーションテスト**: あるウェブページから別のウェブページへ移動すると、多くのリンクに出会います。一部は内部リンクであり、他は別のウェブサイトへのリンクです。これらのリンクをクリックすると、特定のブラウザAPIにより、最初のサイトが2番目のサイトと通信できるようになります。これを解決するには、リンクをクリックした際にウェブサイト間でトラッキングデータを共有できないようにするウェブブラウザを選択してください。ニーズに適していると思うブラウザを選ぶ際は、強力なプライバシー機能と、組み込み広告ブロッカーなどの必須機能を備えていることを確認してください。さらに、こうしたウェブブラウザの多くは拡張機能やアドオンに対応しており、これらの拡張機能がセキュリティリスクとなることもあります。必ず安全なエコシステムまたは信頼できる提供元からこれらの拡張機能をインストールしてください。
 
## Brave Browser Zcash ウォレット（Wallet）統合

BraveブラウザはWeb3エコシステムへの道を切り開いています。どのようにでしょうか。現在、200万を超えるアンストッパブル・ドメインを分散型ウェブサイトの表示に活用できます。Brave Browsersの強力なセキュリティ機能により、人々は追跡されることなくインターネットを探索できます。BraveとZcashは、Web3エコシステムに新しいプライバシー・ツールをもたらすために協力しています。さらなる利点のため、BraveはBraveの組み込み暗号資産ウォレットを介してZcashプロトコルと迅速に統合し、暗号資産トランザクションを革新するでしょう。この統合により、ユーザーはZECをはじめとする他の暗号資産も、非常に簡単に安全に保管、送信、受信できるようになります。BraveウェブブラウザとZcashの連携は、ユーザーがWeb3活動をより細かく制御できるようになるため、真に状況を一変させるでしょう。 

BraveブラウザとZcashの統合に関するもう1つの興味深い点は、プライベートで分散型のメッセージング機能です。Brave、ECC、およびFilecoin Foundationチームは、Braveブラウザにプライバシーを基盤とする機能を導入する道を切り開いています。この連携は、Zcashプロトコルを介してプライベートメッセージとメディア伝送を提供することを目的としています。ここでは、Interplanetary File System（IPFS）が、暗号化されたコンテンツに安全なストレージ機能を提供するうえで不可欠な役割を果たします。
