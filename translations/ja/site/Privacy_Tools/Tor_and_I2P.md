# プライバシーが重要な理由

## 要約

- **Tor** はトラフィックを3つのリレー経由でルーティングし、通常のウェブとオニオンサービスの両方で機能します。現在では、ウォレット接続とブラウジングを匿名化するための実用的な標準選択肢です
- **I2P** は独自の内部サービス向けに設計された完全に暗号化されたピアツーピアのオーバーレイネットワークです。現在のZcashノードはI2Pをネイティブにサポートしていません
- **モバイルの場合：**Orbot（「Tor Enabled Apps」）を使えば、数回のタップでZcashウォレットをTor経由にできます
- **現時点でZcashノードをTor経由で運用することはできません：**`zcashd`は2026年7月18日にサポート終了となり、ZebraのTor機能は依然としてアップストリームで無効化されています
- Torは*あなたがどこにいるか*を隠しますが、*オンチェーン（on-chain）で何をするか*は隠しません。公開型トランザクションは引き続き公開されます

デジタル時代において、[プライバシー（privacy）](https://www.privacyguides.org/en/)を守ることはますます重要になっています。プライバシーを失われた大義だと考える人もいるかもしれませんが、そうではありません。あなたのプライバシーは危険にさらされており、懸念すべきものです。プライバシーは権力と関係するため大きな価値を持ち、その権力が責任を持って行使されることを確保することが重要です。

## TorとI2Pの技術

## Tor

[Tor](https://www.privacyguides.org/en/tor/?h=tor)は、Torネットワークを利用してアプリケーション向けの接続を確立するプロキシツールです。Torは、トラフィックをTor経由でルーティングすることでこれを実現し、これらのアプリケーションの[プライバシーと匿名性](https://www.torproject.org/)を向上させます。

## I2Pネットワーク

I2Pネットワークは、[Invisible Internet Project](https://geti2p.net/en/about/intro)とも呼ばれ、完全に暗号化されたピアツーピアのオーバーレイネットワークです。メッセージの内容、送信元、宛先が観察者から隠されることを保証します。言い換えると、誰もトラフィックの発信元や宛先、あるいは送信されるメッセージの実際の内容を見ることができません。I2Pで使用される暗号化は、ユーザーに高水準のプライバシーと匿名性を保証します。

### I2Pのインストール

実装は2つあります。元祖の[Java I2P](https://geti2p.net/en/download)はWindows、macOS、Linux、Androidで動作します。C++で書かれた[i2pd](https://i2pd.website/)はより軽量で、サーバーまたは低性能なマシンでは通常こちらが選ばれます。

起動すると、I2Pは`127.0.0.1:7657`でローカルコンソールを、`127.0.0.1:4444`（HTTP）および`127.0.0.1:4447`（SOCKS）でプロキシを公開します。初回起動には数分かかることを想定してください。I2Pは何かが機能する前にネットワークを通るトンネルを構築する必要があり、オンライン状態を長く保つほど高速になります。

### ZcashでI2Pを使用する

**現在のZcashノードはI2Pをネイティブにサポートしていないことに注意してください。**ZebraはI2Pをサポートしておらず、zcashdもサポートしていませんでした。ZcashノードをI2P経由で運用すると主張するガイドを見かけた場合、それはソフトウェアが実行しないことを説明しています。

ここでI2Pが本当に役立つのは、アドレスを明かさずにサイト、フォーラム、またはサービスにアクセスするなど、ウォレット周辺のすべてです。ウォレット接続そのものを匿名化するには、現在Torが実用的な選択肢であり、以下の節で説明します。

## TorとI2Pは共通の機能を持つ一方で、大きな違いもあります。 

TorとI2Pはいずれも分散型で匿名のピアツーピアネットワークですが、I2PはTorと比べてより高い水準のセキュリティを提供します。しかし、I2Pは主にネットワーク内でメール、チャット、トレントなどのサービスへアクセスするよう設計されており、通常のインターネットへのアクセスには使用できません。一方、Torは、I2Pと同様にユーザーがディープウェブへアクセスできるようにするだけでなく、サーフェスウェブ上のウェブサイトにアクセスするための通常のブラウザーとしても機能します。

*注：TorとI2Pの類似点および違いについての詳細は、[こちら](https://geti2p.net/en/comparison/tor)をご覧ください*

## Orbotを使ってモバイルウォレットをTor経由にルーティングする

Orbotは、デバイス上のすべてのアプリケーションのトラフィックをTorネットワーク経由にするよう設計された、スマートフォン向けの無料バーチャルプライベートネットワーク（VPN）です。

以下の手順に従って、ZcashウォレットをTor経由にルーティングしてください。このガイドの旧バージョンで使用していたYWalletは、現在は保守されておらず、Ironwood以降のネットワークを追跡しないため、[ウォレット](/using-zcash/wallets)ページから保守されているウォレットを選んでください。

1.  アプリストアから*Orbot*をダウンロードしてインストールします。

2.  インストール後、挨拶メッセージが表示されます。*Orbot*のホームページに進み、*「Tor Enabled Apps」*をクリックします。              

3.  これにより、Tor対応アプリケーションを表示するページが画面に表示されます。リストからZcashウォレットを探し、選択されていることを確認します。

4.  VPNを設定するための接続リクエストが表示され、*Orbot*がネットワークトラフィックを監視できるようになります。この許可が承認されると、*Orbot*が初期化されます。 

5.  タスクバーまたはOrbotのホームページを確認し、Torが稼働していることを確認します。「Connected to the Tor network」と表示されていれば確認できます。

*注：Torがモバイルネットワークでブロックされている場合は、代替の接続方法としてブリッジサーバーを使用できます。*


## PCまたはデスクトップへのTorのインストール

* Torブラウザーは公式ウェブサイトからダウンロードできます。リンクには[こちら](https://download.torproject.org/)からアクセスできます。

 Torをインストールする最も便利な方法は、Tor Browser Bundleを利用することです。ヘッドレスインストールを希望する場合は、Torデーモンを別途インストールできます。 

*注：デフォルトでは、Tor Browser Bundleはtcp/9150でSOCKSリスナーを公開し、Torデーモンはtcp/9050でSOCKSリスナーを公開します。*

* Tor Projectが提供する、オペレーティングシステム固有のインストール[手順](https://support.torproject.org/little-t-tor/getting-started/installing/)を参照してください。

## Tor経由でノードを運用する

これは最も大きく変わった部分であり、正直なところ、現在は以前より困難です。

**zcashdは終了しました。**2026年7月18日、ブロック3,417,100でサポート終了に達して停止しました。再起動することはなく、ダウンロードページは404を返し、aptリポジトリも提供されなくなりました。`zcashd -proxy=127.0.0.1:9050`を実行するよう指示する内容は、もはや何にも適用されません。

**Zebraもまだ実行できません。**Zebraは保守されているノードであり、そのネットワーククレートにはTor向けの隔離接続コードが含まれていますが、その機能は`zebra-network/Cargo.toml`でコメントアウトされています。

```
# tor = ["arti-client", "tor-rtcompat"]
```

クレートのドキュメントにも同じことが明記されています。*「Tor接続は、`arti-client`の依存関係である`x25519-dalek v1.2.0`が更新されるまで、現在無効化されています。」*`connect_isolated_tor`関数もそれとともにコメントアウトされています。したがって、現在ZcashノードをTor経由で運用するサポートされた方法はありません。

現在ノードレベルの匿名性が必要な場合、実行可能な方法は、ノード自体を設定するのではなく、マシン全体をTorまたはオペレーティングシステムレベルのVPNの背後に置くことです。これにより、実装されていないノード機能に依存することなく、ネットワーク上の所在地を保護できます。

### 現在もできること

- 上記の説明のとおり、モバイルではOrbotを使って**ウォレットをTor経由にルーティング**します。これはほとんどの人にとって実用的な選択肢であり、ウォレットが通信するlightwalletdサーバーからIPを隠します
- ブロックエクスプローラー、フォーラム、その他アドレスによる関連付けを避けたいあらゆる用途には、**Tor Browser**を使用します
- **Torが隠さないものを覚えておいてください。**これはネットワーク上の所在地を匿名化しますが、オンチェーン活動は匿名化しません。公開型アドレスからの送信は依然として公開され、シールドされたプール間を移動する価値は依然として金額を公開します。表示されたままとなる情報については、[シールドされたプール](/using-zcash/shielded-pools)を参照してください
