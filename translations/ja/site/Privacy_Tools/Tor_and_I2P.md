# プライバシーが重要な理由

デジタル時代において、自分の[プライバシー](https://www.privacyguides.org/en/)を守ることは、これまで以上に重要になっています。プライバシーはもはや失われたものだと考える人もいるかもしれませんが、そうではありません。あなたのプライバシーは危機にさらされており、真剣に考えるべき問題です。プライバシーは権力と関係しているため、大きな価値を持っています。そして、その権力が責任を持って行使されるようにすることが極めて重要です。

## Tor と I2P の技術

## Tor

[Tor](https://www.privacyguides.org/en/tor/?h=tor)は、Tor ネットワークを利用してアプリケーション用の接続を確立するプロキシツールです。Torbot は、トラフィックを Tor 経由でルーティングすることでこれを実現し、これらのアプリケーションの[プライバシーと匿名性](https://www.torproject.org/)を高めます。

## I2P ネットワーク

I2P ネットワークは、[Invisible Internet Project](https://geti2p.net/en/about/intro)としても知られており、完全に暗号化されたピアツーピアのオーバーレイネットワークです。これにより、メッセージの内容、送信元、宛先は観測者から隠されます。つまり、トラフィックの発信元や宛先、あるいは送信されているメッセージの実際の内容を誰も見ることができません。I2P で使われる暗号化は、利用者に高いレベルのプライバシーと匿名性を提供します。

### I2P のインストール

実装は 2 つあります。元祖の [Java I2P](https://geti2p.net/en/download) は Windows、macOS、Linux、Android で動作します。C++ で書かれた [i2pd](https://i2pd.website/) はより軽量で、サーバーや低性能なマシンでは一般的な選択肢です。

起動すると、I2P は `127.0.0.1:7657` にローカルコンソールを、`127.0.0.1:4444` にプロキシ（HTTP）、`127.0.0.1:4447` にプロキシ（SOCKS）を公開します。最初の起動では数分かかることがあります。I2P は動作を開始する前にネットワーク内にトンネルを構築する必要があり、オンライン状態を長く保つほど高速になります。

### Zcash で I2P を使う

**現在の Zcash ノードはどれも I2P をネイティブには話しません。** Zebra には I2P サポートがなく、zcashd にもありませんでした。Zcash ノードを I2P 上で動かすと主張するガイドを見かけても、それはソフトウェアが実際にはできないことを説明しているにすぎません。

ここで I2P が本当に役立つのは、ウォレットの周辺すべてです。つまり、自分のアドレスを明かさずにサイト、フォーラム、サービスへアクセスすることです。ウォレット接続そのものを匿名化したい場合、現時点で実用的な選択肢は Tor であり、以下のセクションでそれを説明します。

## Tor と I2P は共通する機能を持っていますが、重要な違いもあります。 

Tor と I2P はどちらも分散型で匿名性のあるピアツーピアネットワークですが、I2P は Tor と比べてより高いレベルのセキュリティを提供します。ただし、I2P は主に、そのネットワーク内で email、chat、torrenting のようなサービスにアクセスするために設計されており、通常のインターネットへアクセスすることはできません。一方で、Tor は I2P と同様に deep web へアクセスできるだけでなく、surface web 上のウェブサイトにアクセスするための通常のブラウザとしても機能します。

*注: Tor と I2P の類似点と相違点について詳しくは、[こちら](https://geti2p.net/en/comparison/tor)をご覧ください*

## Orbot を使ってモバイルウォレットを Tor 経由でルーティングする

Orbot は、スマートフォン向けに設計された無料の仮想プライベートネットワーク（VPN）で、デバイス上のすべてのアプリケーションのトラフィックを Tor ネットワーク経由にします。

以下の手順に従って、Zcash ウォレットを Tor 経由でルーティングしてください。なお、このガイドの以前の版で使われていた Ywallet は、現在はメンテナンスされておらず、Ironwood 以降のネットワークには追従しないため、[Wallets](/using-zcash/wallets) ページからメンテナンス中のウォレットを選んでください。

1.  アプリストアから *Orbot* をダウンロードしてインストールします。

2.  インストール後、歓迎メッセージが表示されます。*Orbot* のホームページに進み、*'Tor Enabled Apps'* をクリックします。              

3. すると、Tor に対応したアプリケーションが表示されたページが開きます。リストの中から自分の Zcash ウォレットを見つけて、必ず選択されていることを確認してください。

4. VPN を設定するための接続リクエストが表示されます。これにより、*Orbot* がネットワークトラフィックを監視できるようになります。この許可が承認されると、*Orbot* が初期化されます。 

5. タスクバーまたは Orbot のホームページを確認して、Tor が実行中であることを確認してください。'Connected to the Tor network' と表示されていれば確認できます。

*注: Tor がモバイルネットワークでブロックされている場合は、代替の接続方法として Bridge Server を利用できます。*


## PC またはデスクトップへの Tor のインストール

* Tor Browser は公式サイトからダウンロードできます。リンクは[こちら](https://www.torproject.org/download/)です。

 Tor をインストールする最も便利な方法は、Tor Browser Bundle を使うことです。ヘッドレスでのインストールを好む場合は、Tor デーモンを個別にインストールすることもできます。 

*注: デフォルトでは、Tor Browser バンドルは tcp/9150 で SOCKS リスナーを公開し、Tor デーモンは tcp/9050 で SOCKS リスナーを公開します。*

* Tor Project が提供している、使用しているオペレーティングシステム向けのインストール[手順](https://support.torproject.org/apt/)を参照してください。

## Tor 上でノードを実行する

ここが最も大きく変わった部分であり、率直に言えば、現在は以前より難しくなっています。

**zcashd は終了しました。** サポート終了に達し、2026 年 7 月 18 日にブロック 3,417,100 で停止しました。再起動することはなく、ダウンロードページは 404 を返し、apt リポジトリももはや配信されていません。`zcashd -proxy=127.0.0.1:9050` を実行するよう指示するものは、もはや何にも当てはまりません。

**Zebra もまだできません。** Zebra は現在メンテナンスされているノードですが、そのネットワーククレートには Tor 用の isolated-connection コードが含まれているものの、この機能は `zebra-network/Cargo.toml` でコメントアウトされています。

```
# tor = ["arti-client", "tor-rtcompat"]
```

クレートのドキュメントにも同じことがはっきり書かれています。*"Tor connections are currently disabled until `arti-client`'s dependency `x25519-dalek v1.2.0` is updated."* `connect_isolated_tor` 関数もそれとともにコメントアウトされています。したがって、現時点では Zcash ノードを Tor 上で実行するためのサポートされた方法はありません。

今すぐノードレベルの匿名性が必要なら、実用的なアプローチは、ノード自体を設定するのではなく、マシン全体をオペレーティングシステムレベルで Tor または VPN の背後に置くことです。これにより、実装されていないノード機能に頼ることなく、ネットワーク上の所在を保護できます。

### 今日でもまだできること

- **モバイルでは Orbot を使ってウォレットを Tor 経由でルーティングする**。上で説明したとおりです。これは大半の人にとって実用的な選択肢であり、ウォレットが接続する lightwalletd サーバーからあなたの IP を隠します
- **Tor Browser を使う**。ブロックエクスプローラー、フォーラム、その他アドレスで紐付けられたくないものに使えます
- **Tor が隠せないものを忘れないこと。** Tor が匿名化するのはネットワーク上の所在であり、オンチェーン上の行動ではありません。透過アドレスからの送信は依然として公開されますし、shielded pool 間をまたぐ価値移動では金額も依然として公開されます。何が可視のまま残るのかについては、[Shielded Pools](/using-zcash/shielded-pools) を参照してください
