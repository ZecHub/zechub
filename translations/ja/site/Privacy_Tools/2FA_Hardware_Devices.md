# 2FAハードウェアデバイス

データセキュリティとプライバシー（privacy）は、個人と企業の双方にとって重大な懸念事項です。サイバー攻撃とデータ侵害はますます一般的になっており、機密データを保護してプライバシーを維持するためには、積極的な対策を講じることが不可欠です。そのような対策の1つが、デバイスとデータを保護するための追加の保護層を提供するハードウェアセキュリティキーの使用です。

## ハードウェアセキュリティキーとは何ですか？

ハードウェアセキュリティキーは、アカウントとデバイスを保護するために2要素認証（two-factor authentication、2FA）で使用される物理デバイスです。ユーザー名とパスワードと連携して機能し、認可されたユーザーのみがアカウントとデータにアクセスできるようにします。

これらのキーは、ユーザー名とパスワードと連携して機能するよう設計されており、認可されたユーザーのみがアカウントとデータにアクセスできるようにします。ペンドライブ、NFCカード、Bluetoothデバイスなど、さまざまな形態があります。

![Hardware Security Key Example](/content-images/1dff66a4-d8e6-483f-9a1e-065d3974d665-a4c6c73e00.webp)

## ハードウェアセキュリティキーの仕組み

この技術をサポートするウェブサイトまたはプラットフォームで、ハードウェアセキュリティキーによる2FAを有効にする必要があります。たとえば、BinanceやCoinbaseの取引所です。

YubiKeyのようなハードウェアセキュリティキーでは、デスクトップ／ノートパソコンまたはスマートフォンのUSBポートまたはType-Cポートにハードウェアキーを接続するだけで、キーが認証を完了します。

## ハードウェアセキュリティキーを使用する利点は何ですか？

ハードウェアセキュリティキーには、従来のパスワードベースの認証方法に比べていくつかの利点があります。ブルートフォース、ソーシャルエンジニアリング、フィッシング攻撃によって容易に侵害される可能性があるパスワードよりも、はるかに攻撃が困難です。セキュリティキーは使用するたびに一意のコードを生成するため、攻撃者がそのコードを予測または複製することはほぼ不可能です。また、使いやすく設定も簡単で、デバイスに追加のソフトウェアやドライバーをインストールする必要がありません。

## ハードウェアセキュリティキーは、すべてのデバイスおよびオペレーティングシステムと互換性がありますか？

いいえ、ハードウェアセキュリティキーには多くの形式があり、すべてのデバイスおよびオペレーティングシステムと互換性があるとは限りません。キーを購入する前に、デバイスとオペレーティングシステムに対応していることを確認してください。

![Hardware Security Key Form Factors](/content-images/a830c435-ad20-4183-b381-475afe1089b3-5537cd7388.webp)

## ハードウェアセキュリティキーは複数のアカウントで使用できますか？

はい、1つのハードウェアセキュリティキーで、異なるウェブサイトやサービス上の複数のアカウントを保護できます。

## ハードウェアセキュリティキーを紛失した場合はどうなりますか？

ハードウェアセキュリティキーを紛失すると、アカウントがロックされるおそれがあります。この状況を避けるため、バックアップキーまたは代替の認証方法を用意しておくことをおすすめします。

## 2FAハードウェアの例

市場で入手できる2FAハードウェアの例をいくつか紹介します。

**Yubico YubiKey 5 NFC**

![Yubico YubiKey 5 NFC](/content-images/bf1ac95e-7277-4559-b5ef-63117b66971b-3aa542aba7.webp)

多くのセキュリティキーで使用されているFIDO U2Fオープン認証標準の共同開発元であるYubicoによって製造されているYubiKey 5 NFCは、デバイスを安全に保護します。名前が示すとおり、USB A（またはアダプター使用時はUSB C）またはNFCで動作します。  
Google Chrome、Facebook、Dropbox、LastPass、1Passwordなど、多くのサービスと標準で互換性があります。YubiKey 5はコンパクトで耐久性が高く軽量であり、防水仕様でもあります。  
サービスの手順に従い、求められたときにキーをUSBスロットに挿入すれば、問題なくYubiKeyを第2のU2F要素として設定できます。キーの金色の円にタップまたは押下するとキーが登録されるため、次回ログイン時にはパスワードを入力し、キーを挿入してタップするだけです。

**Thetis Fido U2Fセキュリティキー**

![Thetis Fido U2F Security Key](/content-images/b83e42e5-bba6-4175-ad6c-d64972ef54ef-a2ef17a10d.webp)

コストパフォーマンスに優れたセキュリティキーをお探しなら、Thetisのこのモデルを候補に入れるべきです。Bluetoothは搭載されておらず（より高価なモデルでは利用できます）、FIDO U2F標準のみをサポートするため、UAFまたはOTPとの互換性はありません。ただし、Windows、macOS、またはLinuxでChromeまたはOperaをブラウザーとして使用している場合、ウェブサイトへの安全なアクセスを提供します。  
便利なことに、この手頃なセキュリティキーは、持ち運び中にコネクターが損傷する可能性を防ぐ回転式アルミニウムケースを備えたコンパクトな折りたたみ設計です。ブラック、ゴールド、シルバーの魅力的な3色が用意されています。  
プラスチックケースは頑丈で比較的耐久性があるように感じられますが、バッグの中で重い物と一緒に入れないようにしてください。キーの穴は十分に大きくないため、キーチェーンやランヤードを取り付ける選択肢は限られます。

**CryptoTrust OnlyKey**

![CryptoTrust OnlyKey](/content-images/13be6ecc-227e-498c-8a36-6d52c023cd78-06e3e924dc.webp)

名前が示すとおり、OnlyKeyには競合製品にはない便利な機能があります。コンピューターに侵入したキーロガーを回避できる内蔵キーパッドにより、コンピューターまたはウェブサイトが侵害された場合でもオンラインアカウントを安全に保つことができます。FIDO 2 U2F、Yubico OTP、TOTPを含む複数の2FA方式をサポートしています。  
主流用途に最適なパスワードマネージャーではありませんが、OnlyKeyは1つのキーに24のOTPアカウント、24のパスワード、24のユーザー名／URLを保存できます。複数のパスワードを覚えたくなく、キーに任せたい場合に、この機能は非常に便利です。  
暗号化されたバックアップ、自己破壊機能（一定回数の誤った試行後にデバイスを消去します）、新機能にアクセスするためのファームウェア更新機能などを提供します。欠点として、ユーザーインターフェースは理想的とは言えません。

## 2FAハードウェアキーをGoogleアカウントに紐付ける

2FAハードウェアキーとは何か、またその仕組みを理解したところで、キーをGoogleアカウントに接続する方法を説明します。

**ステップ1**  
Gmailアカウントにログインし、**Google アカウントを管理**をクリックします。

![Google Account - Manage Account](/content-images/995fc955-791a-4456-9218-7e5964da48b5-31c64640b2.webp)

**ステップ2**  
**セキュリティ**をクリックします。

![Google Security Settings](/content-images/246db235-6596-41ff-bd7a-f8ee4f80962b-340193c2c3.webp)

**ステップ3**  
**2 段階認証プロセス**をクリックします。

![2-Step Verification Screen](/content-images/19cd202a-1a70-47e6-a02a-aa24f6e199fa-a9fcb911ce.webp)

**ステップ4**  
**その他のオプションを表示**を選択します。

![Show More Options](/content-images/2ade9531-1cf6-48e8-b9a8-178d41a4cd30-b1e9ea1400.webp)

**ステップ5**  
**セキュリティキー**を選択し、次に**詳細設定**をクリックします。

**ステップ6**  
2FAセキュリティキーを接続します。

**ステップ7**  
デバイスに付けたい名前を入力し、**完了**をクリックします。
