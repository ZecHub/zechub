# Penumbra 

Penumbraは、Cosmosエコシステムにおける、完全にシールドされたproof-of-stakeレイヤー1ネットワーク（network）および分散型（decentralized）取引所（exchange）です。そのインターチェーン・シールドされたプール（pool）は、IBCに接続されたチェーン（chain）の資産を保有できます。ユーザーは、個々のアカウント残高を公開したり、それらの行為を自身の身元と結び付けたりすることなく、Penumbra内で送金、ステーキング（staking）、スワップ（swap）、流動性の提供を行えます。ただし、これはネットワークまたはDEXデータのすべてがプライバシー（privacy）保護されていることを意味するわけではありません。

## Penumbra IBCで使用される技術 

IBC統合：インターブロックチェーン通信（IBC）プロトコルは、Penumbraを他のIBC対応チェーンに接続します。IBCの入金送金では、資金がPenumbraに入る際にシールドされます。出金送金では、資金が出る際にシールドが解除されます。入金の送付先アドレス（address）を含め、公開型（transparent）の相手方チェーン上の活動は公開されたままです。[プライバシー境界はIBC境界に従います](https://guide.penumbra.zone/overview/interchain-privacy)。

ゼロ知識（zero-knowledge）proof（ZKP）：Penumbraはクライアント側のゼロ知識proofを使用し、ユーザーの非公開トランザクション（transaction）データを公開することなく、暗号化（encryption）された状態更新が有効であることを示します。ウォレット（wallet）は、自身に表示されるデータをローカルでスキャンして復号します。公開ノード（node）がユーザーの非公開残高を単純に返すことはできません。

プライバシーを備えた分散型取引所：Penumbraには、そのシールドされたプール内で資産を取引するためのDEXが含まれています。個々のスワップ出力は非公開ですが、バッチ実行の結果と匿名の流動性ポジションは公開されています。取引所が何を隠すかを説明する際には、これらの違いが重要です。

## ユースケース（Use Cases）

安全なトランザクション：Penumbraのシールドされたプール内での送金は、送信者、受信者、金額、資産の種類を保護します。ユーザーは、許可された第三者に活動を選択的に開示できます。受取アドレスを共有するだけでは、その所有者の残高は公開されません。資金を引き出した後の別のチェーン上の公開活動には、これらの性質は適用されません。

ステーキング：Penumbraのネイティブ・ステーキングトークン（token）は**UM**です。UMをバリデーターに委任すると、そのバリデーターの委任プールにおける持分を表す委任トークンが返されます。各バリデーターのプールにある総ステークは公開されていますが、個々の委任は匿名です。委任解除では、まずバリデーター固有のアンボンディング・トークンが作成されます。これらはアンボンディング遅延が終了するまでスラッシングの対象であり続けます。公式の[シールドされたステーキングガイド](https://guide.penumbra.zone/overview/staking)をご覧ください。

トークンスワップ：スワップ意図は取引ペアごとにグループ化され、各ブロック（block）の終わりにバッチとして実行されます。これにより、トレーダーが利用できる手段としてのブロック内におけるスワップ意図の順序付けが排除されます。これは特定の仕組みであり、いかなる形態のMEVも存在しないことを保証するものではありません。バッチ結果は公開チェーン状態に書き込まれ、ユーザーは結果における自分の取り分をシールドされたプールへ非公開で請求します。[DEXガイド](https://guide.penumbra.zone/overview/dex)では、バッチ実行とプロトコルの自動アービトラージについて説明しています。

マーケットメイキング：流動性提供者は、匿名の集中流動性ポジションを作成します。ポジションの流動性と取引機能は公開されていますが、提供者の身元とは結び付けられていません。
