# Penumbra 

Penumbraは、Cosmosエコシステムで競争する最先端の完全にシールドされたレイヤー1ネットワークです。ユーザーは、メタデータをオンチェーン上で公開することなく、安全にトランザクションを行い、トークンをステーキングおよびスワップし、マーケットメイクできます。完全にシールドされたブロックチェーンとして、プライバシーや分散型の性質を損なうことなく、ウェブ上でシールドされたトランザクションも提供します。Penumbraはデフォルトでプライバシーを備えており、公開型トランザクションや公開型バリュープールは存在しません。

## Penumbra IBCで使用される技術 

IBC統合：最初に挙げられるのは、Penumbraの運用を促進する画期的かつ革新的な技術である、インターブロックチェーン通信（Inter-Blockchain Communication、IBC）プロトコルです。これは、ネットワーク内の相互運用性を向上させるうえで不可欠です。IBCは、異なるブロックチェーンネットワーク間の通信およびデータ交換を可能にします。さらに、IBCはPenumbra間におけるシームレスな資産移転、データ共有、相互作用を促進する重要な役割を担います。この相互運用性と技術により、ユーザーはさまざまなブロックチェーン間でトークンや資産を容易に移動できます。一方で、IBCはスケーラビリティにも貢献し、高速なトランザクションを実現し、パフォーマンスを最適化し、Penumbraのネットワークにおける遅延を低減します。

ゼロ知識proof（Zero-Knowledge Proofs、ZKPs）：Penumbraはゼロ知識proof暗号技術を活用し、送信者、受信者、送金額といった詳細を一切公開することなく、すべてのトランザクションが検証および妥当性確認されるようにしています。

プライバシーを備えた分散型取引所：Panumbraネットワークの中核にはプライバシーがあります。このネットワークは、取引および暗号資産トランザクションのプライバシーを促進しながら、金融データを保護し、ユーザーが自身の取引戦略の開示を管理する権利を得られる分散型取引所メカニズムを活用する可能性があります。

## ユースケース（Use Cases）

安全なトランザクション：Penumbraにより、ユーザーはあらゆる暗号資産でシールドされたトランザクションを試すことができます。Penumbraは完全にシールドされたブロックチェーンであるため、ユーザーはチェーン間を移動する際に送信者、受信者、金額、資産の種類を保護しながら、プライベートにトランザクションを行えます。これにより、トランザクションはプライベートに保たれ、ユーザーの許可なく追跡または復号されることはありません。Penumbraのすべてのアドレスは閲覧機能をサポートしていることに留意する価値があります。この設計により、ユーザーはコンプライアンスやその他の理由で承認した第三者に対し、自身の活動を開示することを選択できます。興味深いことに、Penumbraのトランザクションは低いトランザクション手数料で光速のように動作します。これはプルーフ・オブ・ステークのコンセンサスによるものです。 

ステーキング：俯瞰的に見ると、Penumbraは食物連鎖の頂点に留まりたいと考えています。世界初のシールドされたプルーフ・オブ・ステークネットワークとして、その唯一の目的は、委任者のプライバシーとバリデーターの説明責任を確保することです。Penumbraが提供するもう1つの興味深い機能はPENステーキングトークンであり、トークン保有者にオンチェーン投票プロセスを通じてプロジェクトのガバナンスに参加する権利を与えつつ、ネットワークを保護します。ネットワーク上のすべての委任者には、dPENと呼ばれるネイティブトークンが付与されます。なお、dPENはシールドされたプールに記録され、他のあらゆる資産と同様に取引できます。オンチェーンガバナンスの観点では、提案への投票と意思決定への参加を通じて、プロジェクトが中央集権的な組織に支配されないよう確保するステークホルダーの手に、ネットワークの将来は委ねられています。 

トークンスワップ：トークンスワップもPenumbraのユースケースです。このネットワークは、あらゆる種類の暗号資産間でシールドされたスワップをサポートしており、送信されるとすべてのスワップは封印されます。ZSwapを活用することで、ユーザーは取引履歴やタイムスタンプなど、金融詐欺の防止に役立つ可能性がある機密情報を公開せずに、あらゆるペアの暗号資産をスワップできます。最大抽出可能価値（Maximal Extractable Value、MEV）は公開型チェーンと同義ですが、Penumbraのような完全にシールドされたチェーンには、ネットワークトランザクションがユーザー活動に関するデータを漏洩しないため、MEVはありません。

マーケットメイク：完全にシールドされたチェーンであるPenumbraは、マーケットメーカーに対し、そのすべての活動を世界に公開するのではなく、取引戦略や特性に関する情報を開示するかどうかを管理する権限を与えます。
