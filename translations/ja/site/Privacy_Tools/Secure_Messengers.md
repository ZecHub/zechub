# セキュアメッセンジャー（Secure Messengers）

## エンドツーエンド暗号化（End-to-end encryption）

セキュアメッセンジャーにおいて、エンドツーエンド暗号化は会話を安全に保つためのセキュリティ手法です。メッセージがあるデバイスから別のデバイスへ送信される間は、メッセージの送信元であるコミュニケーションアプリケーションや第三者を含め、誰も対象のメッセージを読むことはできません。さらに、Facebook、Whatsapp、Zoomなど、多くの革新的で著名なメッセージングサービスプロバイダーがすでにエンドツーエンド暗号化技術を活用しています。 

## E2EEが必要な理由

エンドツーエンド暗号化技術は、金融、コミュニケーション、医療業界などを含む、データセキュリティが必要な場面で大きな役割を果たします。これにより組織は、データプライバシー（privacy）、セキュリティ規制、および法律に円滑に準拠できます。

**データプライバシー（Data Privacy）**: エンドツーエンド暗号化では、メッセージやデータにアクセスして復号できるのは、意図された受信者だけです。つまり、FacebookやWhatsAppなどのメッセージングサービスプロバイダーでさえ、内容を読むことはできません。この高いレベルのデータプライバシーは、金融トランザクション（transaction）、ビジネス上のコミュニケーション、または不正アクセスから守るべきプライベートチャットなどの機密情報を開示されたくないユーザーや組織にとって重要です。

**データセキュリティ（Data Security）**: この強力な技術により、転送中または保存中であっても、潜在的な侵害からデータを保護できます。
データはサーバーやインターネットを経由する際、ハッカーなどによる不正アクセスで傍受されやすくなる多くの要因にさらされます。エンドツーエンド暗号化技術では、送信されたデータは傍受される可能性があっても、送信者または受信者が暗号化（encryption）キーを保持している限り、読み取ることはできません。これにより、個人および組織のコミュニケーションを安全に保ちながら、データ侵害の規模と発生を減らせる可能性があります。

**信頼とユーザー制御（Trust and User Control）**: エンドツーエンド暗号化により、個人や組織はメッセージ、ファイル、その他の機密情報が不正アクセスから安全に守られていると理解した上で、自由にコミュニケーションできます。同様に、この技術は政府による介入や監視から個人や組織を保護する助けにもなります。

### 人気のセキュアメッセンジャー

**Zcash 暗号化されたメモ（Encrypted Memos）**

Zcash デスクトップおよびモバイルウォレット（wallet）には、プライベートなシールドされた（shielded）トランザクションで暗号化されたメッセージを送信できる機能が内蔵されています。メモ（memo）/メッセージのサイズは、トランザクションごとに最大512バイトで、トランザクション手数料（fee）は1米セント未満です。トランザクションの検出方法がプライバシーを保護する仕組みであること、およびネットワークのブロック（block）時間のため、メッセージの受信には1分以上かかる場合があります。 

試してみる: https://z.cash/wallets

**Signalアプリ**

![Signal App](/content-images/signal-app-logo-scaled-454032876-81b24a0421.webp)

Signalプライベートメッセンジャーは、最高水準のデータプライバシーを備えたセキュアなメッセージングアプリです。Signalプライベートメッセンジャーアプリは無料で使いやすく、ユーザーに事前の経験は必要ありません。Signalアプリには、コミュニケーションの完全なプライバシーを確保するエンドツーエンド暗号化技術があります。安全にプライベートメッセージを送りたい人は、サイバーセキュリティ上の脆弱性とデータフットプリントの両方を大幅に減らせるため、Signalプライベートメッセンジャーアプリの利用を検討すべきです。

試してみる: [https://signal.org/download/](https://signal.org/download/)

**BisonRelay**

![Bison Relay](/content-images/ogimg-v1-1000556235-9390372d1e.webp)

Bison Relayアプリは2022年に登場しました。Bison Relayはユーザーアカウントに依存しません。驚くべきことです！ここでは、送受信されるすべてのメッセージに対して、Decred Lightning Network経由で個別に支払いが行われます。このアプリの唯一の目的は、メタデータを最小化しながら、アカウントの必要性を完全になくすことです。一方で、Bison Relayは一般的に行われる検閲の実装方法に終止符を打ちました。 

試してみる: [https://bisonrelay.org/download](https://bisonrelay.org/download)

**Sessionアプリ**

![Session App](/content-images/logo-black-9e799f2b06.webp)

Sessionアプリをご存じでなくても、心配はいりません。概要をご紹介します。Sessionは、競争力のあるエンドツーエンド暗号化メッセンジャーの1つです。このアプリは機密性の高いメタデータを最小限に抑えるために構築されました。Sessionアプリは、完全なプライバシーとあらゆる形態の監視からの自由を求める人のために設計されています。Sessionアプリでは、電話番号やメールアドレスなしでアカウントを作成できるため、完全に匿名です。ユーザーはネットワーク経由で痕跡を残さずに安全にメッセージを送信できるため、漏洩するものはありません。

試してみる: [https://getsession.org](https://getsession.org)

## まとめ

エンドツーエンド暗号化は、堅牢なプライバシー保護を促進し、データセキュリティを根本から強化し、ネットワークやデバイスを介して情報が移動する際にも、ユーザーが自身の情報を完全に制御できるようにするため重要です。これにより、デジタル時代における重大な懸念に対処できます。
