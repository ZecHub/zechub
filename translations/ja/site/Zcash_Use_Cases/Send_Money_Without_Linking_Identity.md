# <img src="/content-images/send-svgrepo-com-b62f643de0.svg" width="24" height="24" alt="Journalist icon"/> 身元を結び付けずに送金する

<span className="inline-flex items-center gap-[6px]"><span className="inline-block w-[12px] h-[12px] bg-green-500 rounded-full"></span>中級 - 7分</span>

## 要点

- 必ず**シールドアドレス**から送金する
- `t から t` への直接取引は避ける
- 身元同士の結び付き可能性を断つ
- タイミングやパターンに注意する

<br/>

## <img src="/content-images/user-svgrepo-com-21adf62b7c.svg" width="24" height="24" className="inline-block align-middle mr-1 p-[2px]" alt="user icon"/> これは誰向け？

- 機微な支払いを送るすべての人
- プライバシー意識の高いユーザー
- 監視リスクのある環境で活動する人々

<br/>

## <img src="/content-images/warning-error-svgrepo-com-b7ea8a50da.svg" width="24" height="24" className="inline-block align-middle mr-1 p-[2px]" alt="warning icon"/> 問題点

暗号資産の送金では、しばしば次の情報が明らかになります:
- あなたのウォレットの身元
- あなたの取引履歴
- あなたが誰とやり取りしているか

これによって、**追跡可能な金融グラフ**が作られてしまいます。

<br/>

## <img src="/content-images/icons8-lock-2f8e221321.svg" width="24" height="24" className="inline-block align-middle mr-1 p-[2px]" alt="toolbox icon"/> なぜ Zcash なのか？


Zcash は、シールド取引を使って**完全にプライベートな送金**を可能にします。

これにより、次のことを断てます:
- アドレスの結び付き可能性
- 公開された取引追跡

<br/>

## <img src="/content-images/icons8-toolbox-9bebbb1619.svg" width="24" height="24" className="inline-block align-middle mr-1 p-[2px]" alt="toolbox icon"/> 必要なもの

- シールド取引に対応したウォレット
- z-address の基本的な理解

<br/>

## <img src="/content-images/ladder-svgrepo-com-7232bf46ed.svg" width="24" height="24" className="inline-block align-middle mr-1 p-[2px]" alt="step icon"/> ステップごとのガイド

### ステップ1: 資金がシールドされていることを確認する

資金が透明アドレスにある場合:
- まずシールドアドレスに移してください


### ステップ2: シールドからシールドへ送る
常に `z から z` の取引を優先しましょう

これにより、最大限のプライバシーが確保されます。


### ステップ3: 身元の結び付きを避ける

次のことはしないでください:
- 取引を公開の場で告知する
- 同じアドレスを異なる文脈で使い回す
- アドレスを既知の身元に結び付ける

### ステップ4: タイミングのパターンを考慮する

上級者向けのヒント:
- 多額の受け取りの直後にすぐ送金するのは避ける
- 可能な限り予測可能なパターンを崩す

<br/>

## <img src="/content-images/icons8-cancel-7f786be3c1.svg" width="24" height="24" className="inline-block align-middle mr-1 p-[2px]" alt="cancel icon"/> 避けるべきよくあるミス

- 透明アドレスから直接送金する  
- 複数の相手に対してアドレスを使い回す  
- 取引を公に確認する  
- メタデータ（タイミング、頻度）を無視する

<br/>

## <img src="/content-images/checked-checkbox-svgrepo-com-7ea19022da.svg" width="28" height="28" className="inline-block align-middle mr-1 p-[2px]" alt="done icon"/> 結果

次のことができるようになります:
- 資金を非公開で送る
- 自分の身元との結び付きを避ける
- 追跡可能性を下げる
