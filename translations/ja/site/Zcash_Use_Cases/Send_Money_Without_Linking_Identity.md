# <img src="/content-images/send-svgrepo-com-b62f643de0.svg" width="24" height="24" alt="Journalist icon"/> 身元を紐付けずに送金する

<span className="inline-flex items-center gap-[6px]"><span className="inline-block w-[12px] h-[12px] bg-green-500 rounded-full"></span>中級 - 7分</span>

## 要約

- 常に**シールドされたアドレス（shielded address）**から送金してください
- 公開型から公開型への直接トランザクションは避けてください
- 身元間の紐付け可能性を断ち切ってください
- タイミングとパターンに注意してください

<br/>

- 機密性の高い支払いを行うすべての人
- プライバシーを重視するユーザー

<br/>

## <img src="/content-images/warning-error-svgrepo-com-b7ea8a50da.svg" width="24" height="24" className="inline-block align-middle mr-1 p-[2px]" alt="warning icon"/> 問題点

暗号資産を送ると、しばしば以下が明らかになります。
- あなたのウォレット（wallet）の身元
- あなたのトランザクション履歴
- あなたが誰と関わっているか

これにより、**追跡可能な金融グラフ**が作られます。

<br/>

## <img src="/content-images/icons8-lock-2f8e221321.svg" width="24" height="24" className="inline-block align-middle mr-1 p-[2px]" alt="toolbox icon"/> なぜZcashなのですか？


Zcashでは、シールドされたトランザクションを使用して**完全にプライベートな送金**が可能です。

これにより、以下を断ち切れます。
- アドレスの紐付け可能性
- 公開トランザクションの追跡

<br/>

## <img src="/content-images/ladder-svgrepo-com-7232bf46ed.svg" width="24" height="24" className="inline-block align-middle mr-1 p-[2px]" alt="step icon"/> ステップごとのガイド

### ステップ1: 資金がシールドされていることを確認する

資金が公開型アドレスにある場合：
- まずシールドされたアドレスに移してください


### ステップ2: シールドされた状態からシールドされた状態へ送る
常に`z to z`トランザクションを優先してください

これにより、最大限のプライバシーが確保されます。


### ステップ3: 身元の紐付けを避ける

以下を行わないでください。
- トランザクションを公に告知する
- 異なる文脈で同じアドレスを再利用する
- アドレスを既知の身元に紐付ける

### ステップ4: タイミングのパターンを考慮する

上級者向けのヒント：
- 大きな金額を受け取った直後に送金することは避けてください
- 可能な場合は、予測可能なパターンを崩してください

<br/>

## <img src="/content-images/icons8-cancel-7f786be3c1.svg" width="24" height="24" className="inline-block align-middle mr-1 p-[2px]" alt="cancel icon"/> 避けるべきよくある間違い

- 公開型アドレスから直接送る  
- 複数の人に対してアドレスを再利用する  
- トランザクションを公に確認する  
- メタデータ（タイミング、頻度）を無視する
