## TL;DR

- **シールドされた（z）アドレス**を使う
- 透明な（t）アドレスを公開しない
- 寄付者にはシールド対応ウォレットから送金するよう勧める
- 自分の身元と取引を結び付けないようにする

<br/>

## <img src="/content-images/user-svgrepo-com-21adf62b7c.svg" width="24" height="24" className="inline-block align-middle mr-1 p-[2px]" alt="user icon"/> これは誰向け？
- 寄付を受け付けるクリエイター
- オープンソースへの貢献者
- 資金を集めるコミュニティ
- 金銭的支援をプライベートに受け取りたいすべての人

<br/>

## <img src="/content-images/warning-error-svgrepo-com-b7ea8a50da.svg" width="24" height="24" className="inline-block align-middle mr-1 p-[2px]" alt="warning icon"/> 問題点

ほとんどの暗号資産は、あらゆる情報を公開してしまいます：
- あなたのウォレット残高
- 誰があなたに送金したか
- あなたの全取引履歴

これにより、深刻なリスクが生じます：
- 金融プライバシーの喪失
- 標的化や監視
- 寄付者の公開的な露出

<br/>

## <img src="/content-images/icons8-lock-2f8e221321.svg" width="24" height="24" className="inline-block align-middle mr-1 p-[2px]" alt="toolbox icon"/> なぜZcashなのか？

Zcashのシールド取引では、以下が隠されます：
- 送信者アドレス
- 受信者アドレス
- 取引金額

これにより、**あなたの金融グラフを公開することなく**資金を受け取れます。

<br/>

## <img src="/content-images/icons8-toolbox-9bebbb1619.svg" width="24" height="24" className="inline-block align-middle mr-1 p-[2px]" alt="toolbox icon"/> 必要なもの

- シールドアドレスをサポートするZcashウォレット：
  - Zodl
  - YWallet
  - その他の対応ウォレット

<br/>

## <img src="/content-images/ladder-svgrepo-com-7232bf46ed.svg" width="24" height="24" className="inline-block align-middle mr-1 p-[2px]" alt="step icon"/> ステップごとのガイド

### ステップ1：シールドアドレスを作成する
ウォレットを開いて、**zアドレス**を生成します。
通常、次のように始まります：`zs...`


### ステップ2：シールドアドレスだけを共有する

- 次の場所にzアドレスを掲載します：
  - ウェブサイト
  - ソーシャルメディア
  - 寄付ページ

**透明な（t）アドレスは共有しないでください。**

### ステップ3：寄付者を案内する（任意ですが推奨）

寄付者に次のことを勧めましょう：
- シールド取引をサポートするウォレットを使う
- シールドプールから送金する（透明ではなく）

### ステップ4：基本的なプライバシー衛生を保つ

- 無関係な複数の身元で同じアドレスを使い回さない
- 必要がない限り、自分のアドレスを個人の身元と公に結び付けない

<br/>

## <img src="/content-images/icons8-cancel-7f786be3c1.svg" width="24" height="24" className="inline-block align-middle mr-1 p-[2px]" alt="cancel icon"/> 避けるべきよくある間違い

- 透明な（t）アドレスを共有する  
- 個人の身元情報と一緒にウォレットを投稿する  
- シールドせずに透明な送金元から資金を受け取る  
- 同じアドレスを複数の文脈で使い回す  

<br/>
