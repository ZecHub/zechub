## 要約

- **シールドされた（shielded）(z) アドレス**を使用します
- 公開型（transparent）(t) アドレスを公開しないでください
- 寄付者にはシールドされたウォレットから送るよう促します
- 自分の身元をトランザクションに結び付けないようにします

<br/>

## <img src="/content-images/user-svgrepo-com-21adf62b7c.svg" width="24" height="24" className="inline-block align-middle mr-1 p-[2px]" alt="user icon"/> 対象者
- 寄付を受け取るクリエイター
- オープンソースへの貢献者
- 資金を募るコミュニティ
- プライベートな資金支援を望むすべての人

<br/>

## <img src="/content-images/warning-error-svgrepo-com-b7ea8a50da.svg" width="24" height="24" className="inline-block align-middle mr-1 p-[2px]" alt="warning icon"/> 問題点

ほとんどの暗号資産では、すべてが公開されます。
- あなたのウォレット（wallet）残高
- 誰があなたに資金を送ったか
- あなたのトランザクション（transaction）履歴全体

これにより、重大なリスクが生じます。
- 金融プライバシー（privacy）の喪失
- 標的化や監視
- 寄付者の情報が公開されること

<br/>

## <img src="/content-images/icons8-lock-2f8e221321.svg" width="24" height="24" className="inline-block align-middle mr-1 p-[2px]" alt="toolbox icon"/> Zcashを使う理由

Zcashのシールドされたトランザクションは、以下を隠します。
- 送信者アドレス（address）
- 受信者アドレス
- トランザクション金額

これにより、**金融関係のネットワークを公開せずに**資金を受け取れます。

<br/>

## <img src="/content-images/ladder-svgrepo-com-7232bf46ed.svg" width="24" height="24" className="inline-block align-middle mr-1 p-[2px]" alt="step icon"/> 手順ガイド

### ステップ1: シールドされたアドレスを作成する
ウォレットを開き、**zアドレス**を生成します。
通常、次の文字列で始まります：`zs...`


### ステップ2: シールドされたアドレスだけを共有する

- zアドレスを以下に掲載します。
  - ウェブサイト
  - ソーシャルメディア
  - 寄付ページ

**公開型 (t) アドレスは共有しないでください。**

### ステップ3: 寄付者を案内する（任意ですが推奨）

寄付者に以下を促します。
- シールドされたトランザクションをサポートするウォレットを使用すること
- シールドされたプール（pool）（公開型ではないもの）から送金すること

### ステップ4: 基本的なプライバシー対策を維持する

- 関係のない身元情報で同じアドレスを再利用しないようにします
- 必要な場合を除き、アドレスを個人の身元情報と公開で結び付けないでください

<br/>

## <img src="/content-images/icons8-cancel-7f786be3c1.svg" width="24" height="24" className="inline-block align-middle mr-1 p-[2px]" alt="cancel icon"/> 避けるべきよくある間違い

- 公開型 (t) アドレスを共有すること  
- ウォレットを個人の身元情報とともに掲載すること  
- シールドせずに公開型の送信元から資金を受け取ること  
- 複数の状況で同じアドレスを再利用すること
