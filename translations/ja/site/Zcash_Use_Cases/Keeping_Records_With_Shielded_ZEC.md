# シールドされた（shielded）ZECで記録を管理する

## 要約

- シールドされた資金はプライベートですが、整理された完全な財務記録を保持できます
- メモは、請求書番号や支払いの目的など、元帳の明細として機能します
- ビューイングキー（viewing key）を使うと、自分や会計士など選択した相手が、公開せずに履歴を確認できます
- 任意の期間について収入と支出を合計でき、これは報告や税務に必要なものです
- 誰が何を見るかは自分で決められるため、これによってプライバシーが損なわれることはありません

<br/>

## これは誰のためのものですか？

- ZECで報酬を受け取るフリーランサーや中小企業
- プライベートな状態を保ちながら帳簿を管理する必要がある人
- 会計士や税務のための記録を準備している人

<br/>

## 課題

プライバシーと記録管理は正反対のものに感じられることがあります。トランザクションがシールドされている場合、金額とアドレスは一般に公開されないため、適切な帳簿を管理したり、会計士に収入を示したりするにはどうすればよいのでしょうか。

Zcashでは、これは誤ったトレードオフです。シールドされたトランザクションはデフォルトであなたの活動をすべての人から隠しますが、Zcashは、必要とする人々に対して自分の記録を自分の条件で開示するためのツールも提供します。世界に対してはプライベートなままで、同時に会計士に対しては情報を公開できます。

<br/>

## メモはあなたの元帳です

すべてのシールドされた（zからzへの）トランザクションには、暗号化された[メモ（memo）](/using-zcash/memos)を含められます。記録管理において、メモには支払いの目的を記載します。たとえば請求書番号、顧客名、プロジェクトコード、または「3月の家賃」のような短いノートです。

メモはトランザクションとともに送られ、関係者だけが読めるため、帳簿内のプライベートな明細になります。自分または顧客が各支払いに明確なメモを含めることで、トランザクション履歴は、文脈のない金額の一覧ではなく、利用可能な元帳になります。

簡単な習慣として、常にメモに請求書番号を含めるよう顧客と合意してください。後で支払いと請求書を照合する作業が簡単になります。

<br/>

## 自分の履歴を確認する

帳簿を管理するには、自分の活動を確認する必要があります。ウォレット（wallet）にはシールドされたトランザクションを復号する鍵が保管されているため、ウォレットでは全体像を確認できます。日付、金額、受け取ったもの、送ったもの、および添付されたメモです。

これは一般には見えない部分ですが、データは自分のものなので確認できます。年末ではなく定期的に履歴を確認することで、記録を正確に保ち、誤りを見つけやすくなります。

<br/>

## 会計士と記録を共有する

会計士や監査人など、他の人にシールドされた活動を見せる必要がある場合、支出鍵（spending key）を渡したり、何かを公開したりする必要はありません。[ビューイングキー](/zcash-tech/viewing-keys)を共有します。

フルビューイングキーは読み取り専用です。保有者は、金額やメモを含め、あるアドレスへの入出金トランザクションを確認できますが、資金を動かすことは決してできません。そのため、会計士に渡すのに安全です。会計士は必要な可視性を正確に得られ、資金は自分の管理下に置かれたままであり、世界の他の人々には依然として何も見えません。

これは選択的開示（selective disclosure）と呼ばれ、シールドされたZcashが適切な帳簿管理を妨げるのではなく可能にする実用的な理由の1つです。

<br/>

## 期間ごとの合計

ほとんどの報告では、一定期間の合計が必要です。この四半期に受け取った金額、送った金額、純額などです。自分の完全な履歴を確認できるため、1か月、1四半期、1年など、選択した任意の期間についてこれらを合計できます。

メモを一貫して記録すると、日付や金額だけでなく支払いの目的ごとに分類できるため、これが簡単になります。

<br/>

## 税務に関する注意

税制は国ごとに異なり、時間とともに変わるため、これは一般的な情報であり税務上の助言ではありません。多くの地域では、暗号資産を受け取ることや処分することが税務上の影響を持つ場合があり、受け取ったもの、受け取った時期、およびその時点の価値を記録しておくことが求められる場合があります。

良い知らせは、シールドされたZcashがこれらの義務を果たす妨げにはならないことです。完全なプライベート記録を保持し、税務当局が要求する期間について合計し、活動を公開することなくビューイングキーを使って会計士または税務当局に開示できます。自分の義務が不明な場合は、自国の資格を持つ専門家に相談してください。

<br/>

## 避けるべきよくある間違い

- メモを省略し、年末に金額だけで文脈がない状態にすること
- すべてに1つのアドレスを再利用し、顧客や目的を分けにくくすること
- 日々記録を保持せず、税務シーズンまで待って1年分の履歴を確認すること
- 会計士に必要なのが読み取り専用のビューイングキーだけであるにもかかわらず、支出鍵を共有すること
