# 金融プライバシー財団（Financial Privacy Foundation、FPF）
![FPF](/content-images/FPFgrants-226bdea4bb.webp)

## FPFについて
Financial Privacy Foundation（FPF）は、ケイマン諸島で法人化された非営利団体です。FPFの主な目標は、個人やコミュニティが自身の金融上のプライバシーとセキュリティを管理できるよう、教育し支援することです。FPFはまた、個人のプライバシーを尊重する公正かつ公平な金融システムの推進にも取り組んでいます。金融プライバシーに関するFPFの主な活動は、個人やコミュニティが金融上のプライバシーを保護・最適化するための情報、リソース、支援を提供することです。Financial Privacy Fund（FPF）は現在、FPF X FPFという名称の助成金（grant）プログラムを作成しています。

##  FPF X FPFに関する情報

 FPF X FPFは、FPF初の実験的助成金プログラムであるFinancial Privacy Fund（FPF x FPF）に関するものです。このプログラムは、完成間近のZcashエコシステム内のエンジニアリングプロジェクト、またはエコシステムに即座に貢献し、指定された期間および資金の上限内で完了できるプロジェクトに資金を提供します。FPF X FPFは、助成金の資金提供プロセスを改善するため、非常に限られた資金で開始され、将来のラウンド開始を目指しています。

## FPF X FPFプログラムの詳細 

FPF X FPFプログラムの詳細として、FPFには以下の内容があります。

- 資金額：最大$50,000 USDです
- 最大申請額：$25,000 USDです
- KYC要件：ありません
- プロジェクトの種類：Zcashエコシステムに直接利益をもたらし、完全に完了できるエンジニアリングプロジェクトのみが検討されます。
- 支払い（Payment）：プロジェクトの完了が成功した時点で行われます
- 開始日：2024年3月18日です

## 助成金申請プロセス 

FPF X FPFの助成金申請プロセスには、いくつかの段階があります。まず、申請者は提供された安全なフォームを通じて助成金を申請する必要があります。その後、FPFが申請の適格性を審査し、申請締切日から5暦日以内に申請者へ状況が通知されます。次に、臨時の審査委員会が提出締切日から20暦日以内に助成金の交付について審査・決定します。透明性と説明責任のため、交付された助成金の詳細はFPFのウェブサイトで公開されます。
