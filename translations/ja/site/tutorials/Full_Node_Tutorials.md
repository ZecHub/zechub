# フルノードのチュートリアル

Zcash フルノードは、ネットワーク上の透明トランザクションとシールドトランザクションを検証します。フルノードを稼働させることで、ネットワークのレジリエンスと安定性に貢献できます。さらに、フルノードを運用することで、ユーザーはより高い安全性とセキュリティ保証を得られます。以下は、zcashd または zebrad フルノードのセットアップ/アップグレードのための動画ガイドです。

> **注:** zcashd は、ノードとしての [Zebra](https://github.com/ZcashFoundation/zebra)（`zebrad`）およびウォレットとしての [Zallet](https://github.com/zcash/zallet) を優先するため、[非推奨化](https://z.cash/support/zcashd-deprecation/) が進められています。以下の zcashd 動画は参考用として残されています。新規セットアップについては、[移行ガイド: zcashd から Zebrad/Zallet へ](https://zechub.wiki/migration-guide-zcashd-to-zebrad-zallet) に従ってください。

詳細については、[フルノードガイド](https://zechub.wiki/full-nodes)をご覧ください。
