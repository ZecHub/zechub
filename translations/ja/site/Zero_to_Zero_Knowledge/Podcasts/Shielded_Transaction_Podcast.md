# Foresight Instituteによるシールドされた（Shielded）トランザクション（Transactions）ポッドキャスト

Foresight Instituteは、影響力の大きい技術の有益な発展を支援する研究組織および非営利団体です。強力な技術を導くというビジョンのもと1987年に設立されて以来、従来の機関では支援が難しいほど野心的な複数の科学技術分野に注力する、多方面に活動する組織へと発展し続けてきました。
