# Zcashのネットワークアップグレード

Zcashはネットワークアップグレードによって改善されます。これは、すべてのノードが合意するルールへの協調的な変更であり、それぞれ所定のブロック高で有効化されます。以下の各アップグレードには、それぞれ専用のページがあり、何がどのように変更され、なぜ変更されたのかを平易な言葉で説明しています。Zcashを初めて知る方は、SproutからIronwoodまで順番に読んでください。

これらのアップグレードを通じてZcashのプライバシーがどのように進化してきたかを視覚的にたどるには、[プライバシーの進化](https://zechub.wiki/zcash-evolution)をご覧ください。このページは索引です。そちらはタイムラインです。

| Upgrade | Activation (UTC) | Block | Branch id | What it changed |
|---|---|---|---|---|
| [Sprout](../zcash-tech/sprout) | 2016年10月28日 | genesis | 00000000 | ローンチ：最初のシールドプールとzk-SNARKのプライベートトランザクション |
| [Overwinter](../zcash-tech/overwinter) | 2018年6月26日 | 347,500 | 5ba81b19 | リプレイ保護、トランザクションのバージョニング、そして有効期限により、安全なアップグレードが可能になった |
| [Sapling](../zcash-tech/sapling) | 2018年10月29日 | 419,200 | 76b809bb | 効率的なシールドトランザクションにより、スマートフォンやハードウェアウォレットでも十分高速に利用可能になった |
| [Blossom](../zcash-tech/blossom) | 2019年12月11日 | 653,600 | 2bb40e60 | ブロックが高速化され、約75秒になり、スループットも向上した |
| [Heartwood](../zcash-tech/heartwood) | 2020年7月16日 | 903,000 | f5b9230b | シールドされたマイニング報酬と、より軽量なクライアント（FlyClient） |
| [Canopy](../zcash-tech/canopy) | 2020年11月18日 | 1,046,400 | e9ff75a6 | Development Fund、最初の半減期、そしてSproutプールの段階的な終了 |
| [NU5](../zcash-tech/nu5) | 2022年5月31日 | 1,687,104 | c2d6d0b4 | Halo 2上のOrchardプール（trusted setup不要）、Unified Address、そしてv5トランザクション |
| [NU6](../zcash-tech/nu6) | 2024年11月23日 | 2,726,400 | c8e71055 | Deferred Dev Fund Lockboxと、新しい開発資金配分 |
| [NU6.1](../zcash-tech/nu6-1) | 2025年11月24日 | 3,146,400 | 4dec4df0 | その資金に対するコミュニティとコイン保有者によるガバナンス |
| [NU6.2](../zcash-tech/nu6-2) | 2026年6月3日 | 3,364,600 | 5437f330 | Orchard回路を修正した緊急修正 |
| [Ironwood (NU6.3)](../zcash-tech/ironwood) | ~2026年7月28日 | 3,428,143 | 37a5165b | Ironwoodプールと、誰でも供給量を監査できる公開ターンスタイル |

日付はUTCで表示されています。ダッシュボードによっては現地時間で表示されることがありますが、同じブロックであり、同じ瞬間です。Ironwoodの日付は、その有効化ブロック高からの推定であり、固定されたトリガーはブロック高なので、正確な日は多少前後する可能性があります。将来のアップグレードであるNU7はまだ計画段階にあり、Ironwoodと同じものではありません。
