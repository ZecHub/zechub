# Zcash ネットワークアップグレード（Network Upgrades）

Zcashは、各ノード（node）が合意するルールへの協調的な変更であり、設定されたブロック高（block height）でそれぞれ有効化されるネットワークアップグレードを通じて改善されます。以下の各アップグレードには、それが何を、なぜ変更したのかを平易な言葉で説明する専用ページがあります。Zcashを初めてご利用ですか？SproutからIronwoodまで、順番にお読みください。

これらのアップグレードを通じてZcashのプライバシー（privacy）がどのように進化したかを視覚的に知るには、[プライバシーの進化](https://zechub.wiki/zcash-evolution)をご覧ください。このページは索引であり、そちらはタイムラインです。

日付はUTCで表示されています。一部のダッシュボード（dashboard）では現地時間で表示されますが、同じブロックであり同じ時点です。各アップグレードの固定トリガーは暦上の日付ではなく、有効化ブロック高です。

### NU7の状況

NU7は、高さ**4,465,026**で公開Testnet上に稼働しています（2026年10月4日に有効化）。Mainnetの有効化ブロック高は**3,543,405**です（[ZIP 259](https://zips.z.cash/zip-0259)）。**2026年11月5日**を目標としています。

対象範囲（ZIP 259）:

- **25秒ブロック**（ZIP 218）— 最初の承認は約3倍高速になり、日次ZEC発行量は変わりません。
- **ネットワーク持続可能性メカニズム（Network Sustainability Mechanism）**（ZIP 235 + ZIP 237）— トランザクション手数料の60%を流通から除去して準備金に移し、約2031年2月から半減期を維持するスケジュールでマイナー（miners）に再発行します。
- **Sproutの廃止**（ZIP 2003）— バージョン4トランザクションは無効になり、残存するSprout資金は使用不能になります。
- シールドされたアクションの上限、およびより広い難易度平均化ウィンドウ（17 → 102ブロック）。

新しいトランザクション形式は導入されません。コンセンサス（consensus）ブランチID: `0x77190ad9`。

詳細については、[プライバシーの進化](https://zechub.wiki/zcash-evolution)タイムラインおよび[ZIP 259](https://zips.z.cash/zip-0259)をご覧ください。フォーラムのタイムライン: [NU7タイムライン](https://forum.zcashcommunity.com/t/nu7-timeline/57655)。
