# Zcash ネットワークアップグレード

Zcashはネットワークアップグレードを通じて改善されます。これは、すべてのノードが合意するルールへの協調的な変更であり、それぞれ設定されたブロック高で有効化されます。以下の各アップグレードには、それによって何が、なぜ変更されたのかを平易な言葉で説明する専用ページがあります。Zcashは初めてですか？ SproutからIronwoodまで、順に読んでください。

これらのアップグレードを通じてZcashのプライバシーがどのように進化してきたかを視覚的に見るには、[プライバシーの進化](https://zechub.wiki/zcash-evolution)をご覧ください。このページは索引です。そちらはタイムラインです。

### NU7の状況

NU7はブロック高**4,465,026**で公開Testnet上ですでに稼働しています（2026年10月4日に有効化）。Mainnetの有効化ブロック高は**3,543,405**です（[ZIP 259](https://zips.z.cash/zip-0259)）。目標日は**2026年11月5日**です。

対象範囲（ZIP 259）：

- **25秒ブロック**（ZIP 218）— 最初の承認が約3倍高速化。ZECの日次発行量は変わりません。
- **Network Sustainability Mechanism**（ZIP 235 + ZIP 237）— トランザクション手数料の60%を流通から除去して準備金に入れ、約2031年2月から半減期を維持するスケジュールでマイナーに再発行します。
- **Sproutの廃止**（ZIP 2003）— バージョン4のトランザクションが無効になり、残存するSprout資金は使用不能になります。
- シールドアクションの上限と、より広い難易度平均化ウィンドウ（17 → 102ブロック）。

新しいトランザクション形式は導入されません。コンセンサスブランチID：`0x77190ad9`。

詳細については、[プライバシーの進化](https://zechub.wiki/zcash-evolution)タイムラインおよび[ZIP 259](https://zips.z.cash/zip-0259)をご覧ください。フォーラムのタイムライン：[NU7 タイムライン](https://forum.zcashcommunity.com/t/nu7-timeline/57655)。
