# 開発者向けリソース

**Zcash の新規開発者向けに推奨されるリソース一覧**

ブロックチェーンと Zcash の仕組みに関する広範な概要:

[Zcash ドキュメント](https://zcash.readthedocs.io/en/latest/)

[Mastering Bitcoin: オープン・ブロックチェーンをプログラミングする](https://www.amazon.com/Mastering-Bitcoin-Programming-Open-Blockchain-ebook/dp/B071K7FCD4)

[Zcashd RPC 一覧](https://zcash.github.io/rpc/)

[Zcashd ブック](https://zcash.github.io/zcash/)

[Zebrad ブック](https://zebra.zfnd.org/)

[ライトクライアント・プロトコル](https://zcash.readthedocs.io/en/latest/lightwalletd/index.html)

[Android Mobile SDK](https://github.com/zcash/zcash-android-wallet-sdk) / [iOS Mobile SDK](https://github.com/zcash/ZcashLightClientKit)

依存関係がチームによってどのようにレビューされ、保守されているかを理解するためのリソース:

[ZIP 一覧](https://zips.z.cash)

[アドレスのエンコーディング](https://zips.z.cash/protocol/protocol.pdf#5.6%20Encodings%20of%20Addresses%20and%20Keys)

[Zebrad リポジトリ](https://github.com/ZcashFoundation/zebra) / [Zebrad のプルリクエスト](https://github.com/ZcashFoundation/zebra/pulls)

[暗号署名ライブラリ](https://github.com/orgs/ZcashFoundation/repositories?type=all)

[halo 2 ブック](https://zcash.github.io/halo2/index.html)

[orchard ブック](https://zcash.github.io/orchard/)

[Halo2 クレート](https://docs.rs/halo2_proofs/latest/halo2_proofs/) / [Orchard クレート](https://docs.rs/orchard/latest/orchard/)

[Zcash R&D Discord](https://discord.gg/6AK7keWFaK)

[FROST ブック](https://frost.zfnd.org/)

[Zechub Hackathon 2024 の結果](https://x.com/ZecHub/status/1845212469809033489)

[Zechub Hackathon 2025 の結果](https://x.com/ZecHub/status/1975565960661635283)

[Zypherpunk Hackathon 2025 の結果](https://forum.zcashcommunity.com/t/zypherpunk-hackathon-winners/53985)

[Rust 製 Arti ToR クライアント](https://docs.rs/arti/latest/arti/)

[Tailscale](https://github.com/tailscale/tailscale)

[Hanh による Zcash ウォレット Warp2-Sync](https://github.com/hhanh00/warp2)

[Zcash テストネット・エクスプローラー](https://testnet.zcashblockexplorer.com/)


この一覧は、Zcash Foundation と ECC の開発者が提供した推奨事項をもとにまとめられました。

一覧を更新するための追加リソース（リンク、書籍、チャンネルなど）があれば、ぜひ追加してください！

*チームは必ずしもすべてを完全に最新の状態に保つためのリソースを確保できるとは限りませんが、遭遇した問題について issue を立てることで、ガイドやリソースの方向性を示すことができます*
