# ZecHubとは？
---

ZecHubは、Zcashのための分散型の学習ハブです。[ZecHub](http://zechub.xyz)が目指しているのは、Zcashエコシステムを支えるコンテンツを、コミュニティのメンバーが協力して作成・検証・発信できる学習プラットフォームを提供することです。そのために、次のような取り組みを行っています。

1. [チュートリアル](https://www.youtube.com/playlist?list=PL6_epn0lASLFF28ePj7P5TvtMG_WE7p3O)
2. [Wikiドキュメント](https://zechub.wiki/)
3. [コミュニティメンバーへのインタビューを配信するポッドキャスト](https://www.youtube.com/playlist?list=PL6_epn0lASLHlNCMtUErX8UfaJK6N9K5O)
4. [Zcashの週刊ニュースレター](https://zechub.substack.com/)

チュートリアル、短いブログ記事、ニュースレターはオープンソースとしてGitHubで公開されているので、コミュニティの誰でも貢献できます。こうすることで内容の正確さを保ち、発信の場そのものが単一障害点を抱えないようにしています。

Zcashを初めて使う方は、[こちらのガイド](/start-here/new-user-guide)をご覧ください。****

---

```markdown
1. すべてのページに、内容を裏付ける参考リソース（例：z.cash へのリンク）を載せること
2. マーケティングやスポンサードコンテンツは載せないこと
3. 不適切なコンテンツは載せないこと
```
