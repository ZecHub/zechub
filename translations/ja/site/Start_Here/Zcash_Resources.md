# Zcash リソース

Zcashを理解するのに役立つリソースはたくさんあります。

**[Zcash Media](https://www.youtube.com/c/ZcashMedia)**

Zcash Mediaは、Zcashを解説するドキュメンタリーを制作している独立系の団体です。最初の動画「Built to Fix Bitcoin's Fatal Flaw, What is Zcash (ZEC)?」は、Zcash入門にぴったりです。

**[X（旧Twitter）](https://x.com)**

Twitterは、Zcashコミュニティだけでなく暗号資産業界全体にとって、事実上のコミュニケーションの中心です。Zcashの最新動向をつかんだり、コミュニティの主要メンバーをフォローしたりするのに最適な場所です。フォローすべき主要アカウントをまとめた[ドキュメント](https://www.notion.so/zechub/Social-Media-Links-05b9df645af54de7a1989d9c4ccc4d05)はこちらです。

**[Zcash Community](https://www.zcashcommunity.com/)**

Zcash Communityは、Zcashエコシステムを支えるコミュニティ主導のプロジェクトを紹介している、コミュニティ運営のサイトです。Zcashコミュニティのことや、通貨としてのさまざまな使い道を知るのにうってつけです。

**[Zcash Forum](https://forum.zcashcommunity.com/)**

新規ユーザーガイドでも触れたとおり、Zcashフォーラムは、Zcashに関する話題や新しい提案についてじっくり議論するのに最適な場所です。提案は必ずフォーラムに投稿されるので、コミュニティはその内容を議論し、検討することができます。

**[Z.cash](https://z.cash/)**

Z.cashはZcashの公式メインサイトです。幅広いユーザーに向けてZcashの解説やドキュメントを提供しており、新しいユーザーもZcashの技術的な仕組みをより深く学べます。

**[Zcash Github](https://github.com/zcash/zcash)**

プログラミングが得意で、Zcashの技術面をもっと深く知りたい方へ。Zcash Github Repoは、最初のZcashノード実装であるzcashdのリポジトリです。zcashdは2026年7月18日にサポート終了に伴う自動停止（end-of-support halt）を迎え、現在はメンテナンスされていません。この項目で以前リンクしていたダウンロードページも、すでに公開が終了しています。現在メンテナンスされているのは、ノードの[Zebra](https://github.com/ZcashFoundation/zebra)とウォレットの[Zallet](https://github.com/zcash/zallet)です。詳細は[zcashdからZebraおよびZalletへの移行ガイド](https://zechub.wiki/guides/migration-guide-zcashd-to-zebrad-zallet)を参照してください。

**[Zcash Foundation Github](https://github.com/ZcashFoundation)**

Zcash Foundationのプロジェクトを公開しているもう一つのGitHubです。Rustで書かれたZcashノード実装の[zebra](https://github.com/ZcashFoundation/zebra)などがあります。

**[Halo2](https://zcash.github.io/halo2/index.html)**

ゼロ知識証明システムの基本的な考え方を解説しています。

**[Zcash RPC Docs](https://zcash.github.io/rpc/)**

zcashdが提供していたRPCコマンドの一覧です。現在メンテナンスされているウォレットのRPCについては、[Zallet Book](https://zcash.github.io/zallet/)を参照してください。
