# Zcash リソース（Resources）

Zcashを理解するのに役立つリソースが数多くあります。

**[Zcash メディア（Media）](https://www.youtube.com/c/ZcashMedia)**

Zcash Mediaは、Zcashに関する教育的なドキュメンタリーを制作する独立組織です。最初の動画「Bitcoinの致命的な欠陥を修正するために作られたZcash（ZEC）とは？」は、Zcashの優れた入門です。

**[X（旧Twitter）](https://x.com)**

Twitterは、Zcashコミュニティおよびより広範な暗号資産分野における事実上のコミュニケーションハブです。Zcashに関する最新動向を把握し、著名なコミュニティメンバーをフォローするのに最適な場所です。フォローすべき主要アカウントをまとめた[ドキュメント](https://www.notion.so/zechub/Social-Media-Links-05b9df645af54de7a1989d9c4ccc4d05)はこちらです。

**[Zcash コミュニティ（Community）](https://www.zcashcommunity.com/)**

Zcash Communityは、Zcashエコシステムを支援するコミュニティ運営プロジェクトを紹介する、コミュニティ運営のサイトです。Zcashコミュニティと、通貨としてのさまざまな用途に触れるための優れた手段です。

**[Zcashフォーラム（Forum）](https://forum.zcashcommunity.com/)**

新規ユーザーガイドで説明したとおり、Zcashフォーラムは、Zcashに関する話題や提案されたアイデアについて、長文で議論するのに最適な場所です。提案は常にフォーラムに掲載されるため、コミュニティは提案されたアイデアについて議論し、意見を交わす機会を得られます。

**[Z.cash](https://z.cash/)**

Z.cashはZcashの主要ウェブサイトです。幅広いユーザーに向けてZcashのコンテンツとドキュメントを提供し、新規ユーザーがZcashに関する技術的説明をより深く学べるようにしています。

**[Zcash GitHub](https://github.com/zcash/zcash)**

コーディングの腕に自信があり、Zcashの技術的側面をより深く学びたいですか？Zcash GitHubリポジトリ（Repo）は、最初のZcashノード実装であるzcashdのリポジトリです。zcashdは2026年7月18日に自動サポート終了に達し、現在は保守されていません。また、この項目が以前リンクしていたダウンロードページも提供されていません。保守されているスタックは、ノード用の[Zebra](https://github.com/ZcashFoundation/zebra)と、ウォレット（wallet）用の[Zallet](https://github.com/zcash/zallet)です。[zcashdからZebraおよびZallet移行ガイド](https://zechub.wiki/guides/migration-guide-zcashd-to-zebrad-zallet)をご覧ください。

**[Zcash Foundation GitHub](https://github.com/ZcashFoundation)**

GitHubのプロジェクトをホストする別のZcash Foundationリポジトリです。これには、Zcashで書かれた[zebra](https://github.com/ZcashFoundation/zebra)（Rustのノード実装）が含まれます。

**[Zcash RPCドキュメント（Docs）](https://zcash.github.io/rpc/)**

zcashdが公開しているRPCコマンドの一覧です。保守されているウォレットRPCの機能については、[Zallet Book](https://zcash.github.io/zallet/)をご覧ください。
