# このWikiの使い方

情報が多すぎて、圧倒されてしまうかもしれません。その気持ち、よくわかります！ このWikiにはたくさんの情報があります。そこで、Wikiをどう読み進めればよいかを、ステップごとに簡単にまとめました。

## Zcashが初めての方

Zcashが初めてなら、ここから始めるのがおすすめです。まずは次のページをチェックしてください：

[Zcash 新規ユーザーガイド](https://zechub.wiki/start-here/new-user-guide#content)

[Zcash リソース](https://zechub.wiki/start-here/zcash-resources#content)

[Zcashの基礎知識](https://zechub.wiki/start-here/what-is-zec-and-zcash#content)

## Zcashを使ってみたい方

入門ページとその参考リソースを読み終えたら、[ZECを使う](https://zechub.wiki/guides/using-zec-privately#content)と[チュートリアル](https://youtube.com/playlist?list=PL6_epn0lASLFF28ePj7P5TvtMG_WE7p3O&si=4vleWUbCGbNJu1-M)の動画で、ZECの使い方を学びましょう。

## Zcashコミュニティのメンバーの方

コミュニティのメンバーなら最高です！ 最新情報を追いかけるには、週刊ニュースレター[Zcash Ecosystem Digest](https://zechub.substack.com/s/zcash-ecosystem-digest)を購読し、[Zcashコミュニティページ一覧](https://zechub.wiki/zcash-community/community-links#content)にあるアカウントをすべてフォローするのがいちばんです。

## ZecHubに貢献したい方

ありがとうございます！ まず[ZecHubとは？](https://zechub.wiki/start-here/what-is-zechub#content)を読んでから、[ZecHubの構築を手伝う](https://zechub.wiki/contribute/help-build-zechub)で貢献の方法を確認してください。
