# Zcash 開発基金（Development Fund）

Zcash は、自主資金で運営されるため、ユニークなブロックチェーン（blockchain）プロトコルです。これは、Zcash に取り組むチームは外部投資家から資金を受け取る必要がなく、Zcash のより広範な理念と使命に沿いつつ、導入（adoption）の促進に集中し続けられることを意味します。
