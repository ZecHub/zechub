# Zcash 開発基金

Zcash は自己資金で運営されるため、ユニークなブロックチェーンプロトコルです。これは、Zcash に取り組むチームが外部投資家から資金を得る必要がなく、Zcash のより広範な理念と使命に沿い続けながら、普及の促進に注力できることを意味します。
