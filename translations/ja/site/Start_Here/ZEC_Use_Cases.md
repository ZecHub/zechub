# Zcashの基礎

## ZECのユースケース（Use Cases）

#### 支払い（Payments）

人々はZECを使用して、低い手数料（fees）で効率的かつ安全にトランザクション（transact）を行えます。シールドされた（Shielded）Zcashにより、トランザクションは機密性を保ったままにでき、必要に応じてアドレス（address）やトランザクション情報を共有する選択肢も得られます。プライベートな「Z-Z」トランザクションは、実行されたことと手数料（fees）が支払われたことが分かるよう、公開ブロックチェーン（blockchain）に表示されます。しかし、アドレス、トランザクション額、メモ（memo）フィールドはすべて暗号化（encryption）され、公開されません。 

#### 価値の保存

人々はZECを使用して、堅固でプライバシー（privacy）を保護する資産に富を保存することもできます。ZECのユニットは合計21 millionしか存在しないため、この資産の供給量は固定されています。21 million個目のZECが[流通に向けてマイニング（mining）される](https://z.cash/mining-zcash/)と、この資産はインフレ耐性を持つようになります。中央集権的なゲートキーパーが国の通貨供給量を増やす場合、インフレ耐性を持つ資産はインフレに対する有効なヘッジとなります。

#### メッセージング

人々は、シールドされたZ-Zトランザクションのメモフィールドを使用して、完全に暗号化されたメッセージを送信できます。メモを送信するには、ユーザーはトランザクションを実行してトランザクション手数料を支払う必要がありますが、その額は$0.01未満です。
