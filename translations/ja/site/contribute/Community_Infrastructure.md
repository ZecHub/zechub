# ZecHub コミュニティ・インフラストラクチャ・フレームワーク


### コミュニティ・インフラストラクチャ

ZecHubのバウンティプログラム（bounty program）は、この作業に対する有償の手段です：[ZEC Bounties](https://bounties.zechub.wiki/)。ZEC番号の選び方：[バウンティ金額ポリシー](https://bounties.zechub.wiki/docs/bounty-amounts)。貢献者向けワークフロー：[ZecHubへの貢献](https://zechub.wiki/contribute/contributing-guide)。
