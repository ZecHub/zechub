# シールドされたZcashトランザクション（Transaction）は実際にどのように機能するのか

### 数学の前の直感：数式を使わないプライベートな支払いの解説

> **シリーズ：** *第一原理から学ぶZcash* 。**記事 0 . アンカー**
> **対象読者：** 完全な初心者。暗号技術、ブロックチェーン、数学の知識は必要ありません。
> **この記事で得られること：** Zcashが*誰が誰に、いくら支払ったか*を隠しながら、世界中の誰もが通貨が偽造も二重支払いもされていないと検証できる仕組みについて、正しいメンタルモデルを得られます。

このシリーズの後続記事では、これから紹介する仕組みの各部分を詳しく見ていきます。したがって、ここで曖昧に感じる言葉があっても、*それでよいのです*。後で戻ってきて、きちんと理解できるようにするという約束です。

## 1. なぜ気にかけるべきなのでしょうか？

銀行明細が町の広場の壁に、永久に釘で打ち付けられているところを想像してください。誰でも（家主、雇用主、見知らぬ人、将来の雇用主、政府など）が、すべての家賃支払い、医療費、寄付、コーヒー代を読み、あなたが誰に送金したか、誰があなたに送金したかを正確に追跡できます。

これはディストピア的な仮説ではありません。**Bitcoinはおおよそこのように機能します。**

Bitcoinはしばしば「匿名」と呼ばれますが、そうではありません。これは*仮名性*を持つだけです。台帳にあなたの名前は載っていませんが、すべてのトランザクション、金額、アドレス間のつながりは公開され、永久に残ります。この薄い仮名を剥がし、アドレスを実在の人物に結び付けるために、「チェーン分析」という分野全体が存在します。あなたのアドレスの1つがあなたと結び付けられると、金融履歴が明らかになります。

Zcashは、一見すると単純ですが難しい問いに答えるために作られました。

> **送信者、受信者、金額を隠しながら、誰もがルールが守られたと検証できる、完全にプライベートな通貨を持つことはできるでしょうか？**

この2つの目標は互いに対立します。公開台帳は、誰もが見られる*からこそ*検証可能です。プライバシー（privacy）とは、誰も見られないことです。では、見ることを許されていないものを、公開の場でどのように検証できるのでしょうか？

この逆説を解決することが、このシリーズ全体の物語です。始めましょう。

## 2. Zcashの中には2つの世界があります

まず、よくある誤解を解きましょう。**Zcashは「プライベートコイン」ではありません。プライバシーを選択肢として提供するコインです。**実際にはBitcoinのフォークとして始まり、同じブロックチェーン上で2つの並行したシステムを備えています。

| | **公開型の世界** | **シールドされた世界** |
|---|---|---|
| プライバシー | Bitcoinと同様に公開 | プライベート |
| アドレスの先頭 | `t...` | `z...` または `u...` |
| 送信者 / 受信者 / 金額 | 全員に**見える** | 全員から**隠される** |
| 基盤技術 | Bitcoin形式の公開台帳 | 暗号学的コミットメント + ゼロ知識プルーフ |

資金は両者の境界をまたぐこともできます。資金をシールドされた世界へ移すことを*シールディング*、再び外へ移すことを*デシールディング*と呼びます。

公開型の世界は、「すでに大まかに理解しているBitcoin」です。美しい暗号技術をすべて含んでいるのは**シールドされた世界**であり、このシリーズが扱うのもその世界だけです。

## 3. 直感：公開掲示板上の封印された封筒

この記事の残りを通じて使う、1つのメンタルイメージを紹介します。これから何度も戻ってきます。

地球上の誰もが常に見られる、巨大な**公開掲示板**を想像してください。

* **お金を受け取ること**は、誰かが**封印され不透明な封筒**を掲示板に貼ることを意味します。封筒の中には*入っている金額*と*受取人だけが読める秘密*が入っています。封筒は受取人の個人キーでロックされているためです。世界中の人は*封筒が現れた*ことを見られます。しかし、中身を見られるのは所有者だけです。

* **掲示板は増え続けるだけです。**封筒が剥がされたり消されたりすることはありません。新しい封筒が永久に上から貼り足されます。

* **お金を使うこと**は、カーテンの裏に入り、「この掲示板にある未使用の封筒の1つを所有しており、それを開ける権限がある」とプルーフし、一意の**無効化トークン**を公開された「使用済み」箱に入れ、支払先のための**新しい封筒**を貼ることを意味します。

この小さな儀式（無効化トークンを貼り、新しい封筒を貼る。すべてカーテンの裏で行われます）こそが、Zcashの支払いです。それ以外はすべて詳細です。

では、これらの小道具に本当の名前を付けましょう。

## 4. 5つの名詞

この5つの用語が、シールドされたZcashの語彙のすべてです。用語集としてではなく、*物語*として学ぶと記憶に残ります。

| 物語の中で | 実際のZcash用語 | 実際には何か |
|---|---|---|
| 封筒の内容（金額 + 所有者 + 秘密） | **ノート（Note）** | 誰かに属する価値の一塊である、プライベートな「コイン」 |
| 掲示板上の封印され不透明な封筒 | **ノートコミットメント（Note commitment）** | 中身を隠しながら封筒の存在を示す暗号学的な封印 |
| 掲示板そのもの | **ノートコミットメントツリー（Note commitment tree）** | *作成されたすべてのノート*の追記専用記録 |
| 「使用済み」箱の中の無効化トークン | **ヌリファイア（Nullifier）** | 「このノートは使用済みである」ことを示す一意のマーカー |
| 「カーテンの裏」の魔法 | **ゼロ知識プルーフ（Zero-knowledge proof）** | 使用全体が有効であることを、何も明かさずに示すプルーフ |

この記事から他に何も覚えていなくても、この表は覚えてください。続く内容はすべて、各要素がなぜこの形でなければならないかの説明にすぎません。

## 5. 各要素がその形である理由

多くの解説が省く部分ですが、「いくつかの単語を暗記した」と「設計を理解した」を分ける、まさに重要な部分です。5つの要素はそれぞれ、**1つの特定の問題**を解決するために存在します。

### ノートコミットメント：内容を隠しつつ、偽造を不可能にする

普通の封筒は蒸気で開封できます。暗号学的な**ノートコミットメント**はできません。これは、2つの超能力を持つ、*魔法のように*封印された完全に不透明な封筒だと考えてください。

- **秘匿性**：封印された封筒を見ても、中の金額や所有者について*何も*分かりません。
- **束縛性**：一度封印されると、中身をすり替えることはできません。後から封筒に別の金額が入っていたと主張することはできません。

封印はどのようにして両方を同時に実現できるのでしょうか？これは実在し、答えられる問いです。**記事 3（コミットメント）**のテーマです。今のところは、封筒を魔法として受け入れ、先へ進みましょう。

### ヌリファイア：本当に巧妙な部分

ノートを使用するとき、その**ヌリファイア**、つまり「無効化トークン」を公開します。このトークンは、*ノートそのもの*と*あなたの秘密キー*から計算されます。この仕組みにより、3つの特性を同時に実現します。どれも重要です。

1. **所有者だけが作成できます。**計算には秘密キーが必要なため、他者があなたのノートを勝手に使用することはできません。
2. **特定のノートに対して、常に*同じ*トークンになります。**同じノートを2回使用しようとすると、両方で同一の無効化トークンが生成されます。そして公開された「使用済み」箱にはすでにそれが入っています。二重支払いは拒否されます。
3. **誰も封筒まで追跡できません。**無効化トークンは、それが由来する封筒とは完全に無関係に見えます。

この3番目の特性こそが、Zcashのプライバシーの**核心**であり、後ほど独立した節で扱います。

### ゼロ知識プルーフ：カーテンそのもの

すべてはカーテンの裏で起こり、その後に世界へ渡すものが**ゼロ知識プルーフ**です。これは偽造不可能な証明書の一種です。次のすべてを一度に、静かに保証します。

- *使用する封筒は本当に掲示板に貼られている*（実在する本物のノートです）、
- *私は本当にそれを開ける権限を持っている*（正しいキーを保持しています）、
- *無効化トークンは正しく計算されている*（二重支払いチェックを不正に回避していません）、
- *新しい封筒には古い封筒とまったく同じ額の資金が入っている*：**何もないところから資金は作られていません。**

驚くべきことに、このプルーフは、これらの事実を**何も**明かしません。金額も、アドレスも、どの封筒かも明かしません。ただ、*上記のすべての記述が真実である*と納得させるだけです。これがどうして可能なのかは、シリーズの最高潮である**記事 5（ゼロ知識プルーフ）**で扱います。

## 7. 支払いの始まりから終わりまで

公開されるすべての手順と非公開の手順にラベルを付けながら、AliceがBobに支払う様子を見てみましょう。

![alt text](/content-images/image-4-7af0dfe795.webp)

プライバシーを機能させる非対称性に注目してください。

- **Aliceの古いノート**は、使用済み箱内の*ヌリファイア*によって消滅します。
- **Bobの新しいノート**は、掲示板上の新しい*コミットメント*によって生まれます。
- 見ているすべての人にとって、この2つの出来事には**目に見えるつながりがありません。**資金の追跡はここで途切れます。

> **Bobは支払いを受けたことをどのように知るのでしょうか？**Bobのノートは*Bobのキーに対して*暗号化されています。Bobは掲示板を継続的にスキャンし、Bobの封筒だけが開きます。これは、特定の鍵穴の組に合う唯一のキーを持っているようなものです。この仕組みを支えるのは、後で扱う**ビューイングキー**です。

## 8. 世界に見えるものと隠されたままのもの

| 支払いに関する事実 | 公開されていますか？ |
|---|---|
| *ある*シールドされたトランザクションが発生したこと | はい |
| すべてのルールに従ったこと（偽造なし、二重支払いなし） | はい（プルーフによって） |
| 誰が資金を送ったか | 隠される |
| 誰が資金を受け取ったか | 隠される |
| いくら送られたか | 隠される |
| どの過去のノートが使用されたか | 隠される |

これが、セクション1で示した逆説の解決です。公開の場が検証するのは*ルール*であり、*内容*ではありません。ゼロ知識プルーフにより、後者に触れることなく前者を確認できるため、検証とプライバシーは対立しなくなります。

## 9. 核心：封筒と無効化トークンを結び付けられない理由

この1つの考え方を理解すれば、Zcashがなぜプライベートなのかを理解できます。ゆっくり読んでください。

- **封筒（コミットメント）**は、ノートが**生まれる**ときに掲示板へ貼られます。
- **無効化トークン（ヌリファイア）**は、同じノートが**使用される**ときに箱へ入れられます。これは数か月後になる可能性もあります。
- 両者は**異なる秘密の計算式**で生成され、一方を他方へ変換する**公開された計算方法**はありません。

そのため、外部の観察者は、封筒が現れる流れと無効化トークンが現れる流れを見ますが、**それらを対応付けることはできません。**「今日投入された無効化トークンは、昨年3月に貼られた封筒に対応する」と言うことはできません。このつながりはノートの所有者の秘密の知識の中に*のみ*存在し、ゼロ知識プルーフは、つながりが有効であることを*明かさずに*確認します。

この切断されたつながりこそ、チェーン分析企業がBitcoinで追跡するものであり、Zcashが意図的に断ち切るものです。

## 12. まとめ

- Bitcoinは**公開型**です。Zcashは、送信者、受信者、金額が隠される**シールドされた**世界を提供します。
- 見かけ上の逆説（*プライベートでありながら公開検証可能*）こそが重要であり、解決できます。
- シールドされた支払いは、相互に組み合わさる5つの要素から成ります。**ノート**（コイン）、**ノートコミットメント**（封印された封筒）、**ノートコミットメントツリー**（公開掲示板）、**ヌリファイア**（二重支払いを防ぐ無効化トークン）、そして**ゼロ知識プルーフ**（何も明かさずに有効性を示すカーテン）です。
- プライバシーは究極的に、**1つの切断されたつながり**に基づいています。外部の誰も、ノートの誕生（コミットメント）と消滅（ヌリファイア）を結び付けられません。
- 公開の場が検証するのは**ルール**であり、**内容**ではありません。

これで地図を手にしました。シリーズの残りが、そこを埋めていきます。

## FAQ

**Zcashは常にプライベートですか？**  
いいえ。プライバシーが適用されるのは、シールドされた世界（`z...`/`u...`アドレス）です。公開型（`t...`）トランザクションは、Bitcoinと同様に公開されます。

**すべてが隠されているなら、誰かが無料でお金を発行することを何が防ぐのでしょうか？**  
ゼロ知識プルーフです。金額を秘密に保ちながら、すべてのトランザクションの出力が、実在する未使用の入力によって裏付けられることを数学的に強制します。

**同じノートを2回使用できますか？**  
いいえ。ノートを使用するとヌリファイアが公開されます。2回目の試行では同一のヌリファイアが公開されますが、それはすでに「使用済み」箱にあるため、ネットワークが拒否します。

**外部者は送信者と受信者を結び付けられますか？**  
いいえ。コミットメント（ノートの誕生）とヌリファイア（ノートの消滅）は、所有者の秘密の知識を持たない者には対応付けられません。

### 直感テストの答え（セクション9）

ヌリファイアが秘密キーなしで、*ノートだけ*から計算される場合、**誰でも**計算できるため、特性 #1（所有者だけが使用できる）が壊れます。さらに悪いことに、ヌリファイアはノートに関する公開情報から直接導出できるようになります。そのため観察者は**ヌリファイアをコミットメントまで結び付けられる**可能性があり、特性 #3を壊し、システム全体のプライバシーを密かに解体してしまいます。秘密キーこそが、無効化トークンを*あなただけのもの*かつ*関連付け不能*にします。
