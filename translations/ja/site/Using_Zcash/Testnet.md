# Zcash テストネット（Testnet）

## Zcash テストネットとは何ですか？

**Zcash テストネット**は、実際のZcashメインネット（Mainnet）と同一のプロトコル、ルール、トランザクションロジックを複製した並行ブロックチェーンです。ただし、次の2つの重要な違いがあります。

1. **コインには実際の金銭的価値がありません** - ZECではなく**TAZ**と呼ばれ、テスト目的でのみ使用されます。  
2. **ネットワークアップグレード、ツール、ソフトウェアは、実際のZcashブロックチェーンへ導入される前に、ここで最初にテストされます**。  

言い換えると、テストネットは、developer、監査者、ビルダーが実際のお金を危険にさらすことなくアイデアを試せる**サンドボックスまたは実験環境**のようなものです。


## テストネットが存在する理由

テストネットはブロックチェーン開発において極めて重要です。なぜなら、Zcashのような**実際のブロックチェーンは不変**であり、メインネット上でトランザクションが確認されると取り消せないためです。テストネットは、メインネットへ導入する前に機能の実験、テスト、デバッグを行うための**安全な複製環境**を提供します。

### テストネットの用途

#### 1. ソフトウェア開発と統合

ウォレット、取引所、マイニングソフトウェア、またはプライバシーツールを構築するdeveloperは、テストネット上で安全にテストできます。以下の機能が含まれます。

- トランザクションの送受信  
- 価値がゼロのTAZコインによる新しいブロックのマイニング  
- ユーザーインターフェースとAPIの構築  
- トランザクションのプライバシー機能（公開型とシールドされた機能）のテスト  

**例：**  
[`zcash_tx_tool`](https://github.com/QED-it/zcash_tx_tool)のようなツールは、トランザクションを生成し、Zcashのシールドされた資産機能をテストするためにテストネットを使用します。  

**実際のシナリオ：**  
ウォレットのdeveloperは、ソフトウェアをテストネットのRPCエンドポイントに接続し、メインネットで稼働する前に、アドレスの作成、シールドされたトランザクションの送信、残高の検証まで、完全なライフサイクルをシミュレートできます。

#### 2. ネットワークアップグレードのテスト

Zcashは、定期的にコアプロトコルをアップグレードします（例：NU6.1、NU6.2、Ironwood）。テストネットでは、新しいアップグレードを**メインネットより前に**有効化するため、developerとコミュニティはバグを特定して修正できます。

**例：**  
新しいコンセンサスルールまたはトランザクションタイプは、まずテストネットに導入されます。テストが成功した後、事前に定められたブロック高でメインネット上に有効化されます。

#### 3. ノード実装のテスト

Zcashで維持されているノードは**Zebra**（Zcash Foundationが維持するRustベースのノード）であり、維持されているウォレットは[Zallet](https://github.com/zcash/zallet)です。元のノード実装である`zcashd`は、2026年7月18日に自動サポート終了停止に達し、現在は維持されていません。[zcashdからZebraおよびZalletへの移行ガイド](https://zechub.wiki/guides/migration-guide-zcashd-to-zebrad-zallet)を参照してください。テストネットにより、金銭的リスクなしに実環境の条件でノードをテストできます。

ノードのdeveloperは、次のことができます。

- ブロック伝播の検証  
- RPCインターフェースのテスト  
- 負荷時のノード動作の観察  
- マイニングソフトウェアとの相互作用のテスト  

#### 4. 学習と教育

初心者は、マイニング、シールドされたトランザクションの作成、統合アドレスの使用など、Zcashの機能を学べます。  
コミュニティのチュートリアルとドキュメントでは、**テストネットのフォーセット、エクスプローラー、ガイド**を利用できます。


## 実際のテストネットのユースケース

### 1. developerによるテスト（ウォレット / アプリ）

- Zcash テストネットに接続する  
- フォーセットからTAZをリクエストする  
- シールドされたトランザクションを送信する  
- プライバシーとUIの安定性を検証する  

間違いが起きても、実際のZECが失われることはありません。

### 2. 取引所統合テスト

- テストネットノードを実行する  
- Zebrad JSON-RPCエンドポイントを使用してトランザクションを処理する  
- 自動入金・出金ロジックをテストする  

安全な本番コードを確保し、金銭的損失を防ぎます。

### 3. マイニング設定の試行

- マイニングテンプレートを使用する  
- ブロック検証をテストする  
- マイニング報酬を観察する（TAZのみ）  
- マイニング性能を調整する  

メインネットへ移行する際のダウンタイムや収益損失を防ぎます。

### 4. 学術・プロトコル研究

研究者は、テストネットを使用して、**ステートレス検証**、**ゼロ知識（zero-knowledge）proof最適化**、その他のプロトコル実験といった革新をテストできます。  
上級ユーザーは、専門的な実験のために**カスタムテストネットまたはregtest環境**を実行することもできます。


## メインネットとテストネットの主な違い

| 機能               | メインネット           | テストネット                  |
|-----------------------|-----------------|--------------------------|
| コインの価値        | 実際のZEC         | TAZ（金銭的価値なし）  |
| リスク                  | 金銭的リスク   | テストに安全         |
| プロトコルアップグレード     | 本番環境       | 早期有効化         |
| マイニング報酬        | 実際の発行    | テスト報酬のみ         |
| ネットワークの用途       | 実際のトランザクション| テストと開発  |

## よくある誤解

- **テストネットコインには価値がある** -> 誤りです。TAZの価値はゼロです。  
- **テストネットコインを失うことは重要である** -> 誤りです。実際の価値は失われません。  
- **テストネットとメインネットは同一である** -> 誤りです。テストネットは頻繁にリセットされ、メインネットのような経済的保護はありません。

## TAZとは何ですか？

**TAZ**はZcashコインのテストネット版です。  

- 実際のお金ではなく、ZECや法定通貨と交換できません  
- テスト、開発、学習に使用されます  
- 送信、マイニング、シールドされたアドレスでの使用が可能であり、Zcashのすべてのルールに従います  

**例：**  
developerは、実際のZECを危険にさらすことなく、ウォレット機能をテストするために、1つのテストネットアドレスから別のアドレスへ100 TAZを送信できます。  

TAZは、Zcash テストネット向けの**「おもちゃのお金」**と考えてください。


## フォーセットとは何ですか？

**フォーセット（faucet）**は、テスト用に無料のTAZコインを配布するサービスです。

- 通常はウェブサイトまたはAPIです  
- ユーザーがテストネットアドレスを提供すると、フォーセットが少額のTAZを送信します  
- TAZを手作業でマイニングする必要がなくなります  

**例：**  
1. テストネットのフォーセットにアクセスします（例：[fauzec.com](https://fauzec.com/) | [zcashfaucet.jinolabs.xyz](https://zcashfaucet.jinolabs.xyz/)）  
2. テストネットアドレスを入力します  
3. TAZをリクエストします  
4. テストを開始できるよう、即座にTAZを受け取ります  

**重要な理由：**  
- ZECを危険にさらすことなく安全にテストできます  
- 初心者とdeveloperにとって利用しやすくなります  
- ウォレット、取引所、アプリの迅速なプロトタイピングが可能になります  



## ZkoolおよびZingo!ウォレット

### Zkool

- 上級Zcashユーザー向けのマルチアカウントウォレット  
- シードフレーズ、ビューイングキー、公開型およびシールドされたアドレスをサポートします  
- フルノードまたはlightwalletサーバーを介して、メインネット、テストネット、またはRegtestに接続できます

### Zingo!

- プライバシーとシンプルさに重点を置いたモバイルウォレット  
- シールドされたアドレスと統合アドレスをサポートします  
- テストネットプロトコル（NU6 テストネットを含む）をサポートするよう更新されています

## テストネットを有効にした後

- トランザクションはメインネットと同様に動作しますが、**価値がゼロのTAZ**を使用します  
- シールドされたトランザクション、複数のアドレス、プライバシー機能をテストできます  
- developerは、実際のZECを危険にさらすことなく機能のデバッグとテストを行えます


## 要約

- **Zcash テストネット**は、構築、テスト、実験のための安全なサンドボックス環境です  
- ユースケース：developerテスト、ノードテスト、取引所統合、研究、教育  
- **TAZコイン**はZECの代わりに使用され、実際の価値はありません  
- テストネットは、機能をメインネットで公開する前に不可欠です
