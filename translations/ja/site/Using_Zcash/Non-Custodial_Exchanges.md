# <img src="/content-images/ZEC-USD-a2189a84b9.webp" alt="代替テキスト" width="50"/>   非カストディアル取引所

[Zcash 非カストディアル取引所](/dex)

絶えず進化する暗号資産取引の世界で、分散型取引所またはDEXとも呼ばれる非カストディアル取引所では、資金を取引所アカウントに預けることなく取引できます。自分自身で鍵を管理できますが、それは他の誰も関与しないという意味ではありません。経路によっては、スワップはウェブサイトやウォレットアプリ、ルーティングサービス、スマートコントラクト、ソルバー、ブリッジを経由する場合があります。

上記の取引所では、自分のウォレットからZcashを取得・取引できます。スワップのプライバシーの程度は、サービス、支払い元のネットワーク、そしてZECがシールドアドレスに到達するかどうかに左右されます。以下のセクションでその違いを説明します。

### **非カストディアル取引所を理解する**

分散型取引所（DEX）とも呼ばれる非カストディアル取引所は、ユーザーが資金を取引所自体に預け入れることなく、暗号資産取引を可能にするプラットフォームです。代わりに、ユーザーは秘密鍵の管理を維持し、自分のウォレットから取引します。クロスチェーンスワップでは、取引の価格提示、ルーティング、決済のために、依然として他者に依存します（下記参照）。

これは、ユーザーが資産の保管を取引所に依存しないため、ハッキングや管理不全のリスクを減らし、セキュリティを向上させることがあります。ただし、それだけでスワップがプライベートになるわけではありません。非カストディアル取引所での取引では、多くの場合公開されたスマートコントラクトが使用され、利用するサービスは依然としてあなたのアドレスや接続の詳細を確認できます。

非カストディアル暗号資産取引所の主な利点は、ユーザーが資産をより強く管理できることにあります。これらの取引所は資産を保管しないため、ユーザーはデジタル通貨に対する完全な所有権と権限を享受できます。

### **非カストディアル取引所とカストディアル取引所の比較**

**#1 セキュリティ**: 非カストディアル取引所では、中央集権的な取引所アカウントに資金を保管する必要がありません。ユーザーは秘密鍵の管理を維持できるため、カストディアル取引所で起こり得るハッキング、内部攻撃、プラットフォーム障害のリスクを減らせます。クロスチェーンスワップでは、取引の決済中に入金アドレスやブリッジで資金が短時間保留される場合があります。

**#2 プライバシー**: 非カストディアルスワップでは通常、取引所アカウントは不要であるため、メールアドレスやIDでの登録を省けることが多いです。しかし、それは匿名性と同じではありません。送信元ネットワーク（たとえばSolanaやEthereum）で送る入金はそのチェーン上で公開されており、サービスは依然としてあなたのウォレットアドレス、IPアドレス、スワップの詳細を確認できます。Zcash側のプライバシーは、ZECがどこに到達するかに依存します（下記参照）。

**#3 分散化**: 非カストディアル取引所は、暗号資産の分散化という理念により近く沿っています。ユーザーは、ブロックチェーン技術のより広範な原則に即して、取引活動に関するより大きな自律性と管理権を持ちます。

カストディアル取引所の場合、ほとんどの中央集権型取引所では分散化の度合いは非常に低く、取引所チームや運営者が取引所上のユーザーデータや情報を管理することになります。

**#4 規制変更への適応性**: 非カストディアル取引所は、変化する規制環境により適応しやすいことが多いです。ユーザー資金を保有しないため、カストディアル取引所と比べてコンプライアンス上の課題が少ない可能性があります。

**#5 イノベーションと実験**: 非カストディアル取引所は、暗号資産分野のイノベーションを頻繁に推進しています。自動マーケットメーカー（AMM）や分散型金融（DeFi）アプリケーションといった、分散型技術の開発を促進します。

**#6 グローバルなアクセス性**: 非カストディアル取引所は、規制上の障壁によってカストディアル取引所サービスの利用可能性が制限される地域を含め、世界中のユーザーに暗号資産へのアクセスを提供することが多いです。

**#7 KYC不要**: 多くの非カストディアル取引所は、最初に本人確認書類を求めません。ただし、ほとんどはコンプライアンスデータベースを使用してウォレットアドレスを照合しており、何らかのフラグが立った場合はスワップが遅延、ブロック、拒否されることがあります。利用を頼りにする前に、サービスの利用規約を確認してください。

### **Zcashが保護するものと保護しないもの**

Zcashのプライバシーは、シールドアドレスによって実現されます。ZECがシールドアドレス間で移動する場合、送信者、受信者、金額、メモはZcashチェーン上で暗号化されます。仕組みについては、[シールドプール](/using-zcash/shielded-pools)を参照してください。

スワップには、Zcashでは隠せない部分があります。

- **送信元ネットワーク。** Solana、Ethereum、または他のパブリックチェーンから送る資金は、そのチェーン上で公開されます。これにはあなたのアドレスと金額が含まれます。
- **受取アドレス。** 一部のスワップ経路では、ZECがトランスペアレントアドレスに送られます。たとえば、Near Intentsは、ZECが[トランスペアレントアドレスのみ](https://docs.near-intents.org/resources/chain-support)でサポートされていると記載しています。トランスペアレント（t1またはt3）アドレスに送られたZECは、Bitcoinと同様に公開されます。その後にシールド化すれば次に行うことは保護されますが、入金とシールド化トランザクションは表示されたままです。
- **サービス。** アプリおよびルーティングサービスは、あなたが提供するアドレスと金額に加え、IPアドレスなどの接続データを確認します。

ZECを自分で管理するウォレットに送り、使用する前にシールド化してください。[ZECをプライベートに使用する](/guides/using-zec-privately)では、次の手順を説明しています。

### **スワップに関与する主体**

例として、Near Intentsの1Clickサービスを経由するスワップを考えてみましょう。その[API利用規約](https://docs.near-intents.org/security-compliance/terms-of-service)では、以下を別個の構成要素として扱っています。

- **インターフェース**: 使用するウェブサイトまたはウォレットです。Intents Technologyが運営する場合も、独自の利用規約を持つ第三者が運営する場合もあります。
- **1Click**: Intents Technology Limitedが運営するルーティングおよび決済サービスです。提示された見積もり用に作成された入金アドレスへ資金を送ります。ドキュメントでは1Clickはカストディを行わないとされていますが、利用規約では、送金の進行中に資産がブリッジインフラ内で保有またはロックされる可能性があると記載されています。
- **プロトコル**: Near Intentsのスマートコントラクトです。
- **ソルバー**: 見積もりを履行する独立した第三者です。
- **ブリッジ**: ネイティブZECは、Intents Technologyが運営するPoA Bridgeを介して移動します。

Near Intentsはまた、統合された見積もりフローを複数のAMLデータベースと照合して[スクリーニング](https://docs.near-intents.org/security-compliance/risk-and-compliance)しており、対象範囲はフローや統合によって異なると述べています。利用規約に基づき、フラグが立ったスワップは遅延、ブロック、凍結、拒否される場合があります。

### **スワップ中に共有する情報**

- スワップを受け取るZECアドレスと、送信元ネットワーク上の返金アドレス。
- 資産と金額、および送信する入金トランザクション。これは送信元チェーン上で公開されます。
- 接続データ。1Clickの利用規約では、Intents Technologyがリクエストメタデータ、IPアドレス、ウォレットアドレスを収集する可能性があるとされ、near.comのプライバシーポリシーにはIPアドレス、位置情報、ブラウザ、デバイス情報が記載されています。
- アプリが追加する情報（他に接続されたウォレットアドレスなど）。アプリは、独自のコンプライアンスチェックを通じてあなたのウォレットを確認する場合もあります。

### **利用規約とサポートの確認先**

利用規約は変わるため、大きなスワップの前に最新バージョンを確認してください。

- **まず利用するアプリを確認してください。** それが主な問い合わせ先です。1Click API利用規約では、Intents Technologyは、それを利用して構築されたアプリのユーザーと直接の関係を持たないと記載されています。
- **Near Intents:** near.com/termsおよびnear.com/privacyの利用規約とプライバシーポリシー、ならびに[1Click API利用規約](https://docs.near-intents.org/security-compliance/terms-of-service)と[リスクおよびコンプライアンス](https://docs.near-intents.org/security-compliance/risk-and-compliance)。
- **追跡とサポート:** [Near Intents Explorer](https://explorer.near-intents.org)でスワップを確認するか、[Near Intents Telegram](https://t.me/near_intents)で問い合わせてください。
- **返金:** 失敗したスワップは、指定した返金アドレスに返送される場合がありますが、near.comの利用規約では返金は保証されないとされています。1Clickの利用規約では、300米ドル未満のユーザーエラーに対する回復依頼は検討されないとも記載されています。

ここから、Zcash取引を可能にする、利用しやすい非カストディアル取引所をいくつか見ていきましょう。これらのプラットフォームを利用すれば、より多くのZcashコインを便利に取得できます。

### **まとめ**

非カストディアル取引所、つまりDEXでは、秘密鍵の管理を維持したまま自分のウォレットから取引できます。これはセキュリティに役立ちますが、プライバシーは経路に依存します。送信元チェーンは公開され、サービスはあなたのアドレスと接続データを確認でき、ZECはシールドアドレスに入って初めてプライベートになります。

非カストディアル取引所には魅力的な利点がありますが、流動性に関する潜在的な問題や、経験の少ないユーザーにとって学習曲線が急になるといった欠点がある可能性も認識することが重要です。

あらゆる金融上の判断と同様に、トレーダーは非カストディアル取引所とカストディアル取引所のどちらを選ぶかを決める前に、自身の優先事項、リスク許容度、技術への習熟度を慎重に評価する必要があります。
