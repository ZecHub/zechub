# Zcashを使ったモバイルチャージ

このガイドでは、ZECで携帯電話の通話料を購入する方法を学びます。

## 以下の手順に従ってください：

### 1. アカウントを作成する
[Coinsbee.com](https://www.coinsbee.com/en/shop/mobile-top-ups/)にアクセスし、アカウントを作成します。

### 2. 国と通信事業者を選択する
左上までスクロールして国を選択し、携帯電話クレジットを選んだ後、チャージしたい通信事業者を選択します（例：MTN）。

![ステップ2 - 国と通信事業者の選択](/content-images/0-qvB7ZCWaVWa-C2d8-db0d4ea372.webp)

### 3. 詳細を入力して購入する
正しい情報を入力し、「Buy Now」ボタンを押します。カートを開いて注文内容を確認し、「continue」をクリックして、$ZECでの購入を確定します。

![ステップ3 - 購入画面](/content-images/0-ikF-ooBc9W7olfNt-7a4584edda.webp)

### 4. 支払い詳細
$ZECでの相当額と、資金の送付先となるトランスペアレントアドレスが表示されます。

![ステップ4 - ZECの支払い詳細](/content-images/0-6_YhAhQnsLbrMvHN-c9646f3604.webp)

### 5. 支払いを送る
金額とアドレスを慎重にコピー＆ペーストします。返金が発生した場合に備え、メモ欄に自分のシールドアドレスを追加してください。

![ステップ5 - ZECの送信](/content-images/0-DNnpyemsKcW-k-u-bcaaa51d3a.webp)

### 6. 処理中
資金を送信すると、リクエストは数分以内に処理されます。

![ステップ6 - 処理画面](/content-images/0-LgXuUVLVecqrUW5G-a894c7b2dd.webp)

### 7. 確認
おお…回線にチャージされました！支払い手続き中にメールアドレスを確認することもでき、取引が完了するとメールで通知を受け取れます。

![ステップ7 - チャージ成功](/content-images/0-TJKIcqznQ4Y8_jgo-e725aed571.webp)

## アカウントなしでチャージを購入する

上記の方法ではCoinsbeeアカウントの作成が必要です。アカウントを作成したくない場合は、CardsRelayが登録不要でZECによるモバイルチャージを販売しています。

### 1. 国と通信事業者を選択する
[CardsRelay](https://cardsrelay.com)にアクセスし、「Mobile Top Ups」セクションを開きます。世界中で750社以上の通信事業者に対応しています。

### 2. 番号と金額を入力する
チャージ先の携帯電話番号を入力し、チャージ額を選択します。表示価格は単一の総額であり、後から別途為替レートの上乗せが追加されることはありません。

### 3. メールアドレスを入力する
確認通知を届けるためにメールアドレスが必要で、注文前に認証されます。アカウントは作成されず、本人確認書類も要求されません。

### 4. ZECで支払う
チェックアウト時にZcashを選択します。ZECは第三者による換金を介さず、直接受け付けられます。支払いアドレスと正確な金額が表示されます。

### 5. 確認
チャージが処理され、通常は数秒以内に確認通知がメールで届きます。

CardsRelayは約2,500ブランドのギフトカードも販売しており、Zcashに加えてMoneroとZanoも受け付けています。運営会社はPayzy ME FZ Ltdです。

### ZECを利用できるその他の場所

近年、Zcashにはいくつかの新しい活用分野が生まれ、日常利用でさらに実用的になっています。多くのオンラインストアや加盟店が、商品やサービスの支払い方法としてZECを受け付けています。特にプライバシーに配慮した取引を重視する事業者で顕著です。  

事業を営んでいて、ZECでの支払い受付を始めたいですか？[PayWithZash](https://paywithz.cash/)を利用すれば、提供するサービスに対してZECを受け付ける事業者の一覧に、あなたの事業を追加できる可能性があります。
