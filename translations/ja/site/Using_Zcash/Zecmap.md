# ZecMap

ZecMapは、Zcash（ZEC）を受け付ける企業やサービスを見つけるための、グローバルでコミュニティ主導のディレクトリです。インタラクティブな地図インターフェースを中心に構築されており、ZEC保有者が抱く実用的な疑問、**「自分のZECはどこで使えるのか？」** に答えるのに役立ちます。

ウェブサイト: [zecmap.com](https://zecmap.com/)

---

## 要点

- ZecMapは、ZECを受け付ける加盟店をまとめた**無料の公開ディレクトリ**です。地域の店舗からオンラインショップまで掲載されています。
- **インタラクティブマップ**を閲覧して、近くや世界中のZEC対応加盟店を見つけられます。
- **誰でも企業や店舗を登録申請**でき、掲載前にコミュニティによるレビューが行われます。
- **Contributor Rewards Program**により、加盟店データの追加や検証にインセンティブが与えられます。
- ZecMapは最近、加盟店向け統合を拡大するために[CipherPay](https://x.com/ZecMap/status/2059622324958093616)と提携しました。

---

## ZecMapが提供するもの

ZecMapは、Zcashを受け付ける企業を世界地図上に整理して掲載します。各掲載情報には、企業名、カテゴリ、所在地またはウェブサイト、そしてどのようにZECが受け付けられているかが表示されます。これにより、ZEC保有者は次のことを簡単に行えます。

- 旅行前に、近くのカフェ、レストラン、ホテル、ショップ、またはサービスでZECを受け付ける場所を探す。
- Zcash決済に対応するオンラインストア、VPNプロバイダー、フリーランサー、またはデジタルサービスを見つける。
- 都市、国、または旅行ルートごとに地域のZcash普及状況を確認する。
- 新たにZECを受け付け始めた企業の情報を追加し、ディレクトリを最新に保つ手助けをする。

## 利用例

### 地元の加盟店を探す

[zecmap.com](https://zecmap.com/)を開き、地図上で近くの加盟店を検索します。訪問前に、その企業が現在もZECを受け付けているか、またどのウォレットや支払いフローを希望しているかを確認してください。

### オンラインショップやサービスを見つける

ZecMapにはオンライン事業者も掲載されています。カテゴリ別に閲覧して、ECストア、ホスティングサービス、VPNプロバイダー、そのほかZEC決済を受け付けるデジタル加盟店を探せます。

### ZECを中心に旅行計画を立てる

新しい都市や国へ旅行しますか？ ZecMapを使えば到着前に加盟店の分布を確認できるため、ZEC対応のレストラン、ショップ、サービスに立ち寄る計画を立てられます。

### 新しいZcashユーザーを支援する

新しいユーザーは、ZECの購入方法や保管方法を学んでも、どこで使えるかを知る前に止まってしまうことがよくあります。ZecMapはその次のステップ、つまり現実世界でのZECの実用性を一覧できる、実践的で閲覧しやすいリストを提供します。

## 企業・店舗を追加する

ある企業や店舗がZECを受け付けていて、まだZecMapに載っていない場合は、コミュニティメンバーなら誰でも登録申請できます。良い申請には次の情報が含まれます。

| 項目 | 提供する内容 |
|-------|----------------|
| 企業・店舗名 | 公開されている正式名称 |
| ウェブサイトまたは連絡先 | URLまたはソーシャルプロフィール |
| 所在地 | 実店舗なら住所、オンラインなら地域 |
| カテゴリ | カフェ、レストラン、店舗、サービス、オンラインショップなど |
| 証拠 | 公開された支払いページ、加盟店の告知、または直接確認 |
| 支払いに関する注記 | 対面、オンライン、または両方；transparent ZECまたはshielded ZEC |

登録申請には、顧客の個人データを含めないようにしてください。取引証明を使う場合は、共有前に個人情報、注文番号、自宅住所を削除してください。

## 検証と承認

掲載情報は、公開される前にレビュー工程を通ります。

1. 投稿者が、検証に十分な公開情報を添えて企業・店舗を登録申請する。
2. 掲載情報に重複がないか、基本的な正確性が確認される。
3. ZEC受け付けの有無が、公開情報源または加盟店への連絡を通じて確認される。
4. 承認された掲載情報が地図上に表示される。
5. コミュニティメンバーは、古くなった掲載情報や誤った掲載情報を報告でき、ディレクトリを最新に保てる。

加盟店の支払いオプションは変わることがあるため、掲載情報はコミュニティによって維持される情報であり、保証ではないと考えてください。旅行や高額購入の前には加盟店に確認しましょう。

## Contributor Rewards Program

ZecMapは、ディレクトリの成長と維持に貢献する投稿者へ報酬を提供しています。報酬は、次のような行動を促すよう設計されています。

- **新規掲載** — ZECを受け付ける未掲載の企業や店舗を追加すること。
- **検証** — 既存の掲載情報が現在も有効で正確かを確認すること。
- **保守** — 古い情報を更新したり、閉業した企業を報告したりすること。
- **掲載範囲の拡大** — 十分に掲載されていない都市、地域、またはオンラインカテゴリの加盟店を追加すること。

最新の報酬ルールや受け取り方法については、[zecmap.com](https://zecmap.com/)を参照するか、Zcashコミュニティの各チャネルにあるZecMapのお知らせを確認してください。

## 主な機能

- **インタラクティブな世界地図** — 所在地ごとに加盟店を閲覧または検索できます。
- **企業・店舗の掲載情報** — 支払い詳細付きの地域加盟店およびオンライン加盟店。
- **ユーザーアカウント** — 掲載情報の申請、貢献の追跡、投稿者プロフィールの構築が可能です。
- **コミュニティレビュー** — 掲載情報は公開前に確認されます。
- **報告ツール** — 古いまたは誤った掲載情報を報告して、地図の正確性を保てます。

## エコシステム統合

ZecMapは、利用店舗が増えつつある決済ネットワーク**Flexa**を通じてZcash決済を受け付ける加盟店も掲載しています。これにより、Zcashをネイティブに受け付ける加盟店だけでなく、地図上に掲載される現実世界の加盟店数が拡大しています。

またZecMapは、ディレクトリに掲載される加盟店向けの決済インフラ統合を強化するため、[CipherPay](https://cipherpay.app)との提携も発表しています。

## 今後の開発

予定されている改善点は次のとおりです。

- AndroidおよびiOS向けモバイルアプリ。
- 各地域のZcashコミュニティ向け多言語対応。
- 加盟店向けの決済統合ツールと導入ガイド。
- 投稿者ランキングと評価機能。
- オンラインサービスやコミュニティ検証済み事業者向けカテゴリの拡充。
- 非アクティブな掲載情報の報告や、実際にZECが現在受け付けられているかを確認するためのより良いツール。

## ZecMapを使う際のヒント

- **行く前に確認する。** 現在もZECが受け付けられていることを、必ず加盟店に確認してください。
- **支払いタイプを確認する。** transparent ZECを受け付ける企業もあれば、shieldedを好む企業もあります。支払う前に確認しましょう。
- **コミュニティを助ける。** 古くなっている、または誤っている掲載情報を見つけたら、他の人が誤解しないように報告してください。
- **知っている情報を追加する。** 地元の企業や店舗がZECを受け付けていて未掲載なら、ぜひ登録申請してください。あなたの地域情報には価値があります。
