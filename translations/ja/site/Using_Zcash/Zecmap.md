# ZecMap

ZecMapは、Zcash（ZEC）を受け入れる企業やサービスを見つけるための、グローバルでコミュニティ主導のディレクトリです。インタラクティブな地図インターフェースを中心に構築されており、ZEC保有者が実用的な問い、**「自分のZECはどこで使えますか？」**に答えるのを支援します。

ウェブサイト：[zecmap.com](https://zecmap.com/)

---

## 要約

- ZecMapは、ZECを受け入れる加盟店（地域の企業やオンラインショップ）の**無料の公開ディレクトリ**です。
- **インタラクティブな地図**を閲覧して、近隣または世界中のZEC対応加盟店を見つけられます。
- **誰でも企業を登録できます**。掲載情報は公開前にコミュニティによるレビューを受けます。
- **コントリビューター報酬プログラム**により、加盟店データの追加と検証が奨励されます。
- ZecMapは最近、加盟店統合を拡大するために[CipherPay](https://x.com/ZecMap/status/2059622324958093616)と提携しました。

---

## ZecMapの機能

ZecMapは、Zcashを受け入れる企業を世界地図上で整理しています。各掲載情報には、企業名、カテゴリ、所在地またはウェブサイト、およびZECの受け入れ方法が表示されます。これにより、ZEC保有者は以下を簡単に行えます。

- 移動前に、ZECを受け入れる近隣のカフェ、レストラン、ホテル、店舗、またはサービスを見つけます。
- Zcashによる支払いをサポートするオンラインストア、VPNプロバイダー、フリーランサー、またはデジタルサービスを見つけます。
- 都市、国、または旅行ルートごとに、地域のZcash導入状況を閲覧します。
- 新たな企業がZECの受け入れを開始した際、ディレクトリを最新の状態に保つ支援をします。

## ユースケース

### 地元の加盟店を探す

[zecmap.com](https://zecmap.com/)を開き、地図で近隣の加盟店を検索します。訪問前に、ZECが現在も受け入れられていることを企業に確認し、どのウォレット（Wallet）または支払いフローを希望するか尋ねてください。

### オンラインショップとサービスを見つける

ZecMapにはオンライン企業も掲載されています。カテゴリ別に閲覧して、ZECによる支払いを受け入れるEコマースストア、ホスティングサービス、VPNプロバイダー、その他のデジタル加盟店を見つけてください。

### ZECを使った旅行計画

新しい都市や国へ旅行しますか？ ZecMapでは、到着前に加盟店の利用可能範囲を閲覧できるため、ZEC対応のレストラン、店舗、サービスに立ち寄る計画を立てられます。

### 新しいZcashユーザーを支援する

新しいユーザーは、ZECをどこで使えるかを知る前に、購入方法や保管方法を学ぶことがよくあります。ZecMapは、その次の段階、すなわち現実世界におけるZECの実用性を確認できる、実用的で閲覧可能なリストを提供します。

## 企業を追加する

ある企業がZECを受け入れており、まだZecMapに掲載されていない場合、コミュニティの誰でも登録できます。適切な登録には以下が含まれます。

| 項目 | 提供する情報 |
|-------|----------------|
| Business name | 公開されている正式名称 |
| Website or contact | URLまたはソーシャルプロフィール |
| Location | 実店舗の場合は住所、オンラインの場合は地域 |
| Category | カフェ、レストラン、店舗、サービス、オンラインショップなど |
| Evidence | 公開されている支払いページ、加盟店のお知らせ、または直接確認 |
| Payment notes | 対面、オンライン、または両方。公開型またはシールドされたZEC |

登録内容には、顧客の非公開データを含めないでください。トランザクション（Transaction）のproofを使用する場合は、共有前に個人情報、注文番号、自宅住所を削除してください。

## 検証と承認

掲載情報は公開前にレビュー手続きを経ます。

1. コントリビューターは、検証に十分な公開情報とともに企業を登録します。
2. 掲載情報について、重複と基本的な正確性が確認されます。
3. ZECの受け入れは、公開情報源または加盟店への連絡を通じて確認されます。
4. 承認された掲載情報は地図に表示されます。
5. コミュニティメンバーは、古くなった情報や不正確な掲載情報を報告でき、ディレクトリを最新の状態に保てます。

加盟店の支払いオプションは変更される可能性があるため、掲載情報は保証ではなく、コミュニティによって維持される情報として扱ってください。旅行や高額な購入の前には、加盟店に確認してください。

## コントリビューター報酬プログラム

ZecMapは、ディレクトリの拡充と維持に貢献するコントリビューターに報酬を提供します。報酬は次の活動を奨励するよう設計されています。

- **新規掲載** — ZECを受け入れる、まだ地図に載っていない企業を追加します。
- **検証** — 既存の掲載情報が現在も有効で正確であることを確認します。
- **保守** — 古くなった情報を更新するか、閉業した企業を報告します。
- **対象範囲の拡大** — 十分に掲載されていない都市、地域、またはオンラインカテゴリの加盟店を追加します。

現在の報酬ルールと受け取り方法については、[zecmap.com](https://zecmap.com/)を参照するか、ZcashコミュニティチャネルのZecMapお知らせを確認してください。

## 主な機能

- **インタラクティブな世界地図** — 所在地別に加盟店を閲覧または検索できます。
- **企業掲載情報** — 支払い詳細を含む、地域およびオンラインの加盟店情報です。
- **ユーザーアカウント** — 掲載情報の登録、貢献の追跡、コントリビュータープロフィールの作成ができます。
- **コミュニティレビュー** — 掲載情報は公開前に確認されます。
- **報告ツール** — 地図の正確性を保つため、古くなった項目や不正確な項目を報告できます。

## エコシステム統合

ZecMapは、増加する小売店舗で使用されている支払いネットワークである**Flexa**を通じて、Zcashによる支払いを受け入れる加盟店を受け入れています。これにより、Zcashをネイティブに受け入れる加盟店を超えて、地図に掲載される現実世界の加盟店数が増加します。

ZecMapはまた、ディレクトリ内の加盟店向け支払いインフラ統合を深めるため、[CipherPay](https://cipherpay.app)との提携を発表しました。

## ZecMapを利用するためのヒント

- **訪問前に確認してください。** ZECが現在も受け入れられていることを、必ず加盟店に確認してください。
- **支払いタイプを確認してください。** 公開型のZECを受け入れる企業もあれば、シールドされたものを希望する企業もあります。支払い前に尋ねてください。
- **コミュニティを支援してください。** 古くなった、または不正確な掲載情報を見つけた場合は、他の人が誤解しないよう報告してください。
- **知っている情報を追加してください。** 地元の企業がZECを受け入れていて掲載されていない場合は、登録してください。あなたの地域に関する知識は貴重です。
