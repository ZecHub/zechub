# Zcash マイニングガイド: 個人所有のハードウェアでマイニングプールに参加する

## はじめに

Zcash (ZEC) は、マイニングに Equihash プルーフ・オブ・ワーク・アルゴリズムを使用する、プライバシー重視の暗号資産です。Zcash のマイニングでは、計算能力を使って複雑な数学的問題を解き、トランザクションを検証し、ネットワークを保護する対価として ZEC 報酬を得ます。ネットワーク難易度が高いため、ほとんどのユーザーにはソロマイニングは推奨されません。自分のハッシュパワーをほかの人と組み合わせて安定した報酬を得るには、マイニングプールへの参加が最適です。

このガイドでは、個人所有のハードウェア（例: GPU を搭載した家庭用 PC やエントリークラスの ASIC）を使用した Zcash マイニングに焦点を当てます。GPU でも依然として Zcash をマイニングできますが、ネットワーク難易度の影響により、2026年時点では ASIC のほうがはるかに効率的かつ収益性が高い点に注意してください。電気料金、ハードウェア価格、ZEC の価値といった要因が採算性に影響するため、必ず WhatToMine.com のようなツールで現在の収益性を確認してください。マイニングは誰にとっても利益が出るとは限りません。現地の規制や電力単価も調べましょう（目安は < $0.08/kWh）。


## 必要なもの

### ハードウェア
- **GPU マイニング（初心者向けの個人環境として推奨）:**
  - 少なくとも 4GB の VRAM を備えた NVIDIA または AMD の GPU（例: NVIDIA GTX 1070、RTX 3060、AMD RX 580 以上）。
  - 対応するマザーボード、十分な容量の PSU（複数 GPU の場合は最低 750W）、および過熱防止のための適切な冷却。
  - より高いハッシュレートを得るためにマルチ GPU リグが一般的です（例: GPU 6 枚で 1～2 kSol/s を達成可能）。
- **ASIC マイニング（より高効率だが高コスト）:**
  - Bitmain Antminer Z15 (420 kSol/s) や Innosilicon A9 (50 kSol/s) などの Equihash 対応 ASIC。
  - これらは騒音が大きく、高温になりやすく、消費電力も高い（例: 1500W+）ため、専用スペース向きです。Bitmain.com や販売代理店（Blockware Mining）など信頼できる供給元から購入してください。
- **全般:** 安定したインターネット接続、設定および監視用のコンピューター。2026年にはネットワークの大半を ASIC が占めています（総ハッシュレート約 13 GSol/s）ので、GPU マイニングの競争力は下がっていますが、趣味用途としては依然可能です。

### ソフトウェア
- **オペレーティングシステム:** Windows 10/11、Linux（安定性の面で Ubuntu 推奨）。
- **マイニングソフトウェア:**
  - GPU 向け: lolMiner（AMD/NVIDIA 対応）、GMiner、または miniZ（NVIDIA 向け）。公式 GitHub リポジトリからダウンロードしてください（例: github.com/Lolliedieb/lolMiner-releases）。
  - ASIC 向け: メーカー組み込みのファームウェア／ダッシュボードを使用します（例: Bitmain の Web インターフェース）。
- **ウォレット:** 支払いを受け取るための Zcash ウォレット。推奨:
  - Shielded（プライベート）: Zashi Wallet、Zingo (Mobile/Desktop) YWallet (mobile/desktop)。
  - Transparent（より簡単だがプライバシーは低い）: Edge Wallet、Zecwallet Lite。
  - [wallets](https://zechub.wiki/wallets) からダウンロードしてください。プールが対応している場合は、プライバシー保護のため shielded アドレス（`zs` で始まる）を生成してください。

### その他
- 電気代: コストを計算してください。GPU は 1 枚あたり 150～300W、ASIC は 1000W+ を消費します。
- アンチウイルス: マイナーを脅威として検出する場合があるため、セットアップ中は無効化してください。

## マイニングプール参加のステップバイステップガイド

### ステップ 1: Zcash ウォレットを設定する
1. 公式 Zcash サイトの [wallets](https://zechub.wiki/wallets) からウォレットをダウンロードしてインストールします。
2. 新しいウォレットを作成し、シードフレーズを安全にバックアップします。
3. 受信用アドレスを生成します（プライバシーのため、できれば shielded）。例: `zs1exampleaddress...` のように控えておきます。
4. Transparent アドレス（`t` で始まる）を使う場合は簡単ですが、プライバシーは低くなります。

### ステップ 2: ハードウェアを準備する
- GPU の場合:
  1. PC に GPU を取り付け、ドライバーを更新します（NVIDIA: GeForce Experience、AMD: Radeon Software）。
  2. 経験がある場合はオーバークロックします（安定性のため MSI Afterburner を使用し、効率重視でコアクロック +100～200、メモリ -500 を目安にします）。
- ASIC の場合:
  1. ASIC を電源と Ethernet に接続します。
  2. Advanced IP Scanner やメーカーのアプリなどを使って IP アドレスを見つけます。
  3. Web ダッシュボードにアクセスします（例: ブラウザに IP を入力、Bitmain のデフォルトログインは root/root）。

**警告:** 適切な換気を確保してください。マイニングでは熱が発生します。まずは小規模で始めてテストしましょう。

### ステップ 3: マイニングプールを選んで参加する
マイニングプールは作業を分配し、貢献したハッシュレートに応じて報酬を分け合います。手数料（0～2%）、最低支払額（0.01～0.1 ZEC）、所在地（低 ping）、信頼性を基準に選びましょう。

**推奨プール（ハッシュレート、手数料、レビューに基づく）:**
- **2Miners (zec.2miners.com)**: 手数料 1%、PPLNS 支払い、GPU/ASIC/NiceHash 対応。高ハッシュレート（約 1.17 GSol/s）でサーバーも安定。
- **F2Pool (zec.f2pool.com)**: 手数料 2%、PPS+ 支払い、複数コイン対応。大規模プール（約 2.57 GSol/s）。
- **ViaBTC (zec.viabtc.com)**: 手数料 2%（PPS+）、使いやすいダッシュボード、グローバルサーバー。
- **AntPool (zec.antpool.com)**: 手数料 1%、Bitmain 提供、ASIC 向けに適しています（約 494 MSol/s）。
- **Sovright (mining.sovright.com)**: Stratum V2 上に構築された Zcash プールで、現在はパブリックテストネットとして稼働中です。まだ実際の ZEC 支払いはないため、収益源というよりセットアップを試す手段として扱ってください。詳細は以下の専用セクションを参照してください。
- その他: Kryptex Pool、Luxor（リアルタイム統計は poolwatch.io/coin/zcash を確認）。

1. プールの Web サイトにアクセスし、アカウントを作成します（メール登録、または 2Miners のように登録不要の場合もあります）。
2. 支払い設定に Zcash ウォレットアドレスを追加します。
3. プールの stratum サーバー（例: zec.2miners.com:1010）とポートを控えておきます。

### ステップ 4: マイニングソフトウェアをインストールして設定する
- GPU の場合（例: Windows/Linux 上の lolMiner）:
  1. GitHub から lolMiner をダウンロードします（最新版、例: 1.88）。
  2. フォルダーに展開します。
  3. 設定用のバッチファイル（start.bat）を作成します:
     ```
     lolMiner.exe --coin ZEC --pool zec.2miners.com:1010 --user YOUR_WALLET_ADDRESS.WORKER_NAME --pass x
     ```
     - `YOUR_WALLET_ADDRESS` を自分の ZEC アドレスに置き換えます。
     - `WORKER_NAME`: 自分のリグ名（例: Rig1）。
     - EU サーバーの場合: eu.zec.2miners.com:1010。
  4. バッチファイルを実行します。プールに接続してマイニングを開始します。
- ASIC の場合（例: Bitmain Antminer）:
  1. Web ダッシュボードにログインします。
  2. Miner Configuration に移動します。
  3. プール情報を追加します:
     - URL: stratum+tcp://zec.2miners.com:1010
     - Username: YOUR_WALLET_ADDRESS.WORKER_NAME
     - Password: x（または空欄）。
  4. 保存してマイナーを再起動します。
- その他のソフトウェアの場合（例: GMiner）:
  ```
  miner.exe --algo 125_4 --server zec.2miners.com:1010 --user YOUR_WALLET_ADDRESS.WORKER_NAME --pass x
  ```

**テスト:** 10～15 分実行し、accepted shares とハッシュレートをコンソールで確認してください。

### ステップ 5: マイニングを開始して監視する
1. マイナーを起動すると、プールに接続して share の送信を開始します。
2. 次の方法で監視します:
   - プールのダッシュボード: ウォレットアドレスを入力して、ハッシュレート、未払い残高、統計を確認します。
   - ソフトウェアコンソール: エラーや温度を確認します（80℃ 未満を維持）。
   - ツール: リモートでリグを管理するために HiveOS や SimpleMining OS を使用します。
3. 支払い: 多くのプールでは、最低額（例: 0.05 ZEC）に達すると自動支払いされます。プールのルールを確認してください。

## Sovright: テストネットプールとリレーネットワーク

Sovright (sovright.com) は、Stratum V2 マイニングプールと、別個のブロックリレーネットワークを運用しています。両者は役割が異なるため、以下で分けて説明します。

### マイニングプール (mining.sovright.com)

Sovright のプールは Zcash メインネットではなく、パブリック Zcash テストネット（NU6、Stratum V2）上で稼働しています。テストネットでは実際の ZEC は支払われません。収益目的ではなく、マイナー設定のテストに使用してください。

- 開始にあたってアカウントは不要です。CPU または ASIC の Equihash マイナーをプールに向ければ、share がライブダッシュボードに表示されます。
- Sovright はまた、プールのジョブをそのまま受け取るだけでなく、自分でブロックテンプレートを選びたいマイナー向けに、オープンソースの Stratum V2 プロキシも公開しています:
  ```
  git clone https://github.com/sovright/mining-infra
  cd mining-infra
  cargo build --release -p sovright-v1-stratum-proxy
  ./target/release/sovright-v1-stratum-proxy --listen 0.0.0.0:3334 --upstream 34.28.134.13:3333
  ```
  マイナーはプールに直接ではなく、このプロキシに向けてください:
  ```
  stratum+tcp://<your-proxy-ip>:3334
  ```
  ワーカー名には `yourname.rig1` のような形式を使用します。
- Sovright の透明性ページには、shielded トランザクションを除外する一部のプールとは異なり、「すべて含める」ポリシーが明記されています。各ブロックには署名付き証明が付与され、このポリシーを独立して検証できます。
- サンプルダッシュボードデータではなく自分自身のワーカーを追跡したい場合は、mining.sovright.com でアカウントを作成してください（Google またはメールでサインイン）。

### リレーネットワーク (relay.sovright.com)

Sovright はこれとは別に、Zcash メインネット上でパブリックなブロックリレーネットワークを運用しています。プールがブロックを見つけたとき、そのブロックがネットワーク全体へどれだけ速く届くかによって orphan になる頻度が決まります。つまり、伝播競争に負けて報酬を失う可能性があるということです。このリレーは、前方誤り訂正付きの compact block relay を使って、4つのリージョン間でブロックを転送します。

パブリックダッシュボードではその効果がリアルタイムで確認できます。リレー接続されたリージョンでは、通常のピアツーピア gossip に比べて半分未満の時間で新しいブロックを受信し、ダッシュボードではネットワークの現在の orphan rate も追跡しています。

これは個人マイナー向けではなく、プール運営者向けのインフラです。Sovright のオープンソース `mining-infra` リポジトリには、見つかったブロックをネイティブ P2P より速くメッシュへ流し込むための `submitblock` リレーゲートウェイが文書化されています。接続するには、リレーピアアドレスと認証キーを取得するため、Sovright（support@sovright.com）へ直接連絡してください。


## ヒントとベストプラクティス
- **収益性:** whattomine.com/coins/166-zec-equihash のような計算機を使用してください。例: RTX 3060（約 300 Sol/s）では、$50/ZEC の場合、電気代約 $0.50 を差し引く前で 1 日あたり約 0.001 ZEC を稼げます。
- **プライバシー:** 可能であれば shielded 対応プールを使い、アドレスの再利用は避けてください。
- **セキュリティ:** 強力なパスワードを使い、プールやウォレットで 2FA を有効にしてください。秘密鍵は絶対に共有しないでください。
- **トラブルシューティング:** share が送られない場合は、ファイアウォール、アンチウイルス、設定ミスを確認してください。forum.zcashcommunity.com や Reddit の r/zec のようなフォーラムに参加するのも有効です。
- **代替案:** 採算が取れない場合は、クラウドマイニングや他のコインのステーキングを検討してください。
- **環境面の注意:** マイニングはエネルギーを消費します。可能であれば再生可能エネルギー源を使ってください。
- **アップデート:** Zcash は今後進化する可能性があります（例: PoS への移行の可能性）。ニュースは z.cash で確認してください。
