# Zcash マイニングガイド: 個人用ハードウェアでマイニングプールに参加する

## はじめに

Zcash (ZEC) は、マイニングに Equihash プルーフ・オブ・ワークアルゴリズムを使用する、プライバシー重視の暗号資産です。Zcash のマイニングでは、計算能力を使って複雑な数学的問題を解き、トランザクションを検証し、ネットワークを保護することで、その対価として ZEC 報酬を得ます。ネットワークの難易度が高いため、ほとんどのユーザーにはソロマイニングは推奨されません。マイニングプールに参加することは、自分のハッシュパワーを他の参加者と組み合わせて、安定した報酬を得るための最善の方法です。

このガイドは、個人用ハードウェア（例: GPU を搭載した家庭用 PC やエントリーレベルの ASIC）を使って Zcash をマイニングすることに焦点を当てています。GPU でも依然として Zcash をマイニングできますが、ネットワーク難易度のため 2026 年時点では ASIC のほうがはるかに効率的で収益性が高い点に注意してください。電気代、ハードウェア価格、ZEC の価値などが採算性に影響するため、WhatToMine.com のようなツールで常に最新の収益性を確認してください。マイニングはすべての人にとって利益が出るとは限りません。地域の規制と電力料金を調べましょう（目安は < $0.08/kWh）。


## 必要なもの

### ハードウェア
- **GPU マイニング（初心者に推奨される個人セットアップ）:**
  - 4GB 以上の VRAM を搭載した NVIDIA または AMD の GPU（例: NVIDIA GTX 1070、RTX 3060、AMD RX 580 以上）。
  - 対応するマザーボード、十分な容量の PSU（複数 GPU の場合は最低 750W）、および過熱を防ぐための適切な冷却。
  - より高いハッシュレートを得るためにマルチ GPU リグが一般的です（例: GPU 6 枚で 1〜2 kSol/s を達成可能）。
- **ASIC マイニング（より効率的だが高コスト）:**
  - Bitmain Antminer Z15 (420 kSol/s) や Innosilicon A9 (50 kSol/s) などの Equihash 対応 ASIC。
  - これらは騒音が大きく、発熱も高く、消費電力も大きい（例: 1500W+）ため、専用スペース向きです。Bitmain.com やリセラー（Blockware Mining）など信頼できる販売元から購入してください。
- **一般:** 安定したインターネット接続、セットアップと監視用のコンピューター。ネットワークは ASIC が支配的です（2026 年の総ハッシュレートは約 13 GSol/s）ので、GPU マイニングの競争力は低めですが、趣味としては依然可能です。

### ソフトウェア
- **オペレーティングシステム:** Windows 10/11、Linux（安定性の観点から Ubuntu 推奨）。
- **マイニングソフトウェア:**
  - GPU 向け: lolMiner（AMD/NVIDIA 対応）、GMiner、または miniZ（NVIDIA 重視）。公式 GitHub リポジトリ（例: github.com/Lolliedieb/lolMiner-releases）からダウンロードしてください。
  - ASIC 向け: メーカー内蔵のファームウェア/ダッシュボードを使用します（例: Bitmain の Web インターフェース）。
- **ウォレット:** 支払いを受け取るための Zcash ウォレット。推奨:
  - Shielded（プライベート）: Zodl Wallet、Zingo (Mobile/Desktop) YWallet (mobile/desktop)。
  - Transparent（簡単だがプライバシーは低い）: Edge Wallet、Zecwallet Lite。
  - [wallets](https://zechub.wiki/wallets) からダウンロードしてください。プールが対応している場合は、プライバシー保護のため shielded アドレス（`zs` で始まる）を生成してください。

### その他
- 電気代: コストを計算してください。GPU は 1 枚あたり 150〜300W、ASIC は 1000W+ を消費します。
- アンチウイルス: セットアップ中は無効にしてください。マイナーを脅威として検知する場合があります。

## マイニングプールに参加する手順ガイド

### ステップ 1: Zcash ウォレットをセットアップする
1. 公式 Zcash ウェブサイトの [wallets](https://zechub.wiki/wallets) からウォレットをダウンロードしてインストールします。
2. 新しいウォレットを作成し、シードフレーズを安全にバックアップします。
3. 受取アドレスを生成します（プライバシーのため、できれば shielded）。例として `zs1exampleaddress...` のように控えておきます。
4. transparent アドレス（`t` で始まる）を使う場合は簡単ですが、プライバシーは低くなります。

### ステップ 2: ハードウェアを準備する
- GPU の場合:
  1. PC に GPU を取り付け、ドライバーを更新します（NVIDIA: GeForce Experience、AMD: Radeon Software）。
  2. 経験がある場合はオーバークロックします（安定性のため MSI Afterburner を使用し、効率重視でコアクロック +100〜200、メモリ -500 を目安にします）。
- ASIC の場合:
  1. ASIC を電源と Ethernet に接続します。
  2. Advanced IP Scanner やメーカーのアプリなどのツールを使って IP アドレスを見つけます。
  3. Web ダッシュボードにアクセスします（例: ブラウザに IP を入力、Bitmain のデフォルトログインは root/root）。

**警告:** 適切な換気を確保してください。マイニングは熱を発生させます。まずは小規模に始めてテストしてください。

### ステップ 3: マイニングプールを選んで参加する
マイニングプールは作業を分配し、提供したハッシュレートに応じて報酬を分配します。手数料（0〜2%）、最低支払額（0.01〜0.1 ZEC）、所在地（低 ping）、信頼性を基準に選びましょう。

**推奨プール（ハッシュレート、手数料、レビューに基づく）:**
- **2Miners (zec.2miners.com)**: 手数料 1%、PPLNS 支払い、GPU/ASIC/NiceHash 対応。高ハッシュレート（約 1.17 GSol/s）、信頼性の高いサーバー。
- **F2Pool (zec.f2pool.com)**: 手数料 2%、PPS+ 支払い、マルチコイン対応。大規模プール（約 2.57 GSol/s）。
- **ViaBTC (zec.viabtc.com)**: 手数料 2%（PPS+）、使いやすいダッシュボード、グローバルサーバー。
- **AntPool (zec.antpool.com)**: 手数料 1%、Bitmain 提供、ASIC 向けに適しています（約 494 MSol/s）。
- **Foundry Zcash Pool (foundrydigital.com/foundry-zcash-pool/)**: Foundry Digital によるプロフェッショナル向け Zcash マイニングプール。PPLNS 支払いを採用し、透明性のある報酬追跡とエンタープライズ級サポートを提供します。機関投資家や大規模 ASIC マイナーに最適で、アカウント確認が必要です。
- **Sovright (mining.sovright.com)**: Stratum V2 上に構築された Zcash プールで、現在は公開テストネットとして稼働しています。まだ実際の ZEC 支払いはないため、収益源ではなくセットアップをテストする手段として扱ってください。詳細は下の専用セクションを参照してください。
- その他: Kryptex Pool、Luxor（リアルタイム統計は poolwatch.io/coin/zcash を確認）。

1. プールの Web サイトにアクセスし、アカウントを作成します（メール登録、または 2Miners のように一部は登録不要）。
2. 支払い設定で自分の Zcash ウォレットアドレスを追加します。
3. プールの stratum サーバー（例: zec.2miners.com:1010）とポートを控えます。

### ステップ 4: マイニングソフトウェアをインストールして設定する
- GPU の場合（例: Windows/Linux 上の lolMiner）:
  1. GitHub から lolMiner をダウンロードします（最新バージョン、例: 1.88）。
  2. フォルダーに展開します。
  3. 設定内容を含むバッチファイル（start.bat）を作成します:
     ```
     lolMiner.exe --coin ZEC --pool zec.2miners.com:1010 --user YOUR_WALLET_ADDRESS.WORKER_NAME --pass x
     ```
     - `YOUR_WALLET_ADDRESS` を自分の ZEC アドレスに置き換えます。
     - `WORKER_NAME`: 自分のリグ名（例: Rig1）。
     - EU サーバーの場合: eu.zec.2miners.com:1010。
  4. バッチファイルを実行します。プールに接続し、マイニングを開始します。
- ASIC の場合（例: Bitmain Antminer）:
  1. Web ダッシュボードにログインします。
  2. Miner Configuration に移動します。
  3. プール詳細を追加します:
     - URL: stratum+tcp://zec.2miners.com:1010
     - Username: YOUR_WALLET_ADDRESS.WORKER_NAME
     - Password: x (または空欄)。
  4. 保存してマイナーを再起動します。
- 他のソフトウェアの場合（例: GMiner）:
  ```
  miner.exe --algo 125_4 --server zec.2miners.com:1010 --user YOUR_WALLET_ADDRESS.WORKER_NAME --pass x
  ```

**テスト:** 10〜15 分間実行し、コンソールで受理されたシェアとハッシュレートを確認してください。

### ステップ 5: マイニングを開始して監視する
1. マイナーを起動します。プールに接続し、シェアの送信を開始します。
2. 次の方法で監視します:
   - プールのダッシュボード: ウォレットアドレスを入力して、ハッシュレート、未払い残高、統計を確認します。
   - ソフトウェアのコンソール: エラーや温度を監視します（80℃ 未満を維持）。
   - ツール: リモートでのリグ管理には HiveOS や SimpleMining OS を使用します。
3. 支払い: ほとんどのプールは最低額（例: 0.05 ZEC）に達すると自動で支払います。プールのルールを確認してください。

## Sovright: テストネットプールとリレーネットワーク

Sovright (sovright.com) は Stratum V2 マイニングプールと、別個のブロックリレーネットワークを運用しています。役割が異なるため、以下で分けて説明します。

### マイニングプール (mining.sovright.com)

Sovright のプールは、メインネットではなく公開 Zcash テストネット（NU6、Stratum V2）上で動作しています。テストネットでは実際の ZEC は支払われません。収益目的ではなく、マイナー設定のテストに使ってください。

- 開始にアカウントは不要です。CPU または ASIC の Equihash マイナーをプールに向けると、シェアがライブダッシュボードに表示されます。
- Sovright は、プールのジョブを受け取るだけでなく、自分でブロックテンプレートを選びたいマイナー向けに、オープンソースの Stratum V2 プロキシも公開しています:

### Foundry Zcash Pool の監視

Foundry Zcash Pool のユーザー向け:

- Foundry プールのダッシュボードを通じてマイナーのパフォーマンスを監視します。
- 確認項目:
  - 稼働中のワーカー
  - 報告ハッシュレート
  - 受理されたシェア
  - 推定報酬
  - 支払い状況

Foundry は PPLNS 報酬モデルを使用しているため、マイニング報酬は瞬間的なハッシュレートだけでなく、プールの報酬ウィンドウ内で提供したシェアに依存します。

推奨される監視方法:
- ASIC ダッシュボードのハッシュレートと Foundry の報告ハッシュレートを比較する。
- リジェクトされたシェア、stale シェア、接続の不安定さを調査する。
- ダウンタイムにより送信シェア数と潜在報酬が減少するため、安定したネットワーク接続を維持する。
  ```
  git clone https://github.com/sovright/mining-infra
  cd mining-infra
  cargo build --release -p sovright-v1-stratum-proxy
  ./target/release/sovright-v1-stratum-proxy --listen 0.0.0.0:3334 --upstream 34.28.134.13:3333
  ```
  プールに直接接続する代わりに、マイナーをこのプロキシに向けてください:
  ```
  stratum+tcp://<your-proxy-ip>:3334
  ```
  `yourname.rig1` のようなワーカー名を使用します。
- Sovright の透明性ページには、一部のプールのように shielded トランザクションを除外せず、「すべて含める」ポリシーが記載されています。各ブロックには署名付き証明が付与されるため、このポリシーは独立して検証できます。
- サンプルダッシュボードのデータではなく自分自身のワーカーを追跡するには、mining.sovright.com でアカウントを作成します（Google またはメールでサインイン）。

### リレーネットワーク (relay.sovright.com)

Sovright はこれとは別に、Zcash メインネット上で公開ブロックリレーネットワークを運用しています。プールがブロックを見つけた際、そのブロックがネットワーク全体にどれだけ速く届くかによって、どれだけ orphaned されるかが決まります。つまり伝播競争に負けて、その報酬を失う可能性があるということです。このリレーは、前方誤り訂正を用いた compact block relay により、4 つの地域をまたいでブロックを転送します。

公開ダッシュボードではその効果をリアルタイムで確認できます。リレー接続された地域では、通常のピアツーピアのゴシップ伝播に比べて半分未満の時間で新しいブロックを受信でき、ダッシュボードではネットワークのリアルタイム orphan 率も追跡されています。

これは個人マイナー向けではなく、プール運営者向けのインフラです。Sovright のオープンソース `mining-infra` リポジトリには、見つかったブロックをネイティブ P2P より速くメッシュへ送り込むための `submitblock` リレーゲートウェイが文書化されています。接続するには、リレーピアアドレスと認証キーについて Sovright（support@sovright.com）に直接問い合わせてください。


## ヒントとベストプラクティス
- **収益性:** whattomine.com/coins/166-zec-equihash のような計算機を使用してください。例: RTX 3060（約 300 Sol/s）は、$50/ZEC の場合、電気代約 ~$0.50 を差し引く前で 1 日あたり約 0.001 ZEC を稼げます。
- **プライバシー:** 可能なら shielded 対応プールを使用し、アドレスの再利用を避けてください。
- **セキュリティ:** 強力なパスワードを使用し、プール/ウォレットで 2FA を有効にしてください。秘密鍵は絶対に共有しないでください。
- **トラブルシューティング:** シェアが送られない場合は、ファイアウォール、アンチウイルス、設定ミスを確認してください。forum.zcashcommunity.com や Reddit の r/zec のようなフォーラムに参加しましょう。
- **代替案:** 収益が出ない場合は、クラウドマイニングや他のコインのステーキングを検討してください。
- **環境面の注意:** マイニングはエネルギーを消費します。可能なら再生可能エネルギーを利用してください。
- **更新情報:** Zcash は今後進化する可能性があります（例: PoS への移行の可能性）。最新情報は z.cash で確認してください。
