# Zcash クリエイター向けツール：投げ銭・プロフィールプラットフォーム

## 要約

* 2つのZcashツールが、クリエイターのプライベートな収益受け取りを支援します。Zcash.meはシールドアドレスを掲載したプロフィールページを提供し、TIPZはファンからの投げ銭を受け取れるようにします。
* Zcash.meでは、統合アドレスとソーシャルアカウントを表示する1つのリンク、`zcash.me/[username]`を共有します。
* TIPZでは、ファンは他の暗号資産で投げ銭でき、すべての投げ銭がシールドされたZECとして届きます。
* どちらのツールでも、統合アドレス（`u1...`）が必要です。
* シールドアドレスへの投げ銭により、収入と残高は公開されません。

## 基本解説

### Zcash.me

![Zcash.me Logo](/content-images/_unavailable.svg)

#### 概要

**Zcash.me**は、誰でも簡単にZcashユーザーを見つけてZECを送れるプロフィールディレクトリ兼発見プラットフォームです。「Zcash版Linktree」として、シールドアドレスとソーシャル上の存在を1つのリンクで共有できるシンプルな方法を提供します。

| 項目              | 詳細 |
|-------------------|---------|
| **ウェブサイト**       | [https://zcash.me/](https://zcash.me/) |
| **Twitter**       | [@zcashme](https://x.com/zcashme) |
| **プロフィール形式**| `zcash.me/[username]` |
| **ステータス**        | 公開中（機能は開発中） |

#### 主な機能

##### 現在利用可能
- **カスタムプロフィールページ** - ユーザー名、自己紹介、アバター、所在地を含むパーソナライズされたページ
- **シールドアドレス表示** - 統合アドレスをワンクリックでコピーできるボタン
- **ソーシャルリンク統合** - X、LinkedIn、Telegram、カスタムウェブサイト
- **認証システム** - コミュニティの信頼性を高める認証バッジ
- **紹介者リーダーボード** - 上位紹介者とコミュニティリーダーを追跡
- **アクティビティステータス** - 最終アクティブ時刻を表示。

##### 近日公開
| 機能            | 説明 |
|--------------------|-------------|
| ロケーションマップ       | 近くのZcashユーザーを探す |
| プラットフォーム統計| 成長指標を確認 |
| コミュニティ投票    | エコシステムのトピックに投票 |

#### はじめ方
1. [https://zcash.me/](https://zcash.me/)にアクセスし、**Join**をクリックします。
2. 一意のユーザー名を選び、自己紹介とプロフィール画像を追加します。
3. Zcashの統合アドレス（`u1...`）を貼り付けます。
4. ソーシャルアカウントを連携します。
5. リンクを共有します：`zcash.me/[yourusername]`

### TIPZ

![TIPZ Logo](/content-images/BbXM8cDV_400x400-e6071ba983.webp)

#### 概要

**TIPZ**は、クリエイターとサイファーパンクのために設計された**プライベート投げ銭プロトコル**です。ファンは主要な暗号資産で投げ銭でき、それは自動的に変換され、**シールドされたZEC**として届けられます。

| 項目              | 詳細 |
|-------------------|---------|
| **ウェブサイト**       | [https://tipz.cash/](https://tipz.cash/) |
| **Twitter**       | [@tipz_cash](https://x.com/tipz_cash) |
| **プロフィール形式**| `tipz.cash/@[username]` |
| **ステータス**        | 公開中 |

> *「tipz.cashは、クリエイターとサイファーパンクのためのプライベート投げ銭プロトコルです。」*

#### クリエイターにとってプライバシーが重要な理由

##### 経済的自由
- プラットフォーム手数料0%
- ノンカストディアル＆セルフカストディ
- 仲介者なし

##### プライバシー優先の設計
- すべての投げ銭はシールドされたZECとして届きます。
- 非公開のウォレット残高
- 投げ銭に添える暗号化メッセージ
- クリエイターの完全匿名化オプション

##### クロスチェーン決済
| 通貨 | ネットワーク |
|----------|---------|
| ETH      | Ethereum |
| USDC     | 複数チェーン |
| SOL      | Solana |
| ZEC      | 直接Zcash |

##### クリエイター保護
- プラットフォームから排除されるリスクなし
- 検閲耐性
- KYC不要

## ビジュアル / たとえ

カフェのカウンターにあるチップジャーはガラス製です。部屋にいる誰もが、誰がコインを入れたか、そして瓶がどれほど満たされているかを見られます。

シールドアドレスは、投函口付きの鍵付き郵便受けのように機能します。ファンはコインとメモを入れた封筒を投函し、箱を開けられるのはクリエイターだけです。TIPZは入口に通貨交換を追加します。ファンはETHまたはSOLを持って到着でき、郵便受けに届くのはZECです。

```
TIPZ Payment Flow

Fan -> tipz.cash Protocol -> Creator's Wallet (Shielded ZEC)

Fan selects amount + message -> Protocol auto-converts -> Creator receives private shielded ZEC.
```
