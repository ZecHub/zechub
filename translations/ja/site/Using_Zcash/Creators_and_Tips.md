# Zcash クリエイター（Creators）向けツール（Tools）: 投げ銭とプロフィールプラットフォーム

> **コンテンツクリエイター、サイファーパンク、プライバシー（privacy）を重視するコミュニティのために、Zcash 上で構築されたプライバシーを保護する投げ銭およびプロフィールツールの包括的ガイドです。**

## 要約

* 2つのZcashツールが、クリエイターがプライベートに報酬を受け取ることを支援します。Zcash.meでは、シールドされたアドレスを掲載したプロフィールページを作成でき、TIPZではファンから投げ銭を受け取れます。
* Zcash.meでは、統合アドレスとソーシャルアカウントを表示する1つのリンク、`zcash.me/[username]`を共有します。
* TIPZでは、ファンは他の暗号通貨で投げ銭でき、すべての投げ銭はシールドされたZECとして届きます。
* どちらのツールも統合アドレス（`u1...`）を必要とします。
* シールドされたアドレスへの投げ銭により、収入と残高は公開ビューから保護されます。

## 基本説明

### Zcash.me

![Zcash.me Logo](/content-images/_unavailable.svg)

#### 概要

**Zcash.me**は、誰でもZcashユーザーを見つけてZECを送れるようにするプロフィールディレクトリおよび発見プラットフォームです。「ZcashのためのLinktree」として機能し、1つのリンクでシールドされたアドレスとソーシャル上での存在を共有するシンプルな方法を提供します。

| 項目              | 詳細 |
|-------------------|---------|
| **ウェブサイト**       | [https://zcash.me/](https://zcash.me/) |
| **Twitter**       | [@zcashme](https://x.com/zcashme) |
| **プロフィール形式**| `zcash.me/[username]` |
| **ステータス**        | 公開中（機能は開発中） |

#### 主な機能

##### 現在利用可能
- **カスタムプロフィールページ** - ユーザー名、自己紹介、アバター、所在地を含むパーソナライズされたページ
- **シールドされたアドレスの表示** - 統合アドレス用のワンクリックコピーボタン
- **ソーシャルリンク連携** - X、LinkedIn、Telegram、カスタムウェブサイト
- **認証システム** - コミュニティの信頼のための認証バッジ
- **紹介者リーダーボード** - 上位の紹介者とコミュニティリーダーを追跡
- **アクティビティステータス** - 最終アクティブ時刻を表示します。

##### 近日公開
| 機能            | 説明 |
|--------------------|-------------|
| ロケーションマップ       | 近くのZcashユーザーを探す |
| プラットフォーム統計| 成長指標を表示 |
| コミュニティ投票    | エコシステムのトピックに投票 |
| ニュースとお知らせ | 公式アップデート |
| フォーラム              | コミュニティディスカッション |

#### はじめに
1. [https://zcash.me/](https://zcash.me/)にアクセスし、**Join** をクリックします。
2. 固有のユーザー名を選び、自己紹介とプロフィール写真を追加します。
3. Zcashの統合アドレス（`u1...`）を貼り付けます。
4. ソーシャルアカウントを接続します。
5. リンクを共有します: `zcash.me/[yourusername]`

### TIPZ

![TIPZ Logo](/content-images/BbXM8cDV_400x400-e6071ba983.webp)

#### 概要

**TIPZ**は、クリエイターとサイファーパンクのために特別に設計された**プライベート投げ銭プロトコル**です。ファンは主要な任意の暗号通貨で投げ銭でき、自動的に変換されて**シールドされたZEC**として届けられます。

| 項目              | 詳細 |
|-------------------|---------|
| **ウェブサイト**       | [https://tipz.cash/](https://tipz.cash/) |
| **Twitter**       | [@tipz_cash](https://x.com/tipz_cash) |
| **プロフィール形式**| `tipz.cash/@[username]` |
| **ステータス**        | 公開中 |

> *「tipz.cashは、クリエイターとサイファーパンクのためのプライベート投げ銭プロトコルです。」*

#### クリエイターにとってプライバシーが重要な理由

##### 経済的自由
- プラットフォーム手数料0%
- 非カストディアルかつ自己管理
- 仲介者なし

##### プライバシー第一の設計
- すべての投げ銭はシールドされたZECとして届きます。
- プライベートなウォレット（Wallet）残高
- 投げ銭に添えた暗号化（encryption）メッセージ
- クリエイターの完全匿名化オプション

##### クロスチェーン（cross-chain）支払い（payment）
| 通貨 | ネットワーク |
|----------|---------|
| ETH      | Ethereum |
| USDC     | 複数のチェーン（chain） |
| SOL      | Solana |
| ZEC      | 直接Zcash |

##### クリエイターの保護
- プラットフォームから排除されるリスクなし
- 検閲耐性
- KYC不要

## 図解 / たとえ

カフェのカウンターにある投げ銭箱はガラス製です。部屋にいる全員が、誰が硬貨を入れたか、そして箱がどれほど満たされているかを見られます。

シールドされたアドレスは、投函口のある鍵付き郵便受けのように機能します。ファンは硬貨とノート（note）が入った封筒を投函し、箱を開けられるのはクリエイターだけです。TIPZは扉のところに通貨取引所（exchange）を追加します。ファンはETHまたはSOLを持って来られ、郵便受けに届くのはZECです。

```
TIPZ Payment Flow

Fan -> tipz.cash Protocol -> Creator's Wallet (Shielded ZEC)

Fan selects amount + message -> Protocol auto-converts -> Creator receives private shielded ZEC.
```
