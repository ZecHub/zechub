# Unified Address

> Zcashのすべてに対応する1つのアドレス。これを共有すれば、送信者のウォレットがあなたに支払う最もプライベートな方法を見つけます。

Unified Address（UA）は、複数の受取先を1つにまとめた単一のZcashアドレスです。受取先とは、特定のバリュープールで資金を受け取るアドレスの部分であり、Ironwood、Sapling、および透明型があります。UAはメインネットでは`u1`で始まり、2022年5月31日のNU5ネットワークアップグレードで導入された[ZIP 316](https://zips.z.cash/zip-0316)で定義されています。

Unified Address以前は、ZECを受け取る際にアドレスの種類を考える必要がありました。`zs`アドレスはSaplingの資金を受け取り、`t`アドレスは透明型の資金を受け取り、種類間で送金するには追加の手順が必要でした。UAはそれを解消します。共有するアドレスは1つだけで、残りはウォレットが処理します。

## 仕組み

誰かがあなたのUAに送金すると、送信者のウォレットは内部の受取先を読み取り、両方のウォレットが対応する中で最もプライベートなプールを選びます。

1. 両方のウォレットが現在のシールドプールに対応している場合、支払いはシールドされた状態で届きます。公開情報がチェーンに触れることはありません。
2. 送信者が古いプールからしか送金できない場合、ウォレットはSaplingなど、両者が共有する最適な受取先にフォールバックします。
3. 送信者が透明型の資金しか送れない場合、支払いはUAの透明型受取先に届き、あなたのウォレットはそこから資金をシールドできます。

これを自分で管理する必要はありません。アドレスは変わらず、ルーティングはその内部で行われます。

## 今重要な理由

Zcashは継続的にアップグレードされています。2026年7月28日にNU6.3でIronwoodプールが有効化されたとき、UA保有者は新しいアドレスを必要としませんでした。ウォレットは、既に人々が持っているアドレス内のIronwood受取先を選ぶようになっただけです。古い単独アドレスを持つユーザーは移行が必要でしたが、UA保有者は何もする必要がありませんでした。

これが設計上の目標です。将来のネットワークアップグレードで新しいプールが追加されても、Unified Addressがそれらを取り込みます。誰もアドレスを再共有したり、手作業で資金を移動したりする必要はありません。現在のプール構成については、[Zcashバリュープール](/using-zcash/shielded-pools)を参照してください。

## 送信者ごとに新しいアドレス

ウォレットは、1つのアカウントに対して多数の多様化されたUnified Addressを生成できます。いずれも同じ資金に支払われますが、チェーン上でそれらを相互に関連付けることはできません。あなたに支払う人やサービスごとに異なるUAを渡せば、同じウォレットに支払っていることを知るために、アドレスを比較できる組み合わせは存在しません。

## 関連ツール

- **Viewing Key。** すべてのアカウントには、支出権限を共有せずに、UAが受け取るもの（または送信するすべてのもの）を共有できるUnified Viewing Keyがあります。プレフィックスは`uview`および`uivk`です。[Viewing Key](/zcash-tech/viewing-keys)を参照してください。
- **TEXアドレス。** 現在Binanceなど一部の取引所では、入金が透明型の送信元から届くことを要求しています。TEXアドレス（[ZIP 320](https://zips.z.cash/zip-0320)）は、まさにそのケースのための、UAに付随する透明型専用アドレスです。[透明型取引所アドレス](/using-zcash/transparent-exchange-addresses)を参照してください。
- **支払いリクエスト。** UAは、金額とメモがあらかじめ入力された支払いリクエストURIに埋め込めます。[支払いリクエストURI](/using-zcash/payment-request-uris)を参照してください。
