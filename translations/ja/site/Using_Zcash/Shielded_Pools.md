# Zcash バリュープール

## TL;DR

- Zcash には現在、**5つのバリュープール**があります：Sprout（レガシー）、Sapling、Orchard（支出専用）、Ironwood、および公開型。
- **Ironwood** は現在の主要なシールドされたプールであり、2026年7月28日のNU6.3アップグレード以降稼働しています。
- **Orchard** は現在**支出専用**です。新たな価値を入れることはできず、既存の資金はIronwoodへ移行します。
- **Sapling**（`zs`で始まるzアドレス）は引き続き広くサポートされており、相当量のシールドされたZECを保護し続けています。
- **公開型**アドレス（t...）はトランザクションのプライバシーを提供せず、Bitcoinと同様に機能します。
- **Sprout** は、アクティブな利用から引退したレガシーのシールドされたプールです。
- OrchardからIronwoodへの移行は**進行中**であり、ターンスタイルによって公開監査されています。
- 最も強力なプライバシー保証のため、可能な限り**シールドされたアドレス間（z → z）**のトランザクションを優先してください。


<br/>

## Zcashのバリュープールを理解する

Zcashは、資金をバリュープールとして知られる個別の会計システムに分離しています。各プールには独自の暗号学的ルールとプライバシー特性があり、プロトコルはそれらの間を移動する総価値を追跡します。

現在、ネットワークには5つの主要なバリュープールがあります：

- 公開型 — オンチェーンで公開され、完全に可視です。
- Sapling — 最初に広く採用された現代的なシールドされたプールで、現在も有効です。
- Orchard — 以前の主要なシールドされたプールで、現在は支出専用です。
- Ironwood — NU6.3で導入された、現在の主要なシールドされたプールです。
- Sprout — 2016年にZcashとともに開始された、最初のシールドされたプールです。
  


Zcashの進化に伴い、既存資金との互換性を維持しながら、セキュリティ、プライバシー、使いやすさ、監査可能性を向上させる新たなシールドされたプールが導入される場合があります。

## シールドされたプール


1. <h3 id="ironwood" class="text-3xl font-bold my-4">Ironwoodプール</h3>

Ironwoodは現在の主要なシールドされたプールです。2026年7月28日、ブロック3,428,143でNU6.3ネットワークアップグレードの一環として有効化され、新たなシールドされた価値は現在ここに存在します。

これは、2026年5月にOrchardのプルーフシステムで脆弱性が発見されたために存在します。悪用された証拠はありませんが、この欠陥により、シールドされた供給量の健全性をプルーフだけで証明することはできませんでした。その場で修正するのではなく、ネットワークは修正済みの回路を持つ新しいプールを作成し、すべてのコインを公開で数えるターンスタイルを通じて価値を移動させました。この会計によって、シールドされた供給量が完全に裏付けられているという保証が回復されます。

IronwoodはOrchardのアクションモデルとHalo 2プルーフを再利用しているため、日常的な動作は同じです。新しい点は2つあります。トランザクションはv6形式を使用すること、そしてIronwoodノートは[ZIP 2005](https://zips.z.cash/zip-2005)の下で**量子回復可能**であることです。つまり、将来の量子コンピューターが今日の暗号技術を破った場合でも、コインのオンチェーン記録は回復可能なままです。これは回復経路であり、量子耐性ではなく、古いプールには適用されません。

新しいアドレスは必要ありません。統合アドレスは複数の受信者をまとめており、ウォレットが適切なプールを選択します。

____

2. <h3 id="orchard" class="text-3xl font-bold my-4">Orchardプール</h3>


![img2](/content-images/a672e001-6dbc-4e76-ab31-0ed7d7d2ff72-93b5a23e5d.webp)
図2：Ironwoodが有効化される前の2025年10月29日までのOrchardプールを示すグラフ

<br/>

Orchardシールドされたプールは、NU5ネットワークアップグレードの一環として2022年5月31日に有効化されました。Orchardはトラステッドセットアップの必要性を排除する新しいシールドされたプロトコルを導入し、統合アドレス（UAs）で使用される主要なシールドされたプールとなりました。

Orchardは、従来のシールドされた入力と出力ではなくアクションに基づく、より柔軟なトランザクションモデルを導入することで、トランザクションメタデータの漏洩を減らし、使いやすさ、効率、プライバシーを大幅に改善しました。

2026年7月28日にIronwoodアップグレードが有効化されて以降、**Orchardは支出専用**です。新たな価値をプールに入れることはできません。すでにそこに保有されている資金は引き続き支出でき、ターンスタイルを通じてIronwoodへ移行しています。ウォレットがこれを処理しますが、ほとんどのウォレットでは移行ペースをある程度制御できます。Orchardからの各移動では金額がブロックチェーンに表示されるため、ウォレットが移行をどのように分割し、いつ実行するかはプライバシーにとって重要です。

Orchard資金を保有している場合は、移行が実際に何を意味するかについて[Ironwood](/zcash-tech/ironwood)を参照してください。

____

3. <h3 id="sapling" class="text-3xl font-bold my-4">Saplingプール</h3>


![img3](/content-images/b1c6bb71-9356-45eb-8e4a-19d7cf1790ae-5e3051b082.webp)
図3：Ironwoodが有効化される前の2025年10月29日までのSaplingプールを示すグラフ

<br/>

[Zcash Sapling](https://z.cash/upgrade/sapling)は、2018年10月28日に導入されたZcashプロトコルのアップグレードです。これは、プライバシー、効率、使いやすさの面でいくつかの制限があったSproutとして知られる以前のバージョンに対する大幅な改善です。 

アップグレードには、シールドされたアドレスのパフォーマンス向上、ユーザーの秘密鍵を公開せずに受信および送信トランザクションを確認できるようにする改善されたビューイングキー、トランザクション署名時のハードウェアウォレット用の独立したゼロ知識キーなどが含まれます。 

Zcash Saplingにより、ユーザーはSproutシリーズで必要だったより長い時間と比較して、わずか数秒でプライベートトランザクションを実行できます。 

トランザクションのシールドはプライバシーを強化し、第三者がトランザクションを関連付けたり、転送されるZECの金額を特定したりすることを不可能にします。Saplingは、プライベートトランザクションの生成に必要な計算要件を減らすことで、ユーザーにとってより利用しやすくし、使いやすさも向上させます。

Saplingウォレットアドレスは「zs」で始まり、組み込みのSaplingアドレスを持つ、サポート対象のすべてのZcashシールドされたウォレット（Zkool、Zingo Wallet、Nighthawkなど）で確認できます。Zcash Saplingは、トランザクションのプライバシーと効率性において重要な技術的発展を示しており、プライバシーとセキュリティを重視するユーザーにとってZcashを実用的かつ効果的な暗号資産にしています。

____

4. <h3 id="sprout" class="text-3xl font-bold my-4">Sproutプール</h3>


![img4](/content-images/956eceed-f4d6-4087-99d0-32a770449dda-a3cc45305e.webp)
図4：Ironwoodが有効化される前の2025年10月29日までのSproutプールを示すグラフ

Sproutは、これまでに開始された最初のオープンなパーミッションレスのゼロ知識プライバシープロトコルでした。2016年10月28日に開始されました。

Sproutアドレスは、常に「zc」である最初の2文字で識別されます。これは、ソフトウェアが大きく成長する可能性を持ち、開発に開かれた若い芽生えたブロックチェーンであることを強調するという主な目的から「Sprout」と名付けられました。 

Sproutは、[Zcashスロースタート・マイニング](https://electriccoin.co/blog/slow-start-and-mining-ecosystem/)の初期ツールとして使用され、ZECおよびマイナーへのブロック報酬の分配をもたらしました。 

シールドされたトランザクション数の増加とともにZcashエコシステムが拡大を続ける中、Zcash Sproutシリーズは、ユーザーのプライバシー、トランザクションのスケーリング、処理において制限があり、効率も低いことが判明しました。これにより、ネットワークとSaplingアップグレードが修正されました。

5. <h3 id="transparent" class="text-3xl font-bold my-4">公開型プール</h3>
<br/>

![img5](/content-images/01de2907-b62d-4421-83d7-ea4908faa828-6f74b724ed.webp)
図5：Ironwoodが有効化される前の2025年10月29日までの公開型プールを示すグラフ

<br/>

Zcash公開型プールはシールドされておらず、プライベートではありません。Zcash上の公開型ウォレットアドレスは「t」で始まり、このアドレス種別をトランザクションに使用する場合のプライバシーは非常に低くなります。

Zcashにおける公開型トランザクションはBitcoinトランザクションと似ており、マルチシグネチャトランザクションをサポートし、標準的な公開アドレスを使用します。

Zcash公開型は主に中央集権型取引所によって使用され、ユーザー間でZECを送受信する際の高い透明性とネットワーク確認を確保します。

また、Zcashシールドされたアドレスはトランザクション中に高いプライバシーを提供する一方、トランザクション処理にはより多くの計算リソースが必要であることにも注意が必要です。そのため、同程度のプライバシーを必要としないトランザクションには、公開型アドレスを採用するユーザーもいます。

<br/>

## プール間送金の推奨プラクティス

Zcashネットワーク上のトランザクションにおいて高水準のプライバシーを考慮する場合は、以下のプラクティスに従うことを推奨します。

Zcashブロックチェーン上の「zからz」ウォレット間で行われるトランザクションは、ほとんどがシールドされており、高い水準のプライバシーが得られるため、プライベートトランザクションと呼ばれることもあります。プライバシーが必要な場合、これは通常、$ZECを送受信する最善かつ最も推奨される方法です。 

---

ZECを「Zアドレス」から「Tアドレス」へ送信する場合、それはデシールディングトランザクションの一形態を意味します。この種のトランザクションでは、ZECを公開型アドレスに送信する影響により、一部の情報がブロックチェーン上で可視となるため、プライバシー水準は必ずしも高くありません。高いプライバシーが必要な場合、デシールディングトランザクションは常に推奨されるわけではありません。 

---

ZECを公開型アドレス（Tアドレス）からZアドレスへ転送することは、シールディングとして知られています。この種のトランザクションのプライバシー水準は、z-zトランザクションと比べて必ずしも高くありませんが、プライバシーが必要な場合にも推奨されます。 

---

Zcashネットワーク上で、ZECを公開型アドレス（Tアドレス）から別の公開型アドレス（Tアドレス）へ送信すること（T-Tトランザクション）は、Bitcoinトランザクションと非常によく似ています。このため、Zcash上のT-Tトランザクションは常に公開トランザクションと呼ばれます。送信者と受信者のトランザクション詳細の両方が公開され、このようなトランザクションのプライバシー水準が非常に低くなるためです。 

ほとんどの暗号資産中央集権型取引所は、Zcashブロックチェーン上でトランザクションを行う際に公開型アドレス（「Tアドレス」）を使用しますが、この種類のトランザクション（T-T）にはプライベートな特性はありません。

<br/>

## OrchardからIronwoodへの移行

移行は現在行われています。Orchardは新規入金を受け付けない状態であり、そこに残る価値はトランザクションごとにIronwoodへ移動しています。合計は[ironwood.live](https://ironwood.live/)で確認できます。

これが何を意味するかは、資金の所在によって異なります：

1. **新しいシールドされたアクティビティ**は、自動的にIronwoodへ入ります。対応は不要です。
2. **既存のOrchard資金**は移行する必要があります。保守されているウォレットがこれを処理し、通常は一度にではなく段階的に行います。
3. **Saplingは影響を受けず**、引き続き資金を受け付けます。封鎖されたのはOrchardのみです。
4. **ターンスタイルはすべてを数えます**。プール間を通過するものすべてを数えることで、途中でコインが作り出されていないことを証明します。

> **知っておくべきプライバシー上の注意点。** ターンスタイルは、プール間を移動する*金額*とブロック高を公開します。送信者と受信者は従来どおり隠されていますが、特徴的な金額はあなたに結び付けられる可能性があります。このため、ウォレットは残高を1つの識別可能な塊として移動するのではなく、標準的な額を使用して段階的に移行します。ウォレットに適切なペースで進めさせ、移動する金額にIPが紐付かないよう、TorまたはVPNの使用を検討してください。

アップグレード自体については[Ironwood](/zcash-tech/ironwood)を、会計の仕組みについては[ターンスタイル](/zcash-tech/the-turnstile)を参照してください。

## 避けるべき一般的な間違い

- **tアドレスからtアドレスへの送信** — 完全に公開され、プライバシーはありません。必ず最初に資金をシールドしてください。
- **Orchardがまだ資金を受け付けていると思い込むこと** — 2026年7月28日以降は支出専用です。価値を出すことはできますが、新たに入れることはできません。
- **Saplingと統合アドレスを混同すること** — Saplingアドレスは`zs`で始まります。統合アドレスは`u1`で始まり、複数の受信者をまとめるため、支払いが入るプールは、そのアドレスが持つ受信者に依存します。
- **Sproutプールに資金を残すこと** — Sproutは何年も前から非推奨です。これらの資金を移動してください。
- **移行が完全に見えなくなると期待すること** — 送信者と受信者は見えなくても、ターンスタイルを通過する金額は公開されます。
- **t → z（シールディング）が完全にプライベートだと考えること** — シールディング行為自体はオンチェーンで可視です。内容は可視ではありません。
