# Zcashのバリュープール

## 要点

- Zcashには現在、**4つのバリュープール**があります: Sprout（レガシー）、Sapling、Orchard、Transparent。
- **Orchard** は、Unified Address（u1...）で使われる現在の主要なシールドプールです。
- **Sapling**（`zs` で始まるzアドレス）は今も広くサポートされており、かなりの量のシールドされたZECを引き続き保護しています。
- **Transparent** アドレス（t...）には取引プライバシーがなく、Bitcoinと同様に動作します。
- **Sprout** は、アクティブな利用から退いたレガシーなシールドプールです。
- **Ironwood** として知られる将来のシールドプールが提案されており、プライバシーを維持しつつ、シールドされたZEC供給の完全性に対する信頼を強化することが期待されています。
- 最も強力なプライバシー保護を得るには、可能な限り **shielded-to-shielded（z → z）** 取引を引き続き優先すべきです。


<br/>

## Zcashのバリュープールを理解する

Zcashは資金を、バリュープールと呼ばれる個別の会計システムに分けています。各プールはそれぞれ独自の暗号学的ルールとプライバシー特性を持ち、プロトコルはそれらの間を移動する総価値を追跡します。

現在、ネットワークには4つの主要なバリュープールがあります:

- Transparent — 公開されており、オンチェーンで完全に可視です。
- Sapling — 最初に広く採用された近代的なシールドプールです。
- Orchard — Unified Addressとともに導入された、現在の主要なシールドプールです。
- Sprout — 2016年のZcash開始時にローンチされた、最初のシールドプールです。
  


Zcashの進化に伴い、既存の資金との互換性を維持しながら、セキュリティ、プライバシー、使いやすさ、監査可能性を向上させるために、新しいシールドプールが導入される可能性があります。

## シールドプール


1. <h3 id="orchard" class="text-3xl font-bold my-4">Orchardプール</h3>


![img2](/content-images/a672e001-6dbc-4e76-ab31-0ed7d7d2ff72-93b5a23e5d.webp)
図2: 2025年10月時点のOrchardプールを示すチャート

<br/>

Orchard Shielded Poolは、NU5ネットワークアップグレードの一部として2022年5月31日に有効化されました。Orchardは、trusted setupを不要にする新しいシールドプロトコルを導入し、Unified Address（UA）で使われる主要なシールドプールとなりました。

Orchardは、従来のシールド入力と出力ではなく、Actionに基づくより柔軟なトランザクションモデルを導入し、トランザクションのメタデータ漏えいを減らすことで、使いやすさ、効率性、プライバシーを大きく向上させました。

現在も、OrchardはZcashの主要なシールドプールです。しかしコミュニティでは、Ironwoodと呼ばれる新しいシールドプールへの将来的な移行が検討されており、これはZcashのプライバシー保証を維持しつつ、シールドされたZEC供給の完全性に関して追加の保証を提供するものです。

[Zcashのシールド対応ウォレット](/wallets) は現在Orchardをサポートしています。

____

2. <h3 id="sapling" class="text-3xl font-bold my-4">Saplingプール</h3>


![img3](/content-images/b1c6bb71-9356-45eb-8e4a-19d7cf1790ae-5e3051b082.webp)
図3: 2025年10月時点のSaplingプールを示すチャート

<br/>

[Zcash Sapling](https://z.cash/upgrade/sapling) は、2018年10月28日に導入されたZcashプロトコルのアップグレードです。これは、プライバシー、効率性、使いやすさの面でいくつかの制限があった、Sproutとして知られる以前のバージョンに対する大幅な改良です。 

アップグレード内容には、シールドアドレスのパフォーマンス向上、ユーザーの秘密鍵を公開することなく入出金トランザクションを閲覧できる改良版Viewing Key、そしてトランザクション署名時にハードウェアウォレット向けの独立したゼロ知識鍵を導入したことなどが含まれます。 

Zcash Saplingにより、ユーザーはSproutシリーズで必要だったより長い時間と比べて、わずか数秒でプライベートトランザクションを実行できるようになりました。 

トランザクションのシールド化はプライバシーを強化し、第三者がトランザクションを関連付けたり、送金されているZECの量を特定したりすることを不可能にします。Saplingはまた、プライベートトランザクション生成に必要な計算要件を下げることで使いやすさも改善し、より多くのユーザーが利用しやすくなりました。

Saplingウォレットアドレスは "zs" で始まり、これはSaplingアドレスを内蔵した、対応するすべてのZcashシールドウォレット（YWallet、Zingo Wallet、Nighthawkなど）で確認できます。Zcash Saplingは、プライバシーと取引効率の面で重要な技術的進歩を示しており、プライバシーと安全性を重視するユーザーにとって、Zcashを実用的かつ効果的な暗号資産にしています。

____

3. <h3 id="sprout" class="text-3xl font-bold my-4">Sproutプール</h3>


![img4](/content-images/956eceed-f4d6-4087-99d0-32a770449dda-a3cc45305e.webp)
図4: 2025年10月時点のSproutプールを示すチャート

Sproutは、これまでにローンチされた最初のオープンでパーミッションレスなゼロ知識プライバシープロトコルでした。2016年10月28日にローンチされました。

Sproutのアドレスは、最初の2文字が常に "zc" であることで識別されます。"Sprout" という名前は、このソフトウェアが若く芽吹いたばかりのブロックチェーンであり、大きく成長する可能性を持ち、開発に開かれていることを強調することを主な目的として付けられました。 

Sproutは、初期の [Zcash slow start Mining](https://electriccoin.co/blog/slow-start-and-mining-ecosystem/) の仕組みで使われ、ZECとマイナー向けブロック報酬の分配につながりました。 

シールドトランザクションの数が増え、Zcashエコシステムが拡大し続けるにつれて、Zcash Sproutシリーズは、ユーザーのプライバシー、トランザクションのスケーラビリティ、処理性能の面で制約があり、効率も低いことが判明しました。これがネットワークの改良とSaplingアップグレードにつながりました。

4. <h3 id="transparent" class="text-3xl font-bold my-4">Transparentプール</h3>
<br/>

![img5](/content-images/01de2907-b62d-4421-83d7-ea4908faa828-6f74b724ed.webp)
図5: 2025年10月時点のTransparentプールを示すチャート

<br/>

ZcashのTransparentプールは非シールドで、プライバシーがありません。ZcashのTransparentウォレットアドレスは "t" で始まり、この種類のアドレスを使った取引ではプライバシーは非常に低くなります。

ZcashのTransparentトランザクションはBitcoinのトランザクションに似ており、マルチシグトランザクションをサポートし、標準的な公開アドレスを使用します。

ZcashのTransparentは主に中央集権型取引所で使われており、ユーザー間でZECを送受信する際に高い透明性とネットワーク確認を確保できます。

また、Zcashのシールドアドレスは取引時に高いプライバシーを提供する一方で、トランザクション処理により多くの計算リソースを必要とする点にも注意が必要です。そのため、一部のユーザーは、同じレベルのプライバシーを必要としない取引ではTransparentアドレスを採用することがあります。

<br/>

## プール間転送の推奨プラクティス

Zcashネットワーク上で高いレベルのプライバシーを考慮して取引する場合、以下のプラクティスに従うことが推奨されます。

Zcashブロックチェーン上で "z から z" のウォレット間で行われるトランザクションは、ほとんどがシールドされており、高いレベルのプライバシーが得られることから、プライベートトランザクションと呼ばれることもあります。これは通常、プライバシーが必要なときに$ZECを送受信するための最良かつ最も推奨される方法です。 

---

"Z-address" から "T-address" にZECを送る場合、それは単にデシールディング取引を意味します。この種のトランザクションでは、Transparent AddressにZECを送る影響により、一部の情報がブロックチェーン上で可視になるため、プライバシーレベルは必ずしも高くありません。高いプライバシーが必要な場合、デシールディング取引は常に推奨されるわけではありません。 

---

Transparent Address（T-address）からZ-addressへZECを転送することは、単にシールディングとして知られています。この種のトランザクションでは、z-zトランザクションと比較するとプライバシーレベルは必ずしも高くありませんが、プライバシーが必要な場合にはこれも推奨されます。 

---

Zcashネットワーク上でTransparent Address（T-address）から別のTransparent Address（T-address）へZECを送ること（T-Tトランザクション）は、Bitcoinのトランザクションと非常によく似ています。このため、Zcash上のT-Tトランザクションは常にパブリックトランザクションと呼ばれます。というのも、送信者と受信者のトランザクション詳細の両方が公開されてしまい、この種のトランザクションではプライバシーレベルが非常に低くなるからです。 

多くの暗号資産の中央集権型取引所は、Zcashブロックチェーン上で取引を行う際にTransparent Address（"T-address"）を使用していますが、この種のトランザクション（T-T）にはプライベートな特性はありません。

<br/>

## 将来: Ironwoodプール

Zcashコミュニティは現在、Ironwoodと呼ばれる提案中のシールドプールを評価しています。

Ironwoodは、最近発見されて修正されたOrchardの証明システムの脆弱性に対処するために設計されています。この脆弱性が実際に悪用された証拠はありませんが、Ironwoodは、Orchardから新たに作成されたシールドプールへの制御された移行を可能にすることで、追加の保証レイヤーを提供します。

目的はZcashのプライバシーを置き換えることではなく、シールドされたZEC供給の完全性に対する信頼を強化することです。

## 提案の内容:

1. 新しいシールド活動は徐々にIronwoodへ移行します。
2. 既存のOrchard資金はプライベートに移行できます。
3. パブリックなターンスタイル会計により、すべてのシールド資金が完全に裏付けられていることを示す、より強力な証拠が提供されます。
4. ユーザーは、Zcashに期待するのと同じプライバシー保護を引き続き利用できます。

<br/>
将来のネットワークアップグレードを通じて有効化された場合、Ironwoodは既存のシールド資金との互換性を維持しながら、Zcashのシールドエコシステムの次世代となるでしょう。

<br/>

## 避けるべきよくあるミス

- **t-addressからt-addressへ送金すること** — 完全に公開され、プライバシーはありません。必ず先に資金をシールドしましょう。
- **SaplingアドレスとOrchardアドレスを混同すること** — Saplingアドレスは `zs` で始まり、Orchard/Unifiedアドレスは `u1` で始まります
- **資金をSproutプールに残したままにすること** — Sproutは非推奨です。資金をOrchardへ移行しましょう
- **t → z（シールディング）が完全にプライベートだと思い込むこと** — シールディングという行為自体はオンチェーンで可視ですが、中身は見えません
