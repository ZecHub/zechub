# トランザクション

ZECは支払いに広く利用されているデジタル資産であり、友人への支払い、買い物、寄付など、さまざまな取引に適した強力なプライバシー機能を備えています。プライバシーとセキュリティを最大限に高めるには、Zcash内で異なる種類のトランザクションがどのように機能するかを理解することが不可欠です。

## TL;DR

- Zcashは2種類のトランザクションに対応しています。詳細を非公開にする**シールド**トランザクションと、詳細を公開記録する**トランスペアレント**トランザクションです。
- シールドアドレスは`u`または`z`で始まります。トランスペアレントアドレスは`t`で始まり、Bitcoinアドレスとよく似た動作をします。
- 選択は支払いごとにあなた自身が行います。プライバシーは、他者が決める設定ではなく、Zcashがあなたに提供する選択肢です。
- 取引所からの出金は、プライバシーが失われやすい最も一般的な場面です。取引所がトランスペアレント出金しか対応していない場合は、資金の到着後に自身でシールドしてください。
- 手数料は[ZIP 317](https://zips.z.cash/zip-0317)に従い、トランザクションのサイズに応じて増加します。古い固定手数料を送信し続けるウォレットでは、トランザクションが遅延する可能性があります。
- ほとんどのZcashトランザクションには、[ZIP 203](https://zips.z.cash/zip-0203)に基づく有効期限ブロック高があります。採掘前にトランザクションが期限切れになると、その有効期限ブロック高以降に承認されることはなく、再送が必要になる場合があります。

シールドトランザクションは、ZECをシールドウォレットに移動する際に発生します。シールドウォレットのアドレスは`u`または`z`で始まります。シールドトランザクションを送信すると、あなたと取引相手は、デフォルトで公開されている決済ネットワークでは実現できない水準のプライバシーを維持できます。

シールドトランザクションの送信は、現在のZcashネットワークと現在のシールドプールに対応したウォレットを使用するのが最も簡単です。プライバシーのためにウォレットを利用する前に、シールド送信、シールド受信、および使用予定のプールに対応しているか確認してください。取引所からZECを出金する際は、その取引所がシールド出金またはトランスペアレント出金に対応しているか確認してください。トランスペアレント出金にしか対応していない場合は、資金到着後にシールド対応ウォレットへ移動してください。

資金の送受信にシールドトランザクションを使うことは、プライバシーを維持し、支払いデータが漏洩するリスクを減らす最良の方法です。

## トランスペアレントトランザクション

トランスペアレントトランザクションはBitcoinトランザクションと同様に機能します。トランスペアレントアドレスやトランスペアレントな金額を含むトランザクションの詳細は、ブロックチェーン上で公開されます。プライバシーを重視する場合は、トランスペアレントトランザクションを避けるべきです。

特に取引所やサービスがシールドアドレスに対応していない場合、トランスペアレントアドレスは依然として役立ちます。トランスペアレントアドレスでZECを受け取った場合は、その後の支払いを行う前にシールドすることを検討してください。

## シンプルなイメージ

トランスペアレントトランザクションは、はがきのようなものです。配達員はそれを届けますが、途中で扱う誰もがメッセージを読み、送信者と受信者を確認できます。

シールドトランザクションは、封をした封筒のようなものです。郵便サービスは、本物の郵便料金が貼られた実在の手紙がシステムを通過したことを確認でき、誰も偽造したり、同じ手紙を二度送ったりすることはできません。封筒の中身は、送信者と受信者の間だけに留まります。

重要なのは、Zcashでは支払いごとにどちらを送るか決められることです。

## Zcashの手数料

ZcashはEthereum形式のガス単位を使用しません。Zcashのトランザクション手数料はZECで支払われ、通常は**zatoshi**単位で計測されます。1 ZECは100,000,000 zatoshiに相当します。

[ZIP 317](https://zips.z.cash/zip-0317)は、トランザクションの複雑さに応じて変動する標準的な手数料メカニズムを定義しています。すべてのトランザクションで従来の1,000 zatoshiの固定手数料を使用するのではなく、標準手数料は入力、出力、シールドアクションなどの「論理アクション」に基づきます。単純なトランザクションは通常10,000 zatoshi、すなわち0.0001 ZEC程度から始まり、より複雑なトランザクションではさらに多く必要になる場合があります。

現在のほとんどのウォレットでは、ユーザーがZIP 317の手数料を手動で計算する必要はありません。ウォレットが適切な手数料を自動的に選択するはずです。ウォレットが依然として古い固定手数料を使用している、またはZIP 317の標準手数料を大幅に下回る手数料を設定できる場合、トランザクションは遅延、優先度低下、一部ノードによる破棄、または信頼性の低いリレーにつながる可能性があります。

## 停滞したトランザクションのトラブルシューティング

Zcashトランザクションは、ウォレットに表示されたからといって確定したわけではありません。ブロックに採掘され、状況に応じて十分な承認を受けることで、通常の利用において確定します。取引所やサービスでは、ウォレットがデフォルトで表示するより多くの承認が必要な場合があります。

再送する前に、次の判断ツリーを使用してください。

1. **ウォレットにトランザクションIDが表示されていますか？**
   - いいえの場合、ウォレットはまだトランザクションを作成またはブロードキャストしていない可能性があります。同期状態、インターネット接続、ウォレットのバージョン、およびウォレットに表示されるエラーメッセージを確認してください。
   - はいの場合、トランザクションIDをコピーして続行してください。
2. **トランザクションはブロック内で承認されていますか？**
   - はいの場合、ウォレット、取引所、加盟店、またはサービスが必要とする回数の承認を待ってください。
   - いいえの場合、続行してください。
3. **トランザクションは有効期限ブロック高に達しましたか？**
   - いいえの場合、同じ支払いをまだ手動で再送しないでください。元のトランザクションが承認される可能性は残っています。
   - はいの場合、そのトランザクションはその有効期限ブロック高以降に採掘されることはありません。ウォレットで期限切れまたは失敗として表示される場合があり、新しいトランザクションを作成する必要があるかもしれません。
4. **トランザクションはあるサーバーやエクスプローラーには表示されるものの、別のものには表示されませんか？**
   - これはトランザクション失敗の証拠ではなく、ネットワーク上の可視性の問題として扱ってください。ノードごとにメンプールの表示が異なる場合があります。
   - 待つか、ウォレットを再同期するか、ウォレットが対応している場合は別の信頼できるサーバーに切り替えてください。
5. **トランザクションは承認済みと表示された後に消えましたか？**
   - 短期間のチェーン再編成により、トランザクションが最良チェーンから一時的に除外されることがあります。
   - さらにブロックが生成されるのを待ってください。トランザクションが戻った場合は、承認を待ち続けてください。戻らず、後に期限切れとなった場合は、新しいトランザクションを作成してください。
6. **ウォレットから再送を求められていますか？**
   - 前のトランザクションが期限切れ、失敗、または無効になったことを確認した後にのみ、ウォレットの現在の案内に従ってください。
   - 不明な場合は、再送する前にサポートへ問い合わせてください。

## 保留、期限切れ、破棄、再編成

- **保留中**は、トランザクションが作成またはブロードキャストされたものの、まだブロックに採掘されていないことを意味します。
- **期限切れ**は、トランザクションの有効期限ブロック高を過ぎたことを意味します。ZIP 203では、有効期限ブロック高を持つトランザクションは、そのブロック高以降に採掘できません。
- **破棄**は、1つ以上のノードがトランザクションをメンプールに保持しなくなったことを意味します。これは、期限切れ、低い手数料、メンプールポリシー、再起動時の挙動、またはリレーの違いによって発生する場合があります。
- **再編成済み**は、以前そのトランザクションを含んでいたブロックが、もはや最良チェーンの一部ではないことを意味します。トランザクションは後に再び採掘される可能性があり、有効である限り保留状態に戻ることもあります。

## 再送すべきでない場合

トランザクションが保留中、遅延中、または1つのエクスプローラーに表示されないというだけで、すぐに再送しないでください。早すぎる再送は混乱を招き、ウォレットが新しい支払いをどのように作成するかによっては、二重払いのリスクが生じる可能性があります。

次の場合は、まず待つかサポートを受けてください。

- トランザクションにトランザクションIDがあり、まだ期限切れではない。
- あるサーバーには表示されるが、別のサーバーには表示されない。
- 最近採掘されたが、再編成の可能性により承認を失った。
- 受信側のサービスがまだ承認数の確認を終えていない。
- ウォレットがまだ同期中である。

通常は、ウォレットがトランザクションを明確に期限切れまたは失敗と表示した後、またはサポートが元のトランザクションは承認されないと確認した後にのみ再送する方が安全です。

## プライバシーを保護した確認方法

必要以上の情報を公開せずに、基本的なトランザクション状態を確認できます。

- ウォレットが完全に同期されているか確認する。
- ウォレットアプリが最新か確認する。
- トランザクションにトランザクションIDがあるか確認する。
- トランザクションが承認済み、保留中、期限切れ、または失敗のどれかを確認する。
- ウォレットに表示される場合は、現在のブロック高を確認し、トランザクションの有効期限ブロック高と比較する。
- トランスペアレントトランザクションでは、ブロックエクスプローラーで公開トランザクション、アドレス、金額、承認数を確認できます。
- シールドトランザクションでは、ブロックエクスプローラーでトランザクションの存在は確認できますが、シールドされた送信者、受信者、金額、メモの詳細は確認できません。

## 公開してはいけない情報

公開チャット、ソーシャルメディア、または課題トラッカーに、次の情報を絶対に投稿しないでください。

- シードフレーズまたはリカバリーフレーズ
- 支払いキー、秘密鍵、またはウォレットバックアップ
- Full Viewing Key
- 残高、完全なアドレス、メモ、QRコード、または取引所アカウントの詳細を表示したスクリーンショット
- 本人確認書類またはアカウント復旧記録

トランザクションIDはチェーン上で公開されていますが、それでもサポートに関する質問をあなたの身元と結び付ける可能性があります。プライバシーが重要な場合は、信頼できるサポートチャネルとのみ共有してください。

## サポートチームが必要とする情報

ウォレット、取引所、またはサービスのサポートに問い合わせる際は、役立つ最小限の情報だけを共有してください。

- ウォレットまたはサービス名
- アプリのバージョンとオペレーティングシステム
- トランザクションがシールド、トランスペアレント、またはシールドアドレスとトランスペアレントアドレス間のものか
- 共有しても問題ない場合はトランザクションID
- おおよその送信時刻
- ウォレットが完全に同期されているか
- ウォレットに表示される現在の状態
- 秘密データを除去した正確なエラーメッセージ
- 残高、アドレス、メモ、アカウント詳細を隠したスクリーンショット

サポートチームにシードフレーズ、支払いキー、秘密鍵、またはFull Viewing Keyは必要ありません。

## よくある間違い

- **ZECを扱えると記載されているウォレットなら、どれでも非公開で送信できると思い込むこと。** 多くのマルチコインウォレットは、Zcashのトランスペアレント側にしか対応していません。プライバシー目的で利用する前に、ウォレットが対応するプールを確認してください。[ウォレット](https://zechub.wiki/using-zcash/wallets)ページには、各選択肢についてこれが記載されています。
- **トランスペアレントアドレスに出金し、そのまま資金を置いておくこと。** 出金自体が公開され、そのアドレスからの以後のすべての移動も公開されたままです。資金が到着したらシールドしてください。
- **プライバシーを一度有効にすれば済むものとして扱うこと。** 各トランザクションは個別の選択です。今日シールド送信しても、先週行ったトランスペアレントな支払いが取り消されるわけではありません。
- **すべてに同じトランスペアレントアドレスを再利用すること。** トランスペアレントな活動は恒久的に可視であるため、1つのアドレスを再利用すると、本来関連付ける理由のない支払いが徐々に結び付けられてしまいます。
- **古いデフォルト手数料で送信すること。** ZIP 317を採用していないウォレットでは、古い固定手数料を送信し続ける場合があり、トランザクションが未承認のままになる可能性があります。
- **期限切れ前に再送すること。** 保留中のトランザクションは、期限切れになるまで承認される可能性があります。別の支払いを作成する前に、有効期限の状態を確認してください。

## 注記

送信者、受信者、ウォレット、サービスのすべてが対応している場合、ZECを最も安全に利用する方法はシールドトランザクションを使用することです。一部のウォレットや取引所は、複数のZcash受信者タイプを1つのアドレスに統合できる[統合アドレス](https://electriccoin.co/blog/unified-addresses-in-zcash-explained/#:~:text=The%20unified%20address%20(UA)%20is,within%20the%20broader%20Zcash%20ecosystem.)に対応しています。
