# トランザクション

ZECは、支払いに広く利用されているデジタル資産であり、友人への支払いや購入、寄付など、さまざまなトランザクションに適した強力なプライバシー機能を備えています。プライバシーとセキュリティを最大限に高めるには、Zcash内で異なる種類のトランザクションがどのように機能するかを理解することが不可欠です。

## 要約

- Zcashは、詳細を非公開に保つ**シールドされた**トランザクションと、詳細を公開記録する**公開型**トランザクションという2種類のトランザクションをサポートしています。
- シールドされたアドレスは`u`または`z`で始まります。公開型アドレスは`t`で始まり、Bitcoinアドレスとよく似た動作をします。
- 支払いのたびに選択するのはあなたです。プライバシーは、他者があなたのために決める設定ではなく、Zcashが提供する選択肢です。
- 取引所からの出金は、プライバシーを失う最も一般的な場面です。取引所が公開型出金しかサポートしていない場合は、資金が到着した後に自分でシールドしてください。
- 手数料は[ZIP 317](https://zips.z.cash/zip-0317)に従い、トランザクションのサイズに応じて増加します。古い定額手数料を送信し続けるウォレットでは、トランザクションが遅延することがあります。
- ほとんどのZcashトランザクションには、[ZIP 203](https://zips.z.cash/zip-0203)に基づく有効期限ブロック高があります。トランザクションがマイニングされる前に期限切れとなった場合、その有効期限ブロック高以降に承認されることはなく、再送信が必要になる場合があります。

シールドされたトランザクションは、ZECをシールドされたウォレットに移動するときに発生します。シールドされたウォレットのアドレスは、`u`または`z`で始まります。シールドされたトランザクションを送信すると、あなたと取引相手は、デフォルトで公開される支払いネットワークでは実現できない水準のプライバシーを維持できます。

シールドされたトランザクションの送信は、現在のZcashネットワークと現在のシールドされたプールをサポートするウォレットを使用する場合に最も簡単です。プライバシーのためにウォレットを利用する前に、シールドされた送信、シールドされた受信、および使用予定のプールをサポートしているか確認してください。取引所からZECを出金する際は、取引所がシールドされた出金または公開型出金をサポートしているか確認してください。公開型出金しかサポートしていない場合は、資金が到着後、シールド機能を備えたウォレットへ移動してください。

資金の送受信にシールドされたトランザクションを使用することは、プライバシーを維持し、支払いデータ漏洩のリスクを減らす最善の方法です。

## 公開型トランザクション

公開型トランザクションはBitcoinトランザクションと同様に機能します。公開型アドレスおよび公開型金額を含むトランザクションの詳細は、ブロックチェーン上で公開されます。プライバシーを優先する場合は、公開型トランザクションを避けるべきです。

公開型アドレスは、特に取引所やサービスがシールドされたアドレスをサポートしていない場合など、一部の状況では依然として役立ちます。ZECを公開型アドレスで受け取った場合は、その後の支払いを行う前にシールドすることを検討してください。

## 簡単なイメージ

公開型トランザクションは葉書です。郵便配達員はそれを届けますが、途中で扱う人は誰でもメッセージを読め、誰が送ったか、誰が受け取るかを見ることができます。

シールドされたトランザクションは封をした封筒です。郵便サービスは、本物の郵便料金が貼られた本物の手紙がシステムを通過したことを確認でき、誰もそれを偽造したり、同じ手紙を2回送ったりすることはできません。封筒の中身は送信者と受取人だけのものです。

重要なのは、Zcashによって、支払いごとにどちらを送るかをあなたが決められることです。

## Zcashの手数料

ZcashはEthereum形式のガス単位を使用しません。Zcashのトランザクション手数料はZECで支払われ、通常は**zatoshi**で測定されます。1 ZECは100,000,000 zatoshiに相当します。

[ZIP 317](https://zips.z.cash/zip-0317)は、トランザクションの複雑さに応じて変動する標準的な手数料メカニズムを定義しています。すべてのトランザクションが従来の1,000-zatoshiの定額手数料を使用する代わりに、標準手数料は入力、出力、シールドされたアクションなどの「論理アクション」に基づきます。単純なトランザクションは通常10,000 zatoshi、つまり0.0001 ZEC程度から始まり、より複雑なトランザクションではさらに多く必要になることがあります。

現在のほとんどのウォレットでは、ユーザーがZIP 317の手数料を手動で計算する必要はありません。ウォレットが適切な手数料を自動的に選択するはずです。ウォレットが従来の定額手数料を使用し続けている、またはZIP 317の標準手数料を大幅に下回る手数料を設定できる場合、トランザクションが遅延したり、優先度が下げられたり、一部のノードによって破棄されたり、確実にリレーされなかったりする可能性があります。

## 停滞したトランザクションのトラブルシューティング

Zcashのトランザクションは、ウォレットに表示されただけでは確定しません。ブロックにマイニングされ、状況に応じて十分な承認を受けた後、通常の利用において確定します。取引所やサービスでは、ウォレットがデフォルトで表示するより多くの承認が必要な場合があります。

再送信する前に、次の判断ツリーを使用してください。

1. **ウォレットにトランザクションIDが表示されていますか？**
   - いいえの場合、ウォレットはまだトランザクションを作成またはブロードキャストしていない可能性があります。同期状況、インターネット接続、ウォレットのバージョン、およびウォレットのエラーメッセージを確認してください。
   - はいの場合、トランザクションIDをコピーして続行してください。
2. **トランザクションはブロック内で承認されていますか？**
   - はいの場合、ウォレット、取引所、加盟店、またはサービスが必要とする承認数に達するまで待ってください。
   - いいえの場合、続行してください。
3. **トランザクションは有効期限ブロック高に到達しましたか？**
   - いいえの場合、まだ同じ支払いを手動で再送信しないでください。元のトランザクションが承認される可能性があります。
   - はいの場合、そのトランザクションは有効期限ブロック高以降にマイニングできません。ウォレットが期限切れまたは失敗として表示する場合があり、新しいトランザクションを作成する必要があるかもしれません。
4. **トランザクションは1つのサーバーまたはエクスプローラーには表示されるものの、別のものには表示されませんか？**
   - これはトランザクションが失敗した証拠ではなく、ネットワーク上の可視性の問題として扱ってください。ノードによってメモリプールの表示が異なる場合があります。
   - 待機するか、ウォレットを再同期するか、ウォレットが対応している場合は別の信頼できるサーバーに切り替えてください。
5. **トランザクションは承認済みとして表示された後に消えましたか？**
   - 短期間のチェーン再編成により、トランザクションが最良のチェーンから一時的に削除されることがあります。
   - さらにブロックが追加されるまで待ってください。トランザクションが戻った場合は、承認を待ち続けてください。戻らず、後に期限切れとなった場合は、新しいトランザクションを作成してください。
6. **ウォレットから再送信するよう求められていますか？**
   - 以前のトランザクションが期限切れ、失敗、または無効であることを確認した後にのみ、ウォレットの現在の案内に従ってください。
   - 確信が持てない場合は、再送信する前にサポートへ問い合わせてください。

## 保留中、期限切れ、破棄済み、再編成済み

- **保留中**とは、トランザクションが作成またはブロードキャストされたものの、まだブロックにマイニングされていないことを意味します。
- **期限切れ**とは、トランザクションの有効期限ブロック高を過ぎたことを意味します。ZIP 203では、有効期限ブロック高を持つトランザクションは、そのブロック高以降にマイニングできません。
- **破棄済み**とは、1つ以上のノードがトランザクションをメモリプールに保持しなくなったことを意味します。これは、有効期限切れ、低い手数料、メモリプールのポリシー、再起動時の挙動、またはリレーの違いによって発生することがあります。
- **再編成済み**とは、以前トランザクションを含んでいたブロックが、最良のチェーンの一部ではなくなったことを意味します。トランザクションは後で再びマイニングされる場合があり、依然として有効であれば保留中に戻る場合もあります。

## 再送信しない場合

トランザクションが保留中、遅延中、または1つのエクスプローラーに表示されないというだけで、すぐに再送信しないでください。早すぎる再送信は混乱を招く可能性があり、ウォレットが新しい支払いを構築する方法によっては、二重に支払うリスクがあります。

次の場合は、まず待つかサポートに問い合わせてください。

- トランザクションにトランザクションIDがあり、まだ期限切れではない場合。
- あるサーバーには表示されるものの、別のサーバーには表示されない場合。
- 最近マイニングされたものの、再編成の可能性の後に承認を失った場合。
- 受取サービスがまだ承認のカウントを完了していない場合。
- ウォレットがまだ同期中の場合。

通常は、ウォレットがトランザクションを明確に期限切れまたは失敗として表示した後、または元のトランザクションが承認されないことをサポートが確認した後にのみ、再送信する方が安全です。

## プライバシーを守る確認

必要以上の情報を公開せずに、基本的なトランザクションの状況を確認できます。

- ウォレットが完全に同期されているか確認してください。
- ウォレットアプリが最新か確認してください。
- トランザクションにトランザクションIDがあるか確認してください。
- トランザクションが承認済み、保留中、期限切れ、または失敗のいずれかを確認してください。
- ウォレットに表示される場合は、現在のブロック高を確認し、トランザクションの有効期限ブロック高と比較してください。
- 公開型トランザクションでは、ブロックエクスプローラーで公開トランザクション、アドレス、金額、および承認を確認できます。
- シールドされたトランザクションでは、ブロックエクスプローラーでトランザクションの存在を確認できますが、シールドされた送信者、受取人、金額、またはメモの詳細は確認できません。

## 公開してはいけない情報

以下の情報を公開チャット、ソーシャルメディア、または課題トラッカーに投稿しないでください。

- シードフレーズまたは復元フレーズ
- 支出鍵、秘密鍵、またはウォレットのバックアップ
- Full Viewing Key
- 残高、完全なアドレス、メモ、QRコード、または取引所アカウントの詳細が表示されたスクリーンショット
- 個人の身分証明書またはアカウント復元記録

トランザクションIDはチェーン上で公開されていますが、サポートに関する質問をあなたの身元に結び付ける可能性があります。プライバシーが重要な場合は、信頼できるサポートチャネルにのみ共有してください。

## サポートチームに必要な情報

ウォレット、取引所、またはサービスのサポートに支援を求める際は、役立つ最小限の情報だけを共有してください。

- ウォレットまたはサービス名
- アプリのバージョンとオペレーティングシステム
- トランザクションがシールドされたもの、公開型のもの、またはシールドされたアドレスと公開型アドレス間のものかどうか
- 共有しても問題ない場合はトランザクションID
- おおよその送信時刻
- ウォレットが完全に同期されているかどうか
- ウォレットに表示されている現在のステータス
- 秘密情報を削除した正確なエラーメッセージ
- 残高、アドレス、メモ、およびアカウント詳細を隠したスクリーンショット

サポートチームにシードフレーズ、支出鍵、秘密鍵、または完全なビューイングキーは必要ありません。

## よくある間違い

- **ZECを掲載するウォレットなら、どれでも非公開で送信できると思い込むこと。** 多数のマルチコインウォレットは、Zcashの公開型側のみをサポートしています。プライバシーのために利用する前に、ウォレットがサポートするプールを確認してください。[Wallets](https://zechub.wiki/using-zcash/wallets)ページには、各選択肢についてこれが記載されています。
- **公開型アドレスへ出金し、そこに資金を残しておくこと。** 出金自体が公開され、そのアドレスからのその後のすべての移動も公開されたままです。資金が到着したらシールドしてください。
- **プライバシーを一度有効にすればよいものとして扱うこと。** 各トランザクションは個別の選択です。今日シールドして送信しても、先週行った公開型の支払いが取り消されることはありません。
- **すべてに同じ公開型アドレスを再利用すること。** 公開型の活動は恒久的に表示されるため、再利用された1つのアドレスにより、本来関連付ける理由のない支払いが徐々に結び付けられます。
- **古いデフォルト手数料で送信すること。** ZIP 317を採用していないウォレットでは、古い定額手数料を送信することがあり、トランザクションが未承認のままになる可能性があります。
- **期限切れ前に再送信すること。** 保留中のトランザクションは、期限切れまで承認される可能性があります。別の支払いを作成する前に、有効期限の状態を確認してください。

## 注記

ZECを使用する最も安全な方法は、送信者、受取人、ウォレット、およびサービスのすべてが対応している場合に、シールドされたトランザクションを使用することです。一部のウォレットおよび取引所は、複数のZcash受取タイプを1つのアドレスに組み合わせられる[unified addresses](https://web.archive.org/web/20260823012524/https://electriccoin.co/blog/unified-addresses-in-zcash-explained/#:~:text=The%20unified%20address%20(UA)%20is,within%20the%20broader%20Zcash%20ecosystem.)をサポートしています。
