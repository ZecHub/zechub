# トランザクション

ZECは支払いに広く利用されているデジタル資産であり、友人への支払い、購入、寄付など、さまざまな取引に適した強力なプライバシー機能を提供します。プライバシーとセキュリティを最大限に確保するには、Zcash内で異なる種類のトランザクションがどのように機能するかを理解することが不可欠です。

## TL;DR

- Zcashは2種類のトランザクションをサポートしています。詳細を非公開に保つ**シールド**トランザクションと、詳細を公開記録する**トランスペアレント**トランザクションです。
- シールドアドレスは`u`または`z`で始まります。トランスペアレントアドレスは`t`で始まり、Bitcoinアドレスとよく似た挙動をします。
- 支払いごとに選択するのはあなたです。プライバシーは、他者があなたのために決める設定ではなく、Zcashがあなたに提供する選択肢です。
- 取引所からの出金は、最もよくプライバシーが失われる場面です。取引所がトランスペアレント出金のみをサポートしている場合、資金の到着後に自分でシールドしてください。
- 手数料は[ZIP 317](https://zips.z.cash/zip-0317)に従い、トランザクションのサイズに応じて増加します。旧来の固定手数料を送信しているウォレットでは、トランザクションが遅延する可能性があります。
- ほとんどのZcashトランザクションには、[ZIP 203](https://zips.z.cash/zip-0203)に基づく有効期限ブロック高があります。トランザクションが採掘される前に期限切れとなった場合、その有効期限ブロック高以降に承認されることはなく、再送信が必要になる場合があります。

シールドトランザクションは、ZECをシールドウォレットへ移動する際に発生します。シールドウォレットのアドレスは`u`または`z`で始まります。シールドトランザクションを送信すると、あなたと取引相手は、デフォルトで公開される決済ネットワークでは実現できない水準のプライバシーを維持できます。

シールドトランザクションの送信は、現在のZcashネットワークおよび現在のシールドプールをサポートするウォレットを使用するのが最も簡単です。プライバシーのためにウォレットを利用する前に、シールド送信、シールド受信、および使用予定のプールをサポートしているか確認してください。取引所からZECを出金する際は、その取引所がシールド出金またはトランスペアレント出金をサポートしているか確認してください。トランスペアレント出金しか対応していない場合は、資金の到着後にシールド対応ウォレットへ移してください。

シールドトランザクションで資金を送受信することは、プライバシーを維持し、支払いデータ漏えいのリスクを低減する最善の方法です。

## トランスペアレントトランザクション

トランスペアレントトランザクションはBitcoinトランザクションと同様に機能します。トランスペアレントアドレスやトランスペアレント残高を含むトランザクションの詳細は、ブロックチェーン上で公開されます。プライバシーを優先する場合、トランスペアレントトランザクションは避けるべきです。

トランスペアレントアドレスは、特に取引所やサービスがシールドアドレスをサポートしていない場合など、状況によっては依然として有用です。トランスペアレントアドレスでZECを受け取った場合、その後の支払いを行う前にシールドすることを検討してください。

## 簡単にイメージする方法

トランスペアレントトランザクションは、絵葉書のようなものです。配達員はそれを届けますが、途中で扱う人は誰でもメッセージを読め、誰が送ったか、誰が受け取るかを確認できます。

シールドトランザクションは、封をした封筒のようなものです。郵便サービスは、本物の切手が貼られた本物の手紙がシステムを通過したことを確認できます。また、誰も偽造したり、同じ手紙を二度送ったりできません。封筒の中身は送信者と受信者の間だけに留まります。

重要なのは、Zcashでは支払いごとに、どちらを送るかをあなた自身が決められることです。

## Zcashの手数料

ZcashはEthereum形式のガス単位を使用しません。Zcashのトランザクション手数料はZECで支払われ、通常は**zatoshi**で測定されます。1 ZECは100,000,000 zatoshiです。

[ZIP 317](https://zips.z.cash/zip-0317)は、トランザクションの複雑さに応じて変動する標準的な手数料メカニズムを定義しています。すべてのトランザクションで旧来の1,000 zatoshi固定手数料を使用するのではなく、標準手数料は入力、出力、シールドアクションなどの「論理アクション」に基づきます。単純なトランザクションは一般に10,000 zatoshi、すなわち0.0001 ZEC程度から始まり、より複雑なトランザクションではさらに多く必要になる場合があります。

現在のほとんどのウォレットでは、ユーザーがZIP 317の手数料を手動で計算する必要はありません。ウォレットが適切な手数料を自動的に選択するはずです。ウォレットが依然として旧来の固定手数料を使用している場合や、ZIP 317の標準手数料を大幅に下回る手数料を設定できる場合、そのトランザクションは遅延したり、優先順位を下げられたり、一部のノードによって破棄されたり、確実に中継されなかったりする可能性があります。

## 滞留中のトランザクションのトラブルシューティング

Zcashトランザクションは、ウォレットに表示されたからといって確定しているわけではありません。ブロックに採掘され、用途に応じて十分な承認を受けると、通常の利用において確定します。取引所やサービスでは、ウォレットがデフォルトで表示するより多くの承認が必要な場合があります。

再送信する前に、次の判断ツリーを使用してください。

1. **ウォレットにトランザクションIDが表示されていますか？**
   - いいえの場合、ウォレットがまだトランザクションを作成またはブロードキャストしていない可能性があります。同期状態、インターネット接続、ウォレットのバージョン、およびウォレットのエラーメッセージを確認してください。
   - はいの場合、トランザクションIDをコピーして続行してください。
2. **トランザクションはブロックで承認されていますか？**
   - はいの場合、ウォレット、取引所、加盟店、またはサービスが必要とする回数の承認を待ってください。
   - いいえの場合、続行してください。
3. **トランザクションは有効期限ブロック高に達していますか？**
   - いいえの場合、同じ支払いをまだ手動で再送信しないでください。元のトランザクションが承認される可能性はまだあります。
   - はいの場合、そのトランザクションはその有効期限ブロック高以降に採掘できません。ウォレットでは期限切れまたは失敗として表示されることがあり、新しいトランザクションの作成が必要になる場合があります。
4. **トランザクションは一方のサーバーまたはエクスプローラーには表示されるものの、他方には表示されませんか？**
   - これはトランザクション失敗の証拠ではなく、ネットワーク上の可視性の問題として扱ってください。異なるノードでは、mempoolの表示が異なる場合があります。
   - 待機するか、ウォレットを再同期するか、ウォレットが対応している場合は別の信頼できるサーバーに切り替えてください。
5. **トランザクションは承認済みとして表示された後に消えましたか？**
   - 短期間のチェーン再編成により、最良チェーンから一時的にトランザクションが除外される場合があります。
   - さらにブロックが追加されるのを待ってください。トランザクションが戻った場合は、引き続き承認を待ってください。戻らず、その後期限切れになった場合は、新しいトランザクションを作成してください。
6. **ウォレットから再送信を求められていますか？**
   - 前のトランザクションが期限切れ、失敗、または無効になったことを確認してから、ウォレットの最新の案内に従ってください。
   - 不明な場合は、再送信する前にサポートへ問い合わせてください。

## 保留、期限切れ、破棄、再編成

- **保留中**は、トランザクションが作成またはブロードキャストされたものの、まだブロックに採掘されていないことを意味します。
- **期限切れ**は、トランザクションの有効期限ブロック高を過ぎたことを意味します。ZIP 203では、有効期限ブロック高を持つトランザクションは、そのブロック高以降に採掘できません。
- **破棄**は、1つ以上のノードがトランザクションをmempoolに保持しなくなったことを意味します。これは、期限切れ、低い手数料、mempoolポリシー、再起動時の挙動、または中継の違いによって発生することがあります。
- **再編成**は、以前そのトランザクションを含んでいたブロックが最良チェーンの一部ではなくなったことを意味します。トランザクションは後で再び採掘される場合があり、まだ有効であれば保留中に戻る場合もあります。

## 再送信すべきでない場合

トランザクションが保留中、遅い、またはあるエクスプローラーに表示されないという理由だけで、すぐに再送信しないでください。早すぎる再送信は混乱を招く可能性があり、ウォレットが新しい支払いをどのように構築するかによっては、二重払いのリスクが生じる可能性があります。

次の場合は、まず待つかサポートに問い合わせてください。

- トランザクションIDがあり、まだ期限切れになっていない。
- あるサーバーには表示されるが、別のサーバーには表示されない。
- 最近採掘されたものの、再編成の可能性の後に承認数が失われた。
- 受信サービスがまだ承認数のカウントを完了していない。
- ウォレットがまだ同期中である。

通常は、ウォレットがトランザクションを明確に期限切れまたは失敗と表示した後、またはサポートが元のトランザクションは承認できないと確認した後にのみ、再送信する方が安全です。

## プライバシーを保護した確認方法

必要以上の情報を公開せずに、基本的なトランザクションの状態を確認できます。

- ウォレットが完全に同期しているか確認してください。
- ウォレットアプリが最新か確認してください。
- トランザクションにトランザクションIDがあるか確認してください。
- トランザクションが承認済み、保留中、期限切れ、または失敗のどれであるか確認してください。
- ウォレットに表示される場合は、現在のブロック高を確認し、トランザクションの有効期限ブロック高と比較してください。
- トランスペアレントトランザクションでは、ブロックエクスプローラーで公開トランザクション、アドレス、金額、承認数を確認できます。
- シールドトランザクションでは、ブロックエクスプローラーでトランザクションの存在を確認できますが、シールドされた送信者、受信者、金額、またはメモの詳細は確認できません。

## 公開してはいけない情報

次の情報は、公開チャット、ソーシャルメディア、または課題トラッカーに絶対に投稿しないでください。

- シードフレーズまたはリカバリーフレーズ
- 支払いキー、秘密鍵、またはウォレットバックアップ
- Full Viewing Key
- 残高、完全なアドレス、メモ、QRコード、または取引所アカウントの詳細を表示したスクリーンショット
- 個人の本人確認書類またはアカウント復旧記録

トランザクションIDはチェーン上で公開されていますが、サポートへの問い合わせとあなたの身元を結び付ける可能性があります。プライバシーが重要な場合は、信頼できるサポートチャネルとのみ共有してください。

## サポートチームが必要とする情報

ウォレット、取引所、またはサービスのサポートに支援を依頼する場合は、有用な最小限の情報のみを共有してください。

- ウォレットまたはサービスの名称
- アプリのバージョンとオペレーティングシステム
- トランザクションがシールド、トランスペアレント、またはシールドアドレスとトランスペアレントアドレス間のものか
- 共有しても問題なければトランザクションID
- おおよその送信時刻
- ウォレットが完全に同期しているか
- ウォレットに表示される現在の状態
- 秘密情報を削除した正確なエラーメッセージ
- 残高、アドレス、メモ、アカウントの詳細を隠したスクリーンショット

サポートチームにシードフレーズ、支払いキー、秘密鍵、またはFull Viewing Keyは必要ありません。

## よくある間違い

- **ZECを扱うと記載されたあらゆるウォレットが、非公開で送信できると考えること。** 複数通貨対応ウォレットの中には、Zcashのトランスペアレント側のみをサポートするものがあります。プライバシー目的で利用する前に、ウォレットがサポートするプールを確認してください。[ウォレット](https://zechub.wiki/using-zcash/wallets)ページには、各選択肢についてこれが記載されています。
- **トランスペアレントアドレスに出金し、資金をそのまま置いておくこと。** 出金自体が公開され、そのアドレスからの以後のすべての移動も公開されたままです。資金が到着したらシールドしてください。
- **プライバシーを一度有効にすれば済むものとして扱うこと。** 各トランザクションは個別の選択です。今日シールド送信しても、先週行ったトランスペアレントな支払いを取り消すことはできません。
- **すべてに同じトランスペアレントアドレスを再利用すること。** トランスペアレントな活動は恒久的に可視であるため、再利用する1つのアドレスは、結び付ける理由のなかった支払いを徐々に関連付けてしまいます。
- **古いデフォルト手数料で送信すること。** ZIP 317を採用していないウォレットでは、旧来の固定手数料が送信される場合があり、トランザクションが未承認のまま滞留する可能性があります。
- **期限切れ前に再送信すること。** 保留中のトランザクションは、期限切れになるまで承認される可能性があります。別の支払いを作成する前に、有効期限の状態を確認してください。

## 注記

ZECを使用する最も安全な方法は、送信者、受信者、ウォレット、およびサービスのすべてが対応している場合に、常にシールドトランザクションを使用することです。一部のウォレットおよび取引所は、複数のZcash受信者タイプを1つのアドレスにまとめられる[Unified Address](https://electriccoin.co/blog/unified-addresses-in-zcash-explained/#:~:text=The%20unified%20address%20(UA)%20is,within%20the%20broader%20Zcash%20ecosystem.)をサポートしています。
