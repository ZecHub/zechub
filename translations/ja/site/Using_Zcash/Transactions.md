# トランザクション

ZEC は支払いに広く使われているデジタル資産であり、強力なプライバシー機能を備えているため、友人への支払い、買い物、寄付など、さまざまな取引に適しています。プライバシーとセキュリティを最大限に高めるには、Zcash における異なる種類のトランザクションがどのように機能するのかを理解することが重要です。

## 要点

- Zcash は 2 種類のトランザクションをサポートしています。**shielded** は詳細を非公開に保ち、**transparent** はそれを公開記録します。
- Shielded アドレスは `u` または `z` で始まります。Transparent アドレスは `t` で始まり、Bitcoin アドレスによく似た動作をします。
- どの支払いでも選ぶのはあなた自身です。プライバシーは、他人があなたの代わりに決める設定ではなく、Zcash があなたに与える選択肢です。
- 取引所からの出金は、人々が最もプライバシーを失いやすい場面です。取引所が transparent 出金しかサポートしていない場合は、着金後に自分で資金を shield してください。
- 手数料は [ZIP 317](https://zips.z.cash/zip-0317) に従い、トランザクションのサイズに応じて増加します。古い固定手数料をまだ送っているウォレットでは、トランザクションが遅延することがあります。
- ほとんどの Zcash トランザクションには、[ZIP 203](https://zips.z.cash/zip-0203) に基づく有効期限ブロック高があります。トランザクションがマイニングされる前に期限切れになると、その期限ブロック高を過ぎてから承認されることはなく、再送が必要になる場合があります。

Shielded トランザクションは、ZEC をあなたの shielded ウォレットに移動するときに発生します。あなたの shielded ウォレットアドレスは `u` または `z` で始まります。Shielded トランザクションを送信すると、あなたと取引相手は、デフォルトで公開される支払いネットワークでは不可能なレベルのプライバシーを維持できます。

Shielded トランザクションの送信は、現在の Zcash ネットワークと現在の shielded プールをサポートするウォレットを使うのが最も簡単です。プライバシー目的でウォレットに依存する前に、それが shielded 送信、shielded 受信、そして使用予定のプールをサポートしているか確認してください。取引所から ZEC を出金する際は、その取引所が shielded 出金と transparent 出金のどちらをサポートしているかを確認してください。transparent 出金しかサポートしていない場合は、着金後に shielded 対応ウォレットへ資金を移動してください。

資金の送受信に shielded トランザクションを使うことは、プライバシーを維持し、支払いデータの漏えいリスクを減らす最善の方法です。

## Transparent トランザクション

Transparent トランザクションは Bitcoin のトランザクションと似た仕組みで動作します。transparent アドレスや transparent な金額を含む取引の詳細は、ブロックチェーン上で公開されます。プライバシーを重視する場合、transparent トランザクションは避けるべきです。

Transparent アドレスは、特に取引所やサービスが shielded アドレスをサポートしていない場合など、一部の状況では依然として有用です。transparent アドレスで ZEC を受け取った場合は、後の支払いを行う前に shield することを検討してください。

## シンプルなイメージ

Transparent トランザクションは、はがきのようなものです。配達員はそれを届けますが、途中で扱う人は誰でも、そのメッセージを読み、誰が送ったのか、誰が受け取るのかを見ることができます。

Shielded トランザクションは、封をした封筒のようなものです。郵便サービスは、本物の切手が貼られた本物の手紙がシステムを通過したことを確認できますし、誰もそれを偽造したり、同じ手紙を二度送ったりすることはできません。封筒の中身は、送信者と受信者の間だけにとどまります。

重要なのは、Zcash では支払いごとにどちらを送るかを自分で決められるという点です。

## Zcash の手数料

Zcash は Ethereum のようなガス単位を使用しません。Zcash のトランザクション手数料は ZEC で支払われ、通常は **zatoshis** で測られます。1 ZEC は 100,000,000 zatoshis に相当します。

[ZIP 317](https://zips.z.cash/zip-0317) は、トランザクションの複雑さに応じて変動する慣例的な手数料の仕組みを定義しています。すべてのトランザクションが従来の 1,000 zatoshi 固定手数料を使うのではなく、この慣例的手数料は、入力、出力、shielded アクションなどの「論理的アクション」に基づきます。シンプルなトランザクションは一般に 10,000 zatoshis、つまり 0.0001 ZEC 前後から始まり、より複雑なトランザクションではさらに多く必要になることがあります。

現在のほとんどのウォレットでは、ユーザーが ZIP 317 の手数料を手計算する必要はありません。ウォレットが自動的に適切な手数料を選ぶはずです。もしウォレットがまだ古い固定手数料を使っていたり、ZIP 317 の慣例的手数料を大きく下回る手数料を設定できたりする場合、そのトランザクションは遅延したり、優先度を下げられたり、一部のノードに破棄されたり、確実に中継されなかったりする可能性があります。

## 動かないトランザクションの対処法

Zcash のトランザクションは、ウォレットに表示されたというだけでは確定ではありません。ブロックにマイニングされ、あなたの状況に応じて十分な承認数を得た時点で、通常利用において確定となります。取引所やサービスは、ウォレットのデフォルト表示より多くの承認を要求する場合があります。

再送する前に、次の判断ツリーを使ってください。

1. **あなたのウォレットにトランザクション ID は表示されていますか？**
   - いいえの場合、ウォレットはまだトランザクションを作成またはブロードキャストしていない可能性があります。同期状態、インターネット接続、ウォレットのバージョン、ウォレットのエラーメッセージを確認してください。
   - はいの場合、トランザクション ID をコピーして次に進んでください。
2. **そのトランザクションはブロック内で承認されていますか？**
   - はいの場合、ウォレット、取引所、加盟店、またはサービスが要求する承認数に達するまで待ってください。
   - いいえの場合、次に進んでください。
3. **そのトランザクションは有効期限ブロック高に達していますか？**
   - いいえの場合、同じ支払いをまだ手動で再送しないでください。元のトランザクションがまだ承認される可能性があります。
   - はいの場合、そのトランザクションはその有効期限ブロック高を過ぎるとマイニングできません。ウォレットが期限切れまたは失敗として表示することがあり、新しいトランザクションを作成する必要があるかもしれません。
4. **そのトランザクションはあるサーバーやエクスプローラーには表示されるのに、別のものには表示されませんか？**
   - これはトランザクション失敗の証拠ではなく、ネットワーク上の可視性の問題として扱ってください。ノードごとに mempool の見え方が異なる場合があります。
   - 待つか、ウォレットを再同期するか、ウォレットが対応していれば別の信頼できるサーバーに切り替えてください。
5. **承認済みと表示された後に、そのトランザクションが消えましたか？**
   - 短いチェーン再編成によって、トランザクションが一時的に最良チェーンから外れることがあります。
   - さらにブロックが積まれるのを待ってください。トランザクションが戻ったら、そのまま承認を待ち続けてください。戻らず、後で期限切れになった場合は、新しいトランザクションを作成してください。
6. **ウォレットが再送を求めていますか？**
   - 前のトランザクションが期限切れ、失敗、または無効になっていることを確認したうえでのみ、ウォレットの現在の案内に従ってください。
   - 判断に迷う場合は、再送する前にサポートへ問い合わせてください。

## Pending、Expired、Dropped、Reorged

- **Pending** は、トランザクションが作成またはブロードキャストされたが、まだブロックにマイニングされていない状態を意味します。
- **Expired** は、トランザクションの有効期限ブロック高を過ぎたことを意味します。ZIP 203 では、有効期限ブロック高を持つトランザクションは、その高さを過ぎるとマイニングできません。
- **Dropped** は、1 つ以上のノードがそのトランザクションを mempool に保持しなくなったことを意味します。これは、有効期限切れ、低い手数料、mempool ポリシー、再起動時の挙動、中継の違いなどが原因で起こることがあります。
- **Reorged** は、以前そのトランザクションを含んでいたブロックが、もはや最良チェーンの一部ではなくなったことを意味します。トランザクションは後で再びマイニングされることもあれば、まだ有効なら Pending に戻ることもあります。

## 再送すべきでない場合

トランザクションが Pending、遅い、またはあるエクスプローラーに表示されないという理由だけで、すぐに再送しないでください。早すぎる再送は混乱を招き、ウォレットが新しい支払いをどのように構築するかによっては、二重支払いのリスクも生じます。

次のような場合は、まず待つかサポートに相談してください。

- トランザクションにトランザクション ID があり、まだ期限切れになっていない。
- あるサーバーには表示されるが、別のサーバーには表示されない。
- 最近マイニングされたが、reorg の可能性の後で承認数を失った。
- 受取側のサービスがまだ承認数のカウントを終えていない。
- あなたのウォレットがまだ同期中である。

通常は、ウォレットがそのトランザクションを明確に期限切れまたは失敗と表示した後、またはサポートが元のトランザクションは承認されないと確認した後にのみ、再送する方が安全です。

## プライバシーを損なわない確認方法

必要以上の情報を公開せずに、基本的なトランザクション状況を確認できます。

- ウォレットが完全に同期しているか確認する。
- ウォレットアプリが最新か確認する。
- トランザクションにトランザクション ID があるか確認する。
- トランザクションが confirmed、pending、expired、または failed か確認する。
- 現在のブロック高を確認し、ウォレットが表示していればトランザクションの有効期限ブロック高と比較する。
- Transparent トランザクションでは、ブロックエクスプローラーで公開されたトランザクション、アドレス、金額、承認数を確認できる。
- Shielded トランザクションでは、ブロックエクスプローラーはトランザクションの存在を示せても、shielded の送信者、受信者、金額、または memo の詳細は表示できない。

## 公開してはいけないもの

次のものは、公開チャット、ソーシャルメディア、または issue tracker に絶対に投稿しないでください。

- シードフレーズまたはリカバリーフレーズ
- Spending key、秘密鍵、またはウォレットのバックアップ
- Full Viewing Key
- 残高、完全なアドレス、memo、QR コード、または取引所アカウントの詳細が表示されたスクリーンショット
- 個人の本人確認書類またはアカウント復旧記録

トランザクション ID はチェーン上では公開情報ですが、それでもあなたのサポート問い合わせを本人確認情報と結び付ける可能性があります。プライバシーが重要であれば、信頼できるサポート窓口にのみ共有してください。

## サポートチームが必要とする情報

ウォレット、取引所、またはサービスのサポートに助けを求めるときは、有用な最小限の情報だけを共有してください。

- ウォレットまたはサービス名
- アプリのバージョンとオペレーティングシステム
- そのトランザクションが shielded、transparent、または shielded アドレスと transparent アドレスの間かどうか
- 共有に抵抗がなければトランザクション ID
- 送信したおおよその時刻
- ウォレットが完全に同期しているかどうか
- ウォレットが表示している現在の状態
- 秘密情報を除去した正確なエラーメッセージ
- 残高、アドレス、memo、アカウント詳細を隠したスクリーンショット

サポートチームに、シードフレーズ、Spending key、秘密鍵、または Full Viewing Key は必要ありません。

## よくある間違い

- **ZEC を表示しているウォレットなら、どれでも非公開で送れると思い込むこと。** 多くのマルチコインウォレットは、Zcash の transparent 側しかサポートしていません。プライバシー目的で利用する前に、そのウォレットがサポートするプールを確認してください。[ウォレット](https://zechub.wiki/using-zcash/wallets)ページには、各選択肢についてこれが一覧化されています。
- **Transparent アドレスに出金し、そのまま資金を置いておくこと。** 出金自体が公開され、そのアドレスから後で動かすすべての資金移動も公開のままになります。着金したら資金を shield してください。
- **プライバシーを一度オンにすればよいものだと考えること。** 各トランザクションはそれぞれ別の選択です。今日 shielded で送ったとしても、先週行った transparent 支払いが取り消されるわけではありません。
- **1 つの transparent アドレスを何にでも使い回すこと。** Transparent な活動は永久に可視であるため、1 つの再利用アドレスによって、本来つながる理由のない支払い同士が徐々に結び付けられてしまいます。
- **古いデフォルト手数料で送信すること。** ZIP 317 を採用していないウォレットは、まだ古い固定手数料を送ることがあり、その結果、トランザクションが未承認のまま滞留する可能性があります。
- **期限切れ前に再送すること。** Pending のトランザクションは、期限切れになるまではまだ承認される可能性があります。別の支払いを作成する前に、有効期限の状態を確認してください。

## 注意

ZEC を最も安全に使う方法は、送信者、受信者、ウォレット、サービスのすべてが対応している場合に、可能な限り shielded トランザクションを使うことです。一部のウォレットや取引所は [Unified Address](https://electriccoin.co/blog/unified-addresses-in-zcash-explained/#:~:text=The%20unified%20address%20(UA)%20is,within%20the%20broader%20Zcash%20ecosystem.) をサポートしており、複数の Zcash の受信タイプを 1 つのアドレスにまとめることができます。

## ZEC から ZAT へのコンバーター
