# トランザクション

ZECは支払いに広く利用されているデジタル資産であり、友人への支払い、購入、寄付など、さまざまな取引に適した強力なプライバシー機能を提供します。プライバシーとセキュリティを最大限に高めるには、Zcash内で異なる種類のトランザクションがどのように機能するかを理解することが不可欠です。

## TL;DR

- Zcashは、詳細を非公開にする**シールド**トランザクションと、詳細を公開記録する**トランスペアレント**トランザクションの2種類をサポートしています。
- シールドアドレスは`u`または`z`で始まります。トランスペアレントアドレスは`t`で始まり、Bitcoinアドレスとよく似た動作をします。
- 支払いごとに選択できるのはあなた自身です。プライバシーはZcashが提供する選択肢であり、他者があなたのために決める設定ではありません。
- 取引所からの出金は、プライバシーを失う最も一般的な場面です。取引所がトランスペアレント出金しかサポートしていない場合は、資金が到着した後に自分でシールドしてください。
- 手数料は[ZIP 317](https://zips.z.cash/zip-0317)に従い、トランザクションのサイズに応じて増加します。古い固定手数料を送信し続けるウォレットでは、トランザクションが遅延する可能性があります。
- ほとんどのZcashトランザクションには、[ZIP 203](https://zips.z.cash/zip-0203)に基づく有効期限ブロック高があります。採掘される前にトランザクションが期限切れになると、その有効期限ブロック高以降に承認されることはなく、再送信が必要になる場合があります。

シールドトランザクションは、ZECをシールドウォレットへ移動するときに発生します。シールドウォレットのアドレスは`u`または`z`で始まります。シールドトランザクションを送信すると、あなたと取引相手は、デフォルトで公開される決済ネットワークでは実現できない水準のプライバシーを維持できます。

シールドトランザクションを送信する最も簡単な方法は、現在のZcashネットワークと現在のシールドプールをサポートするウォレットを使うことです。プライバシーのためにウォレットを信頼する前に、シールド送信、シールド受信、および使用予定のプールをサポートしているか確認してください。取引所からZECを出金する際は、その取引所がシールド出金またはトランスペアレント出金をサポートしているか確認してください。トランスペアレント出金しかサポートしていない場合は、資金が到着後、シールド対応ウォレットへ移動してください。

資金の送受信にシールドトランザクションを使用することは、プライバシーを維持し、支払いデータ漏えいのリスクを減らす最良の方法です。

## トランスペアレントトランザクション

トランスペアレントトランザクションは、Bitcoinトランザクションと同様に機能します。トランスペアレントアドレスとトランスペアレント金額を含むトランザクションの詳細は、ブロックチェーン上で公開されます。プライバシーが優先される場合、トランスペアレントトランザクションは避けるべきです。

トランスペアレントアドレスは、一部の状況では依然として役立ちます。特に、取引所やサービスがシールドアドレスをサポートしていない場合に有用です。トランスペアレントアドレスでZECを受け取った場合は、その後の支払いを行う前にシールドすることを検討してください。

## イメージしやすい例え

トランスペアレントトランザクションは、はがきのようなものです。配達員はそれを届けますが、途中で扱う誰もがメッセージを読み、誰が送ったのか、誰が受け取るのかを確認できます。

シールドトランザクションは、封をした封筒のようなものです。郵便サービスは、正規の郵便料金が支払われた本物の手紙がシステムを通過したことを確認でき、誰もそれを偽造したり、同じ手紙を二度送ったりすることはできません。封筒の中身は、送信者と受信者の間だけに留まります。

重要なのは、Zcashでは支払いごとにどちらを送るか決められることです。

## Zcashの手数料

ZcashはEthereum形式のガス単位を使用しません。Zcashトランザクション手数料はZECで支払われ、通常は**zatoshis**で測定されます。1 ZECは100,000,000 zatoshisに相当します。

[ZIP 317](https://zips.z.cash/zip-0317)は、トランザクションの複雑さに応じて増加する標準的な手数料メカニズムを定義しています。すべてのトランザクションに従来の1,000-zatoshi固定手数料を使用する代わりに、標準手数料は入力、出力、シールドアクションなどの「論理アクション」に基づきます。単純なトランザクションでは一般に10,000 zatoshis、すなわち0.0001 ZEC程度から始まり、より複雑なトランザクションではそれ以上必要になることがあります。

現在のほとんどのウォレットでは、ユーザーがZIP 317の手数料を手動で計算する必要はありません。ウォレットが適切な手数料を自動的に選択するはずです。ウォレットが依然として古い固定手数料を使用している、またはZIP 317の標準手数料を大幅に下回る手数料を設定できる場合、トランザクションが遅延したり、優先順位を下げられたり、一部のノードによって破棄されたり、確実にリレーされなかったりする可能性があります。

## 停滞したトランザクションのトラブルシューティング

Zcashトランザクションは、ウォレットに表示されたからといって確定したわけではありません。通常の利用においては、ブロックに採掘され、状況に応じて十分な承認を受けることで確定します。取引所やサービスは、ウォレットがデフォルトで表示するより多くの承認を要求する場合があります。

再送信する前に、この判断ツリーを使用してください。

1. **ウォレットにトランザクションIDが表示されていますか？**
   - いいえの場合、ウォレットはまだトランザクションを作成またはブロードキャストしていない可能性があります。同期状態、インターネット接続、ウォレットのバージョン、およびウォレットのエラーメッセージを確認してください。
   - はいの場合、トランザクションIDをコピーして続けてください。
2. **トランザクションはブロック内で承認されていますか？**
   - はいの場合、ウォレット、取引所、加盟店、またはサービスが必要とする承認数に達するまで待ってください。
   - いいえの場合、続けてください。
3. **トランザクションは有効期限ブロック高に達していますか？**
   - いいえの場合、同じ支払いをまだ手動で再送信しないでください。元のトランザクションはまだ承認される可能性があります。
   - はいの場合、そのトランザクションはその有効期限ブロック高以降に採掘されることはできません。ウォレットは期限切れまたは失敗として表示する場合があり、新しいトランザクションを作成する必要があるかもしれません。
4. **トランザクションは一方のサーバーまたはエクスプローラーには表示されるが、別のものには表示されませんか？**
   - これはトランザクションが失敗した証拠ではなく、ネットワーク可視性の問題として扱ってください。異なるノードではmempoolの表示が異なる場合があります。
   - 待機するか、ウォレットを再同期するか、ウォレットが対応していれば別の信頼できるサーバーに切り替えてください。
5. **トランザクションは承認済みとして表示された後に消えましたか？**
   - 短いチェーン再編成により、トランザクションが一時的に最良チェーンから除外されることがあります。
   - さらにブロックが追加されるのを待ってください。トランザクションが戻った場合は、承認を待ち続けてください。戻らず、その後期限切れになった場合は、新しいトランザクションを作成してください。
6. **ウォレットから再送信を求められていますか？**
   - 以前のトランザクションが期限切れ、失敗、または無効であることを確認した後にのみ、ウォレットの現在の案内に従ってください。
   - 確信がない場合は、再度送信する前にサポートへ問い合わせてください。

## 保留、期限切れ、破棄、再編成

- **保留中**とは、トランザクションが作成またはブロードキャストされたものの、まだブロックに採掘されていないことを意味します。
- **期限切れ**とは、トランザクションの有効期限ブロック高を過ぎたことを意味します。ZIP 203では、有効期限ブロック高を持つトランザクションは、そのブロック高以降に採掘できません。
- **破棄**とは、1つ以上のノードがトランザクションをmempool内に保持しなくなったことを意味します。これは、期限切れ、低い手数料、mempoolポリシー、再起動時の動作、またはリレーの違いによって発生する可能性があります。
- **再編成**とは、以前にトランザクションを含んでいたブロックが最良チェーンの一部ではなくなったことを意味します。トランザクションは後で再び採掘される場合もあれば、まだ有効であれば保留中に戻る場合もあります。

## 再送信すべきでない場合

トランザクションが保留中、遅い、またはあるエクスプローラーで見つからないという理由だけで、すぐに再送信しないでください。早すぎる再送信は混乱を招き、ウォレットが新しい支払いをどのように構築するかによっては、二重に支払うリスクがあります。

以下の場合は、まず待機するかサポートを受けてください。

- トランザクションにトランザクションIDがあり、まだ期限切れではない。
- あるサーバーには表示されるが、別のサーバーには表示されない。
- 最近採掘されたものの、再編成の可能性によって承認を失った。
- 受信サービスがまだ承認数のカウントを完了していない。
- ウォレットがまだ同期中である。

通常は、ウォレットがトランザクションを明確に期限切れまたは失敗と表示した後、またはサポートが元のトランザクションは承認されないと確認した後にのみ再送信する方が安全です。

## プライバシーを守る確認方法

必要以上の情報を公開せずに、基本的なトランザクション状態を確認できます。

- ウォレットが完全に同期されているか確認する。
- ウォレットアプリが最新であるか確認する。
- トランザクションにトランザクションIDがあるか確認する。
- トランザクションが承認済み、保留中、期限切れ、または失敗のいずれかを確認する。
- ウォレットに表示される場合は、現在のブロック高を確認し、トランザクションの有効期限ブロック高と比較する。
- トランスペアレントトランザクションでは、ブロックエクスプローラーで公開トランザクション、アドレス、金額、および承認を確認できます。
- シールドトランザクションでは、ブロックエクスプローラーでトランザクションの存在を確認できますが、シールドされた送信者、受信者、金額、またはメモの詳細は確認できません。

## 公開してはいけないもの

次の情報を公開チャット、ソーシャルメディア、または課題トラッカーに投稿しないでください。

- シードフレーズまたはリカバリーフレーズ
- Spending key、秘密鍵、またはウォレットバックアップ
- Full Viewing Key
- 残高、完全なアドレス、メモ、QRコード、または取引所アカウントの詳細を示すスクリーンショット
- 個人の身元確認書類またはアカウント復旧記録

トランザクションIDはチェーン上で公開されていますが、それでもサポートに関する質問とあなたの身元を結び付ける可能性があります。プライバシーが重要な場合は、信頼できるサポートチャネルとのみ共有してください。

## サポートチームが必要とする情報

ウォレット、取引所、またはサービスのサポートに問い合わせる際は、役立つ最小限の情報のみを共有してください。

- ウォレットまたはサービスの名前
- アプリのバージョンとオペレーティングシステム
- トランザクションがシールド、トランスペアレント、またはシールドアドレスとトランスペアレントアドレス間のどれであるか
- 共有して問題なければ、トランザクションID
- おおよその送信時刻
- ウォレットが完全に同期されているか
- ウォレットに表示される現在の状態
- 非公開データを削除した正確なエラーメッセージ
- 残高、アドレス、メモ、アカウント詳細を隠したスクリーンショット

サポートチームにシードフレーズ、Spending key、秘密鍵、またはFull Viewing Keyは必要ありません。

## よくある間違い

- **ZECを掲載しているウォレットなら、どれでもプライベートに送信できると考えること。** 複数通貨対応ウォレットの中には、Zcashのトランスペアレント側のみをサポートするものがあります。プライバシーのために利用する前に、ウォレットがサポートするプールを確認してください。[ウォレット](https://zechub.wiki/using-zcash/wallets)ページには、各選択肢についてこれが記載されています。
- **トランスペアレントアドレスに出金し、そのまま資金を置いておくこと。** 出金自体が公開され、そのアドレスからの以後のすべての移動も公開されたままです。資金が到着したらシールドしてください。
- **プライバシーを一度有効にすれば済むものとして扱うこと。** 各トランザクションは個別の選択です。今日シールド送信しても、先週行ったトランスペアレントな支払いを取り消すことはできません。
- **すべてに同じトランスペアレントアドレスを再利用すること。** トランスペアレントな活動は恒久的に可視であるため、再利用された1つのアドレスは、関連付ける理由のない支払いを徐々に結び付けます。
- **古いデフォルト手数料で送信すること。** ZIP 317を採用していないウォレットでは、依然として古い固定手数料を送信する可能性があり、トランザクションが未承認のまま残ることがあります。
- **期限切れ前に再送信すること。** 保留中のトランザクションは、期限切れになるまで承認される可能性があります。別の支払いを作成する前に、期限の状態を確認してください。

## 注記

送信者、受信者、ウォレット、およびサービスのすべてが対応している場合、ZECを使用する最も安全な方法は常にシールドトランザクションを使用することです。一部のウォレットや取引所は、複数のZcash受信者タイプを1つのアドレスに組み合わせられる[統合アドレス](https://electriccoin.co/blog/unified-addresses-in-zcash-explained/#:~:text=The%20unified%20address%20(UA)%20is,within%20the%20broader%20Zcash%20ecosystem.)をサポートしています。
