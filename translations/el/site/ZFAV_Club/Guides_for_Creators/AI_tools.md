# Εργαλεία AI: Δημιουργία κειμένου, εικόνας, βίντεο, ήχου (online)

Ακολουθεί μια λίστα για να κάνεις τη ζωή σου ευκολότερη. Το πώς θα τα χρησιμοποιήσεις είναι άλλο θέμα.

Η σύνταξη των καλύτερων prompts έχει καμπύλη μάθησης. Μπορείς να μάθεις τα βασικά αρκετά γρήγορα.

## Δημιουργία κειμένου/βοηθοί

[Αναλυτής prompt](https://novelai.net/tokenizer) (tokenizer) για να μάθεις πώς λειτουργούν τα prompts και πόσα tokens χρησιμοποιούν.

Μπορείς πάντα να ζητήσεις από βοηθούς Chatbot να σε βοηθήσουν να δημιουργήσεις ένα καλό prompt.

### Δωρεάν εργαλεία:

- [Anthropic's Claude](https://claude.ai/) - μπορεί να χρειαστείς VPN για εγγραφή (μόνο ΗΠΑ)
- [ChatGPT 3.5](https://chat.openai.com/) - ζητά αριθμό τηλεφώνου
- [Bing Chat (GPT4)](https://www.bing.com/search?q=Bing+AI&showconv=1&FORM=hpcodx) - περιορισμένα prompts ανά ημέρα
- [Llama 2 - 70B](https://www.llama2.ai/) - δωρεάν στον ιστότοπο

### Επί πληρωμή εργαλεία:

- [Free2Z Chat2Z](https://free2z.com/ai) - Πλήρωσε με ZEC / 2Zs για GPT-3.5 και GPT-4 λεπτά/prompt
- [Chat GPT-4](https://chat.openai.com/auth/login) - $20/μήνα.

## Δημιουργία εικόνας

### Δωρεάν εργαλεία:

τώρα επίσης [Webapp ImgnAI](https://app.imgnai.com/home) με ξεχωριστή σύνδεση λογαριασμού

- [Ideogram](https://ideogram.ai/login) - καλό στη δημιουργία ρεαλιστικού, ευανάγνωστου κειμένου σε εικόνες
- [Playground AI](https://playgroundai.com/) - δωρεάν λειτουργία, συνδρομή από $15/μήνα
- [Clipdrop από το stability.ai](https://clipdrop.co/stable-diffusion)

### Επί πληρωμή εργαλεία:

- [DALL-E 3](https://openai.com/dall-e-3/) - περιλαμβάνεται στο ChatGPT-4 - $20/μήνα
- [Nightcafe Creator](https://creator.nightcafe.studio/) (4 δωρεάν δημιουργίες, η επί πληρωμή έκδοση ξεκινά από $6/μήνα)
