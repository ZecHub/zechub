# Βιβλιοθήκη Zcash

Ένα ολοκληρωμένο γλωσσάρι βασικών όρων, εννοιών και πόρων που σχετίζονται με το Zcash. Αυτή είναι η ενιαία βιβλιοθήκη για αναζήτηση όρων από σημειώσεις έκδοσης, συζητήσεις στο φόρουμ ή changelog πορτοφολιών.

## P

| Όρος | Ορισμός |
|------|-----------|
| Payments | Είναι δυνατό να χρησιμοποιείς το Zcash για καθημερινές αγορές μέσω αρκετών διαφορετικών παρόχων πληρωμών. [Εφαρμογές πληρωμών](https://z.cash/pay-with-zcash/) |
| PCD (Proof-Carrying Data) | Μια πρωτογενής έννοια όπου τα δεδομένα ταξιδεύουν μαζί με μια απόδειξη της δικής τους ορθότητας, ώστε ο συνδυασμός δεδομένων να συνδυάζει και τις αποδείξεις. Το Project Tachyon ανακατασκευάζει το θωρακισμένο πρωτόκολλο γύρω από το PCD, επιτρέποντας σε κάθε πορτοφόλι να φέρει μια αναδρομική απόδειξη ότι το δικό του υπόλοιπο είναι σωστό, αντί να επανασαρώνει την αλυσίδα. Η υλοποίηση Zcash είναι το [Ragu](https://github.com/tachyon-zcash/ragu), το οποίο ακολουθεί το Halo και δεν χρειάζεται trusted setup. |
| Peer-to-Peer Network | Τα δίκτυα P2P βασίζονται στην έννοια της αποκέντρωσης. Αποτελούν τη θεμελιώδη αρχιτεκτονική της τεχνολογίας blockchain. |
| PIR (Private Information Retrieval) | Τεχνικές που σου επιτρέπουν να ανακτάς μια εγγραφή από έναν server χωρίς ο server να μαθαίνει ποια εγγραφή ζήτησες. Βρίσκονται υπό ενεργή έρευνα για το Zcash ως τρόπος για τα ελαφριά πορτοφόλια να ανακτούν ό,τι χρειάζονται χωρίς να διαρρέουν τι αναζητούν. |
| Podcast | [Radiolab (Τελετή Zcash)](https://archive.org/details/radiolab_podcast17crypto_zcash_ceremony) / [RealVisionFinance](https://www.youtube.com/watch?v=ibA_4kwd_YI) / [EthDenver](https://www.youtube.com/watch?v=t62isi58XcQ) / [UpOnlyPodcast](https://www.youtube.com/watch?v=AjC9T938o3Q) / [Zcast στα Ισπανικά](https://www.youtube.com/@ZcastEsp) |

## Q

| Όρος | Ορισμός |
|------|-----------|
| QR Code | Ένας κωδικός αναγνώσιμος από μηχανή που χρησιμοποιείται για την κωδικοποίηση διευθύνσεων Zcash, ώστε να σαρώνεται εύκολα. Οι Unified Addresses (UAs) συνήθως κοινοποιούνται μέσω κωδικών QR σε σύγχρονα πορτοφόλια Zcash. |
| Quantum Recoverability | Μια ιδιότητα των notes Ironwood, που καθορίζεται στο [ZIP 2005](https://zips.z.cash/zip-2005), η οποία διατηρεί ανακτήσιμη την on-chain καταχώριση ενός νομίσματος αν ένας μελλοντικός κβαντικός υπολογιστής σπάσει την κρυπτογράφηση που το προστατεύει σήμερα. Αποτελεί διαδρομή ανάκτησης και όχι ανθεκτικότητα στους κβαντικούς υπολογιστές και εφαρμόζεται σε notes Ironwood, όχι σε υπάρχοντα κεφάλαια Sprout, Sapling ή Orchard. |

## R

| Όρος | Ορισμός |
|------|-----------|
| Recovery Phrase | Μια ακολουθία 12 ή 24 γραμμάτων και αριθμών που χρησιμοποιείται για τη δημιουργία αντιγράφου ασφαλείας και την επαναφορά ενός πορτοφολιού. Στο Zcash, αυτή η φράση αναδημιουργεί spending και viewing keys, καθιστώντας την κρίσιμη για την ανάκτηση κεφαλαίων και την ασφάλεια. |

## S

| Όρος | Ορισμός |
|------|-----------|
| Sapling | Μια σημαντική αναβάθμιση δικτύου που εισήγαγε ουσιαστικές βελτιώσεις αποδοτικότητας για θωρακισμένες συναλλαγές και άνοιξε τον δρόμο για την υιοθέτηση σε κινητές συσκευές. Ενεργοποιήθηκε στο μπλοκ 419200. |
| Selective Disclosure | Επιτρέπει στον ιδιοκτήτη μιας θωρακισμένης διεύθυνσης να κοινοποιεί επιλεκτικά viewing keys ή αποκαλύψεις πληρωμών σε τρίτα μέρη, διατηρώντας τα δεδομένα ιδιωτικά από όλους τους υπόλοιπους. |
| Shielded Address | Ονομάζεται επίσης zaddr. Αρχίζει με z. Αποκρύπτει τον αποστολέα, τον παραλήπτη, το ποσό και το σημείωμα χρησιμοποιώντας zk-SNARKs. |
| Shielded Labs | Ένας ανεξάρτητος οργανισμός που εργάζεται πάνω στην οικονομία πρωτοκόλλου και τη συναίνεση του Zcash. Επί του παρόντος ηγείται των Crosslink και του Μηχανισμού Βιωσιμότητας Δικτύου. [GitHub](https://github.com/ShieldedLabs) |
| Shielded Transaction | Μια συναλλαγή αποκλειστικά μεταξύ θωρακισμένων διευθύνσεων. Πλήρως ιδιωτική στο blockchain. |
| Sol/s | Λύσεις ανά δευτερόλεπτο - μετρά την απόδοση εξόρυξης Equihash. |
| Spending Key | Το ιδιωτικό κλειδί που επιτρέπει τη δαπάνη από μια θωρακισμένη διεύθυνση (σου επιτρέπει επίσης να βλέπεις το υπόλοιπο και το ιστορικό). |
| Sprout | Η αρχική θωρακισμένη έκδοση πρωτοκόλλου του Zcash (κυκλοφόρησε το 2016). |

## T

| Όρος | Ορισμός |
|------|-----------|
| Tachyon | Το πρόγραμμα κλιμάκωσης του Zcash. Δεν αποτελεί μέρος του NU7 ([ZIP 259](https://zips.z.cash/zip-0259)) και δεν έχει ημερομηνία ενεργοποίησης. Μετακινεί τα πορτοφόλια από τη σάρωση κάθε μπλοκ προς κατάσταση πορτοφολιού που μεταφέρει αποδείξεις, τυφλό συγχρονισμό και κατάσταση κόμβου με δυνατότητα περικοπής, με στόχο θωρακισμένη διεκπεραιωτική ικανότητα χιλιάδων συναλλαγών ανά δευτερόλεπτο. [Ιστότοπος έργου](https://tachyon.z.cash/overview/) |
| TAZ | Testnet Zcash (δοκιμαστικό νόμισμα χωρίς αξία). |
| Testnet | Ένα ξεχωριστό blockchain για τη δοκιμή αναβαθμίσεων και λειτουργιών πριν από το mainnet. |
| Trailing Finality Layer (TFL) | Έρευνα για την προσθήκη ενός επιπέδου τελικοποίησης πίσω από την αλυσίδα proof-of-work του Zcash, ώστε πρόσφατα μπλοκ να μπορούν να τελικοποιούνται χωρίς να αντικαθίσταται η εξόρυξη. Το Crosslink είναι ο σχεδιασμός που προέκυψε από αυτήν. |
| Transaction | Μια πληρωμή μεταξύ χρηστών, η οποία υποβάλλεται στο δίκτυο και τελικά επιβεβαιώνεται σε ένα μπλοκ. |
| Transaction Expiry | Οι συναλλαγές λήγουν μετά από περίπου 25 λεπτά (20 μπλοκ) αν δεν επιβεβαιωθούν· τα κεφάλαια επιστρέφουν αυτόματα. |
| Transaction Fee | Τα προεπιλεγμένα τέλη είναι 0,0001 ZEC. Τα υψηλότερα τέλη λαμβάνουν προτεραιότητα· τα πολύ χαμηλά τέλη μπορεί να προκαλέσουν καθυστερήσεις ή λήξη. |
| Transparent Address | Ονομάζεται επίσης taddr. Αρχίζει με t. Πλήρως δημόσια (όπως το Bitcoin). |
| Transparent Transaction | Μια συναλλαγή αποκλειστικά μεταξύ διαφανών διευθύνσεων - όλα είναι δημόσια ορατά. |
| Turnstile | Ο λογιστικός κανόνας που παρακολουθεί πόση αξία εισέρχεται και εξέρχεται από κάθε θωρακισμένο pool, ώστε κανένα pool να μην μπορεί να αποδεσμεύσει περισσότερα από όσα εισήλθαν σε αυτό. Χρησιμοποιείται σε κάθε μετάβαση pool στην ιστορία του Zcash και επί του παρόντος προστατεύει τη μετεγκατάσταση από το Orchard στο Ironwood. [Περισσότερες πληροφορίες](/zcash-tech/the-turnstile) |

## U

| Όρος | Ορισμός |
|------|-----------|
| Unified Address | Σύγχρονη μορφή διεύθυνσης (εισήχθη στο NU5) που λειτουργεί για διαφανείς και θωρακισμένες πληρωμές σε μία συμβολοσειρά. |
| Upgrade Activation | Το συγκεκριμένο ύψος μπλοκ όπου μια αναβάθμιση δικτύου (π.χ. NU5, NU6) ενεργοποιείται αυτόματα. |

## V

| Όρος | Ορισμός |
|------|-----------|
| Viewing Key | Ένα ιδιωτικό κλειδί που σου επιτρέπει να βλέπεις το υπόλοιπο και το ιστορικό συναλλαγών μιας θωρακισμένης διεύθυνσης χωρίς να μπορείς να δαπανήσεις τα κεφάλαια. |

## W

| Όρος | Ορισμός |
|------|-----------|
| Wallet | Λογισμικό ή hardware που αποθηκεύει ιδιωτικά κλειδιά και σου επιτρέπει να στέλνεις/λαμβάνεις ZEC. Τα ενεργά πορτοφόλια περιλαμβάνουν τα ZODL (iOS/Android), Zingo! (κινητό/υπολογιστής), Nighthawk (Android), Zkool (κινητό/υπολογιστής), Zallet (προσεχώς) και Keystone (hardware). Για πλήρη λίστα, δες [ZcashΠορτοφόλια του οικοσυστήματος](https://z.cash/ecosystem/?wallets=#tag-wallets) |
| WebZjs | Το πρώτο SDK JavaScript για το Zcash, που δημιουργήθηκε από την ChainSafe για περιβάλλοντα προγράμματος περιήγησης. Αποτελεί τη βάση του snap Shielded Wallet του Zcash που έφερε θωρακισμένες συναλλαγές ZEC στο MetaMask. |

## X

| Όρος | Ορισμός |
|------|-----------|
| XZC | Ένα παλαιότερο σύμβολο διαπραγμάτευσης για το Zcash, που χρησιμοποιείται σε ορισμένα παλαιότερα ανταλλακτήρια. Το επίσημο σύμβολο είναι το ZEC. |

## Y

| Όρος | Ορισμός |
|------|-----------|
| YWallet | Ένα πορτοφόλι Zcash με έμφαση στην ιδιωτικότητα, που υποστηρίζει Orchard, Sapling και διαφανείς διευθύνσεις και είναι γνωστό για τον γρήγορο συγχρονισμό του. Δεν συντηρείται πλέον: ο προγραμματιστής του έχει επιβεβαιώσει ότι δεν θα ενημερωθεί για το Ironwood, επομένως δεν μπορεί πλέον να ακολουθεί το δίκτυο. Το Zkool, από τον ίδιο προγραμματιστή, είναι ο συντηρούμενος διάδοχός του. |

## Z

| Όρος | Ορισμός |
|------|-----------|
| Zcash | Κρυπτονόμισμα με έμφαση στην ιδιωτικότητα που χρησιμοποιεί zk-SNARKs. Γεφυρώνει διαφανείς πληρωμές (τύπου Bitcoin) και πλήρως θωρακισμένες πληρωμές. |
| Zcash Foundation | Ανεξάρτητος μη κερδοσκοπικός οργανισμός που υποστηρίζει το οικοσύστημα Zcash, χρηματοδοτεί την ανάπτυξη και προωθεί την ιδιωτικότητα. |
| Zcash Network | Δίκτυο peer-to-peer κόμβων που επικυρώνει συναλλαγές και διατηρεί το blockchain. |
| ZEC | Ο επίσημος κωδικός νομίσματος για το Zcash (ορισμένα ανταλλακτήρια εξακολουθούν να εμφανίζουν XZC). |
| Z3 stack | Τα τρία προγράμματα που μαζί αντικαθιστούν το zcashd: το Zebra για τον κόμβο, το Zaino για την ευρετηρίαση, το Zallet για το πορτοφόλι. [Z3 stack](/zcash-tech/z3-stack) |
| Zerocash | Το ακαδημαϊκό πρωτόκολλο (2014) στο οποίο βασίζεται το Zcash. |
| Zaino | Ένας indexer που εξυπηρετεί δεδομένα πορτοφολιού από έναν κόμβο Zebra, γραμμένος σε Rust από το Zingo Labs. Αναλαμβάνει την εργασία ευρετηρίασης που το zcashd εκτελούσε για light πορτοφόλια. [Zaino](/zcash-tech/zaino) |
| Zakura | Ένας ξεχωριστός πλήρης κόμβος Zcash, κατασκευασμένος για κλίμακα, υπό την ηγεσία του Sean Bowe και του Dev Ojha. Συγχρονίζεται ταχύτερα, περικόπτει μπλοκ εγγενώς και μπορεί να εκτελεί το zcashd πάνω του για λογισμικό που εξακολουθεί να εξαρτάται από αυτό. [Κόμβος Zakura](/zcash-tech/zakura-node) |
| Zallet | Το πορτοφόλι που αντικαθιστά το πορτοφόλι zcashd. Μετέφερε ένα υπάρχον `wallet.dat` αντί να ξεκινήσεις από την αρχή. [Zallet](/zcash-tech/zallet) και η [Zalletγρήγορη αναφορά](/using-zcash/zallet-quick-reference-guide) |
| Zebra | Ο πλήρης κόμβος που αντικαθιστά το zcashd, συντηρούμενος από το Zcash Foundation. Εκτέλεσέ τον αν χρειάζεσαι έναν κόμβο επικύρωσης. [ZebraΠλήρης κόμβος](/zcash-tech/zebra-full-node) |
| zcashd | Ο αρχικός πλήρης κόμβος και πορτοφόλι Zcash, που πλέον έχει αποσυρθεί. Η έκδοση 6.20.0 τερμάτισε τη λειτουργία της στο μπλοκ 3417100 στις 18 Ιουλίου 2026 και δεν υποστήριξε ποτέ το NU6.3. Εκτέλεσε το Z3 stack ή το Zakura αντί αυτού. [Οδηγός μετεγκατάστασης](/guides/migration-guide-zcashd-to-zebrad-zallet) |
| ZIP | Πρόταση βελτίωσης του Zcash - η διαδικασία κοινοτικής διακυβέρνησης που χρησιμοποιείται για την πρόταση και επικύρωση αλλαγών πρωτοκόλλου. [ZIPΑποθετήριο](https://github.com/zcash/zips) |
| ZODL | Open Development Lab του Zcash. Ο ανεξάρτητος οργανισμός που ιδρύθηκε στις αρχές του 2026 από το Josh Swihart και την πρώην ομάδα μηχανικών του Electric Coin Company, αφού παραιτήθηκαν λόγω διαφωνίας διακυβέρνησης με το Bootstrap. Συγκέντρωσε πάνω από 25 εκατομμύρια δολάρια σε αρχική χρηματοδότηση τον Μάρτιο του 2026 και συντηρεί το πορτοφόλι ZODL, το οποίο μετονομάστηκε από Zashi τον Φεβρουάριο του 2026. [zodl.com](https://zodl.com) |
| zk-SNARKs | Συνοπτικά μη διαδραστικά επιχειρήματα γνώσης μηδενικής γνώσης — η κρυπτογράφηση που υποστηρίζει τις θωρακισμένες συναλλαγές Zcash. Επιτρέπει την απόδειξη μιας δήλωσης (π.χ. έγκυρη δαπάνη) χωρίς την αποκάλυψη οποιασδήποτε μυστικής πληροφορίας. |
| ZSA (Zcash Shielded Assets) | Tokens που εκδίδονται από χρήστες και κληρονομούν τη θωρακισμένη ιδιωτικότητα του Zcash, επιτρέποντας σε assets πέρα από το ZEC να κινούνται ιδιωτικά στο δίκτυο. Καθορίζονται στο [ZIP 226](https://zips.z.cash/zip-0226). Δεν αποτελούν μέρος του NU7 ([ZIP 259](https://zips.z.cash/zip-0259)) και δεν έχουν ημερομηνία ενεργοποίησης. |
