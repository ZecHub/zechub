# Διέθεσε αποθετήριο GitHub με IPFS

## Εισαγωγή

Σε αυτόν τον οδηγό θα μάθεις πώς να δημιουργήσεις ένα URL με δυνατότητα κλωνοποίησης git για το αποθετήριο GitHub σου, το οποίο διατίθεται χρησιμοποιώντας ένα CID του IPFS. Αυτό είναι χρήσιμο για να διασφαλίσεις τη διαθεσιμότητα περιεχομένου ανεξαρτήτως γεωγραφικής περιοχής, την ανθεκτικότητα στη λογοκρισία και ως μόνιμο αντίγραφο ασφαλείας πολύτιμων πληροφοριών!

Σημείωση: Τα δεδομένα που ανεβαίνουν στο IPFS είναι διαθέσιμα σε *όλους* τους χρήστες του δικτύου. Ίσως θελήσεις να κρυπτογραφήσεις τοπικά προσωπικά/ευαίσθητα δεδομένα.


## Εγκατάσταση του IPFS Kubo

Ακολούθησε τις οδηγίες εγκατάστασης που παρέχονται [εδώ](https://docs.ipfs.tech/install/command-line/#install-official-binary-distributions)

Σε αυτό το παράδειγμα χρησιμοποιούμε το Linux, ενώ είναι διαθέσιμες και άλλες εκδόσεις λειτουργικών συστημάτων.

Έλεγξε ότι η εγκατάσταση ολοκληρώθηκε επιτυχώς χρησιμοποιώντας το «ipfs --version»


## Κλωνοποίηση αποθετηρίου

Για να ξεκινήσεις, επίλεξε ένα αποθετήριο Git που θέλεις να φιλοξενήσεις και κλωνοποίησέ το:

Εκτέλεσε την εντολή: «git clone https://github.com/zechub/zechub"

![](/content-images/Screenshot-from-2023-05-20-14-14-46-8503afccc3.webp)


Τώρα, ετοίμασέ το για να μπορεί να κλωνοποιηθεί μέσω IPFS.

cd zechub
git update-server-info


Αποσυμπίεσε τα αντικείμενα του Git:

mv objects/pack/*.pack .
git unpack-objects < *.pack
rm -f *.pack objects/pack/*

Με αυτόν τον τρόπο, το IPFS θα μπορεί να αποδιπλασιάζει αντικείμενα αν ενημερώσεις αργότερα το αποθετήριο Git.


## Προσθήκη στο IPFS

Αφού το κάνεις αυτό, το αποθετήριο είναι έτοιμο να διατεθεί. Απομένει μόνο να το προσθέσεις στο IPFS:

$ pwd

/code/myrepo

$ ipfs add -r .

![](/content-images/Screenshot-from-2023-05-20-14-22-38-3fc2f72d91.webp)

Το CID που προκύπτει: Qmbgqox5g3614gjTb43s5mdSmmk95aGWWA9EHksL2T91A2

![](/content-images/Screenshot-from-2023-05-20-14-26-34-6e00fee828.webp)

Υπέροχα! Τώρα το αποθετήριό σου έχει ανέβει στο δίκτυο.


## Κλωνοποίηση με IPFS

Τώρα θα πρέπει να μπορείς να ανακτήσεις το αποθετήριο GitHub χρησιμοποιώντας:

git clone http://ipfs.io/ipfs/"yourCID"

Εναλλακτικά, μπορείς να αναζητήσεις και να ανακτήσεις το αποθετήριο χρησιμοποιώντας τον τοπικό κόμβο IPFS σου.

Τελική σημείωση: Ο φάκελος του αποθετηρίου στο IPFS δεν λαμβάνει ενημερώσεις μαζί με το πραγματικό αποθετήριο GitHub. Συνιστάται να ανεβάζεις ξανά τον φάκελο σε τακτά χρονικά διαστήματα.
