# Δημοσίευσε έναν ιστότοπο στο IPFS 

![](/content-images/IPFS-40c2e22732.webp)

## Εισαγωγή στο IPFS 

Το IPFS (InterPlanetary File System) είναι ένα peer-to-peer πρωτόκολλο και δίκτυο που έχει σχεδιαστεί για να δημιουργεί έναν αποκεντρωμένο τρόπο αποθήκευσης και κοινοποίησης αρχείων. 

Σε αντίθεση με το παραδοσιακό μοντέλο client-server του διαδικτύου, το IPFS επιτρέπει στους χρήστες να μοιράζονται αρχεία απευθείας μεταξύ τους, αντί να βασίζονται σε έναν κεντρικό διακομιστή για την αποθήκευση και διανομή περιεχομένου. 

Τα αρχεία στο IPFS λαμβάνουν διεύθυνση με χρήση *content-addressing*, που σημαίνει ότι σε κάθε αρχείο δίνεται ένα μοναδικό hash ή ΑΝΑΓΝΩΡΙΣΤΙΚΟ ΠΕΡΙΕΧΟΜΕΝΟΥ (CID) βάσει του περιεχομένου του, και αυτό το hash χρησιμοποιείται για την ανάκτηση του αρχείου από το δίκτυο.

Όταν ένας χρήστης προσθέτει ένα αρχείο στο IPFS, το αρχείο χωρίζεται σε μικρά κομμάτια που ονομάζονται μπλοκ και σε κάθε μπλοκ δίνεται ένα CID. Αυτά τα μπλοκ αποθηκεύονται έπειτα σε διαφορετικούς κόμβους του δικτύου, ώστε το αρχείο να μπορεί να ανακτηθεί εύκολα από πολλαπλές πηγές. 

Αυτό εξασφαλίζει πλεονασμό και ανοχή σε σφάλματα, ενώ παράλληλα δυσκολεύει οποιονδήποτε μεμονωμένο κόμβο να γίνει μοναδικό σημείο αποτυχίας ή ελέγχου. 

Διάβασε το [Μια εισαγωγή στο IPFS](https://blog.infura.io/post/an-introduction-to-ipfs)



## Δημιούργησε τον ιστότοπό σου 

Για αυτό το παράδειγμα, δημιουργούμε έναν απλό ιστότοπο. 

[Παράδειγμα ιστότοπου](https://squirrel.surf)


**Βήμα 1:** Αν δεν είσαι εξοικειωμένος με τον σχεδιασμό ιστοσελίδων, γράψε το κύριο περιεχόμενο για τον ιστότοπό σου, συμπεριλαμβανομένων του τίτλου, του κύριου σώματος κειμένου, συνδέσμων προς άλλες σελίδες/ιστότοπους και υποσέλιδων.

**Βήμα 2:** Χρησιμοποίησε ένα [πρότυπο HTML!](https://nicepage.com/html-templates). Επικόλλησε το κείμενο που έγραψες αναλόγως. Προαιρετικά, δημιούργησε επίσης ένα φύλλο στυλ .CSS για τον ιστότοπό σου. 

**Βήμα 3:** Αποθήκευσε τον κατάλογό σου. Όλες οι σελίδες .html και οι εικόνες πρέπει να βρίσκονται στον ίδιο φάκελο. 



## Ρύθμιση ενός κόμβου

Κατέβασε και εγκατέστησε το IPFS από τον [Επίσημο ιστότοπο](https://docs.ipfs.tech/install/ipfs-desktop/).



### Αρχικοποίηση IPFS: 

Αν χρησιμοποιείς την εφαρμογή Desktop, δεν θα χρειαστεί να κάνεις αρχικοποίηση. 

Χρησιμοποιώντας ένα Terminal ή τη γραμμή εντολών, εκτέλεσε την εντολή: <mark>ipfs init </mark>. 



**Πρόσθεσε τον φάκελο του ιστότοπου στο IPFS**: 

Επίλεξε τον φάκελο με τα αρχεία του ιστότοπού σου και μετακινήσου στην επιλογή Add Folder.

![](/content-images/ipfs-site-folder-2c96524d98.webp)

--

Αν χρησιμοποιείς Terminal, εκτέλεσε την εντολή: <mark>ipfs add -r "folder_name"</mark> για να προσθέσεις αναδρομικά ολόκληρο τον φάκελο στο IPFS.


### Κάνε pin τον ιστότοπο στο IPFS: 

Μόλις τα αρχεία του ιστότοπού σου προστεθούν στο IPFS, πρέπει να τα **κάνεις pin** ώστε να διασφαλίσεις ότι παραμένουν διαθέσιμα στο δίκτυο.

--

Αν χρησιμοποιείς Terminal, εκτέλεσε την εντολή: Αν χρησιμοποιείς Terminal, εκτέλεσε την εντολή: <mark>ipfs pin add "hash"</mark> 

"hash" = CID του φακέλου που πρόσθεσες στο προηγούμενο βήμα.


Εναλλακτικά, μπορείς επίσης να κάνεις pin καταλόγους χρησιμοποιώντας υπηρεσίες όπως το [Pinata](https://pinata.cloud) ή το [Dolpin](https://dolpin.io)

Σου εξοικονομεί πολύ χρόνο! 

--

### Πρόσβαση στον ιστότοπό σου στο IPFS: 

Ο ιστότοπός σου έχει πλέον δημοσιευτεί στο IPFS και μπορείς να έχεις πρόσβαση σε αυτόν χρησιμοποιώντας το hash του φακέλου. Για να αποκτήσεις πρόσβαση στον ιστότοπό σου, μπορείς να επισκεφθείς το https://ipfs.io/ipfs/"hash" 

"hash" = CID του φακέλου.

Στην περίπτωσή μας, το CID = "QmW2UEfap1vrRRvS5H9wed8qmsx4WsvXBk3GPGVVfWx3r3"


## IPNS 

Το Interplanetary Naming System (IPNS) σου επιτρέπει να ενημερώνεις τα CID του IPFS που σχετίζονται με τον ιστότοπό σου και να εξακολουθείς να παρέχεις έναν στατικό σύνδεσμο. Παρέχεται ως κλειδί. 

![](/content-images/dns-query.a0134a75-9ef7817f80.webp)

Στο μενού ρυθμίσεων για τον φάκελο του ιστότοπού σου στην εφαρμογή IPFS Desktop, επίλεξε Publish to IPNS.  

![](/content-images/IPNS-2fe62cc369.webp)

Κλειδί: "k51qzi5uqu5di670a6uxywo17b2be1eyhoa2cl0qlwpfxn5p9ypcu8jbzgnj4n"

Μπορεί επίσης να χρησιμοποιηθεί για την προβολή του ιστότοπού μας μέσω ενός gateway: https://ipfs.io/ipns/k51qzi5uqu5di670a6uxywo17b2be1eyhoa2cl0qlwpfxn5p9ypcu8jbzgnj4n


## Σύνδεσμος DNS 
 
Ο ιστότοπος έχει δημιουργηθεί, τώρα χρειαζόμαστε έναν τρόπο να κατευθύνουμε ένα URL προς το περιεχόμενο. 

Αν έχεις ήδη μια διεύθυνση ιστού, μπορείς να προσθέσεις μια νέα εγγραφή χρησιμοποιώντας την εγγραφή TXT "_dnslink(your domain)". Ανάλογα με τον πάροχο, μπορεί να συμπληρωθεί αυτόματα. 

![](/content-images/example-c2a9edb28b.webp)

Θα χρειαστεί χρόνος για να διαδοθεί στο δίκτυο προτού μπορέσεις να το δεις.
