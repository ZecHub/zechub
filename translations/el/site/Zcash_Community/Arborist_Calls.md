# Arborist Calls

Οι Zcash Arborist Calls είναι επαναλαμβανόμενες συναντήσεις ανάπτυξης πρωτοκόλλου που εστιάζουν στον σχεδιασμό αναβαθμίσεων δικτύου, στην εργασία υλοποίησης κόμβων συναίνεσης, στις εξαρτήσεις πορτοφολιών και υποδομών, καθώς και στην έρευνα πρωτοκόλλου.

Η επίσημη σελίδα του Arborist Calls συντηρείται από το Zcash Foundation:

**[https://zfnd.org/arborist-calls/](https://zfnd.org/arborist-calls/)****

## Πώς να συμμετάσχεις

Οι κλήσεις εναλλάσσονται μεταξύ δύο επαναλαμβανόμενων ωρών, ώστε να μπορούν να συμμετέχουν συνεισφέροντες από διαφορετικές περιοχές. Χρησιμοποίησε την επίσημη σελίδα του Zcash Foundation για τα τρέχοντα αρχεία ημερολογίου και τους συνδέσμους Zoom:

- **15:00 UTC** ώρα

Η σελίδα του Foundation είναι η έγκυρη πηγή για συνδέσμους εγγραφής, αρχεία ημερολογίου και πρόσβαση στις συναντήσεις, επειδή οι σύνδεσμοι των συναντήσεων μπορεί να αλλάξουν.

## Ποιοι πρέπει να συμμετάσχουν

Οι Arborist Calls είναι χρήσιμες για:

- Μηχανικούς και ερευνητές πρωτοκόλλου
- Προγραμματιστές κόμβων, πορτοφολιών, SDK και υποδομών lightwallet
- Αποδέκτες επιχορηγήσεων των οποίων η εργασία αφορά τη συναίνεση, αναβαθμίσεις δικτύου ή εξαρτήσεις πρωτοκόλλου
- Μέλη της κοινότητας που θέλουν να παρακολουθούν δημόσια τη λήψη τεχνικών αποφάσεων
