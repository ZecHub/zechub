# Τι είναι οι TEX διευθύνσεις του Zcash;

## TL;DR

* Μια TEX διεύθυνση είναι μια διαφανής διεύθυνση Zcash γραμμένη σε διαφορετική μορφή. Αρχίζει με `tex1` και ορίζεται στο [ZIP 320](https://zips.z.cash/zip-0320).
* Λέει στο πορτοφόλι σου ένα πράγμα: πλήρωσε αυτή τη διεύθυνση μόνο με διαφανή κεφάλαια.
* Αν το υπόλοιπό σου είναι θωρακισμένο, ένα συμβατό πορτοφόλι εκτελεί δύο βήματα για εσένα. Μετακινεί το ποσό σε μια προσωρινή διαφανή διεύθυνση και έπειτα το στέλνει στην TEX διεύθυνση.
* Το 2023, το Binance ζήτησε από την κοινότητα του Zcash έναν τρόπο να απορρίπτει θωρακισμένες καταθέσεις και να τις επιστρέφει. Οι TEX διευθύνσεις είναι η απάντηση, και το Binance είναι το ανταλλακτήριο στη λίστα ZecHub [Custodial Exchanges](/using-zcash/custodial-exchanges) που δέχεται TEX καταθέσεις.
* Μια πληρωμή σε TEX διεύθυνση είναι δημόσια στο blockchain, όπως κάθε διαφανής πληρωμή. Το υπόλοιπο θωρακισμένο υπόλοιπό σου παραμένει ιδιωτικό.

## Βασική εξήγηση

Μια TEX διεύθυνση Zcash είναι ένας ειδικός τύπος διεύθυνσης λήψης. Το TEX σημαίνει «Transparent Exchange». Είναι μια επανακωδικοποίηση Bech32m μιας μεμονωμένης διαφανούς διεύθυνσης p2pkh. Οι TEX διευθύνσεις αρχίζουν με `tex1` και αποτελούν ξεχωριστό τύπο από τις Unified Addresses.

Μια TEX διεύθυνση λέει σε ένα συμβατό πορτοφόλι να πραγματοποιήσει μια συναλλαγή μόνο διαφανών κεφαλαίων (T -> T). 

Η λογική είναι η εξής: Όταν ένα συμβατό πορτοφόλι εντοπίζει μια TEX διεύθυνση, την αποκωδικοποιεί για να λάβει τον διαφανή παραλήπτη που περιέχει. Έπειτα, το πορτοφόλι στέλνει τα απαιτούμενα κεφάλαια για τη συναλλαγή από το θωρακισμένο pool σε μια ξεχωριστή, ελεγχόμενη από εσένα, εφήμερη διαφανή διεύθυνση (Z -> T). Στη συνέχεια στέλνει αυτά τα κεφάλαια στον αποκωδικοποιημένο διαφανή παραλήπτη της TEX διεύθυνσης (T -> T).  

Η τεχνική πρόταση για τις TEX διευθύνσεις περιγράφεται στο Zcash [ZIP 320](https://zips.z.cash/zip-0320), το οποίο ορίζει έναν τύπο διεύθυνσης αποκλειστικά για τη λήψη κεφαλαίων από διαφανείς διευθύνσεις.

![TEX](/content-images/ZashiTex-b1cbec5f07.webp)

Οι TEX διευθύνσεις δεν έχουν ακόμη υιοθετηθεί ευρέως. Οι χρήστες του Zcash ενδέχεται τελικά να υποχρεωθούν να τις χρησιμοποιούν.

### Πότε χρειάζομαι μια TEX διεύθυνση

#### Χρειάζεσαι μια TEX διεύθυνση όταν στέλνεις κεφάλαια σε διαφανή διεύθυνση χρησιμοποιώντας πορτοφόλι που δεν υποστηρίζει απευθείας αποστολή σε διαφανή διεύθυνση.

Ορισμένα πορτοφόλια δεν επιτρέπουν την απευθείας αποστολή σε διαφανή διεύθυνση και ο παραλήπτης μπορεί να μη διαθέτει ισοδύναμη TEX διεύθυνση. Επομένως, μερικές φορές μπορεί να απαιτείται μετατροπή από διαφανή σε TEX διεύθυνση. Αυτό μπορεί να επιτευχθεί χειροκίνητα εκτελώντας την υλοποίηση αναφοράς που περιγράφεται στο [zip-320](https://zips.z.cash/zip-0320#reference-implementation).

#### Χρειάζεσαι μια TEX διεύθυνση όταν στέλνεις κεφάλαια σε κεντρικοποιημένο ανταλλακτήριο που απαιτεί αυτά τα κεφάλαια να προέρχονται από διαφανή πηγή.

Το [Binance](https://www.binance.com/) είναι ο λόγος ύπαρξης των TEX διευθύνσεων. Τον Νοέμβριο του 2023, ενημέρωσε την κοινότητα του Zcash ότι το ZEC θα μπορούσε να διαγραφεί από τη λίστα, εκτός αν υπήρχε τρόπος να απορρίπτονται καταθέσεις από θωρακισμένες διευθύνσεις και να επιστρέφονται στον καταθέτη ([ZIP 320, Υπόβαθρο](https://zips.z.cash/zip-0320#background)). Το ZIP 320 δεν αναμένει ότι άλλα ανταλλακτήρια θα εκδώσουν TEX διευθύνσεις, εκτός αν χρειάζεται να γνωρίζουν από ποια διεύθυνση προήλθε μια πληρωμή. Το Binance είναι το ανταλλακτήριο στη λίστα μας [Custodial Exchanges](/using-zcash/custodial-exchanges) που δέχεται καταθέσεις σε TEX διεύθυνση.
Οι TEX διευθύνσεις ενημερώνουν ένα συμβατό πορτοφόλι ότι όλα τα κεφάλαια που αποστέλλονται σε αυτή τη διεύθυνση πρέπει να είναι διαφανή και αποκλείουν κάθε θωρακισμένη αξία από την αποστολή στην εν λόγω διεύθυνση.
Αν ένα ανταλλακτήριο όπως το Binance απορρίψει την αποσταλμένη αξία, διαθέτει τα απαραίτητα μέσα για να επιστρέψει αυτή την αξία στη διεύθυνση από την οποία προήλθε. Βοηθά επίσης οντότητες όπως το Binance να συμμορφώνονται με τους νόμους και τους κανονισμούς που επιβάλλουν κυβερνήσεις ή άλλες αρχές.

### Ποια πορτοφόλια υποστηρίζουν TEX διευθύνσεις;

Μπορείς να δεις την πιο ενημερωμένη λίστα στη σελίδα μας [πορτοφόλια](/using-zcash/wallets). Χρησιμοποίησε το φίλτρο TEX Address.

## Οπτική αναλογία

Σκέψου το θωρακισμένο υπόλοιπό σου ως χρήματα σε ένα κλειδωμένο χρηματοκιβώτιο στο σπίτι. Κανείς εκτός δεν μπορεί να δει πόσα βρίσκονται μέσα.

Ένα ανταλλακτήριο όπως το Binance έχει μια πινακίδα στον γκισέ του: δέχονται πληρωμές μόνο σε διάφανο φάκελο, ώστε ο ταμίας να μπορεί να δει από πού προήλθαν τα χρήματα και να τα επιστρέψει αν χρειαστεί. Η TEX διεύθυνση είναι αυτή η πινακίδα.

Όταν το πορτοφόλι σου δει την πινακίδα, βγάζει το ποσό από το χρηματοκιβώτιο, το τοποθετεί σε έναν διάφανο φάκελο με τη διεύθυνση επιστροφής σου επάνω του (την προσωρινή διαφανή διεύθυνση) και μεταφέρει τον φάκελο στον γκισέ. Το χρηματοκιβώτιο παραμένει κλειδωμένο και κανείς δεν μαθαίνει τι άλλο περιέχει.

## Αναλυτική εξέταση

### Πώς κατασκευάζεται μια TEX διεύθυνση

Μια κανονική διαφανής διεύθυνση που αρχίζει με `t1` περιέχει ένα hash κλειδιού 20 byte, γραμμένο σε Base58Check. Μια TEX διεύθυνση περιέχει τα ίδια 20 byte, επανακωδικοποιημένα σε Bech32m με το πρόθεμα `tex` (`textest` στο testnet). Η μετατροπή της μίας στην άλλη απαιτεί λίγες γραμμές κώδικα, τις οποίες το ZIP 320 δείχνει στην υλοποίηση αναφοράς του.

Ο απλός σχεδιασμός ήταν απαίτηση του Binance: η μετατροπή έπρεπε να εκτελείται μόνο με βιβλιοθήκες Base58Check και Bech32m στον κώδικα front-end του ανταλλακτηρίου. Ένα προηγούμενο προσχέδιο του ZIP 320 ενσωμάτωνε την ιδέα στις Unified Addresses και αυτή η έκδοση εγκαταλείφθηκε για αυτόν τον λόγο.

### Πληρωμή μιας TEX διεύθυνσης από θωρακισμένο υπόλοιπο

Το ZIP 320 απαιτεί από ένα συμβατό πορτοφόλι να δημιουργήσει εδώ δύο συναλλαγές. Η πρώτη μετακινεί τα κεφάλαια από το θωρακισμένο υπόλοιπό σου σε μια νέα εφήμερη διαφανή διεύθυνση. Η δεύτερη τα στέλνει από εκείνη τη διεύθυνση στην TEX διεύθυνση.

Αν το ανταλλακτήριο απορρίψει την κατάθεση, επιστρέφει τα κεφάλαια στην εφήμερη διεύθυνση. Το πορτοφόλι σου πρέπει να μπορεί να τα βρει και να τα ξοδέψει, επομένως το ZIP 320 ζητά από τα πορτοφόλια να παράγουν εφήμερες διευθύνσεις από τη φράση ανάκτησης σου. Ζητά επίσης από τα πορτοφόλια να χρησιμοποιούν κάθε φορά μια νέα εφήμερη διεύθυνση, ώστε ξεχωριστές πληρωμές να μην μπορούν να συνδεθούν μεταξύ τους.

### Τι δείχνει το blockchain

Ο κανόνας TEX εφαρμόζεται στα πορτοφόλια. Οι κόμβοι δεν τον ελέγχουν, επομένως οι κανόνες συναίνεσης παραμένουν ίδιοι. On-chain, μια πληρωμή σε TEX διεύθυνση μοιάζει ίδια με μια πληρωμή στην αντίστοιχη διεύθυνση `t1`. Το ποσό, η εφήμερη διεύθυνση και η διεύθυνση του ανταλλακτηρίου είναι δημόσια, όπως σε κάθε διαφανή συναλλαγή.
