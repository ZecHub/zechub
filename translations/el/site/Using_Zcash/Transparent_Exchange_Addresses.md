# Τι είναι οι διευθύνσεις TEX του Zcash;

## Με λίγα λόγια

* Μια διεύθυνση TEX είναι μια διαφανής διεύθυνση Zcash γραμμένη σε διαφορετική μορφή. Αρχίζει με `tex1` και ορίζεται στο [ZIP 320](https://zips.z.cash/zip-0320).
* Λέει ένα πράγμα στο πορτοφόλι σου: πλήρωσε αυτή τη διεύθυνση μόνο με διαφανή κεφάλαια.
* Αν το υπόλοιπό σου είναι θωρακισμένο, ένα συμβατό πορτοφόλι εκτελεί δύο βήματα για σένα. Μεταφέρει το ποσό σε μια προσωρινή διαφανή διεύθυνση και έπειτα το στέλνει στη διεύθυνση TEX.
* Το 2023, το Binance ζήτησε από την κοινότητα του Zcash έναν τρόπο να απορρίπτει θωρακισμένες καταθέσεις και να τις επιστρέφει. Οι διευθύνσεις TEX είναι η απάντηση, και το Binance είναι το ανταλλακτήριο στη λίστα ZecHub [Custodial Exchanges](/using-zcash/custodial-exchanges) που δέχεται καταθέσεις TEX.
* Η υποστήριξη έχει αυξηθεί και από την πλευρά της αποστολής: το Coinbase επιτρέπει στους χρήστες του να στέλνουν ZEC σε διευθύνσεις TEX και τα εργαλεία ανάπτυξης πορτοφολιών προσθέτουν υποστήριξη για το ZIP 320.
* Μια πληρωμή σε διεύθυνση TEX είναι δημόσια στο blockchain, όπως κάθε διαφανής πληρωμή. Το υπόλοιπο θωρακισμένο υπόλοιπό σου παραμένει ιδιωτικό.

## Βασική εξήγηση

Μια διεύθυνση TEX του Zcash είναι ένας ειδικός τύπος διεύθυνσης λήψης. TEX σημαίνει «Transparent Exchange». Είναι μια επανακωδικοποίηση Bech32m μιας μεμονωμένης διαφανούς διεύθυνσης p2pkh. Οι διευθύνσεις TEX αρχίζουν με `tex1` και αποτελούν ξεχωριστό τύπο από τις Unified Addresses.

Μια διεύθυνση TEX λέει σε ένα συμβατό πορτοφόλι να δημιουργήσει μια συναλλαγή μόνο διαφανών κεφαλαίων (T -> T). 

Η λογική είναι η εξής: Όταν ένα συμβατό πορτοφόλι εντοπίζει μια διεύθυνση TEX, την αποκωδικοποιεί για να λάβει τον διαφανή παραλήπτη που περιέχει. Στη συνέχεια, το πορτοφόλι στέλνει τα απαιτούμενα κεφάλαια για τη συναλλαγή από το θωρακισμένο pool σε μια ξεχωριστή, ελεγχόμενη από τον χρήστη, προσωρινή διαφανή διεύθυνση (Z -> T). Έπειτα στέλνει αυτά τα κεφάλαια στον αποκωδικοποιημένο διαφανή παραλήπτη της διεύθυνσης TEX (T -> T).  

Η τεχνική πρόταση για τις διευθύνσεις TEX περιγράφεται στο Zcash [ZIP 320](https://zips.z.cash/zip-0320), το οποίο ορίζει έναν τύπο διεύθυνσης αποκλειστικά για τη λήψη κεφαλαίων από διαφανείς διευθύνσεις.

### Πόσο ευρέως χρησιμοποιούνται οι διευθύνσεις TEX;

Η υιοθέτηση εξακολουθεί να είναι μερική, αλλά δεν περιορίζεται πλέον σε ένα μόνο ανταλλακτήριο. Αξίζει να διαχωρίσουμε δύο διαφορετικούς ρόλους:

* **Έκδοση διευθύνσεων κατάθεσης TEX.** Το Binance είναι το ανταλλακτήριο στη λίστα μας [Custodial Exchanges](/using-zcash/custodial-exchanges) που παρέχει μια διεύθυνση TEX για καταθέσεις, ώστε τα κεφάλαια να φτάνουν από διαφανή πηγή ([ZIP 320, Ιστορικό](https://zips.z.cash/zip-0320#background)). Το ZIP 320 δεν αναμένει από άλλα ανταλλακτήρια να εκδίδουν διευθύνσεις TEX, εκτός αν χρειάζονται να γνωρίζουν από ποια διεύθυνση προήλθε μια πληρωμή.
* **Αποστολή σε διευθύνσεις TEX.** Αυτή είναι η πλευρά που έχει αναπτυχθεί. Τον Οκτώβριο του 2024, το Coinbase ανακοίνωσε ότι οι χρήστες του Coinbase.com μπορούν να στέλνουν Zcash σε διευθύνσεις TEX ([Coinbase Ανακοίνωση Assets](https://x.com/CoinbaseAssets/status/1844428577921507416)). Τα εργαλεία ανάπτυξης πορτοφολιών προσθέτουν επίσης υποστήριξη για το ZIP 320: το KeepKey πρόσθεσε υπογραφή για συναλλαγές TEX στο firmware 7.15 ([keepkey/hdwallet #75](https://github.com/keepkey/hdwallet/pull/75)), και η βιβλιοθήκη XChainJS `zcash-js` διορθώθηκε αφού απέρριπτε έγκυρους παραλήπτες `tex1` (περισσότερα παρακάτω).

Επομένως, οι διευθύνσεις TEX δεν είναι καθολικές, αλλά δεν θα πρέπει πλέον να υποθέτεις ότι το Binance είναι το μόνο μέρος όπου εμφανίζονται.

### Πότε χρειάζομαι μια διεύθυνση TEX

#### Χρειάζεσαι μια διεύθυνση TEX όταν στέλνεις κεφάλαια σε μια διαφανή διεύθυνση χρησιμοποιώντας ένα πορτοφόλι που δεν υποστηρίζει απευθείας αποστολή σε διαφανή διεύθυνση.

Ορισμένα πορτοφόλια δεν επιτρέπουν την απευθείας αποστολή σε διαφανή διεύθυνση και ο παραλήπτης μπορεί να μην παρέχει ισοδύναμο TEX. Επομένως, κατά καιρούς μπορεί να απαιτείται μετατροπή από διαφανή διεύθυνση σε διεύθυνση TEX. Αυτό μπορεί να επιτευχθεί χειροκίνητα εκτελώντας την υλοποίηση αναφοράς που περιγράφεται στο [zip-320](https://zips.z.cash/zip-0320#reference-implementation).

#### Χρειάζεσαι μια διεύθυνση TEX όταν στέλνεις κεφάλαια σε ένα κεντρικοποιημένο ανταλλακτήριο που απαιτεί αυτά τα κεφάλαια να προέρχονται από διαφανή πηγή.

Το [Binance](https://www.binance.com/) είναι ο λόγος που υπάρχουν οι διευθύνσεις TEX. Τον Νοέμβριο του 2023, ενημέρωσε την κοινότητα του Zcash ότι το ZEC θα μπορούσε να διαγραφεί από τη λίστα, εκτός αν υπήρχε τρόπος να απορρίπτονται καταθέσεις από θωρακισμένες διευθύνσεις και να επιστρέφονται στον καταθέτη ([ZIP 320, Ιστορικό](https://zips.z.cash/zip-0320#background)). Το ZIP 320 δεν αναμένει από άλλα ανταλλακτήρια να εκδίδουν διευθύνσεις TEX, εκτός αν χρειάζονται να γνωρίζουν από ποια διεύθυνση προήλθε μια πληρωμή. Το Binance είναι το ανταλλακτήριο στη λίστα μας [Custodial Exchanges](/using-zcash/custodial-exchanges) που δέχεται καταθέσεις σε διεύθυνση TEX.
Οι διευθύνσεις TEX ενημερώνουν ένα συμβατό πορτοφόλι ότι όλα τα κεφάλαια που αποστέλλονται σε αυτή τη διεύθυνση πρέπει να είναι διαφανή και αποκλείουν την αποστολή κάθε θωρακισμένης αξίας στην εν λόγω διεύθυνση.
Αν ένα ανταλλακτήριο όπως το Binance απορρίψει την αποσταλμένη αξία, διαθέτει τα απαραίτητα μέσα για να την επιστρέψει στη διεύθυνση από την οποία προήλθε. Βοηθά επίσης οντότητες όπως το Binance να συμμορφώνονται με τους νόμους και τους κανονισμούς που επιβάλλονται από κυβερνήσεις ή άλλες αρχές.

### Ποια πορτοφόλια υποστηρίζουν διευθύνσεις TEX;

Μπορείς να δεις την πιο ενημερωμένη λίστα στη σελίδα μας [wallets](/using-zcash/wallets). Χρησιμοποίησε το φίλτρο TEX Address.

## Οπτική αναλογία

Σκέψου το θωρακισμένο υπόλοιπό σου ως χρήματα σε ένα κλειδωμένο χρηματοκιβώτιο στο σπίτι. Κανείς έξω δεν μπορεί να δει πόσα υπάρχουν μέσα.

Ένα ανταλλακτήριο όπως το Binance έχει μια πινακίδα στον πάγκο του: γίνονται δεκτές πληρωμές μόνο σε διαφανή φάκελο, ώστε ο ταμίας να βλέπει από πού προήλθαν τα χρήματα και να μπορεί να τα επιστρέψει αν χρειαστεί. Η διεύθυνση TEX είναι αυτή η πινακίδα.

Όταν το πορτοφόλι σου βλέπει την πινακίδα, βγάζει το ποσό από το χρηματοκιβώτιο, το βάζει σε έναν διαφανή φάκελο με τη διεύθυνση επιστροφής σου επάνω του (την προσωρινή διαφανή διεύθυνση) και μεταφέρει τον φάκελο στον πάγκο. Το χρηματοκιβώτιο παραμένει κλειδωμένο και κανείς δεν μαθαίνει τι άλλο υπάρχει μέσα.

## Αναλυτική εξέταση

### Πώς δημιουργείται μια διεύθυνση TEX

Μια κανονική διαφανής διεύθυνση που αρχίζει με `t1` περιέχει ένα hash κλειδιού 20 byte, γραμμένο σε Base58Check. Μια διεύθυνση TEX περιέχει τα ίδια 20 byte, επανακωδικοποιημένα σε Bech32m με το πρόθεμα `tex` (`textest` στο testnet). Η μετατροπή της μίας στην άλλη απαιτεί λίγες γραμμές κώδικα, τις οποίες δείχνει το ZIP 320 στην υλοποίηση αναφοράς του.

Ο απλός σχεδιασμός ήταν απαίτηση του Binance: η μετατροπή έπρεπε να εκτελείται μόνο με βιβλιοθήκες Base58Check και Bech32m στον κώδικα front-end του ανταλλακτηρίου. Ένα προηγούμενο προσχέδιο του ZIP 320 ενσωμάτωνε την ιδέα στις Unified Addresses και αυτή η έκδοση εγκαταλείφθηκε για αυτόν τον λόγο.

Οι διευθύνσεις TEX δανείζονται την κωδικοποίηση Bech32m από τη μορφή Unified Address, αλλά διατηρούν σχεδόν τίποτα από τη δομή της. Αν είσαι νέος στο Bech32m και στον τρόπο επικύρωσης των διευθύνσεων Zcash, η σελίδα [Unified Addresses](/using-zcash/unified-addresses) καλύπτει τα βασικά στο [ZIP 316](https://zips.z.cash/zip-0316). Μια διεύθυνση TEX διαφέρει από ένα Unified Address με τέσσερις συγκεκριμένους τρόπους:

| | Unified Address (ZIP 316) | Διεύθυνση TEX (ZIP 320) |
|---|---|---|
| Τι περιέχει | πολλούς παραλήπτες ομαδοποιημένους μαζί | έναν μεμονωμένο διαφανή παραλήπτη P2PKH |
| Αναγνώσιμο από ανθρώπους πρόθεμα (HRP) | `u` (mainnet) | `tex` (`textest` στο testnet) |
| Απόκρυψη F4Jumble | ναι | όχι |
| Typecodes για κάθε παραλήπτη | ναι | όχι |

Με λίγα λόγια, μια διεύθυνση TEX είναι το απλούστερο δυνατό περιτύλιγμα Bech32m: ένα διαφανές hash κλειδιού, ένα πρόθεμα `tex` και τίποτα άλλο.

### Κανόνες χειρισμού για πορτοφόλια και ενσωματωτές

Αυτό είναι το μέρος στο οποίο οι υλοποιήσεις κάνουν λάθη, επομένως αξίζει να διατυπωθεί ξεκάθαρα. Κατά τον εντοπισμό μιας διεύθυνσης TEX, ένα πορτοφόλι ή ένας ενσωματωτής **δεν πρέπει να δαπανά απευθείας από το θωρακισμένο pool προς τον προορισμό TEX.** Το ZIP 320 απαιτεί κάθε είσοδο μιας πληρωμής TEX να είναι διαφανής, επομένως η πληρωμή δημιουργείται σε δύο βήματα:

1. **Αποθωράκιση.** Μετέφερε το ποσό από το θωρακισμένο pool σε μια νέα, ελεγχόμενη από τον χρήστη προσωρινή διαφανή διεύθυνση που ανήκει στο πορτοφόλι σου (Z -> T).
2. **Αποστολή από διαφανή σε διαφανή.** Δαπάνησε αυτή την προσωρινή έξοδο στον αποκωδικοποιημένο παραλήπτη P2PKH μέσα στη διεύθυνση TEX (T -> T).

Μερικοί κανόνες καθιστούν αυτή τη διαδικασία ασφαλή, όλοι από το ZIP 320:

* Η προσωρινή διεύθυνση θα πρέπει να παράγεται από τη φράση ανάκτησης σου, ώστε αν το ανταλλακτήριο επιστρέψει τα κεφάλαια, το πορτοφόλι σου να μπορεί ακόμη να τα βρει και να τα δαπανήσει.
* Θα πρέπει να χρησιμοποιείται κάθε φορά μια νέα προσωρινή διεύθυνση, ώστε ξεχωριστές πληρωμές να μην μπορούν να συνδεθούν μεταξύ τους.
* Η δεύτερη συναλλαγή θα πρέπει να δαπανά μόνο διαφανείς εισόδους, ώστε το ανταλλακτήριο να βλέπει μια καθαρή κατάθεση από διαφανή σε διαφανή.

Η μετατροπή και η ροή των δύο βημάτων παρουσιάζονται στην [ZIP υλοποίηση αναφοράς του 320](https://zips.z.cash/zip-0320#reference-implementation). Το να γίνει αυτό λάθος είναι ένα πραγματικό, πρόσφατο πρόβλημα: τον Οκτώβριο του 2026 η βιβλιοθήκη XChainJS `zcash-js` απέρριπτε έγκυρους παραλήπτες `tex1` με σφάλμα «Μη έγκυρη διεύθυνση “to”», επειδή ο επικυρωτής της δεχόταν μόνο τη μορφή Base58Check `t1`, κάτι που εμπόδιζε καταθέσεις ZEC σε υπηρεσίες που δημοσιεύουν μια διεύθυνση `tex1` ([issue #1782](https://github.com/xchainjs/xchainjs-lib/issues/1782)). Διορθώθηκε διδάσκοντας τον επικυρωτή να δέχεται την κωδικοποίηση του ZIP 320 ([PR #1783](https://github.com/xchainjs/xchainjs-lib/pull/1783)).

### Τι αποκαλύπτει μια αποστολή TEX

Μια πληρωμή TEX είναι διαφανής πληρωμή, άρα είναι δημόσια, αλλά αξίζει να είμαστε ακριβείς σχετικά με το τι μπορεί και τι δεν μπορεί να δει ένας παρατηρητής.

Τι είναι **ορατό** on-chain:

* Η προσωρινή διαφανής διεύθυνση, καθώς εμφανίζεται ως έξοδος του βήματος αποθωράκισης και ως είσοδος της τελικής αποστολής.
* Και τα δύο ποσά: η αξία που έφυγε από το θωρακισμένο pool στο βήμα Z -> T και η αξία που παραδόθηκε στο βήμα T -> T.
* Ο διαφανής παραλήπτης του ανταλλακτηρίου, δηλαδή η διεύθυνση P2PKH που κωδικοποιείται στη διεύθυνση TEX.

Τι παραμένει **κρυφό**:

* Το υπόλοιπο θωρακισμένο υπόλοιπό σου και το ποια συγκεκριμένα θωρακισμένα notes χρηματοδότησαν την πληρωμή. Το βήμα αποθωράκισης αποκαλύπτει ότι *κάποια* αξία έφυγε από το pool προς την προσωρινή διεύθυνση, όχι από πού μέσα στο pool προήλθε.

Επομένως, ένας παρατηρητής μπορεί να συνδέσει την προσωρινή διεύθυνση με την πληρωμή στο ανταλλακτήριο (τα ίδια κεφάλαια, από διαφανή σε διαφανή) και μπορεί να δει ότι τροφοδοτήθηκε από θωρακισμένη ανάληψη. Δεν μπορεί να τη συνδέσει με τα άλλα θωρακισμένα κεφάλαια ή τη δραστηριότητά σου. Τίποτα on-chain δεν επισημαίνει πραγματικά την πληρωμή ως αποστολή «TEX»: όπως σημειώνει το ZIP 320, μια πληρωμή σε διεύθυνση TEX δεν διακρίνεται από μια πληρωμή στην αντίστοιχη διεύθυνση `t1`, επειδή οι κανόνες συναίνεσης παραμένουν αμετάβλητοι και ολόκληρος ο κανόνας βρίσκεται στο πορτοφόλι.

![On-chain footprint of a TEX send: funds leave the shielded pool to an ephemeral transparent address, then go transparent-to-transparent to the exchange; the ephemeral address, both amounts and the exchange address are visible, while the rest of the shielded balance stays hidden](/content-images/tex-onchain-footprint.webp)

### Τι δείχνει το blockchain

Ο κανόνας TEX βρίσκεται στα πορτοφόλια. Οι κόμβοι δεν τον ελέγχουν, επομένως οι κανόνες συναίνεσης παραμένουν οι ίδιοι. On-chain, μια πληρωμή σε διεύθυνση TEX μοιάζει με μια πληρωμή στην αντίστοιχη διεύθυνση `t1`. Το ποσό, η προσωρινή διεύθυνση και η διεύθυνση του ανταλλακτηρίου είναι δημόσια, όπως σε κάθε διαφανή συναλλαγή.

## Σχετικές σελίδες

- [Unified Addresses](/using-zcash/unified-addresses): η μορφή διεύθυνσης `u1` στο ZIP 316 και τα βασικά του Bech32m που επαναχρησιμοποιεί μια διεύθυνση TEX.
- [Custodial Exchanges](/using-zcash/custodial-exchanges): ποια ανταλλακτήρια δέχονται ποιους τύπους διευθύνσεων, συμπεριλαμβανομένων των καταθέσεων TEX του Binance.
- [Wallets](/using-zcash/wallets): χρησιμοποίησε το φίλτρο TEX Address για να βρεις πορτοφόλια που μπορούν να πληρώσουν μια διεύθυνση TEX.
- [Shielded Pools](/using-zcash/shielded-pools): πού βρίσκεται το ιδιωτικό υπόλοιπό σου πριν μια πληρωμή TEX μεταφέρει μέρος του εκτός.
- [Ποιος μπορεί να δει την πληρωμή σου Zcash](/start-here/who-can-see-your-zcash-payment): τι γίνεται ορατό μόλις τα κεφάλαια εγκαταλείψουν το θωρακισμένο pool.
- [Τι μπορεί να δει ένα Block Explorer](/zcash-tech/what-a-block-explorer-can-see): πώς εμφανίζεται on-chain μια διαφανής πληρωμή.
- [Zcash URI αιτήματος πληρωμής](/using-zcash/payment-request-uris): ένα ακόμη πρότυπο πορτοφολιού για προσυμπληρωμένες πληρωμές.
