# Οδηγός γρήγορης αναφοράς Zallet

## Με λίγα λόγια

- Το Zallet είναι ένα θωρακισμένο πορτοφόλι πλήρους κόμβου Zcash, γραμμένο σε Rust. Αντικαθιστά το πορτοφόλι που βρισκόταν παλαιότερα μέσα στο zcashd.
- Το zcashd έφτασε τη διακοπή End-of-Support στις 18 Ιουλίου 2026 και δεν εκτελείται πλέον. Το Zebra διαχειρίζεται πλέον την πλευρά του κόμβου· το Zallet διαχειρίζεται την πλευρά του πορτοφολιού.
- Χειρίζεσαι το Zallet από τη γραμμή εντολών με το `zallet rpc <command>`, όπως χρησιμοποιούσες παλαιότερα το `zcash-cli`.
- Κάθε όρισμα μετά το όνομα της εντολής πρέπει να είναι έγκυρο JSON, πράγμα που σημαίνει ότι οι τιμές συμβολοσειρών διατηρούν τα διπλά εισαγωγικά τους.
- Το Zallet βρίσκεται σε beta. Οι εντολές μπορούν να αλλάζουν μεταξύ εκδόσεων και δεν έχει μεταφερθεί ακόμη κάθε RPC του zcashd.

## Βασική επεξήγηση

Το Zallet εκθέτει τη λειτουργικότητά του μέσω JSON-RPC, το ίδιο στυλ διεπαφής που χρησιμοποιούσε το πορτοφόλι zcashd. Οτιδήποτε θέλεις να κάνει το πορτοφόλι — να ελέγξει ένα υπόλοιπο, να δημιουργήσει έναν λογαριασμό, να στείλει μια θωρακισμένη πληρωμή — είναι μια εντολή που δίνεις στο `zallet rpc`.

Δύο πράγματα διαφέρουν από την παλιά συνήθεια του `zcash-cli` και ευθύνονται για τα περισσότερα πρώιμα λάθη. Πρώτον, τα ορίσματα πρέπει να είναι έγκυρο JSON αντί για απλό κείμενο, επομένως ένα όρισμα συμβολοσειράς φέρει τα δικά του εισαγωγικά μέσα στα εισαγωγικά του shell. Δεύτερον, το σύνολο των διαθέσιμων εντολών εξαρτάται από την έκδοση beta που εκτελείς, επομένως η λίστα που είναι ενσωματωμένη στο binary σου είναι πιο αξιόπιστη από οποιαδήποτε γραπτή σελίδα, συμπεριλαμβανομένης αυτής.

Για να εμφανίσεις όλα τα διαθέσιμα RPC:

```bash
zallet rpc help
```

Για να λάβεις λεπτομερή βοήθεια για ένα συγκεκριμένο RPC:

```bash
zallet rpc help '"<command>"'
```

> **Σημαντικό:** Κάθε όρισμα μετά το όνομα της μεθόδου **πρέπει να είναι έγκυρο JSON**.  
> Οι τιμές συμβολοσειρών πρέπει να γράφονται ως `"value"` (συμπεριλαμβανομένων των διπλών εισαγωγικών).

## Συνηθισμένα λάθη

- **Παράλειψη των εσωτερικών εισαγωγικών στα ορίσματα συμβολοσειρών.** Το `zallet rpc validateaddress u1abc...` αποτυγχάνει, επειδή η διεύθυνση πρέπει να φτάσει ως JSON. Πρέπει να γραφτεί ως `'"u1abc..."'`.
- **Υπόθεση ότι κάθε RPC υπάρχει εδώ.** Η μεταφορά βρίσκεται ακόμη σε εξέλιξη. Ορισμένες μέθοδοι συμπεριφέρονται πανομοιότυπα, ορισμένες χρειάζονται διαφορετική χρήση και ορισμένες δεν θα μεταφερθούν καθόλου.
- **Αντιμετώπιση αυτής της σελίδας ως πιο έγκυρης από το binary σου.** Το Zallet βρίσκεται σε beta και αλλάζει γρήγορα. Όταν μια εντολή εδώ δεν λειτουργεί, έλεγξε το `zallet rpc help` προτού υποθέσεις ότι κάτι έχει χαλάσει.
- **Αναμονή ότι το Zallet είναι κόμβος.** Είναι το μισό του πορτοφολιού στο ζεύγος. Το Zebra εκτελεί τον κόμβο και το Zallet επικοινωνεί μαζί του.
