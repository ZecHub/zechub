# <img src="/content-images/image-2024-02-03-173258092-a5440e5ee2.webp" alt="Εναλλακτικό κείμενο" width="50"/>   Custodial ανταλλακτήρια

Το Ironwood είναι το θωρακισμένο pool που ήρθε με την αναβάθμιση δικτύου του Ιουλίου 2026. Τα ανταλλακτήρια που διαχειρίζονται μόνο διαφανείς t-διευθύνσεις δεν έρχονται ποτέ σε επαφή με αυτό, οπότε επισημαίνονται ως μη εφαρμόσιμα. Όπου ένα ανταλλακτήριο διαχειρίζεται θωρακισμένες διευθύνσεις αλλά δεν έχει αναφέρει ποιο pool χρησιμοποιεί, η γραμμή το δηλώνει αντί να γίνεται εικασία.

### [Backpack](https://backpack.exchange)

<a href="https://backpack.exchange">
    <img src="/content-images/_unavailable.svg" alt="Λογότυπο Backpack" width="200" height="100"/>
</a>

- Ιστότοπος: [Backpack](https://backpack.exchange)
- Ζεύγη: ZEC/USDC | ZEC-PERP
- Υποστηρίζει: Οι καταθέσεις και οι αναλήψεις είναι ενεργοποιημένες. Οι τύποι διευθύνσεων δεν αναφέρονται
- Χρόνος κατάθεσης: Δεν αναφέρεται
- Ironwood: Δεν αναφέρεται
