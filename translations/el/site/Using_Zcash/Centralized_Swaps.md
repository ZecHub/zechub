# Κεντρικοποιημένες πλατφόρμες swap

Κάθε επικεφαλίδα `###` παρακάτω είναι μία κάρτα στο https://zechub.wiki/using-zcash/centralizedswaps.
Πρόσθεσε, επεξεργάσου ή αφαίρεσε ένα μπλοκ εδώ· το wiki το εντοπίζει από αυτό το αρχείο.
