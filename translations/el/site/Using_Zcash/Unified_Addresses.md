# Ενοποιημένες διευθύνσεις

> Μία διεύθυνση για όλο το Zcash. Κοινοποίησέ την και το πορτοφόλι του αποστολέα βρίσκει τον πιο ιδιωτικό τρόπο να σε πληρώσει.

## Με λίγα λόγια

* Μια ενοποιημένη διεύθυνση (UA) είναι μία διεύθυνση Zcash που περιέχει αρκετούς δέκτες: Ironwood, Sapling και διαφανείς.
* Οι UA του mainnet αρχίζουν με `u1`. Το ZIP 316 τις όρισε και έφτασαν με την αναβάθμιση NU5 στις 31 Μαΐου 2022.
* Το πορτοφόλι του αποστολέα επιλέγει το πιο ιδιωτικό pool που υποστηρίζουν και τα δύο πορτοφόλια. Δεν επιλέγεις ποτέ εσύ ένα pool.
* Η UA σου συνέχισε να λειτουργεί όταν το pool Ironwood τέθηκε σε λειτουργία τον Ιούλιο του 2026. Δεν χρειάστηκε να κοινοποιήσεις νέα διεύθυνση.
* Το πορτοφόλι σου μπορεί να δημιουργεί μια νέα UA για κάθε αποστολέα και όλες πληρώνουν στον ίδιο λογαριασμό.

## Βασική εξήγηση

Μια ενοποιημένη διεύθυνση (UA) είναι μία μοναδική διεύθυνση Zcash που συνενώνει αρκετούς δέκτες σε μία. Οι δέκτες είναι τα μέρη μιας διεύθυνσης που δέχονται κεφάλαια σε ένα συγκεκριμένο value pool: Ironwood, Sapling και διαφανείς. Μια UA αρχίζει με `u1` στο mainnet και ορίστηκε στο [ZIP 316](https://zips.z.cash/zip-0316), το οποίο εισήχθη με την αναβάθμιση δικτύου NU5 στις 31 Μαΐου 2022.

Πριν από τις ενοποιημένες διευθύνσεις, η λήψη ZEC σήμαινε ότι έπρεπε να σκέφτεσαι τους τύπους διευθύνσεων. Μια διεύθυνση `zs` δεχόταν κεφάλαια Sapling, μια διεύθυνση `t` δεχόταν διαφανή κεφάλαια και η αποστολή μεταξύ τύπων απαιτούσε επιπλέον βήματα. Μια UA το τερματίζει αυτό. Κοινοποιείς μία διεύθυνση και τα πορτοφόλια αναλαμβάνουν τα υπόλοιπα.

### Πώς λειτουργεί

Όταν κάποιος στέλνει στη UA σου, το πορτοφόλι του διαβάζει τους δέκτες που περιέχει και επιλέγει το πιο ιδιωτικό pool που υποστηρίζουν και τα δύο πορτοφόλια:

1. Αν και τα δύο πορτοφόλια υποστηρίζουν το τρέχον θωρακισμένο pool, η πληρωμή φτάνει θωρακισμένη. Τίποτα δημόσιο δεν αγγίζει την αλυσίδα.
2. Αν ο αποστολέας μπορεί να στείλει μόνο από ένα παλαιότερο pool, το πορτοφόλι επιστρέφει στον καλύτερο δέκτη που μοιράζεστε, όπως το Sapling.
3. Αν ο αποστολέας μπορεί να στείλει μόνο διαφανή κεφάλαια, η πληρωμή καταλήγει στον διαφανή δέκτη της UA σου και το πορτοφόλι σου μπορεί να τη θωρακίσει από εκεί.

Δεν διαχειρίζεσαι τίποτα από αυτά εσύ. Η διεύθυνση παραμένει η ίδια· η δρομολόγηση γίνεται μέσα σε αυτήν.

### Γιατί έχει σημασία τώρα

Το Zcash συνεχίζει να αναβαθμίζεται. Όταν το pool Ironwood ενεργοποιήθηκε με το NU6.3 στις 28 Ιουλίου 2026, οι κάτοχοι UA δεν χρειάστηκαν νέα διεύθυνση: τα πορτοφόλια απλώς άρχισαν να επιλέγουν τον δέκτη Ironwood μέσα στις διευθύνσεις που ήδη είχαν. Οι χρήστες που είχαν παλαιότερες αυτόνομες διευθύνσεις έπρεπε να μεταφερθούν. Οι κάτοχοι UA δεν έκαναν τίποτα.

Αυτός είναι ο στόχος του σχεδιασμού. Νέα pools φτάνουν με μελλοντικές αναβαθμίσεις δικτύου και μια ενοποιημένη διεύθυνση τα απορροφά χωρίς να χρειάζεται κανείς να κοινοποιήσει ξανά διευθύνσεις ή να μετακινήσει κεφάλαια με το χέρι. Δες τα [Zcash value pools](/using-zcash/shielded-pools) για την τρέχουσα διάταξη των pools.

### Μια νέα διεύθυνση για κάθε αποστολέα

Τα πορτοφόλια μπορούν να δημιουργούν πολλές διαφοροποιημένες ενοποιημένες διευθύνσεις για έναν λογαριασμό. Κάθε μία πληρώνει στα ίδια κεφάλαια, αλλά καμία δύο δεν μπορούν να συνδεθούν on-chain. Δώσε διαφορετική UA σε κάθε άτομο ή υπηρεσία που σε πληρώνει και κανένα ζευγάρι τους δεν μπορεί να συγκρίνει διευθύνσεις για να μάθει ότι πληρώνουν το ίδιο πορτοφόλι.

## Οπτικοποίηση / Αναλογία

Φαντάσου μια εξώπορτα με τρεις θυρίδες αλληλογραφίας. Η νεότερη θυρίδα ρίχνει τα γράμματα σε ένα κλειδωμένο χρηματοκιβώτιο (Ironwood). Η δεύτερη τα ρίχνει σε ένα κλειδωμένο συρτάρι (Sapling). Η τρίτη τα ρίχνει σε έναν ανοιχτό δίσκο που μπορεί οποιοσδήποτε να διαβάσει από το παράθυρο (διαφανές).

Ο ταχυδρόμος είναι το πορτοφόλι του αποστολέα. Χρησιμοποιεί την πιο ιδιωτική θυρίδα από την οποία χωράει. Δίνεις μία διεύθυνση για την πόρτα και, όταν το σπίτι αποκτήσει νέο χρηματοκιβώτιο, η διεύθυνση στην πόρτα παραμένει η ίδια.

## Εμβάθυνση

### Σχετικά εργαλεία

- **Viewing keys.** Κάθε λογαριασμός έχει ενοποιημένα viewing keys που κοινοποιούν όσα λαμβάνει μια UA (ή όσα στέλνει) χωρίς να κοινοποιούν εξουσία δαπάνης. Προθέματα `uview` και `uivk`. Δες τα [viewing keys](/zcash-tech/viewing-keys).
- **Διευθύνσεις TEX.** Ορισμένα ανταλλακτήρια, επί του παρόντος το Binance, απαιτούν οι καταθέσεις να φτάνουν από διαφανή πηγή. Μια διεύθυνση TEX ([ZIP 320](https://zips.z.cash/zip-0320)) είναι ένα μόνο διαφανές συμπλήρωμα της UA σου ακριβώς για αυτή την περίπτωση. Δες τις [διαφανείς διευθύνσεις ανταλλακτηρίων](/using-zcash/transparent-exchange-addresses).
- **Αιτήματα πληρωμής.** Μια UA μπορεί να ενσωματωθεί σε URI αιτήματος πληρωμής με προσυμπληρωμένα ποσό και σημείωμα. Δες τα [URI αιτημάτων πληρωμής](/using-zcash/payment-request-uris).

### Γρήγορα στοιχεία

| | |
|---|---|
| Πρόθεμα | `u1` (mainnet) |
| Κωδικοποίηση | bech32m |
| Ορίστηκε στο | [ZIP 316](https://zips.z.cash/zip-0316) |
| Εισήχθη | NU5, 31 Μαΐου 2022 |
| Περιέχει | Ironwood, Sapling και διαφανείς δέκτες |
| Spending key | Ένα ανά λογαριασμό, κοινό για όλες τις UA του |

Έλεγξε ποια πορτοφόλια υποστηρίζουν ενοποιημένες διευθύνσεις στη σελίδα [πορτοφολιών](/wallets).

## Συνηθισμένα λάθη

- **Κοινοποίηση παλιάς διεύθυνσης `zs` ή `t`.** Μια αυτόνομη διεύθυνση φτάνει μόνο σε ένα pool και δεν αποκτά νέα. Κοινοποίησε την UA σου.
- **Δίνεις την ίδια UA σε όλους.** Δύο άτομα που σε πληρώνουν μπορούν να συγκρίνουν σημειώσεις και να δουν την ίδια διεύθυνση. Δώσε σε κάθε αποστολέα μια νέα UA από το πορτοφόλι σου.
- **Περιμένεις ότι κάθε πληρωμή σε UA θα είναι ιδιωτική.** Ένας αποστολέας που μπορεί να στείλει μόνο διαφανή κεφάλαια πληρώνει στον διαφανή δέκτη σου και αυτή η πληρωμή είναι δημόσια. Θωράκισέ την έπειτα από το πορτοφόλι σου.
