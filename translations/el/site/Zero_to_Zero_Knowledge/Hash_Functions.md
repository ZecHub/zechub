## Μέρος 1: Συναρτήσεις κατακερματισμού

Σήμερα ξεκινάμε με τις **συναρτήσεις κατακερματισμού** — ένα βασικό κομμάτι της κρυπτογραφίας που χρησιμοποιείται στα blockchain. Αργότερα σε αυτή τη σειρά θα καλύψουμε ορισμένα θέματα που βασίζονται στις ιδιότητές τους.

### Τι είναι μια συνάρτηση κατακερματισμού;

Οι συναρτήσεις κατακερματισμού δέχονται μια είσοδο οποιουδήποτε μήκους και παράγουν μια έξοδο σταθερού μήκους.

- **Μήνυμα προς κατακερματισμό** = Είσοδος  
- **Ο αλγόριθμος που χρησιμοποιείται** = Συνάρτηση κατακερματισμού  
- **Η έξοδος που προκύπτει** = Τιμή κατακερματισμού

### Ιδιότητες των κρυπτογραφικών συναρτήσεων κατακερματισμού

Οι κρυπτογραφικές συναρτήσεις κατακερματισμού πρέπει να έχουν αυτές τις **3 ιδιότητες**:

1. **Μονόδρομη** - Θα πρέπει να είναι ανέφικτη η αντιστροφή μιας συνάρτησης κατακερματισμού  
2. **Ανθεκτική σε συγκρούσεις** - Δύο διαφορετικές είσοδοι δεν πρέπει να κατακερματίζονται στην ίδια έξοδο  
3. **Ντετερμινιστική** - Για οποιαδήποτε είσοδο, μια συνάρτηση κατακερματισμού πρέπει πάντα να δίνει το ίδιο αποτέλεσμα

### Συνήθεις συναρτήσεις κατακερματισμού

Υπάρχουν αρκετές κατηγορίες συναρτήσεων κατακερματισμού. Μερικά παραδείγματα:

- Secure Hashing Algorithm (**SHA-3**)  
- Message Digest Algorithm 5 (**MD5**)  
- **BLAKE2b** - Χρησιμοποιείται στην παραγωγή κλειδιών του Zcash

**Μια εισαγωγή στο BLAKE2**: https://www.blake2.net

### Χρήσεις των συναρτήσεων κατακερματισμού στον πραγματικό κόσμο

#### 1. Κατακερματισμός ακεραιότητας (έλεγχοι ακεραιότητας δεδομένων)
Οι έλεγχοι ακεραιότητας δεδομένων είναι ένα παράδειγμα «κατακερματισμού ακεραιότητας». Χρησιμοποιούνται για την παραγωγή αθροισμάτων ελέγχου σε αρχεία δεδομένων και παρέχουν σε έναν χρήστη διαβεβαίωση ορθότητας.

![Integrity Hashing example](/content-images/Fn_Or0MWIAI6sgx-9aab89b808.webp)

#### 2. Δέντρα Merkle (δέντρα κατακερματισμού)
Ένα **δέντρο κατακερματισμού** ή **δέντρο Merkle** αποτελείται από κλαδιά και κόμβους-φύλλα που επισημαίνονται με τον κρυπτογραφικό κατακερματισμό ενός μπλοκ δεδομένων.

![Merkle Tree diagram](/content-images/Fn_O7ndWIAY5PA-8e30e442ed.webp)

Τα δέντρα Merkle αποτελούν παράδειγμα ενός **σχήματος κρυπτογραφικού commitment**. Η ρίζα του δέντρου θεωρείται commitment και αποδεικνύεται ότι οι κόμβοι-φύλλα αποτελούν μέρος του αρχικού commitment.

Επαληθεύουν δεδομένα που αποθηκεύονται ή μεταφέρονται σε P2P δίκτυα, διασφαλίζοντας ότι τα δεδομένα που λαμβάνονται από ομότιμους δεν έχουν αλλοιωθεί.

#### 3. Δέντρο commitment των note στο Zcash
Στα θωρακισμένα pools Zcash **Sapling** & **Orchard**, το **δέντρο commitment των note** χρησιμοποιείται για να επαληθεύει ότι οι συναλλαγές είναι έγκυρες σύμφωνα με τη συναίνεση, ενώ αποκρύπτει πλήρως τον αποστολέα, τον παραλήπτη και τα ποσά που δαπανώνται.

#### 4. Κατακερματισμός υπογραφής (μπλοκ τύπου Bitcoin)
Το **SHA256** είναι ένα παράδειγμα «κατακερματισμού υπογραφής» που χρησιμοποιείται για την επιβολή της αμεταβλητότητας κάθε μπλοκ στην αλυσίδα του Bitcoin. Οι εξορύκτες χρησιμοποιούν τον κατακερματισμό του προηγούμενου μπλοκ + έναν κατακερματισμό όλων των συναλλαγών στο τρέχον μπλοκ (hashMerkleRoot) + χρονική σήμανση + τυχαία τιμή / δυσκολία δικτύου για νέα μπλοκ.

![SHA256 block diagram](/content-images/Fn_PaVZXoAApHPf-936e479067.webp)

#### 5. Equihash (εξόρυξη Zcash)
Το **Equihash** είναι ο αλγόριθμος κατακερματισμού που χρησιμοποιείται στην εξόρυξη Zcash. Χρησιμοποιείται επίσης από δίκτυα όπως τα Komodo & Horizen.

**Equihash: Ασύμμετρη απόδειξη εργασίας βασισμένη στο γενικευμένο πρόβλημα γενεθλίων** (Biryukov and Khovratovich): https://eprint.iacr.org/2015/946
