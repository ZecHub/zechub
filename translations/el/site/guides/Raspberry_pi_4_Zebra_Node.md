# Οδηγός Raspberry Pi 4 για την εκτέλεση του Zebra

<img src="/content-images/image-2023-11-28-172907488-e7e9fd4ac5.webp" alt="raspberry pi" width="300" height="300"/>

Η εκτέλεση του λογισμικού κόμβου Zebra σε ένα Raspberry Pi 4 σού επιτρέπει να συμμετέχεις στο δίκτυο Zcash ως ανεξάρτητος κόμβος συμβατός με τη συναίνεση. Αυτός ο οδηγός θα σε καθοδηγήσει στα βήματα για να ρυθμίσεις και να εκτελέσεις το Zebra στο Raspberry Pi 4 σου.

## Προϋποθέσεις

1. Raspberry Pi 4 (συνιστώνται 2GB RAM ή περισσότερα).

2. Κάρτα MicroSD (συνιστώνται 16GB ή περισσότερα) με εγκατεστημένο Raspberry Pi OS (Raspbian).

3. Σταθερή σύνδεση στο διαδίκτυο.

4. Πληκτρολόγιο, ποντίκι και οθόνη (για την αρχική ρύθμιση).

5. Πρόγραμμα-πελάτης SSH (προαιρετικό, για απομακρυσμένη πρόσβαση).

## Εγκατάσταση

1. __Ενημέρωσε το σύστημά σου__
   Άνοιξε ένα τερματικό ή συνδέσου μέσω SSH στο Raspberry Pi σου και βεβαιώσου ότι το σύστημά σου είναι ενημερωμένο εκτελώντας:

   __sudo apt update__

   __sudo apt upgrade__

2. __Εγκατέστησε τις εξαρτήσεις__
   Θα χρειαστεί να εγκαταστήσεις ορισμένες απαραίτητες εξαρτήσεις για τη δημιουργία και την εκτέλεση του Zebra:

   __sudo apt install build-essential cmake git clang libssl-dev pkg-config__

3. __Κλωνοποίησε το αποθετήριο Zebra__
   Άνοιξε ένα τερματικό και κλωνοποίησε το αποθετήριο Zebra στο Raspberry Pi σου:

   __git clone https://github.com/ZcashFoundation/zebra.git__

   __cd zebra__

4. __Δημιούργησε το Zebra__
   Για να δημιουργήσεις το Zebra, χρησιμοποίησε τις ακόλουθες εντολές:

   __cargo build --release__

   Αυτή η διαδικασία μπορεί να διαρκέσει λίγο. Βεβαιώσου ότι το Raspberry Pi σου ψύχεται επαρκώς, καθώς η μεταγλώττιση μπορεί να παράγει θερμότητα.

5. __Ρύθμιση__
   Δημιούργησε ένα αρχείο ρυθμίσεων για το Zebra. Μπορείς να χρησιμοποιήσεις την προεπιλεγμένη ρύθμιση ως αφετηρία:

   __cp zcash.conf.example zcash.conf__

   Επεξεργάσου το αρχείο zcash.conf για να προσαρμόσεις τις ρυθμίσεις του κόμβου σου. Μπορείς να καθορίσεις το δίκτυο, να ενεργοποιήσεις την εξόρυξη, να ρυθμίσεις συνδέσεις με ομότιμους και άλλα.

6. __Εκκίνησε το Zebra__
   Τώρα μπορείς να εκκινήσεις το Zebra με την προσαρμοσμένη ρύθμισή σου:

   __./target/release/zebrad -c zcash.conf__

   __git comment__ 

   Αυτή η εντολή θα εκκινήσει τον κόμβο Zebra και θα αρχίσει να συγχρονίζεται με το blockchain Zcash.

7. __Παρακολούθηση__
   Μπορείς να παρακολουθείς την πρόοδο και την κατάσταση του κόμβου Zebra ανοίγοντας ένα πρόγραμμα περιήγησης ιστού και μεταβαίνοντας στη διεύθυνση __http://127.0.0.1:8233/status__.

## Αντιμετώπιση προβλημάτων

Αν αντιμετωπίσεις προβλήματα κατά τη δημιουργία ή την εκτέλεση του Zebra, έλεγξε την τεκμηρίωση [Zebra](https://zebra.zfnd.org/user/troubleshooting.html) για συμβουλές αντιμετώπισης προβλημάτων και πρόσθετες πληροφορίες.

Βεβαιώσου ότι διατηρείς το Raspberry Pi σου δροσερό, καθώς η εκτέλεση ενός κόμβου μπορεί να παράγει θερμότητα. Ίσως θελήσεις να χρησιμοποιήσεις μια λύση ψύξης, όπως ανεμιστήρα ή ψύκτρα.

## Συμπέρασμα

Ακολουθώντας αυτόν τον οδηγό, θα πρέπει να έχεις ρυθμίσει και εκτελέσει με επιτυχία το Zebra στο Raspberry Pi 4 σου. Πλέον συμβάλλεις στο δίκτυο Zcash ως ανεξάρτητος κόμβος, βοηθώντας στην προστασία της ιδιωτικότητας των συναλλαγών Zcash.
