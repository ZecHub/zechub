# Free2Z: Ρύθμιση λογαριασμού + βίντεο με οδηγίες για livestream

## Εισαγωγή

Το Free2Z είναι μια πλατφόρμα όπου δημιουργοί και υποστηρικτές μπορούν να συνδεθούν και να πετύχουν τους στόχους τους. Το Free2Z παρέχει εργαλεία ώστε οι δημιουργοί να παρουσιάζουν τα ταλέντα τους και να συγκεντρώνουν κεφάλαια για τα έργα τους χωρίς να θέτουν σε κίνδυνο την ιδιωτικότητα. Οι υποστηρικτές μπορούν να βρουν και να υποστηρίξουν σκοπούς στους οποίους πιστεύουν.

## Δημιούργησε τον λογαριασμό σου

Προς το παρόν, υπάρχουν δύο τρόποι να δημιουργήσεις τον λογαριασμό σου στο Free2Z:  
1. Επίλεξε όνομα χρήστη και κωδικό πρόσβασης.  
2. Σύνδεσε τον λογαριασμό σου στο Twitter.  

Για να δημιουργήσεις λογαριασμό ή να συνδεθείς, επισκέψου το https://free2z.cash/ και κάνε κλικ στο κουμπί «CREATE».

![Login/signup form](/content-images/image-2023-11-19-133101013-3ee51e3b6f.webp)

Η φόρμα σύνδεσης/εγγραφής θα εμφανιστεί στο πρόγραμμα περιήγησής σου. Επίλεξε το όνομα χρήστη σου και έναν ισχυρό κωδικό πρόσβασης - αυτά θα είναι τα στοιχεία σύνδεσής σου. Λύσε το captcha και κάνε κλικ στο κουμπί «Enter» για να δημιουργήσεις τον λογαριασμό σου.

![Username and password entry form](/content-images/image-2023-11-19-133141052-0387984be1.webp)

Εναλλακτικά, μπορείς να δημιουργήσεις λογαριασμό στο Free2Z συνδέοντας τον λογαριασμό σου στο Twitter. Για να το κάνεις αυτό, κάνε κλικ στο λογότυπο του Twitter δίπλα στο «Login With» και θα σου ζητηθεί να συνδέσεις τον λογαριασμό σου στο Twitter.

![Twitter login option](/content-images/image-2023-11-19-133210103-f65246bbee.webp)

Κάνε κλικ στο **Authorize app** για να συνδέσεις τον λογαριασμό σου στο Twitter με το Free2Z.

## Εξατομίκευσε το προφίλ σου

Αφού δημιουργηθεί ο λογαριασμός σου, θα ανακατευθυνθείς στη σελίδα προφίλ σου στο Free2Z. Αν δημιούργησες τον λογαριασμό σου συνδέοντας το Twitter, τα περισσότερα πεδία θα συμπληρωθούν αυτόματα. Αν δημιούργησες λογαριασμό εισάγοντας όνομα χρήστη και κωδικό πρόσβασης, θα πρέπει να εισαγάγεις εδώ τα στοιχεία σου. Μπορείς να χρησιμοποιήσεις ψευδώνυμο αντί για το πραγματικό σου όνομα.

![Default empty profile header](/content-images/default-header-a11eb8328f.webp)

Προς το παρόν είναι αρκετά βαρετό, οπότε ας το κάνουμε πιο ενδιαφέρον ορίζοντας ένα avatar και ένα banner. Η διεπαφή του Free2Z κάνει αυτό το βήμα πολύ εύκολο με το κουμπί μεταφόρτωσης (το βέλος προς τα πάνω στα δεξιά).

![Avatar and banner upload buttons](/content-images/avatar-and-banner-bd20d0bbfb.webp)

Μπορείς να δεις το αποτέλεσμα στο επάνω μέρος της σελίδας.

![Profile page after customization](/content-images/resultatpage-f4ddacb8b8.webp)

Α, πολύ καλύτερα! Αν έχεις καλλιτεχνικές δεξιότητες, μπορείς να κάνεις τη σελίδα προφίλ σου στο Free2Z να δείχνει καταπληκτική! Γράψε μια ωραία περιγραφή για τη σελίδα σου. Μπορείς να μιλήσεις για τον εαυτό σου ή να περιγράψεις το είδος περιεχομένου που μπορούν να περιμένουν οι άλλοι από εσένα. (Συμβουλή: Χρησιμοποίησε σύνταξη markdown για να εξατομικεύσεις την περιγραφή σου!)

![Editing the description field](/content-images/edit-description-b52afabec1.webp)

Μην ξεχάσεις να δώσεις τη θωρακισμένη διεύθυνση του Zcash, ώστε οι υποστηρικτές να μπορούν να κάνουν δωρεές απευθείας σε εσένα!

![Zcash shielded address field](/content-images/p2p-address-b89f035bd9.webp)

Το τελευταίο βήμα για να ολοκληρώσεις τη ρύθμιση της σελίδας σου είναι να ορίσεις μια «Τιμή μέλους». Αυτή είναι η τιμή σε 2Zs (Tuzies) που θα πληρώνουν άλλοι χρήστες για να εγγραφούν στη σελίδα σου! (Περισσότερα για τα 2Zs αργότερα).

![Member price setting](/content-images/member-price-2dafd7e399.webp)

Τέλος, κάνε κλικ στο κουμπί «Update Profile» για να ολοκληρώσεις τη ρύθμιση του προφίλ σου!

## Συνδρομές και 2Zs

Το Free2Z επιτρέπει στους χρήστες να εγγράφονται στους αγαπημένους τους δημιουργούς και να αποκτούν πρόσβαση σε αποκλειστικές λειτουργίες και περιεχόμενο μόνο για μέλη. Ο δημιουργός πρέπει να διαμορφώσει ένα ελάχιστο ποσό 2Zs για μια συνδρομή.  

Τα 2Zs ή Tuzies είναι ψηφιακές πιστώσεις εντός της εφαρμογής που χρησιμοποιούνται στο Free2Z για πολλούς σκοπούς, όπως:  
1. Εγγραφή σε δημιουργούς  
2. Ενίσχυση της ορατότητας μιας σελίδας στο Free2Z  
3. Κάνεις δωρεές σε δημιουργούς  

Μπορείς να δεις τις πιστώσεις 2Zs στην κεφαλίδα της σελίδας προφίλ σου.

![2Zs / Tuzies balance in header](/content-images/tuzis-balance-9d6a9eff7f.webp)

Μπορείς να αγοράσεις περισσότερα 2Zs με Zcash κάνοντας κλικ στο υπόλοιπο 2Zs σου. Το ελάχιστο ποσό αγοράς είναι 0,05 ZEC και η τρέχουσα ισοτιμία μετατροπής είναι 0,05 ZEC = 10 2Zs.

![Buying 2Zs interface](/content-images/buy-tuzies-e82c626047.webp)

## Δωρεές και συνδρομές

Μόλις βρεις έναν δημιουργό που σου αρέσει, μπορείς να δείξεις την εκτίμησή σου κάνοντας δωρεά και εγγραφόμενος σε αυτόν. Όλες οι δωρεές πηγαίνουν απευθείας στο πορτοφόλι του δημιουργού. Για παράδειγμα, ας εγγραφούμε στη σελίδα του [Free2Z](https://free2z.cash/free2z).

![Free2Z official page](/content-images/free2z-page-94c5fd5f4f.webp)

Για να εγγραφείς σε μια σελίδα, το μόνο που χρειάζεται να κάνεις είναι να κάνεις κλικ στο εικονίδιο εγγραφής στην κεφαλίδα της σελίδας.

![Subscribe button on creator page](/content-images/subscribe-to-creator-76c306d924.webp)

Θα δεις το ελάχιστο ποσό για την εγγραφή. Επιβεβαίωσε ότι έχεις αρκετά tuzies και κάνε κλικ στο κουμπί εγγραφής.

![Confirm subscription popup](/content-images/confirm-subscribe-7381923e36.webp)

### Κάνε δωρεά με 2Zs ή Zcash

Μπορείς να κάνεις δωρεά απευθείας στη σελίδα τους, κάνοντας κλικ στο εικονίδιο Fund creator.

![Fund creator button](/content-images/fund-creator-ac59aee7bf.webp)

Εναλλακτικά, μέσα από μια ανάρτηση, αναζήτησε το αιωρούμενο κουμπί με το συν. Από εδώ, μπορείς να κάνεις δωρεά στον δημιουργό ή να προωθήσεις την ανάρτηση στο Free2Z.

![Floating action buttons inside a post](/content-images/post-floating-buttons-a1e2ef1102.webp)

## Ζωντανή μετάδοση

Η πλατφόρμα Free2Z προσφέρει μια εξαιρετική λειτουργία που ονομάζεται Free2Z Live. Με αυτό το εργαλείο, οι δημιουργοί μπορούν να ξεκινούν ζωντανές μεταδόσεις για εγγεγραμμένα μέλη. Ορισμένες βασικές λειτουργίες του Free2Z Live περιλαμβάνουν:  
- Ήχο και βίντεο  
- Κοινή χρήση οθόνης  
- Συνεργατική επεξεργασία κώδικα  
- Συνομιλία  
- Πίνακα σχεδίασης  
- Και πολλά άλλα!

### Τι μπορείς να κάνεις με το Free2Z Live

Το Free2Z Live είναι ένα ισχυρό εργαλείο που επιτρέπει στους δημιουργούς να μεταδίδουν κάθε είδους περιεχόμενο. Ακολουθούν μερικά παραδείγματα του τύπου περιεχομένου που μπορείς να μεταδώσεις με το Free2Z Live:  
- Οδηγούς και επιδείξεις  
- Παραστάσεις και εκδηλώσεις  
- Συνεργατικά έργα  
- Ζωντανή κάλυψη και δημοσιογραφία  
- Η δημιουργικότητά σου είναι το μόνο όριο!

### Πώς να ξεκινήσεις ζωντανή μετάδοση

Είναι πολύ εύκολο να ξεκινήσεις μια ζωντανή μετάδοση με το Free2Z Live. Ωστόσο, υπάρχουν ορισμένες προϋποθέσεις πριν μπορέσεις να ξεκινήσεις τη μετάδοσή σου.  
1. Ο δημιουργός **πρέπει** να έχει ελάχιστη **τιμή μέλους** 10 2Zs.  
2. Ο δημιουργός **πρέπει** να έχει υπόλοιπο τουλάχιστον 150 2Zs στον λογαριασμό του.  

Αν ο δημιουργός πληροί **και τις δύο** παραπάνω προϋποθέσεις, ένα εικονίδιο με όνομα **Go Live** θα είναι διαθέσιμο στη σελίδα προφίλ του.

![Go Live button](/content-images/go-live-4c8ac67505.webp)

Για να ξεκινήσεις μια ζωντανή μετάδοση, απλώς κάνε κλικ στο κουμπί **Go Live** και η εφαρμογή Free2Z θα ζητήσει άδεια για να χρησιμοποιήσει το μικρόφωνο και την κάμερα web σου (αν έχεις). Αφού παραχωρήσεις τις απαραίτητες άδειες, το Free2Z θα σου ζητήσει να εισαγάγεις ένα ψευδώνυμο που θέλεις να χρησιμοποιείς κατά τη ζωντανή μετάδοση. Μόλις επιλέξεις ψευδώνυμο, κάνε κλικ στο **Join** για να ξεκινήσεις τη ζωντανή μετάδοσή σου.

![Select nickname for live stream](/content-images/select-nickname-414444b992.webp)

Και έτοιμο! Όταν ξεκινήσεις μια ζωντανή μετάδοση, το προφίλ σου θα εμφανίζει ένα εικονίδιο που υποδεικνύει ότι είσαι σε ζωντανή μετάδοση, ώστε οι συνδρομητές σου να μπορούν να συμμετάσχουν.

![Joining a livestream](/content-images/join-livestream-679334ba53.webp)

Όταν οι άνθρωποι συμμετέχουν στη ζωντανή μετάδοση, μπορούν να συνομιλούν, να ζητούν να ανέβουν στη σκηνή, να αλληλεπιδρούν ψηφίζοντας σε δημοσκοπήσεις και πολλά άλλα.

![Example of a Free2Z Live session](/content-images/free2z-live-example-eecb2ae553.webp)

_(Παράδειγμα συνεδρίας Free2Z Live)_

Το Free2Z Live είναι ευέλικτο και ισχυρό. Στην επόμενη ενότητα, θα παρουσιάσω μια επισκόπηση των λειτουργιών και των εργαλείων του.

### Εξερεύνηση του Free2Z Live

Αυτό το έγγραφο wiki δεν προορίζεται να είναι ένας αναλυτικός οδηγός για το Free2Z ή το Free2Z Live. Ακολουθεί όμως μια γενική επισκόπηση των εργαλείων του.

Στο κάτω αριστερό μέρος της οθόνης, βλέπουμε μερικά κουμπιά.

![Bottom left controls](/content-images/free2z-live-left-60b450b01c.webp)

Μια χρήσιμη λειτουργία εδώ είναι η δυνατότητα κοινής χρήσης της οθόνης σου, ώστε οι άλλοι χρήστες να μπορούν να δουν τι κάνεις.

Στο κάτω μέρος μπορούμε να βρούμε τις επιλογές ζωντανής μετάδοσης.

![Bottom toolbar](/content-images/free2z-live-bottom-ae64a6960c.webp)

Ορισμένες από τις βασικές επιλογές εδώ είναι:  
- Σίγαση / άρση σίγασης μικροφώνου  
- Ενεργοποίηση / απενεργοποίηση κάμερας web  
- Αποχώρηση από τη σκηνή  
- Σίγαση όλων των ομιλητών  
- Αποχώρηση  

Για να τερματίσεις μια ζωντανή μετάδοση, πρέπει να κάνεις κλικ στο κουμπί «Leave» και έπειτα να κάνεις κλικ στο «End meeting for all» για να σταματήσεις τη συνάντηση για όλους τους συμμετέχοντες.

![Bottom right interaction panel](/content-images/free2z-live-right-c83cb6d209.webp)

Τα κουμπιά κάτω δεξιά περιέχουν λειτουργίες που σχετίζονται με την αλληλεπίδραση στη ζωντανή μετάδοση, όπως:  
- **Chat**: Επιτρέπει στους συμμετέχοντες να συνομιλούν μεταξύ τους και με τον οικοδεσπότη κατά τη ζωντανή μετάδοση.  
- **Polls**: Επιτρέπει στον οικοδεσπότη να δημιουργεί δημοσκοπήσεις και να συλλέγει σχόλια από τους συμμετέχοντες.  
- **Λίστα συμμετεχόντων**: Εμφανίζει τη λίστα των συμμετεχόντων στη ζωντανή μετάδοση.  
- **Plugins**: Επιτρέπει στον οικοδεσπότη να προσθέτει plugins και επεκτάσεις για να βελτιώσει την εμπειρία της ζωντανής μετάδοσης.

![Plugins panel](/content-images/free2z-live-plugins-e9a30ee355.webp)

Δεν είναι σκοπός αυτού του εγγράφου wiki να εξηγήσει όλα τα plugins, αλλά πραγματικά σε ενθαρρύνω να δοκιμάσεις το καθένα, καθώς όλα προσφέρουν μεγάλη αξία αλληλεπίδρασης μεταξύ δημιουργών και θεατών. Για να εκκινήσεις ένα plugin, απλώς κάνε κλικ στο κουμπί «rocket» στα δεξιά.

## Συμπέρασμα

Συμπερασματικά, το Free2Z είναι μια ευέλικτη πλατφόρμα για δημιουργούς ώστε να παρουσιάζουν τις ικανότητές τους, να μοιράζονται γνώσεις και να συγκεντρώνουν κεφάλαια για τα έργα τους, καθώς και να αλληλεπιδρούν με τους υποστηρικτές τους μέσω του ισχυρού εργαλείου Free2Z Live.
