# Πώς να στέλνεις και να λαμβάνεις θωρακισμένα Zcash (ZEC) με το Brave Wallet: Οδηγός ιδιωτικότητας βήμα προς βήμα

Το Brave Wallet είναι ένα ασφαλές, εγγενές crypto πορτοφόλι ενσωματωμένο απευθείας στον browser Brave - δεν απαιτούνται επεκτάσεις.


## Γιατί έχει σημασία η υποστήριξη θωρακισμένων ZEC


Το Zcash είναι ένα από τα ελάχιστα κρυπτονομίσματα που προσφέρουν ιδιωτικότητα από προεπιλογή με θωρακισμένες συναλλαγές.

Το Brave Wallet υποστηρίζει πλέον θωρακισμένα Orchard ZEC, επιτρέποντας ιδιωτικές συναλλαγές χωρίς λογισμικό τρίτων.

Πλέον μπορείς να στέλνεις/λαμβάνεις ZEC χωρίς να αποκαλύπτεις υπόλοιπα ή μεταδεδομένα - όλα μέσα στον browser Brave.

## Μέρος 1: Ρύθμιση του Brave Wallet

**Βήματα που καλύπτονται:**

1. Άνοιξε τον Browser Brave (προς το παρόν μόνο για υπολογιστές)

2. Κάνε κλικ στο εικονίδιο του πορτοφολιού ή πήγαινε στο brave://wallet

3. Ρύθμισε το πορτοφόλι σου (δημιούργησέ το ή εισήγαγέ το)

4. Άνοιξε τον πίνακα ελέγχου κρυπτονομισμάτων


![img1](/content-images/f54cd1a1-8569-4925-ba1c-7597d030593e-8d83734cd5.webp)


## Μέρος 2: Προσθήκη του Zcash (ZEC) στο Brave Wallet

**Βήματα που καλύπτονται:**

1. Στον πίνακα ελέγχου του πορτοφολιού, κάνε κλικ στο «Manage Assets»

2. Αναζήτησε το ZEC και ενεργοποίησέ το

3. Το ZEC εμφανίζεται τώρα στο πορτοφόλι σου


![img2](/content-images/6f2b2190-cf55-4394-9d5f-29ff9b5bb525-13d37cb455.webp)


## Μέρος 3: Λήψη θωρακισμένων ZEC (Unified Address)

**Βήματα που καλύπτονται:**

1. Κάνε κλικ στο ZEC στα στοιχεία ενεργητικού σου

2. Επίλεξε «Receive»

3. Το Brave δημιουργεί μια Unified Address (UA) - μία διεύθυνση που υποστηρίζει τόσο θωρακισμένες όσο και διαφανείς συναλλαγές

4. Αντέγραψε ή σκάναρε τον κωδικό QR

5. Μοιράσου τη UA σου με τον αποστολέα



![img3](/content-images/53c940b6-1a03-4fa7-aefa-d3478f678a88-23f68a3855.webp)



## Μέρος 4: Ιδιωτική αποστολή θωρακισμένων ZEC

**Βήματα που καλύπτονται:**

1. Επίλεξε ZEC -> Send

2. Επικόλλησε τη Unified Address ή τη θωρακισμένη διεύθυνση του παραλήπτη

3. Εισήγαγε το ποσό

4. Επιβεβαίωσε τις λεπτομέρειες της συναλλαγής

5. Κάνε κλικ στο Send - τα κεφάλαια μεταφέρονται τώρα ιδιωτικά, χρησιμοποιώντας το pool Orchard


![img4](/content-images/Internet_20250808_172118_4-e6df0f7fe2.webp)




## Τύποι διευθύνσεων

Ακολουθεί μια εξήγηση για κάθε τύπο διεύθυνσης Zcash:

**t-addr (t1...)** - Οι διαφανείς διευθύνσεις λειτουργούν όπως οι διευθύνσεις Bitcoin, που σημαίνει ότι οι συναλλαγές είναι δημόσιες στο blockchain. Είναι ευκολότερες στη χρήση με πορτοφόλια εκτός Zcash, αλλά δεν παρέχουν ιδιωτικότητα.

**z-addr (zs...)** - Οι θωρακισμένες διευθύνσεις χρησιμοποιούν την τεχνολογία ιδιωτικότητας του Zcash (Sprout/Sapling) για να αποκρύπτουν τον αποστολέα, τον παραλήπτη και το ποσό. Μόνο τα viewing keys ή ο ιδιοκτήτης μπορούν να αποκαλύψουν λεπτομέρειες.

**UA (u... ή QR)** - Οι Unified Addresses συνδυάζουν πολλούς τύπους διευθύνσεων (διαφανείς, θωρακισμένες, Orchard) σε μία. Αυτό επιτρέπει μέγιστη συμβατότητα, ενώ προτιμά την ιδιωτικότητα όπου είναι δυνατόν.
