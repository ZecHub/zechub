# Τι είναι το ZIP
Μια Πρόταση βελτίωσης Zcash (ZIP) είναι ένα έγγραφο σχεδιασμού που παρέχει πληροφορίες στην κοινότητα Zcash ή περιγράφει ένα νέο χαρακτηριστικό για το Zcash ή τις διαδικασίες ή το περιβάλλον του. Το ZIP θα πρέπει να παρέχει μια συνοπτική τεχνική προδιαγραφή του χαρακτηριστικού και αιτιολόγηση για αυτό.

Σκοπεύουμε τα ZIP να αποτελούν τον κύριο μηχανισμό για την πρόταση νέων χαρακτηριστικών, τη συλλογή σχολίων της κοινότητας για ένα ζήτημα και την τεκμηρίωση των αποφάσεων σχεδιασμού που έχουν ενσωματωθεί στο Zcash. Ο/Οι ιδιοκτήτης/-ες του ZIP (συνήθως ο/οι συγγραφέας/-είς) είναι υπεύθυνος/-οι για την επίτευξη συναίνεσης εντός της κοινότητας και την τεκμηρίωση των διαφωνούντων απόψεων.

Επειδή τα ZIP διατηρούνται ως αρχεία κειμένου σε ένα αποθετήριο με εκδόσεις, το ιστορικό αναθεωρήσεών τους αποτελεί το ιστορικό αρχείο της πρότασης χαρακτηριστικού.

-> [zips.z.cash](https://zips.z.cash)


## Συντάκτες ZIP

Για κάθε ZIP που υποβάλλεται, πρέπει να ακολουθεί τη διαδικασία αξιολόγησης. Οι συντάκτες ZIP έχουν ως καθήκον να διασφαλίζουν ότι η μορφή και το περιεχόμενο κάθε ZIP περιγράφουν επαρκώς τους όρους, την αιτιολόγηση και τις τεχνικές αλλαγές που έγιναν. 

```markdown
* Jack Grigg, Kris Nuttycombe and Daira-Emma Hopwood associated with the ECC.
* Conrado, and Arya, associated with the ZF.
* Sam and Mark, associated with SL.
```
