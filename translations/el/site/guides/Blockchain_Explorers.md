# Εξερευνητές blockchain

## Εισαγωγή

Στον παραδοσιακό επιχειρηματικό κόσμο κάθε συναλλαγή περιλαμβάνει μια απόδειξη αγοράς. Παρόμοια, στον κόσμο του blockchain ένας χρήστης λαμβάνει μια ψηφιακή απόδειξη με τη μορφή αναγνωριστικού συναλλαγής για κάθε ολοκληρωμένη συναλλαγή. Τα περισσότερα πορτοφόλια θα σου το παρέχουν αυτό. Οι εξερευνητές blockchain είναι απλώς εργαλεία που επιτρέπουν σε κάποιον να οπτικοποιεί ό,τι έχει ήδη συμβεί σε ένα blockchain. Δέχονται ως εισόδους: αναγνωριστικά συναλλαγών, διευθύνσεις ή hashes μπλοκ, και εμφανίζουν οπτικά τι συνέβη.

## Χάρτες blockchain

Έχουμε λοιπόν αυτή τη μεγάλη ακολουθία χαρακτήρων ως ψηφιακή απόδειξη, και τώρα τι; Εδώ χρησιμοποιούμε έναν [block explorer](https://nym.com/blog/using-blockchain-privately), ή χάρτη, για να μας βοηθήσει να κατανοήσουμε τι συνέβη στο blockchain. Παρατήρησε πώς κάθε αλυσίδα έχει τη δική της εκδοχή του [block explorer](https://nym.com/blog/using-blockchain-privately) παραπάνω. Είναι σημαντικό να καταλάβεις ότι όλα αυτά τα έργα blockchain είναι παραδείγματα λογισμικού ανοιχτού κώδικα. Δηλαδή, οποιοσδήποτε μπορεί να συνεισφέρει στον κώδικα ή/και να τον κάνει fork όπως επιθυμεί. Με αυτή την κατανόηση, κάθε έργο εξειδικεύεται σε διαφορετικούς τομείς και προσαρμόζει τον block explorer στις ανάγκες του εν λόγω έργου.

### Μπλοκ
Οι συναλλαγές τοποθετούνται σε *μπλοκ*. Όταν ένα μπλοκ εξορύσσεται/επικυρώνεται, κάθε συναλλαγή μέσα σε εκείνο το μπλοκ επιβεβαιώνεται και δημιουργείται ένα hash μπλοκ. Οποιοδήποτε hash δημιουργείται μπορεί να εισαχθεί σε έναν block explorer. Μπορεί να έχεις δει CEX να χρειάζονται έναν αριθμό *επιβεβαιώσεων* πριν αποδεσμεύσουν τα κεφάλαιά σου· αυτή είναι η μέτρηση που χρησιμοποιούν για να βεβαιωθούν ότι η συναλλαγή σου έχει 
οριστικοποιηθεί επαρκώς. Πώς καθορίζει το blockchain ποιες συναλλαγές μπαίνουν στο επόμενο μπλοκ; Είναι σύνθετο θέμα έρευνας, αλλά οι περισσότερες σύγχρονες αλυσίδες χρησιμοποιούν την έννοια των *τελών* για να καθορίσουν ποιος μπαίνει στην αρχή της ουράς. Όσο υψηλότερα είναι τα τέλη, τόσο μεγαλύτερη είναι η πιθανότητα να μετακινηθείς προς την αρχή της ουράς.

### Διευθύνσεις

Ένας διασκεδαστικός τρόπος να μάθεις οπτικά για τους [block explorers](https://nym.com/blog/using-blockchain-privately) είναι να εισαγάγεις τη διεύθυνση οποιασδήποτε τυχαίας συναλλαγής. Έπειτα μπορείς να κινηθείς προς τα πίσω στον χρόνο και να δεις από πού προήλθαν τα κεφάλαια! Κάθε συναλλαγή έχει τόσο μια διεύθυνση εισόδου όσο και εξόδου.  Με αυτή την πληροφορία, μπορείς εύκολα να κινηθείς τόσο προς τα εμπρός όσο και προς τα πίσω από οποιαδήποτε συναλλαγή έχει δαπανηθεί. Για όσους αγαπούν τους γρίφους, αυτό είναι το ψηφιακό ισοδύναμο ενός τεράστιου οικονομικού γρίφου και θα μπορούσε να χρησιμοποιηθεί για σκοπούς διαφάνειας. Η χρήση ενός block explorer όχι μόνο κάνει αυτό πολύ πιο εύκολο να οπτικοποιηθεί, αλλά *τονίζει επίσης* την ανάγκη για ιδιωτικότητα συναλλαγών. Εκτός αν χρησιμοποιείς θωρακισμένα Zcash, μπορείς να το κάνεις αυτό με *οποιοδήποτε* διαφανές blockchain: BTC, ETH, ATOM, DOGE, VTC, κ.λπ. . Αυτό το σημείο είναι κρίσιμο για οποιονδήποτε χρησιμοποιεί το blockchain με ασφάλεια καθώς προχωράμε σε ένα αποκλειστικά ψηφιακό μέλλον.

### Ποσά

Παρόμοια με τις διευθύνσεις παραπάνω, κάθε συναλλαγή σε ένα δημόσιο blockchain έχει τα ποσά διαθέσιμα δημόσια και σε πλήρη θέα. Αυτό περιλαμβάνει ποσά τόσο στις διευθύνσεις εισόδου όσο και εξόδου για κάθε συναλλαγή. Μία εξαίρεση σε αυτό είναι όταν επιλέγεις να χρησιμοποιήσεις θωρακισμένα Zcash -- τότε όλα τα ποσά είναι κρυμμένα. Για ιδιοκτήτες μικρών επιχειρήσεων που χρειάζονται απαραίτητα ιδιωτικότητα για *δίκαιο εμπόριο*, αυτό είναι ένα τεράστιο όφελος!

### Τι μπορεί και τι δεν μπορεί να δει ένας εξερευνητής στο Zcash

#### TL;DR
- Οι διαφανείς (`t`) διευθύνσεις είναι πλήρως ορατές σε έναν εξερευνητή, όπως ακριβώς στο Bitcoin
- Οι πλήρως θωρακισμένες (z προς z) συναλλαγές κρύβουν το ποσό, τις διευθύνσεις και το σημείωμα
- Τα τέλη παραμένουν ορατά, ακόμη και σε μια πλήρως θωρακισμένη συναλλαγή
- Η θωράκιση (μετακίνηση `t` σε θωρακισμένα) και η αποθωράκιση (θωρακισμένα πίσω σε `t`) είναι εν μέρει ορατές, επειδή η μία πλευρά είναι διαφανής
- Η ιδιωτικότητα διατηρείται μόνο όσο τα κεφάλαια παραμένουν μέσα στα θωρακισμένα pools

Το Zcash έχει περισσότερα από ένα είδη διευθύνσεων και ένας εξερευνητής τα αντιμετωπίζει πολύ διαφορετικά.

Οι διαφανείς διευθύνσεις, που αρχίζουν με `t`, λειτουργούν όπως το Bitcoin. Ένας εξερευνητής εμφανίζει τον αποστολέα, τον παραλήπτη, το ποσό και τη διαδρομή πίσω στην προέλευση των κεφαλαίων.

Οι θωρακισμένες διευθύνσεις είναι η ιδιωτική πλευρά. Τα κεφάλαια στα Sapling ή Orchard [θωρακισμένα pools](https://zechub.wiki/using-zcash/shielded-pools#content) προστατεύονται από αποδείξεις μηδενικής γνώσης. Αναζήτησε μια πλήρως θωρακισμένη συναλλαγή και ο εξερευνητής δεν μπορεί να εμφανίσει το ποσό, τις διευθύνσεις ή το σημείωμα. Μπορεί μόνο να επιβεβαιώσει ότι συνέβη μια έγκυρη συναλλαγή και καταγράφηκε σε ένα μπλοκ. Αυτό είναι το κρυμμένο ιδιωτικό παράδειγμα που εμφανίζεται κοντά στην κορυφή αυτής της σελίδας.

Μία λεπτομέρεια παραμένει ορατή ακόμη και για πλήρως θωρακισμένες συναλλαγές: τα τέλη. Οι κανόνες συναίνεσης του Zcash απαιτούν τα διαφανή τέλη να δηλώνονται ρητά, επομένως ένας εξερευνητής μπορεί πάντα να τα εμφανίσει, ακόμη και όταν τα ποσά είναι καλυμμένα. Για αυτόν τον λόγο, είναι καλή πρακτική να χρησιμοποιείς τα συνήθη τέλη πορτοφολιού, ώστε η συναλλαγή σου να μη ξεχωρίζει πληρώνοντας ένα ασυνήθιστο ποσό.

Ο εξερευνητής μπορεί επίσης να δει πότε κεφάλαια περνούν μεταξύ της διαφανούς και της θωρακισμένης πλευράς. Η μετακίνηση κεφαλαίων `t` σε ένα pool είναι θωράκιση, ενώ η μετακίνησή τους ξανά έξω είναι αποθωράκιση. Αυτές οι μεταβάσεις είναι εν μέρει ορατές επειδή η μία πλευρά είναι διαφανής. Μόνο η πλήρως ιδιωτική δραστηριότητα z προς z, η οποία δεν αγγίζει ποτέ μια διεύθυνση `t`, διατηρεί κρυμμένα τα πάντα εκτός από τα τέλη.

Το συμπέρασμα: η ιδιωτικότητα εξαρτάται από την παραμονή μέσα στα θωρακισμένα pools. Μόλις τα κεφάλαια αγγίξουν μια διεύθυνση `t`, αυτό το μέρος του ιστορικού τους είναι τόσο δημόσιο όσο στο Bitcoin. Για να αποδείξεις τη δική σου θωρακισμένη δραστηριότητα σε κάποιον που επιλέγεις, όπως έναν λογιστή, μοιράσου ένα viewing key αντί να το δημοσιοποιήσεις. Δες τη σελίδα [Viewing Keys](https://zechub.wiki/zcash-tech/viewing-keys#content).
