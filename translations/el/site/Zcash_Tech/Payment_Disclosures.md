# Θωρακισμένη απόδειξη πληρωμής και γνωστοποιήσεις πληρωμών

## Με λίγα λόγια

- Ένα αναγνωριστικό συναλλαγής προσδιορίζει μια συναλλαγή, αλλά δεν αποκαλύπτει έναν θωρακισμένο παραλήπτη, ποσό ή σημείωμα.
- Μια γνωστοποίηση πληρωμής έχει σχεδιαστεί ώστε να επιτρέπει στον αποστολέα να αποδείξει επιλεγμένες λεπτομέρειες μιας πληρωμής χωρίς να εκθέτει το υπόλοιπο ιστορικό του πορτοφολιού του.
- Ένα viewing key παρέχει συνεχή πρόσβαση ανάγνωσης σε μια διεύθυνση ή λογαριασμό. Χρησιμοποίησέ το για συνεχιζόμενους ελέγχους, όχι για μια διαφωνία σχετικά με μία πληρωμή.
- Μια γνωστοποίηση πληρωμής δεν μπορεί να αποδείξει την παράδοση αγαθών, να ταυτοποιήσει από μόνη της ένα πρόσωπο, να αντιστρέψει μια πληρωμή ή να αντικαταστήσει τους ελέγχους επιβεβαίωσης.
- Το [ZIP 311](https://zips.z.cash/zip-0311) εξακολουθεί να είναι ένα **Προσχέδιο**. Το τρέχον κείμενό του αφήνει ανολοκλήρωτους την υποστήριξη του Orchard, την υποστήριξη διαφανών εισόδων, την κωδικοποίηση, τη διαχείριση εκδόσεων και τους κανόνες διεπαφής χρήστη.

## Γιατί ένα αναγνωριστικό συναλλαγής δεν αρκεί

Οποιοσδήποτε μπορεί να επιθεωρήσει τις δημόσιες λεπτομέρειες μιας διαφανούς πληρωμής Zcash. Ένα block explorer μπορεί να εμφανίσει τις διευθύνσεις, τα ποσά και την κατάσταση επιβεβαίωσής της.

Μια θωρακισμένη πληρωμή λειτουργεί διαφορετικά. Η αλυσίδα αποδεικνύει ότι η συναλλαγή ακολούθησε τους κανόνες του Zcash, αλλά δεν δημοσιεύει τον θωρακισμένο αποστολέα, παραλήπτη, ποσό ή σημείωμα. Η κοινοποίηση του αναγνωριστικού συναλλαγής μπορεί να δείξει ότι μια συναλλαγή εξορύχθηκε, αλλά δεν μπορεί να αποδείξει σε έναν έμπορο ή τρίτο μέρος ποια ιδιωτική πληρωμή περιείχε.

Αυτό δημιουργεί ένα πρακτικό πρόβλημα. Ένας πελάτης μπορεί να χρειάζεται να επιλύσει μια διαφωνία με έμπορο, ένα ανταλλακτήριο μπορεί να χρειάζεται να αποδείξει ότι επεξεργάστηκε μια ανάληψη ή ένας δωρητής μπορεί να θέλει να αποδείξει μία συνεισφορά. Η κοινοποίηση ενός πλήρους viewing key θα αποκάλυπτε πολύ περισσότερα από όσα απαιτεί οποιαδήποτε από αυτές τις περιπτώσεις.

Το [ZIP 311: Zcash Γνωστοποιήσεις πληρωμών](https://zips.z.cash/zip-0311) προτείνει μια πιο περιορισμένη απάντηση: τη γνωστοποίηση και πιστοποίηση επιλεγμένων πληροφοριών από μία συναλλαγή.

A ZIP 311 payment disclosure would let a verifier authenticate only the selected recipient, amount, memo, and optional sender details against the mined transaction.](/content-images/payment-disclosure-proof-flow-208c033e06.webp)

## Πώς λειτουργεί μια γνωστοποίηση πληρωμής

Η βασική ροή είναι η εξής:

1. Ο επαληθευτής δίνει στον αποστολέα μια μοναδική πρόκληση ή αναφορά, όταν είναι κατάλληλη μια διαδραστική απόδειξη.
2. Ο αποστολέας επιλέγει τη συναλλαγή και την θωρακισμένη έξοδο ή εξόδους που θα γνωστοποιήσει.
3. Συμβατό λογισμικό πορτοφολιού δημιουργεί μια γνωστοποίηση πληρωμής συνδεδεμένη με εκείνη τη συναλλαγή και, προαιρετικά, με την πρόκληση.
4. Ο αποστολέας δίνει τη γνωστοποίηση στον επαληθευτή.
5. Ο επαληθευτής λαμβάνει την πραγματική συναλλαγή από έναν αξιόπιστο κόμβο Zcash, ελέγχει ότι εξορύχθηκε και επαληθεύει τη γνωστοποίηση έναντί της.
6. Ένα έγκυρο αποτέλεσμα επιβεβαιώνει μόνο τους ισχυρισμούς που περιέχονται σε εκείνη τη γνωστοποίηση.

Ο σχεδιασμός του ZIP Sapling χρησιμοποιεί ένα εξερχόμενο κλειδί κρυπτογράφησης για να ανακτήσει κάθε επιλεγμένη έξοδο. Αυτό μπορεί να αποκαλύψει τον παραλήπτη, το ποσό και το σημείωμα της εξόδου. Απαιτεί επίσης απόδειξη εξουσίας δαπάνης για τουλάχιστον μία είσοδο συναλλαγής, ώστε ένα πρόσωπο που απλώς βλέπει τη συναλλαγή να μη μπορεί να δημιουργήσει μια έγκυρη γνωστοποίηση σαν να την έστειλε το ίδιο.

Μια γνωστοποίηση πληρωμής Sapling δεν χρειάζεται να αποκαλύπτει διεύθυνση αποστολέα. Η εξουσία δαπάνης μπορεί να ελέγχει πολλές διαφοροποιημένες διευθύνσεις, επομένως η απόδειξη ελέγχου της δαπάνης δεν ταυτοποιεί αυτόματα μία διεύθυνση. Το ZIP 311 περιλαμβάνει μια προαιρετική απόδειξη διεύθυνσης για περιπτώσεις όπου είναι απαραίτητη η σύνδεση της απόδειξης με μια γνωστή διεύθυνση αποστολέα.

| --- | --- | --- | --- | --- |
| Transaction ID | Έλεγχος ότι μια συναλλαγή εξορύχθηκε | Δημόσια δεδομένα συναλλαγής και επιβεβαιώσεις | Όχι | Ναι, αλλά οι λεπτομέρειες της θωρακισμένης πληρωμής παραμένουν κρυφές |
| Screenshot or receipt | Άτυπη τήρηση αρχείων | Ό,τι επιλέξει ο αποστολέας να εμφανίσει | Όχι | Όχι· η εικόνα μπορεί να τροποποιηθεί |
| Payment disclosure | Απόδειξη επιλεγμένων λεπτομερειών μιας πληρωμής | Επιλεγμένες έξοδοι συναλλαγής και οποιαδήποτε συμπεριλαμβανόμενη απόδειξη αποστολέα ή πρόκλησης | Όχι, αλλά η κοινοποιημένη απόδειξη μπορεί να αντιγραφεί | Ναι |
| Incoming Viewing Key | Παρακολούθηση πληρωμών που λαμβάνει ένας λογαριασμός | Εισερχόμενη δραστηριότητα που καλύπτεται από το κλειδί | Ναι | Αποκρυπτογραφεί αντίστοιχες εισερχόμενες πληρωμές |
| Full Viewing Key | Λογιστική ή έλεγχος ενός λογαριασμού | Εισερχόμενη και εξερχόμενη δραστηριότητα, ποσά, σημειώματα και υπόλοιπα που καλύπτονται από το κλειδί | Ναι | Αποκρυπτογραφεί αντίστοιχη δραστηριότητα λογαριασμού |

Χρησιμοποίησε τη μικρότερη γνωστοποίηση που απαντά στην ερώτηση. Μια διαφωνία με έμπορο για μία πληρωμή δεν δικαιολογεί συνήθως πρόσβαση σε κάθε πληρωμή ενός λογαριασμού. Ένας λογιστής που πρέπει να εξετάσει μια πλήρη περίοδο αναφοράς μπορεί να χρειάζεται αντί γι’ αυτό ένα viewing key.

Καμία από τις δύο μεθόδους δεν παρέχει άδεια δαπάνης. Μην κοινοποιείς ποτέ μια φράση ανάκτησης, spending key, ιδιωτικό κλειδί ή αντίγραφο ασφαλείας πορτοφολιού ως απόδειξη πληρωμής.

## Τι μπορώ να χρησιμοποιήσω σήμερα;

Κανένα τρέχον πορτοφόλι δεν αναφέρεται εδώ ως υλοποιώντας δημιουργία ή επαλήθευση γνωστοποίησης πληρωμής του ZIP 311. Το ZIP παραμένει προσχέδιο και αναφέρει την υλοποίηση αναφοράς του ως «TBD». Τα ακόλουθα συντηρούμενα εργαλεία μπορούν ακόμη να βοηθήσουν τον αποστολέα, τον παραλήπτη ή έναν εξουσιοδοτημένο ελεγκτή να επιθεωρήσουν τα αρχεία που είναι διαθέσιμα σήμερα:

| Εφαρμογή | Χρήσιμη σήμερα για | Σημαντικός περιορισμός |
| --- | --- | --- |
| [Zkool](https://github.com/hhanh00/zkool2) | Προβολή λεπτομερών μεταδεδομένων συναλλαγών, ποσών, εισόδων και εξόδων pool και σημειωμάτων· εισαγωγή Unified ή Sapling viewing keys σε λογαριασμούς μόνο για προβολή | Δεν διαφημίζει δημιουργία ή επαλήθευση γνωστοποίησης του ZIP 311 |
| [Zingo PC](https://github.com/zingolabs/zingo-pc) | Εξέταση θωρακισμένου ιστορικού συναλλαγών και σημειωμάτων· εισαγωγή ενός Unified Full Viewing Key σε λειτουργία μόνο για ανάγνωση | Ένα αρχείο πορτοφολιού ή λογαριασμός μόνο για ανάγνωση δεν είναι γνωστοποίηση πληρωμής με επιλεκτικό εύρος |
| [Zallet](https://zcash.github.io/zallet/) | Ροές εργασίας χειριστή με χρήση των `z_viewtransaction`, `z_exportviewingkey` και `z_importviewingkey` | Λογισμικό beta· τα RPC του για viewing key και συναλλαγές είναι ευρύτερα ή τοπικά αρχεία, όχι αποδείξεις του ZIP 311 |

Χρησιμοποίησε πρώτα το πορτοφόλι που έστειλε ή έλαβε την πληρωμή. Έλεγξε τις λεπτομέρειες συναλλαγής, το σημείωμα, το αναγνωριστικό συναλλαγής και τις επιβεβαιώσεις του και έπειτα ζήτησε από το άλλο μέρος να συγκρίνει αυτές τις λεπτομέρειες με τα δικά του αρχεία. Μην εγκαθιστάς νέο πορτοφόλι και μην εισάγεις φράση ανάκτησης απλώς για να παραγάγεις αποδεικτικά στοιχεία. Αν ένας ελεγκτής χρειάζεται συνεχή ορατότητα, εξέτασε έναν συμβατό λογαριασμό μόνο για προβολή και κατανόησε το εύρος του viewing key πριν το κοινοποιήσεις.

Αυτές οι εφαρμογές είναι πρακτικές εναλλακτικές για τον έλεγχο αρχείων, όχι απόδειξη ότι είναι διαθέσιμη μια τυποποιημένη γνωστοποίηση πληρωμής. Ένα στιγμιότυπο οθόνης μπορεί να βοηθήσει ανθρώπους να συγκρίνουν αρχεία, αλλά είναι επεξεργάσιμο και δεν αποτελεί κρυπτογραφική απόδειξη.

## Πού εφαρμόζονται οι γνωστοποιήσεις πληρωμών

### Διαφωνίες με εμπόρους

Ένας πελάτης θα μπορούσε να αποδείξει ότι ένα συγκεκριμένο ποσό στάλθηκε στη θωρακισμένη διεύθυνση του εμπόρου. Η απόδειξη δεν τεκμηριώνει ότι παραδόθηκαν αγαθά, ότι οφείλεται επιστροφή χρημάτων ή ότι το πρόσωπο που την παρουσιάζει έχει συγκεκριμένη νομική ταυτότητα. Αυτά τα ζητήματα εξακολουθούν να εξαρτώνται από το αρχείο παραγγελίας και τη συμφωνία των μερών.

### Θωρακισμένες αναλήψεις

Το ZIP 311 αναφέρει τις θωρακισμένες αναλήψεις ως στοχευμένη περίπτωση χρήσης: ένα ανταλλακτήριο θα αποδείκνυε τον παραλήπτη και το ποσό χωρίς να δημοσιεύει αυτές τις λεπτομέρειες on-chain. Η απόδειξη διαφανών εισόδων του παραμένει ανολοκλήρωτη, επομένως αυτό δεν αποτελεί ακόμη μια πλήρη τυποποιημένη ροή εργασίας. Ο πελάτης πρέπει επίσης να ελέγξει ανεξάρτητα την κατάσταση επιβεβαίωσης της συναλλαγής.

### Δωρεές

Ένας δωρητής ή μια καμπάνια θα μπορούσε να αποδείξει μια συγκεκριμένη συνεισφορά διατηρώντας ιδιωτικές τις άσχετες πληρωμές. Η δημοσίευση της γνωστοποίησης καθιστά τις επιλεγμένες λεπτομέρειές της δημόσιες για όλους όσοι λαμβάνουν αντίγραφο, επομένως ένα ιδιωτικό κανάλι επαλήθευσης είναι ασφαλέστερο όταν η δημόσια απόδειξη δεν είναι απαραίτητη.

### Λογιστική

Χρησιμοποίησε μια γνωστοποίηση πληρωμής όταν ένας λογιστής χρειάζεται αποδεικτικά στοιχεία για μία συναλλαγή. Χρησιμοποίησε το στενότερο κατάλληλο viewing key όταν ο λογιστής χρειάζεται συνεχή πρόσβαση σε πολλές συναλλαγές ή σε μια πλήρη περίοδο αναφοράς.

## Μια ροή εργασίας ασφαλής για την ιδιωτικότητα

Το ZIP 311 δεν είναι ακόμη ένα ολοκληρωμένο, ευρέως αναπτύξιμο πρότυπο πορτοφολιού. Όταν γίνουν διαθέσιμα συμβατά εργαλεία αποστολέα και επαληθευτή, χρησιμοποίησε αυτή τη λίστα ελέγχου:

1. **Επιβεβαίωσε πρώτα τη συμβατότητα.** Και τα δύο εργαλεία πρέπει να υποστηρίζουν την ίδια μορφή γνωστοποίησης και το θωρακισμένο pool που χρησιμοποιεί η πληρωμή.
2. **Επίλυσε πρώτα τα συνηθισμένα προβλήματα.** Έλεγξε τον συγχρονισμό του πορτοφολιού, το αναγνωριστικό συναλλαγής, τον αριθμό επιβεβαιώσεων, την κατάσταση λήξης και τα αρχεία του παραλήπτη προτού αποκαλύψεις ιδιωτικές λεπτομέρειες.
3. **Ζήτησε μια πρόκληση.** Για μια διαφωνία, ο επαληθευτής θα πρέπει να παρέχει έναν νέο αριθμό παραγγελίας ή τυχαία πρόκληση, ώστε η γνωστοποίηση να συνδέεται με το αίτημα αυτό.
4. **Επίλεξε μόνο την απαιτούμενη έξοδο.** Μην συμπεριλαμβάνεις άσχετες εξόδους από την ίδια συναλλαγή.
5. **Προεπισκόπησε κάθε αποκαλυπτόμενο πεδίο.** Έλεγξε τον παραλήπτη, το ποσό, το σημείωμα, την απόδειξη διεύθυνσης αποστολέα και την πρόκληση πριν από την εξαγωγή.
6. **Κοινοποίησε μέσω ιδιωτικού καναλιού.** Μια γνωστοποίηση δεν είναι μυστικό spending key, αλλά οποιοσδήποτε τη λαμβάνει μπορεί να διατηρήσει ή να αναδιανείμει τις πληροφορίες που αποκαλύπτει.
7. **Επαλήθευσε έναντι της αλυσίδας.** Ο επαληθευτής πρέπει να ανακτήσει την ακριβή συναλλαγή από έναν αξιόπιστο κόμβο, να επιβεβαιώσει ότι βρίσκεται στο προβλεπόμενο δίκτυο και μπλοκ και έπειτα να επικυρώσει τη γνωστοποίηση.
8. **Κατέγραψε το αποτέλεσμα, όχι πρόσθετα μυστικά.** Διατήρησε μόνο ό,τι απαιτεί η διαδικασία διαφωνίας, ανάληψης, δωρεάς ή λογιστικής.

Αν το πορτοφόλι δεν μπορεί να δημιουργήσει γνωστοποίηση, μην αντικαταστήσεις μια πλήρη γνωστοποίηση με ένα πλήρες viewing key χωρίς να κατανοείς το ευρύτερο και μόνιμο εύρος του. Ρώτησε αν ο παραλήπτης μπορεί να επιβεβαιώσει την πληρωμή από τα δικά του αρχεία πορτοφολιού ή να δεχτεί αντί γι’ αυτό ένα λιγότερο ευαίσθητο αρχείο.

## Τι δεν αποδεικνύει μια έγκυρη γνωστοποίηση

Μια επιτυχής επαλήθευση δεν αποδεικνύει:

- Ότι η συναλλαγή έχει αρκετές επιβεβαιώσεις για την πολιτική κινδύνου του επαληθευτή
- Ότι μια αναδιοργάνωση της αλυσίδας δεν μπορεί να αφαιρέσει μια πρόσφατη συναλλαγή
- Ότι παραδόθηκαν αγαθά ή υπηρεσίες
- Ότι απαιτείται επιστροφή χρημάτων ή αντιλογισμός χρέωσης
- Ότι ο αποστολέας ελέγχει μια συγκεκριμένη διεύθυνση, εκτός αν περιλαμβάνεται κατάλληλη απόδειξη διεύθυνσης
- Ότι το πρόσωπο που παρουσιάζει τη γνωστοποίηση έχει μια ισχυριζόμενη πραγματική ταυτότητα
- Ότι μη γνωστοποιημένες έξοδοι, άλλες συναλλαγές ή το υπόλοιπο του πορτοφολιού έχουν κάποια συγκεκριμένη αξία
- Ότι η γνωστοποίηση παραμένει ιδιωτική αφού κοινοποιηθεί

Ο επαληθευτής πρέπει να ελέγχει χωριστά τη συμπερίληψη στην αλυσίδα και την κατάσταση επιβεβαίωσης. Η διαδικασία επαλήθευσης του ZIP 311 υποθέτει ότι ο καλών έχει ήδη λάβει την εξορυγμένη συναλλαγή και το ύψος του μπλοκ της.

## Τρέχοντες περιορισμοί

Αντιμετώπισε το ZIP 311 ως προτεινόμενο πρότυπο, όχι ως υπόσχεση ότι ένα τρέχον πορτοφόλι διαθέτει λειτουργικό κουμπί **Απόδειξη πληρωμής**.

Το προσχέδιο ορίζει επί του παρόντος δαπάνες και εξόδους Sapling, αλλά εξακολουθεί να περιέχει ανολοκλήρωτα στοιχεία για το Orchard, τις διαφανείς εισόδους, την κωδικοποίηση της γνωστοποίησης, τη διαχείριση εκδόσεων και τον τρόπο με τον οποίο τα πορτοφόλια πρέπει να εμφανίζουν διαφορετικά επίπεδα εγκυρότητας. Η υλοποίηση αναφοράς του αναφέρεται επίσης ως «TBD». Όπως είναι γραμμένο, δεν ορίζει γνωστοποιήσεις πληρωμών για πληρωμές Orchard ή Ironwood.

Ο αποστολέας μπορεί επίσης να μην μπορεί να γνωστοποιήσει μια έξοδο, αν η συναλλαγή δημιουργήθηκε σκόπιμα χωρίς εξερχόμενο viewing key για εκείνη την έξοδο. Το ZIP 311 διατηρεί αυτή την επιλογή ιδιωτικότητας αντί να δημιουργεί μια νέα διαδρομή ανάκτησης.

Παλαιότερη τεκμηρίωση περιγράφει τις πειραματικές εντολές `z_getpaymentdisclosure` και `z_validatepaymentdisclosure` στο `zcashd`. Αυτές οι εντολές υποστήριζαν **μόνο εξόδους Sprout JoinSplit**, όχι τον σχεδιασμό Sapling στο ZIP 311, και έχουν καταργηθεί. Το `zcashd` έφτασε στην τελική διακοπή υποστήριξής του τον Ιούλιο του 2026. Μη χρησιμοποιείς αυτή την παλαιά περιγραφή ως οδηγίες για τρέχοντα κεφάλαια.

Αυτά τα κενά δεν καθιστούν την ιδέα άχρηστη. Εξηγούν γιατί ένας προσεκτικός οδηγός πρέπει να διαχωρίζει το μοντέλο ιδιωτικότητας και τις περιπτώσεις χρήσης από λογισμικό που είναι έτοιμο για συνηθισμένους χρήστες.

## Συχνές ερωτήσεις

### Μπορώ να αποδείξω μια θωρακισμένη πληρωμή μόνο με το αναγνωριστικό συναλλαγής;

Όχι. Το αναγνωριστικό μπορεί να προσδιορίσει τη συναλλαγή και την κατάσταση επιβεβαίωσής της, αλλά ο θωρακισμένος παραλήπτης, το ποσό και το σημείωμα δεν είναι δημόσια.

### Είναι μια γνωστοποίηση πληρωμής το ίδιο με ένα viewing key;

Όχι. Μια γνωστοποίηση περιορίζεται σε επιλεγμένες λεπτομέρειες μίας συναλλαγής. Ένα viewing key μπορεί να αποκαλύπτει αντίστοιχη δραστηριότητα για μια διεύθυνση ή λογαριασμό με την πάροδο του χρόνου.

### Μπορεί ο παραλήπτης να δημιουργήσει την απόδειξη του αποστολέα;

Όχι σύμφωνα με τον σχεδιασμό του ZIP 311. Μια έγκυρη γνωστοποίηση πρέπει να αποδεικνύει εξουσία δαπάνης για τουλάχιστον μία είσοδο. Ο παραλήπτης μπορεί να επιβεβαιώσει μια πληρωμή χρησιμοποιώντας τα δικά του αρχεία πορτοφολιού, αλλά αυτός είναι διαφορετικός ισχυρισμός.

### Μπορώ να ανακαλέσω μια γνωστοποίηση αφού την κοινοποιήσω;

Όχι. Δεν παρέχει μελλοντική πρόσβαση σε λογαριασμό όπως ένα viewing key, αλλά τα αποκαλυπτόμενα δεδομένα και η απόδειξη μπορούν να αντιγραφούν. Κοινοποίησέ τη με την ίδια προσοχή που θα έδειχνες για οποιοδήποτε ιδιωτικό οικονομικό αρχείο.

### Η επαλήθευση μετακινεί ή κλειδώνει οποιαδήποτε ZEC;

Όχι. Η δημιουργία ή επαλήθευση μιας γνωστοποίησης δεν δαπανά, επιστρέφει, δεσμεύει ή αντιστρέφει κεφάλαια.

### Τι πρέπει να χρησιμοποιήσω σήμερα αν το πορτοφόλι μου δεν έχει δυνατότητα γνωστοποίησης;

Ξεκίνα με τα αρχεία πορτοφολιού του παραλήπτη, το αναγνωριστικό συναλλαγής και την κατάσταση επιβεβαίωσης, μια αναφορά τιμολογίου στο κρυπτογραφημένο σημείωμα ή άλλη αμοιβαία αποδεκτή απόδειξη. Χρησιμοποίησε ένα viewing key μόνο όταν το ευρύτερο εύρος του χρειάζεται πραγματικά και είναι κατανοητό.
