# Προγράμματα περιήγησης ιστού

1. **Brave:** Ένα από τα πιο εξέχοντα και ασφαλή προγράμματα περιήγησης στην αγορά σήμερα. Μπλοκάρει διαφημίσεις και trackers που παραβιάζουν την ιδιωτικότητα. Μπλοκάρει την αποθήκευση δεδομένων από τρίτους. 

2. **Mulvad:** Ένα πρόγραμμα περιήγησης ιστού με επίκεντρο την ιδιωτικότητα, που αναπτύχθηκε σε συνεργασία μεταξύ του Mullvad VPN και του έργου Tor. Δημιουργήθηκε για να ελαχιστοποιεί την παρακολούθηση και το fingerprinting

3. **Tor:** Αυτό το πρόγραμμα περιήγησης μπλοκάρει plugins όπως τα Flash, RealPlayer, QuickTime και άλλα: μπορούν να χειραγωγηθούν ώστε να αποκαλύψουν τη διεύθυνση IP σου. Δεν συνιστούμε να εγκαταστήσεις πρόσθετα add-ons ή plugins στο πρόγραμμα περιήγησης Tor


## Ποιες είναι οι παράμετροι ασφάλειας όταν επιλέγεις ένα πρόγραμμα περιήγησης ιστού;

Όταν επιλέγεις ένα πρόγραμμα περιήγησης ιστού, υπάρχουν μερικά πράγματα που πρέπει να έχεις υπόψη: Οι ευπάθειες ασφαλείας και τα exploits συνήθως ανακαλύπτονται τακτικά. Ορισμένα προγράμματα περιήγησης μπορούν να ανιχνευθούν με κάποιον τρόπο, όμως υπάρχουν προγράμματα περιήγησης που σου επιτρέπουν να περιηγείσαι ανώνυμα - το πρόγραμμα περιήγησης [Tor](https://download.torproject.org/), για παράδειγμα. 

**Fingerprinting**: Αν θέλεις να διατηρήσεις ιδιωτικά πράγματα όπως τα softwares που είναι εγκατεστημένα στη συσκευή σου, τη διαμόρφωση hardware και άλλα, σκέψου να αναζητήσεις ένα πρόγραμμα περιήγησης ιστού που υποστηρίζει τη λειτουργία ανθεκτικότητας στο fingerprinting. 

**Δοκιμή HTTPS**: Μια άλλη παράμετρος ασφάλειας που πρέπει να εξετάσεις όταν επιλέγεις ένα πρόγραμμα περιήγησης ιστού είναι το πρωτόκολλο δοκιμής HTTPS, το οποίο βοηθά στην κρυπτογράφηση της σύνδεσης με τον ιστότοπο και αποκρύπτει cookies, URLs και άλλους τύπους ευαίσθητων metadata. Με το HTTPS, η σύνδεση είναι κρυπτογραφημένη και κανένα τρίτο μέρος στο δίκτυο δεν μπορεί να διαβάσει το περιεχόμενο που μεταφέρεται μεταξύ του server και του προγράμματος περιήγησής σου. 

**Προστασία από tracking cookies**: Επιπλέον, μεγάλο μέρος των ιστοσελίδων στον παγκόσμιο ιστό έχει κρυφούς trackers τρίτων· αυτοί οι trackers διαβάζουν και γράφουν cookies στο πρόγραμμα περιήγησής σου. Αυτά τα cookies μπορεί να αποτελούν κακόβουλες απειλές, επειδή μπορούν να χρησιμοποιηθούν για την παρακολούθηση της περιήγησής σου σε ιστότοπους· για να αποτρέψεις αυτή την παρακολούθηση, επίλεξε ένα πρόγραμμα περιήγησης ιστού που μπλοκάρει άγνωστα cookies περιήγησης.

**Δοκιμή πλοήγησης**: Καθώς μεταβαίνεις από μια ιστοσελίδα σε άλλη, θα συναντήσεις πολλούς συνδέσμους (μερικοί είναι εσωτερικοί σύνδεσμοι, ενώ άλλοι παραπέμπουν σε άλλον ιστότοπο). Όταν κάνεις κλικ σε αυτούς τους συνδέσμους, ορισμένα browser APIs επιτρέπουν στον πρώτο ιστότοπο να επικοινωνεί με τον δεύτερο. Για να το επιλύσεις αυτό, επίλεξε ένα πρόγραμμα περιήγησης ιστού που εμποδίζει τους ιστότοπους να μοιράζονται δεδομένα παρακολούθησης όταν κάνεις κλικ σε έναν σύνδεσμο. Όταν επιλέγεις το πρόγραμμα περιήγησης που θεωρείς ότι μπορεί να καλύψει τις ανάγκες σου, βεβαιώσου ότι παρέχει ισχυρές λειτουργίες ιδιωτικότητας και βασικές λειτουργίες, όπως ενσωματωμένα ad blockers και άλλα παρόμοια. Επιπλέον, πολλά από αυτά τα προγράμματα περιήγησης ιστού υποστηρίζουν extensions και add-ons, και μερικές φορές αυτά τα extensions μπορεί να ενέχουν κινδύνους ασφαλείας· φρόντισε να εγκαθιστάς πάντα αυτά τα extensions από ένα ασφαλές οικοσύστημα ή αξιόπιστες πηγές.
 
## Ενσωμάτωση πορτοφολιού στο πρόγραμμα περιήγησης Brave Zcash

Το πρόγραμμα περιήγησης Brave ανοίγει τον δρόμο για το οικοσύστημα Web3. Πώς; Πάνω από 2 εκατομμύρια unstoppable domains μπορούν πλέον να αξιοποιηθούν για την εμφάνιση αποκεντρωμένων ιστότοπων. Με τις ισχυρές λειτουργίες ασφαλείας του προγράμματος περιήγησης Brave, οι άνθρωποι μπορούν να εξερευνούν το διαδίκτυο χωρίς να παρακολουθούνται. Τα Brave και Zcash ενώνουν τις δυνάμεις τους για να φέρουν νέα εργαλεία ιδιωτικότητας στο οικοσύστημα Web3. Για μεγαλύτερα οφέλη, το Brave θα ενσωματωνόταν γρήγορα με το πρωτόκολλο Zcash μέσω του ενσωματωμένου crypto πορτοφολιού του Brave, για να φέρει επανάσταση στις crypto συναλλαγές - Αυτή η ενσωμάτωση θα επέτρεπε στους χρήστες να αποθηκεύουν, να στέλνουν και να λαμβάνουν με ασφάλεια ZEC πολύ εύκολα, καθώς και άλλα crypto νομίσματα. Η συνεργασία μεταξύ του προγράμματος περιήγησης ιστού Brave και του Zcash θα άλλαζε πραγματικά τα δεδομένα, καθώς οι χρήστες θα είχαν μεγαλύτερο έλεγχο στη δραστηριότητά τους στο Web3. 

Ένα ακόμη ενδιαφέρον στοιχείο για το πρόγραμμα περιήγησης Brave και την ενσωμάτωση Zcash είναι η λειτουργία ιδιωτικής και αποκεντρωμένης ανταλλαγής μηνυμάτων· οι Brave, ECC και η ομάδα του Ιδρύματος Filecoin ανοίγουν τον δρόμο για μια λειτουργία βασισμένη στην ιδιωτικότητα στο πρόγραμμα περιήγησης Brave — αυτή η συνεργασία στοχεύει να προσφέρει ιδιωτικά μηνύματα και μετάδοση πολυμέσων μέσω του πρωτοκόλλου Zcash. Εδώ, το Interplanetary File System (IPFS) θα διαδραματίσει ουσιαστικό ρόλο στην παροχή δυνατότητας ασφαλούς αποθήκευσης για το κρυπτογραφημένο περιεχόμενο.
