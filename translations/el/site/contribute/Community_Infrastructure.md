# Πλαίσιο υποδομής κοινότητας του ZecHub


### Υποδομή κοινότητας 

Το πρόγραμμα ανταμοιβών ZecHub είναι η αμειβόμενη οδός για αυτήν την εργασία: [ZEC Bounties](https://bounties.zechub.wiki/). Πώς να επιλέξεις έναν αριθμό ZEC: [πολιτική ποσών ανταμοιβών](https://bounties.zechub.wiki/docs/bounty-amounts). Ροή εργασίας συνεισφερόντων: [Συνεισφορά στο ZecHub](https://zechub.wiki/contribute/contributing-guide).
