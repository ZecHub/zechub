# Τήρηση αρχείων με θωρακισμένο ZEC

## TL;DR

- Τα θωρακισμένα κεφάλαια είναι ιδιωτικά, αλλά μπορείς και πάλι να τηρείς καθαρά, πλήρη οικονομικά αρχεία
- Τα σημειώματα λειτουργούν ως γραμμές στο λογιστικό βιβλίο σου, όπως ένας αριθμός τιμολογίου ή ο σκοπός μιας πληρωμής
- Ένα viewing key επιτρέπει σε εσένα ή σε κάποιον που επιλέγεις, όπως έναν λογιστή, να εξετάζει το ιστορικό σου χωρίς να το δημοσιοποιεί
- Μπορείς να υπολογίζεις συνολικά τα έσοδα και τις δαπάνες για οποιαδήποτε περίοδο, όπως χρειάζεσαι για αναφορές ή φορολογία
- Τίποτα από αυτά δεν αποδυναμώνει την ιδιωτικότητά σου, επειδή εσύ αποφασίζεις ποιος βλέπει τι

<br/>

## Σε ποιον απευθύνεται;

- Ελεύθερους επαγγελματίες και μικρές επιχειρήσεις που πληρώνονται σε ZEC
- Οποιονδήποτε χρειάζεται να τηρεί λογιστικά βιβλία διατηρώντας παράλληλα την ιδιωτικότητά του
- Άτομα που ετοιμάζουν αρχεία για έναν λογιστή ή για φορολογία

<br/>

## Η πρόκληση

Η ιδιωτικότητα και η τήρηση αρχείων μπορεί να μοιάζουν αντίθετες. Αν οι συναλλαγές σου είναι θωρακισμένες, τα ποσά και οι διευθύνσεις αποκρύπτονται από το κοινό, οπότε πώς τηρείς σωστά βιβλία ή δείχνεις το εισόδημά σου σε έναν λογιστή;

Με το Zcash αυτό είναι ένα ψευδές δίλημμα. Οι θωρακισμένες συναλλαγές αποκρύπτουν τη δραστηριότητά σου από όλους από προεπιλογή, αλλά το Zcash σου παρέχει επίσης εργαλεία για να αποκαλύπτεις τα δικά σου αρχεία στα άτομα που τα χρειάζονται, με τους δικούς σου όρους. Παραμένεις ιδιωτικός απέναντι στον κόσμο και ταυτόχρονα ανοιχτός απέναντι στον λογιστή σου.

<br/>

## Τα σημειώματα είναι το λογιστικό βιβλίο σου

Κάθε θωρακισμένη συναλλαγή (z προς z) μπορεί να περιέχει ένα κρυπτογραφημένο [σημείωμα](/using-zcash/memos). Για την τήρηση αρχείων, στο σημείωμα γράφεις τον σκοπό της πληρωμής: έναν αριθμό τιμολογίου, ένα όνομα πελάτη, έναν κωδικό έργου ή μια σύντομη σημείωση όπως «ενοίκιο Μαρτίου».

Επειδή το σημείωμα ταξιδεύει μαζί με τη συναλλαγή και είναι αναγνώσιμο μόνο από τα εμπλεκόμενα μέρη, γίνεται μια ιδιωτική γραμμή στα βιβλία σου. Όταν εσύ ή ο πελάτης σου συμπεριλαμβάνετε ένα σαφές σημείωμα σε κάθε πληρωμή, το ιστορικό συναλλαγών σου μετατρέπεται σε ένα χρήσιμο λογιστικό βιβλίο αντί για μια λίστα ποσών χωρίς πλαίσιο.

Μια απλή συνήθεια: συμφώνησε με τους πελάτες σου να συμπεριλαμβάνουν πάντα τον αριθμό τιμολογίου στο σημείωμα. Αργότερα, η αντιστοίχιση πληρωμών με τιμολόγια γίνεται απλή.

<br/>

## Εξέταση του δικού σου ιστορικού

Για να τηρείς βιβλία, χρειάζεται να βλέπεις τη δική σου δραστηριότητα. Το πορτοφόλι σου διατηρεί τα κλειδιά που αποκρυπτογραφούν τις θωρακισμένες συναλλαγές σου, οπότε μπορεί να σου δείξει την πλήρη εικόνα: ημερομηνίες, ποσά, ποιες συναλλαγές έλαβες, ποιες έστειλες και τα συνημμένα σημειώματα.

Αυτό είναι το μέρος που δεν μπορεί να δει το κοινό, αλλά μπορείς εσύ, επειδή τα δεδομένα είναι δικά σου. Η τακτική εξέταση του ιστορικού σου, αντί να το κάνεις στο τέλος του έτους, διατηρεί τα αρχεία σου ακριβή και διευκολύνει τον εντοπισμό λαθών.

<br/>

## Κοινοποίηση αρχείων με έναν λογιστή

Όταν χρειάζεται κάποιος άλλος να δει τη θωρακισμένη δραστηριότητά σου, όπως ένας λογιστής ή ελεγκτής, δεν χρειάζεται να παραδώσεις τα spending keys σου ή να δημοσιοποιήσεις οτιδήποτε. Μοιράζεσαι ένα [viewing key](/zcash-tech/viewing-keys).

Ένα πλήρες viewing key είναι μόνο για ανάγνωση. Επιτρέπει στον κάτοχό του να βλέπει εισερχόμενες και εξερχόμενες συναλλαγές για μια διεύθυνση, συμπεριλαμβανομένων ποσών και σημειωμάτων, αλλά δεν του επιτρέπει ποτέ να μετακινήσει τα κεφάλαιά σου. Αυτό είναι που μπορείς με ασφάλεια να δώσεις σε έναν λογιστή. Λαμβάνει ακριβώς την ορατότητα που χρειάζεται, τα χρήματά σου παραμένουν υπό τον έλεγχό σου και ο υπόλοιπος κόσμος εξακολουθεί να μη βλέπει τίποτα.

Αυτό ονομάζεται επιλεκτική αποκάλυψη και είναι ένας από τους πρακτικούς λόγους που το θωρακισμένο Zcash λειτουργεί υπέρ της έντιμης τήρησης βιβλίων αντί εναντίον της.

<br/>

## Υπολογισμός συνόλων για μια περίοδο

Για τις περισσότερες αναφορές, χρειάζεσαι σύνολα για ένα χρονικό διάστημα: πόσα έλαβες αυτό το τρίμηνο, πόσα έστειλες, την καθαρή θέση σου. Εφόσον μπορείς να εξετάζεις το πλήρες ιστορικό σου, μπορείς να τα υπολογίζεις για όποια περίοδο επιλέξεις, έναν μήνα, ένα τρίμηνο ή ένα έτος.

Η συνεπής χρήση σημειωμάτων το διευκολύνει, επειδή μπορείς να ομαδοποιείς τις πληρωμές με βάση τον σκοπό τους και όχι μόνο την ημερομηνία και το ποσό.

<br/>

## Μια σημείωση για τη φορολογία

Οι φορολογικοί κανόνες διαφέρουν ανά χώρα και αλλάζουν με τον χρόνο, επομένως αυτές είναι γενικές πληροφορίες και όχι φορολογική συμβουλή. Σε πολλά μέρη, η λήψη ή η διάθεση κρυπτονομισμάτων μπορεί να έχει φορολογικές συνέπειες και ίσως αναμένεται να τηρείς αρχεία για όσα έλαβες, πότε τα έλαβες και την αξία τους εκείνη τη στιγμή.

Τα καλά νέα είναι ότι το θωρακισμένο Zcash δεν σε εμποδίζει να εκπληρώνεις αυτές τις υποχρεώσεις. Μπορείς να τηρείς πλήρη ιδιωτικά αρχεία, να υπολογίζεις τα σύνολά τους για την περίοδο που απαιτεί η φορολογική αρχή σου και να τα αποκαλύπτεις σε έναν λογιστή ή φορολογική αρχή χρησιμοποιώντας ένα viewing key, χωρίς να δημοσιοποιείς τη δραστηριότητά σου. Αν δεν είσαι βέβαιος για τις υποχρεώσεις σου, μίλησε με έναν καταρτισμένο επαγγελματία στη χώρα σου.

<br/>

## Συνηθισμένα λάθη που πρέπει να αποφύγεις

- Παράλειψη σημειωμάτων, που σε αφήνει με ποσά και χωρίς πλαίσιο στο τέλος του έτους
- Επαναχρησιμοποίηση μιας διεύθυνσης για τα πάντα, που δυσκολεύει τον διαχωρισμό πελατών ή σκοπών
- Αναμονή μέχρι τη φορολογική περίοδο για να εξετάσεις ένα έτος ιστορικού, αντί να τηρείς αρχεία καθώς προχωράς
- Κοινοποίηση ενός spending key όταν ένα viewing key μόνο για ανάγνωση είναι το μόνο που χρειάζεται ένας λογιστής
