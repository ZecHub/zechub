## Part 2: a few words in your glossary

These are words from your glossary that we'd like to double-check. For each one write `OK` to keep your word, or the word you prefer, and a short reason.

| # | English | Your word | Question | Your answer | Notes |
|---:|---|---|---|---|---|
| 1 | block | kizuizi | In everyday Swahili *kizuizi* also means "obstacle". Is it the right word for a block of transactions, or should it stay "block"? |  |  |
| 2 | note | dokezo | A Zcash note is a unit of value held by a shielded address. Does *dokezo* (a remark, a hint) work, or is another word (or English "note") better? |  |  |
| 3 | commitment | ahadi | In cryptography a commitment is a value that locks hidden data without showing it. *Ahadi* usually means "promise". Keep *ahadi*, or keep English "commitment"? |  |  |
| 4 | tools | kifaa / vifaa | *Kifaa* sounds like a physical device. For software tools ("Privacy Tools"), is *zana* better? |  |  |
| 5 | hardware wallet | pochi ya vifaa | Is *pochi ya vifaa* clear for a small physical device that holds your keys, or is there a more common phrase (or English "hardware wallet")? |  |  |
| 6 | decentralized | isiyodhibitiwa | *Isiyodhibitiwa* can sound like "uncontrolled / unregulated". Is that fine, or is *-liogatuliwa* (from *ugatuzi*) better? |  |  |
| 7 | Store (menu) | Duka | The Store menu link is the ZecHub merch shop. You had approved *Hifadhi*, which we read as "storage/archive". Is *Duka* (like Shop) right? |  |  |
