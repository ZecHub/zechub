# ZecHub website menus: Indonesian review

These are the labels of the ZecHub website's menus in Indonesian. They appear on every page, so they matter most.

**How to fill in:** in the **✅ Confirmed** column, write OK if the Indonesian label is right, or write the label you'd use. Add a note if needed. Keep labels short: they are menu entries, not sentences.

Names that stay in English in every language (brands, products, programmes) are listed at the end. They don't need checking.
