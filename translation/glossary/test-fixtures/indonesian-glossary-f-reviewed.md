# ZecHub wiki: Indonesian terminology (Bahasa Indonesia)

Thank you for helping! The ZecHub wiki (https://zechub.wiki) is being translated into Indonesian. All 218 pages will be translated, so every term below will be used the same way everywhere.

**How to fill in:** for each row, write the term to use in the **✅ Confirmed term** column. You can pick one of the options, write your own, or write "keep English". Add a note if the term should change in some contexts.

**Already fixed (no need to decide):** Zcash, ZEC, wallet names, and these protocol terms, which always stay in English when written exactly like this: **Viewing Key**, **Full Viewing Key**, **Incoming Viewing Key**, **Unified Address**, **ZK-SNARK**, **Orchard**, **Sapling**, **Ironwood**.
